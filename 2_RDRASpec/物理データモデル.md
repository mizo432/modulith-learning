## 1. 前提と設計方針

| 項目 | 方針 | 根拠・備考 |
|------|------|-----------|
| DB 製品 | **PostgreSQL**（Issue #560 で決定） | backend/build.gradle.kts の既存実装が PostgreSQL 前提で構築済み（JDBC ドライバ、Flyway の PostgreSQL 対応、Testcontainers PostgreSQL） |
| スキーマ | 事業領域ごとに分離し、Agiloom は `undecided_ag` スキーマ | 初期要望の制約「各事業領域は独立したデータベーススキーマを持つ」。スキーマ名は実装側の命名規則（undecided_<領域コード小文字>、backend/build.gradle.kts の Flyway 構成）に合わせた |
| 命名 | テーブル名・列名は小文字スネークケース。論理名を小文字化したものをそのまま使う | PostgreSQL の慣習に合わせ、論理モデルとの対応を機械的に追えるようにする |
| 主キー | 全テーブル **Snowflake ID**（物理型は BIGINT）。アプリ側で採番し、DB のシーケンス／IDENTITY は使わない | 支援サブドメイン（undecided.supporting.snowflake）に既存の SnowflakeIdGenerator があり、それを利用して取得する。詳細は 1.1 |
| 外部キー | モジュール（事業領域）内は FK 制約を張る。モジュール跨ぎは ID 参照のみで制約を張らない | Spring Modulith のモジュール境界を DB でも守るため |
| FK の削除時動作 | すべて `ON DELETE RESTRICT` | 削除ポリシー（物理削除しない）と整合する |
| 監査列 | 全テーブルに `created_at` / `updated_at`（TIMESTAMPTZ, NOT NULL）を統一配置。値は Spring Data JPA の監査機能（@CreatedDate / @LastModifiedDate）で自動付与する | 論理モデルで updated_at が無い Entity（SUCCESS_METRIC 等）にも物理側で追加する |
| 変更履歴 | **Hibernate Envers を利用する**（Issue #565 で決定）。監査対象 Entity の変更履歴を Envers の監査テーブルに記録する | 現行の backend/build.gradle.kts には Envers 未導入のため、実装時に依存追加が必要 |
| 楽観ロック | 全テーブルに `version BIGINT NOT NULL DEFAULT 0` を配置 | 排他制御は未設計だったため、物理側で先に器だけ用意する |
| 削除ポリシー | **物理削除はしない**（Issue #561 で決定）。論理削除列は持たず、ライフサイクルは状態コードで表現する。ただし表示用の Query テーブルがある場合は例外とし、その削除タイミングを別途決定する | 全画面 data_access に D が無かったこととも整合する |
| タイムゾーン | **日本時間（Asia/Tokyo）固定**（Issue #564 で決定）。DB・アプリとも JST で扱い、UTC 変換はしない | 国内向けシステムのため |
| 相関チェック | SUCCESS_METRIC の baseline / target_value の大小関係などの項目間チェックは DB 制約に入れず、**アプリ側の検証で担保する**（Issue #567 で決定） | 具体的な検証内容は項目検証仕様（ビジネスルールの機械可読化）で定義する |
| 状態・区分値 | コード値（英語）で保持し、CHECK 制約で値集合を固定する。**処理の分岐条件として使用する**（ADR-003） | 表示用の日本語ラベルは DB に持たず、アプリ側（enum）で対応付ける。対応表は 3 章 |
| カテゴリー | 処理の分岐には使用せず、**検索条件としてのみ使用する**。値は DB に保持する（ADR-004） | 更新頻度・出所・影響範囲・連絡方法など。CHECK 制約は付けず、初期値集合は項目辞書で定義する |

### 1.1 主キー：Snowflake ID の仕様

全テーブルの主キー（およびそれを参照する FK 列）は Snowflake ID とする。採番には支援サブドメインの既存実装を利用し、新規に採番の仕組みは作らない（Issue #568 で決定）。

| 項目 | 仕様 |
|------|------|
| 物理型 | BIGINT（符号付き64bit整数） |
| ビット構成 | 標準構成：符号 1bit ／ タイムスタンプ 41bit（ミリ秒）／ ノードID 10bit ／ シーケンス 12bit |
| 採番の責務 | 支援サブドメインの `SnowflakeIdGenerator`（undecided.supporting.snowflake）を利用して取得する。各モジュールは `nextIdValue()` で `SnowflakeId` を受け取る |
| DB 側の自動採番 | 使わない。DDL に IDENTITY / SEQUENCE の DEFAULT を付けない |
| エポック | 2025-01-01T00:00:00Z（EPOCH_MILLIS = 1735689600000）。既存実装（SnowflakeConfiguration）の定義に従う |
| ノードID の割り当て | `SnowflakeNodeLeaseManager` がリース方式で割り当てる（SnowflakeNode を DB で管理）。利用側が個別に決めることはしない |
| ソート性 | 時刻順に概ね単調増加する。作成順ソートの目安には使えるが、厳密な順序保証は created_at と併用する |
| 画面・API での扱い | JSON や画面では **string として扱う**。JavaScript の Number は 53bit までしか整数を正確に表せないため、数値のまま渡すと下位ビットが欠ける。論理モデルで ID が string 表記だったのはこの扱いと整合する |
| Java 側の表現 | 既存の値オブジェクト `SnowflakeId`（undecided.supporting.snowflake）を使う。JPA 用のコンバータも同パッケージに用意されている |

## 2. 論理型 → 物理型の対応

| 論理型 | 物理型 | 使い分け |
|--------|--------|---------|
| string（ID） | Snowflake ID（BIGINT） | 支援サブドメインの SnowflakeIdGenerator で採番。DB 保管は BIGINT、画面・API では string として扱う（1.1 参照） |
| string（名称系：title / name 等） | VARCHAR(200)（name 系は 100） | 桁数は現行値のまま進め、詳細設計で最終確定する（Issue #563） |
| string（本文系：description / content 等） | TEXT | 長さ上限を設けない |
| string（日付：start_date / end_date） | DATE | 時刻を持たない日付として具体化 |
| string（日時：created_at 等） | TIMESTAMPTZ | タイムゾーンは日本時間（Asia/Tokyo）固定（Issue #564） |
| string（状態以外のコード系） | VARCHAR(20〜50) | 項目ごとに桁を定義 |
| number | NUMERIC(20, 4)（金額・指標値）／ INTEGER（件数・年齢） | SUCCESS_METRIC の基準値・目標値は NUMERIC、回答数・年齢は INTEGER |
| enum | VARCHAR(20) + CHECK 制約 | 値集合は 3 章のコード表で定義 |

## 3. 状態・区分値コード表

| 対象 | 日本語（論理モデル／状態遷移表） | コード値 |
|------|-------------------------------|---------|
| PRODUCT_VISION.state | 下書き ／ 公開 ／ 更新中 | DRAFT ／ PUBLISHED ／ UPDATING |
| PRODUCT_GOAL.state | 未設定 ／ 進行中 ／ 達成 ／ 見送り | NOT_SET ／ IN_PROGRESS ／ ACHIEVED ／ POSTPONED |
| ISSUE.state | 新規 ／ 調査中 ／ 解決 ／ 保留 | NEW ／ INVESTIGATING ／ RESOLVED ／ ON_HOLD |
| HYPOTHESIS.state | 未検証 ／ 検証中 ／ 支持 ／ 反証 | UNVERIFIED ／ VERIFYING ／ SUPPORTED ／ REFUTED |
| REQUEST.state | 新規 ／ 検討中 ／ 採用 ／ 却下 | NEW ／ UNDER_REVIEW ／ ADOPTED ／ REJECTED |
| KANO_EVALUATION.classification | 当たり前品質 ／ 一元品質 ／ 魅力的品質 ／ 無関心品質 ／ 逆品質 | MUST_BE ／ ONE_DIMENSIONAL ／ ATTRACTIVE ／ INDIFFERENT ／ REVERSE |
| EXPERIMENT_PLAN.state | 下書き ／ 実施中 ／ 完了 | DRAFT ／ IN_PROGRESS ／ COMPLETED（ビジネスルール.md の状態遷移表に定義。Issue #562） |

## 4. DDL（PostgreSQL）

主キーはすべて Snowflake ID（アプリ側採番の BIGINT）のため、IDENTITY 等の自動採番は付けていない。FK 列も参照先と同じ Snowflake ID（BIGINT）。

```sql
CREATE SCHEMA IF NOT EXISTS undecided_ag;

-- プロダクトビジョン
CREATE TABLE undecided_ag.product_vision (
    product_vision_id BIGINT       NOT NULL,  -- Snowflake ID
    title             VARCHAR(200) NOT NULL,
    target            VARCHAR(200),
    problem           TEXT,
    future_vision     TEXT,
    description       TEXT,
    state             VARCHAR(20)  NOT NULL DEFAULT 'DRAFT'
                      CHECK (state IN ('DRAFT', 'PUBLISHED', 'UPDATING')),
    created_at        TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version           BIGINT       NOT NULL DEFAULT 0,
    CONSTRAINT pk_product_vision PRIMARY KEY (product_vision_id)
);

-- プロダクトゴール
CREATE TABLE undecided_ag.product_goal (
    product_goal_id   BIGINT       NOT NULL,  -- Snowflake ID
    product_vision_id BIGINT       NOT NULL,  -- Snowflake ID（FK）
    title             VARCHAR(200) NOT NULL,
    description       TEXT,
    start_date        DATE         NOT NULL,  -- ビジネスルール3「ゴール期間の明示」より NOT NULL とした
    end_date          DATE         NOT NULL,
    state             VARCHAR(20)  NOT NULL DEFAULT 'NOT_SET'
                      CHECK (state IN ('NOT_SET', 'IN_PROGRESS', 'ACHIEVED', 'POSTPONED')),
    created_at        TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version           BIGINT       NOT NULL DEFAULT 0,
    CONSTRAINT pk_product_goal PRIMARY KEY (product_goal_id),
    CONSTRAINT fk_product_goal_vision FOREIGN KEY (product_vision_id)
        REFERENCES undecided_ag.product_vision (product_vision_id) ON DELETE RESTRICT,
    CONSTRAINT ck_product_goal_period CHECK (start_date <= end_date)
);

-- 成功指標
CREATE TABLE undecided_ag.success_metric (
    success_metric_id BIGINT        NOT NULL,  -- Snowflake ID
    product_goal_id   BIGINT        NOT NULL,  -- Snowflake ID（FK）
    name              VARCHAR(100)  NOT NULL,
    unit              VARCHAR(20),
    baseline          NUMERIC(20,4),
    target_value      NUMERIC(20,4),
    data_source       VARCHAR(200),
    update_frequency  VARCHAR(50),
    created_at        TIMESTAMPTZ   NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        TIMESTAMPTZ   NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version           BIGINT        NOT NULL DEFAULT 0,
    CONSTRAINT pk_success_metric PRIMARY KEY (success_metric_id),
    CONSTRAINT fk_success_metric_goal FOREIGN KEY (product_goal_id)
        REFERENCES undecided_ag.product_goal (product_goal_id) ON DELETE RESTRICT
);

-- 課題
CREATE TABLE undecided_ag.issue (
    issue_id   BIGINT       NOT NULL,  -- Snowflake ID
    title      VARCHAR(200) NOT NULL,
    background TEXT,
    impact     TEXT,
    state      VARCHAR(20)  NOT NULL DEFAULT 'NEW'
               CHECK (state IN ('NEW', 'INVESTIGATING', 'RESOLVED', 'ON_HOLD')),
    reporter   VARCHAR(100),
    created_at TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version    BIGINT       NOT NULL DEFAULT 0,
    CONSTRAINT pk_issue PRIMARY KEY (issue_id)
);

-- 仮説
CREATE TABLE undecided_ag.hypothesis (
    hypothesis_id       BIGINT       NOT NULL,  -- Snowflake ID
    issue_id            BIGINT       NOT NULL,  -- Snowflake ID（FK）
    title               VARCHAR(200) NOT NULL,
    hypothesis_content  TEXT,
    verification_method VARCHAR(200),
    state               VARCHAR(20)  NOT NULL DEFAULT 'UNVERIFIED'
                        CHECK (state IN ('UNVERIFIED', 'VERIFYING', 'SUPPORTED', 'REFUTED')),
    created_at          TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version             BIGINT       NOT NULL DEFAULT 0,
    CONSTRAINT pk_hypothesis PRIMARY KEY (hypothesis_id),
    CONSTRAINT fk_hypothesis_issue FOREIGN KEY (issue_id)
        REFERENCES undecided_ag.issue (issue_id) ON DELETE RESTRICT
);

-- 実験計画
CREATE TABLE undecided_ag.experiment_plan (
    experiment_plan_id BIGINT      NOT NULL,  -- Snowflake ID
    hypothesis_id      BIGINT      NOT NULL,  -- Snowflake ID（FK）
    title              VARCHAR(200) NOT NULL,
    plan_content       TEXT,
    result             TEXT,
    learning           TEXT,
    state              VARCHAR(20) NOT NULL DEFAULT 'DRAFT'
                       CHECK (state IN ('DRAFT', 'IN_PROGRESS', 'COMPLETED')),
    created_at         TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at         TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version            BIGINT      NOT NULL DEFAULT 0,
    CONSTRAINT pk_experiment_plan PRIMARY KEY (experiment_plan_id),
    CONSTRAINT fk_experiment_plan_hypothesis FOREIGN KEY (hypothesis_id)
        REFERENCES undecided_ag.hypothesis (hypothesis_id) ON DELETE RESTRICT
);

-- 要望
CREATE TABLE undecided_ag.request (
    request_id BIGINT       NOT NULL,  -- Snowflake ID
    issue_id   BIGINT       NOT NULL,  -- Snowflake ID（FK）
    title      VARCHAR(200) NOT NULL,
    content    TEXT,
    source     VARCHAR(100),
    state      VARCHAR(20)  NOT NULL DEFAULT 'NEW'
               CHECK (state IN ('NEW', 'UNDER_REVIEW', 'ADOPTED', 'REJECTED')),
    created_at TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version    BIGINT       NOT NULL DEFAULT 0,
    CONSTRAINT pk_request PRIMARY KEY (request_id),
    CONSTRAINT fk_request_issue FOREIGN KEY (issue_id)
        REFERENCES undecided_ag.issue (issue_id) ON DELETE RESTRICT
);

-- Kano評価
CREATE TABLE undecided_ag.kano_evaluation (
    kano_evaluation_id    BIGINT      NOT NULL,  -- Snowflake ID
    request_id            BIGINT      NOT NULL,  -- Snowflake ID（FK）
    question_id           VARCHAR(50),
    functional_question   TEXT,
    non_functional_question TEXT,
    response_count        INTEGER     CHECK (response_count >= 0),
    classification        VARCHAR(20)
                          CHECK (classification IN ('MUST_BE', 'ONE_DIMENSIONAL', 'ATTRACTIVE', 'INDIFFERENT', 'REVERSE')),
    created_at            TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at            TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version               BIGINT      NOT NULL DEFAULT 0,
    CONSTRAINT pk_kano_evaluation PRIMARY KEY (kano_evaluation_id),
    CONSTRAINT fk_kano_evaluation_request FOREIGN KEY (request_id)
        REFERENCES undecided_ag.request (request_id) ON DELETE RESTRICT
);

-- ステークホルダー
CREATE TABLE undecided_ag.stakeholder (
    stakeholder_id BIGINT       NOT NULL,  -- Snowflake ID
    name           VARCHAR(100) NOT NULL,
    organization   VARCHAR(100),
    interest       VARCHAR(200),
    impact_scope   VARCHAR(50),
    contact_method VARCHAR(50),
    registered_at  TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at     TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version        BIGINT       NOT NULL DEFAULT 0,
    CONSTRAINT pk_stakeholder PRIMARY KEY (stakeholder_id)
);

-- ペルソナ
CREATE TABLE undecided_ag.persona (
    persona_id    BIGINT       NOT NULL,  -- Snowflake ID
    name          VARCHAR(100) NOT NULL,
    age           INTEGER      CHECK (age BETWEEN 0 AND 150),
    occupation    VARCHAR(100),
    needs         TEXT,
    usage_context TEXT,
    created_at    TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version       BIGINT       NOT NULL DEFAULT 0,
    CONSTRAINT pk_persona PRIMARY KEY (persona_id)
);

-- ユーザージャーニー
CREATE TABLE undecided_ag.user_journey (
    user_journey_id BIGINT       NOT NULL,  -- Snowflake ID
    persona_id      BIGINT       NOT NULL,  -- Snowflake ID（FK）
    title           VARCHAR(200) NOT NULL,
    scene           VARCHAR(200),
    action          TEXT,
    problem         TEXT,
    emotion         VARCHAR(100),
    opportunity     TEXT,
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version         BIGINT       NOT NULL DEFAULT 0,
    CONSTRAINT pk_user_journey PRIMARY KEY (user_journey_id),
    CONSTRAINT fk_user_journey_persona FOREIGN KEY (persona_id)
        REFERENCES undecided_ag.persona (persona_id) ON DELETE RESTRICT
);
```
