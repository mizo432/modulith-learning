## 1. RDRA モデルドキュメントの配置

[ドキュメント格納先ディレクトリ命名規則 (Document Directory Naming Guidelines)](../docs/directory-name.guidelines.md)
を参照してください
構築したRDRAモデルは `docs/22 要件定義書` ディレクトリに格納されます。

### 事業領域ディレクトリ

`docs/22 要件定義書/` 直下には、事業領域ごとにサブディレクトリを作成します。

| ディレクトリ名            | 説明                         |
|---------------------------|------------------------------|
| `AD 住所レジストリ`       | 住所レジストリ事業領域       |
| `AG アジルーム`           | アジルーム事業領域           |
| `AR 承認申請`             | 承認申請事業領域             |
| `AS 関連付け`             | 関連付け事業領域             |
| `AZ 認可`                 | 認可事業領域                 |
| `CA カレンダーレジストリ` | カレンダーレジストリ事業領域 |
| `DO 開発運用`             | 開発運用事業領域             |
| `EF 電子帳票`             | 電子帳票事業領域             |
| `ER 元号レジストリ`       | 元号レジストリ事業領域       |
| `EX サンプル`             | サンプル事業領域             |
| `FI 金融機関レジストリ`   | 金融機関レジストリ事業領域   |
| `NT 通知`                 | 通知事業領域                 |
| `TA 税率レジストリ`       | 税率レジストリ事業領域       |

事業領域の命名規則は、`2文字コード + スペース + 日本語名` の形式です。

### 非機能要件サブディレクトリ

各事業領域配下の `01 非機能要件/` ディレクトリ内には、非機能要件一覧.md と 非機能要件一覧.tsv を配置します。

### 機能要件サブディレクトリ

各事業領域配下の `03 機能要件/` ディレクトリ内には、業務領域ごとにサブディレクトリを作成します。

各業務領域ディレクトリ内には、RDRAの4レイヤーに対応するサブディレクトリが構成されます：

| レイヤー         | ディレクトリ名     | 内容                                        |
|------------------|--------------------|---------------------------------------------|
| システム価値     | `01.システム価値/` | 要求、アクター、外部システム                |
| システム外部環境 | `02.外部環境/`     | 業務、BUC、アクティビティ、外部システム定義 |
| システム境界     | `03.システム境界/` | ユースケース、画面、イベント、UC複合図      |
| システム         | `04.システム/`     | 情報、状態、条件、バリエーション            |

### 用語集サブディレクトリ

各事業領域配下の `07 用語集/` ディレクトリ内には、用語集.md と 用語集.tsv を配置します。

### 関連ディレクトリ

- **`docs/11 事業領域/`**: 事業領域一覧 (MD/TSV) を格納します。
- **`docs/12 業務領域/`**: 業務領域一覧 (MD/TSV) を格納します。
- **`docs/13 非機能要件項目/`**: 非機能要件の大項目一覧を格納します。RDRA では参照のみで利用し、出力は行いません。
- **`docs/14 用語分類/`**: 用語分類一覧 (TSV) を格納します。

詳細なディレクトリ構造は [
`.agents/guidelines/docs/directory-name.guidelines.md`](../docs/directory-name.guidelines.md)
を参照してください。
