# ステップ7: RDRAモデルとして出力 チェックリスト

**目的**: 分析結果をRDRA Sheet形式（TSV）とRDRAGraph形式で出力する。

---

## 可視化のゴール

### システム再構築の場合

- [ ] アクター・外部システムを分かる範囲で洗い出す
- [ ] ビジネスで管理しているIDを洗い出す
- [ ] 状態の存在を認識できた場合に洗い出す
- [ ] ビジネスルールを洗い出す（存在が分かる程度）
- [ ] 区分・種別からバリエーションを整理する
- [ ] 業務を網羅的に出す
- [ ] 調査で明らかになった画面とイベントを適用する

### 保守開発の品質向上の場合

- [ ] アクター・外部システムを網羅的に整理する
- [ ] ビジネスで管理しているIDを全て洗い出す
- [ ] 状態遷移にUCを適用し欠けてるUCを洗い出す
- [ ] 条件につながるバリエーションを全て出す
- [ ] 業務・BUC・アクティビティ・UCは関連部署の担当者と共通認識が取れるベースを目指す

---

## 出力形式

分析結果を以下の形式で出力します：

| ファイル | 形式 | 内容 |
|---------|------|------|
| アクター.tsv | TSV | アクター群 / アクター / 説明 |
| 外部システム.tsv | TSV | 外部システム群 / 外部システム / 説明 |
| BUC.tsv | TSV | 業務 / BUC / 先 / アクティビティ / 次 / UC / 関連モデル1 / 関連オブジェクト1 / 関連モデル2 / 関連オブジェクト2 / 説明 |
| 情報.tsv | TSV | コンテキスト / 情報 / 属性 / 関連情報 / 状態モデル / バリエーション / 説明 |
| 状態.tsv | TSV | コンテキスト / 状態モデル / 状態 / 遷移UC / 遷移先状態 / 状態モデル・状態の説明 |
| 条件.tsv | TSV | コンテキスト / 条件 / 条件の説明 / バリエーション / 状態モデル |
| バリエーション.tsv | TSV | コンテキスト / バリエーション / 値 / 説明 |

### 出力チェック

- [ ] アクター.tsvを出力する
- [ ] 外部システム.tsvを出力する
- [ ] BUC.tsvを出力する
- [ ] 情報.tsvを出力する
- [ ] 状態.tsvを出力する
- [ ] 条件.tsvを出力する
- [ ] バリエーション.tsvを出力する
- [ ] RDRAGraph形式で視覚化する
