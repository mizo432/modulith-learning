# ステップ2: 入出力から整理 チェックリスト

**目的**: 信頼性の高い資料（画面・イベント）からRDRA形式に変換する。

---

## 画面から整理

### ① 画面を整理する

- [ ] 現在使われている画面をベースに画面一覧を作成する
- [ ] 画面がない場合は画面のハードコピーを取る
- [ ] 各画面の画面名を整理する
- [ ] 各画面の役割（登録・編集・照会・一覧など）を整理する
- [ ] 各画面の表示・入力項目を整理する

### ② 画面を分類しユースケースを求める

- [ ] 画面を機能単位で分類する
- [ ] 各画面が提供する機能からユースケース（UC）を導出する
- [ ] UCの命名ルール：「[情報]を[動詞]する」形式で命名する（例：「受注を登録する」）

### ③ 画面を使っているアクターを求める

- [ ] 各画面を誰が使うかを特定する
- [ ] アクターは役割として命名する（個人名や組織名は使わない）
- [ ] アクター群としてグループ化する

---

## イベントから整理

### ① イベントを整理する

- [ ] 外部とのインターフェース一覧を調べる
- [ ] インターフェース一覧がない場合はバッチ処理/APIから連携している部分を探す
- [ ] 連携する会社との資料（契約書など）を調べる

### ② イベントを分類しユースケースを求める

- [ ] イベントを機能単位で分類する
- [ ] 画面から求めたUCを再利用できる場合は再利用する
- [ ] 外部システムとの連携として新たなUCを導出する

### ③ イベントと外部システムの関係を整理する

- [ ] 各イベントがどの外部システムと連携するかを特定する
- [ ] 外部システムは役割に応じて分類する
- [ ] 外部システム群としてグループ化する
