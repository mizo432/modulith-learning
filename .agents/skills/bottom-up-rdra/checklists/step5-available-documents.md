# ステップ5: 手に入る資料から整理 チェックリスト

**目的**: 手に入った資料をベースとして整理し、対応するものがなければ類推して補完する。

---

## 機能一覧から

- [ ] 大中小の分類を一旦、業務・BUC・UCに当てはめる
- [ ] 全体を俯瞰しながら適切な単位に変えていく

---

## 機能詳細から

- [ ] 機能一覧に対応する形で詳細な機能を記述した資料があれば利用する
- [ ] 条件や区分を洗い出すのに利用する

---

## 契約書などから

- [ ] 契約書などの文書からビジネスルールを条件として洗い出す
- [ ] 条件につながるバリエーションを全て出す
- [ ] 仕組みとしてのルールは含めない
