# フェーズ1: データベース設計 チェックリスト

**目的**: 要件定義のRDRAモデルからデータベース設計を導出する。

**参照スキル**: [data-design](../data-design/SKILL.md)

---

## 出力ディレクトリの準備

- [ ] 出力先ディレクトリを特定する
  - `docs/23 詳細設計書/[事業領域コード]_[事業領域名]/01 データベース設計/`
- [ ] 事業領域コードと区分を `docs/11 事業領域/事業領域一覧.tsv` から確認する
- [ ] スキーマ名を決定する
  - 汎用の場合: `undecided_<業務領域コード>`
  - 汎用以外: `undecided_<事業領域コード>`

---

## テーブル一覧の作成

- [ ] 情報一覧からテーブルを導出する
- [ ] 各情報を1つのテーブルとして定義する
- [ ] 親子関係がある情報は親と子のテーブルに分割する
- [ ] 属性で構造を持っているものは別テーブルとして抜き出す
- [ ] `01 table一覧.md` と `01 table一覧.tsv` を出力する

---

## テーブルカラム定義の作成

- [ ] 各情報属性詳細 (`INF-[ID]_[名前]_情報属性一覧.md`) を読み込む
- [ ] 属性をカラムに変換する
  - 型の変換: Long→BIGINT, UUID→UUID, String→VARCHAR(N), Boolean→BOOLEAN, DateTime→TIMESTAMP, Enum→VARCHAR(N)
  - 必須/任意からNOT NULL制約を決定
  - 制約からCHECK制約を決定
- [ ] 標準カラムを追加する
  - `id BIGINT PRIMARY KEY`
  - `created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`
  - `updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`
  - `deleted_at TIMESTAMP NULL`
- [ ] 主キー・外部キー・ユニーク制約を定義する
- [ ] インデックスを定義する
  - 外部キーカラムにインデックスを適用
  - 検索条件として頻繁に使用されるカラムにインデックスを適用
- [ ] 各テーブルのカラム定義ファイルを `02 テーブルカラム定義/[テーブル名].md` に出力する

---

## 状態・バリエーションの定義

- [ ] ステート一覧から状態モデルを抽出する
- [ ] バリエーション一覧から列挙型を抽出する
- [ ] 状態・バリエーションをENUMまたはVARCHARカラムとして定義する
- [ ] 列挙値の説明をコメントとして追加する

---

## Flywayマイグレーションスクリプトの作成

- [ ] テーブル作成用のマイグレーションスクリプトを作成する
  - 配置先: `backend/src/main/resources/db/migration/[モジュール]/`
  - 命名規則: `V<バージョン>__<説明>.sql`
- [ ] スキーマ作成を含める
- [ ] インデックス作成を含める
- [ ] 標準カラムを含める

---

## View定義 (必要に応じて)

- [ ] 複雑な結合が必要な場合はViewを定義する
- [ ] `03 viewカラム定義/` にView定義を出力する

---

## 出力チェック

- [ ] 全情報がテーブルとして定義されているか確認する
- [ ] 全属性がカラムとして定義されているか確認する
- [ ] 状態・バリエーションが列挙型として定義されているか確認する
- [ ] 標準カラムが全テーブルに含まれているか確認する
- [ ] `data-design` スキルのガイドラインに従っているか確認する
- [ ] スキーマ名が正しいか確認する
