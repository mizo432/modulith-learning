# 要件分析チェックリスト (Requirement Checklist)

## Wiki ドキュメントの読み取り

- [ ] 対象となる Wiki ページまたは `src/doc/` 配下の Markdown ファイルを正確に特定したか
- [ ] 要件の階層構造（Epic → Feature → User Story）を把握したか
- [ ] 関連するドキュメント（現行システム分析、要求分析、要件定義等）を参照したか

## ビジネス能力の特定

- [ ] 要件がどのビジネスドメインに属するかを特定したか
    - 例: 顧客管理 (customerAccountMgmt)、売上管理 (productSaleMgmt/cashSaleMgmt)、部門管理
      (relationshipMgmt)
- [ ] 関連する Spring Modulith モジュールを特定したか
- [ ] ドメイン間の依存関係を把握したか

## 要件の整理

- [ ] 機能要件と非機能要件を分離したか
- [ ] 依存関係がある要件を特定したか
- [ ] 実装順序（優先度）を考慮したか
- [ ] MoSCoW 法（Must / Should / Could / Won't）で優先度を付与したか

## 受け入れ基準

- [ ] 各要件に対して明確で検証可能な受け入れ基準を定義したか
- [ ] 正常系のシナリオをカバーしたか
- [ ] 異常系のシナリオをカバーしたか
- [ ] 境界値やエッジケースを含めたか
