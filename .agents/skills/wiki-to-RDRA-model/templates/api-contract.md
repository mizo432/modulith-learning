## リクエスト

### URI

```
{HTTP_METHOD} /api/v1/{resource-path}/{id}
```

### パスパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------------|----|------|------|
|            |    |      |      |

### クエリパラメータ

| パラメータ | 型      | 必須   | 説明                           |
|------------|---------|--------|--------------------------------|
| page       | Integer | いいえ | ページ番号（デフォルト: 0）    |
| size       | Integer | いいえ | ページサイズ（デフォルト: 20） |
| sort       | String  | いいえ | ソートキー                     |

## レスポンス

### 正常系 (200 OK / 201 Created)

```json
{
  // レスポンスボディのJSONスキーマ
}
```

### 異常系

| ステータスコード          | 説明                 | レスポンス例                                       |
|---------------------------|----------------------|----------------------------------------------------|
| 400 Bad Request           | バリデーションエラー | `{"errors": [{"field": "xxx", "message": "xxx"}]}` |
| 401 Unauthorized          | 認証失敗             | -                                                  |
| 403 Forbidden             | 権限不足             | -                                                  |
| 404 Not Found             | リソース不存在       | `{"error": "Resource not found"}`                  |
| 500 Internal Server Error | サーバーエラー       | `{"error": "Internal server error"}`               |
