# ユースケース一覧

詳細なユースケースをリストアップします。

## ユースケース一覧

| ユースケースID | ユースケース名 | 説明 | アクター | 優先度 | ビジネスユースケース | 外部システム | 画面 | 帳票 |
|----------------|----------------|------|----------|--------|----------------------|--------------|------|------|
|                |                |      |          |        |                      |              |      |      |

> **注意**: ユースケースとビジネスユースケースの関連付けは必須です。各ユースケースに対応するビジネスユースケースを必ず指定してください。
> **注意**: ユースケースとアクターの関連付けは必須です。各ユースケースに対応するアクターのIDを必ず指定してください（例：AC-01）。
> **注意**:
>
アクター列にはアクターIDを表示し、アクター一覧ファイルにリンクしてください（例：[AC-01](../02.アクター/02.アクター一覧.md)）。
> **注意**: ユースケースと外部システムの関連付けは必須です。各ユースケースが連携する外部システムのIDを必ず指定してください（例：ES-01）。
> **注意**:
>
外部システム列には外部システムIDを表示し、外部システム定義ファイルにリンクしてください（例：[ES-01](../../02.外部環境/01.外部システム定義/ES-01%20データベース.md)）。
> **注意**: ユースケースと画面の関連付けはオプションです。関連する画面がある場合は画面IDを指定してください（例：SCR-01）。
> **注意**:
>
画面列には画面IDを表示し、画面定義ファイルにリンクしてください（例：[SCR-01](../../04.システム/04.画面/SCR-01%20データベース一覧画面.md)）。
> **注意**: ユースケースと帳票の関連付けはオプションです。関連する帳票がある場合は帳票IDを指定してください（例：RPT-01）。
> **注意**:
>
帳票列には帳票IDを表示し、帳票定義ファイルにリンクしてください（例：[RPT-01](../../04.システム/05.帳票/RPT-01%20データベース一覧帳票.md)）。
