# 利用シーン図（ユースケース図） - 図書館システム例

本ファイルは、Qiita記事「PlantUML で始めるリレーションシップ駆動要件分析 (RDRA)」を参考にした、
RDRAのダイアグラム例です。

題材は「図書館システム」で、会員登録・本の貸出・返却・予約などのユースケースを例にしています。

## 1. 利用シーン図 - 会員登録

本の貸出・返却時の単純化のために事前に会員登録を行うユースケース図です。

```plantuml
@startuml
title 利用シーン図 - 会員登録: BUC
left to right direction

actor 会員
actor 図書館員

frame 会員登録 {
    note right of 会員登録
        本の貸出・返却時の単純化のために事前に会員登録を行う
        既に図書カードを導入しているが、忘れる人が多いので図書カード以外での確認方法も欲しい
        新しい機器を持たない老人もいるので図書カードもそのまま残したい
        会員登録も利用者本人ができるようにしたい
    end note

    usecase 会員IDを発行する
    usecase 会員カードを作成する
}

frame 会員の確認 {
    note right of 会員の確認
        本（電子図書含む）の貸出の時の会員認証を簡単に行いたい
        図書カード等を忘れた場合にも口頭で対応できるようにしたい
    end note

    usecase 会員を特定する
}

:会員: -- 会員登録
:図書館員: -- 会員登録

会員登録 -- (会員IDを発行する)
会員登録 -- (会員カードを作成する)

:図書館員: -- 会員の確認
会員の確認 -- (会員を特定する)
@enduml
```

## 2. 利用シーン図 - 本の貸出

本の貸出に関するユースケース図です。

```plantuml
@startuml
title 利用シーン図 - 本の貸出: BUC
left to right direction

actor 会員
actor 図書館員

frame 本の貸出 {
    note right of 本の貸出
        会員が本を借りられるようにする
        貸出制限（冊数・期間）を管理したい
        遅延している会員には貸出を制限したい
    end note

    usecase 本を貸し出す
    usecase 貸出記録を作成する
    usecase 貸出制限をチェックする
}

frame 本の返却 {
    note right of 本の返却
        会員が本を返却できるようにする
        遅延料金を計算したい
        返却時に予約がある場合は取置処理をしたい
    end note

    usecase 本を受け取る
    usecase 返却記録を作成する
    usecase 遅延料金を計算する
}

:会員: -- 本の貸出
:図書館員: -- 本の貸出

本の貸出 -- (本を貸し出す)
本の貸出 -- (貸出記録を作成する)
本の貸出 -- (貸出制限をチェックする)

:会員: -- 本の返却
:図書館員: -- 本の返却

本の返却 -- (本を受け取る)
本の返却 -- (返却記録を作成する)
本の返却 -- (遅延料金を計算する)
@enduml
```

## 3. 関連情報

- **アクター**: 会員、図書館員
- **ビジネスユースケース (BUC)**: 会員登録、会員の確認、本の貸出、本の返却
- **ユースケース**:
  会員IDを発行する、会員カードを作成する、会員を特定する、本を貸し出す、貸出記録を作成する、貸出制限をチェックする、本を受け取る、返却記録を作成する、遅延料金を計算する

## 4. 補足

利用シーン図は、RDRAの「システム外部環境レイヤー」で使用するダイアグラムです。
業務フローをユースケースとして可視化し、誰がどの業務に参加するかを明確にします。
