# コミットメッセージテンプレート

## 形式

```
<type>(<scope>): <subject>

<body>

Refs #<issue_number>
```

## 例

### 機能追加

```
feat(account): ユーザー登録機能を追加

- メールアドレスとパスワードでの登録を実装
- 重複チェックとバリデーションを追加
- 登録成功時の通知メール送信機能を実装

Refs #123
```

### バグ修正

```
fix(login): ログインエラーを修正

- セッション切れ時のエラーハンドリングを改善
- エラーメッセージの表示を修正

Fixes #456
```

### ドキュメント更新

```
docs(readme): インストール手順を更新

- Docker 環境の構築手順を追加
- 必要な依存パッケージのリストを更新

Refs #789
```

### リファクタリング

```
refactor(auth): 認証ロジックを整理

- 認証処理を個別のクラスに分離
- 共通ロジックをユーティリティクラスに抽出

Refs #101
```

## タイプ一覧

| タイプ | 説明 |
|:---|:---|
| `feat` | 新規機能追加 |
| `fix` | バグ修正 |
| `docs` | ドキュメント変更 |
| `style` | コードスタイル修正 (フォーマット等) |
| `refactor` | リファクタリング (仕様変更なし) |
| `perf` | パフォーマンス改善 |
| `test` | テストコードの変更 |
| `chore` | 雑務 (ビルド設定等) |

## 注意事項

- **subject**: 50文字以内で簡潔に記載
- **body**: 改行して詳細を記載 (任意)
- **Issue 番号**: 必ず `Refs #<番号>` を記載
- **複数 Issue**: `Refs #123, #456` の形式で記載
- **解決時**: `Closes #123` または `Fixes #123` を使用
