# データベース設計チェックリスト (Database Design Checklist)

データベース設計時・実装時に以下の項目を確認してください。

### 1. データモデリング

- [ ] データモデルがドメイン駆動設計と整合している
- [ ] テーブル命名規則が守られている（スネークケース、複数形）
- [ ] 標準カラム（id, created_at, updated_at, deleted_at）が含まれている
- [ ] 主キー制約が定義されている
- [ ] ユニーク制約が適切に適用されている
- [ ] チェック制約でデータ整合性が保証されている

### 2. JPA/Hibernateマッピング

- [ ] JPAエンティティが @Table でスキーマ・テーブル名を明示している
- [ ] 関連マッピングで FetchType.LAZY がデフォルトとして使用されている
- [ ] N+1問題が @EntityGraph または JOIN FETCH で回避されている
- [ ] 論理削除が @SQLRestriction で実装されている

### 3. Flywayマイグレーション

- [ ] Flywayマイグレーションが事業領域ごとに分離されている
- [ ] マイグレーションスクリプトがバージョン管理されている

### 4. データアクセス

- [ ] リポジトリインターフェースがDomain層に定義されている
- [ ] クエリがパラメータ化されており、SQLインジェクション対策が施されている
- [ ] トランザクション境界が適切に定義されている
- [ ] 読み取り専用クエリに readOnly = true が指定されている
- [ ] ページネーションが大量データの取得に使用されている

### 5. パフォーマンス・セキュリティ

- [ ] インデックスが検索・結合・ソート条件に適用されている
- [ ] 機密データが暗号化されている
- [ ] 楽観的ロックが競合が発生するエンティティに適用されている

### 6. テスト

- [ ] テストでデータベース統合テストが実行されている
