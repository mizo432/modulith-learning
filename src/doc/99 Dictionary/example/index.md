# 用語辞書の記入例

## 目的

このファイルは、用語辞書テンプレートの使用方法を示す記入例です。実際のプロジェクトで使用される用語の定義例を示しています。

## 用語定義の例

以下に、各カテゴリの用語定義例を示します。

### 業務ドメイン

#### 顧客管理ドメイン

##### 顧客

| 項目      | 説明                                   |
|---------|--------------------------------------|
| 用語名     | 顧客                                   |
| 読み方     | こきゃく                                 |
| 英語表記    | Customer (Customers)                 |
| 同義語/類義語 | クライアント、ユーザー                          |
| 定義      | 当社のサービスや製品を利用する個人または法人               |
| 補足説明    | 本システムでは、契約済みの利用者のみを「顧客」と呼び、見込み客は含まない |
| 関連用語    | 見込み客、契約者                             |
| カテゴリ    | 顧客管理                                 |

##### 見込み客

| 項目      | 説明                                   |
|---------|--------------------------------------|
| 用語名     | 見込み客                                 |
| 読み方     | みこみきゃく                               |
| 英語表記    | Prospect (Prospects)                 |
| 同義語/類義語 | リード、潜在顧客                             |
| 定義      | 当社のサービスに関心を示しているが、まだ契約を結んでいない個人または法人 |
| 補足説明    | 営業活動の対象となり、将来的に顧客になる可能性がある           |
| 関連用語    | 顧客、商談                                |
| カテゴリ    | 顧客管理                                 |

#### 契約管理ドメイン

##### 契約

| 項目      | 説明                        |
|---------|---------------------------|
| 用語名     | 契約                        |
| 読み方     | けいやく                      |
| 英語表記    | Contract (Contracts)      |
| 同義語/類義語 | 利用契約、サービス契約               |
| 定義      | 当社のサービスを利用するために顧客と交わす法的合意 |
| 補足説明    | 契約には基本契約とオプション契約の2種類がある   |
| 関連用語    | 顧客、契約期間、契約種別              |
| カテゴリ    | 契約管理                      |
