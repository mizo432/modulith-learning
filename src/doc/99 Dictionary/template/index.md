# 用語辞書テンプレート

## 目的

本用語辞書は、プロジェクトにおいて使用される専門用語を統一的に定義し、関係者間の共通理解を促進するために作成されています。

## 用語定義の形式

各用語は以下の形式で定義されています：

| 項目      | 説明                            |
|---------|-------------------------------|
| 用語名     | 用語の正式名称                       |
| 読み方     | 用語の読み方（ふりがな）                  |
| 英語表記    | 用語の英語表記（該当する場合、名詞は複数形も括弧内に記載） |
| 同義語/類義語 | 同じ意味または類似した意味を持つ他の用語          |
| 定義      | 用語の明確な定義                      |
| 補足説明    | 必要に応じた追加情報や具体例                |
| 関連用語    | 関連する他の用語（相互参照）                |
| カテゴリ    | 用語が属するカテゴリ                    |

## カテゴリ区分

### 業務ドメイン

1. **顧客管理** - 顧客情報や顧客との関係性に関する用語
2. **契約管理** - 契約や契約条件に関する用語
3. **商品・サービス** - 提供する商品やサービスに関する用語
4. **請求・決済** - 料金請求や支払いに関する用語

### その他カテゴリ

1. **システム用語** - システムの機能や構造に関する用語
2. **技術用語** - 使用技術やプログラミングに関する用語
3. **プロジェクト用語** - 開発プロセスや管理に関する用語
