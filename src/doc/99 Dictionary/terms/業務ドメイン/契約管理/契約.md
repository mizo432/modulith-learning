# 契約

| 項目      | 説明                        |
|---------|---------------------------|
| 用語名     | 契約                        |
| 読み方     | けいやく                      |
| 英語表記    | Contract (Contracts)      |
| 同義語/類義語 | 利用契約、サービス契約               |
| 定義      | 当社のサービスを利用するために顧客と交わす法的合意 |
| 補足説明    | 契約には基本契約とオプション契約の2種類がある   |
| 関連用語    | 顧客、契約期間、契約種別              |
| カテゴリ    | 契約管理                      |
