# ADRテンプレート

このディレクトリには、アーキテクチャ決定記録（ADR）を作成するためのテンプレートが含まれています。

## 使用方法

1. `template.md` ファイルをコピーして新しいADRファイルを作成します
2. ファイル名は連番とタイトルを含めてください（例：`001-database-selection.md`）
3. テンプレートの各セクションに適切な内容を記入してください
4. 完成したADRをチームでレビューし、合意を得てください

## テンプレートの構造

テンプレートには以下のセクションが含まれています：

1. **タイトル**: 決定の簡潔な説明
2. **ステータス**: 提案中、承認済み、廃止、置換など
3. **日付**: 決定が行われた日付
4. **コンテキスト**: 決定が必要となった背景や状況
5. **決定**: 実際に選択された選択肢とその詳細
6. **結果**: この決定から予想される結果（ポジティブ、ネガティブ、中立）
7. **代替案**: 検討されたが選択されなかった他の選択肢
8. **関連**: 関連する他のADRや文書へのリンク
9. **見直しの条件**: 決定から再度判断が必要となる条件
