## テーブル定義

### 01. users (ユーザーアカウント情報)

システム利用者のアカウント情報を管理するテーブルです。

| 順 | カラム名       | データ型                 | NULL | PK | 制約        | 説明                      |
|----|----------------|--------------------------|------|----|-------------|---------------------------|
| 1  | id             | BIGINT                   | NOT  | ○  | PRIMARY KEY | ユーザーID (Snowflake ID) |
| 2  | username       | VARCHAR(50)              | NOT  |    | UNIQUE      | ユーザー名                |
| 3  | password       | VARCHAR                  | NOT  |    |             | パスワード (ハッシュ化)   |
| 4  | is_first_login | BOOLEAN                  | NOT  |    |             | 初回ログインフラグ        |
| 5  | valid_from     | TIMESTAMP WITH TIME ZONE | NOT  |    |             | 有効開始日                |
| 6  | valid_to       | TIMESTAMP WITH TIME ZONE |      |    |             | 有効終了日                |

#### 補足

- `id`: Snowflake ID で一意に識別
- `username`: ユーザー名、一意制約あり
- `is_first_login`: 初回ログイン時に true、パスワード変更後に false になる
- `valid_from` / `valid_to`: アカウントの有効期間を管理
