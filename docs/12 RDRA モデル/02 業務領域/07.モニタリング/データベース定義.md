# データベース定義 - モニタリング

## 概要

本ドキュメントは、「モニタリング」業務領域で使用するデータベーステーブルの定義を記述します。

## テーブル一覧

| 番号 | スキーマ     | テーブル名            | 説明                     |
|------|--------------|-----------------------|--------------------------|
| 01   | address_reg  | prefectures           | 都道府県マスタ           |
| 02   | address_reg  | cities                | 市区町村民スタ           |
| 03   | address_reg  | chou_aza              | 字・丁目マスタ           |
| 04   | calendar_reg | holiday               | 祝日マスタ               |
| 05   | bank_reg     | banks                 | 銀行マスタ               |
| 06   | bank_reg     | bank_master_imports   | 銀行マスタインポート履歴 |
| 07   | bank_reg     | branches              | 支店マスタ               |
| 08   | bank_reg     | branch_master_imports | 支店マスタインポート履歴 |

## テーブル定義

### 01. prefectures (都道府県マスタ)

都道府県の基本情報を管理するテーブルです。

| 順 | カラム名        | データ型     | NULL | PK | 制約        | 説明               |
|----|-----------------|--------------|------|----|-------------|--------------------|
| 1  | prefecture_id   | BIGINT       | NOT  | ○  | PRIMARY KEY | 都道府県ID         |
| 2  | prefecture_code | VARCHAR(2)   | NOT  |    |             | 都道府県コード     |
| 3  | lg_code         | VARCHAR(6)   | NOT  |    |             | 法定コード         |
| 4  | pref_name       | VARCHAR(10)  | NOT  |    |             | 都道府県名         |
| 5  | pref_kana       | VARCHAR(50)  | NOT  |    |             | 都道府県名カナ     |
| 6  | pref_roma       | VARCHAR(50)  | NOT  |    |             | 都道府県名ローマ字 |
| 7  | effective_date  | DATE         | NOT  |    |             | 有効開始日         |
| 8  | abolition_data  | DATE         | NOT  |    |             | 廃止日             |
| 9  | remarks         | VARCHAR(256) |      |    |             | 備考               |

#### 補足

- `id`: 都道府県を一意に識別するID
- `prefecture_code`: 都道府県コード（最大2文字）
- `lg_code`: 法定コード（全国地方公共団体コード、最大6文字）
- `pref_name`: 都道府県名（最大10文字）
- `pref_kana`: 都道府県名のカナ表記（最大50文字）
- `pref_roma`: 都道府県名のローマ字表記（最大50文字）

### 02. cities (市区町村マスタ)

市区町村の情報を管理するテーブルです。

| 順 | カラム名       | データ型     | NULL | PK | 制約            | 説明               |
|----|----------------|--------------|------|----|-----------------|--------------------|
| 1  | city_id        | BIGINT       | NOT  | ○  | PRIMARY KEY     | 市区町村ID         |
| 2  | prefecture_id  | BIGINT       | NOT  |    | FK(prefectures) | 都道府県ID         |
| 3  | lg_code        | VARCHAR(6)   | NOT  |    |                 | 法定コード         |
| 4  | country_name   | VARCHAR(24)  |      |    |                 | 郡名               |
| 5  | country_kana   | VARCHAR(50)  |      |    |                 | 郡名カナ           |
| 6  | country_roma   | VARCHAR(100) |      |    |                 | 郡名ローマ字       |
| 7  | city_name      | VARCHAR(24)  |      |    |                 | 市区町村名         |
| 8  | city_kana      | VARCHAR(50)  |      |    |                 | 市区町村名カナ     |
| 9  | city_roma      | VARCHAR(100) |      |    |                 | 市区町村名ローマ字 |
| 10 | ward_name      | VARCHAR(24)  |      |    |                 | 政令市区名         |
| 11 | ward_kana      | VARCHAR(50)  |      |    |                 | 政令市区名カナ     |
| 12 | ward_roma      | VARCHAR(100) |      |    |                 | 政令市区名ローマ字 |
| 13 | effective_date | DATE         | NOT  |    |                 | 有効開始日         |
| 14 | abolition_data | DATE         | NOT  |    |                 | 廃止日             |
| 15 | remarks        | VARCHAR(256) |      |    |                 | 備考               |

#### 補足

- `prefecture_id`: prefectures テーブルの外部キー
- `lg_code`: 法定コード（全国地方公共団体コード、最大6文字）

### 03. chou_aza (字・丁目マスタ)

字・丁目の情報を管理するテーブルです。

| 順 | カラム名           | データ型     | NULL | PK | 制約        | 説明                          |
|----|--------------------|--------------|------|----|-------------|-------------------------------|
| 1  | chou_aza_id        | BIGINT       | NOT  | ○  | PRIMARY KEY | 字ID                          |
| 2  | city_id            | BIGINT       | NOT  |    | FK(cities)  | 市区町村ID                    |
| 3  | lg_code            | VARCHAR(6)   | NOT  |    |             | 法定コード                    |
| 4  | machiaza_code      | VARCHAR(7)   | NOT  |    |             | 町字コード                    |
| 5  | machiaza_type      | VARCHAR(1)   | NOT  |    |             | 町字区分コード                |
| 6  | oaza_cho_name      | VARCHAR(120) |      |    |             | 大字・町名                    |
| 7  | oaza_cho_kana      | VARCHAR(240) |      |    |             | 大字・町名カナ                |
| 8  | oaza_cho_roma      | VARCHAR(180) |      |    |             | 大字・町名ローマ字            |
| 9  | chome_name         | VARCHAR(32)  |      |    |             | 丁目名                        |
| 10 | chome_kana         | VARCHAR(50)  |      |    |             | 丁目名カナ                    |
| 11 | chome_number       | VARCHAR(2)   |      |    |             | 丁目番号                      |
| 12 | koaza_name         | VARCHAR(120) |      |    |             | 小字名                        |
| 13 | koaza_kana         | VARCHAR(240) |      |    |             | 小字名カナ                    |
| 14 | koaza_roma         | VARCHAR(180) |      |    |             | 小字名ローマ字                |
| 15 | machiaza_dist      | VARCHAR(120) |      |    |             | 同名町字識別コード            |
| 16 | rsdt_addr_flg      | BOOLEAN      | NOT  |    |             | 住居表示フラグ                |
| 17 | rsdt_addr_mtd_code | VARCHAR(1)   |      |    |             | 住居表示方式コード            |
| 18 | oaza_cho_aka_flg   | BOOLEAN      | NOT  |    |             | 大字・町名_通称フラグ         |
| 19 | koaza_aka_code     | VARCHAR(1)   |      |    |             | 小字_通称フラグ/コード        |
| 20 | oaza_cho_gsi_uncmn | VARCHAR(50)  |      |    |             | 大字・町名_電子国土基本図外字 |
| 21 | koaza_gsi_uncmn    | VARCHAR(50)  |      |    |             | 小字_電子国土基本図外字       |
| 22 | status             | INTEGER      | NOT  |    |             | 状態フラグ                    |
| 23 | wake_num_flg       | BOOLEAN      | NOT  |    |             | 起番フラグ                    |
| 24 | src_code           | VARCHAR(2)   |      |    |             | 原典資料コード                |
| 25 | effective_date     | DATE         | NOT  |    |             | 有効開始日                    |
| 26 | abolition_data     | DATE         | NOT  |    |             | 廃止日                        |
| 27 | remarks            | VARCHAR(256) |      |    |             | 備考                          |

#### 補足

- `city_id`: cities テーブルの外部キー
- `machiaza_code`: 町字コード（最大7文字）
- `machiaza_type`: 町字区分コード（1文字）
- `rsdt_addr_flg`: 住居表示フラグ（Boolean）
- `status`: 状態フラグ（Integer）

### 04. holiday (祝日マスタ)

祝日の情報を管理するテーブルです。

| 順 | カラム名     | データ型     | NULL | PK | 制約        | 説明     |
|----|--------------|--------------|------|----|-------------|----------|
| 1  | holiday_id   | BIGINT       | NOT  | ○  | PRIMARY KEY | 祝日ID   |
| 2  | holiday_date | DATE         | NOT  |    |             | 祝日月日 |
| 3  | holiday_name | VARCHAR(50)  | NOT  |    |             | 祝日名   |
| 4  | remarks      | VARCHAR(256) |      |    |             | 備考     |

#### 補足

- `id`: 祝日を一意に識別するID（例: 20240101）
- `holiday_date`: 祝日・休日の日付
- `holiday_name`: 祝日・休日の名称（最大50文字）

### 05. banks (銀行マスタ)

銀行の情報を管理するテーブルです。

| 順 | カラム名           | データ型     | NULL | PK | 制約        | 説明           |
|----|--------------------|--------------|------|----|-------------|----------------|
| 1  | bank_code          | VARCHAR(4)   | NOT  | ○  | PRIMARY KEY | 銀行コード     |
| 2  | bank_name          | VARCHAR(128) | NOT  |    |             | 銀行名         |
| 3  | bank_half_kana     | VARCHAR(256) |      |    |             | 銀行名半角カナ |
| 4  | bank_full_kana     | VARCHAR(256) |      |    |             | 銀行名全角カナ |
| 5  | bank_full_hira     | VARCHAR(256) |      |    |             | 銀行名ひらがな |
| 6  | business_type_code | VARCHAR(8)   |      |    |             | 業態コード     |
| 7  | business_type      | VARCHAR(64)  |      |    |             | 業態名         |
| 8  | dataset_id         | VARCHAR(128) | NOT  |    |             | データセットID |

#### 補足

- `bank_code`: 金融機関コード（4桁、先頭ゼロを含む）
- `dataset_id`: 最後に更新した Master Export のデータセットID

### 06. bank_master_imports (銀行マスタインポート履歴)

銀行マスタのインポート履歴を管理するテーブルです。

| 順 | カラム名       | データ型                 | NULL | PK | 制約        | 説明                 |
|----|----------------|--------------------------|------|----|-------------|----------------------|
| 1  | dataset_id     | VARCHAR(128)             | NOT  | ○  | PRIMARY KEY | データセットID       |
| 2  | published_at   | TIMESTAMP WITH TIME ZONE |      |    |             | 公開日時             |
| 3  | occurred_at    | TIMESTAMP WITH TIME ZONE | NOT  |    |             | インポート日時       |
| 4  | zip_sha256     | VARCHAR(64)              | NOT  |    |             | ZIPファイルのSHA-256 |
| 5  | bank_row_count | INTEGER                  | NOT  |    |             | インポート行数       |

#### 補足

- `dataset_id`: 取り込んだ Master Export のデータセットID
- `zip_sha256`: ダウンロードした ZIP ファイルの SHA-256 ハッシュ

### 07. branches (支店マスタ)

銀行支店の情報を管理するテーブルです。複合主キー (bank_code, branch_code) を使用します。

| 順 | カラム名         | データ型     | NULL | PK | 制約        | 説明           |
|----|------------------|--------------|------|----|-------------|----------------|
| 1  | bank_code        | VARCHAR(4)   | NOT  | ○  | PRIMARY KEY | 銀行コード     |
| 2  | branch_code      | VARCHAR(3)   | NOT  | ○  | PRIMARY KEY | 支店コード     |
| 3  | branch_name      | VARCHAR(128) | NOT  |    |             | 支店名         |
| 4  | branch_half_kana | VARCHAR(256) |      |    |             | 支店名半角カナ |
| 5  | branch_full_kana | VARCHAR(256) |      |    |             | 支店名全角カナ |
| 6  | branch_hiragana  | VARCHAR(256) |      |    |             | 支店名ひらがな |
| 7  | dataset_id       | VARCHAR(128) | NOT  |    |             | データセットID |

#### 補足

- `bank_code`: 所属する金融機関のコード（4桁）
- `branch_code`: 支店コード（3桁、先頭ゼロを含む）
- 複合主キー: (bank_code, branch_code)

### 08. branch_master_imports (支店マスタインポート履歴)

支店マスタのインポート履歴を管理するテーブルです。

| 順 | カラム名         | データ型                 | NULL | PK | 制約        | 説明                 |
|----|------------------|--------------------------|------|----|-------------|----------------------|
| 1  | dataset_id       | VARCHAR(128)             | NOT  | ○  | PRIMARY KEY | データセットID       |
| 2  | published_at     | TIMESTAMP WITH TIME ZONE |      |    |             | 公開日時             |
| 3  | occurred_at      | TIMESTAMP WITH TIME ZONE | NOT  |    |             | インポート日時       |
| 4  | zip_sha256       | VARCHAR(64)              | NOT  |    |             | ZIPファイルのSHA-256 |
| 5  | branch_row_count | INTEGER                  | NOT  |    |             | インポート行数       |

#### 補足

- `dataset_id`: 取り込んだ Master Export のデータセットID
- `zip_sha256`: ダウンロードした ZIP ファイルの SHA-256 ハッシュ
