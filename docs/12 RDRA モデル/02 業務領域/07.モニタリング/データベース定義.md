# データベース定義 - モニタリング

## 概要

本ドキュメントは、「モニタリング」業務領域で使用するデータベーステーブルの定義を記述します。

## テーブル一覧

| 番号 | スキーマ     | テーブル名            | 説明                     |
|------|--------------|-----------------------|--------------------------|
| 01   | address_reg  | prefectures           | 都道府県マスタ           |
| 02   | address_reg  | cities                | 市区町村民スタ           |
| 03   | address_reg  | chou_aza              | 字・丁目マスタ           |
| 04   | calendar_reg | holiday               | 祝日マスタ               |
| 05   | bank_reg     | banks                 | 銀行マスタ               |
| 06   | bank_reg     | bank_master_imports   | 銀行マスタインポート履歴 |
| 07   | bank_reg     | branches              | 支店マスタ               |
| 08   | bank_reg     | branch_master_imports | 支店マスタインポート履歴 |

## テーブル定義

### 01. prefectures (都道府県マスタ)

都道府県の基本情報を管理するテーブルです。

| 順 | カラム名        | データ型 | NULL | PK | 制約        | 説明           |
|----|-----------------|----------|------|----|-------------|----------------|
| 1  | prefecture_id   | BIGINT   | NOT  | ○  | PRIMARY KEY | 都道府県ID     |
| 2  | prefecture_code | VARCHAR  | NOT  |    | UNIQUE      | 都道府県コード |
| 3  | prefecture_name | VARCHAR  | NOT  |    |             | 都道府県名     |

### 02. cities (市区町村民スタ)

市区町村の情報を管理するテーブルです。

| 順 | カラム名      | データ型 | NULL | PK | 制約            | 説明           |
|----|---------------|----------|------|----|-----------------|----------------|
| 1  | city_id       | BIGINT   | NOT  | ○  | PRIMARY KEY     | 市区町村ID     |
| 2  | city_code     | VARCHAR  | NOT  |    | UNIQUE          | 市区町村コード |
| 3  | city_name     | VARCHAR  | NOT  |    |                 | 市区町村名     |
| 4  | prefecture_id | BIGINT   | NOT  |    | FK(prefectures) | 都道府県ID     |

### 03. chou_aza (字・丁目マスタ)

字・丁目の情報を管理するテーブルです。

| 順 | カラム名      | データ型 | NULL | PK | 制約        | 説明       |
|----|---------------|----------|------|----|-------------|------------|
| 1  | chou_aza_id   | BIGINT   | NOT  | ○  | PRIMARY KEY | 字ID       |
| 2  | chou_aza_code | VARCHAR  | NOT  |    |             | 字コード   |
| 3  | chou_aza_name | VARCHAR  | NOT  |    |             | 字名       |
| 4  | city_id       | BIGINT   | NOT  |    | FK(cities)  | 市区町村ID |

### 04. holiday (祝日マスタ)

祝日の情報を管理するテーブルです。

| 順 | カラム名     | データ型 | NULL | PK | 制約        | 説明   |
|----|--------------|----------|------|----|-------------|--------|
| 1  | holiday_id   | BIGINT   | NOT  | ○  | PRIMARY KEY | 祝日ID |
| 2  | holiday_date | DATE     | NOT  |    | UNIQUE      | 祝日   |
| 3  | holiday_name | VARCHAR  | NOT  |    |             | 祝日名 |

### 05. banks (銀行マスタ)

銀行の情報を管理するテーブルです。

| 順 | カラム名   | データ型     | NULL | PK | 制約        | 説明           |
|----|------------|--------------|------|----|-------------|----------------|
| 1  | bank_code  | VARCHAR(4)   | NOT  | ○  | PRIMARY KEY | 銀行コード     |
| 2  | bank_name  | VARCHAR      | NOT  |    |             | 銀行名         |
| 3  | dataset_id | VARCHAR(128) |      |    |             | データセットID |

### 06. bank_master_imports (銀行マスタインポート履歴)

銀行マスタのインポート履歴を管理するテーブルです。

| 順 | カラム名       | データ型     | NULL | PK | 制約        | 説明                 |
|----|----------------|--------------|------|----|-------------|----------------------|
| 1  | dataset_id     | VARCHAR(128) | NOT  | ○  | PRIMARY KEY | データセットID       |
| 2  | published_at   | TIMESTAMP    |      |    |             | 公開日時             |
| 3  | occurred_at    | TIMESTAMP    | NOT  |    |             | インポート日時       |
| 4  | zip_sha256     | VARCHAR(64)  | NOT  |    |             | ZIPファイルのSHA-256 |
| 5  | bank_row_count | INTEGER      | NOT  |    |             | インポート行数       |

#### インデックス

- `idx_bank_master_imports_occurred_at`: occurred_at

### 07. branches (支店マスタ)

銀行支店の情報を管理するテーブルです。

| 順 | カラム名    | データ型     | NULL | PK | 制約        | 説明           |
|----|-------------|--------------|------|----|-------------|----------------|
| 1  | branch_code | VARCHAR(3)   | NOT  | ○  | PRIMARY KEY | 支店コード     |
| 2  | bank_code   | VARCHAR(4)   | NOT  |    | FK(banks)   | 銀行コード     |
| 3  | branch_name | VARCHAR      | NOT  |    |             | 支店名         |
| 4  | dataset_id  | VARCHAR(128) |      |    |             | データセットID |

### 08. branch_master_imports (支店マスタインポート履歴)

支店マスタのインポート履歴を管理するテーブルです。

| 順 | カラム名         | データ型     | NULL | PK | 制約        | 説明                 |
|----|------------------|--------------|------|----|-------------|----------------------|
| 1  | dataset_id       | VARCHAR(128) | NOT  | ○  | PRIMARY KEY | データセットID       |
| 2  | published_at     | TIMESTAMP    |      |    |             | 公開日時             |
| 3  | occurred_at      | TIMESTAMP    | NOT  |    |             | インポート日時       |
| 4  | zip_sha256       | VARCHAR(64)  | NOT  |    |             | ZIPファイルのSHA-256 |
| 5  | branch_row_count | INTEGER      | NOT  |    |             | インポート行数       |

#### インデックス

- `idx_branch_master_imports_occurred_at`: occurred_at
