# データベース定義 - 組織ロール

## 概要

本ドキュメントは、「組織ロール」業務領域で使用するデータベーステーブルの定義を記述します。

## テーブル一覧

| 番号 | スキーマ | テーブル名      | 説明     |
|------|----------|-----------------|----------|
| 01   | public   | departments     | 部門情報 |
| 02   | public   | organizations   | 組織情報 |

## テーブル定義

### 01. departments (部門情報)

部門の基本情報を管理するテーブルです。

| 順 | カラム名 | データ型    | NULL | PK | 制約        | 説明       |
|----|----------|-------------|------|----|-------------|------------|
| 1  | id       | BIGINT      | NOT  | ○  | PRIMARY KEY | 部門ID     |
| 2  | code     | VARCHAR(13) | NOT  |    | UNIQUE      | 部門コード |

#### 補足

- `id`: Snowflake ID で一意に識別
- `code`: 部門を一意に識別するコード（最大13文字）

### 02. organizations (組織情報)

組織の階層構造を管理するテーブルです。

| 順 | カラム名          | データ型                 | NULL | PK | 制約        | 説明              |
|----|-------------------|--------------------------|------|----|-------------|-------------------|
| 1  | organization_id   | UUID                     | NOT  | ○  | PRIMARY KEY | 組織ID            |
| 2  | organization_code | VARCHAR(13)              | NOT  |    | UNIQUE      | 組織コード        |
| 3  | full_name         | VARCHAR                  | NOT  |    |             | 組織名            |
| 4  | level0_code       | VARCHAR(4)               | NOT  |    |             | レベル0組織コード |
| 5  | level1_code       | VARCHAR(2)               | NOT  |    |             | レベル1組織コード |
| 6  | level2_code       | VARCHAR(2)               | NOT  |    |             | レベル2組織コード |
| 7  | level3_code       | VARCHAR(2)               | NOT  |    |             | レベル3組織コード |
| 8  | level4_code       | VARCHAR(3)               | NOT  |    |             | レベル4組織コード |
| 9  | level0_name       | VARCHAR(100)             | NOT  |    |             | レベル0名称       |
| 10 | level1_name       | VARCHAR(100)             | NOT  |    |             | レベル1名称       |
| 11 | level2_name       | VARCHAR(100)             | NOT  |    |             | レベル2名称       |
| 12 | level3_name       | VARCHAR(100)             | NOT  |    |             | レベル3名称       |
| 13 | level4_name       | VARCHAR(100)             | NOT  |    |             | レベル4名称       |
| 14 | valid_from        | TIMESTAMP WITH TIME ZONE | NOT  |    |             | 有効開始日時      |
| 15 | valid_to          | TIMESTAMP WITH TIME ZONE |      |    |             | 有効終了日時      |

#### 補足

- 組織コードは5階層構造 (LEVEL0~LEVEL4) で管理
- 各レベルのコード長さは固定: LEVEL0=4, LEVEL1=2, LEVEL2=2, LEVEL3=2, LEVEL4=3
- `organization_code`: 各レベルコードを結合した一意のコード
- `valid_from` / `valid_to`: 組織の有効期間を管理（`valid_to` が NULL の場合は無期限）
