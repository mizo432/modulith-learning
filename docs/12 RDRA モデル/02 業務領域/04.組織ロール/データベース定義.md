# データベース定義 - 組織ロール

## 概要

本ドキュメントは、「組織ロール」業務領域で使用するデータベーステーブルの定義を記述します。

## テーブル一覧

| 番号 | スキーマ | テーブル名              | 説明             |
|------|----------|-------------------------|------------------|
| 01   | public   | organization_units      | 組織単位情報     |
| 02   | public   | organizations           | 組織情報         |
| 03   | public   | role                    | ロール情報       |
| 04   | public   | role_assignment_for_org | 組織ロール割当   |
| 05   | public   | role_assignment_for_emp | 従業員ロール割当 |

## テーブル定義

### 01. organization_units (組織単位情報)

組織単位の詳細情報を管理するテーブルです。

| 順 | カラム名  | データ型     | NULL | PK | 制約                     | 説明         |
|----|-----------|--------------|------|----|--------------------------|--------------|
| 1  | party_id  | BIGINT       | NOT  | ○  | PRIMARY KEY, FK(parties) | パーティーID |
| 2  | unit_name | VARCHAR(100) | NOT  |    |                          | 組織単位名   |
| 3  | unit_type | VARCHAR(20)  |      |    |                          | 組織単位種別 |

#### 補足

- `party_id`: parties テーブルの外部キー

### 02. organizations (組織情報)

組織の階層構造を管理するテーブルです。

| 順 | カラム名        | データ型   | NULL | PK | 制約        | 説明              |
|----|-----------------|------------|------|----|-------------|-------------------|
| 1  | organization_id | UUID       | NOT  | ○  | PRIMARY KEY | 組織ID            |
| 2  | level0_code     | VARCHAR(4) |      |    |             | レベル0組織コード |
| 3  | level1_code     | VARCHAR(2) |      |    |             | レベル1組織コード |
| 4  | level2_code     | VARCHAR(2) |      |    |             | レベル2組織コード |
| 5  | level3_code     | VARCHAR(2) |      |    |             | レベル3組織コード |
| 6  | level4_code     | VARCHAR(3) |      |    |             | レベル4組織コード |

#### 補足

- 組織コードは5階層構造 (LEVEL0~LEVEL4) で管理
- 各レベルのコード長さは固定

### 03. role (ロール情報)

ロールの基本情報を管理するテーブルです。

| 順 | カラム名  | データ型 | NULL | PK | 制約        | 説明     |
|----|-----------|----------|------|----|-------------|----------|
| 1  | role_id   | UUID     | NOT  | ○  | PRIMARY KEY | ロールID |
| 2  | role_name | VARCHAR  |      |    |             | ロール名 |

### 04. role_assignment_for_org (組織ロール割当)

組織へのロール割当を管理するテーブルです。

| 順 | カラム名                   | データ型 | NULL | PK | 制約              | 説明     |
|----|----------------------------|----------|------|----|-------------------|----------|
| 1  | role_assignment_for_org_id | UUID     | NOT  | ○  | PRIMARY KEY       | 割当ID   |
| 2  | role_id                    | UUID     |      |    | FK(role)          | ロールID |
| 3  | organization_id            | UUID     |      |    | FK(organizations) | 組織ID   |

#### インデックス

- `fk01_role_assignment_for_org`: role_id
- `fk02_role_assignment_for_org`: organization_id

### 05. role_assignment_for_emp (従業員ロール割当)

従業員へのロール割当を管理するテーブルです。

| 順 | カラム名                   | データ型 | NULL | PK | 制約          | 説明     |
|----|----------------------------|----------|------|----|---------------|----------|
| 1  | role_assignment_for_emp_id | UUID     | NOT  | ○  | PRIMARY KEY   | 割当ID   |
| 2  | role_id                    | UUID     |      |    | FK(role)      | ロールID |
| 3  | employee_id                | UUID     |      |    | FK(employees) | 従業員ID |

#### インデックス

- `fk01_role_assignment_for_emp`: role_id
- `fk02_role_assignment_for_emp`: employee_id
