# データベース定義 - パーティー

## 概要

本ドキュメントは、「パーティー」業務領域で使用するデータベーステーブルの定義を記述します。

## テーブル一覧

| 番号 | スキーマ | テーブル名 | 説明               |
|------|----------|------------|--------------------|
| 01   | public   | parties    | パーティー基本情報 |

## テーブル定義

### 01. parties (パーティー基本情報)

パーティーの基本情報を管理するテーブルです。個人・法人・組織など、システム内で一意に識別されるすべてのエンティティを格納します。

| 順 | カラム名    | データ型    | NULL | PK | 制約        | 説明                                           |
|----|-------------|-------------|------|----|-------------|------------------------------------------------|
| 1  | party_id    | BIGINT      | NOT  | ○  | PRIMARY KEY | パーティーID                                   |
| 2  | party_type  | VARCHAR(10) | NOT  |    |             | パーティー種別 (PERSON, COMPANY, ORGANIZATION) |
| 3  | simple_name | VARCHAR(50) | NOT  |    |             | 略称                                           |

#### 補足

- `party_type`: パーティーの種別を識別するコード
    - `PERSON`: 個人
    - `COMPANY`: 法人
    - `ORGANIZATION`: 組織
- `simple_name`: パーティーの略称または短縮名
