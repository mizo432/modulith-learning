# データベース定義 - 人ロール

## 概要

本ドキュメントは、「人ロール」業務領域で使用するデータベーステーブルの定義を記述します。

## テーブル一覧

| 番号 | スキーマ | テーブル名 | 説明       |
|------|----------|------------|------------|
| 01   | public   | employees  | 従業員情報 |

## テーブル定義

### 01. employees (従業員情報)

従業員の詳細情報を管理するテーブルです。

| 順 | カラム名    | データ型                 | NULL | PK | 制約        | 説明       |
|----|-------------|--------------------------|------|----|-------------|------------|
| 1  | employee_id | UUID                     | NOT  | ○  | PRIMARY KEY | 従業員ID   |
| 2  | lastNane    | VARCHAR                  | NOT  |    |             | 姓         |
| 3  | first_name  | VARCHAR                  | NOT  |    |             | 名         |
| 4  | valid_from  | TIMESTAMP WITH TIME ZONE | NOT  |    |             | 有効開始日 |
| 5  | valid_to    | TIMESTAMP WITH TIME ZONE |      |    |             | 有効終了日 |

#### 補足

- `employee_id`: UUID で一意に識別
- `valid_from` / `valid_to`: 従業員の有効期間を管理（`valid_to` が NULL の場合は無期限）
