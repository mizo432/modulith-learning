# データベース定義 - ビルド

## 概要

本ドキュメントは、「ビルド」業務領域で使用するデータベーステーブルの定義を記述します。

## テーブル一覧

| 番号 | スキーマ | テーブル名     | 説明                |
|------|----------|----------------|---------------------|
| 01   | idMgmt   | snowflakeNodes | Snowflakeノード情報 |

## テーブル定義

### 01. snowflakeNodes (Snowflakeノード情報)

Snowflake ID 生成用のノード情報を管理するテーブルです。

| 順 | カラム名      | データ型                 | NULL | PK | 制約        | 説明           |
|----|---------------|--------------------------|------|----|-------------|----------------|
| 1  | node_id       | INTEGER                  | NOT  | ○  | PRIMARY KEY | ノードID       |
| 2  | instance_name | VARCHAR                  |      |    |             | インスタンス名 |
| 3  | lease_until   | TIMESTAMP WITH TIME ZONE |      |    |             | リース期限     |

#### 補足

- `node_id`: Snowflake ID 生成時に使用するノード識別子
- `instance_name`: ノードに割り当てられたインスタンス名
- `lease_until`: ノードのリース有効期限
- 分散環境での一意ID生成に使用
