# データベース定義 - パーティーロール

## 概要

本ドキュメントは、「パーティーロール」業務領域で使用するデータベーステーブルの定義を記述します。

## テーブル一覧

| 番号 | スキーマ | テーブル名          | 説明         |
|------|----------|---------------------|--------------|
| 01   | public   | companies           | 法人情報     |
| 02   | public   | address_use_history | 住所利用履歴 |

## テーブル定義

### 01. companies (法人情報)

法人パーティーの詳細情報を管理するテーブルです。

| 順 | カラム名     | データ型     | NULL | PK | 制約                     | 説明         |
|----|--------------|--------------|------|----|--------------------------|--------------|
| 1  | party_id     | BIGINT       | NOT  | ○  | PRIMARY KEY, FK(parties) | パーティーID |
| 2  | company_name | VARCHAR(100) | NOT  |    |                          | 法人名       |
| 3  | company_type | VARCHAR(20)  |      |    |                          | 法人種別     |

#### 補足

- `party_id`: parties テーブルの外部キー
- `company_type`: 法人の種別コード

### 02. address_use_history (住所利用履歴)

パーティーの住所利用履歴を管理するテーブルです。

| 順 | カラム名            | データ型    | NULL | PK | 制約        | 説明         |
|----|---------------------|-------------|------|----|-------------|--------------|
| 1  | address_use_id      | BIGINT      | NOT  | ○  | PRIMARY KEY | 住所利用ID   |
| 2  | party_id            | BIGINT      | NOT  |    | FK(parties) | パーティーID |
| 3  | address_Id          | BIGINT      | NOT  |    |             | 住所ID       |
| 4  | begin_date          | DATE        | NOT  |    |             | 開始日       |
| 5  | end_date            | DATE        | NOT  |    |             | 終了日       |
| 6  | type                | VARCHAR(20) | NOT  |    |             | 種別         |
| 7  | reason_for_transfer | VARCHAR(30) |      |    |             | 転居理由     |

#### 補足

- `party_id`: parties テーブルの外部キー
- `type`: 住所の種別 (自宅, 勤務先, など)
