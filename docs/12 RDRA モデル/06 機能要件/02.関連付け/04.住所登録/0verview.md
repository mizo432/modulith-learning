# 概要

本ドキュメントは、住所登録業務領域の機能要件の概要を定義します。
住所関連のマスターデータ（都道府県、市区町村、町字）を管理する機能を提供します。

## 事業領域情報

| 項目         | 値         |
|--------------|------------|
| 事業領域     | 関連付け   |
| 業務領域     | 住所登録   |
| 業務領域英名 | AddressReg |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 住所登録業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号  | ユースケース名         | 説明                     | 優先度 |
|-------|------------------------|--------------------------|--------|
| UC-01 | 都道府県一覧を取得する | 都道府県の一覧を取得する | 高     |
| UC-02 | 市区町村一覧を取得する | 市区町村の一覧を取得する | 中     |
| UC-03 | 町字一覧を取得する     | 町字の一覧を取得する     | 中     |
