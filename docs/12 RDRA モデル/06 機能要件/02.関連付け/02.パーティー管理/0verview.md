# 概要

本ドキュメントは、パーティー管理業務領域の機能要件の概要を定義します。
パーティー（個人・法人・組織）のマスターデータと関係情報を管理する機能を提供します。

## 事業領域情報

| 項目         | 値             |
|--------------|----------------|
| 事業領域     | 関連付け       |
| 業務領域     | パーティー管理 |
| 業務領域英名 | PartyMgmt      |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: パーティ管理業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号  | ユースケース名         | 説明                             | 優先度 |
|-------|------------------------|----------------------------------|--------|
| UC-01 | 個人パーティを登録する | 新規個人パーティを登録する       | 高     |
| UC-02 | 法人パーティを登録する | 新規法人パーティを登録する       | 高     |
| UC-03 | パーティを検索する     | パーティ情報を検索する           | 高     |
| UC-04 | 組織を登録する         | 新規組織を登録する               | 高     |
| UC-05 | 組織一覧を取得する     | 組織の一覧を取得する             | 高     |
| UC-06 | 部署を登録する         | 新規部署を登録する               | 高     |
| UC-07 | 従業員を登録する       | 新規従業員を登録する             | 高     |
| UC-08 | 従業員を検索する       | 従業員情報を検索する             | 高     |
| UC-09 | ロールを割り当てる     | 従業員・組織にロールを割り当てる | 高     |
| UC-10 | 住所を登録する         | パーティの住所を登録する         | 中     |
| UC-11 | 銀行口座を登録する     | パーティの銀行口座を登録する     | 中     |
| UC-12 | パーティ関係を登録する | パーティ間の関係を登録する       | 中     |
