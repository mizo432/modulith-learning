# 概要

本ドキュメントは、発注・受入業務領域の機能要件の概要を定義します。
本店への発注から荷受、受入、未払金確認までのフローをシステム化します。

## 事業領域情報

| 項目         | 値              |
|--------------|-----------------|
| 事業領域     | 購買事業        |
| 業務領域     | 発注・受入      |
| 業務領域英名 | PurchaseReceive |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 発注・受入業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号  | ユースケース名   | 説明                     | 優先度 |
|-------|------------------|--------------------------|--------|
| UC-06 | 発注を入力する   | 本店への発注を入力       | 高     |
| UC-07 | 荷受进行处理する | 本店からの荷受け进行处理 | 高     |
| UC-08 | 受入进行处理する | 資材の受入进行处理       | 高     |
| UC-09 | 未払金を確認する | 受入に対する未払金を確認 | 中     |
