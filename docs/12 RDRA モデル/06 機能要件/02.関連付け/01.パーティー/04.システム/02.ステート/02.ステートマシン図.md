# ステートマシン図

データベース接続およびキャッシュの状態遷移を定義します。

## ステート遷移図

```plantuml
@startuml

title データベース接続およびキャッシュの状態遷移

skinparam state {
  BackgroundColor White
  BorderColor Black
}

state "未接続\n(ST-01)" as Disconnected
state "接続中\n(ST-02)" as Connecting
state "接続完了\n(ST-03)" as Connected
state "接続失敗\n(ST-04)" as ConnectionFailed
state "キャッシュ有効\n(ST-05)" as CacheValid
state "キャッシュ期限切れ\n(ST-06)" as CacheExpired

[*] --> Disconnected

Disconnected --> Connecting : 接続リクエスト
Connecting --> Connected : 接続成功
Connecting --> ConnectionFailed : 接続失敗
Connected --> Disconnected : 切断リクエスト
ConnectionFailed --> Connecting : 再接続リクエスト

Connected --> CacheValid : メタデータ取得
CacheValid --> CacheExpired : 期限切れ
CacheExpired --> CacheValid : 再取得成功
CacheExpired --> ConnectionFailed : 再取得失敗

note right of Disconnected
  データベースに接続していない状態
end note

note right of Connecting
  データベースに接続中の状態
end note

note right of Connected
  データベースに接続完了した状態
end note

note right of ConnectionFailed
  データベース接続に失敗した状態
end note

note right of CacheValid
  メタデータキャッシュが有効な状態
end note

note right of CacheExpired
  メタデータキャッシュが期限切れになった状態
end note

@enduml
```

## ステート一覧

| ステートID | ステート名         | 説明                                       |
|------------|--------------------|--------------------------------------------|
| ST-01      | 未接続             | データベースに接続していない状態           |
| ST-02      | 接続中             | データベースに接続中の状態                 |
| ST-03      | 接続完了           | データベースに接続完了した状態             |
| ST-04      | 接続失敗           | データベース接続に失敗した状態             |
| ST-05      | キャッシュ有効     | メタデータキャッシュが有効な状態           |
| ST-06      | キャッシュ期限切れ | メタデータキャッシュが期限切れになった状態 |
