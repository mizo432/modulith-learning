# 外部システム定義

## 概要

| 項目           | 内容                       |
|----------------|----------------------------|
| 外部システムID | ES-01                      |
| 外部システム名 | 会計システム               |
| 説明           | 会計処理を行う既存システム |

## 接続情報

| 項目           | 内容    |
|----------------|---------|
| 接続方法       | API連携 |
| 通信プロトコル | HTTPS   |
| 認証方式       | APIキー |

## 連携内容

| 項目       | 内容                 |
|------------|----------------------|
| 送信データ | 供給情報、未収金情報 |
| 受信データ | 会計処理結果         |
| 連携頻度   | 供給処理完了時       |

## 制約事項

- 会計システムは営業時間のみ利用可能
- 連携データは暗号化して送信する必要がある
