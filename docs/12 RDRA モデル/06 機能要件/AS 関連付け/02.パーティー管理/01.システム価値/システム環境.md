# システム環境

システムが属する環境を定義します。

## システムコンテキスト図

```
┌─────────────────────────────────────────────┐
│           パーティ管理システム               │
│                                             │
│  ┌───────────┐  ┌───────────┐              │
│  │ パーティ   │  │  組織      │              │
│  │ 管理       │  │  管理      │              │
│  └───────────┘  └───────────┘              │
│                                             │
│  ┌───────────┐  ┌───────────┐              │
│  │ 従業員     │  │  ロール    │              │
│  │ 管理       │  │  管理      │              │
│  └───────────┘  └───────────┘              │
└─────────────────────────────────────────────┘
         ▲                ▲
         │                │
   ┌─────┴─────┐    ┌────┴────┐
   │  管理者   │    │ 外部システム│
   └───────────┘    └─────────┘
```

## 外部システム

| 番号 | 外部システムID | 外部システム名 | 説明                   |
|------|----------------|----------------|------------------------|
| 01   | ES-01          | データベース   | パーティ情報の永続化先 |
| 02   | ES-02          | 認証サービス   | ユーザー認証との連携   |
