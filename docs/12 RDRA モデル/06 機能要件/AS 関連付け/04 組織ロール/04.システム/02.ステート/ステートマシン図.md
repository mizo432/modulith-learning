# ステートマシン図

## 有効期間ステート遷移

```
┌────────┐    validFrom設定     ┌────────┐    validTo設定     ┌────────┐
│ 未設定  │ ──────────────────→ │  有効   │ ──────────────────→ │  無効   │
└────────┘                      └────────┘                      └────────┘
```

## パーティ関係ステート遷移

```
┌────────────┐   whenAssociated設定    ┌────────────┐   whenDisassociated設定   ┌────────────┐
│  未関連付け  │ ─────────────────────→ │  関連付け済み │ ──────────────────────→ │ 関連付け解除 │
└────────────┘                         └────────────┘                            └────────────┘
```
