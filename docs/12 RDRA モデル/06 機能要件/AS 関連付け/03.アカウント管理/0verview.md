# 概要

本ドキュメントは、アカウント管理業務領域の機能要件の概要を定義します。
ユーザーアカウントの管理機能を提供します。

## 事業領域情報

| 項目         | 値             |
|--------------|----------------|
| 事業領域     | 関連付け       |
| 業務領域     | アカウント管理 |
| 業務領域英名 | AccountMgmt    |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: アカウント管理業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号  | ユースケース名               | 説明                           | 優先度 |
|-------|------------------------------|--------------------------------|--------|
| UC-01 | ユーザーステータスを取得する | ユーザーのステータスを取得する | 高     |
| UC-02 | パスワードを変更する         | ユーザーのパスワードを変更する | 高     |
