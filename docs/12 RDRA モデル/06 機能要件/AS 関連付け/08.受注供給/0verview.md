# 概要

本ドキュメントは、受注・供給業務領域の機能要件の概要を定義します。
組合員からの資材の受注から配送、供給、未収金確認までのフローをシステム化します。

## 事業領域情報

| 項目         | 値          |
|--------------|-------------|
| 事業領域     | 購買事業    |
| 業務領域     | 受注・供給  |
| 業務領域英名 | OrderSupply |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 受注・供給業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号  | ユースケース名     | 説明                       | 優先度 |
|-------|--------------------|----------------------------|--------|
| UC-01 | 資材一覧を取得する | 注文可能な資材の一覧を取得 | 高     |
| UC-02 | 受注を入力する     | 組合員の注文を入力         | 高     |
| UC-03 | 配送を指示する     | 資材の配送を指示           | 高     |
| UC-04 | 供給进行处理する   | 組合員への供給进行处理     | 高     |
| UC-05 | 未収金を確認する   | 供給に対する未収金を確認   | 中     |
