# 概要

本ドキュメントは、関連付け事業領域の機能要件の概要を定義します。
パーティー（個人・法人・組織）のマスターデータ管理、アカウント管理、住所登録、金融機関登録、カレンダー登録などの関連付け機能を提供します。

## 事業領域情報

| 項目           | 値          |
|----------------|-------------|
| 事業領域コード | AS          |
| 事業領域区分   | 支援        |
| 事業領域名     | 関連付け    |
| 事業領域英名   | Association |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 関連付け業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義
