# ユースケース図

受注・供給フローのユースケース図を定義します。

## ユースケース図

```plantuml
@startuml
left to right direction

actor "組合員" as member
actor "店舗担当者" as store

rectangle "受注・供給" {
  usecase "UC-01 資材一覧を取得する" as UC01
  usecase "UC-02 受注を入力する" as UC02
  usecase "UC-03 配送を指示する" as UC03
  usecase "UC-04 供給进行处理する" as UC04
  usecase "UC-05 未収金を確認する" as UC05
}

note "会計システム\n(ES-01)" as es

member -- UC01
store -- UC02
store -- UC03
store -- UC04
store -- UC05

UC05 ..> es : 連携

@enduml
```

## ユースケース一覧

| ユースケースID | ユースケース名     | 説明                       |
|----------------|--------------------|----------------------------|
| UC-01          | 資材一覧を取得する | 注文可能な資材の一覧を取得 |
| UC-02          | 受注を入力する     | 組合員の注文を入力         |
| UC-03          | 配送を指示する     | 資材の配送を指示           |
| UC-04          | 供給进行处理する   | 組合員への供給进行处理     |
| UC-05          | 未収金を確認する   | 供給に対する未収金を確認   |

## 関連情報

- アクター: 組合員、店舗担当者
- 外部システム: 会計システム
- ユースケース数: 5
