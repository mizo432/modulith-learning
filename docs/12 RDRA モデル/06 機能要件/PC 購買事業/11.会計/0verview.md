# 概要

本ドキュメントは、会計業務領域の機能要件の概要を定義します。
請求書発行、会計情報確認、会計システム連携などの会計処理をシステム化します。

## 事業領域情報

| 項目         | 値         |
|--------------|------------|
| 事業領域     | 購買事業   |
| 業務領域     | 会計       |
| 業務領域英名 | Accounting |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 会計業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号  | ユースケース名         | 説明                     | 優先度 |
|-------|------------------------|--------------------------|--------|
| UC-13 | 請求書を発行する       | 供給に対する請求書を発行 | 高     |
| UC-14 | 会計情報を確認する     | 会計情報を確認           | 中     |
| UC-15 | 会計システムに送信する | 会計データを連携         | 高     |
