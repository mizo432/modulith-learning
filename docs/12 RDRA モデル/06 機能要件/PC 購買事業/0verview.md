# 概要

本ドキュメントは、購買事業領域の機能要件の概要を定義します。
資材の受注・供給、発注・受入、在庫管理、会計などの購買関連業務をシステム化します。

## 事業領域情報

| 項目           | 値          |
|----------------|-------------|
| 事業領域コード | PC          |
| 事業領域区分   | コア        |
| 事業領域名     | 購買事業    |
| 事業領域英名   | Procurement |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 購買業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 業務領域一覧

| 番号 | 業務領域名 | 説明                             |
|------|------------|----------------------------------|
| 08   | 受注・供給 | 組合員側の受注・配送・供給フロー |
| 09   | 発注・受入 | 本店側の発注・荷受・受入フロー   |
| 10   | 在庫管理   | 資材の在庫管理と棚卸             |
| 11   | 会計       | 会計処理と請求書発行             |
