# 概要

本ドキュメントは、関連付け事業領域の汎用機能の概要を定義します。
住所登録、金融機関登録、カレンダー登録、税率登録、元号登録などの汎用的なマスターデータ管理機能を提供します。

## 事業領域情報

| 項目           | 値          |
|----------------|-------------|
| 事業領域コード | AS          |
| 事業領域区分   | 支援        |
| 事業領域名     | 関連付け    |
| 事業領域英名   | Association |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 汎用マスターデータ登録業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 業務領域一覧

| 番号 | 業務領域名     | 説明                                         |
|------|----------------|----------------------------------------------|
| 04   | 住所登録       | 都道府県、市区町村、町字のマスターデータ管理 |
| 05   | 金融機関登録   | 金融機関・支店のマスターデータ管理           |
| 06   | カレンダー登録 | 祝日などのカレンダー情報管理                 |
| 07   | 税率登録       | 税率のマスターデータ管理                     |
| ER   | 元号登録       | 元号のマスターデータ管理                     |
