# ステートマシン図

## 元号ステート遷移

```
┌────────┐    適用開始日到来    ┌────────┐    適用終了日超え    ┌────────┐
│  無効   │ ──────────────────→ │  有効   │ ──────────────────→ │  無効   │
└────────┘                     └────────┘                      └────────┘
```

## 遷移説明

| 遷移        | 条件               | 説明                           |
|-------------|--------------------|--------------------------------|
| 無効 → 有効 | 適用開始日が到来   | 元号が適用開始日になると有効   |
| 有効 → 無効 | 適用終了日を過ぎる | 元号の適用期間が終了すると無効 |
