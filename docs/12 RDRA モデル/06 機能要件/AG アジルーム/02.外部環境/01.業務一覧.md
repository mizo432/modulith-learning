# 業務一覧

アジルーム（Agiloom）でシステム化対象の業務をリストアップします。

## 業務

| 番号 | 業務名             | 説明                                                             |
|------|--------------------|------------------------------------------------------------------|
| 01   | プロダクト管理業務 | プロダクトの定義・管理を行う業務                                 |
| 02   | チーム編成業務     | プロダクトに属するチームメンバーを管理する業務                   |
| 03   | 要件定義業務       | エピック・フィーチャー・ユーザーストーリーを階層的に定義する業務 |
| 04   | バックログ管理業務 | プロダクトバックログの優先順位付けと整理を行う業務               |
| 05   | スプリント計画業務 | スプリントの計画・開始を行う業務                                 |
| 06   | スプリント実行業務 | スプリント期間中のタスク管理・進捗追跡を行う業務                 |
| 07   | Scrumイベント業務  | デイリースクラム、レビュー、レトロスペクティブを実施する業務     |
| 08   | リリース管理業務   | スプリントの成果をリリースとしてまとめる業務                     |
| 09   | 可視化業務         | 各レベルのダッシュボードで進捗・状況を可視化する業務             |
