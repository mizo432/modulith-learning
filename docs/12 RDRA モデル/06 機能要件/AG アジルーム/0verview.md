# 概要

本ドキュメントは、アジルーム（Agiloom）業務領域の機能要件の概要を定義します。
Scrumに基づくアジャイルソフトウェア開発プロジェクトの管理をシステム化します。

## 事業領域情報

| 項目         | 値             |
|--------------|----------------|
| 事業領域     | アジルーム     |
| 業務領域     | 17業務領域全体 |
| 業務領域英名 | Agiloom        |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: Scrum関連業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号   | ユースケース名                 | 説明                                 | 優先度 |
|--------|--------------------------------|--------------------------------------|--------|
| UC-001 | プロダクトを作成する           | 新規プロダクトを登録                 | 高     |
| UC-002 | プロダクト一覧を取得する       | 登録済みプロダクトの一覧を取得       | 高     |
| UC-003 | チームメンバーを追加する       | プロダクトにチームメンバーを追加     | 高     |
| UC-004 | ユーザーストーリーを作成する   | ユーザーストーリーを登録             | 高     |
| UC-005 | エピックを作成する             | 大規模な機能単位のエピックを登録     | 高     |
| UC-006 | フィーチャーを作成する         | エピックを分解したフィーチャーを登録 | 高     |
| UC-007 | プロダクトバックログを管理する | バックログの優先順位を整理           | 高     |
| UC-008 | スプリントを作成する           | 新規スプリントを計画・開始           | 高     |
| UC-009 | スプリントバックログを作成する | スプリントで実施するタスクを決定     | 高     |
| UC-010 | タスクを更新する               | タスクの進捗・状態を更新             | 高     |
| UC-011 | デイリースクラムを記録する     | 進捗状況を記録                       | 中     |
| UC-012 | スプリントレビューを行う       | 完成した機能をレビュー               | 中     |
| UC-013 | レトロスペクティブを行う       | スプリントの振り返りを記録           | 中     |
| UC-014 | リリースを作成する             | スプリントの成果をリリース           | 中     |
| UC-015 | ダッシュボードを表示する       | 各レベルのダッシュボードを表示       | 中     |
