# ES-01. データベース定義

接続対象のデータベースの定義を記述します。

## 概要

| 項目           | 内容                   |
|----------------|------------------------|
| 外部システムID | ES-01                  |
| 外部システム名 | データベース           |
| 説明           | 接続対象のデータベース |
| 種類           | RDBMS                  |
| 接続方法       | JDBC                   |

## 接続情報

| 項目       | 内容                             |
|------------|----------------------------------|
| プロトコル | TCP/IP                           |
| ポート     | 3306 (MySQL) / 5432 (PostgreSQL) |
| 認証方式   | ユーザーID/パスワード            |

## 連携内容

| 番号 | 連携項目               | 説明                                             |
|------|------------------------|--------------------------------------------------|
| 01   | データベース一覧取得   | 接続可能なデータベースの一覧を取得               |
| 02   | スキーマ一覧取得       | 指定されたデータベースのスキーマ一覧を取得       |
| 03   | テーブル・View一覧取得 | 指定されたスキーマのテーブル・View一覧を取得     |
| 04   | テーブル定義取得       | 指定されたテーブルの定義とインデックス定義を取得 |
| 05   | View定義取得           | 指定されたViewの定義とインデックス定義を取得     |

## 制約事項

| 番号 | 制約事項 | 説明                                 |
|------|----------|--------------------------------------|
| 01   | 接続制限 | 同時接続数はデータベースの設定に依存 |
| 02   | 権限制限 | 読み取り専用権限での接続を推奨       |
