# ADR-0015: 非機能要件 C-02（監視項目・通知）に対応する

## 日時

2026-10-27

## 状態

承認済み

## 背景

AgiloomシステムはクラウドベースのSaaS学習プロジェクトです。非機能要件 C-02（監視項目・通知）では、以下の要件が定義されています。

- 監視対象：アプリケーション、インフラ、データベース、ネットワーク
- 監視間隔：1 分間隔
- アラート通知：メール、Slack、PagerDuty 等
- ダッシュボード：リアルタイムの監視ダッシュボードを提供

監視体制は、システムの異常を早期に検知し、迅速に対応するために重要であり、本番環境を想定した設計として対応する方針とする。

## 決定

非機能要件 C-02（監視項目・通知）に対応する。

具体的には、以下の要件を実装する。

- アプリケーション、インフラ、データベース、ネットワークの監視を実装する
- アラート通知機能を実装し、異常発生時に即座に通知する
- リアルタイムの監視ダッシュボードを提供する

## 代替案

1. **監視項目を簡素化する**: アプリケーションの監視のみとし、インフラ監視は実施しない
2. **アラート通知を簡素化する**: メール通知のみとし、SlackやPagerDutyは導入しない
3. **クラウドプロバイダーの機能に依存する**: 自前の監視機能は実装しない

## 影響

### 肯定的な影響

- システムの異常を早期に検知できる
- 迅速な対応が可能になる
- システムの安定稼働が確保される

### 否定的な影響

- 監視機能の実装により開発コストが増加する
- アラート対応により運用負荷が増加する可能性がある
