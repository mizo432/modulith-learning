# ADR-0005: 非機能要件 E-04（不正アクセス・侵入検知・防御）を現時点で対応しない

## 日時

2026-10-27

## 状態

承認済み

## 背景

AgiloomシステムはクラウドベースのSaaS学習プロジェクトです。非機能要件
E-04（不正アクセス・侵入検知・防御）では、以下の要件が定義されています。

- WAF（Web Application Firewall）：導入
- IDS/IPS：導入
- 不正アクセス検知：対応
- ブルートフォース対策：対応（アカウントロック機能）

しかし、現時点では学習プロジェクトであり、以下の理由からこれらの要件に対応することが困難です。

1. **クラウドプロバイダー依存**: WAFやIDS/IPSはクラウドプロバイダーが提供する機能を依存する
2. **コスト制約**: WAFやIDS/IPSの導入はインフラコストが増加する
3. **運用負荷**: 不正アクセス検知のルール管理やアラート対応には専任のセキュリティチームが必要
4. **プロジェクトの目的**: 学習プロジェクトであり、本番環境での不正アクセス対策は優先度が低い

## 決定

現時点では、非機能要件 E-04（不正アクセス・侵入検知・防御）に対応しない。

具体的には、以下の要件を保留とする。

- WAF（Web Application Firewall）は導入しない
- IDS/IPSは導入しない
- 不正アクセス検知の専用機能は実装しない

ただし、以下の最小限のセキュリティ対策は実施する。

- 認証・認可は OAuth 2.0 / OpenID Connect を用いて実装する（E-01 で対応）
- パスワードポリシーを適用する（最小文字数、複雑性要件）
- アカウントロック機能は、簡易的な実装を行う（連続失敗回数制限）
- クラウドプロバイダーが提供する基本的なセキュリティ機能を有効にする

## 代替案

1. **WAFを本格導入する**: AWS WAF 等のクラウドネイティブサービスを利用する
2. **IDS/IPSを導入する**: 不正アクセス検知を強化するが、コスト増と運用負荷増
3. **アカウントロック機能のみ実装する**: ブルートフォース対策として最小限の機能を実装する

## 影響

### 肯定的な影響

- インフラコストを抑制できる
- 運用負荷を軽減できる
- プロジェクトの目的（学習）に集中できる

### 否定的な影響

- 不正アクセスに対する防御力が低下する
- セキュリティインシデント発生時の検知が遅れる可能性がある
- 本番環境への移行時には、改めて不正アクセス対策を検討する必要がある

## 見直し条件

以下の条件が満たされた場合、本決定を見直す。

- システムが本番環境として運用され始める
- セキュリティインシデントが発生した
- 規制要件により不正アクセス対策が必須となった
