# ADR-0019: 非機能要件 C-07（ソフトウェア配布・展開）に対応する

## 日時

2026-10-27

## 状態

承認済み

## 背景

AgiloomシステムはクラウドベースのSaaS学習プロジェクトです。非機能要件
C-07（ソフトウェア配布・展開）では、以下の要件が定義されています。

- CI/CD パイプライン：導入
- デプロイ頻度：週 1 回以上を目標
- ロールバック：自動ロールバック機能の実装
- ブルーグリーンデプロイ：対応

CI/CDパイプラインは、迅速かつ安全なデプロイを可能にし、開発効率を向上させるために重要であり、本番環境を想定した設計として対応する方針とする。

## 決定

非機能要件 C-07（ソフトウェア配布・展開）に対応する。

具体的には、以下の要件を実装する。

- CI/CDパイプラインを導入し、自動ビルド・テスト・デプロイを実現する
- 自動ロールバック機能を実装し、デプロイ失敗時に即座に復旧する
- デプロイは、自動テストを通過したビルドのみを対象とする

## 代替案

1. **CI/CDパイプラインを簡素化する**: 自動ビルドのみとし、自動デプロイは実施しない
2. **ロールバック機能は実装しない**: 手動でのロールバックのみとする
3. **ブルーグリーンデプロイは導入しない**: 通常のデプロイのみとする

## 影響

### 肯定的な影響

- デプロイの迅速化と安全性が向上する
- 開発効率が向上する
- デプロイ失敗時の影響を最小限に抑えられる

### 否定的な影響

- CI/CDパイプラインの構築により開発コストが増加する
- 自動ロールバック機能の実装により複雑性が増す
