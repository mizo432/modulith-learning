# ADR-0029: 非機能要件 F-02（ハードウェア・ソフトウェア制約）に対応する

## 日時

2026-10-27

## 状態

承認済み

## 背景

AgiloomシステムはクラウドベースのSaaS学習プロジェクトです。非機能要件
F-02（ハードウェア・ソフトウェア制約）では、以下の要件が定義されています。

- Java バージョン：21 以上
- データベース：MySQL 8.0 以上 / PostgreSQL 14 以上
- Web ブラウザ：最新バージョンおよびその前バージョン
- OS：Linux (Ubuntu 22.04 LTS 以上 / RHEL 8 以上)

ハードウェア・ソフトウェア制約の定義は、システムの互換性とサポート期間を確保するために重要であり、本番環境を想定した設計として対応する方針とする。

## 決定

非機能要件 F-02（ハードウェア・ソフトウェア制約）に対応する。

具体的には、以下の要件を実装する。

- Java 21以上を使用する
- MySQL 8.0以上またはPostgreSQL 14以上を使用する
- 主要ブラウザの最新2バージョンを対象として、互換性を確保する
- サポート終了したソフトウェアは使用しない

## 代替案

1. **Javaバージョンを低くする**: Java 17以上とし、Java 21は必須としない
2. **データベースを1つに限定する**: MySQLのみとし、PostgreSQLは対応しない
3. **ブラウザ互換性を広げる**: 最新2バージョンではなく、最新3バージョンを対象とする

## 影響

### 肯定的な影響

- システムの互換性が確保される
- サポート期間が明確になる
- セキュリティパッチの適用が容易になる

### 否定的な影響

- 特定のバージョンに依存することで、アップグレード時のコストが増加する可能性がある
- ブラウザ互換性のテストにより開発コストが増加する
