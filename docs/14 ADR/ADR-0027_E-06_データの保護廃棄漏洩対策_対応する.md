# ADR-0027: 非機能要件 E-06（データの保護・廃棄・漏洩対策）に対応する

## 日時

2026-10-27

## 状態

承認済み

## 背景

AgiloomシステムはクラウドベースのSaaS学習プロジェクトです。非機能要件
E-06（データの保護・廃棄・漏洩対策）では、以下の要件が定義されています。

- E-06-01 機微情報の暗号化：AES-256-GCM方式で暗号化
- E-06-02 鍵管理：環境変数または秘密管理サービスから取得
- E-06-03 データの安全な廃棄：論理削除と物理削除の両方に対応
- E-06-04 データ漏洩対策：データ分類とアクセス制御

データの保護は、個人情報の保護と法的要求事項に対応するために重要であり、本番環境を想定した設計として対応する方針とする。

## 決定

非機能要件 E-06（データの保護・廃棄・漏洩対策）に対応する。

具体的には、以下の要件を実装する。

- JPA AttributeConverterを使用して、エンティティレベルで暗号化/復号化を透明に行う
- Spring Security CryptoのAesGcmContentEncryptorを利用
- 鍵は環境変数から取得し、本番環境では秘密管理サービスと連携
- 論理削除と物理削除の両方に対応する

## 代替案

1. **暗号化を簡素化する**: 機微情報の一部のみ暗号化する
2. **鍵管理を簡素化する**: 環境変数のみとし、秘密管理サービスは導入しない
3. **物理削除は実施しない**: 論理削除のみとし、物理削除は実施しない

## 影響

### 肯定的な影響

- 個人情報の保護が強化される
- 法的要求事項に対応できる
- データ漏洩時の影響を最小限に抑えられる

### 否定的な影響

- 暗号化機能の実装により開発コストが増加する
- 鍵管理により運用負荷が増加する
