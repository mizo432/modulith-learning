# ADR-0012: 非機能要件 B-03（処理性能・リソース使用率）に対応する

## 日時

2026-10-27

## 状態

承認済み

## 背景

AgiloomシステムはクラウドベースのSaaS学習プロジェクトです。非機能要件
B-03（処理性能・リソース使用率）では、以下の要件が定義されています。

- CPU 使用率：平常時 70% 以下
- メモリ使用率：平常時 80% 以下
- ディスク使用率：80% 以下を維持
- ネットワーク帯域：平常時 70% 以下

リソース使用率の監視は、システムの安定稼働とコスト最適化のために重要であり、本番環境を想定した設計として対応する方針とする。

## 決定

非機能要件 B-03（処理性能・リソース使用率）に対応する。

具体的には、以下の要件を実装する。

- リソース使用率の監視を実装し、閾値を超えた場合はアラート通知を行う
- 自動スケールアウト機能を活用し、負荷に応じて自動拡張する
- 監視ツールによる常時監視を実施する

## 代替案

1. **リソース使用率の監視を簡素化する**: 手動での確認のみとし、自動アラートは実装しない
2. **自動スケールアウトは導入しない**: 手動での拡張のみとする
3. **クラウドプロバイダーの機能に依存する**: 自前の監視機能は実装しない

## 影響

### 肯定的な影響

- システムの安定稼働が確保される
- リソース使用の可視化が向上する
- コスト最適化が可能になる

### 否定的な影響

- 監視機能の実装により開発コストが増加する
- アラート対応により運用負荷が増加する可能性がある
