# ADR-0011: 非機能要件 B-02（応答時間）に対応する

## 日時

2026-10-27

## 状態

承認済み

## 背景

AgiloomシステムはクラウドベースのSaaS学習プロジェクトです。非機能要件 B-02（応答時間）では、以下の要件が定義されています。

- 画面表示時間：2 秒以内（95 パーセンタイル）
- API 応答時間：500 ms 以内（95 パーセンタイル）
- 検索応答時間：3 秒以内（95 パーセンタイル）
- バッチ処理応答時間：処理内容に応じて定義

応答時間はユーザー体験に直接影響する重要な指標であり、本番環境を想定した設計として対応する方針とする。

## 決定

非機能要件 B-02（応答時間）に対応する。

具体的には、以下の要件を実装する。

- 画面表示時間は2秒以内、API応答時間は500ms以内を目標とする
- 検索機能は3秒以内に応答するよう最適化する
- 応答時間の測定は、本番環境に近い環境で実施する

## 代替案

1. **応答時間要件を緩和する**: 学習プロジェクトであるため、要件を低く設定する
2. **応答時間の測定を簡素化する**: 本番環境に近い環境での測定は実施しない
3. **クラウドプロバイダーの機能に依存する**: 自前のキャッシュ機能は実装しない

## 影響

### 肯定的な影響

- ユーザー体験が向上する
- システムの性能目標が明確になる
- 性能テストの基準が設定される

### 否定的な影響

- 性能最適化により開発コストが増加する
- キャッシュ機能の実装により複雑性が増す
