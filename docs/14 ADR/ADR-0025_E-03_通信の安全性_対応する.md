# ADR-0025: 非機能要件 E-03（通信の安全性）に対応する

## 日時

2026-10-27

## 状態

承認済み

## 背景

AgiloomシステムはクラウドベースのSaaS学習プロジェクトです。非機能要件 E-03（通信の安全性）では、以下の要件が定義されています。

- TLS：1.2 以上（1.3 を推奨）
- 証明書：信頼できる CA 発行
- HSTS：有効
- API 通信：全通信を TLS で保護

通信の安全性は、データの機密性と完全性を保護するために重要であり、本番環境を想定した設計として対応する方針とする。

## 決定

非機能要件 E-03（通信の安全性）に対応する。

具体的には、以下の要件を実装する。

- TLS 1.2以上（1.3を推奨）を用いて、全通信を暗号化する
- 信頼できるCA発行の証明書を使用する
- HSTSを有効にし、ブラウザが常にHTTPSを使用하도록強制する
- 内部通信も可能な限り暗号化する

## 代替案

1. **TLSバージョンを低くする**: TLS 1.0/1.1も許容する
2. **HSTSは有効にしない**: ユーザーがHTTPでアクセスした場合でも、HTTPSにリダイレクトするのみとする
3. **内部通信は暗号化しない**: 外部通信のみ暗号化し、内部通信は平文とする

## 影響

### 肯定的な影響

- データの機密性と完全性が保護される
- 中間者攻撃のリスクが低減される
- セキュリティ基準に準拠できる

### 否定的な影響

- TLS暗号化によりパフォーマンスが低下する可能性がある
- 証明書の管理により運用負荷が増加する
