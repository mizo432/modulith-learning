# データベース定義 機能要望

## 概要

本ドキュメントは、「データベース定義」業務領域における機能要望を定義します。
アプリケーションが参照しているデータベースから取得した情報を階層的に表示する機能を提供します。

## 業務領域情報

| 項目         | 値               |
|--------------|------------------|
| 事業領域     | 開発運用         |
| 業務領域     | データベース定義 |
| 業務領域英名 | DatabaseDef      |

## 機能一覧

| 番号 | 機能名             | エンドポイント                                                           | 説明                                                 |
|------|--------------------|--------------------------------------------------------------------------|------------------------------------------------------|
| F-01 | データベース一覧   | GET /do/databases                                                        | 接続可能なデータベースの一覧を取得する               |
| F-02 | スキーマ一覧       | GET /do/databases/{databaseName}                                         | 指定されたデータベースのスキーマ一覧を取得する       |
| F-03 | テーブル・View一覧 | GET /do/databases/{databaseName}/schemas/{schemaName}                    | 指定されたスキーマのテーブル一覧とView一覧を取得する |
| F-04 | テーブル定義       | GET /do/databases/{databaseName}/schemas/{schemaName}/tables/{tableName} | 指定されたテーブルの定義とインデックス定義を取得する |
| F-05 | View定義           | GET /do/databases/{databaseName}/schemas/{schemaName}/views/{viewName}   | 指定されたViewの定義とインデックス定義を取得する     |

## 機能詳細

### F-01. データベース一覧

| 項目           | 内容                                   |
|----------------|----------------------------------------|
| 機能ID         | F-01                                   |
| 機能名         | データベース一覧                       |
| エンドポイント | GET /do/databases                      |
| 説明           | 接続可能なデータベースの一覧を取得する |
| 優先度         | 高                                     |

**入力パラメータ**

| パラメータ | 型 | 必須 | 説明           |
|------------|----|------|----------------|
| -          | -  | -    | パラメータなし |

**出力データ**

| 項目         | 型     | 説明               |
|--------------|--------|--------------------|
| databaseName | String | データベース名     |
| description  | String | データベースの説明 |

---

### F-02. スキーマ一覧

| 項目           | 内容                                           |
|----------------|------------------------------------------------|
| 機能ID         | F-02                                           |
| 機能名         | スキーマ一覧                                   |
| エンドポイント | GET /do/databases/{databaseName}               |
| 説明           | 指定されたデータベースのスキーマ一覧を取得する |
| 優先度         | 高                                             |

**入力パラメータ**

| パラメータ   | 型     | 必須 | 説明           |
|--------------|--------|------|----------------|
| databaseName | String | 必須 | データベース名 |

**出力データ**

| 項目           | 型     | 説明                    |
|----------------|--------|-------------------------|
| schemaName     | String | スキーマ名              |
| schemaKanaName | String | スキーマの説明(";"まで) |
| description    | String | スキーマの説明(";"以降) |

---

### F-03. テーブル・View一覧

| 項目           | 内容                                                  |
|----------------|-------------------------------------------------------|
| 機能ID         | F-03                                                  |
| 機能名         | テーブル・View一覧                                    |
| エンドポイント | GET /do/databases/{databaseName}/schemas/{schemaName} |
| 説明           | 指定されたスキーマのテーブル一覧とView一覧を取得する  |
| 優先度         | 高                                                    |

**入力パラメータ**

| パラメータ   | 型     | 必須 | 説明           |
|--------------|--------|------|----------------|
| databaseName | String | 必須 | データベース名 |
| schemaName   | String | 必須 | スキーマ名     |

**出力データ**

テーブル一覧

| 項目          | 型     | 説明                                           |
|---------------|--------|------------------------------------------------|
| tableName     | String | テーブル名                                     |
| tableKanaName | String | テーブルの説明(最初の";"まで)                  |
| tableType     | String | テーブルの説明(一番目の";"から二番目の";"まで) |
| description   | String | テーブルの説明(二番目の";"から最後まで)        |

View一覧

| 項目         | 型     | 説明                                       |
|--------------|--------|--------------------------------------------|
| viewName     | String | View名                                     |
| viewKanaName | String | Viewの説明(最初の";"まで)                  |
| viewType     | String | Viewの説明(一番目の";"から二番目の";"まで) |
| description  | String | Viewの説明(二番目の";"から最後まで)        |

---

### F-04. テーブル定義

| 項目           | 内容                                                                     |
|----------------|--------------------------------------------------------------------------|
| 機能ID         | F-04                                                                     |
| 機能名         | テーブル定義                                                             |
| エンドポイント | GET /do/databases/{databaseName}/schemas/{schemaName}/tables/{tableName} |
| 説明           | 指定されたテーブルの定義とインデックス定義を取得する                     |
| 優先度         | 高                                                                       |

**入力パラメータ**

| パラメータ   | 型     | 必須 | 説明           |
|--------------|--------|------|----------------|
| databaseName | String | 必須 | データベース名 |
| schemaName   | String | 必須 | スキーマ名     |
| tableName    | String | 必須 | テーブル名     |

**出力データ**

テーブル定義

| 項目         | 型      | 説明           |
|--------------|---------|----------------|
| columnName   | String  | カラム名       |
| dataType     | String  | データ型       |
| nullable     | Boolean | NULL許否       |
| primaryKey   | Boolean | 主キーフラグ   |
| defaultValue | String  | デフォルト値   |
| comment      | String  | カラムコメント |

インデックス定義

| 項目            | 型      | 説明                                  |
|-----------------|---------|---------------------------------------|
| indexName       | String  | インデックス名                        |
| indexType       | String  | インデックス種別 (UNIQUE / NONUNIQUE) |
| columnName      | String  | 構成カラム名                          |
| ordinalPosition | Integer | 構成カラムの順序                      |

---

### F-05. View定義

| 項目           | 内容                                                                                                                                     |
|----------------|------------------------------------------------------------------------------------------------------------------------------------------|
| 機能ID         | F-05                                                                                                                                     |
| 機能名         | View定義                                                                                                                                 |
| エンドポイント | GET /do/databases/{databaseName}/schemas/{schemaName}/views/{viewName}                                                                   |
| 説明           | 指定されたView（PostgreSQLの通常ViewおよびマテリアライズドView）の定義を取得する。マテリアライズドViewの場合はインデックス定義も取得する |
| 優先度         | 高                                                                                                                                       |

**入力パラメータ**

| パラメータ   | 型     | 必須 | 説明           |
|--------------|--------|------|----------------|
| databaseName | String | 必須 | データベース名 |
| schemaName   | String | 必須 | スキーマ名     |
| viewName     | String | 必須 | View名         |

**出力データ**

View定義

| 項目            | 型      | 説明           |
|-----------------|---------|----------------|
| columnName      | String  | カラム名       |
| dataType        | String  | データ型       |
| ordinalPosition | Integer | カラムの順序   |
| comment         | String  | カラムコメント |

インデックス定義
データベースがpostgresでmaterialized viewを使用している場合、インデックス定義を表示する。

| 項目            | 型      | 説明                                  |
|-----------------|---------|---------------------------------------|
| indexName       | String  | インデックス名                        |
| indexType       | String  | インデックス種別 (UNIQUE / NONUNIQUE) |
| columnName      | String  | 構成カラム名                          |
| ordinalPosition | Integer | 構成カラムの順序                      |

## 非機能要件

| 要件ID     | 要件内容                                                                           | 優先度 |
|------------|------------------------------------------------------------------------------------|--------|
| NFR-DB-001 | データベースメタデータの取得はキャッシュし、過度なデータベースアクセスを避けること | 高     |
| NFR-DB-002 | キャッシュの有効期間は5分以内とする                                                | 中     |
| NFR-DB-003 | 接続できないデータベースが存在する場合、エラーレスポンスを返すこと                 | 高     |
