# フロントエンド設計 - フェーズ1: 画面からページ・コンポーネントへの分割

## 1. 概要

本ドキュメントは、`frontend-design` スキル（React 18、TypeScript、MUI v5、React Router v6）に基づいて、
アジルーム（Agiloom）システムのフロントエンドを、画面単位からページとコンポーネントに分割する設計を定義します。

### 2.2 現在の問題点

1. **ページコンポーネントが大きすぎる**: 各ページがデータ取得・ステート管理・UI表示のすべてを担っている
2. **再利用可能なUI部品が抽出されていない**: テーブル表示、フォーム、検索バーなどが各ページに重複して実装されている
3. **ドメイン別のページ分離が不十分**: `projects/` と `users/` のみがドメイン別ディレクトリとして分離されている
4. **プレゼンテーションとコンテナの分離がされていない**: ガイドラインで推奨されるコンポーネント分類が適用されていない

## 3. 設計目標

ガイドラインに基づき、以下の目標を達成します：

1. **単一責任の原則**: 各コンポーネントは一つの明確な責務を持つ
2. **再利用性**: 共通機能はプレゼンテーションコンポーネントとして抽出
3. **コンポジション**: コンポーネントの組み合わせで複雑なUIを構築
4. **Props駆動**: コンポーネントはPropsによって動作が決定される純粋関数として設計

## 9. 実装フェーズ

### フェーズ1: 画面からページ・コンポーネントへの分割（本設計）

1. **認証関連ページの分割**
    - `Login.tsx` → `Login.tsx` (コンテナ) + `LoginForm.tsx` (プレゼンテーション)
    - `ChangePassword.tsx` → `ChangePassword.tsx` (コンテナ) + `PasswordForm.tsx`
      (プレゼンテーション)

2. **ダッシュボードの分割**
    - `Dashboard.tsx` → `Dashboard.tsx` (コンテナ) + `DashboardCard.tsx` + `ProductShortcut.tsx`

3. **製品選択ページの分割**
    - `ProductSelection.tsx` → `ProductSelection.tsx` (コンテナ) + `ProductSearchBar.tsx` +
      `ProductCard.tsx` + `ProductGrid.tsx`

4. **プロジェクト関連ページの分割**
    - `ProjectList.tsx` → `ProjectList.tsx` (コンテナ) + `ProjectTable.tsx` +
