# フロントエンド詳細設計書

## 1. 概要

本ドキュメントは、アジルーム（Agiloom）システムのフロントエンドの詳細設計を定義します。
`frontend-design` スキルに基づき、各コンポーネントのProps、ステート、ロジック、子コンポーネントを詳細に記述します。

| 言語             | TypeScript 4.9（strictモード） |
| UIコンポーネント | MUI v5 + Emotion               |

## 5. カスタムフックの詳細設計

### 5.1 hooks/useApi.ts

```typescript
interface UseApiResult<T> {
  data: T | null;
  loading: boolean;
  error: string | null;
  refetch: () => Promise<void>;
}

function useApi<T>(apiCall: () => Promise<T>): UseApiResult<T> {
  const [data, setData] = useState<T | null>(null);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);

  const refetch = async () => {
    try {
      setLoading(true);
      setError(null);
      const result = await apiCall();
      setData(result);
    } catch (err) {
      setError(err instanceof Error ? err.message : 'An error occurred');
    } finally {
      setLoading(false);
    }
  };

  useEffect(() => {
    refetch();
  }, []);

  return { data, loading, error, refetch };
}

export default useApi;
```

### 5.2 hooks/useSearch.ts

```typescript
interface UseSearchResult<T> {
  filteredData: T[];
  searchTerm: string;
  setSearchTerm: (term: string) => void;
}

function useSearch<T>(data: T[], key: keyof T): UseSearchResult<T> {
  const [searchTerm, setSearchTerm] = useState<string>('');

  const filteredData = useMemo(() => {
    if (searchTerm.trim() === '') {
      return data;
    }
    return data.filter(item =>
      String(item[key]).toLowerCase().includes(searchTerm.toLowerCase())
    );
  }, [searchTerm, data, key]);

  return { filteredData, searchTerm, setSearchTerm };
}

export default useSearch;
```

### 5.3 hooks/usePagination.ts

```typescript
interface UsePaginationResult {
  currentPage: number;
  totalPages: number;
  paginatedData: T[];
  goToPage: (page: number) => void;
  goToNextPage: () => void;
  goToPreviousPage: () => void;
}

function usePagination<T>(data: T[], itemsPerPage: number = 10): UsePaginationResult<T> {
  const [currentPage, setCurrentPage] = useState<number>(1);
  const totalPages = Math.ceil(data.length / itemsPerPage);

  const paginatedData = useMemo(() => {
    const start = (currentPage - 1) * itemsPerPage;
    return data.slice(start, start + itemsPerPage);
  }, [currentPage, data, itemsPerPage]);

  const goToPage = (page: number) => {
    if (page >= 1 && page <= totalPages) {
      setCurrentPage(page);
    }
  };

  const goToNextPage = () => goToPage(Math.min(currentPage + 1, totalPages));
  const goToPreviousPage = () => goToPage(Math.max(currentPage - 1, 1));

  return { currentPage, totalPages, paginatedData, goToPage, goToNextPage, goToPreviousPage };
}

export default usePagination;
```

### 5.4 hooks/useForm.ts

```typescript
interface useFormProps<T> {
  initialValues: T;
  validate: (values: T) => Record<string, string>;
  onSubmit: (values: T) => Promise<void>;
}

interface useFormReturn<T> {
  values: T;
  errors: Record<string, string>;
  loading: boolean;
  handleChange: (e: React.ChangeEvent<HTMLInputElement | HTMLTextAreaElement | HTMLSelectElement>) => void;
  handleSubmit: (e: React.FormEvent) => Promise<void>;
  setFieldValue: (field: keyof T, value: T[keyof T]) => void;
}

function useForm<T extends Record<string, any>>({
  initialValues,
  validate,
  onSubmit
}: useFormProps<T>): useFormReturn<T> {
  const [values, setValues] = useState<T>(initialValues);
  const [errors, setErrors] = useState<Record<string, string>>({});
  const [loading, setLoading] = useState<boolean>(false);

  const handleChange = useCallback((e: React.ChangeEvent<HTMLInputElement | HTMLTextAreaElement | HTMLSelectElement>) => {
    const { name, value } = e.target;
    setValues(prev => ({ ...prev, [name]: value }));
    if (errors[name]) {
      setErrors(prev => {
        const newErrors = { ...prev };
        delete newErrors[name];
        return newErrors;
      });
    }
  }, [errors]);

  const setFieldValue = useCallback((field: keyof T, value: T[keyof T]) => {
    setValues(prev => ({ ...prev, [field]: value }));
  }, []);

  const handleSubmit = useCallback(async (e: React.FormEvent) => {
    e.preventDefault();
    const validationErrors = validate(values);
    setErrors(validationErrors);
    if (Object.keys(validationErrors).length > 0) {
      return;
    }
    setLoading(true);
    try {
      await onSubmit(values);
    } finally {
      setLoading(false);
    }
  }, [values, validate, onSubmit]);

  return { values, errors, loading, handleChange, handleSubmit, setFieldValue };
}

export default useForm;
```

## 8. ルーティング設計

### 8.1 ルート定義

| ルート               | ページ             | ガード          | 説明               |
|----------------------|--------------------|-----------------|--------------------|
| `/login`             | `Login`            | なし            | ログイン画面       |
| `/change-password`   | `ChangePassword`   | FirstLoginRoute | 初回パスワード変更 |
| `/`                  | `Dashboard`        | ProtectedRoute  | ダッシュボード     |
| `/products`          | `ProductSelection` | ProtectedRoute  | 製品選択           |
| `/projects`          | `ProjectList`      | ProtectedRoute  | プロジェクト一覧   |
| `/projects/create`   | `ProjectCreate`    | ProtectedRoute  | プロジェクト作成   |
| `/projects/edit/:id` | `ProjectEdit`      | ProtectedRoute  | プロジェクト編集   |
| `/projects/:id`      | `ProjectDetail`    | ProtectedRoute  | プロジェクト詳細   |
| `/users/all`         | `UserList`         | AdminRoute      | ユーザー一覧       |
| `/users/add`         | `UserCreate`       | AdminRoute      | ユーザー作成       |
| `/users/edit/:id`    | `UserEdit`         | AdminRoute      | ユーザー編集       |
| `*`                  | `NotFound`         | なし            | 404ページ          |

### 8.2 ルートガード

- **ProtectedRoute**: 認証チェックと初回ログイン判定
- **AdminRoute**: 認証チェックと管理者権限チェック
- **FirstLoginRoute**: 初回ログイン判定

## 10. 設計チェックリスト

frontend-designスキルの設計チェックリストに基づき、以下の項目を確認します。

- [x] コンポーネントの責務が明確で単一である
    - 各コンポーネントはコンテナ（データ取得・ステート管理）またはプレゼンテーション（UI表示）のいずれかの責務を持つ
- [x] Propsの型定義が明確でデフォルト値が設定されている
    - 全プレゼンテーションコンポーネントでPropsの型定義を明確に記述
- [x] `any`型を使用していない
    - 型定義をtypes/配下に集約し、any型の使用を排除
- [x] 副作用の管理が適切でクリーンアップ関数が実装されている
    - useEffectで副作用を管理し、必要な場合はクリーンアップ関数を実装
- [x] ステート管理のスコープが適切（ローカル/グローバル）
    - ローカルステートはuseState、グローバルステートはContext APIで管理
- [x] ルーティング構造が一貫している
    - React Router v6で宣言的ルーティングを定義
- [x] API通信がサービス層で一元管理されている
    - 各ドメイン별サービスファイルでAPI通信を一元管理
- [x] エラーハンドリングとローディング状態が適切に処理されている
    - ErrorDisplayとLoadingIndicator共有コンポーネントで統一
- [ ] Storybookによるテストがloading/error/empty/successをカバーしている（フェーズ2で実装）
- [x] パフォーマンス最適化（useMemo, useCallback, React.memo）が適切に適用される設計
    - カスタムフックでuseMemo/useCallbackを使用、プレゼンテーションコンポーネントでReact.memoを適用
- [x] アクセシビリティ基準（ARIA, キーボード操作, カラーコントラスト）を満たす設計
    - MUIコンポーネントを使用し、ARIA属性を適切に設定
- [x] セキュリティ対策（XSS, 入力サニタイズ, トークン管理）が講じられている
    - トークンはlocalStorageに保存、入力バリデーションを実装

    - MUIテーマをtheme.tsで一元管理

    - 環境変数でAPI URLなどを管理
