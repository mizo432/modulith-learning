画面で管理者が住所をメンテナンスする

住所は郵便番号、県、市、字、丁目、番地、号、建物名、部屋番号のマスターデータを関連付けで管理する。
郵送する郵便物に宛先毎に付与するカスタマバーコード値を保持しておく。

# 関連付け

住所は、郵便番号、県、市、字、丁目、番地、号、建物名、部屋番号で構成される。
これらの要素はそれぞれ独立したマスターデータとして管理され、住所はこれらを参照する関連付け情報として管理される。

県、市、字、丁目、番地、号のマスターデータは、住所レジストリ内で一元管理する。
マスターデータは、県→市→字→丁目の階層構造で管理する。

住所は、郵便番号、県ID、市ID、字ID、丁目ID、番地ID、号ID、建物名、部屋番号の組み合わせで一意に識別される。
同一の要素の組み合わせは、1つの住所として管理する。

# カスタマバーコード値の要望

住所を設定する段階でカスタマバーコード値を保持しておく。
カスタマバーコード値は日本郵政の郵便バーコード仕様に従い、23桁で構成される。

- スタートコード: 1桁
- 郵便番号: 7桁（ハイフン除く）
- 住所表示番号: 13桁（町域名以降の住所をバーコードデータに変換）
- チェックデジット: 1桁（郵便番号～住所表示番号の合計が19の倍数となるように生成）
- ストップコード: 1桁

参考: [日本郵政 郵便番号・バーコードマニュアル](https://www.post.japanpost.jp/service/search/zipcode/zipmanual/p17.html)
