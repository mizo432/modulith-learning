# ロードマップの作成

プロダクトの機能進化を計画し、チームやステークホルダーと共有するためのロードマップを作成します。

## 概要

メインメニューに「ロードマップ」項目が追加され、そこからすべてのロードマップ機能にアクセスできます。

ロードマップは、時間の経過とともに機能がどのように進化していくかを可視化し、プロダクトのビジョンを定義・共有するのを支援します。ロードマップはプロダクトオーナーによって管理され、デフォルトではプロジェクトにアクセスできるすべてのメンバーが閲覧できます。

プロダクトに単一のロードマップだけを定義するのはアジャイルの考え方には適しません。ビジネスや技術に関する知識が蓄積されるにつれて、ロードマップも進化し、戦略の変更や代替案を反映できる柔軟性が必要です。実際の地図と同じように、理想的なルートだけでなく、状況の変化に応じて取りうる分岐点や代替ルートも把握しておきたいものです。

各ロードマップは、名前と URL
生成に使用される一意のコードで識別されます。ロードマップの詳細画面では、専用のタブで機能がリスト表示され、現時点では関係のない機能を非表示にすることもできます。

ロードマップは PNG 画像としてエクスポートできるため、iceScrum 外でも簡単に共有できます。

ロードマップには以下の 3 つの種類があります。

- **ライブロードマップ**：プランニング情報から自動的に生成されるロードマップ。プロジェクト作成時にデフォルトで作成されます。
- **スナップショット**：指定した時点でのライブロードマップの状態をキャプチャしたものです。
- **編集可能ロードマップ**：手動で自由に描画・編集できるロードマップです。

## ライブロードマップ

ライブロードマップを表示し、現在のプランニング状況を把握します。

ライブロードマップは、広い時間軸でプロダクトのプランニング状況をリアルタイムに可視化します。ライブロードマップ自体は編集できませんが、イベントの追加は可能です。また、現在の状態を後で参照できるようにスナップショットとして保存することもできます。

画面に表示される細い黄色の縦線は今日の日付を示しています。ロードマップの表示を操作するには、以下の方法があります。

- スクロール、ピンチ、またはドロップダウンメニューを使って時間軸のスケールを調整します。
- クリックしてドラッグすることで、表示範囲を移動します。

最上部の行には、時間の経過とともにスプリントとリリースがどのように計画されているかが表示されます。ロードマップはすべてのリリース期間にわたって展開されます。より広い時間軸で表示したい場合は、現在のリリース期間を延長するか、新しいリリースを追加することを検討してください。

各機能は個別の行に表示されます。アクティブな機能は実線の長方形で、非アクティブな機能は破線で表示されます。あるスプリント内で、その機能に関連するストーリーポイントが少なくとも
1 つ計画済みまたは完了している場合、その機能はアクティブとみなされます。

各機能のアクティブな期間ごとに、ステータスバーにはその期間中に計画されているストーリーの数が表示されます。現在進行中の期間については、完了したストーリーの割合とともに進捗状況も表示されます。

## ロードマップスナップショット

ライブロードマップのスナップショットを取得し、時間経過に伴う変化を追跡して戦略を見直します。

スナップショット機能を使うと、現在のライブロードマップの状態をコピーして固定し、参照用として保持できます。取得した時点でのライブロードマップの状況をそのまま保存します。

ライブロードマップのメニューからいつでもスナップショットを取得できます。一度取得したスナップショットの内容（リリース、スプリント、機能、イベントなど）は変更できません。ただし、一部の機能を一時的に非表示にすることは可能です。

## 編集可能ロードマップ

代替案を検討するために、時間軸に沿って機能の進捗を自由に計画します。

編集可能ロードマップでは、実際のストーリーの計画状況に依存せず、機能の進捗を自由に描画できます。各機能に作業期間を追加し、必要に応じて期間の拡張や移動が可能です。操作方法は以下の
2 つがあります。

- 機能タブから追加する方法
- 描画画面から直接追加する方法

ライブロードマップと同様に、編集可能ロードマップにもイベントを追加できます。他のロードマップ種類とは異なり、編集可能ロードマップでは非表示にした機能の設定が保持されます。

## イベント

イベントを追加して、プロダクトの重要な日程をマークします。

イベント機能を使うと、プロダクトにとって重要な日程やミーティングのタイミングを可視化できます。チームやステークホルダーとの連携タイミングを忘れないようにするリマインダーとしても活用できます。

イベントはプロダクト全体に関連するものや、特定の機能に関連するもののどちらにも設定できます。さらに、用途に応じてイベントの形状を選択し、分類することも可能です。
