# 電子帳票システム：最新Feature一覧

シングルテナント構成を反映した最新版です。

今回の更新では、テナント管理を廃止し、単一の企業・組織が複数の業務システムから共通利用する電子帳票基盤として整理しています。

設計上の重要ポイント： シングルテナントであっても、複数業務システムの帳票を扱うため、帳票データには業務システムを識別する情報（`system_id` など）を持たせる設計を推奨します。これはテナント分離ではなく、業務上のデータ分類・アクセス制御のためです。
