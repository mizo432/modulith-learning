# アジルーム 要件定義書 概要

## システム概要

アジルーム（Agiloom）は、Scrumに基づくアジャイルソフトウェア開発プロジェクトを管理するシステムです。
本システムは、プロダクトの定義からチーム編成、ユーザーストーリーの管理、スプリント計画・実行・レビュー・レトロスペクティブまでのScrumフルサイクルをサポートします。また、エピックやフィーチャーによる大規模な機能の階層管理、リリース管理、および各レベルのダッシュボードによる可視化機能を提供します。

## RDRA 4レイヤー

1. **システム価値レイヤー**: 要求、アクター、外部システム
2. **システム外部環境レイヤー**: 業務、BUC、アクティビティ
3. **システム境界レイヤー**: ユースケース、アクター
4. **システムレイヤー**: 情報、状態、条件、バリエーション、画面、イベント、帳票

## ドキュメント構成

各事業領域配下に以下のドキュメントが配置されます：

- `01 非機能要件/非機能要件一覧.md`
- `03 機能要件/[業務領域]/`
- `07 用語集/用語集.md`

非機能要件の項目一覧は [docs/13 非機能要件項目/非機能要件項目一覧.md](../13%20非機能要件項目/非機能要件項目一覧.md)
