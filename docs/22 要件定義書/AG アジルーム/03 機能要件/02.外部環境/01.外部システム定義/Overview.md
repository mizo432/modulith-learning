# 外部システム定義 Overview

プロダクトディスカバリー業務領域（AG-01）が連携する外部システムを定義します。

## 概要

プロダクトディスカバリーは、プロダクトの方向性策定、課題・仮説の整理、ビジョン・ゴールの管理を行う業務領域です。本業務領域では、課題・仮説・ビジョン・ゴールなどの情報はAgiloom内で管理するため、外部システムとの直接的な連携はありません。

## 外部システム一覧

本業務領域で連携する外部システムはありません。

| ID       | 外部システム名 | 連携内容 |
|----------|----------------|----------|
| （なし） | -              | -        |

## 補足

- プロダクトディスカバリーで管理する情報（Product Vision、Product
  Goal、課題、仮説、成功指標など）は、Agiloom内の他の業務領域（バックログ管理、スプリント実行、品質管理、学習など）と連携しますが、これらはシステム内部の連携であり、外部システム連携には該当しません。
- 将来的に、外部アンケートツールやユーザー行動分析ツールとの連携が検討される場合がありますが、現時点ではMVP範囲外です。
