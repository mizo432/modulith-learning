# BUC-SP-03 障害・依存関係の解消

## 概要

進行を妨げる問題を可視化し、解消を支援する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:障害を特定する;
:依存関係を特定する;
:問題を記録する;
:影響度を評価する;

:担当者を割り当てる;
:解消策を検討する;

if (外部依存か?) then (はい)
  :外部関係者に連絡する;
  :対応状況を待つ;
  else (いいえ)
  :内部で解消する;
  endif

:解消状況を追跡する;

if (解消完了か?) then (はい)
  :問題を閉じる;
  :教訓を記録する;
else (いいえ)
  :エスカレーションを検討する;
  endif

:結果を共有する;

stop
@enduml
```
