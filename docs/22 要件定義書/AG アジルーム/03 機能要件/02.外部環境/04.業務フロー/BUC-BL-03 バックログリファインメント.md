# BUC-BL-03 バックログリファインメント

## 概要

項目の説明・分割・受入条件・依存関係・準備状況を整える。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:リファインメント対象の項目を特定する;
:項目の説明を確認する;

if (説明が明確か?) then (いいえ)
  :説明を補足する;
  else (はい)
  :項目のサイズを確認する;
  if (分割が必要か?) then (はい)
    :項目を分割する;
    else (いいえ)
    :そのまま進む;
    endif
  endif

:受入条件を見直す;
:依存関係を確認する;
:見積もりを更新する;
:準備状況を確認する;

if (準備完了か?) then (はい)
  :項目をReadyにする;
else (いいえ)
  :不足事項を記録する;
  endif

:リファインメント結果を記録する;

stop
@enduml
```
