# BUC-LR-05 利用者レビュー・試用の実施

## 概要

対象者にレビュー・試用に参加させ、結果を記録する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:レビュー対象を特定する;
:参加者を募集する;
:レビュー環境を準備する;
:レビューガイドを作成する;

:レビューを実施する;
:フィードバックを収集する;
:問題を記録する;

:結果を分析する;
:改善点を特定する;

if (アクションが必要か?) then (はい)
  :アクションアイテムを記録する;
  :担当者を割り当てる;
  endif

:結果を記録する;
:関係者に共有する;

stop
@enduml
```
