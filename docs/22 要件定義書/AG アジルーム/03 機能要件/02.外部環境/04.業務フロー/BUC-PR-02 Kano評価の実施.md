# BUC-PR-02 Kano評価の実施

## 概要

要望について充足・不充足質問を収集し、品質カテゴリに分類する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:評価対象の要望を特定する;
:充足質問を作成する;
:不充足質問を作成する;
:対象者に質問を配布する;
:回答を収集する;

:回答を分析する;
:品質カテゴリに分類する;

if (分類結果が明確か?) then (いいえ)
  :追加調査を行う;
  else (はい)
  :分類結果を記録する;
  endif

:結果を優先順位に反映する;
:結果を関係者に共有する;

stop
@enduml
```
