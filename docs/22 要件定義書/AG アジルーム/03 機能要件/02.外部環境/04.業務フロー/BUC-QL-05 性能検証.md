# BUC-QL-05 性能検証

## 概要

性能要件・負荷条件を満たすか検証する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:性能要件を確認する;
:負荷条件を定義する;
:テスト環境を準備する;
:性能テストケースを作成する;

:性能テストを実行する;
:測定結果を記録する;

if (性能要件を満たすか?) then (はい)
  :合格として記録する;
else (いいえ)
  :原因を分析する;
  :改善策を提案する;
  :再テストを計画する;
  endif

:性能テスト結果をまとめする;
:関係者に報告する;

stop
@enduml
```
