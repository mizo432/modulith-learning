# BUC-QL-02 テストケースの作成・管理

## 概要

要求や受入条件に関連づけたテストケースを管理する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:テスト対象の要求を確認する;
:受入条件を確認する;
:テストケースを作成する;
:テストデータを準備する;
:期待結果を定義する;

:テストケースを検証する;

if (検証に合格か?) then (はい)
  :テストケースを登録する;
else (いいえ)
  :テストケースを修正する;
  :再検証を行う;
  endif

:テストケースを更新する;
:関連付けを記録する;

stop
@enduml
```
