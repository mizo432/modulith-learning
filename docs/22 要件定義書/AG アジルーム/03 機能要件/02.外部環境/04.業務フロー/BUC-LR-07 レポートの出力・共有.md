# BUC-LR-07 レポートの出力・共有

## 概要

権限に応じたレポートを出力・共有する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:レポート種類を確認する;
:対象期間を設定する;
:権限を確認する;

:データを収集する;
:レポートを生成する;
:フォーマットを適用する;

if (共有方法は?) then (メール)
  :メールで送信する;
else (ダッシュボード)
  :ダッシュボードに公開する;
else (ファイル)
  :ファイルを出力する;
  endif

:共有履歴を記録する;
:フィードバックを収集する;

stop
@enduml
```
