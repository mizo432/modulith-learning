# アクター一覧

プロダクトディスカバリー業務領域でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                                  |
|--------|--------------------------|-----------------------------------------------------------------------|
| ACT-01 | 従業員                   | 業務上の課題・要望・機会を共有し、ユーザー視点のフィードバックを提供  |
| ACT-02 | プロダクトオーナー（PO） | Product Vision/Goalを定め、課題・仮説を整理し、ステークホルダーと協働 |
| ACT-05 | トラッキング担当         | プロダクトの方向性・目標・仮説検証結果を参照                          |
