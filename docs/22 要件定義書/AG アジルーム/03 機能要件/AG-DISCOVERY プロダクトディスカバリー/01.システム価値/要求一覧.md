# 要求一覧

プロダクトディスカバリー業務領域の機能要求と非機能要求を定義します。

## 機能要求

| ID        | 要求名                 | 概要                                                           | 優先度 |
|-----------|------------------------|----------------------------------------------------------------|--------|
| FR-DIS-01 | Product Vision管理     | プロダクトの対象者、課題、目指す将来像を共有する               | MVP    |
| FR-DIS-02 | Product Goal管理       | プロダクト目標、期間、状態、関連指標を管理する                 | MVP    |
| FR-DIS-03 | 課題・機会・仮説管理   | 課題の背景、影響、仮説、検証方法を記録する                     | MVP    |
| FR-DIS-04 | ステークホルダー管理   | 関係者、関心事、影響範囲、連絡方法を整理する                   | 次期   |
| FR-DIS-05 | ユーザー・ペルソナ管理 | ユーザー像、ニーズ、利用状況を記録する                         | 次期   |
| FR-DIS-06 | ユーザージャーニー管理 | 利用者の行動、課題、感情、機会を可視化する                     | 次期   |
| FR-DIS-07 | Kanoモデル要望評価     | 機能の充足・不充足質問と評価マトリックスを使い、要望を分類する | 次期   |
| FR-DIS-08 | 成功指標管理           | 指標の定義、基準値、目標値、データ元、更新頻度を管理する       | 次期   |
| FR-DIS-09 | 実験・仮説検証管理     | 実験計画、結果、学びを仮説や目標と関連づける                   | 拡張   |

## 非機能要求

| ID         | 要求名       | 概要                                           |
|------------|--------------|------------------------------------------------|
| NFR-DIS-01 | 変更履歴追跡 | 情報の変更履歴を追跡可能にする                 |
| NFR-DIS-02 | 判断根拠記録 | 重要な決定の背景や前提を記録する               |
| NFR-DIS-03 | 情報検索     | 課題・仮説・ビジョンなどの情報を検索可能にする |
