# 成功指標属性一覧

プロダクトディスカバリー業務領域で扱う「成功指標」の属性を定義します。

| 属性名          | 型          | PK | 必須 | 説明                           |
|-----------------|-------------|----|------|--------------------------------|
| metric_id       | SnowflakeID | *  | Y    | 成功指標の一意な識別子         |
| product_goal_id | UUID        |    | Y    | 関連するプロダクト目標の識別子 |
| name            | String      |    | Y    | 指標名                         |
| description     | Text        |    | N    | 指標の説明                     |
| baseline_value  | Decimal     |    | N    | 基準値                         |
| target_value    | Decimal     |    | Y    | 目標値                         |
| unit            | String      |    | N    | 単位                           |
| created_at      | DateTime    |    | Y    | 作成日時                       |
| updated_at      | DateTime    |    | Y    | 最終更新日時                   |
