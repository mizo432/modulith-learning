# UC-DIS-003 Product Visionを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-003 |
| ユースケース名 | Product Visionを参照する |
| 英語名 | View Product Vision |
| 説明 | 現在のProduct Visionの内容を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-DIS-02 |
| 外部システム | - |
| 関連画面 | SCR-002（プロダクトビジョン・目標） |

## 前置条件

- ユーザーがシステムにログインしていること
- Product Vision（INF-DIS-01）が既に存在すること

## 基本フロー

1. ユーザーが「プロダクトビジョン・目標」画面（SCR-002）にアクセスする
2. システムがProduct Vision（INF-DIS-01）の内容を表示する
3. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- Product Visionの内容がユーザーに表示される
