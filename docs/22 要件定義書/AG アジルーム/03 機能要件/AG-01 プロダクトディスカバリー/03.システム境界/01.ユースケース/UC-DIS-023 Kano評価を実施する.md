# UC-DIS-023 Kano評価を実施する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-023 |
| ユースケース名 | Kano評価を実施する |
| 英語名 | Conduct Kano Evaluation |
| 説明 | Kano質問票に基づいて回答を収集し、品質カテゴリに分類する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-05 |
| 外部システム | - |
| 関連画面 | SCR-004（フィードバック管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- Kano質問票（INF-DIS-10）が既に存在すること

## 基本フロー

1. ユーザーが「フィードバック管理」画面（SCR-004）にアクセスする
2. 「Kano評価を実施」ボタンをクリックする
3. Kano質問票に基づいて回答を入力する
4. 入力を保存する
5. システムが回答を品質カテゴリに分類する
6. システムがKano評価結果（INF-DIS-10）を更新する
7. 評価完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Kano評価結果（INF-DIS-10）が更新される
- イベント「EVT-DIS-018 Kano評価が完了した」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-10 | Kano評価結果 | 更新対象の情報 |
| INF-DIS-14 | Kanoカテゴリ | 分類基準 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-018 | Kano評価が完了した | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 回答は必須入力 |
| 2 | 選択肢制限 | 回答は所定の選択肢から選択 |
