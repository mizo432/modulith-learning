# UC-DIS-019 ユーザージャーニーを作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-019 |
| ユースケース名 | ユーザージャーニーを作成する |
| 英語名 | Create User Journey |
| 説明 | 利用者の行動、課題、感情、機会を可視化する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-04 |
| 外部システム | - |
| 関連画面 | SCR-006（ユーザージャーニーマップ） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること

## 基本フロー

1. プロダクトオーナーが「ユーザージャーニーマップ」画面（SCR-006）にアクセスする
2. 「ユーザージャーニーを作成」ボタンをクリックする
3. 行動、課題、感情、機会を入力する
4. 入力を保存する
5. システムがユーザージャーニー（INF-DIS-08）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- ユーザージャーニー（INF-DIS-08）がシステムに登録される
- イベント「EVT-DIS-014 ユーザージャーニーが作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-08 | ユーザージャーニー | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-014 | ユーザージャーニーが作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 行動、課題は必須入力 |
| 2 | 文字数制限 | 各項目は1000文字以内 |
