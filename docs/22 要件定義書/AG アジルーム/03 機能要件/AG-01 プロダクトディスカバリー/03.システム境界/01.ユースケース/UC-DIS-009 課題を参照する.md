# UC-DIS-009 課題を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-009 |
| ユースケース名 | 課題を参照する |
| 英語名 | View Issue |
| 説明 | 登録された課題の一覧・詳細を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-DIS-01 |
| 外部システム | - |
| 関連画面 | SCR-004（フィードバック管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 課題（INF-DIS-03）が既に存在すること

## 基本フロー

1. ユーザーが「フィードバック管理」画面（SCR-004）にアクセスする
2. システムが課題（INF-DIS-03）の一覧を表示する
3. ユーザーが対象の課題を選択する
4. システムが課題の詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 課題の一覧・詳細がユーザーに表示される
