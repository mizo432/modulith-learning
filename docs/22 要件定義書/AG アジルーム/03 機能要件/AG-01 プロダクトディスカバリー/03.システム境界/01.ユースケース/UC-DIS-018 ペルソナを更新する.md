# UC-DIS-018 ペルソナを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-018 |
| ユースケース名 | ペルソナを更新する |
| 英語名 | Update Persona |
| 説明 | 既存のペルソナ情報を修正する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-04 |
| 外部システム | - |
| 関連画面 | SCR-005（ペルソナ管理） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- ペルソナ（INF-DIS-07）が既に存在すること

## 基本フロー

1. プロダクトオーナーが「ペルソナ管理」画面（SCR-005）にアクセスする
2. 既存のペルソナを選択する
3. 「編集」ボタンをクリックする
4. ユーザー像、ニーズ、利用状況を修正する
5. 変更を保存する
6. システムがペルソナ（INF-DIS-07）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- ペルソナ（INF-DIS-07）が更新される
- イベント「EVT-DIS-013 ペルソナが更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-07 | ペルソナ | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-013 | ペルソナが更新された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 名前、ユーザー像是必須入力 |
| 2 | 文字数制限 | ユーザー像是1000文字以内 |
