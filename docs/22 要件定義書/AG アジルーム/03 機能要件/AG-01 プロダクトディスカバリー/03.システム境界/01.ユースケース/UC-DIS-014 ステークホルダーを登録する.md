# UC-DIS-014 ステークホルダーを登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-014 |
| ユースケース名 | ステークホルダーを登録する |
| 英語名 | Register Stakeholder |
| 説明 | 関係者、関心事、影響範囲、連絡方法を整理して登録する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-04 |
| 外部システム | - |
| 関連画面 | SCR-003（ステークホルダー管理） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること

## 基本フロー

1. プロダクトオーナーが「ステークホルダー管理」画面（SCR-003）にアクセスする
2. 「ステークホルダーを登録」ボタンをクリックする
3. 名前、関心事、影響範囲、連絡方法を入力する
4. 入力を保存する
5. システムがステークホルダー（INF-DIS-06）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- ステークホルダー（INF-DIS-06）がシステムに登録される
- イベント「EVT-DIS-010 ステークホルダーが登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-06 | ステークホルダー | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-010 | ステークホルダーが登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 名前、連絡方法は必須入力 |
| 2 | 文字数制限 | 関心事は1000文字以内 |
