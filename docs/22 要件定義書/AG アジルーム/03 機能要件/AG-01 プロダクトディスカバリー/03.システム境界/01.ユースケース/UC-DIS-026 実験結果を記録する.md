# UC-DIS-026 実験結果を記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-026 |
| ユースケース名 | 実験結果を記録する |
| 英語名 | Record Experiment Result |
| 説明 | 実験の実施結果と得られた学びを記録する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 低 |
| ビジネスユースケース | BUC-DIS-03 |
| 外部システム | - |
| 関連画面 | SCR-002（プロダクトビジョン・目標） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 実験計画（INF-DIS-11）が既に存在すること

## 基本フロー

1. プロダクトオーナーが「プロダクトビジョン・目標」画面（SCR-002）にアクセスする
2. 既存の実験計画を選択する
3. 「実験結果を記録」ボタンをクリックする
4. 実施結果、得られた学びを入力する
5. 入力を保存する
6. システムが実験計画（INF-DIS-11）を更新する
7. 記録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 実験計画（INF-DIS-11）が更新される
- イベント「EVT-DIS-020 実験結果が記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-11 | 実験計画 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-020 | 実験結果が記録された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 実施結果は必須入力 |
| 2 | 文字数制限 | 学びは2000文字以内 |
