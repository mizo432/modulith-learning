# UC-DIS-016 ステークホルダーを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-016 |
| ユースケース名 | ステークホルダーを参照する |
| 英語名 | View Stakeholder |
| 説明 | 登録されたステークホルダーの一覧・詳細を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-04 |
| 外部システム | - |
| 関連画面 | SCR-003（ステークホルダー管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ステークホルダー（INF-DIS-06）が既に存在すること

## 基本フロー

1. ユーザーが「ステークホルダー管理」画面（SCR-003）にアクセスする
2. システムがステークホルダー（INF-DIS-06）の一覧を表示する
3. ユーザーが対象のステークホルダーを選択する
4. システムがステークホルダーの詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- ステークホルダーの一覧・詳細がユーザーに表示される
