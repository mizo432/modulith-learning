# UC-DIS-024 Kano評価結果を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-024 |
| ユースケース名 | Kano評価結果を参照する |
| 英語名 | View Kano Evaluation Result |
| 説明 | 要望のKano分類結果を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-05 |
| 外部システム | - |
| 関連画面 | SCR-004（フィードバック管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- Kano評価結果（INF-DIS-10）が既に存在すること

## 基本フロー

1. ユーザーが「フィードバック管理」画面（SCR-004）にアクセスする
2. システムがKano評価結果（INF-DIS-10）の一覧を表示する
3. ユーザーが対象の評価結果を選択する
4. システムがKano分類結果を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- Kano評価結果がユーザーに表示される
