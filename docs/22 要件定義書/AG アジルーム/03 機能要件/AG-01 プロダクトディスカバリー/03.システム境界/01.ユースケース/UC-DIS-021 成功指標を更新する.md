# UC-DIS-021 成功指標を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-021 |
| ユースケース名 | 成功指標を更新する |
| 英語名 | Update Success Metric |
| 説明 | 既存の成功指標の値・目標値を修正する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-02 |
| 外部システム | - |
| 関連画面 | SCR-002（プロダクトビジョン・目標） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 成功指標（INF-DIS-09）が既に存在すること

## 基本フロー

1. プロダクトオーナーが「プロダクトビジョン・目標」画面（SCR-002）にアクセスする
2. 既存の成功指標を選択する
3. 「編集」ボタンをクリックする
4. 基準値、目標値、データ元、更新頻度を修正する
5. 変更を保存する
6. システムが成功指標（INF-DIS-09）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 成功指標（INF-DIS-09）が更新される
- イベント「EVT-DIS-016 成功指標が更新された」が発行される
