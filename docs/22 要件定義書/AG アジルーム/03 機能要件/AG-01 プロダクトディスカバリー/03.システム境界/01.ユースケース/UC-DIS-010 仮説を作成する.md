# UC-DIS-010 仮説を作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-010 |
| ユースケース名 | 仮説を作成する |
| 英語名 | Create Hypothesis |
| 説明 | 課題に対する検証可能な仮説と検証方法を定義する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-DIS-03 |
| 外部システム | - |
| 関連画面 | SCR-002（プロダクトビジョン・目標） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 課題（INF-DIS-03）が既に存在すること

## 基本フロー

1. プロダクトオーナーが「プロダクトビジョン・目標」画面（SCR-002）にアクセスする
2. 「仮説を作成」ボタンをクリックする
3. 仮説名、検証方法、関連課題を入力する
4. 入力を保存する
5. システムが仮説（INF-DIS-05）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 仮説（INF-DIS-05）がシステムに登録される
- イベント「EVT-DIS-007 仮説が作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-05 | 仮説 | 作成対象の情報 |
| INF-DIS-13 | 仮説と課題 | 関連付け情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-007 | 仮説が作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 仮説名、検証方法は必須入力 |
| 2 | 文字数制限 | 仮説名は500文字以内 |
