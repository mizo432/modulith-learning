# UC-DIS-007 課題を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-007 |
| ユースケース名 | 課題を登録する |
| 英語名 | Register Issue |
| 説明 | 業務上の困りごとや繰り返し発生する問題を背景とともに記録する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-DIS-01 |
| 外部システム | - |
| 関連画面 | SCR-004（フィードバック管理） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「フィードバック管理」画面（SCR-004）にアクセスする
2. 「課題を登録」ボタンをクリックする
3. 課題名、詳細、影響、背景を入力する
4. 入力を保存する
5. システムが課題（INF-DIS-03）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 課題（INF-DIS-03）がシステムに登録される
- イベント「EVT-DIS-005 課題が登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-03 | 課題 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-005 | 課題が登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 課題名、詳細は必須入力 |
| 2 | 文字数制限 | 詳細は2000文字以内 |
