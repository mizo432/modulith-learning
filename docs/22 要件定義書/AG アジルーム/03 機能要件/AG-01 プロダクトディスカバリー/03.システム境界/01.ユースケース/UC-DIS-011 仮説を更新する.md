# UC-DIS-011 仮説を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-011 |
| ユースケース名 | 仮説を更新する |
| 英語名 | Update Hypothesis |
| 説明 | 仮説の検証方法・結果・学びを修正・更新する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-DIS-03 |
| 外部システム | - |
| 関連画面 | SCR-002（プロダクトビジョン・目標） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 仮説（INF-DIS-05）が既に存在すること

## 基本フロー

1. プロダクトオーナーが「プロダクトビジョン・目標」画面（SCR-002）にアクセスする
2. 既存の仮説を選択する
3. 「編集」ボタンをクリックする
4. 検証方法、結果、学びを修正する
5. 変更を保存する
6. システムが仮説（INF-DIS-05）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 仮説（INF-DIS-05）が更新される
- イベント「EVT-DIS-008 仮説が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-05 | 仮説 | 更新対象の情報 |
| INF-DIS-13 | 仮説と課題 | 関連付け情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-008 | 仮説が更新された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 仮説名、検証方法は必須入力 |
| 2 | 文字数制限 | 仮説名は500文字以内 |
