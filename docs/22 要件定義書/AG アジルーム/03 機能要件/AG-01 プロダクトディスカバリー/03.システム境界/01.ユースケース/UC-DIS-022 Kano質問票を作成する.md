# UC-DIS-022 Kano質問票を作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-022 |
| ユースケース名 | Kano質問票を作成する |
| 英語名 | Create Kano Questionnaire |
| 説明 | 各要望について機能がある場合・ない場合の反応を対で定義する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-05 |
| 外部システム | - |
| 関連画面 | SCR-004（フィードバック管理） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 要望（INF-DIS-04）が既に存在すること

## 基本フロー

1. プロダクトオーナーが「フィードバック管理」画面（SCR-004）にアクセスする
2. 「Kano質問票を作成」ボタンをクリックする
3. 要望、機能がある場合の反応、機能がない場合の反応を入力する
4. 入力を保存する
5. システムがKano評価結果（INF-DIS-10）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Kano評価結果（INF-DIS-10）がシステムに登録される
- イベント「EVT-DIS-017 Kano質問票が作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-10 | Kano評価結果 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-017 | Kano質問票が作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 要望、反応は必須入力 |
| 2 | 選択肢制限 | 反応は所定の選択肢から選択 |
