# UC-DIS-020 成功指標を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-020 |
| ユースケース名 | 成功指標を登録する |
| 英語名 | Register Success Metric |
| 説明 | 指標の定義、基準値、目標値、データ元、更新頻度を設定する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-02 |
| 外部システム | - |
| 関連画面 | SCR-002（プロダクトビジョン・目標） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること

## 基本フロー

1. プロダクトオーナーが「プロダクトビジョン・目標」画面（SCR-002）にアクセスする
2. 「成功指標を登録」ボタンをクリックする
3. 指標名、定義、基準値、目標値、データ元、更新頻度を入力する
4. 入力を保存する
5. システムが成功指標（INF-DIS-09）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 成功指標（INF-DIS-09）がシステムに登録される
- イベント「EVT-DIS-015 成功指標が登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-09 | 成功指標 | 作成対象の情報 |
| INF-DIS-12 | Product Goalと成功指標 | 関連付け情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-015 | 成功指標が登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 指標名、定義は必須入力 |
| 2 | 数値制限 | 基準値、目標値は数値入力 |
