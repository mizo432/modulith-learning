# UC-DIS-008 課題を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-008 |
| ユースケース名 | 課題を更新する |
| 英語名 | Update Issue |
| 説明 | 既存の課題の詳細・影響・状態を修正する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-DIS-01 |
| 外部システム | - |
| 関連画面 | SCR-004（フィードバック管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 課題（INF-DIS-03）が既に存在すること

## 基本フロー

1. ユーザーが「フィードバック管理」画面（SCR-004）にアクセスする
2. 既存の課題を選択する
3. 「編集」ボタンをクリックする
4. 詳細、影響、状態を修正する
5. 変更を保存する
6. システムが課題（INF-DIS-03）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 課題（INF-DIS-03）が更新される
- イベント「EVT-DIS-006 課題が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-03 | 課題 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-006 | 課題が更新された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 課題名、詳細は必須入力 |
| 2 | 文字数制限 | 詳細は2000文字以内 |
