# UC-DIS-025 実験計画を作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-025 |
| ユースケース名 | 実験計画を作成する |
| 英語名 | Create Experiment Plan |
| 説明 | 実験計画、結果、学びを仮説や目標と関連づけて登録する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 低 |
| ビジネスユースケース | BUC-DIS-03 |
| 外部システム | - |
| 関連画面 | SCR-002（プロダクトビジョン・目標） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 仮説（INF-DIS-05）が既に存在すること

## 基本フロー

1. プロダクトオーナーが「プロダクトビジョン・目標」画面（SCR-002）にアクセスする
2. 「実験計画を作成」ボタンをクリックする
3. 実験名、目的、方法、期間、関連仮説を入力する
4. 入力を保存する
5. システムが実験計画（INF-DIS-11）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 実験計画（INF-DIS-11）がシステムに登録される
- イベント「EVT-DIS-019 実験計画が作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-11 | 実験計画 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-019 | 実験計画が作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 実験名、目的は必須入力 |
| 2 | 文字数制限 | 方法は2000文字以内 |
