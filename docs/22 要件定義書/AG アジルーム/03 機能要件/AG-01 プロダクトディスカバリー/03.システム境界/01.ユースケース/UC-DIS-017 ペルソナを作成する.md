# UC-DIS-017 ペルソナを作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-DIS-017 |
| ユースケース名 | ペルソナを作成する |
| 英語名 | Create Persona |
| 説明 | ユーザー像、ニーズ、利用状況を定義して登録する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-DIS-04 |
| 外部システム | - |
| 関連画面 | SCR-005（ペルソナ管理） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること

## 基本フロー

1. プロダクトオーナーが「ペルソナ管理」画面（SCR-005）にアクセスする
2. 「ペルソナを作成」ボタンをクリックする
3. 名前、ユーザー像、ニーズ、利用状況を入力する
4. 入力を保存する
5. システムがペルソナ（INF-DIS-07）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- ペルソナ（INF-DIS-07）がシステムに登録される
- イベント「EVT-DIS-012 ペルソナが作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-DIS-07 | ペルソナ | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-DIS-012 | ペルソナが作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 名前、ユーザー像是必須入力 |
| 2 | 文字数制限 | ユーザー像是1000文字以内 |
