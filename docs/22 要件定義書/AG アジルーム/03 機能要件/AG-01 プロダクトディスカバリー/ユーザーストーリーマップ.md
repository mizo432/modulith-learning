# ユーザーストーリーマップ

AG-01 プロダクトディスカバリーのユーザーストーリーマップを定義します。

## 概要

ユーザーストーリーマップは、ユーザーの活動とストーリーを視覚的に配置し、プロダクトの範囲と優先順位を検討するためのツールです。

## ユーザー活動

| 番号 | 活動名 | 説明 |
|------|--------|------|
| 1 | ビジョン策定 | プロダクトのビジョンと目標を定義する |
| 2 | 課題把握 | 業務上の課題や要望を収集・整理する |
| 3 | 仮説検証 | 仮説を作成し、実験を通じて検証する |
| 4 | ステークホルダー理解 | 関係者やユーザーを理解する |
| 5 | 評価・分類 | Kano評価などにより要望を分類する |
| 6 | 実験実施 | 実験計画を作成し、結果を記録する |
