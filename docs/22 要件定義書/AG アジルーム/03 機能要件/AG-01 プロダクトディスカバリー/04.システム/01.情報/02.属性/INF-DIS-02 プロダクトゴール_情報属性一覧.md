# 情報属性一覧

プロダクトゴールの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-02 |
| 情報名 | プロダクトゴール |
| 情報種類 | リソース |
| 説明 | プロダクト目標、期間、状態、関連指標を定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | プロダクトゴールの一意な識別子 |
| 2 | visionId | | Long | 必須 | 関連するプロダクトビジョンのID |
| 3 | title | | String | 必須 | ゴールのタイトル |
| 4 | description | | String | 任意 | 詳細な説明 |
| 5 | startDate | | Date | 必須 | ゴールの開始日 |
| 6 | endDate | | Date | 必須 | ゴールの終了日 |
| 7 | goalState | | Enum | 必須 | ゴールの状態（未着手、進行中、完了、中止） |
| 8 | createdDate | | DateTime | 必須 | 作成日時 |
| 9 | updatedDate | | DateTime | 必須 | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのプロダクトゴールは、タイトル・期間・状態の組み合わせで1つのゴールを構成する |
| 同一性 (Sameness) | idが同じ場合、同じプロダクトゴールであると判断する |
| カテゴリ (Category) | プロダクトの目標を示すゴール情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未着手 | ゴールが設定されたがまだ開始されていない状態 | - | 進行中 | プロダクトゴールを開始する |
| 進行中 | ゴールに向かって作業が進行中の状態 | 未着手 | 完了、中止 | プロダクトゴールを完了する、プロダクトゴールを中止する |
| 完了 | ゴールが達成された状態 | 進行中 | - | - |
| 中止 | ゴールが中止された状態 | 進行中 | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-DIS-01 | プロダクトビジョン | 多対1 | プロダクトゴールは1つのビジョンに属する |
| INF-DIS-03 | 成功指標 | 1対多 | プロダクトゴールは複数の成功指標を持つ |
