# 情報属性一覧

実験計画の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-06 |
| 情報名 | 実験計画 |
| 情報種類 | リソース |
| 説明 | 実験計画、結果、学びを定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 実験計画の一意な識別子 |
| 2 | hypothesisId | | Long | 必須 | 関連する仮説のID |
| 3 | title | | String | 必須 | 実験計画のタイトル |
| 4 | planContent | | String | 必須 | 計画内容 |
| 5 | result | | String | 任意 | 実験結果 |
| 6 | learning | | String | 任意 | 学び |
| 7 | createdDate | | DateTime | 必須 | 作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの実験計画は、計画内容・結果・学びの組み合わせで1つの実験を構成する |
| 同一性 (Sameness) | idが同じ場合、同じ実験計画であると判断する |
| カテゴリ (Category) | 仮説検証のための実験計画情報 |
