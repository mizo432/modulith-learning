# 情報属性一覧

Kano評価の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-08 |
| 情報名 | Kano評価 |
| 情報種類 | リソース |
| 説明 | Kano質問票、回答、品質カテゴリを定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | Kano評価の一意な識別子 |
| 2 | requestId | | Long | 必須 | 関連する要望のID |
| 3 | questionId | | String | 必須 | 質問票ID |
| 4 | functionalQuestion | | String | 必須 | 充足質問 |
| 5 | nonFunctionalQuestion | | String | 必須 | 不充足質問 |
| 6 | responseCount | | Integer | 必須 | 回答数 |
| 7 | classification | | Enum | 必須 | Kano分類結果（魅力的品質、一元的品質、必須品質、反対品質、無関係） |
| 8 | createdDate | | DateTime | 必須 | 作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのKano評価は、質問票ID・充足質問・不充足質問の組み合わせで1つの評価を構成する |
| 同一性 (Sameness) | idが同じ場合、同じKano評価であると判断する |
| カテゴリ (Category) | 要望の品質分類を行うKano評価情報 |
