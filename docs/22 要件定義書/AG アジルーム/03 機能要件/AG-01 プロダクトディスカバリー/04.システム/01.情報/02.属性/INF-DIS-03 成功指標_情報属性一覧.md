# 情報属性一覧

成功指標の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-03 |
| 情報名 | 成功指標 |
| 情報種類 | リソース |
| 説明 | 指標の定義、基準値、目標値、データ元を定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 成功指標の一意な識別子 |
| 2 | goalId | | Long | 必須 | 関連するプロダクトゴールのID |
| 3 | metricName | | String | 必須 | 指標の名前 |
| 4 | unit | | String | 必須 | 指標の単位 |
| 5 | baseline | | Double | 必須 | 基準値 |
| 6 | targetValue | | Double | 必須 | 目標値 |
| 7 | dataSource | | String | 任意 | データのソース |
| 8 | updateFrequency | | String | 任意 | 更新頻度 |
| 9 | createdDate | | DateTime | 必須 | 作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの成功指標は、名前・単位・基準値・目標値の組み合わせで1つの指標を構成する |
| 同一性 (Sameness) | idが同じ場合、同じ成功指標であると判断する |
| カテゴリ (Category) | プロダクトゴールの達成度を測る指標情報 |

## 状態遷移
