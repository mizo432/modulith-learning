# 情報属性一覧

ユーザージャーニーの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-11 |
| 情報名 | ユーザージャーニー |
| 情報種類 | リソース |
| 説明 | 利用者の行動、課題、感情、機会を定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | ユーザージャーニーの一意な識別子 |
| 2 | title | | String | 必須 | ジャーニーのタイトル |
| 3 | scene | | String | 必須 | シーン |
| 4 | action | | String | 必須 | 行動 |
| 5 | problem | | String | 任意 | 課題 |
| 6 | emotion | | String | 任意 | 感情 |
| 7 | opportunity | | String | 任意 | 機会 |
| 8 | createdDate | | DateTime | 必須 | 作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのユーザージャーニーは、タイトル・シーン・行動・課題の組み合わせで1つのジャーニーを構成する |
| 同一性 (Sameness) | idが同じ場合、同じユーザージャーニーであると判断する |
| カテゴリ (Category) | ユーザーの行動フローを表すジャーニー情報 |

## 状態遷移

この情報は状態遷移を持ちません。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | - | - | - | - |
