# 情報属性一覧

仮説の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-05 |
| 情報名 | 仮説 |
| 情報種類 | リソース |
| 説明 | 課題に対する検証可能な仮説と検証方法を定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 仮説の一意な識別子 |
| 2 | issueId | | Long | 必須 | 関連する課題のID |
| 3 | title | | String | 必須 | 仮説のタイトル |
| 4 | content | | String | 必須 | 仮説の内容 |
| 5 | verificationMethod | | String | 必須 | 検証方法 |
| 6 | hypothesisState | | Enum | 必須 | 仮説の状態（未検証、検証中、検証済み、棄却） |
| 7 | createdDate | | DateTime | 必須 | 作成日時 |
| 8 | updatedDate | | DateTime | 必須 | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの仮説は、内容・検証方法の組み合わせで1つの仮説を構成する |
| 同一性 (Sameness) | idが同じ場合、同じ仮説であると判断する |
| カテゴリ (Category) | 課題解決のための仮説情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未検証 | 仮説が作成されたがまだ検証されていない状態 | - | 検証中 | 仮説を検証開始する |
| 検証中 | 仮説の検証が進行中の状態 | 未検証 | 検証済み、棄却 | 仮説を検証完了する、仮説を棄却する |
| 検証済み | 仮説が検証され支持された状態 | 検証中 | - | - |
| 棄却 | 仮説が検証され棄却された状態 | 検証中 | - | - |
