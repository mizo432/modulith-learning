# 情報属性一覧

要望の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-07 |
| 情報名 | 要望 |
| 情報種類 | リソース |
| 説明 | 顧客や利用者から受けた意見・要望を定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 要望の一意な識別子 |
| 2 | issueId | | Long | 任意 | 関連する課題のID |
| 3 | title | | String | 必須 | 要望のタイトル |
| 4 | content | | String | 必須 | 要望の内容 |
| 5 | source | | String | 任意 | 情報源 |
| 6 | requestState | | Enum | 必須 | 要望の状態（未対応、検討中、実装済み、却下） |
| 7 | createdDate | | DateTime | 必須 | 作成日時 |
| 8 | updatedDate | | DateTime | 必須 | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの要望は、タイトル・内容・情報源の組み合わせで1つの要望を構成する |
| 同一性 (Sameness) | idが同じ場合、同じ要望であると判断する |
| カテゴリ (Category) | 顧客や利用者からの要望情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未対応 | 要望が登録されたがまだ対応されていない状態 | - | 検討中 | 要望を検討開始する |
| 検討中 | 要望の検討が進行中の状態 | 未対応 | 実装済み、却下 | 要望を実装する、要望を却下する |
| 実装済み | 要望が実装された状態 | 検討中 | - | - |
| 却下 | 要望が却下された状態 | 検討中 | - | - |
