# 情報属性一覧

ステークホルダーの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-09 |
| 情報名 | ステークホルダー |
| 情報種類 | リソース |
| 説明 | 関係者、関心事、影響範囲、連絡方法を定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | ステークホルダーの一意な識別子 |
| 2 | name | | String | 必須 | 名前 |
| 3 | organization | | String | 任意 | 所属組織 |
| 4 | interest | | String | 任意 | 関心事 |
| 5 | impactScope | | String | 任意 | 影響範囲 |
| 6 | contactMethod | | String | 任意 | 連絡方法 |
| 7 | registeredDate | | DateTime | 必須 | 登録日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのステークホルダーは、名前・組織・関心事の組み合わせで1つの関係者を構成する |
| 同一性 (Sameness) | idが同じ場合、同じステークホルダーであると判断する |
| カテゴリ (Category) | プロダクトに関与する関係者情報 |
