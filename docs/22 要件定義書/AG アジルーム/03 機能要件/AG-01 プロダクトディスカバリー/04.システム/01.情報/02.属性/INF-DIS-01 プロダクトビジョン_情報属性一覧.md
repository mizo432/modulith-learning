# 情報属性一覧

プロダクトビジョンの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-01 |
| 情報名 | プロダクトビジョン |
| 情報種類 | リソース |
| 説明 | プロダクトの対象者、課題、目指す将来像を定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | プロダクトビジョンの一意な識別子 |
| 2 | title | | String | 必須 | ビジョンのタイトル |
| 3 | target | | String | 必須 | 対象ユーザーや市場 |
| 4 | problem | | String | 必須 | 解決する課題 |
| 5 | futureVision | | String | 必須 | 目指す将来像 |
| 6 | description | | String | 任意 | 詳細な説明 |
| 7 | state | | Enum | 必須 | ビジョンの状態（下書き、公開、アーカイブ） |
| 8 | createdDate | | DateTime | 必須 | 作成日時 |
| 9 | updatedDate | | DateTime | 必須 | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのプロダクトビジョンは、対象者・課題・将来像の組み合わせで1つのビジョンを構成する |
| 同一性 (Sameness) | idが同じ場合、同じプロダクトビジョンであると判断する |
| カテゴリ (Category) | プロダクトの方向性を示すビジョン情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 下書き | ビジョンが作成されたが未公開の状態 | - | 公開 | プロダクトビジョンを公開する |
| 公開 | ビジョンがチームに公開されている状態 | 下書き | アーカイブ | プロダクトビジョンをアーカイブする |
| アーカイブ | 過去のビジョンとして保存されている状態 | 公開 | - | - |
