# 情報属性一覧

ペルソナの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-10 |
| 情報名 | ペルソナ |
| 情報種類 | リソース |
| 説明 | ユーザー像、ニーズ、利用状況を定義する情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | ペルソナの一意な識別子 |
| 2 | name | | String | 必須 | ペルソナの名前 |
| 3 | age | | Integer | 任意 | 年齢 |
| 4 | occupation | | String | 任意 | 職業 |
| 5 | needs | | String | 任意 | ニーズ |
| 6 | usageContext | | String | 任意 | 利用状況 |
| 7 | createdDate | | DateTime | 必須 | 作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのペルソナは、名前・年齢・職業・ニーズの組み合わせで1つのユーザー像を構成する |
| 同一性 (Sameness) | idが同じ場合、同じペルソナであると判断する |
| カテゴリ (Category) | プロダクトのターゲットユーザーを表すペルソナ情報 |
