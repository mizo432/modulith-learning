# 画面属性一覧

プロダクトビジョン管理画面の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-002 |
| 画面名 | プロダクトビジョン管理画面 |
| 説明 | プロダクトビジョン、ゴール、仮説の登録・編集・参照を行う画面 |
| 関連ユースケース | UC-DIS-01, UC-DIS-02, UC-DIS-03 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | タイトル | 入力 | String | 必須 | - | 最大200文字 | ビジョン/ゴール/仮説のタイトル |
| 2 | 対象者 | 入力 | String | 必須 | - | 最大500文字 | 対象ユーザーや市場 |
| 3 | 課題 | 入力 | String | 必須 | - | 最大1000文字 | 解決する課題 |
| 4 | 将来像 | 入力 | String | 必須 | - | 最大1000文字 | 目指す将来像 |
| 5 | 説明 | 入力 | String | 任意 | - | 最大2000文字 | 詳細な説明 |
| 6 | 状態 | 選択 | Enum | 必須 | 下書き | 下書き、公開、アーカイブ | ビジョンの状態 |
| 7 | 開始日 | 入力 | Date | 必須 | 今日 | - | ゴールの開始日 |
| 8 | 終了日 | 入力 | Date | 必須 | - | 開始日以降 | ゴールの終了日 |
| 9 | ゴール状態 | 選択 | Enum | 必須 | 未着手 | 未着手、進行中、完了、中止 | ゴールの状態 |
| 10 | 指標名 | 入力 | String | 必須 | - | 最大100文字 | 成功指標の名前 |
| 11 | 基準値 | 入力 | Double | 必須 | 0 | 0以上 | 現在の基準値 |
| 12 | 目標値 | 入力 | Double | 必須 | 0 | 基準値以上 | 目標とする値 |
| 13 | 仮説内容 | 入力 | String | 必須 | - | 最大2000文字 | 仮説の内容 |
| 14 | 検証方法 | 入力 | String | 必須 | - | 最大1000文字 | 仮説の検証方法 |
| 15 | 仮説状態 | 選択 | Enum | 必須 | 未検証 | 未検証、検証中、検証済み、棄却 | 仮説の状態 |
| 16 | 計画内容 | 入力 | String | 任意 | - | 最大2000文字 | 実験計画の内容 |
| 17 | 結果 | 入力 | String | 任意 | - | 最大2000文字 | 実験結果 |
| 18 | 学び | 入力 | String | 任意 | - | 最大1000文字 | 実験から得た学び |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | プロダクトビジョン領域 | ビジョンの基本情報 | タイトル、対象者、課題、将来像、説明、状態 |
| 2 | プロダクトゴール領域 | ゴールの基本情報 | タイトル、開始日、終了日、ゴール状態 |
| 3 | 成功指標領域 | 指標の定義 | 指標名、基準値、目標値 |
| 4 | 仮説領域 | 仮説の基本情報 | 仮説内容、検証方法、仮説状態 |
| 5 | 実験計画領域 | 実験の詳細 | 計画内容、結果、学び |

## 画面操作

画面で実行可能な操作を定義します。

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | 登録 | ボタンクリック | 新規ビジョン/ゴール/仮説を登録 | - |
| 2 | 更新 | ボタンクリック | 既存のデータを更新 | - |
| 3 | 削除 | ボタンクリック | 選択したデータを削除 | - |
| 4 | 一覧表示 | リンククリック | 一覧画面へ遷移 | SCR-002 |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 終了日制約 | 終了日 | 開始日以降であること | ゴールの期間が正しく設定される |
| 2 | 目標値制約 | 目標値 | 基準値以上であること | 目標が基準を上回る |
