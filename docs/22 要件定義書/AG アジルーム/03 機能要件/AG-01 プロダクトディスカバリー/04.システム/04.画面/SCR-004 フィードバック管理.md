# フィードバック管理

フィードバック管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-004 |
| 画面名           | フィードバック管理 |
| 説明             | 要望・意見・課題を記録し、評価・追跡する |
| 関連ユースケース | UC-DIS-007, UC-DIS-008, UC-DIS-009, UC-DIS-013, UC-DIS-022, UC-DIS-023, UC-DIS-024 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、フィードバック総数、未対応数を表示 |
| 検索・フィルター | 種類、状態、優先度で検索・絞り込み |
| メインコンテンツ | フィードバック一覧表または詳細情報を表示 |
| サイドバー | 種類別集計、状態別集計を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | タイトル | 文字列 | はい | フィードバックのタイトル |
| 2 | 種類 | 選択 | はい | 種類（課題、要望、意見） |
| 3 | 内容 | テキスト | はい | 詳細な内容 |
| 4 | 提出者 | 文字列 | いいえ | 提出した人の名前 |
| 5 | 提出日 | 日付 | はい | 提出された日付 |
| 6 | 優先度 | 選択 | いいえ | 優先度（高、中、低） |
| 7 | 状態 | 選択 | はい | 処理状態（未対応、対応中、完了、却下） |
| 8 | 影響度 | 選択 | いいえ | 影響の大きさ（大、中、小） |
| 9 | 背景 | テキスト | いいえ | 発生背景や状況 |
| 10 | 対応内容 | テキスト | いいえ | 対応した内容の記録 |
| 11 | Kano分類 | 選択 | いいえ | Kano評価結果（必須、魅力、一元的、無関心、逆転） |
| 12 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 課題を登録 | 新規の課題を記録する |
| 2 | 課題を更新 | 既存の課題を修正する |
| 3 | 課題を参照 | 登録された課題を確認する |
| 4 | 要望を登録 | 新規の要望を記録する |
| 5 | Kano質問票を作成 | 要望に対するKano質問票を定義する |
| 6 | Kano評価を実施 | 質問票に基づいて回答を収集・分類する |
| 7 | Kano評価結果を参照 | Kano分類結果を確認する |
| 8 | 検索 | 条件に合致するフィードバックを検索する |
| 9 | エクスポート | フィードバック一覧をエクスポートする |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 状態遷移 | 状態は規定された遷移ルールに従って変更できる |
| 2 | Kano評価 | Kano評価は要望種類のみ対象 |
