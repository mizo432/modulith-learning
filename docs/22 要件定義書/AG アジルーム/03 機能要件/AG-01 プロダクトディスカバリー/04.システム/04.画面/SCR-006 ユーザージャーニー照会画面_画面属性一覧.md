# 画面属性一覧

ユーザージャーニー照会画面の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-006 |
| 画面名 | ユーザージャーニー照会画面 |
| 説明 | ユーザージャーニーの一覧参照・詳細参照を行う画面 |
| 関連ユースケース | UC-DIS-08 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | タイトル | 表示 | String | 必須 | - | 最大200文字 | ジャーニーのタイトル |
| 2 | シーン | 表示 | String | 必須 | - | 最大500文字 | シーン |
| 3 | 行動 | 表示 | String | 必須 | - | 最大1000文字 | 行動 |
| 4 | 課題 | 表示 | String | 任意 | - | 最大1000文字 | 課題 |
| 5 | 感情 | 表示 | String | 任意 | - | 最大500文字 | 感情 |
| 6 | 機会 | 表示 | String | 任意 | - | 最大1000文字 | 機会 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | 一覧領域 | ユーザージャーニー一覧 | タイトル、シーン |
| 2 | 詳細領域 | ユーザージャーニー詳細 | タイトル、シーン、行動、課題、感情、機会 |
