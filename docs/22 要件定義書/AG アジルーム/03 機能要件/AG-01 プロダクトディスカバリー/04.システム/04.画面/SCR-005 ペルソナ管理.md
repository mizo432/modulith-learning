# ペルソナ管理

ペルソナ管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-005 |
| 画面名           | ペルソナ管理 |
| 説明             | ユーザー像、ニーズ、前提、根拠を整理する |
| 関連ユースケース | UC-DIS-017, UC-DIS-018 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、ペルソナ総数、最終更新日を表示 |
| 検索・フィルター | 名前、属性で検索・絞り込み |
| メインコンテンツ | ペルソナ一覧カードまたは詳細情報を表示 |
| サイドバー | 属性別集計を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ペルソナ名 | 文字列 | はい | ペルソナの名前 |
| 2 | 年齢層 | 文字列 | いいえ | 対象年齢層 |
| 3 | 職業 | 文字列 | いいえ | 職業または役職 |
| 4 | 属性 | テキスト | いいえ | 性別、地域などの属性 |
| 5 | ニーズ | テキスト | はい | 持っているニーズや欲求 |
| 6 | 目標 | テキスト | いいえ | 達成したい目標 |
| 7 | 行動パターン | テキスト | いいえ | 典型的な行動パターン |
| 8 | 利用状況 | テキスト | いいえ | システムの利用頻度や場面 |
| 9 | 前提条件 | テキスト | いいえ | 前提となる条件 |
| 10 | 根拠 | テキスト | いいえ | ペルソナ作成の根拠データ |
| 11 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ペルソナを作成 | 新規のペルソナを定義する |
| 2 | ペルソナを更新 | 既存のペルソナを修正する |
| 3 | ペルソナを参照 | 登録されたペルソナを確認する |
| 4 | 検索 | 条件に合致するペルソナを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ペルソナの編集はプロダクトオーナーのみ可能 |
| 2 | 重複チェック | 同じ名前のペルソナは重複登録できない |
