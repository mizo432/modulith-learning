# 画面属性一覧

ペルソナ管理の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-005 |
| 画面名 | ペルソナ管理 |
| 説明 | ユーザー像、ニーズ、前提、根拠を整理する |
| 関連ユースケース | UC-DIS-017, UC-DIS-018 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ペルソナ名 | 入力 | String | はい | - | 最大255文字 | ペルソナの名前 |
| 2 | 年齢層 | 入力 | String | いいえ | - | 最大100文字 | 年齢範囲 |
| 3 | 職業 | 入力 | String | いいえ | - | 最大255文字 | 職業・役職 |
| 4 | ニーズ | 入力 | String | はい | - | 最大2000文字 | 必要性・要望 |
| 5 | 利用状況 | 入力 | String | いいえ | - | 最大1000文字 | 利用シーン・頻度 |
| 6 | 前提条件 | 入力 | String | いいえ | - | 最大1000文字 | 前提となる条件 |
| 7 | 根拠 | 入力 | String | いいえ | - | 最大1000文字 | ペルソナ作成の根拠 |
| 8 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | ペルソナ総数を表示 | ペルソナ名 |
| 2 | 検索・フィルター | 検索 | 検索キーワード |
| 3 | メインコンテンツ | ペルソナ一覧表または詳細情報を表示・編集 | ペルソナ名、年齢層、職業、ニーズ、利用状況、前提条件、根拠 |

## 制約事項

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
