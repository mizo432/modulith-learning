# ペルソナ管理

ペルソナ管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-005 |
| 画面名           | ペルソナ管理 |
| 説明             | ユーザー像、ニーズ、前提、根拠を整理する |
| 関連ユースケース | UC-DIS-017, UC-DIS-018 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | ペルソナ総数を表示 |
| 検索・フィルター | 検索・絞り込み |
| メインコンテンツ | ペルソナ一覧表または詳細情報を表示・編集 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ペルソナ名 | 文字列 | はい | ペルソナの名前 |
| 2 | ユーザー像 | テキスト | はい | ユーザーの詳細な像 |
| 3 | ニーズ | テキスト | いいえ | ユーザーのニーズ |
| 4 | 利用状況 | テキスト | いいえ | 利用状況 |
| 5 | 検索キーワード | 文字列 | いいえ | 検索キーワード |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ペルソナを作成 | 新しいペルソナを作成する |
| 2 | ペルソナを更新 | 既存のペルソナを修正する |
| 3 | 検索 | 条件に合致するペルソナを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ペルソナの編集はプロダクトオーナーとUX担当のみ可能 |
| 2 | 参照権限 | ペルソナの参照は全チームメンバー |
