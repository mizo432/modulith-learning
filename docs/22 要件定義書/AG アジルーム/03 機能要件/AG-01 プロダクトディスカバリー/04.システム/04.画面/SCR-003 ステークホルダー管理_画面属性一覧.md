# 画面属性一覧

ステークホルダー管理の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-003 |
| 画面名 | ステークホルダー管理 |
| 説明 | 関係者、所属組織、関心、要望、参加状況を管理する |
| 関連ユースケース | UC-DIS-014, UC-DIS-015, UC-DIS-016 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ステークホルダー名 | 入力 | String | はい | - | 最大255文字 | 関係者の名前 |
| 2 | 所属組織 | 入力 | String | はい | - | 最大255文字 | 所属する組織名 |
| 3 | 役職 | 入力 | String | いいえ | - | 最大255文字 | 役職名 |
| 4 | 関心事 | 入力 | String | はい | - | 最大1000文字 | 関心のある事項 |
| 5 | 影響範囲 | 入力 | String | いいえ | - | 最大500文字 | 影響を受ける範囲 |
| 6 | 連絡方法 | 入力 | String | いいえ | - | 最大255文字 | 連絡先情報 |
| 7 | 参加状況 | 表示 | Enum | はい | - | 積極的/受動的/不参加 | プロジェクトへの参加度 |
| 8 | 要望 | リンク | String | いいえ | - | - | 関連する要望一覧 |
| 9 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 10 | 組織フィルター | 選択 | String | いいえ | すべて | - | 組織で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | ステークホルダー総数、参加状況集計を表示 | ステークホルダー名 |
| 2 | 検索・フィルター | 検索・絞り込み | 検索キーワード、組織フィルター |
| 3 | メインコンテンツ | ステークホルダー一覧表または詳細情報を表示・編集 | ステークホルダー名、所属組織、役職、関心事、影響範囲、連絡方法、参加状況 |
| 4 | 関連情報 | 関連する要望の一覧を表示 | 要望 |
