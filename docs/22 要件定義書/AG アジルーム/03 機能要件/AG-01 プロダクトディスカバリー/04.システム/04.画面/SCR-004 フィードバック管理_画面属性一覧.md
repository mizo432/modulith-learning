# 画面属性一覧

フィードバック管理の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-004 |
| 画面名 | フィードバック管理 |
| 説明 | 要望・意見・課題を記録し、評価・追跡する |
| 関連ユースケース | UC-DIS-007, UC-DIS-008, UC-DIS-009, UC-DIS-013, UC-DIS-022, UC-DIS-023, UC-DIS-024 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 課題名 | 入力 | String | はい | - | 最大255文字 | 課題の名前 |
| 2 | 課題詳細 | 入力 | String | はい | - | 最大2000文字 | 課題の詳細説明 |
| 3 | 影響範囲 | 入力 | String | いいえ | - | 最大500文字 | 影響を受ける範囲 |
| 4 | 状態 | 表示 | Enum | はい | - | 新規/調査中/対応済み/見送り | 課題の進捗状態 |
| 5 | 要望名 | 入力 | String | はい | - | 最大255文字 | 要望の名前 |
| 6 | 要望詳細 | 入力 | String | はい | - | 最大2000文字 | 要望の詳細説明 |
| 7 | 提出者 | 入力 | String | はい | - | 最大255文字 | 要望を提出した人 |
| 8 | Kano分類 | 表示 | Enum | いいえ | - | 当たり前/一元/魅力的/無関心/逆 | Kano評価結果 |
| 9 | Kano質問票 | リンク | String | いいえ | - | - | 関連するKano質問票 |
| 10 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 11 | 状態フィルター | 選択 | Enum | いいえ | すべて | - | 状態で絞り込む |
| 12 | 種類フィルター | 選択 | Enum | いいえ | すべて | - | 課題/要望で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | 課題・要望総数、状態別集計を表示 | 課題名、要望名 |
| 2 | 検索・フィルター | 検索・絞り込み | 検索キーワード、状態フィルター、種類フィルター |
| 3 | メインコンテンツ | 課題・要望一覧表または詳細情報を表示・編集 | 課題名、課題詳細、影響範囲、状態、要望名、要望詳細、提出者、Kano分類 |
| 4 | 関連情報 | Kano質問票・評価結果の一覧を表示 | Kano質問票、Kano分類 |
