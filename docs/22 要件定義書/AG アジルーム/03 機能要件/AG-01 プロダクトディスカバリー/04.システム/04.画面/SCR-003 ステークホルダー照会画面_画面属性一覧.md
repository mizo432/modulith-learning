# 画面属性一覧

ステークホルダー照会画面の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-003 |
| 画面名 | ステークホルダー照会画面 |
| 説明 | ステークホルダーの一覧参照・詳細参照を行う画面 |
| 関連ユースケース | UC-DIS-04 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 名前 | 表示 | String | 必須 | - | 最大100文字 | ステークホルダーの名前 |
| 2 | 組織 | 表示 | String | 任意 | - | 最大200文字 | 所属組織 |
| 3 | 関心事 | 表示 | String | 任意 | - | 最大500文字 | 関心事 |
| 4 | 影響範囲 | 表示 | String | 任意 | - | 最大200文字 | 影響範囲 |
| 5 | 連絡方法 | 表示 | String | 任意 | - | 最大200文字 | 連絡方法 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

| 2 | 詳細領域 | ステークホルダー詳細 | 名前、組織、関心事、影響範囲、連絡方法 |
