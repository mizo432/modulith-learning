# 画面属性一覧

プロダクトビジョン・目標の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-002 |
| 画面名 | プロダクトビジョン・目標 |
| 説明 | ビジョン、Product Goal、成功指標、仮説を管理する |
| 関連ユースケース | UC-DIS-001, UC-DIS-002, UC-DIS-003, UC-DIS-004, UC-DIS-005, UC-DIS-006, UC-DIS-010, UC-DIS-011, UC-DIS-012, UC-DIS-020, UC-DIS-021, UC-DIS-025, UC-DIS-026 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Product Vision | 入力 | String | はい | - | 最大2000文字 | プロダクトの対象者、課題、目指す将来像 |
| 2 | 対象者 | 入力 | String | はい | - | 最大500文字 | プロダクトの利用者層 |
| 3 | 課題 | 入力 | String | はい | - | 最大1000文字 | 解決する課題 |
| 4 | 目指す将来像 | 入力 | String | はい | - | 最大1000文字 | 実現したい将来の姿 |
| 5 | Product Goal | 入力 | String | はい | - | 最大2000文字 | プロダクト目標 |
| 6 | 期間 | 入力 | Date | はい | - | - | 目標達成期間 |
| 7 | 状態 | 表示 | Enum | はい | - | 未着手/進行中/完了/見送り | Product Goalの進捗状態 |
| 8 | 成功指標 | リンク | String | いいえ | - | - | 関連する成功指標一覧 |
| 9 | 仮説 | リンク | String | いいえ | - | - | 関連する仮説一覧 |
| 10 | 実験計画 | リンク | String | いいえ | - | - | 関連する実験計画一覧 |
| 11 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 12 | 状態フィルター | 選択 | Enum | いいえ | すべて | - | 状態で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
