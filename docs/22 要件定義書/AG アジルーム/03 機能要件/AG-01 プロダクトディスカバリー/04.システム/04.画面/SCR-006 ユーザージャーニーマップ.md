# ユーザージャーニーマップ

ユーザージャーニーマップ画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-006 |
| 画面名           | ユーザージャーニーマップ |
| 説明             | フェーズ、行動、タッチポイント、ペイン、機会を可視化する |
| 関連ユースケース | UC-DIS-019 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、ジャーニー総数、最終更新日を表示 |
| ナビゲーション | ジャーニー一覧、新規作成、編集の切り替え |
| メインコンテンツ | タイムライン形式でフェーズごとの行動・感情・機会を表示 |
| サイドバー | 関連ペルソナ、関連情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ジャーニー名 | 文字列 | はい | ユーザージャーニーの名前 |
| 2 | 関連ペルソナ | 選択 | はい | 関連するペルソナ |
| 3 | 目標 | テキスト | いいえ | ユーザーが達成したい目標 |
| 4 | フェーズ名 | 文字列 | はい | ジャーニーのフェーズ名 |
| 5 | 行動 | テキスト | はい | そのフェーズでのユーザーの行動 |
| 6 | タッチポイント | テキスト | いいえ | システムと接するポイント |
| 7 | 思考 | テキスト | いいえ | ユーザーの思考や疑問 |
| 8 | 感情 | 選択 | いいえ | 感情の起伏（高、中、低） |
| 9 | ペインポイント | テキスト | いいえ | 課題や不満点 |
| 10 | 機会 | テキスト | いいえ | 改善の機会 |
| 11 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ユーザージャーニーを作成 | 新規のジャーニーマップを定義する |
| 2 | フェーズを追加 | 新しいフェーズを追加する |
| 3 | フェーズを編集 | 既存のフェーズを修正する |
| 4 | フェーズを削除 | フェーズを削除する |
| 5 | ジャーニーを参照 | 登録されたジャーニーを確認する |
| 6 | エクスポート | ジャーニーマップを画像としてエクスポートする |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ジャーニーマップの編集はプロダクトオーナーのみ可能 |
| 2 | フェーズの順序 | フェーズはドラッグ＆ドロップで順序を変更可能 |
