# ステークホルダー管理

ステークホルダー管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-003 |
| 画面名           | ステークホルダー管理 |
| 説明             | 関係者、所属組織、関心、要望、参加状況を管理する |
| 関連ユースケース | UC-DIS-014, UC-DIS-015, UC-DIS-016 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、ステークホルダー総数、最終更新日を表示 |
| 検索・フィルター | 名前、組織、関心度で検索・絞り込み |
| メインコンテンツ | ステークホルダー一覧表または詳細情報を表示 |
| サイドバー | 組織別集計、関心度分布を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 名前 | 文字列 | はい | ステークホルダーの名前 |
| 2 | 所属組織 | 文字列 | いいえ | 所属する組織や部署 |
| 3 | 役職 | 文字列 | いいえ | 役職または役割 |
| 4 | 連絡先 | 文字列 | いいえ | メールアドレスや電話番号 |
| 5 | 関心事 | テキスト | いいえ | 関心を持っている事項 |
| 6 | 影響範囲 | 選択 | いいえ | プロダクトへの影響度（高、中、低） |
| 7 | 関心度 | 選択 | いいえ | プロダクトへの関心度（高、中、低） |
| 8 | 参加状況 | テキスト | いいえ | 会議やレビューへの参加状況 |
| 9 | 要望 | テキスト | いいえ | 提出した要望や意見 |
| 10 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ステークホルダーを登録 | 新規のステークホルダー情報を登録する |
| 2 | ステークホルダーを更新 | 既存のステークホルダー情報を修正する |
| 3 | ステークホルダーを参照 | 登録されたステークホルダーの一覧・詳細を確認する |
| 4 | 検索 | 条件に合致するステークホルダーを検索する |
| 5 | エクスポート | ステークホルダー一覧をエクスポートする |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ステークホルダー情報の編集はプロダクトオーナーのみ可能 |
| 2 | 重複チェック | 同じ名前と組織の組み合わせは重複登録できない |
