# イベント属性一覧

Product Visionが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-002 |
| イベント名 | Product Visionが更新された |
| 説明 | 既存のProduct Visionが修正・更新された |
| 関連ユースケース | UC-DIS-002 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | productVisionId | String | はい | - | 最大255文字 | Product VisionのID |
| 2 | 対象者 | String | はい | - | 最大500文字 | プロダクトの利用者層 |
| 3 | 課題 | String | はい | - | 最大1000文字 | 解決する課題 |
| 4 | 目指す将来像 | String | はい | - | 最大1000文字 | 実現したい将来の姿 |
| 5 | 更新日時 | DateTime | はい | - | - | 更新された日時 |
| 6 | 更新者 | String | はい | - | 最大255文字 | 更新者の名前 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Product Vision更新完了 | システム内部 | Product Visionが更新されたとき | Product Visionの更新が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
