イベント属性の一覧を定義します。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-007 |
| イベント名 | 仮説が作成された |
| 説明 | 課題に対する検証可能な仮説と検証方法が定義された |
| 関連ユースケース | UC-DIS-010 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 仮説名 | String | はい | - | 最大500文字 | 仮説の名前 |
| 4 | 仮説内容 | String | はい | - | 最大2000文字 | 仮説の詳細内容 |
| 5 | 検証方法 | String | はい | - | 最大1000文字 | 仮説の検証方法 |
| 6 | 関連課題 | String | いいえ | - | - | 関連する課題 |
| 7 | 作成者 | String | はい | - | - | 仮説を作成したユーザー |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 仮説作成完了 | システム内部 | 仮説が保存された | 仮説が新規作成された |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
