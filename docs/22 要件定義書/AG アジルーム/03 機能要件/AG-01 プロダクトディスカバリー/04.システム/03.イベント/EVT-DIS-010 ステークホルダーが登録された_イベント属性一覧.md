# ステークホルダーが登録された

イベント属性の一覧を定義します。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-010 |
| イベント名 | ステークホルダーが登録された |
| 説明 | 関係者、関心事、影響範囲、連絡方法が整理された |
| 関連ユースケース | UC-DIS-014 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | ステークホルダー名 | String | はい | - | 最大500文字 | ステークホルダーの名前 |
| 4 | 所属組織 | String | いいえ | - | 最大200文字 | 所属する組織 |
| 5 | 関心事 | String | いいえ | - | 最大1000文字 | 関心事項 |
| 6 | 影響範囲 | String | いいえ | - | 最大1000文字 | 影響を受ける範囲 |
| 7 | 連絡方法 | String | いいえ | - | 最大200文字 | 連絡手段 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | ステークホルダー登録完了 | システム内部 | ステークホルダーが保存された | ステークホルダーが新規登録された |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
