# ステークホルダーが登録された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-010 |
| イベント名 | ステークホルダーが登録された |
| 説明 | 関係者、関心事、影響範囲、連絡方法が整理された |
| 関連ユースケース | UC-DIS-014 |
| 関連情報 | INF-DIS-06 |
| 集約 | ステークホルダー |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 名前 | 文字列 | はい | ステークホルダーの名前 |
| 所属組織 | 文字列 | いいえ | 所属する組織や部署 |
| 関心事 | テキスト | いいえ | 関心を持っている事項 |
| 影響範囲 | 選択 | いいえ | プロダクトへの影響度 |
