# 仮説が更新された

イベント属性の一覧を定義します。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-008 |
| イベント名 | 仮説が更新された |
| 説明 | 仮説の検証方法・結果・学びが修正された |
| 関連ユースケース | UC-DIS-011 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |

| 1 | ID | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 仮説ID | String | はい | - | 一意 | 更新された仮説のID |
| 4 | 仮説名 | String | いいえ | - | 最大500文字 | 仮説の名前 |
| 5 | 仮説内容 | String | いいえ | - | 最大2000文字 | 仮説の詳細内容 |
| 6 | 検証方法 | String | いいえ | - | 最大1000文字 | 仮説の検証方法 |
| 7 | 検証結果 | String | いいえ | - | 最大1000文字 | 仮説の検証結果 |
| 8 | 学び | String | いいえ | - | 最大1000文字 | 検証から得られた学び |
| 9 | 状態 | Enum | いいえ | - | 新規, 検証中, 検証完了, 棄却 | 仮説の進捗状態 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
