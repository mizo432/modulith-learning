# 要望が登録された

イベント属性の一覧を定義します。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-009 |
| イベント名 | 要望が登録された |
| 説明 | 顧客や利用者から受けた意見・要望が記録された |
| 関連ユースケース | UC-DIS-013 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 要望名 | String | はい | - | 最大500文字 | 要望の名前 |
| 4 | 説明 | String | いいえ | - | 最大2000文字 | 要望の詳細説明 |
| 5 | 提出者 | String | はい | - | - | 要望を提出したユーザー |
| 6 | 優先度 | Enum | はい | 通常 | 高, 通常, 低 | 要望の優先度 |
| 7 | カテゴリ | String | いいえ | - | 最大100文字 | 要望のカテゴリ |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 要望登録完了 | システム内部 | 要望が保存された | 要望が新規登録された |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
