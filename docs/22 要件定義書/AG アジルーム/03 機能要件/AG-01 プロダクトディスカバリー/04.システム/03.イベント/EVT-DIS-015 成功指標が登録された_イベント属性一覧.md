# 成功指標が登録された

イベント属性の一覧を定義します。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-015 |
| イベント名 | 成功指標が登録された |
| 説明 | 指標の定義、基準値、目標値、データ元、更新頻度が設定された |
| 関連ユースケース | UC-DIS-020 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 指標名 | String | はい | - | 最大500文字 | 成功指標の名前 |
| 4 | 定義 | String | はい | - | 最大2000文字 | 指標の定義 |
| 5 | 基準値 | Double | いいえ | - | - | 基準値 |
| 6 | 目標値 | Double | いいえ | - | - | 目標値 |
| 7 | データ元 | String | いいえ | - | 最大200文字 | データのソース |
| 8 | 更新頻度 | Enum | いいえ | 手動 | 手動, 日次, 週次, 月次 | 更新頻度 |
| 9 | 登録者 | String | はい | - | - | 指標を登録したユーザー |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 成功指標登録完了 | システム内部 | 成功指標が保存された | 成功指標が新規登録された |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
