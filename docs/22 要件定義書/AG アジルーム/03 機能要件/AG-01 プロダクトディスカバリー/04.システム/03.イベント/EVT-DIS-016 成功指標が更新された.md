# 成功指標が更新された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-016 |
| イベント名 | 成功指標が更新された |
| 説明 | 既存の成功指標の値・目標値が修正された |
| 関連ユースケース | UC-DIS-021 |
| 関連情報 | INF-DIS-09 |
| 集約 | 成功指標 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 指標名 | 文字列 | はい | 指標の名前 |
| 基準値 | 数値 | いいえ | 現在の基準値 |
| 目標値 | 数値 | いいえ | 達成したい目標値 |
| データ元 | 文字列 | いいえ | 指標のデータソース |
