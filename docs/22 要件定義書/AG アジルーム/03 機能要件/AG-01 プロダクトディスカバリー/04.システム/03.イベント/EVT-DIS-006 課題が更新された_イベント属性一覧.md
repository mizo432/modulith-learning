# 課題が更新された

イベント属性の一覧を定義します。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-006 |
| イベント名 | 課題が更新された |
| 説明 | 既存の課題の詳細・影響・状態が修正された |
| 関連ユースケース | UC-DIS-008 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 課題ID | String | はい | - | 一意 | 更新された課題のID |
| 4 | 課題名 | String | いいえ | - | 最大500文字 | 課題の名前 |
| 5 | 説明 | String | いいえ | - | 最大2000文字 | 課題の詳細説明 |
| 6 | 影響範囲 | String | いいえ | - | 最大1000文字 | 影響を受ける範囲 |
| 7 | 緊急度 | Enum | いいえ | - | 緊急, 高, 通常, 低 | 課題の緊急度 |
| 8 | 状態 | Enum | いいえ | - | 新規, 進行中, 完了, 中止 | 課題の進捗状態 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
