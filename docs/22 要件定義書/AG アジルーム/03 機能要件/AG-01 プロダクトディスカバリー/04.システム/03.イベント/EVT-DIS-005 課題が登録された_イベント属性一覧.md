# 課題が登録された

イベント属性の一覧を定義します。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-DIS-005 |
| イベント名 | 課題が登録された |
| 説明 | 業務上の困りごとや繰り返し発生する問題が記録された |
| 関連ユースケース | UC-DIS-007 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 課題名 | String | はい | - | 最大500文字 | 課題の名前 |
| 4 | 説明 | String | いいえ | - | 最大2000文字 | 課題の詳細説明 |
| 5 | 影響範囲 | String | いいえ | - | 最大1000文字 | 影響を受ける範囲 |
| 6 | 緊急度 | Enum | はい | 通常 | 緊急, 高, 通常, 低 | 課題の緊急度 |
| 7 | 提出者 | String | はい | - | - | 課題を提出したユーザー |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 課題登録完了 | システム内部 | 課題が保存された | 課題が新規登録された |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
