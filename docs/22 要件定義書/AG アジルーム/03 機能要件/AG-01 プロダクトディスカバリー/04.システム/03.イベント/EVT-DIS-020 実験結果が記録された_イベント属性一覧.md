| 項目 | 内容 |
|------|------|

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|

| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 実験ID | String | はい | - | 一意 | 記録された実験結果のID |

| 5 | 学び | String | いいえ | - | 最大1000文字 | 得られた学び |
| 6 | 結論 | Enum | いいえ | - | 支持, 棄却, 不確定 | 実験の結論 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
