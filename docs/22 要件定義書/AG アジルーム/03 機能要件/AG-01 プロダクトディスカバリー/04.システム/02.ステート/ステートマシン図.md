# ステートマシン図

プロダクトディスカバリー業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、AG-01 プロダクトディスカバリー業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図（英語版）

```plantuml
@startuml
title Product Discovery State Model Diagram
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

' Product Goal states
state "Draft" as Draft_PG <<entry>>
state "Active" as Active_PG
state "Achieved" as Achieved_PG <<exit>>
state "Abandoned" as Abandoned_PG <<exit>>

' Issue/Request states
state "New" as New_ISS <<entry>>
state "Organizing" as Organizing_ISS
state "Addressed" as Addressed_ISS <<exit>>
state "Rejected" as Rejected_ISS <<exit>>

' Hypothesis states
state "Planned" as Planned_HP <<entry>>
state "Verifying" as Verifying_HP
state "Verified" as Verified_HP <<exit>>

' Product Goal transitions
Draft_PG --> Active_PG : Product Goal Updated (UC-DIS-005)
Active_PG --> Achieved_PG : Product Goal Updated (UC-DIS-005)
Active_PG --> Abandoned_PG : Product Goal Updated (UC-DIS-005)

' Issue/Request transitions
New_ISS --> Organizing_ISS : Issue Updated (UC-DIS-008)
Organizing_ISS --> New_ISS : Issue Updated (UC-DIS-008)
Organizing_ISS --> Addressed_ISS : Issue Updated (UC-DIS-008)
Organizing_ISS --> Rejected_ISS : Issue Updated (UC-DIS-008)

' Hypothesis transitions
Planned_HP --> Verifying_HP : Hypothesis Updated (UC-DIS-011)
Verifying_HP --> Verified_HP : Hypothesis Updated (UC-DIS-011)
@enduml
```

## 4. 状態一覧

| 状態名 (ID)       | 英語名        | 対象情報     | 説明                                     |
|-------------------|---------------|--------------|------------------------------------------|
| 草案 (ST-DIS-01)  | Draft         | Product Goal | 目標が作成されたが、まだ確定されていない |
| 有効 (ST-DIS-02)  | Active        | Product Goal | 目標が確定され、現在有効な状態           |
| 達成済み (ST-DIS-03) | Achieved  | Product Goal | 目標が達成された状態                     |
| 見送り (ST-DIS-04) | Abandoned   | Product Goal | 目標が達成されずに終了した状態           |
| 新規 (ST-DIS-05)  | New           | 課題・要望   | 登録されたが、まだ整理されていない       |
| 整理中 (ST-DIS-06) | Organizing  | 課題・要望   | POが背景・影響を整理中                   |
| 対応済み (ST-DIS-07) | Addressed | 課題・要望   | バックログ項目に変換された               |
| 却下 (ST-DIS-08)  | Rejected      | 課題・要望   | 対応しないことが決定された               |
| 検証予定 (ST-DIS-09) | Planned   | 仮説         | 仮説が作成され、検証計画が立てられた     |
| 検証中 (ST-DIS-10) | Verifying   | 仮説         | 検証が進行中                             |
| 検証済み (ST-DIS-11) | Verified  | 仮説         | 検証が完了し、結果が記録された           |
