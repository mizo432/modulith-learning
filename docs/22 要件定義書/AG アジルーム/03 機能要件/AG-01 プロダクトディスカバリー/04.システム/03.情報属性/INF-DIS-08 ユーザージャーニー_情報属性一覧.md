# 情報属性一覧

ユーザージャーニーの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-08 |
| 情報名 | ユーザージャーニー |
| 情報種類 | リソース |
| 説明 | 利用者の行動、課題、感情、機会 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | ジャーニー名 | | String | 必須 | ユーザージャーニーの名前 |
| 3 | 行動 | | String | 任意 | 利用者の行動 |
| 4 | 課題 | | String | 任意 | 利用者の課題 |
| 5 | 感情 | | String | 任意 | 利用者の感情 |
| 6 | 機会 | | String | 任意 | 改善の機会 |
| 7 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 8 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのユーザージャーニーは1つの利用者体験の流れとして1つのもの |
| 同一性 (Sameness) | idが同じであれば同じユーザージャーニー |
| カテゴリ (Category) | 利用者の体験を可視化する情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 下書き | 作成中の状態 | - | 確定 | UC-DIS-019 |
| 確定 | 確定された状態 | 下書き | 更新中 | UC-DIS-019 |
| 更新中 | 更新中の状態 | 確定 | 確定 | UC-DIS-019 |
