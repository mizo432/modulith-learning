# 情報属性一覧

課題の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-03 |
| 情報名 | 課題 |
| 情報種類 | リソース |
| 説明 | 業務上の困りごとや繰り返し発生する問題 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 課題名 | | String | 必須 | 課題の名前 |
| 3 | 詳細 | | String | 任意 | 課題の詳細説明 |
| 4 | 影響度 | | Enum | 任意 | 課題の影響度 |
| 5 | 状態 | | Enum | 必須 | 課題の状態 |
| 6 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 7 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの課題は1つの業務上の困りごととして1つのもの |
| 同一性 (Sameness) | idが同じであれば同じ課題 |
| カテゴリ (Category) | 業務上の課題を記録する情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 新規 | 登録された状態 | - | 調査中 | UC-DIS-007 |
| 調査中 | 調査中の状態 | 新規 | 解決, 却下 | UC-DIS-008 |
| 解決 | 解決された状態 | 調査中 | - | UC-DIS-008 |
| 却下 | 却下された状態 | 調査中 | - | UC-DIS-008 |
