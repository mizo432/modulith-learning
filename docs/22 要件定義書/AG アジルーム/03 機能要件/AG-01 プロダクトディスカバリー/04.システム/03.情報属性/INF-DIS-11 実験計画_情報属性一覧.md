# 情報属性一覧

実験計画の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-11 |
| 情報名 | 実験計画 |
| 情報種類 | リソース |
| 説明 | 実験計画、結果、学び |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 実験名 | | String | 必須 | 実験の名前 |
| 3 | 計画内容 | | String | 任意 | 実験の計画内容 |
| 4 | 結果 | | String | 任意 | 実験の結果 |
| 5 | 学び | | String | 任意 | 実験から得られた学び |
| 6 | 状態 | | Enum | 必須 | 実験の状態 |
| 7 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 8 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの実験計画は1つの実験として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じ実験計画 |
| カテゴリ (Category) | 仮説を検証する実験を記録する情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 計画済み | 計画が作成された状態 | - | 実行中 | UC-DIS-025 |
| 実行中 | 実行中の状態 | 計画済み | 完了 | UC-DIS-026 |
| 完了 | 完了した状態 | 実行中 | - | UC-DIS-026 |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-DIS-05 | 仮説 | 多対1 | 実験計画は1つの仮説に関連する |
| INF-DIS-02 | Product Goal | 多対1 | 実験計画は1つのProduct Goalに関連する |
