# 情報属性一覧

仮説の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-05 |
| 情報名 | 仮説 |
| 情報種類 | リソース |
| 説明 | 課題に対する検証可能な仮説 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 仮説名 | | String | 必須 | 仮説の名前 |
| 3 | 検証方法 | | String | 任意 | 仮説の検証方法 |
| 4 | 結果 | | String | 任意 | 検証結果 |
| 5 | 学び | | String | 任意 | 検証から得られた学び |
| 6 | 状態 | | Enum | 必須 | 仮説の状態 |
| 7 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 8 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの仮説は1つの検証可能な主張として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じ仮説 |
| カテゴリ (Category) | 課題に対する仮説を記録する情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 新規 | 作成された状態 | - | 検証中 | UC-DIS-010 |
| 検証中 | 検証中の状態 | 新規 | 検証済み, 却下 | UC-DIS-011 |
| 検証済み | 検証が完了した状態 | 検証中 | - | UC-DIS-011 |
| 却下 | 却下された状態 | 検証中 | - | UC-DIS-011 |
