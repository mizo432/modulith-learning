# 情報属性一覧

ペルソナの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-07 |
| 情報名 | ペルソナ |
| 情報種類 | リソース |
| 説明 | ユーザー像、ニーズ、利用状況 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | ペルソナ名 | | String | 必須 | ペルソナの名前 |
| 3 | ユーザー像 | | String | 任意 | ユーザーの像 |
| 4 | ニーズ | | String | 任意 | ユーザーのニーズ |
| 5 | 利用状況 | | String | 任意 | 利用状況 |
| 6 | 前提 | | String | 任意 | 前提条件 |
| 7 | 根拠 | | String | 任意 | 根拠 |
| 8 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 9 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのペルソナは1つのユーザー像として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じペルソナ |
| カテゴリ (Category) | ユーザー像を定義する情報 |
