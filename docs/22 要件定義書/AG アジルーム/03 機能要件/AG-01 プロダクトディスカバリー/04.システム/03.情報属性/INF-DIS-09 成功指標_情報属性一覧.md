# 情報属性一覧

成功指標の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-09 |
| 情報名 | 成功指標 |
| 情報種類 | リソース |
| 説明 | 指標の定義、基準値、目標値 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 指標名 | | String | 必須 | 指標の名前 |
| 3 | 定義 | | String | 必須 | 指標の定義 |
| 4 | 基準値 | | Double | 任意 | 現在の基準値 |
| 5 | 目標値 | | Double | 任意 | 目標とする値 |
| 6 | データ元 | | String | 任意 | データの元となるソース |
| 7 | 更新頻度 | | Enum | 任意 | データの更新頻度 |
| 8 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 9 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの成功指標は1つの指標定義として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じ成功指標 |
| カテゴリ (Category) | プロダクトの成功を測定する指標情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 下書き | 作成中の状態 | - | 確定 | UC-DIS-020 |
| 確定 | 確定された状態 | 下書き | 更新中 | UC-DIS-021 |
| 更新中 | 更新中の状態 | 確定 | 確定 | UC-DIS-021 |
