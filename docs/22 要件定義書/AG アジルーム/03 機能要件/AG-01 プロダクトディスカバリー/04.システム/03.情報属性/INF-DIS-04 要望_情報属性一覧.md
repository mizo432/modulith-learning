# 情報属性一覧

要望の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-04 |
| 情報名 | 要望 |
| 情報種類 | リソース |
| 説明 | 顧客や利用者から受けた意見 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 要望名 | | String | 必須 | 要望の名前 |
| 3 | 詳細 | | String | 任意 | 要望の詳細説明 |
| 4 | 提出者 | | String | 任意 | 要望を提出した人 |
| 5 | 提出日時 | | DateTime | 必須 | 要望が提出された日時 |
| 6 | 状態 | | Enum | 必須 | 要望の状態 |
| 7 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 8 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの要望は1つの顧客意見として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じ要望 |
| カテゴリ (Category) | 顧客や利用者からの意見を記録する情報 |

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |

| 新規 | 登録された状態 | - | 検討中 | UC-DIS-013 |
| 検討中 | 検討中の状態 | 新規 | 採用, 却下 | UC-DIS-013 |
| 採用 | 採用された状態 | 検討中 | - | UC-DIS-013 |
