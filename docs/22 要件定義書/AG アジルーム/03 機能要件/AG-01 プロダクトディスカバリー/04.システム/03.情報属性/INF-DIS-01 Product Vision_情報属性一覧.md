# 情報属性一覧

Product Visionの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-01 |
| 情報名 | Product Vision |
| 情報種類 | リソース |
| 説明 | プロダクトの対象者、課題、目指す将来像 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 対象者 | | String | 必須 | プロダクトの対象となるユーザー層 |
| 3 | 課題 | | String | 必須 | 解決しようとする課題 |
| 4 | 目指す将来像 | | String | 必須 | プロダクトで実現したい将来の姿 |
| 5 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 6 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |
| 7 | 作成者 | | String | 任意 | 作成したユーザー |
| 8 | 更新者 | | String | 任意 | 最終更新したユーザー |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのProduct Visionは1つのプロダクトの対象者・課題・将来像の組み合わせとして1つのもの |
| 同一性 (Sameness) | idが同じであれば同じProduct Vision |
| カテゴリ (Category) | プロダクトの方向性を定義するビジョン情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 下書き | 作成中の状態 | - | 確定 | UC-DIS-001 |
| 確定 | 確定された状態 | 下書き | 更新中 | UC-DIS-002 |
| 更新中 | 更新中の状態 | 確定 | 確定 | UC-DIS-002 |

|------------|------------|------------|------|
