# 情報属性一覧

仮説と課題の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-13 |
| 情報名 | 仮説と課題 |
| 情報種類 | 対応表 |
| 説明 | 仮説と関連する課題の関連 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 仮説ID | | Long | 必須 | 関連する仮説のID |
| 3 | 課題ID | | Long | 必須 | 関連する課題のID |
| 4 | 作成日時 | | DateTime | 必須 | 作成された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの対応は1つの仮説と1つの課題の関連として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じ対応 |
| カテゴリ (Category) | 仮説と課題の関連を記録する対応表 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 関連済み | 関連が設定された状態 | - | - | UC-DIS-010 |
