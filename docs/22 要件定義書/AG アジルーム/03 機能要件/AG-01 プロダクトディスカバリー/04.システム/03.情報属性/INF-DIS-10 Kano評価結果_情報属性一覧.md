# 情報属性一覧

Kano評価結果の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-10 |
| 情報名 | Kano評価結果 |
| 情報種類 | リソース |
| 説明 | 要望のKano分類結果 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 要望ID | | Long | 必須 | 評価対象の要望ID |
| 3 | Kanoカテゴリ | | Enum | 必須 | Kano分類結果（当たり前、一元、魅力的、無関心、逆） |
| 4 | 評価日時 | | DateTime | 必須 | 評価が実行された日時 |
| 5 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 6 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのKano評価結果は1つの要望に対する評価結果として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じKano評価結果 |
| カテゴリ (Category) | 要望のKano分類結果を記録する情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 評価済み | 評価が完了した状態 | - | 更新済み | UC-DIS-023 |
| 更新済み | 評価が更新された状態 | 評価済み | - | UC-DIS-023 |
