# 情報属性一覧

Kanoカテゴリの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-14 |
| 情報名 | Kanoカテゴリ |
| 情報種類 | 対照表 |
| 説明 | 当たり前品質、一元品質、魅力的品質、無関心品質、逆品質 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | カテゴリコード | | String | 必須 | カテゴリのコード |
| 3 | カテゴリ名 | | String | 必須 | カテゴリの名前 |
| 4 | 説明 | | String | 任意 | カテゴリの説明 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのKanoカテゴリは1つの品質分類として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じKanoカテゴリ |
| カテゴリ (Category) | Kanoモデルの品質分類を定義する対照表 |
