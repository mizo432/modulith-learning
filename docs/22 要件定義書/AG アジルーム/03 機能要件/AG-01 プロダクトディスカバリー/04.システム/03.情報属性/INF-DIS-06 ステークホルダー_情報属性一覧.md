# 情報属性一覧

ステークホルダーの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-06 |
| 情報名 | ステークホルダー |
| 情報種類 | リソース |
| 説明 | 関係者、関心事、影響範囲 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 名前 | | String | 必須 | ステークホルダーの名前 |
| 3 | 所属組織 | | String | 任意 | 所属する組織 |
| 4 | 関心事 | | String | 任意 | 関心を持っている事項 |
| 5 | 影響範囲 | | String | 任意 | 影響を受ける範囲 |
| 6 | 連絡方法 | | String | 任意 | 連絡先の情報 |
| 7 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 8 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのステークホルダーは1つの関係者として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じステークホルダー |
| カテゴリ (Category) | プロダクトの関係者を記録する情報 |
