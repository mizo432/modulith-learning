# 情報属性一覧

Product Goalの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-DIS-02 |
| 情報名 | Product Goal |
| 情報種類 | リソース |
| 説明 | プロダクト目標、期間、状態 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 一意の識別子 |
| 2 | 目標名 | | String | 必須 | プロダクト目標の名前 |
| 3 | 目標説明 | | String | 必須 | プロダクト目標の詳細説明 |
| 4 | 開始期間 | | Date | 必須 | 目標の開始期間 |
| 5 | 終了期間 | | Date | 必須 | 目標の終了期間 |
| 6 | 状態 | | Enum | 必須 | 目標の状態（未着手、進行中、完了、キャンセル） |
| 7 | 作成日時 | | DateTime | 必須 | 作成された日時 |
| 8 | 更新日時 | | DateTime | 必須 | 最終更新された日時 |
| 9 | 作成者 | | String | 任意 | 作成したユーザー |
| 10 | 更新者 | | String | 任意 | 最終更新したユーザー |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのProduct Goalは1つのプロダクト目標として1つのもの |
| 同一性 (Sameness) | idが同じであれば同じProduct Goal |
| カテゴリ (Category) | プロダクトの目標を定義する情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未着手 | 目標が設定された状態 | - | 進行中 | UC-DIS-004 |
| 進行中 | 目標が進行中の状態 | 未着手 | 完了, キャンセル | UC-DIS-005 |
| 完了 | 目標が達成された状態 | 進行中 | - | UC-DIS-005 |
| キャンセル | 目標がキャンセルされた状態 | 進行中 | - | UC-DIS-005 |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-DIS-01 | Product Vision | 多対1 | 複数のProduct Goalは1つのProduct Visionに属する |
| INF-DIS-12 | Product Goalと成功指標 | 1対多 | Product Goalは複数の成功指標と関連する |
