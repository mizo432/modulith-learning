# BUC-DIS-05 Kano評価による要望分類

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-DIS-05 |
| BUC名            | Kano評価による要望分類 |
| 説明             | 要望をKanoモデルで評価・分類し、優先順位付けの根拠とする |
| 関連業務         | プロダクトディスカバリー |
| 関連ユースケース | UC-DIS-022, UC-DIS-023, UC-DIS-024 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1 | ACT-01 | プロダクトオーナー | 価値受益アクター、要望の優先順位付け |
| 2 | ACT-02 | 従業員 | 価値提供アクター、Kano評価の実施 |
| 3 | ACT-05 | システム管理者 | 価値提供アクター、システム管理 |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1 | Kano質問票の作成 | 要望に対するKano質問票を作成する | プロダクトオーナー |
| 2 | Kano評価の実施 | 質問票に基づいて評価を実施する | 従業員 |
| 3 | 分類結果の記録 | 評価結果を分類して記録する | 従業員 |
| 4 | 分類結果の参照 | 分類結果を参照する | プロダクトオーナー |
