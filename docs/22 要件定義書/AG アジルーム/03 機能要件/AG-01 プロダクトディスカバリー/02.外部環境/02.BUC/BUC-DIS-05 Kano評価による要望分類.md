# BUC-DIS-05 Kano評価による要望分類

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-DIS-05 |
| BUC名            | Kano評価による要望分類 |
| 説明             | 要望をKanoモデルで評価・分類し、優先順位付けの根拠とする |
| 関連業務         | プロダクトディスカバリー |
| 関連ユースケース | UC-DIS-022, UC-DIS-023, UC-DIS-024 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-01     | 従業員     | Kano質問票に回答し、評価結果を確認する |
| 2    | ACT-02     | プロダクトオーナー（PO） | Kano質問票を作成し、評価を実施・結果を確認する |
| 3    | ACT-05     | トラッキング担当 | Kano評価結果を参照する |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | Kano質問票の作成 | 各要望について機能がある場合・ない場合の反応を対で定義する | ACT-02 |
| 2    | Kano評価の実施   | Kano質問票に基づいて回答を収集し、品質カテゴリに分類する | ACT-01, ACT-02 |
| 3    | Kano評価結果の参照 | 要望のKano分類結果を確認する | ACT-01, ACT-02, ACT-05 |

| 番号 | 制約事項 | 説明 |
