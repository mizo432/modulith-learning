# BUC-DIS-03 仮説作成・検証計画

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-DIS-03 |
| BUC名            | 仮説作成・検証計画 |
| 説明             | 課題に対する検証可能な仮説を作成し、検証計画を立てて実験を実施・結果を記録する |
| 関連業務         | プロダクトディスカバリー |
| 関連ユースケース | UC-DIS-010, UC-DIS-011, UC-DIS-012, UC-DIS-025, UC-DIS-026 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-01     | 従業員     | 仮説の内容を確認する |
| 2    | ACT-02     | プロダクトオーナー（PO） | 仮説を作成・更新し、検証計画を立てる |
| 3    | ACT-05     | トラッキング担当 | 仮説の進捗状況を確認する |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | 仮説の定義       | 課題に対する検証可能な仮説を定義する | ACT-02 |
| 2    | 検証方法の設定   | 仮説を検証するための方法を設定する | ACT-02 |
| 3    | 仮説の更新       | 仮説の検証方法・結果・学びを修正・更新する | ACT-02 |
| 4    | 仮説の参照       | 登録された仮説の一覧・詳細を確認する | ACT-01, ACT-02, ACT-05 |
| 5    | 実験計画の作成   | 実験計画、結果、学びを仮説や目標と関連づけて登録する | ACT-02 |
| 6    | 実験結果の記録   | 実験の実施結果と得られた学びを記録する | ACT-02 |
