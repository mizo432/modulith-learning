# 業務一覧

プロダクトディスカバリー業務領域（AG-01）の業務を定義します。

| ID        | 業務名                           | 概要                                                   | 主なアクター                   |
|-----------|----------------------------------|--------------------------------------------------------|--------------------------------|
| BUC-DIS-01 | 課題・要望の収集・整理           | 従業員やステークホルダーから課題・要望・機会を収集し、背景とともに整理する | ACT-01, ACT-02 |
| BUC-DIS-03 | 仮説作成・検証計画               | 課題に対する仮説を作成し、検証方法を計画する           | ACT-02                         |
| BUC-DIS-04 | ステークホルダー・ユーザー理解   | ステークホルダーやユーザーのニーズを理解し、整理する   | ACT-01, ACT-02                 |
| BUC-DIS-05 | Kano評価による要望分類           | 要望をKanoモデルで評価し、分類する                     | ACT-02                         |
