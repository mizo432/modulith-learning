# BUC-DIS-03 仮説作成・検証計画

## 概要

課題に対する仮説を作成し、検証方法を計画する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:収集した課題を確認する;
:課題の原因を分析する;
:仮説を作成する;

if (仮説が検証可能か?) then (いいえ)
  :仮説を再定義する;
  else (はい)
  :検証方法を計画する;
  :必要なリソースを特定する;
  :検証期間を設定する;
  :成功基準を定義する;
  endif

:検証計画を記録する;
:関係者に承認を求める;

if (承認されたか?) then (はい)
  :検証計画を実行待ちにする;
else (いいえ)
  :修正意见を反映する;
  :検証計画を再提出する;
  endif

stop
@enduml
```
