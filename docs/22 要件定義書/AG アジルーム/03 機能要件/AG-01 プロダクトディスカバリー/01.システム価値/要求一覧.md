# 要求一覧

初期要望から抽出した機能要求と非機能要求を定義します。

## 機能要求

| ID | 要求名 | 概要 | 優先度 |
|----|--------|------|--------|
| FR-AG-01 | プロダクトビジョン管理 | プロダクトの対象者、課題、目指す将来像を定義・更新・参照する | MVP |
| FR-AG-02 | プロダクトゴール管理 | プロダクト目標、期間、状態、関連指標を定義・更新・参照する | MVP |
| FR-AG-03 | 課題管理 | 業務上の困りごとや繰り返し発生する問題を記録・更新・参照する | MVP |
| FR-AG-04 | 仮説管理 | 課題に対する検証可能な仮説と検証方法を定義・更新・参照する | MVP |
| FR-AG-05 | 要望管理 | 顧客や利用者から受けた意見・要望を記録する | MVP |
| FR-AG-06 | ステークホルダー管理 | 関係者、関心事、影響範囲、連絡方法を整理して管理する | 次期 |
| FR-AG-07 | ペルソナ管理 | ユーザー像、ニーズ、利用状況を定義して管理する | 次期 |
| FR-AG-08 | ユーザージャーニー管理 | 利用者の行動、課題、感情、機会を可視化する | 次期 |
| FR-AG-09 | 成功指標管理 | 指標の定義、基準値、目標値、データ元、更新頻度を設定・更新する | 次期 |
| FR-AG-10 | Kano評価 | Kano質問票を作成し、回答を収集して品質カテゴリに分類する | 次期 |
| FR-AG-11 | 実験計画管理 | 実験計画、結果、学びを仮説や目標と関連づけて管理する | 拡張 |

## 非機能要求

| ID | 要求名 | 概要 |
|----|--------|------|
| NFR-AG-01 | 検索性能 | 大量のデータから迅速に検索できる |
| NFR-AG-02 | 可視化 | 情報を視覚的に表現できる |
| NFR-AG-03 | 関連付け | 情報間の関連を維持できる |
