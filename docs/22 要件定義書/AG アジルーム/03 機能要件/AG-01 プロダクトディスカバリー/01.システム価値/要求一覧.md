# 要求一覧

プロダクトディスカバリー業務領域（AG-01）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-DIS-01 | Product Vision管理           | プロダクトの対象者、課題、目指す将来像を定義・更新・参照する | MVP    |
| FR-DIS-02 | Product Goal管理             | プロダクト目標、期間、状態、関連指標を定義・更新・参照する   | MVP    |
| FR-DIS-03 | 課題管理                     | 業務上の困りごとや繰り返し発生する問題を記録・更新・参照する | MVP    |
| FR-DIS-04 | 仮説管理                     | 課題に対する検証可能な仮説と検証方法を定義・更新・参照する   | MVP    |
| FR-DIS-05 | 要望管理                     | 顧客や利用者から受けた意見・要望を記録する                 | MVP    |
| FR-DIS-06 | ステークホルダー管理         | 関係者、関心事、影響範囲、連絡方法を整理して管理する       | 次期   |
| FR-DIS-07 | ペルソナ管理                 | ユーザー像、ニーズ、利用状況を定義して管理する             | 次期   |
| FR-DIS-08 | ユーザージャーニー管理       | 利用者の行動、課題、感情、機会を可視化する                 | 次期   |
| FR-DIS-09 | 成功指標管理                 | 指標の定義、基準値、目標値、データ元、更新頻度を設定・更新する | 次期   |
| FR-DIS-10 | Kano評価                     | Kano質問票を作成し、回答を収集して品質カテゴリに分類する   | 次期   |
| FR-DIS-11 | 実験計画管理                 | 実験計画、結果、学びを仮説や目標と関連づけて管理する       | 拡張   |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-DIS-01 | 検索性能                       | 大量のデータから迅速に検索できる       |
| NFR-DIS-02 | 可視化                         | 情報を視覚的に表現できる               |
| NFR-DIS-03 | 関連付け                       | 情報間の関連を維持できる               |
