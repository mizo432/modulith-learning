# UC-BL-021 要求の関連を設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-021 |
| ユースケース名 | 要求の関連を設定する |
| 英語名 | Set Requirement Relationship |
| 説明 | 類似要求や関連する課題、機能、テストを関連づける |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-BL-06 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 関連設定対象のバックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 関連設定対象の項目を選択する
3. 「関連を設定」ボタンをクリックする
4. 関連する項目（要求、課題、機能、テスト）を選択する
5. 関連の種類（類似/参照/依存）を選択する
6. 設定を保存する
7. システムが項目関連付け（INF-BL-07）を登録する
8. 設定完了メッセージを表示する

## 代替フロー

- なし

## 後置条件

- 項目関連付け（INF-BL-07）がシステムに登録される
- イベント「EVT-BL-015 要求の関連が設定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 関連設定対象の情報 |
| INF-BL-07 | 項目関連付け | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-015 | 要求の関連が設定された | 基本フローステップ7完了後 |

| 番号 | 制約事項 | 説明 |
|------|----------|------|
