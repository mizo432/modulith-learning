# UC-BL-007 バックログ項目を作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-007 |
| ユースケース名 | バックログ項目を作成する |
| 英語名 | Create Backlog Item |
| 説明 | 課題や仮説をEpic・Feature・Storyに変換して登録する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-009（Epic Planningワークスペース） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「Epic Planningワークスペース」画面（SCR-009）にアクセスする
2. 「バックログ項目を作成」ボタンをクリックする
3. 項目種別（Epic/Feature/Story）、タイトル、説明、受入条件を入力する
4. 入力を保存する
5. システムがバックログ項目（INF-BL-01）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- バックログ項目（INF-BL-01）がシステムに登録される
- イベント「EVT-BL-005 バックログ項目が作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-005 | バックログ項目が作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 項目種別、タイトルは必須入力 |
| 2 | 文字数制限 | 説明は2000文字以内 |
