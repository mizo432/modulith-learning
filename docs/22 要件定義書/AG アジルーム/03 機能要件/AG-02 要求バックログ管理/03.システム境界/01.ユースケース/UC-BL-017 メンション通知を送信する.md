# UC-BL-017 メンション通知を送信する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-017 |
| ユースケース名 | メンション通知を送信する |
| 英語名 | Send Mention Notification |
| 説明 | 関係者に通知を送信する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-01 |
| 外部システム | - |
| 関連画面 | SCR-011（User Story詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「User Story詳細」画面（SCR-011）にアクセスする
2. コメント欄で@記号を入力する
3. 通知先のユーザーを選択する
4. コメント内容を入力する
5. 投稿ボタンをクリックする
6. システムがコメント（INF-BL-04）を登録し、通知を送信する
7. 送信完了メッセージを表示する

## 代替フロー

- **4a. 入力が空の場合**
  - コメント内容が空の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- コメント（INF-BL-04）がシステムに登録される
- 通知が選択されたユーザーに送信される
- イベント「EVT-BL-013 メンション通知が送信された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 通知対象の情報 |
| INF-BL-04 | コメント | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-013 | メンション通知が送信された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | コメント内容は必須入力 |
| 2 | 文字数制限 | コメントは2000文字以内 |
