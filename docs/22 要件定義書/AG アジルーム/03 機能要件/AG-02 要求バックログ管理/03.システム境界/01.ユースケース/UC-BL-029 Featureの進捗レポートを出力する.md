# UC-BL-029 Featureの進捗レポートを出力する

## 概要

Featureの進捗状況をレポートとして出力する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-029 |
| ユースケース名 | Featureの進捗レポートを出力する |
| 関連BUC | BUC-BL-07 |
| 関連アクター | ACT-02, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-BL-01 (バックログ項目), INF-BL-22 (Featureダッシュボード集計情報) |
| 関連画面 | SCR-012 (Featureダッシュボード画面) |

## 前提条件

- Featureダッシュボードが表示されていること
- 出力対象のFeatureが存在すること

## 基本フロー

1. アクターはレポート出力対象のFeatureを選択する
2. アクターはレポート形式を選択する（PDF、Excelなど）
3. システムはFeatureの進捗状況をレポートにまとめる
   - Featureの基本情報
   - 開発進捗（構成Storyの完了状況）
   - 価値の実現状況
   - 提供準備状況
   - 依存関係と阻害要因
   - リリース見通し
4. システムはレポートを出力する

## 結果

Featureの進捗状況がレポートとして出力される。
