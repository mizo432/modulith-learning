# UC-BL-014 業務ルールを登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-014 |
| ユースケース名 | 業務ルールを登録する |
| 英語名 | Register Business Rule |
| 説明 | 業務上の期待、例外、受入条件を項目に記録する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-011（User Story詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「User Story詳細」画面（SCR-011）にアクセスする
2. 業務ルールを登録する項目を選択する
3. 「業務ルールを登録」ボタンをクリックする
4. 業務ルールの内容、例外、受入条件を入力する
5. 入力を保存する
6. システムが業務ルール（INF-BL-01）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 業務ルール（INF-BL-01）がシステムに登録される
- イベント「EVT-BL-017 業務ルールが登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 業務ルール登録対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-017 | 業務ルールが登録された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 業務ルールの内容は必須入力 |
| 2 | 文字数制限 | 内容は2000文字以内 |
