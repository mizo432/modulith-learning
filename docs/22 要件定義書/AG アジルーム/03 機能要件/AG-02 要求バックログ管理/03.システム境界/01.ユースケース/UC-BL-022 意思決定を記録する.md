# UC-BL-022 意思決定を記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-022 |
| ユースケース名 | 意思決定を記録する |
| 英語名 | Record Decision |
| 説明 | 決定内容、根拠、決定者、影響範囲を記録する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「意思決定を記録」ボタンをクリックする
3. 決定内容、根拠、決定者、影響範囲を入力する
4. 入力を保存する
5. システムが意思決定（INF-BL-05）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 意思決定（INF-BL-05）がシステムに登録される
- イベント「EVT-BL-016 意思決定が記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-05 | 意思決定 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-016 | 意思決定が記録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 決定内容、根拠、決定者は必須入力 |
| 2 | 文字数制限 | 決定内容は2000文字以内 |
