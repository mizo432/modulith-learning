# UC-BL-004 フィードバックを登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-004 |
| ユースケース名 | フィードバックを登録する |
| 英語名 | Register Feedback |
| 説明 | 利用者からの意見・評価を分類して記録する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-05 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「フィードバックを登録」ボタンをクリックする
3. フィードバックの内容、分類、評価を入力する
4. 入力を保存する
5. システムがフィードバック（INF-BL-03）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- フィードバック（INF-BL-03）がシステムに登録される
- イベント「EVT-BL-003 フィードバックが登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-03 | フィードバック | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-003 | フィードバックが登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | フィードバック内容は必須入力 |
| 2 | 文字数制限 | 内容は2000文字以内 |
