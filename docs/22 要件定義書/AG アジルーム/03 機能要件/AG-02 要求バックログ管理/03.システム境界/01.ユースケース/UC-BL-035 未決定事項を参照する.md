# UC-BL-035 未決定事項を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-035 |
| ユースケース名 | 未決定事項を参照する |
| 英語名 | View Undecided Item |
| 説明 | 登録された未決定事項の一覧・詳細を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 未決定事項（INF-BL-25）が既に存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. システムが未決定事項の一覧を表示する
3. ユーザーが特定の未決定事項を選択する
4. システムが未決定事項の詳細を表示する
   - タイトル、カテゴリ、詳細
   - 状態（未決定、決定済み、却下）
   - 決定内容または却下理由（状態に応じて）
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 未決定事項の一覧・詳細がユーザーに表示される
