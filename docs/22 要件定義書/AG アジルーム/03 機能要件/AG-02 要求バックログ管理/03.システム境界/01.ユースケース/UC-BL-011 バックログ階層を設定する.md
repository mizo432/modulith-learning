# UC-BL-011 バックログ階層を設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-011 |
| ユースケース名 | バックログ階層を設定する |
| 英語名 | Set Backlog Hierarchy |
| 説明 | Product Goal、Epic、Feature、Story、Task間の関係を設定する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-008（Epic一覧・詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- 階層設定対象のバックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「Epic一覧・詳細」画面（SCR-008）にアクセスする
2. 階層設定対象の項目を選択する
3. 「階層を設定」ボタンをクリックする
4. 上位項目（Product Goal/Epic）と下位項目（Feature/Story/Task）を関連付ける
5. 設定を保存する
6. システムがバックログ階層（INF-BL-06）を登録する
7. 設定完了メッセージを表示する

## 代替フロー

- **4a. 循環参照を検出する場合**
  - 循環参照が検出された場合、エラーメッセージを表示する
  - ユーザーは関連付けを修正して再試行する

## 後置条件

- バックログ階層（INF-BL-06）がシステムに登録される
- イベント「EVT-BL-008 バックログ階層が設定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 階層設定対象の情報 |
| INF-BL-06 | バックログ階層 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-008 | バックログ階層が設定された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 循環参照禁止 | 循環する階層関係は設定できない |
| 2 | 階層深度 | 最大5階層まで（Product Goal > Epic > Feature > Story > Task） |
