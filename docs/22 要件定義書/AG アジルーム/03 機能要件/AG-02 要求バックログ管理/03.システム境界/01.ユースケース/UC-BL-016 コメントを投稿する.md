# UC-BL-016 コメントを投稿する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-016 |
| ユースケース名 | コメントを投稿する |
| 英語名 | Post Comment |
| 説明 | 項目上で質問、回答、議論を行う |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-01 |
| 外部システム | - |
| 関連画面 | SCR-011（User Story詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「User Story詳細」画面（SCR-011）にアクセスする
2. コメントを投稿する項目を選択する
3. 「コメントを投稿」ボタンをクリックする
4. コメント内容を入力する
5. 投稿ボタンをクリックする
6. システムがコメント（INF-BL-04）を登録する
7. 投稿完了メッセージを表示する

## 代替フロー

- **4a. 入力が空の場合**
  - コメント内容が空の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- コメント（INF-BL-04）がシステムに登録される
- イベント「EVT-BL-012 コメントが投稿された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | コメント投稿対象の情報 |
| INF-BL-04 | コメント | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-012 | コメントが投稿された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | コメント内容は必須入力 |
| 2 | 文字数制限 | コメントは2000文字以内 |
