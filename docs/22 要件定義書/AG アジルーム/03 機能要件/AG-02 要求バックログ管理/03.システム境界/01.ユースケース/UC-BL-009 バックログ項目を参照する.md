# UC-BL-009 バックログ項目を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-009 |
| ユースケース名 | バックログ項目を参照する |
| 英語名 | View Backlog Item |
| 説明 | 登録されたバックログ項目の一覧・詳細を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. システムがバックログ項目の一覧を表示する
3. ユーザーが特定のバックログ項目を選択する
4. システムがバックログ項目の詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- バックログ項目の一覧・詳細がユーザーに表示される
