# UC-BL-023 Story Mappingを行う

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-023 |
| ユースケース名 | Story Mappingを行う |
| 英語名 | Story Mapping |
| 説明 | ユーザー活動とストーリーを並べ、リリース範囲を検討する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-007（ユーザーストーリーマップ） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「ユーザーストーリーマップ」画面（SCR-007）にアクセスする
2. 「Story Mappingを開始」ボタンをクリックする
3. ユーザー活動（バックボーン）を定義する
4. ストーリーをユーザー活動に割り当てて並べる
5. リリース範囲（スライス）を設定する
6. 設定を保存する
7. システムがStory Mapping結果（INF-BL-01）を登録する
8. 完了メッセージを表示する

## 代替フロー

- **5a. リリース範囲を変更する場合**
  - ユーザーはスライスの境界をドラッグして調整する
  - システムが関連するストーリーを更新する

## 後置条件

- Story Mapping結果（INF-BL-01）がシステムに登録される
- イベント「EVT-BL-021 Story Mappingが完了した」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | Story Mapping対象の情報 |

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
