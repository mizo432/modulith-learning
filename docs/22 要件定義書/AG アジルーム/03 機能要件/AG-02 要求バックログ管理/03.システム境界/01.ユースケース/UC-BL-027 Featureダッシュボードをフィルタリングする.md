# UC-BL-027 Featureダッシュボードをフィルタリングする

## 概要

状態、優先順位、担当者などでFeatureを絞り込んで表示する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-027 |
| ユースケース名 | Featureダッシュボードをフィルタリングする |
| 関連BUC | BUC-BL-07 |
| 関連アクター | ACT-02, ACT-03, ACT-04, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-BL-01 (バックログ項目), INF-BL-10 (優先度), INF-BL-11 (状態) |
| 関連画面 | SCR-012 (Featureダッシュボード画面) |

## 前提条件

- Featureダッシュボードが表示されていること

## 基本フロー

1. アクターはフィルタ条件を入力する
   - 状態（準備中、開発中、検証中、提供準備完了、提供済み、保留中、取り消し）
   - 優先順位
   - 担当者
   - 期間
2. システムは条件に一致するFeatureを絞り込む
3. システムは絞り込んだFeatureの集計情報を更新して表示する

## 結果

条件に一致するFeatureのみがダッシュボードで表示される。
