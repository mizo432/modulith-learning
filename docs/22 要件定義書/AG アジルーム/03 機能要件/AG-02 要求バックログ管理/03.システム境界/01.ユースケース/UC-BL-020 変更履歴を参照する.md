# UC-BL-020 変更履歴を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-020 |
| ユースケース名 | 変更履歴を参照する |
| 英語名 | View Change History |
| 説明 | 要求、計画、テスト、リリースの関連と変更経緯を追跡する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-06 |
| 外部システム | ES-03（ソース管理システム） |
| 関連画面 | SCR-011（User Story詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「User Story詳細」画面（SCR-011）にアクセスする
2. 変更履歴を参照する項目を選択する
3. 「変更履歴」タブをクリックする
4. システムが変更履歴と関連するコミット・ブランチ・PR（ES-03）を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 変更履歴がユーザーに表示される
