# UC-BL-034 未決定事項を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-034 |
| ユースケース名 | 未決定事項を更新する |
| 英語名 | Update Undecided Item |
| 説明 | 未決定事項の状態を決定済みまたは却下到変更する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 未決定事項（INF-BL-25）が既に「未決定」状態で存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 対象の未決定事項を選択する
3. 状態を変更する
   - 「決定済み」に変更する場合（ST-BL-05）
     - 決定内容を記録する
   - 「却下」に変更する場合（ST-BL-06）
     - 却下理由を記録する
4. 変更を保存する
5. システムが未決定事項（INF-BL-25）の状態を更新する
6. 更新完了メッセージを表示する

## 代替フロー

- **3a. 許可されていない状態遷移を試みた場合**
  - 定義された状態遷移以外（COND-BL-10）の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 未決定事項（INF-BL-25）の状態が「決定済み」または「却下」に更新される

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 状態遷移の制約 | 未決定から決定済み、却下のみの遷移を許可（COND-BL-10） |
| 2 | 決定内容の記録 | 決定済みに遷移する場合は決定内容を記録する |
| 3 | 却下理由の記録 | 却下到遷移する場合は却下理由を記録する |
