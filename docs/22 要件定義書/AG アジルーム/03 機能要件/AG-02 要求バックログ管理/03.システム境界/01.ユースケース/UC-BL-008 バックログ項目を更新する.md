# UC-BL-008 バックログ項目を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-008 |
| ユースケース名 | バックログ項目を更新する |
| 英語名 | Update Backlog Item |
| 説明 | 項目の説明・受入条件・詳細を修正する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-011（User Story詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「User Story詳細」画面（SCR-011）にアクセスする
2. 既存のバックログ項目を選択する
3. 「編集」ボタンをクリックする
4. 説明、受入条件、詳細を修正する
5. 変更を保存する
6. システムがバックログ項目（INF-BL-01）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- バックログ項目（INF-BL-01）が更新される
- イベント「EVT-BL-006 バックログ項目が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-006 | バックログ項目が更新された | 基本フローステップ6完了後 |

## 制約事項
