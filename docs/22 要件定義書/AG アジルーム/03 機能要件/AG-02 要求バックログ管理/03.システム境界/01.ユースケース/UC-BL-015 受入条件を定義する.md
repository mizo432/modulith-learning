# UC-BL-015 受入条件を定義する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-015 |
| ユースケース名 | 受入条件を定義する |
| 英語名 | Define Acceptance Criteria |
| 説明 | 期待される振る舞いや境界条件を定義する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-011（User Story詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「User Story詳細」画面（SCR-011）にアクセスする
2. 受入条件を定義する項目を選択する
3. 「受入条件を定義」ボタンをクリックする
4. 期待される振る舞い、境界条件、テストケースを入力する
5. 入力を保存する
6. システムが受入条件（INF-BL-02）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 受入条件（INF-BL-02）がシステムに登録される
- イベント「EVT-BL-011 受入条件が定義された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 受入条件定義対象の情報 |
| INF-BL-02 | 受入条件 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-011 | 受入条件が定義された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 期待される振る舞いは必須入力 |
| 2 | 文字数制限 | 各条件は500文字以内 |
