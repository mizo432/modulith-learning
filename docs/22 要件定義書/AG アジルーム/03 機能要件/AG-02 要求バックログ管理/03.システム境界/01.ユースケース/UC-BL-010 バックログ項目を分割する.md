# UC-BL-010 バックログ項目を分割する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-010 |
| ユースケース名 | バックログ項目を分割する |
| 英語名 | Split Backlog Item |
| 説明 | 大規模な項目を小さな実行可能な項目に分割する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-03 |
| 外部システム | - |
| 関連画面 | SCR-009（Epic Planningワークスペース） |

## 前置条件

- ユーザーがシステムにログインしていること
- 分割対象のバックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「Epic Planningワークスペース」画面（SCR-009）にアクセスする
2. 分割対象のバックログ項目を選択する
3. 「分割」ボタンをクリックする
4. 分割後の各項目のタイトル、説明、受入条件を入力する
5. 分割を実行する
6. システムが元の項目を分割し、新しいバックログ項目（INF-BL-01）を作成する
7. 分割完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 新しいバックログ項目（INF-BL-01）がシステムに登録される
- イベント「EVT-BL-007 バックログ項目が分割された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 分割対象および分割後の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-007 | バックログ項目が分割された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 分割数 | 一度に分割できる数は10個まで |
| 2 | 必須項目 | 各項目のタイトルは必須入力 |
