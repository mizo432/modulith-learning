# UC-BL-012 優先順位を設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-012 |
| ユースケース名 | 優先順位を設定する |
| 英語名 | Set Priority |
| 説明 | 項目の順序・優先理由を設定する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-BL-04 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 優先順位を設定する項目を選択する
3. 「優先順位を設定」ボタンをクリックする
4. 順序と優先理由を入力する
5. 設定を保存する
6. システムが優先順位（INF-BL-01）を更新する
7. 設定完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 優先理由が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- バックログ項目の優先順位が更新される
- イベント「EVT-BL-009 優先順位が設定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 優先順位設定対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-009 | 優先順位が設定された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 優先理由は必須入力 |
| 2 | 文字数制限 | 優先理由は500文字以内 |
