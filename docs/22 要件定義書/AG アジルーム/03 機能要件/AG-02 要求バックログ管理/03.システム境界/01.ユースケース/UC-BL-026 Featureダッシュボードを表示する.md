# UC-BL-026 Featureダッシュボードを表示する

## 概要

Feature単位の価値実現状況、開発進捗、品質、依存関係、リリース見通しをダッシュボードで表示する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-026 |
| ユースケース名 | Featureダッシュボードを表示する |
| 関連BUC | BUC-BL-07 |
| 関連アクター | ACT-02, ACT-03, ACT-04, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-BL-01 (バックログ項目), INF-BL-06 (バックログ階層), INF-BL-07 (項目関連付け), INF-BL-22 (Featureダッシュボード集計情報) |
| 関連画面 | SCR-012 (Featureダッシュボード画面) |

## 前提条件

- Featureが登録されていること

## 基本フロー

1. システムはログインユーザーのロールを確認する
2. システムは権限に応じたFeature一覧を取得する
3. システムは各Featureの開発進捗、価値の実現状況、提供準備状況を集計する
4. システムはFeatureダッシュボードを表示する
   - 開発進捗：構成User Storyの完了状況
   - 価値の実現状況：Feature Goalの達成状況
   - 提供準備状況：テスト・品質・依存関係の準備状況
5. アクターはFeatureを選択して詳細情報を確認できる

## 結果

Feature単位の価値実現状況、開発進捗、品質、依存関係、リリース見通しがダッシュボードで表示される。
