# UC-BL-028 Featureの詳細情報を確認する

## 概要

Featureを構成するStory、依存関係、品質情報、リリース見通しを確認する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-028 |
| ユースケース名 | Featureの詳細情報を確認する |
| 関連BUC | BUC-BL-07 |
| 関連アクター | ACT-02, ACT-03, ACT-04, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-BL-01 (バックログ項目), INF-BL-06 (バックログ階層), INF-BL-07 (項目関連付け), INF-BL-23 (Feature品質情報), INF-BL-24 (Featureリリース情報) |
| 関連画面 | SCR-012 (Featureダッシュボード画面) |

## 前提条件

- Featureダッシュボードが表示されていること
- 確認対象のFeatureが存在すること

## 基本フロー

1. アクターはダッシュボードからFeatureを選択する
2. システムはFeatureの詳細情報を表示する
   - Featureの基本情報（名前、説明、優先順位、状態）
   - 構成User Story一覧とその進捗状況
   - Feature間の依存関係
   - 品質情報（テスト結果、欠陥数など）
   - リリース見通し（予定リリース、準備状況）
3. アクターは構成Storyを選択して詳細を確認できる
4. アクターは依存関係の詳細を確認できる

## 結果

Featureの詳細情報（構成Story、依存関係、品質情報、リリース見通し）が表示される。
