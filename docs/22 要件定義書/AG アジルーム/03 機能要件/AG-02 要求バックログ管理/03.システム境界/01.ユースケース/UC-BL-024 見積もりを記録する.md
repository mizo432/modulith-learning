# UC-BL-024 見積もりを記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-024 |
| ユースケース名 | 見積もりを記録する |
| 英語名 | Record Estimate |
| 説明 | チームの見積もり、リスク、未知事項を記録する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-BL-03 |
| 外部システム | - |
| 関連画面 | SCR-011（User Story詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目（INF-BL-01）が既に存在すること

## 基本フロー

1. ユーザーが「User Story詳細」画面（SCR-011）にアクセスする
2. 見積もりを記録する項目を選択する
3. 「見積もりを記録」ボタンをクリックする
4. 見積もり値、リスク、未知事項を入力する
5. 入力を保存する
6. システムが見積もり（INF-BL-01）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 見積もり（INF-BL-01）がシステムに登録される
- イベント「EVT-BL-018 見積もりが記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-BL-01 | バックログ項目 | 見積もり記録対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-BL-018 | 見積もりが記録された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 見積もり値は必須入力 |
| 2 | 見積もり単位 | ストーリポイントまたは時間単位で記録 |
