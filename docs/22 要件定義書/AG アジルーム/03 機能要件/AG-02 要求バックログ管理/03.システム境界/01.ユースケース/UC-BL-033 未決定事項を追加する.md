# UC-BL-033 未決定事項を追加する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-BL-033 |
| ユースケース名 | 未決定事項を追加する |
| 英語名 | Add Undecided Item |
| 説明 | チームが未決定事項を登録する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-BL-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「未決定事項を追加」ボタンをクリックする
3. タイトルとカテゴリを入力する
4. 詳細を入力する（任意）
5. 入力を保存する
6. システムが未決定事項（INF-BL-25）を「未決定」状態で登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - タイトルまたはカテゴリが未入力の場合、エラーメッセージを表示する（COND-BL-09）
  - ユーザーは入力を修正して再試行する

## 後置条件

- 未決定事項（INF-BL-25）が「未決定」状態でシステムに登録される
