# 要求一覧

要求・プロダクトバックログ管理業務領域（AG-02）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-BL-01 | 課題管理                     | 従業員が課題、要望、利用場面、影響を登録・更新・参照する   | MVP    |
| FR-BL-02 | フィードバック管理           | 利用者からの意見・評価を分類して記録・更新・参照する       | MVP    |
| FR-BL-03 | バックログ項目管理           | 課題や仮説をEpic・Feature・Storyに変換して管理する         | MVP    |
| FR-BL-04 | バックログ階層管理           | Product Goal、Epic、Feature、Story、Task間の関係を設定する | MVP    |
| FR-BL-05 | 優先順位管理                 | 項目の順序・優先理由を設定・更新する                     | MVP    |
| FR-BL-06 | 業務ルール管理               | 業務上の期待、例外、受入条件を項目に記録する             | MVP    |
| FR-BL-07 | 受入条件定義                 | 期待される振る舞いや境界条件を定義する                   | MVP    |
| FR-BL-08 | コメント機能                 | 項目上で質問、回答、議論を行う                           | MVP    |
| FR-BL-09 | メンション通知               | 関係者に通知を送信する                                   | MVP    |
| FR-BL-10 | バックログリファインメント   | 項目の説明・分割・受入条件・依存関係・準備状況を整える     | MVP    |
| FR-BL-11 | 依存関係定義                 | 項目間の依存関係を定義する                               | MVP    |
| FR-BL-12 | 変更履歴追跡                 | 要求、計画、テスト、リリースの関連と変更経緯を追跡する     | MVP    |
| FR-BL-13 | 要求の関連付け               | 類似要求や関連する課題、機能、テストを関連づける           | 次期   |
| FR-BL-14 | 意思決定記録                 | 決定内容、根拠、決定者、影響範囲を記録する               | 次期   |
| FR-BL-15 | Story Mapping               | ユーザー活動とストーリーを並べ、リリース範囲を検討する     | 次期   |
| FR-BL-16 | 見積もり記録                 | チームの見積もり、リスク、未知事項を記録する               | 次期   |
| FR-BL-17 | ソース管理連携               | コミット・ブランチ・PRをバックログ項目と関連付ける         | MVP    |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-BL-01 | 検索性能                       | 大量のバックログ項目から迅速に検索できる |
| NFR-BL-02 | 通知機能                       | 関係者にタイムリーに通知できる         |
| NFR-BL-03 | 変更履歴                       | 変更経緯を追跡できる                   |
