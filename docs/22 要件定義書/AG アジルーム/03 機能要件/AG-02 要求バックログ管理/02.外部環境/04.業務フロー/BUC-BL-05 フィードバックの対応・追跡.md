# BUC-BL-05 フィードバックの対応・追跡

## 概要

フィードバックを分類し、対応状況と判断理由を追跡する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:フィードバックを収集する;
:フィードバックを分類する;

if (分類は?) then (改善要望)
  :バックログ項目として登録する;
else (不具合報告)
  :不具合として登録する;
else (質問)
  :回答を作成する;
  else (その他)
  :適切に処理する;
  endif

:対応方針を決定する;
:判断理由を記録する;
:対応状況を更新する;
:フィードバック元に通知する;

:追跡結果を記録する;

stop
@enduml
```
