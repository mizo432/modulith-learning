# BUC-BL-01 課題・要望の受付・記録

## 概要

従業員から課題・要望を受け付け、背景・影響とともに記録する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:受付渠道を準備する;
:従業員から課題・要望を受け付ける;

if (必須情報が揃っているか?) then (いいえ)
  :不足情報を通知する;
  :提出者に補足を依頼する;
  else (はい)
  :背景情報を記録する;
  :影響範囲を記録する;
  :緊急度を設定する;
  endif

:受付番号を付与する;
:受付完了を通知する;
:関係者に共有する;

stop
@enduml
```
