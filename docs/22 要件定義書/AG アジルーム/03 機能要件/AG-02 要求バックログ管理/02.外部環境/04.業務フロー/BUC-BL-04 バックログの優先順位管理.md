# BUC-BL-04 バックログの優先順位管理

## 概要

項目の順序・優先理由を管理し、変更履歴を追跡する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:バックログ項目を確認する;
:優先順位の基準を確認する;

:価値を評価する;
:リスクを評価する;
:コストを評価する;

:優先順位を決定する;
:優先理由を記録する;
:順序を更新する;

if (変更があるか?) then (はい)
  :変更履歴を記録する;
  :関係者に通知する;
  else (いいえ)
  :そのまま進む;
  endif

:更新結果を共有する;

stop
@enduml
```
