# BUC-BL-06 要求の関連付け・トレーサビリティ

## 概要

要求・計画・テスト・リリースの関連と変更経緯を追跡する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:要求項目を確認する;
:関連する計画を特定する;
:関連するテストケースを特定する;
:関連するリリースを特定する;

:関連付けを記録する;
:トレーサビリティマトリクスを更新する;

if (変更があるか?) then (はい)
  :変更影響を分析する;
  :関連項目を更新する;
  :変更履歴を記録する;
  else (いいえ)
  :そのまま進む;
  endif

:トレーサビリティを確認する;
:結果を共有する;

stop
@enduml
```
