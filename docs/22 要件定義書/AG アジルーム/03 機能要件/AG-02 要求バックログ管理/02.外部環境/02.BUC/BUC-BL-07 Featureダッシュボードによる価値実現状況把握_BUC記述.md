# BUC-BL-07 Featureダッシュボードによる価値実現状況把握_BUC記述

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容                                                     |
|------------------|----------------------------------------------------------|
| BUC ID           | BUC-BL-07                                                |
| BUC名            | Featureダッシュボードによる価値実現状況把握               |
| 説明             | Feature単位で価値の実現状況、開発進捗、品質、依存関係、リリース見通しを把握する |
| 関連業務         | 要求・プロダクトバックログ管理                            |
| 関連ユースケース | UC-BL-026, UC-BL-027, UC-BL-028, UC-BL-029              |

## ビジネスアクター

| 番号 | アクターID | アクター名               | 役割                                                     |
|------|------------|--------------------------|----------------------------------------------------------|
| 1    | ACT-02     | プロダクトオーナー（PO） | Featureの価値、優先順位、進捗、リリース判断材料の確認     |
| 2    | ACT-03     | スクラムマスター（SM）   | 進捗の停滞、依存関係、阻害要因の把握                     |
| 3    | ACT-04     | 開発者                   | Featureを構成するStoryの状況、未完了作業の確認           |
| 4    | ACT-05     | トラッキング担当         | Featureの実現状況と提供時期の見通しの確認               |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## 制約事項

| 番号 | 制約事項 | 説明                                                     |
|------|----------|----------------------------------------------------------|
| 1    | 3つの区別表示 | 開発進捗、価値の実現状況、提供準備状況を区別して表示する必要がある |
| 2    | 進捗率の統合禁止 | 3つを1つの進捗率にまとめてはならない                       |
| 3    | リアルタイム集計 | Featureダッシュボードはバックログ項目の変更をリアルタイムで反映する |
| 4    | 権限に応じた表示 | アクターの権限に応じて表示範囲を制限する                   |
