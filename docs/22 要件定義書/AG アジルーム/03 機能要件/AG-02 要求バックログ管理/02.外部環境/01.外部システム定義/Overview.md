# 外部システム定義 Overview

要求バックログ管理業務領域（AG-02）が連携する外部システムを定義します。

## 概要

要求バックログ管理は、課題や仮説を実行可能な要求へ変換し、Product Goalとのつながりを保ちながら価値順に管理する業務領域です。本業務領域では、バックログ項目・フィードバック・受入条件などの情報はAgiloom内で管理するため、外部システムとの直接的な連携はありません。

## 外部システム一覧

本業務領域で連携する外部システムはありません。

| ID       | 外部システム名 | 連携内容 |
|----------|----------------|----------|
| （なし） | -              | -        |

## 補足

- バックログ管理で管理する情報（Epic、Feature、User Story、欠陥、フィードバックなど）は、Agiloom内の他の業務領域（ディスカバリー、スプリント実行、品質検証、成果適応）と連携しますが、これらはシステム内部の連携であり、外部システム連携には該当しません。
- 将来的に、ソース管理システム（Git）やCI/CDツールとの連携により、バックログ項目とコード変更・ビルド結果を関連付けることが検討される場合がありますが、現時点ではMVP範囲外です。
