# 情報属性一覧

ラベルの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-BL-03 |
| 情報名 | ラベル |
| 情報種類 | リソース |
| 説明 | バックログの分類ラベル |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | ラベルの一意な識別子 |
| 2 | name | | String | 必須 | ラベルの名前 |
| 3 | color | | String | 任意 | ラベルの色 |
| 4 | description | | String | 任意 | ラベルの説明 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのラベルは、名前で1つの分類を構成する |
| 同一性 (Sameness) | idが同じ場合、同じラベルであると判断する |
| カテゴリ (Category) | バックログ項目の分類情報 |
