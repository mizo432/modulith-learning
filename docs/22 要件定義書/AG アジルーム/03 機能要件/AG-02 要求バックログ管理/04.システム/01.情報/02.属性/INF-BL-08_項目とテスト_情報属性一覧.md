# 項目とテスト属性一覧

要求・プロダクトバックログ管理業務領域で扱う「項目とテスト」の属性を定義します。

| 属性名              | 型          | PK | 必須 | 説明                                           |
|---------------------|-------------|----|------|------------------------------------------------|
| item_test_id        | SnowflakeID | *  | Y    | 関連付けの一意な識別子                         |
| backlog_item_id     | SnowflakeID |    | Y    | バックログ項目の識別子                         |
| test_case_id        | SnowflakeID |    | Y    | テストケースの識別子                           |
| created_at          | DateTime    |    | Y    | 作成日時                                       |
