# 優先度属性一覧

要求・プロダクトバックログ管理業務領域で扱う「優先度」の属性を定義します。

| 属性名              | 型          | PK | 必須 | 説明                                           |
|---------------------|-------------|----|------|------------------------------------------------|
| priority_code       | String      | *  | Y    | 優先度コード                                   |
| priority_name       | String      |    | Y    | 優先度名                                       |
| description         | Text        |    | N    | 説明                                           |
