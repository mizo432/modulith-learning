# 情報属性一覧

ストーリーポイントの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-BL-02 |
| 情報名 | ストーリーポイント |
| 情報種類 | リソース |
| 説明 | 見積もりポイント |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | ストーリーポイントの一意な識別子 |
| 2 | backlogItemId | | Long | 必須 | 関連するバックログ項目のID |
| 3 | points | | Integer | 必須 | 見積もりポイント |
| 4 | estimator | | String | 任意 | 見積もり担当者 |
| 5 | estimatedDate | | DateTime | 必須 | 見積もり日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのストーリーポイントは、バックログ項目・ポイント・見積もり担当者の組み合わせで1つの見積もりを構成する |
| 同一性 (Sameness) | idが同じ場合、同じストーリーポイントであると判断する |
| カテゴリ (Category) | バックログ項目の見積もり情報 |
