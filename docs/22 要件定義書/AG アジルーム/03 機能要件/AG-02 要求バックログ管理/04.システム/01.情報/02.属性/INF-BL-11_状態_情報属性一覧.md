# 状態属性一覧

要求・プロダクトバックログ管理業務領域で扱う「状態」の属性を定義します。

| 属性名              | 型          | PK | 必須 | 説明                                           |
|---------------------|-------------|----|------|------------------------------------------------|
| status_code         | String      | *  | Y    | 状態コード                                     |
| status_name         | String      |    | Y    | 状態名                                         |
| description         | Text        |    | N    | 説明                                           |
