# 情報属性一覧

バックログ項目の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-BL-01 |
| 情報名 | バックログ項目 |
| 情報種類 | リソース |
| 説明 | バックログの詳細情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | バックログ項目の一意な識別子 |
| 2 | title | | String | 必須 | 項目のタイトル |
| 3 | description | | String | 必須 | 項目の詳細説明 |
| 4 | type | | Enum | 必須 | 項目のタイプ（Epic, Feature, Story, Task） |
| 5 | priority | | Enum | 必須 | 優先度（高, 中, 低） |
| 6 | status | | Enum | 必須 | 状態（新規, 明確化中, 準備完了, 実装中, 完了） |
| 7 | assignee | | String | 任意 | 担当者 |
| 8 | createdDate | | DateTime | 必須 | 作成日時 |
| 9 | updatedDate | | DateTime | 必須 | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのバックログ項目は、タイトル・説明・タイプの組み合わせで1つの項目を構成する |
| 同一性 (Sameness) | idが同じ場合、同じバックログ項目であると判断する |
| カテゴリ (Category) | プロダクトバックログの項目情報 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 新規 | 項目が作成された直後の状態 | - | 明確化中 | バックログ項目を作成する |
| 明確化中 | 項目の詳細が精査されている状態 | 新規 | 準備完了 | バックログ項目を更新する |
| 準備完了 | リファインメントが完了し、実装可能な状態 | 明確化中 | 実装中 | 優先順位を設定する |
| 実装中 | 実装が進行中の状態 | 準備完了 | 完了 | バックログ項目を更新する |
| 完了 | 実装が完了した状態 | 実装中 | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-BL-02 | ストーリーポイント | 1対多 | バックログ項目は複数のストーリーポイントを持つ |
| INF-BL-03 | ラベル | 1対多 | バックログ項目は複数のラベルを持つ |
