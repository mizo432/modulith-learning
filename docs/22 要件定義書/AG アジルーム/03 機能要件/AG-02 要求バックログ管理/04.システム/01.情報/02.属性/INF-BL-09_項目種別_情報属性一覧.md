# 項目種別属性一覧

要求・プロダクトバックログ管理業務領域で扱う「項目種別」の属性を定義します。

| 属性名              | 型          | PK | 必須 | 説明                                           |
|---------------------|-------------|----|------|------------------------------------------------|
| item_type_code      | String      | *  | Y    | 種別コード                                     |
| item_type_name      | String      |    | Y    | 種別名                                         |
| description         | Text        |    | N    | 説明                                           |
