# 画面属性一覧

Product Backlogの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-010 |
| 画面名 | Product Backlog |
| 説明 | Story等を作成・編集・分割・並べ替え、優先順位を管理する |
| 関連ユースケース | UC-BL-001, UC-BL-002, UC-BL-003, UC-BL-004, UC-BL-005, UC-BL-006, UC-BL-009, UC-BL-012, UC-BL-013, UC-BL-018, UC-BL-021, UC-BL-022 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 項目名 | 入力 | String | はい | - | 最大255文字 | バックログ項目の名前 |
| 2 | 種別 | 選択 | Enum | はい | - | Epic/Feature/Story/Task/欠陥 | 項目の種別 |
| 3 | 説明 | 入力 | String | いいえ | - | 最大2000文字 | 項目の説明 |
| 4 | 優先順位 | 入力 | Integer | はい | - | 1以上 | 優先度 |
| 5 | 状態 | 表示 | Enum | はい | - | 新規/準備中/準備完了/進行中/完了/見送り | 進捗状態 |
| 6 | 見積もり | 表示 | Integer | いいえ | - | 0以上 | 見積もり値 |
| 7 | 関連Epic | リンク | String | いいえ | - | - | 関連するEpic |
| 8 | 関連Feature | リンク | String | いいえ | - | - | 関連するFeature |
| 9 | 意思決定 | リンク | String | いいえ | - | - | 関連する意思決定 |
| 10 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 11 | 状態フィルター | 選択 | Enum | いいえ | すべて | - | 状態で絞り込む |
| 12 | 種別フィルター | 選択 | Enum | いいえ | すべて | - | 種別で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | バックログ総数、状態別集計を表示 | 項目名 |
| 2 | 検索・フィルター | 検索・絞り込み | 検索キーワード、状態フィルター、種別フィルター |
| 3 | メインコンテンツ | バックログ一覧表を表示・編集・並べ替え | 項目名、種別、説明、優先順位、状態、見積もり、関連Epic、関連Feature |
| 4 | サイドバー | 優先順位別集計、意思決定一覧を表示 | 優先順位、意思決定 |
