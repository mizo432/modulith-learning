# User Story詳細

User Story詳細画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-011 |
| 画面名           | User Story詳細 |
| 説明             | 説明、受入条件、見積り、依存関係、関連ジャーニー、履歴を管理する |
| 関連ユースケース | UC-BL-008, UC-BL-014, UC-BL-015, UC-BL-016, UC-BL-017, UC-BL-019, UC-BL-020, UC-BL-022, UC-BL-024, UC-BL-025 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Story名、状態、優先度を表示 |
| ナビゲーション | 基本情報、受入条件、コメント、履歴のタブ切り替え |
| メインコンテンツ | 選択したタブに対応する詳細情報を表示・編集 |
| サイドバー | 関連項目、依存関係、変更履歴を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Story名 | 文字列 | はい | ユーザーストーリーの名前 |
| 2 | 説明 | テキスト | はい | Storyの詳細説明 |
| 3 | 受入条件 | テキスト | はい | 期待される振る舞いや境界条件 |
| 4 | 見積もり | 数値 | いいえ | 作業の見積もり値 |
| 5 | 優先度 | 選択 | はい | 優先度（高、中、低） |
| 6 | 状態 | 選択 | はい | 状態（新規、準備中、進行中、完了） |
| 7 | 関連Epic | 選択 | いいえ | 関連するEpic |
| 8 | 関連Feature | 選択 | いいえ | 関連するFeature |
| 9 | 依存関係 | 複数選択 | いいえ | 依存する他の項目 |
| 10 | 関連ジャーニー | 選択 | いいえ | 関連するユーザージャーニー |
| 11 | 業務ルール | テキスト | いいえ | 関連する業務ルール |
| 12 | コメント | テキスト | いいえ | 議論や質問の記録 |
| 13 | メンション | 文字列 | いいえ | 通知対象者 |
| 14 | 変更履歴 | テキスト | いいえ | 変更の経緯 |
| 15 | ソース管理情報 | 文字列 | いいえ | 関連するコミット・ブランチ・PR |
| 16 | 決定内容 | テキスト | いいえ | 意思決定の記録 |
| 17 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | バックログ項目を更新 | 項目の詳細を修正する |
| 2 | 受入条件を定義 | 期待される振る舞いを定義する |
| 3 | 業務ルールを登録 | 業務上のルールを記録する |
| 4 | コメントを投稿 | 質問や議論を投稿する |
| 5 | メンション通知を送信 | 関係者に通知を送信する |
| 6 | 依存関係を定義 | 項目間の依存関係を定義する |
| 7 | 変更履歴を参照 | 変更の経緯を確認する |
| 8 | 意思決定を記録 | 決定内容と根拠を記録する |
| 9 | 見積もりを記録 | チームの見積もりを記録する |
| 10 | ソース管理情報を関連付ける | コミット・ブランチ・PRを関連付ける |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Storyの編集はプロダクトオーナーと開発チームのみ可能 |
| 2 | 受入条件の必須 | 準備完了状態にするには受入条件が必須 |
