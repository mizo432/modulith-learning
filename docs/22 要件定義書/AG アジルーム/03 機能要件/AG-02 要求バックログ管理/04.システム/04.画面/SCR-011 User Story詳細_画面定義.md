# User Story詳細

User Story詳細画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-011 |
| 画面名           | User Story詳細 |
| 説明             | 説明、受入条件、見積り、依存関係、関連ジャーニー、履歴を管理する |
| 関連ユースケース | UC-BL-008, UC-BL-014, UC-BL-015, UC-BL-016, UC-BL-017, UC-BL-019, UC-BL-020, UC-BL-024, UC-BL-025 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Story名、状態、見積もりを表示 |
| メインコンテンツ | Storyの詳細情報を表示・編集 |
| コメント欄 | コメントの投稿・参照 |
| サイドバー | 変更履歴、ソース管理情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Story名 | 文字列 | はい | ストーリー名 |
| 2 | 説明 | 文字列 | はい | ストーリーの詳細説明 |
| 3 | 受入条件 | 文字列 | はい | 期待される振る舞い |
| 4 | 見積もり | 数値 | いいえ | 見積もり値 |
| 5 | 依存関係 | リンク | いいえ | 依存する項目一覧 |
| 6 | 関連ジャーニー | リンク | いいえ | 関連するユーザージャーニー |
| 7 | コメント | 文字列 | いいえ | コメント |
| 8 | 変更履歴 | 日時 | はい | 最終更新日時 |
| 9 | ソース管理情報 | リンク | いいえ | 関連するコミット・ブランチ・PR |
| 10 | 業務ルール | 文字列 | いいえ | 業務上のルール |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | バックログ項目を更新 | 項目の詳細を修正する |
| 2 | 受入条件を定義 | 受入条件を定義する |
| 3 | 依存関係を定義 | 依存関係を定義する |
| 4 | コメントを投稿 | コメントを投稿する |
| 5 | 見積もりを記録 | 見積もりを記録する |
| 6 | ソース管理情報を関連付ける | ソース管理情報を関連付ける |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Story詳細の編集はプロダクトオーナーと開発者のみ可能 |
| 2 | 参照権限 | Story詳細の参照は全チームメンバー |
