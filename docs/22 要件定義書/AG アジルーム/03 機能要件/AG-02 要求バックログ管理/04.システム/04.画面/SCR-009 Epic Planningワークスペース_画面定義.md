# Epic Planningワークスペース

Epic Planningワークスペース画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-009 |
| 画面名           | Epic Planningワークスペース |
| 説明             | EpicをFeature・Storyへ分解し、依存関係・優先順位・リスクを検討する |
| 関連ユースケース | UC-BL-007, UC-BL-010 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Epic名、Feature・Story総数を表示 |
| 検索・フィルター | 検索キーワードでの絞り込み |
| メインコンテンツ | Epicの分解結果を階層表示・編集 |
| サイドバー | 依存関係図を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Epic名 | 文字列 | はい | 計画対象のEpic名 |
| 2 | Feature名 | 文字列 | はい | 分解したFeature名 |
| 3 | Story名 | 文字列 | はい | 分解したStory名 |
| 4 | 依存関係 | リンク | いいえ | 依存する項目一覧 |
| 5 | 優先順位 | 数値 | いいえ | 優先度 |
| 6 | リスク | 文字列 | いいえ | 関連するリスク |
| 7 | 検索キーワード | 文字列 | いいえ | 検索キーワード |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | バックログ項目を作成 | EpicをFeature・Storyへ分解する |
| 2 | バックログ項目を分割 | 大規模な項目を分割する |
| 3 | 依存関係を定義 | 項目間の依存関係を定義する |
| 4 | 検索 | 条件に合致する項目を検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Epic Planningの編集はプロダクトオーナーと開発者のみ可能 |
| 2 | 参照権限 | Epic Planningの参照は全チームメンバー |
