# ユーザーストーリーマップ

ユーザーストーリーマップ画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-007 |
| 画面名           | ユーザーストーリーマップ |
| 説明             | ユーザー活動・タスク・ストーリーを並べ、価値とリリース範囲を検討する |
| 関連ユースケース | UC-BL-023 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、マップ総数、最終更新日を表示 |
| ナビゲーション | マップ一覧、新規作成、編集の切り替え |
| メインコンテンツ | 横軸にユーザー活動、縦軸に優先度でストーリーを配置 |
| サイドバー | リリース範囲、関連Epicを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | マップ名 | 文字列 | はい | ストーリーマップの名前 |
| 2 | 関連Epic | 選択 | いいえ | 関連するEpic |
| 3 | ユーザー活動 | 文字列 | はい | 横軸のユーザー活動名 |
| 4 | タスク | 文字列 | はい | 活動内のタスク |
| 5 | ストーリー | 文字列 | はい | ユーザーストーリーの内容 |
| 6 | 優先度 | 選択 | はい | 優先度（高、中、低） |
| 7 | リリース範囲 | 選択 | いいえ | 含めるリリースバージョン |
| 8 | 見積もり | 数値 | いいえ | 作業の見積もり値 |
| 9 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Story Mappingを行う | ストーリーマップを作成・編集する |
| 2 | ユーザー活動を追加 | 新しいユーザー活動を追加する |
| 3 | ストーリーを追加 | 新しいストーリーを追加する |
| 4 | リリース範囲を設定 | リリース範囲をドラッグ＆ドロップで設定する |
| 5 | マップを参照 | 登録されたマップを確認する |
| 6 | エクスポート | ストーリーマップを画像としてエクスポートする |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ストーリーマップの編集はプロダクトオーナーと開発チームのみ可能 |
| 2 | ドラッグ＆ドロップ | ストーリーはドラッグ＆ドロップで順序を変更可能 |
