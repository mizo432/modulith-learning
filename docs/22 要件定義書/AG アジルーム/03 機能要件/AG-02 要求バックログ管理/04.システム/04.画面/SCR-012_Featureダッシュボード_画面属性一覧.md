## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-012 |

## 画面レイアウト

| 領域名 | 説明 | 含まれる項目 |
|--------|------|--------------|
| ヘッダー | 画面タイトル、フィルタ条件入力エリア | フィルタ状態, フィルタ優先順位, フィルタ担当者, ソートキー |
| 概要パネル | Feature全体の集計情報 | 総Feature数, 準備中数, 開発中数, 検証中数, 提供準備完了数, 提供済数, 保留中数, 取り消し数 |
| Feature一覧 | Featureカード一覧 | Feature名, 状態, 優先順位, 開発進捗, 価値実現状況, 提供準備状況, 担当者, リリース予定 |
| 詳細パネル | 選択したFeatureの詳細情報 | 構成Story一覧, 依存関係一覧, 品質情報, リリース情報 |

## 画面操作

| 操作名 | トリガー | 説明 | 遷移先画面 |
|--------|----------|------|------------|
| Feature選択 | Featureカードクリック | 詳細パネルを表示 | - |
| フィルタ適用 | フィルタボタンクリック | Feature一覧を絞り込む | - |
| ソート | ソートキー変更 | Feature一覧をソート | - |
| レポート出力 | レポート出力ボタンクリック | 進捗レポートを出力 | - |
| 詳細画面遷移 | Feature名クリック | Featureの詳細画面へ遷移 | SCR-011 |

## 制約事項

| 制約名 | 対象項目 | 制約内容 |
|--------|----------|----------|
| 3つの区別表示 | 開発進捗, 価値実現状況, 提供準備状況 | 3つを区別して表示する必要がある |
| 進捗率の統合禁止 | 開発進捗, 価値実現状況, 提供準備状況 | 3つを1つの進捗率にまとめてはならない |
| リアルタイム更新 | 全項目 | バックログ項目の変更をリアルタイムで反映する |
| 権限に応じた表示 | Feature一覧 | アクターの権限に応じて表示範囲を制限する |

## バリデーションルール

| ルール名 | 対象項目 | 条件 | エラーメッセージ |
|----------|----------|------|------------------|
| フィルタ状態有効値 | フィルタ状態 | 定義された状態のみ選択可能 | 無効な状態が選択されました |
| フィルタ優先順位有効値 | フィルタ優先順位 | 定義された優先度のみ選択可能 | 無効な優先度が選択されました |
