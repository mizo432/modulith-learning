# ユーザーストーリーマップ

ユーザーストーリーマップ画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-007 |
| 画面名           | ユーザーストーリーマップ |
| 説明             | ユーザーの活動や業務の流れを起点として、Activity → User Task → User Story → Release Slice の4階層でストーリーマップを作成・編集し、プロダクトの価値と開発範囲を可視化する |
| 関連ユースケース | UC-BL-023 |

## 画面レイアウト

画面は次の6つの領域に分けます。

| ID     | 領域名              | 説明 |
|--------|-------------------|------|
| USM-01 | マップ基本情報       | マップ名、目的、対象ペルソナ、バージョンを管理 |
| USM-02 | Activity Backbone | ユーザーの大きな活動を横方向に配置 |
| USM-03 | User Task         | Activityを具体的なユーザー行動に分解 |
| USM-04 | User Story        | 各Taskを実現するストーリーを配置 |
| USM-05 | Release Slice     | Storyをリリース単位に分類 |
| USM-06 | 詳細・編集パネル     | 選択した要素の詳細、関連情報、履歴を表示 |

### USM-01 マップ基本情報

| 項目      | 内容              |
|-----------|------------------|
| マップ名    | ユーザーストーリーマップの名称 |
| 説明      | マップの目的や対象業務     |
| Product   | 対象プロダクト         |
| Persona   | 対象ユーザー（複数設定可）  |
| 作成者     | マップの作成者         |
| 参加者     | マップ編集に参加するメンバー  |
| バージョン   | マップのバージョン       |
| 状態      | 下書き・編集中・公開      |
| 更新日時    | 最終更新日時          |

操作：
- マップを新規作成する
- マップを複製する
- マップ名・説明を変更する
- バージョンを作成する
- 過去バージョンを参照する

### USM-02 Activity Backbone

ユーザーが達成したい大きな活動を横方向に配置します。

要件：
- Activityを追加・編集・削除できる
- Activityの順序を変更できる
- Activityごとに説明を登録できる
- Activityに対象Personaを設定できる
- Activityをドラッグ＆ドロップで並べ替えられる

### USM-03 User Task

Activityを構成する具体的なユーザー行動を配置します。

要件：
- Taskを追加・編集・削除できる
- TaskをActivity間で移動できる
- Taskの順序を変更できる
- Taskの説明やユーザーの期待する結果を記録できる
- Taskに関連するPain PointやOpportunityを紐付けられる

### USM-04 User Story

User Taskを実現するユーザーストーリーを配置します。

要件：
- Storyを新規作成できる
- 既存のProduct BacklogからStoryを配置できる
- Storyを別のTaskに移動できる
- Storyの順序を変更できる
- Storyの優先順位を設定できる
- Storyの見積もりを表示できる
- Storyの受入条件を確認できる
- Storyの詳細画面に遷移できる
- Storyが複数のTaskに関連する場合を扱える

Storyカードには、次の情報を表示します：

| 項目       | 表示例         |
|------------|---------------|
| Story ID   | US-001        |
| タイトル     | 申請フォームを表示する |
| 優先順位     | 高           |
| 見積もり     | 3ポイント       |
| 状態       | 未着手         |
| Epic       | 申請管理        |
| Feature    | 申請入力        |

### USM-05 Release Slice

User Storyをリリース単位に分類します。

要件：
- Release Sliceを作成できる
- Release SliceにStoryを割り当てられる
- Storyを別のReleaseに移動できる
- ReleaseごとのStory数・見積もり合計を表示できる
- Releaseに含まれるStoryを一覧表示できる
- Release間の依存関係を確認できる
- Release Sliceの変更履歴を記録できる

### USM-06 詳細・編集パネル

Story Map上の要素を選択すると、右側に詳細情報を表示します。

| 選択要素          | 表示する情報                         |
|-----------------|----------------------------------|
| Activity        | 名称、説明、Persona                  |
| User Task       | 名称、説明、Pain Point、Opportunity   |
| User Story      | 説明、受入条件、優先順位、見積もり、Epic、Feature |
| Release Slice   | Release名、対象Story、提供価値、依存関係     |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | マップ名 | 文字列 | はい | ストーリーマップの名称 |
| 2 | 説明 | 文字列 | いいえ | マップの目的や対象業務 |
| 3 | Product | 選択 | はい | 対象プロダクト |
| 4 | Persona | 選択 | いいえ | 対象ユーザー（複数設定可） |
| 5 | Activity | 文字列 | はい | ユーザーの大きな活動 |
| 6 | User Task | 文字列 | はい | Activityを構成するユーザー行動 |
| 7 | User Story | リンク | いいえ | 関連するストーリー（Product Backlog参照） |
| 8 | Release Slice | 文字列 | いいえ | リリース単位のスライス名 |
| 9 | 優先順位 | 数値 | いいえ | ストーリーの優先度 |
| 10 | 見積もり | 数値 | いいえ | ストーリーの見積もりポイント |
| 11 | 状態 | 選択 | いいえ | 下書き・編集中・公開 |
| 12 | 検索キーワード | 文字列 | いいえ | 検索キーワード |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Story Mapを作成する | 新規ストーリーマップを作成する |
| 2 | マップを複製する | 既存のマップを複製する |
| 3 | Activityを追加する | ユーザーの大きな活動を追加する |
| 4 | Activityを並べ替える | ドラッグ＆ドロップでActivityの順序を変更する |
| 5 | User Taskを追加する | Activityにユーザー行動を追加する |
| 6 | User Taskを移動する | TaskをActivity間で移動する |
| 7 | User Storyを配置する | 新規または既存StoryをTaskに配置する |
| 8 | Storyを移動・並べ替える | ドラッグ＆ドロップでStoryを移動する |
| 9 | Release Sliceを作成する | リリース単位のスライスを作成する |
| 10 | StoryをReleaseに割り当てる | StoryをRelease Sliceに割り当てる |
| 11 | バージョンを作成する | 現在のマップ状態をバージョンとして保存する |
| 12 | 変更履歴を確認する | 過去の変更履歴を表示する |
| 13 | 検索 | 条件に合致するストーリーを検索する |
| 14 | Story Mapを公開・共有する | マップを公開状態にして共有する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ストーリーマップの編集はプロダクトオーナーと開発者のみ可能 |
| 2 | 参照権限 | ストーリーマップの参照は全チームメンバー |
| 3 | Storyの参照 | Story Map専用のUser Storyを別途作成せず、Product BacklogのUser Storyを参照する |
| 4 | Release Sliceの分離 | Story MapのRelease Sliceは計画候補であり、正式なRelease Scopeとは区別する |
| 5 | バージョン管理 | 公開済みマップを再編集する場合は、新しいバージョンとして管理する |
