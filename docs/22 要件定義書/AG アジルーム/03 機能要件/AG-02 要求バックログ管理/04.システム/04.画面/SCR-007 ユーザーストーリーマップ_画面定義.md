# ユーザーストーリーマップ

ユーザーストーリーマップ画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-007 |
| 画面名           | ユーザーストーリーマップ |
| 説明             | ユーザー活動・タスク・ストーリーを並べ、価値とリリース範囲を検討する |
| 関連ユースケース | UC-BL-023 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | マップ名、ストーリー総数を表示 |
| 検索・フィルター | 検索キーワードでの絞り込み |
| メインコンテンツ | ユーザーストーリーマップを可視化・編集 |
| タイムライン | リリース範囲を横軸にストーリーを配置 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ユーザー活動 | 文字列 | はい | ユーザーの主要な活動 |
| 2 | タスク | 文字列 | はい | 活動内のタスク |
| 3 | ストーリー | リンク | いいえ | 関連するストーリー一覧 |
| 4 | リリース範囲 | 選択 | いいえ | リリースに含める範囲 |
| 5 | 優先順位 | 数値 | いいえ | ストーリーの優先度 |
| 6 | 検索キーワード | 文字列 | いいえ | 検索キーワード |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Story Mappingを行う | ユーザー活動とストーリーを並べる |
| 2 | ストーリーを追加 | 新しいストーリーをマップに追加する |
| 3 | リリース範囲を設定 | リリースに含める範囲を設定する |
| 4 | 検索 | 条件に合致するストーリーを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ストーリーマップの編集はプロダクトオーナーと開発者のみ可能 |
| 2 | 参照権限 | ストーリーマップの参照は全チームメンバー |
