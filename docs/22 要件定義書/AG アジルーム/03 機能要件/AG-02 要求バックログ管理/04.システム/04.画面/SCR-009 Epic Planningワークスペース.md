# Epic Planningワークスペース

Epic Planningワークスペース画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-009 |
| 画面名           | Epic Planningワークスペース |
| 説明             | EpicをFeature・Storyへ分解し、依存関係・優先順位・リスクを検討する |
| 関連ユースケース | UC-BL-007, UC-BL-010 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、Epic名、最終更新日を表示 |
| ナビゲーション | Epic、Feature、Storyの階層ナビゲーション |
| メインコンテンツ | ツリー形式でEpicからFeature・Storyへの分解を表示・編集 |
| サイドバー | 依存関係、優先順位、リスクを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Epic名 | 文字列 | はい | 対象Epicの名前 |
| 2 | Feature名 | 文字列 | はい | 分解したFeatureの名前 |
| 3 | Story名 | 文字列 | はい | 分解したStoryの名前 |
| 4 | 説明 | テキスト | いいえ | 項目の説明 |
| 5 | 依存関係 | 複数選択 | いいえ | 依存する他の項目 |
| 6 | 優先順位 | 数値 | いいえ | 優先順位の値 |
| 7 | リスク | テキスト | いいえ | 見込まれるリスク |
| 8 | 見積もり | 数値 | いいえ | 作業の見積もり値 |
| 9 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | バックログ項目を作成 | Epic、Feature、Storyを作成する |
| 2 | バックログ項目を分割 | 大規模な項目を小さな項目に分割する |
| 3 | 依存関係を定義 | 項目間の依存関係を定義する |
| 4 | 優先順位を設定 | 項目の優先順位を設定する |
| 5 | ワークスペースを参照 | 現在の計画状況を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 計画の編集はプロダクトオーナーと開発チームのみ可能 |
| 2 | 階層の整合性 | StoryはFeatureに、FeatureはEpicに属しなければならない |
