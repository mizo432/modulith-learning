# 画面属性一覧

Epic一覧・詳細の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-008 |
| 画面名 | Epic一覧・詳細 |
| 説明 | Epicの目的、成果、状態、関連Feature、リスクを管理する |
| 関連ユースケース | UC-BL-011 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Epic名 | 入力 | String | はい | - | 最大255文字 | Epicの名前 |
| 2 | 目的 | 入力 | String | はい | - | 最大1000文字 | Epicの目的 |
| 3 | 成果 | 入力 | String | いいえ | - | 最大1000文字 | 期待される成果 |
| 4 | 状態 | 表示 | Enum | はい | - | 計画済み/進行中/完了/見送り | Epicの進捗状態 |
| 5 | 関連Feature | リンク | String | いいえ | - | - | 関連するFeature一覧 |
| 6 | リスク | 入力 | String | いいえ | - | 最大1000文字 | 関連するリスク |
| 7 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 8 | 状態フィルター | 選択 | Enum | いいえ | すべて | - | 状態で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | Epic総数、状態別集計を表示 | Epic名 |
| 2 | 検索・フィルター | 検索・絞り込み | 検索キーワード、状態フィルター |
| 3 | メインコンテンツ | Epic一覧表または詳細情報を表示・編集 | Epic名、目的、成果、状態、関連Feature、リスク |

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|

| 3 | 検索 | ボタンクリック | 条件に合致するEpicを検索する | - |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|

| 3 | 検索キーワードの文字数 | 検索キーワード | 文字数 <= 100 | 検索キーワードは100文字以内で入力してください |
