# 画面属性一覧

Epic Planningワークスペースの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-009 |
| 画面名 | Epic Planningワークスペース |
| 説明 | EpicをFeature・Storyへ分解し、依存関係・優先順位・リスクを検討する |
| 関連ユースケース | UC-BL-007, UC-BL-010 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Epic名 | 表示 | String | はい | - | - | 計画対象のEpic名 |
| 2 | Feature名 | 入力 | String | はい | - | 最大255文字 | 分解したFeature名 |
| 3 | Story名 | 入力 | String | はい | - | 最大255文字 | 分解したStory名 |
| 4 | 依存関係 | リンク | String | いいえ | - | - | 依存する項目一覧 |
| 5 | 優先順位 | 入力 | Integer | いいえ | - | 1以上 | 優先度 |
| 6 | リスク | 入力 | String | いいえ | - | 最大1000文字 | 関連するリスク |
| 7 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | Epic名、Feature・Story総数を表示 | Epic名 |
| 2 | 検索・フィルター | 検索 | 検索キーワード |
| 3 | メインコンテンツ | Epicの分解結果を階層表示・編集 | Feature名、Story名、依存関係、優先順位、リスク |
| 4 | サイドバー | 依存関係図を表示 | 依存関係 |

## 画面操作

画面で実行可能な操作を定義します。

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | バックログ項目を作成 | ボタンクリック | EpicをFeature・Storyへ分解する | SCR-009 |
| 2 | バックログ項目を分割 | ボタンクリック | 大規模な項目を分割する | SCR-009 |
| 3 | 依存関係を定義 | ボタンクリック | 項目間の依存関係を定義する | SCR-009 |
| 4 | 検索 | ボタンクリック | 条件に合致する項目を検索する | - |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 編集権限 | 全項目 | Epic Planningの編集はプロダクトオーナーと開発者のみ可能 | 権限チェック |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | Feature名の文字数 | Feature名 | 文字数 <= 255 | Feature名は255文字以内で入力してください |
| 2 | Story名の文字数 | Story名 | 文字数 <= 255 | Story名は255文字以内で入力してください |
| 3 | 検索キーワードの文字数 | 検索キーワード | 文字数 <= 100 | 検索キーワードは100文字以内で入力してください |
