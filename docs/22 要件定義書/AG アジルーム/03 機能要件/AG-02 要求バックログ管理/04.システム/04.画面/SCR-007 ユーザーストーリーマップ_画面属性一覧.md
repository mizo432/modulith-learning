# 画面属性一覧

ユーザーストーリーマップの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-007 |
| 画面名 | ユーザーストーリーマップ |
| 説明 | ユーザー活動・タスク・ストーリーを並べ、価値とリリース範囲を検討する |
| 関連ユースケース | UC-BL-023 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ユーザー活動 | 入力 | String | はい | - | 最大255文字 | ユーザーの主要な活動 |
| 2 | タスク | 入力 | String | はい | - | 最大500文字 | 活動内のタスク |
| 3 | ストーリー | リンク | String | いいえ | - | - | 関連するストーリー一覧 |
| 4 | リリース範囲 | 選択 | Enum | いいえ | - | 初期/第1期/第2期/... | リリースに含める範囲 |
| 5 | 優先順位 | 表示 | Integer | いいえ | - | 1以上 | ストーリーの優先度 |
| 6 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | マップ名、ストーリー総数を表示 | ユーザー活動 |
| 2 | 検索・フィルター | 検索 | 検索キーワード |
| 3 | メインコンテンツ | ユーザーストーリーマップを可視化・編集 | ユーザー活動、タスク、ストーリー、リリース範囲、優先順位 |
| 4 | タイムライン | リリース範囲を横軸にストーリーを配置 | リリース範囲、ストーリー |

## 画面操作

画面で実行可能な操作を定義します。

|------|--------|----------|------|------------|

| 2 | ストーリーを追加 | ボタンクリック | 新しいストーリーをマップに追加する | SCR-007 |
| 3 | リリース範囲を設定 | ボタンクリック | リリースに含める範囲を設定する | SCR-007 |
| 4 | 検索 | ボタンクリック | 条件に合致するストーリーを検索する | - |

画面項目の制約条件を定義します。
