# 画面属性一覧

ユーザーストーリーマップの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-007 |
| 画面名 | ユーザーストーリーマップ |
| 説明 | ユーザーの活動や業務の流れを起点として、Activity → User Task → User Story → Release Slice の4階層でストーリーマップを作成・編集する |
| 関連ユースケース | UC-BL-023 |

## 画面項目一覧

| 3 | Product | 選択 | String | はい | - | - | 対象プロダクト |
| 4 | Persona | 選択 | String | いいえ | - | 複数選択可 | 対象ユーザー |

| 7 | User Task | 入力 | String | はい | - | 最大500文字 | Activityを構成するユーザー行動 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | USM-01 マップ基本情報 | マップ名、目的、対象ペルソナ、バージョンを管理 | マップ名、説明、Product、Persona、状態、バージョン |
| 2 | USM-02 Activity Backbone | ユーザーの大きな活動を横方向に配置 | Activity、Activity説明 |
| 3 | USM-03 User Task | Activityを具体的なユーザー行動に分解 | User Task、Task説明、Pain Point、Opportunity |
| 4 | USM-04 User Story | 各Taskを実現するストーリーを配置 | User Story、優先順位、見積もり |
| 5 | USM-05 Release Slice | Storyをリリース単位に分類 | Release Slice、Release説明 |
| 6 | USM-06 詳細・編集パネル | 選択した要素の詳細、関連情報、履歴を表示 | 選択要素に応じた詳細情報 |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 編集権限 | 全項目 | ストーリーマップの編集はプロダクトオーナーと開発者のみ可能 | 権限チェック |
| 2 | Storyの参照 | User Story | Story Map専用のUser Storyを別途作成せず、Product BacklogのUser Storyを参照する | 参照整合性 |
| 3 | Release Sliceの分離 | Release Slice | Story MapのRelease Sliceは計画候補であり、正式なRelease Scopeとは区別する | 業務ルール |
| 4 | バージョン管理 | 状態 | 公開済みマップを再編集する場合は、新しいバージョンとして管理する | バージョン管理 |
