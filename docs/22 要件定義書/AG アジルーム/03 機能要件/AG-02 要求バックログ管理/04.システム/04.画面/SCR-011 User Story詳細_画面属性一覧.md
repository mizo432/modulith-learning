# 画面属性一覧

User Story詳細の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-011 |
| 画面名 | User Story詳細 |
| 説明 | 説明、受入条件、見積り、依存関係、関連ジャーニー、履歴を管理する |
| 関連ユースケース | UC-BL-008, UC-BL-014, UC-BL-015, UC-BL-016, UC-BL-017, UC-BL-019, UC-BL-020, UC-BL-024, UC-BL-025 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Story名 | 表示 | String | はい | - | - | ストーリー名 |
| 2 | 説明 | 入力 | String | はい | - | 最大2000文字 | ストーリーの詳細説明 |
| 3 | 受入条件 | 入力 | String | はい | - | 最大2000文字 | 期待される振る舞い |
| 4 | 見積もり | 入力 | Integer | いいえ | - | 0以上 | 見積もり値 |
| 5 | 依存関係 | リンク | String | いいえ | - | - | 依存する項目一覧 |
| 6 | 関連ジャーニー | リンク | String | いいえ | - | - | 関連するユーザージャーニー |
| 7 | コメント | 入力 | String | いいえ | - | 最大1000文字 | コメント |
| 8 | 変更履歴 | 表示 | DateTime | はい | - | - | 最終更新日時 |
| 9 | ソース管理情報 | リンク | String | いいえ | - | - | 関連するコミット・ブランチ・PR |
| 10 | 業務ルール | 入力 | String | いいえ | - | 最大1000文字 | 業務上のルール |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
