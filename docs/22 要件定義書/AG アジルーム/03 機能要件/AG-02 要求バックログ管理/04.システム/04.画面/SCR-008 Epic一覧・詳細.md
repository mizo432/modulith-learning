# Epic一覧・詳細

Epic一覧・詳細画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-008 |
| 画面名           | Epic一覧・詳細 |
| 説明             | Epicの目的、成果、状態、関連Feature、リスクを管理する |
| 関連ユースケース | UC-BL-011 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、Epic総数、進行中数を表示 |
| 検索・フィルター | 状態、優先度で検索・絞り込み |
| メインコンテンツ | Epic一覧表または詳細情報を表示 |
| サイドバー | 状態別集計、関連Feature一覧を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Epic名 | 文字列 | はい | Epicの名前 |
| 2 | 目的 | テキスト | はい | Epicの目的 |
| 3 | 期待成果 | テキスト | いいえ | 期待される成果 |
| 4 | 状態 | 選択 | はい | 進捗状態（未着手、進行中、完了） |
| 5 | 優先度 | 選択 | いいえ | 優先度（高、中、低） |
| 6 | 関連Feature | 複数選択 | いいえ | 関連するFeature |
| 7 | リスク | テキスト | いいえ | 見込まれるリスク |
| 8 | 開始日 | 日付 | いいえ | 開始予定日 |
| 9 | 終了日 | 日付 | いいえ | 終了予定日 |
| 10 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | バックログ階層を設定 | Epic、Feature、Storyの階層関係を設定する |
| 2 | Epicを参照 | 登録されたEpicの一覧・詳細を確認する |
| 3 | 検索 | 条件に合致するEpicを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Epicの編集はプロダクトオーナーと開発チームのみ可能 |
| 2 | 階層の整合性 | Featureは必ずEpicに属しなければならない |
