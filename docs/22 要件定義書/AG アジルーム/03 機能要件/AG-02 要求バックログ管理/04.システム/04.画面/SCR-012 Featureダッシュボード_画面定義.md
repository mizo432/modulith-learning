# SCR-012 Featureダッシュボード画面

画面の詳細を定義します。

## 概要

| 項目             | 内容                                                     |
|------------------|----------------------------------------------------------|
| 画面ID           | SCR-012                                                  |
| 画面名           | Featureダッシュボード                                    |
| 説明             | Feature単位で価値の実現状況、開発進捗、品質、依存関係、リリース見通しを把握する画面 |
| 関連ユースケース | UC-BL-026, UC-BL-027, UC-BL-028, UC-BL-029              |

## 画面レイアウト

| 領域 | 説明                                                     |
|------|----------------------------------------------------------|
| ヘッダー | 画面タイトル、フィルタ条件入力エリア                     |
| 概要パネル | Feature全体の集計情報（総数、状態別カウント）           |
| Feature一覧 | Featureカード一覧（開発進捗、価値実現、提供準備の3つの区別表示） |
| 詳細パネル | 選択したFeatureの詳細情報（構成Story、依存関係、品質、リリース） |
| 依存関係図 | Feature間の依存関係を視覚的に表示                       |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明                                                     |
|------|--------|----|------|----------------------------------------------------------|
| 1    | Feature名 | String | 表示 | Featureの名前                                            |
| 2    | 状態 | Enum | 表示 | 準備中、開発中、検証中、提供準備完了、提供済み、保留中、取り消し |
| 3    | 優先順位 | Enum | 表示 | 高、中、低                                               |
| 4    | 開発進捗 | String | 表示 | 構成Storyの完了状況（例：5/10完了）                      |
| 5    | 価値実現状況 | String | 表示 | Feature Goalの達成状況                                   |
| 6    | 提供準備状況 | String | 表示 | テスト・品質・依存関係の準備状況                         |
| 7    | 担当者 | String | 表示 | Featureの担当者                                          |
| 8    | リリース予定 | Date | 表示 | 予定リリース日                                           |
| 9    | フィルタ状態 | Enum | 任意 | 状態でのフィルタ条件                                     |
| 10   | フィルタ優先順位 | Enum | 任意 | 優先順位でのフィルタ条件                                 |
| 11   | フィルタ担当者 | String | 任意 | 担当者でのフィルタ条件                                   |

## 画面操作

| 番号 | 操作名 | 説明                                                     |
|------|--------|----------------------------------------------------------|
| 1    | Feature選択 | Featureカードを選択して詳細パネルを表示                  |
| 2    | フィルタ適用 | フィルタ条件を適用してFeature一覧を絞り込む              |
| 3    | ソート | 状態、優先順位、日付などでソート                         |
| 4    | レポート出力 | Featureの進捗レポートを出力                              |
| 5    | 詳細画面遷移 | Featureの詳細画面へ遷移                                 |

## 制約事項

| 番号 | 制約事項 | 説明                                                     |
|------|----------|----------------------------------------------------------|
| 1    | 3つの区別表示 | 開発進捗、価値の実現状況、提供準備状況を区別して表示する必要がある |
| 2    | 進捗率の統合禁止 | 3つを1つの進捗率にまとめてはならない                       |
| 3    | リアルタイム更新 | バックログ項目の変更をリアルタイムで反映する               |
| 4    | 権限に応じた表示 | アクターの権限に応じて表示範囲を制限する                   |
