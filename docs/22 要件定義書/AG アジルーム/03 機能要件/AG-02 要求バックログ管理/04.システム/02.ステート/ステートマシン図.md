## 状態一覧

### バックログ項目

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーUC |
|--------|------|--------|--------|------------|
| 提案済み | チームメンバーやステークホルダーが作成した直後の状態（初期状態） | - | 受入済み, 凍結 | UC-BL-032 |
| 受入済み | SMまたはPOがチームのバックログとして受け入れた状態 | 提案済み | 準備完了 | UC-BL-032 |
| 凍結 | SMまたはPOが一時的に保留とした状態 | 提案済み | 提案済み | UC-BL-032 |
| 準備完了 | ACCEPTEDから遷移し、スプリント実行の準備が整った状態 | 受入済み | 提案済み, 見積もり済み | UC-BL-032 |
| 見積もり済み | READYから遷移し、ストーリーポイントが設定された状態 | 準備完了 | 準備完了 | UC-BL-032 |
| 進行中 | ESTIMATEDから遷移し、開発が進行中の状態 | 見積もり済み | 完了 | UC-BL-032 |
| 完了 | 終端状態。戻す遷移は設けない。分割で元項目がDONEになる遷移はUC-BL-010でトリガー（未実装） | 進行中 | - | UC-BL-032 |

### フィーチャー

| 状態名      | 説明                             | 遷移元      | 遷移先      | トリガーUC |
|-------------|----------------------------------|-------------|-------------|------------|
| Planned     | フィーチャーが計画された状態     | -           | In Progress | -          |
| In Progress | フィーチャーの開発が進行中の状態 | Planned     | Done        | -          |
| Done        | フィーチャーが完了した状態       | In Progress | -           | -          |

### 未決定一覧

| 状態名   | 説明                       | 遷移元 | 遷移先         | トリガーUC           |
|----------|----------------------------|--------|----------------|----------------------|
| 未決定   | 未決定事項が登録された状態 | -      | 決定済み, 却下 | UC-BL-029, UC-BL-030 |
| 決定済み | 未決定事項が決定された状態 | 未決定 | -              | UC-BL-029, UC-BL-030 |
| 却下     | 未決定事項が却下された状態 | 未決定 | -              | UC-BL-030            |
