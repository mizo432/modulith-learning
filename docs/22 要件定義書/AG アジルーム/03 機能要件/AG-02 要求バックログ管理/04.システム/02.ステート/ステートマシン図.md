# ステートマシン図

要求バックログ管理業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、AG-02 要求バックログ管理業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図（英語版）

```plantuml
@startuml
title Backlog Management State Model Diagram
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

' Backlog Item states
state "New" as New_BL <<entry>>
state "Clarifying" as Clarifying_BL
state "Refined" as Refined_BL
state "Implemented" as Implemented_BL <<exit>>
state "Rejected" as Rejected_BL <<exit>>

' Feedback states
state "New_FB" as New_FB <<entry>>
state "Categorized" as Categorized_FB
state "Addressed_FB" as Addressed_FB <<exit>>

' Backlog Item transitions
New_BL --> Clarifying_BL : Backlog Item Updated (UC-BL-008)
Clarifying_BL --> New_BL : Backlog Item Updated (UC-BL-008)
Clarifying_BL --> Refined_BL : Backlog Refinement (UC-BL-018)
Refined_BL --> Implemented_BL : Backlog Item Updated (UC-BL-008)
Refined_BL --> Rejected_BL : Backlog Item Updated (UC-BL-008)

' Feedback transitions
New_FB --> Categorized_FB : Feedback Updated (UC-BL-005)
Categorized_FB --> Addressed_FB : Feedback Updated (UC-BL-005)

' Story Map states
state "Draft" as Draft_SM <<entry>>
state "In Progress" as InProgress_SM
state "Published" as Published_SM <<exit>>

' Story Map transitions
Draft_SM --> InProgress_SM : Story Mapping Started (UC-BL-023)
InProgress_SM --> Draft_SM : Story Map Updated (UC-BL-023)
InProgress_SM --> Published_SM : Story Map Published (UC-BL-023)
Published_SM --> InProgress_SM : Story Map Republished (UC-BL-023)

' Story Status states
state "Frozen" as Frozen <<entry>>
state "Suggested" as Suggested
state "Accepted" as Accepted
state "Estimated" as Estimated
state "Planned" as Planned
state "In Progress" as InProgress_ST
state "In Review" as InReview
state "Done" as Done <<exit>>

' Story Status transitions
Frozen --> Suggested : Story Status Changed (UC-BL-026)
Suggested --> Accepted : Story Status Changed (UC-BL-026)
Suggested --> Frozen : Story Status Changed (UC-BL-026)
Accepted --> Estimated : Story Status Changed (UC-BL-026)
Estimated --> Planned : Story Status Changed (UC-BL-026)
Planned --> InProgress_ST : Story Status Changed (UC-BL-026)
InProgress_ST --> InReview : Story Status Changed (UC-BL-026)
InReview --> Done : Story Status Changed (UC-BL-026)
InReview --> InProgress_ST : Story Status Changed (UC-BL-026)
@enduml
```

## 4. 状態一覧

| 状態名 (ID)       | 英語名        | 対象情報     | 説明                                     |
|-------------------|---------------|--------------|------------------------------------------|
| 新規 (ST-BL-01)   | New           | バックログ項目 | 登録されたが、まだ明確化されていない   |
| 明確化中 (ST-BL-02) | Clarifying  | バックログ項目 | PO・開発者が内容を整理中               |
| リファイン済み (ST-BL-03) | Refined | バックログ項目 | 受入条件・分割・見積もりが整った       |
| 実装済み (ST-BL-04) | Implemented | バックログ項目 | 開発が完了し、インクリメントに含まれた |
| 却下 (ST-BL-05)   | Rejected      | バックログ項目 | 開発しないことが決定された             |
| 新規 (ST-BL-06)   | New           | フィードバック | 登録されたが、まだ分類されていない     |
| 分類済み (ST-BL-07) | Categorized | フィードバック | 種類・優先度が分類された               |
| 対応済み (ST-BL-08) | Addressed   | フィードバック | バックログ項目に変換または解決された   |
| 下書き (ST-BL-09)   | Draft         | Story Map    | 作成されたが、まだ編集されていない     |
| 編集中 (ST-BL-10)   | In Progress   | Story Map    | 現在編集中                             |
| 公開済み (ST-BL-11) | Published    | Story Map    | 公開されて共有中                       |
| Frozen (ST-BL-12)   | Frozen        | ストーリー   | ストーリーが凍結され、変更できない状態   |
| Suggested (ST-BL-13) | Suggested | ストーリー   | PO・SM・ステークホルダー・開発者がストーリーを提案した状態             |
| Accepted (ST-BL-14) | Accepted   | ストーリー   | 開発者が見積もり可能になった状態             |
| Estimated (ST-BL-15) | Estimated | ストーリー   | 開発者が見積もりを完了した状態           |
| Planned (ST-BL-16) | Planned     | ストーリー   | スプリントに計画された状態               |
| In Progress (ST-BL-17) | In Progress | ストーリー | 開発が進行中の状態                       |
| In Review (ST-BL-18) | In Review | ストーリー   | 開発が完了し、レビュー中の状態           |
| Done (ST-BL-19)   | Done          | ストーリー   | 全ての条件を満たし、完了した状態         |
