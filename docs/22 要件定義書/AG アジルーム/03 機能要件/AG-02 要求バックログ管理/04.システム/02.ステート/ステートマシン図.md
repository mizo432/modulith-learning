# ステートマシン図

バックログ管理の状態遷移をPlantUMLで視覚化します。

## バックログ項目の状態遷移

```plantuml
@startuml
skinparam state {
  BackgroundColor White
  BorderColor Black
  ArrowColor Black
}

state "新規" as New
state "明確化中" as Clarifying
state "準備完了" as Ready
state "実装中" as Implementing
state "完了" as Done

New --> Clarifying : UC-BL-007, UC-BL-008\nバックログ項目を作成/更新
Clarifying --> Ready : UC-BL-010, UC-BL-018\nリファインメント完了
Ready --> Implementing : UC-BL-012, UC-BL-013\n優先順位設定
Implementing --> Done : UC-BL-008\n実装完了

note right of New
  バックログ項目が
  作成された直後の状態
end note

note right of Clarifying
  項目の詳細が
  精査されている状態
end note

note right of Ready
  リファインメントが完了し、
  実装可能な状態
end note

note right of Implementing
  実装が進行中の状態
end note

note right of Done
  実装が完了した状態
end note
@enduml
```

## 状態一覧

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーUC |
|--------|------|--------|--------|-----------|
| 新規 | 項目が作成された直後の状態 | - | 明確化中 | UC-BL-007, UC-BL-008 |
| 明確化中 | 項目の詳細が精査されている状態 | 新規 | 準備完了 | UC-BL-010, UC-BL-018 |
| 準備完了 | リファインメントが完了し、実装可能な状態 | 明確化中 | 実装中 | UC-BL-012, UC-BL-013 |
| 実装中 | 実装が進行中の状態 | 準備完了 | 完了 | UC-BL-008 |
| 完了 | 実装が完了した状態 | 実装中 | - | - |
