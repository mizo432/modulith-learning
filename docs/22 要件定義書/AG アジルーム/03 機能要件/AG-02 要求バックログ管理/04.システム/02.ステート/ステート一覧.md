# ステート一覧

要求バックログ管理業務領域で扱う状態を定義します。

## 一覧

| ID       | 状態名         | 対象情報       | 説明                                   |
|----------|----------------|----------------|----------------------------------------|
| ST-BL-01 | 新規           | バックログ項目 | 登録されたが、まだ明確化されていない   |
| ST-BL-02 | 明確化中       | バックログ項目 | PO・開発者が内容を整理中               |
| ST-BL-03 | リファイン済み | バックログ項目 | 受入条件・分割・見積もりが整った       |
| ST-BL-04 | 実装済み       | バックログ項目 | 開発が完了し、インクリメントに含まれた |
| ST-BL-05 | 却下           | バックログ項目 | 開発しないことが決定された             |
| ST-BL-06 | 新規           | フィードバック | 登録されたが、まだ分類されていない     |
| ST-BL-07 | 分類済み       | フィードバック | 種類・優先度が分類された               |
| ST-BL-08 | 対応済み       | フィードバック | バックログ項目に変換または解決された   |
| ST-BL-09 | 下書き         | Story Map  | 作成されたが、まだ編集されていない     |
| ST-BL-10 | 編集中         | Story Map  | 現在編集中                             |
| ST-BL-11 | 公開済み       | Story Map  | 公開されて共有中                       |
