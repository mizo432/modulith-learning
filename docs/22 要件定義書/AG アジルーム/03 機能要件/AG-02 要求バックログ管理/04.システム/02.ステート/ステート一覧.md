# ステート一覧

要求バックログ管理業務領域で扱う状態を定義します。

| ID       | 状態名      | 対象情報       | 説明                                                       |
|----------|-------------|----------------|------------------------------------------------------------|
| ST-BL-01 | 新規        | バックログ項目 | 登録されたが、まだ明確化されていない                       |

| ST-BL-03 | 準備完了    | バックログ項目 | リファインメントが完了し、実装可能な状態                   |

| ST-BL-05 | 完了        | バックログ項目 | 実装が完了した状態                                         |
| ST-BL-06 | 新規        | フィードバック | 登録されたが、まだ分類されていない                         |
| ST-BL-07 | 分類済み    | フィードバック | 種類・優先度が分類された                                   |
| ST-BL-08 | 対応済み    | フィードバック | バックログ項目に変換または解決された                       |
| ST-BL-09 | 下書き      | Story Map      | 作成されたが、まだ編集されていない                         |
| ST-BL-10 | 編集中      | Story Map      | 現在編集中                                                 |

| ST-BL-12 | Frozen      | ストーリー     | ストーリーが凍結され、変更できない状態                     |
| ST-BL-13 | Suggested   | ストーリー     | PO・SM・ステークホルダー・開発者がストーリーを提案した状態 |
| ST-BL-14 | Accepted    | ストーリー     | 開発者が見積もり可能になった状態                           |
| ST-BL-15 | Ready       | ストーリー     | 開発者が見積もりを行う準備が完了した状態                   |
| ST-BL-16 | Estimated   | ストーリー     | 開発者が見積もりを完了した状態                             |
| ST-BL-17 | Planned     | ストーリー     | スプリントに計画された状態                                 |

| ST-BL-19 | In Review   | ストーリー     | 開発が完了し、レビュー中の状態                             |
| ST-BL-20 | Done        | ストーリー     | 全ての条件を満たし、完了した状態                           |
| ST-BL-21 | Planned     | フィーチャー   | フィーチャーが計画された状態                               |
| ST-BL-22 | In Progress | フィーチャー   | フィーチャーの開発が進行中の状態                           |
| ST-BL-23 | Done        | フィーチャー   | フィーチャーが完了した状態                                 |
| ST-BL-24 | 未決定      | 未決定一覧     | 未決定事項が登録された状態                                 |
| ST-BL-25 | 決定済み    | 未決定一覧     | 未決定事項が決定された状態                                 |
| ST-BL-26 | 却下        | 未決定一覧     | 未決定事項が却下された状態                                 |
