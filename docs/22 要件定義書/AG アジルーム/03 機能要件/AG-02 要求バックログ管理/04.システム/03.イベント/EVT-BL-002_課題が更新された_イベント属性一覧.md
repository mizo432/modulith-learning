# イベント属性一覧

課題が更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-002 |
| イベント名 | 課題が更新された |
| 説明 | 既存課題の詳細・影響・状態が修正された |
| 関連ユースケース | UC-BL-002 |
| 発生元 | システム内部 |

## イベント属性一覧

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | - | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 課題ID | String | はい | - | - | 更新された課題の識別子 |
| 4 | 更新内容 | Text | はい | - | - | 更新された内容 |
| 5 | 更新者 | String | はい | - | - | 更新したユーザー |

## イベントトリガー

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 課題更新完了 | システム内部 | 課題が更新されたとき | 課題の更新完了時に発生 |

## イベントペイロード

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | issueId | String | はい | 課題の識別子 |
| 2 | updatedContent | Text | はい | 更新内容 |
| 3 | updater | String | はい | 更新者 |
| 4 | timestamp | DateTime | はい | 発生日時 |

## 関連情報

| 情報ID | 情報名 | 操作種類 | 説明 |
|--------|--------|----------|------|
| INF-BL-12 | 課題 | 更新 | 課題を更新 |

## 関連イベント

| 関連イベントID | 関連イベント名 | 関係の種類 | 説明 |
|----------------|----------------|------------|------|
| EVT-BL-001 | 課題が登録された | 前駆 | 課題登録後に更新可能 |
