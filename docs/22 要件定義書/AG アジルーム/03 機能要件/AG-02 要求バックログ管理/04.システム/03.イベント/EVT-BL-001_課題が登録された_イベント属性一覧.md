# イベント属性一覧

課題が登録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-001 |
| イベント名 | 課題が登録された |
| 説明 | 新規課題がシステムに記録された |
| 関連ユースケース | UC-BL-001 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | - | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | タイトル | String | はい | - | 最大255文字 | 課題のタイトル |
| 4 | 内容 | Text | はい | - | - | 詳細な内容 |
| 5 | 優先度 | Enum | いいえ | - | 高/中/低 | 優先度 |
| 6 | 状態 | Enum | はい | - | - | 処理状態 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 課題登録完了 | システム内部 | 課題が登録されたとき | 新規課題の登録完了時に発生 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | issueId | String | はい | 課題の識別子 |
| 2 | title | String | はい | 課題のタイトル |
| 3 | content | Text | はい | 詳細な内容 |
| 4 | priority | Enum | いいえ | 優先度 |
| 5 | status | Enum | はい | 処理状態 |
| 6 | timestamp | DateTime | はい | 発生日時 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 課題登録 | 新規課題を記録する | UC-BL-001 | 課題をシステムに記録する |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | タイトルの文字数 | タイトル | 文字数 <= 255 | タイトルは255文字以内 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | タイトルの必須チェック | タイトル | 空でないこと | タイトルは必須です |

## 関連情報

|--------|--------|----------|------|
| INF-BL-12 | 課題 | 更新 | 新規課題を登録 |
