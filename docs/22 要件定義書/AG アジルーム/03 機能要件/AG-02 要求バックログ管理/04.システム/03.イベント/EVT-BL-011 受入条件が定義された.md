## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-011 |
| イベント名 | 受入条件が定義された |
| 説明 | 期待される振る舞いや境界条件が定義された |
| 関連ユースケース | UC-BL-015 |
| 関連情報 | INF-BL-02 |
