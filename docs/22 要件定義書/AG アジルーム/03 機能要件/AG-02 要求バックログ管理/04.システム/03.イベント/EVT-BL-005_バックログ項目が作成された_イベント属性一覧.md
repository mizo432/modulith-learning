# イベント属性一覧

バックログ項目が作成されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-005 |
| イベント名 | バックログ項目が作成された |
| 説明 | Epic・Feature・Storyなどのバックログ項目が登録された |
| 関連ユースケース | UC-BL-007 |
| 発生元 | システム内部 |

## イベント属性一覧

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | ID | String | はい | - | - | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | 項目ID | String | はい | - | - | バックログ項目の識別子 |
| 4 | 種別 | Enum | はい | - | - | 項目の種別 |
| 5 | タイトル | String | はい | - | - | 項目のタイトル |

## イベントトリガー

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 項目作成完了 | システム内部 | バックログ項目が作成されたとき | 項目作成完了時に発生 |
