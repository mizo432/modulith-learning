# EVT-BL-001 課題が登録された

## 概要

新規課題がシステムに記録されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                               |
|------------------|--------------------------------------------------|
| イベントID       | EVT-BL-001                                       |
| イベント名       | 課題が登録された                                 |
| 英語名           | `IssueRegistered`                                |
| 集約             | バックログ項目 (BacklogItem)                     |
| 関連ユースケース | UC-BL-001 課題を登録する                         |
| 関連情報         | INF-BL-03 フィードバック                         |
| 発生条件         | 従業員が課題、要望、利用場面、影響を登録したとき |

## イベントペイロード

| プロパティ      | 型             | 必須 | 説明                             |
|-----------------|----------------|------|----------------------------------|
| `eventId`       | UUID           | ✓   | イベントを一意に識別するID       |
| `occurredAt`    | LocalDateTime  | ✓   | イベントが発生した時刻           |
| `aggregateId`   | String         | ✓   | 関連する集約ルートのID           |
| `aggregateType` | String         | ✓   | "BacklogItem"                    |
| `version`       | int            | ✓   | 集約のバージョン                 |
| `issueId`       | String         | ✓   | 課題の一意な識別子               |
| `title`         | String         | ✓   | 課題のタイトル                   |
| `description`   | String         | ✓   | 課題の詳細説明                   |
| `type`          | String         | ✓   | 課題種別（要望、利用場面、影響） |
| `registeredBy`  | String         | ✓   | 登録者のアクターID               |
| `priority`      | String         | ✗   | 優先度                           |
| `tags`          | List\<String\> | ✗   | タグリスト                       |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-BL-002 課題が更新された     | 更新時に発生                 |
| EVT-BL-012 コメントが投稿された | 関連するコメント追加時に発生 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.backlog.backlogMgmt.spi.backlogItem.event.IssueRegistered`
