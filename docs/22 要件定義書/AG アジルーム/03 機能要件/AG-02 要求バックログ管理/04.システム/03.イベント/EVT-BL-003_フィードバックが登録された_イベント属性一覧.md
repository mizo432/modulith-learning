# イベント属性一覧

フィードバックが登録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-003 |
| イベント名 | フィードバックが登録された |
| 説明 | 利用者からの意見・評価が記録された |
| 関連ユースケース | UC-BL-004 |
| 発生元 | システム内部 |

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |

| 1 | ID | String | はい | - | - | イベントの一意な識別子 |
| 2 | 発生日時 | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | フィードバックID | String | はい | - | - | フィードバックの識別子 |
| 4 | 内容 | Text | はい | - | - | フィードバックの内容 |
| 5 | カテゴリ | Enum | いいえ | - | - | フィードバックのカテゴリ |
