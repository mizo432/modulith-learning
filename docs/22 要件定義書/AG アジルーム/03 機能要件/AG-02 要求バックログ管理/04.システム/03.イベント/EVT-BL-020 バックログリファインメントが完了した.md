| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-020 |
| イベント名 | バックログリファインメントが完了した |
| 説明 | 項目の説明・分割・受入条件・依存関係・準備状況が整えられた |
| 関連ユースケース | UC-BL-018 |

| 項目名 | 型 | 必須 | 説明 |
