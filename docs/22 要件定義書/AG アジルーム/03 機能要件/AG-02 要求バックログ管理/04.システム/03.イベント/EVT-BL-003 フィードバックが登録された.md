| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-003 |
| イベント名 | フィードバックが登録された |
| 説明 | 利用者からの意見・評価が記録された |
| 関連ユースケース | UC-BL-004 |
| 関連情報 | INF-BL-03 |
