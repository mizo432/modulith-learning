| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-012 |
| イベント名 | コメントが投稿された |
| 説明 | 項目上で質問、回答、議論が行われた |
| 関連ユースケース | UC-BL-016 |
| 関連情報 | INF-BL-04 |
