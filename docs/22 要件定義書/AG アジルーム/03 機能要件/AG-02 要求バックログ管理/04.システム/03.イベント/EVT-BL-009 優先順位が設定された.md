# 優先順位が設定された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-BL-009 |
| イベント名 | 優先順位が設定された |
| 説明 | 項目の順序・優先理由が設定された |
| 関連ユースケース | UC-BL-012 |
| 関連情報 | INF-BL-01 |
| 集約 | バックログ項目 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 項目 | 文字列 | はい | 優先順位を設定した項目 |
| 優先順位 | 数値 | はい | 設定された優先順位 |
| 優先理由 | テキスト | いいえ | 優先順位の理由 |
