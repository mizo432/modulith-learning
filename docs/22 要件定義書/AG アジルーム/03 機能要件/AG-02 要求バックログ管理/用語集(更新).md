# 用語集

## 概要

本ドキュメントは、要求バックログ管理業務領域（AG-02）で扱う用語を定義します。

## 用語一覧

| 番号 | 用語 | 英名 | 英名複数形 | 用語分類 | 定義 |
|------|------|------|------------|----------|------|
| 1 | Featureダッシュボード | Feature Dashboard | Feature Dashboards | システム用語 | Feature単位で価値の実現状況、開発進捗、品質、依存関係、リリース見通しを把握する画面 |
| 2 | 開発進捗 | Development Progress | Development Progresses | システム用語 | User Storyがどこまで完了したかを表す指標 |
| 3 | 価値の実現状況 | Value Realization Status | Value Realization Statuses | システム用語 | Feature Goalや期待する成果が実現できているかを表す指標 |
| 4 | 提供準備状況 | Release Readiness Status | Release Readiness Statuses | システム用語 | テスト、品質、依存関係などを満たし、Releaseに含められるかを表す指標 |
| 5 | Feature Goal | Feature Goal | Feature Goals | ビジネス用語 | Featureとして実現したい価値の目標 |
| 6 | Feature | Feature | Features | ビジネス用語 | 複数のUser Storyで構成され、複数のSprintにまたがって開発される機能単位 |
| 7 | User Story | User Story | User Stories | ビジネス用語 | ユーザーが得られる価値を記述した小さな作業単位 |
| 8 | リリース見通し | Release Outlook | Release Outlooks | ビジネス用語 | Featureがいつリリースされるかの予測と準備状況 |
| 9 | 依存関係 | Dependency | Dependencies | ビジネス用語 | FeatureやStory間の前後関係や制約関係 |
| 10 | 阻害要因 | Impediment | Impediments | ビジネス用語 | Featureの開発を妨げている要因 |
