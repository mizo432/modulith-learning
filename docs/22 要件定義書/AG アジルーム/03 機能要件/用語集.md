# 用語集

Agiloomで使用するビジネス用語とシステム用語を定義します。

## ビジネス用語

| ID     | 用語                       | 説明                                                                   | 出典レイヤー |
|--------|----------------------------|------------------------------------------------------------------------|--------------|
| BT-001 | プロダクトビジョン         | プロダクトの対象者、課題、目指す将来像を定義する文書                   | システム境界 |
| BT-002 | プロダクトゴール           | プロダクトが達成すべき目標。期間と状態を持つ                           | システム境界 |
| BT-003 | 課題                       | 業務上の困りごとや繰り返し発生する問題                                 | システム境界 |
| BT-004 | 要望                       | 顧客や利用者から受けた意見・提案                                       | システム境界 |
| BT-005 | 仮説                       | 課題に対する検証可能な仮説と検証方法                                   | システム境界 |
| BT-006 | ステークホルダー           | プロダクトに関わる関係者、関心事、影響範囲                             | システム境界 |
| BT-007 | ペルソナ                   | ユーザー像、ニーズ、利用状況を定義したモデル                           | システム境界 |
| BT-008 | ユーザージャーニー         | 利用者の行動、課題、感情、機会を可視化した図                           | システム境界 |
| BT-009 | 成功指標                   | プロダクトの成功を測定するための指標                                   | システム境界 |
| BT-010 | Kano評価                   | 要望を品質カテゴリ（当たり前・一元・魅力的・無関心・逆）に分類する手法 | システム境界 |
| BT-011 | バックログ                 | 実装予定の項目のリスト。優先順位付けされる                             | システム境界 |
| BT-012 | Epic                       | 大規模なバックログ項目。複数のFeatureに分割される                      | システム境界 |
| BT-013 | Feature                    | Epicより小さくStoryより大きなバックログ項目                            | システム境界 |
| BT-014 | Story                      | 利用者価値を提供する最小単位のバックログ項目                           | システム境界 |
| BT-015 | 受入条件                   | バックログ項目が完了したと判断するための条件                           | システム境界 |
| BT-016 | バックログリファインメント | バックログ項目の内容を明確化・分割・見積もりする活動                   | システム境界 |
| BT-017 | Story Mapping              | ユーザー活動とストーリーを並べ、リリース範囲を検討する手法             | システム境界 |
| BT-018 | スプリント                 | 固定期間の開発イテレーション                                           | システム境界 |
| BT-019 | Sprint Goal                | スプリントで達成すべき目的                                             | システム境界 |
| BT-020 | Sprint Backlog             | スプリントで実行する作業のリスト                                       | システム境界 |
| BT-021 | インクリメント             | スプリントで完成した利用可能な成果物                                   | システム境界 |
| BT-022 | Definition of Done         | チームが「完了」と判断するための基準                                   | システム境界 |
| BT-023 | デイリースクラム           | 毎日行う進捗確認と計画調整のミーティング                               | システム境界 |
| BT-024 | 障害                       | 作業を阻害する要因                                                     | システム境界 |
| BT-025 | Sprint Review              | スプリント終了時に成果を確認し、フィードバックを収集するミーティング   | システム境界 |
| BT-026 | Sprint Retrospective       | スプリントの進め方を振り返り、改善点を整理するミーティング             | システム境界 |
| BT-027 | 改善アクション             | Retrospectiveで決定した改善施策                                        | システム境界 |
| BT-028 | 欠陥                       | 製品の不具合やバグ                                                     | システム境界 |
| BT-029 | テストケース               | 期待される振る舞いを検証するための手順と条件                           | システム境界 |
| BT-030 | 受入テスト                 | 業務シナリオに沿って期待結果を確認するテスト                           | システム境界 |
| BT-031 | 性能テスト                 | システムの性能要件を満たすか検証するテスト                             | システム境界 |
| BT-032 | 利用者レビュー             | 対象者に製品を試してもらい、フィードバックを収集する活動               | システム境界 |
| BT-033 | 成果指標                   | リリース後の利用状況や効果を測定する指標                               | システム境界 |
| BT-034 | リスク                     | プロジェクトに影響を与える可能性のある事象                             | システム境界 |
| BT-035 | 判断待ち                   | 決定が必要な事項                                                       | システム境界 |
| BT-036 | フィードバック             | 利用者からの意見・評価                                                 | システム境界 |
| BT-037 | 見積もり                   | 作業の規模や期間の推定値                                               | システム境界 |
| BT-038 | 依存関係                   | 作業や項目間の前後関係                                                 | システム境界 |
| BT-039 | 実験計画                   | 仮説を検証するための計画                                               | システム境界 |
| BT-040 | 意思決定                   | 決定内容、根拠、決定者、影響範囲を記録した文書                         | システム境界 |
