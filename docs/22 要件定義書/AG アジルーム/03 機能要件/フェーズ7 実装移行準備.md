# フェーズ7 実装移行準備

AG-01, AG-02, AG-06の3業務領域のRDRAモデルとDDDモデル候補に基づき、実装への移行準備を行います。

## 確認概要

| 項目 | 内容 |
|------|------|
| 確認日 | 2026-10-30 |
| 確認結果 | **合格** |
| チェッカー | Junie |

## 1. 実装移行準備の目的

要件定義フェーズで完成したRDRAモデルとDDDモデル候補を基に、以下の実装移行に必要な情報を整理します：

1. **モジュール境界の定義**: バックエンドモジュール構成とDDDバウンデッドコンテキストのマッピング
2. **レイヤー構成**: 各モジュール内のレイヤー構成（オニオンアーキテクチャ）
3. **モジュール間依存関係**: Spring Modulithのモジュール間依存ルール
4. **共通基盤の定義**: 横断的に利用する共通コンポーネント
5. **実装優先順位**: MVPから拡張までの段階的な実装計画

## 2. モジュール境界の定義

### 2.1 バックエンドモジュール構成

フェーズ6で抽出した14個のバウンデッドコンテキストを、実装可能なモジュールにグループ化します。

| モジュールID | モジュール名 | 包含するバウンデッドコンテキスト | 業務領域 |
|-------------|-------------|-------------------------------|---------|
| MOD-01 | product-discovery | Product Vision Context, Problem Discovery Context, Hypothesis Testing Context, User Understanding Context, Kano Evaluation Context | AG-01 |
| MOD-02 | backlog-management | Backlog Management Context, Feedback Management Context, Discussion Context, Traceability Context | AG-02 |
| MOD-03 | sprint-review | Sprint Review Context, Retrospective Context | AG-06 |
| MOD-04 | monitoring | Monitoring Context, User Review Context, Outcome Measurement Context | AG-06 |
| MOD-05 | shared-kernel | UserProblem, Feedback (共通エンティティ) | AG-01, AG-02 横断 |
| MOD-06 | shared-common | 共通基盤（既存のmizo432-shared-common） | 横断 |

### 2.3 モジュール間依存ルール

| 番号 | ルール | 説明 |
|------|--------|------|
| 1 | shared-commonは他のモジュールに依存しない | 共通基盤として独立 |
| 2 | shared-kernelはshared-commonのみ依存 | 共通エンティティの基盤 |
| 3 | product-discoveryはshared-kernelとshared-common依存 | 課題・フィードバックを共有 |
| 4 | backlog-managementはshared-kernelとshared-common依存 | フィードバックを共有 |
| 5 | sprint-reviewはshared-commonのみ依存 | 独立したモジュール |
| 6 | monitoringはshared-commonのみ依存 | 独立したモジュール |
| 7 | モジュール間はドメインイベントで連携 | 直接依存を最小化 |

## 3. レイヤー構成

各モジュールはSpring Modulith + jMoleculesに基づくオニオンアーキテクチャを採用します。

### 3.1 標準的なレイヤー構成

```
modulith-learning/
└── backend/
    └── src/main/java/undecided/
        └── {module-name}/          # モジュールディレクトリ
            ├── internal/            # 内部実装層
            │   ├── command/         # コマンドハンドラー
            │   ├── query/           # クエリハンドラー
            │   ├── repository/      # リポジトリ実装
            │   ├── service/         # ドメインサービス
            │   └── entity/          # エンティティ実装
            └── spi/                 # Service Provider Interface
                ├── {entity}/        # エンティティ定義
                │   ├── dto/         # DTO
                │   └── repository/  # リポジトリインターフェース
                └── event/           # ドメインイベント
```

## 4. 共通基盤の定義

### 4.1 shared-common モジュール (MOD-06)

既存の`mizo432-shared-common`を拡張して、以下の共通コンポーネントを提供します：

| コンポーネント | 説明 | 既存ファイル |
|---------------|------|-------------|
| エンティティ基盤 | BusinessEntity, ThingEntity, RoleEntity等 | com.github.mizo432.shared.entity |
| 例外処理 | BusinessException, SystemException等 | com.github.mizo432.shared.exception |
| メッセージ | ResultMessage, ResultMessages | com.github.mizo432.shared.message |
| ロギング | ExceptionLogger, LogIdBasedLogger | com.github.mizo432.shared.logging |
| 変換器 | EnumConverter, EncryptedStringConverter | com.github.mizo432.shared.converter |

| Feedback | フィードバック | AG-01, AG-02 |

## 5. ドメインイベントの標準化

### 5.1 イベントフォーマット

すべてのドメインイベントは以下のインターフェースを実装します：

```java
public interface DomainEvent {
    UUID eventId();
    Instant occurredOn();
    String aggregateId();
    String aggregateType();
}
```
