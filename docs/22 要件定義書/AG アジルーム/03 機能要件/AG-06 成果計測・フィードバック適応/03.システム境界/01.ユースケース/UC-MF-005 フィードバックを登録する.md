# UC-MF-005 フィードバックを登録する

## 概要

利用者からのフィードバックを登録する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-005 |
| ユースケース名 | フィードバックを登録する |
| 関連BUC | BUC-MF-02 |
| 関連アクター | ACT-01, ACT-02 |
| 外部システム | なし |
| 関連情報 | INF-MF-02 (フィードバック), INF-MF-13 (フィードバック種別) |
| 関連画面 | SCR-MF-04 (フィードバック登録画面) |

## 前提条件

- なし

## 基本フロー

1. アクターはフィードバックの内容を入力する
2. アクターはフィードバックの種別を選択する
3. アクターは関連するバックログ項目を指定する（任意）
4. システムはフィードバックを「未対応」状態で保存する

## 結果

フィードバックが登録され、状態が「未対応」になる。
