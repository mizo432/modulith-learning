# UC-MF-017 成果指標を測定する

## 概要

定義した成果指標の測定値を記録する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-017 |
| ユースケース名 | 成果指標を測定する |
| 関連BUC | BUC-MF-06 |
| 関連アクター | ACT-02, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-MF-07 (成果指標), INF-MF-08 (指標測定値) |
| 関連画面 | SCR-MF-14 (指標測定画面) |

## 前提条件

- 成果指標が定義されている

## 基本フロー

1. システムは定義済みの成果指標を一覧表示する
2. アクターは測定対象の指標を選択する
3. アクターは測定値を入力する
4. システムは測定値を保存する

## 結果

成果指標の測定値が記録される。
