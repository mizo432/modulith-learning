# UC-MF-013 ダッシュボードを表示する

## 概要

ロールに応じたダッシュボードを表示する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-013 |
| ユースケース名 | ダッシュボードを表示する |
| 関連BUC | BUC-MF-05 |
| 関連アクター | ACT-01, ACT-02, ACT-03, ACT-04, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-MF-11 (ダッシュボード設定) |
| 関連画面 | SCR-MF-10 (ダッシュボード画面) |

## 前提条件

- なし

## 基本フロー

1. システムはログインユーザーのロールを確認する
2. システムはロールに応じたダッシュボードを表示する
3. アクターはフィルタ条件を入力する
4. システムは条件に一致する情報を表示する

## 結果

ロールに応じた情報がダッシュボードで表示される。
