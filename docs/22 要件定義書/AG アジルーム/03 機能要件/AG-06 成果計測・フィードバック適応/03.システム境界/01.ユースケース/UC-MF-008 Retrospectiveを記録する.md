# UC-MF-008 Retrospectiveを記録する

## 概要

Sprint Retrospectiveで得られた学び、改善候補、決定事項を記録する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-008 |
| ユースケース名 | Retrospectiveを記録する |
| 関連BUC | BUC-MF-03 |
| 関連アクター | ACT-02, ACT-03, ACT-04 |
| 外部システム | なし |
| 関連情報 | INF-MF-04 (Retrospective) |
| 関連画面 | SCR-MF-06 (Retrospective記録画面) |

## 前提条件

- Sprintが完了している

## 基本フロー

1. アクターはSprintを選択する
2. アクターは良かった点を記録する
3. アクターは改善すべき点を記録する
4. アクターは学びを記録する
5. アクターは決定事項を記録する
6. システムはRetrospective情報を保存する

## 結果

Retrospectiveの記録が保存される。
