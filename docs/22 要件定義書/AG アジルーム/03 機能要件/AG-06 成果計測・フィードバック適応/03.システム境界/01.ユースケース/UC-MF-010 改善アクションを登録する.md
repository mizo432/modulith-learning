# UC-MF-010 改善アクションを登録する

## 概要

Retrospectiveで策定した改善アクションを登録する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-010 |
| ユースケース名 | 改善アクションを登録する |
| 関連BUC | BUC-MF-04 |
| 関連アクター | ACT-02, ACT-03, ACT-04 |
| 外部システム | なし |
| 関連情報 | INF-MF-05 (改善アクション), INF-MF-14 (改善カテゴリ) |
| 関連画面 | SCR-MF-08 (改善アクション登録画面) |

## 前提条件

- なし

## 基本フロー

1. アクターは改善アクションの内容を入力する
2. アクターは改善カテゴリを選択する
3. アクターは担当者を指定する
4. アクターは期限を設定する
5. システムは改善アクションを「未着手」状態で保存する

## 結果

改善アクションが登録され、状態が「未着手」になる。
