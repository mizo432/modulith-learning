# UC-MF-002 Sprint Reviewを実施する

## 概要

Sprint Reviewを開催し、成果をデモしてフィードバックを収集する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-002 |
| ユースケース名 | Sprint Reviewを実施する |
| 関連BUC | BUC-MF-01 |
| 関連アクター | ACT-01, ACT-02, ACT-03, ACT-04 |
| 外部システム | なし |
| 関連情報 | INF-MF-01 (Sprint Review), INF-MF-02 (フィードバック) |
| 関連画面 | SCR-MF-02 (Sprint Review実施画面) |

## 前提条件

- Sprint Reviewが準備されている

## 基本フロー

1. システムはSprint Reviewの準備情報を表示する
2. アクターはSprint Goalと達成状況を確認する
3. アクターは完了した成果をデモする
4. 従業員はフィードバックを入力する
5. システムはフィードバックを保存する
6. アクターはSprint Reviewの状態を「開催中」にする

## 結果

Sprint Reviewが開催され、フィードバックが収集される。
