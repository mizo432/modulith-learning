# UC-MF-015 リスク・判断待ちを管理する

## 概要

リスクと判断待ち事項を登録・更新・確認する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-015 |
| ユースケース名 | リスク・判断待ちを管理する |
| 関連BUC | BUC-MF-05 |
| 関連アクター | ACT-02, ACT-03, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-MF-09 (リスク), INF-MF-10 (判断待ち) |
| 関連画面 | SCR-MF-12 (リスク・判断待ち一覧画面) |

## 前提条件

- なし

## 基本フロー

1. システムはリスク・判断待ちの一覧を表示する
2. アクターは新規リスクを登録する
3. アクターはリスクの状態を更新する
4. アクターは判断待ち事項を登録する
5. アクターは判断待ちの状態を更新する

## 結果

リスク・判断待ちが管理できる。
