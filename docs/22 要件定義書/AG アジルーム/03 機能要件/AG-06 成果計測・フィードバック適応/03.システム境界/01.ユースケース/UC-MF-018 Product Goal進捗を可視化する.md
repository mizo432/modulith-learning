# UC-MF-018 Product Goal進捗を可視化する

## 概要

成果指標とバックログ・リリースの関係を可視化し、Product Goalの進捗を確認する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-018 |
| ユースケース名 | Product Goal進捗を可視化する |
| 関連BUC | BUC-MF-06 |
| 関連アクター | ACT-02, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-MF-07 (成果指標), INF-MF-08 (指標測定値) |
| 関連画面 | SCR-MF-15 (Product Goal進捗画面) |

## 前提条件

- Product Goalが設定されている
- 成果指標が定義されている

## 基本フロー

1. システムはProduct Goalの一覧を表示する
2. アクターは対象のProduct Goalを選択する
3. システムは関連する成果指標の測定値を表示する
4. システムはバックログ・リリースとの関連を表示する
5. アクターは進捗状況を確認する

## 結果

Product Goalの進捗が可視化され、確認できる。
