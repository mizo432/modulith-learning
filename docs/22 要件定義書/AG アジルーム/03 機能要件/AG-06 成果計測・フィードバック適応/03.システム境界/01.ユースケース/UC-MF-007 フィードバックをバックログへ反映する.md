# UC-MF-007 フィードバックをバックログへ反映する

## 概要

評価済みのフィードバックをバックログ項目として反映する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-007 |
| ユースケース名 | フィードバックをバックログへ反映する |
| 関連BUC | BUC-MF-02 |
| 関連アクター | ACT-02 |
| 外部システム | なし |
| 関連情報 | INF-MF-02 (フィードバック), INF-MF-03 (フィードバック対応) |
| 関連画面 | SCR-MF-05 (フィードバック評価画面) |

## 前提条件

- フィードバックが評価済みである

## 基本フロー

1. アクターはバックログ候補のフィードバックを選択する
2. アクターはバックログ項目を作成する
3. システムはフィードバックとバックログ項目の対応関係を記録する
4. システムはフィードバックの状態を「対応済み」にする

## 結果

フィードバックがバックログ項目として反映され、対応関係が記録される。
