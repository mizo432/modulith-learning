# UC-MF-012 改善効果を確認する

## 概要

改善アクションが完了した後、その効果を確認する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-012 |
| ユースケース名 | 改善効果を確認する |
| 関連BUC | BUC-MF-04 |
| 関連アクター | ACT-02, ACT-03, ACT-04 |
| 外部システム | なし |
| 関連情報 | INF-MF-05 (改善アクション) |
| 関連画面 | SCR-MF-09 (改善アクション管理画面) |

## 前提条件

- 改善アクションが完了している

## 基本フロー

1. システムは完了した改善アクションを一覧表示する
2. アクターは対象の改善アクションを選択する
3. アクターは改善効果を記録する
4. システムは改善アクションに効果情報を保存する

## 結果

改善アクションの効果を確認・記録できる。
