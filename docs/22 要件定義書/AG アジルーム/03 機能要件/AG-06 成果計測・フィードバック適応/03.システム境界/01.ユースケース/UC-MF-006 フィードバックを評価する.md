# UC-MF-006 フィードバックを評価する

## 概要

収集したフィードバックを評価し、対応方針を決定する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-006 |
| ユースケース名 | フィードバックを評価する |
| 関連BUC | BUC-MF-02 |
| 関連アクター | ACT-02 |
| 外部システム | なし |
| 関連情報 | INF-MF-02 (フィードバック) |
| 関連画面 | SCR-MF-05 (フィードバック評価画面) |

## 前提条件

- フィードバックが登録されている

## 基本フロー

1. システムは未対応のフィードバックを一覧表示する
2. アクターはフィードバックの詳細を確認する
3. アクターは対応方針を選択する（バックログ候補、保留、却下）
4. アクターは判断理由を記録する
5. システムはフィードバックの状態を更新する

## 結果

フィードバックが評価され、対応方針が記録される。
