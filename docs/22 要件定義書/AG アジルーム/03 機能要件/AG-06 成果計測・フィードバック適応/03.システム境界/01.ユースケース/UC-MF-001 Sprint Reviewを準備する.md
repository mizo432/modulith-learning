# UC-MF-001 Sprint Reviewを準備する

## 概要

Sprint Reviewを開催する前に、Sprint Goal、完了した成果、デモ対象、参加者、議題を準備する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-001 |
| ユースケース名 | Sprint Reviewを準備する |
| 関連BUC | BUC-MF-01 |
| 関連アクター | ACT-02, ACT-03 |
| 外部システム | なし |
| 関連情報 | INF-MF-01 (Sprint Review) |
| 関連画面 | SCR-MF-01 (Sprint Review準備画面) |

## 前提条件

- Sprintが進行中である
- Sprint Goalが設定されている

## 基本フロー

1. システムはSprintの情報を表示する
2. アクターはSprint Goalを確認する
3. アクターは完了した成果を選択する
4. アクターはデモ対象を設定する
5. アクターは参加者を指定する
6. アクターは議題を追加する
7. システムはSprint Review情報を「準備中」状態で保存する

## 結果

Sprint Reviewが準備され、状態が「準備中」になる。
