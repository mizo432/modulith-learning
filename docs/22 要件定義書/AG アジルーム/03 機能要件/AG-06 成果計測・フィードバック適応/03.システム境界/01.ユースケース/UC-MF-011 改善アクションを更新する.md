# UC-MF-011 改善アクションを更新する

## 概要

改善アクションの進捗や状態を更新する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-011 |
| ユースケース名 | 改善アクションを更新する |
| 関連BUC | BUC-MF-04 |
| 関連アクター | ACT-02, ACT-03, ACT-04 |
| 外部システム | なし |
| 関連情報 | INF-MF-05 (改善アクション) |
| 関連画面 | SCR-MF-09 (改善アクション管理画面) |

## 前提条件

- 改善アクションが登録されている

## 基本フロー

1. システムは改善アクションの一覧を表示する
2. アクターは更新対象の改善アクションを選択する
3. アクターは進捗や状態を更新する
4. システムは改善アクションを更新する

## 結果

改善アクションの情報が更新される。
