# UC-MF-003 Sprint Reviewを完了する

## 概要

Sprint Reviewの決定事項を記録し、Reviewを完了状態にする。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-003 |
| ユースケース名 | Sprint Reviewを完了する |
| 関連BUC | BUC-MF-01 |
| 関連アクター | ACT-02, ACT-03 |
| 外部システム | なし |
| 関連情報 | INF-MF-01 (Sprint Review) |
| 関連画面 | SCR-MF-02 (Sprint Review実施画面) |

## 前提条件

- Sprint Reviewが開催中である

## 基本フロー

1. システムはSprint Reviewの情報を表示する
2. アクターは決定事項を記録する
3. アクターは未解決事項を記録する
4. アクターはSprint Reviewを完了する
5. システムはSprint Reviewの状態を「完了」にする

## 結果

Sprint Reviewが完了し、決定事項が記録される。
