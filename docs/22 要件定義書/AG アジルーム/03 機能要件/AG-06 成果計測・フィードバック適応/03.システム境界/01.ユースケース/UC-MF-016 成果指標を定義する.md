# UC-MF-016 成果指標を定義する

## 概要

成果指標の定義、基準値、目標値を設定する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-016 |
| ユースケース名 | 成果指標を定義する |
| 関連BUC | BUC-MF-06 |
| 関連アクター | ACT-02 |
| 外部システム | なし |
| 関連情報 | INF-MF-07 (成果指標) |
| 関連画面 | SCR-MF-13 (成果指標管理画面) |

## 前提条件

- なし

## 基本フロー

1. アクターは指標名を入力する
2. アクターは指標の定義を入力する
3. アクターは基準値を設定する
4. アクターは目標値を設定する
5. アクターはデータ元を指定する
6. アクターは更新頻度を設定する
7. システムは成果指標を保存する

## 結果

成果指標が定義され、保存される。
