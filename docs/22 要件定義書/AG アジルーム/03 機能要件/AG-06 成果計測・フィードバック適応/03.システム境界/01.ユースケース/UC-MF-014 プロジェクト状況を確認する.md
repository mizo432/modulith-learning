# UC-MF-014 プロジェクト状況を確認する

## 概要

プロジェクトの進捗、マイルストーン、成果、リスクを確認する。

## 詳細

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-MF-014 |
| ユースケース名 | プロジェクト状況を確認する |
| 関連BUC | BUC-MF-05 |
| 関連アクター | ACT-02, ACT-05 |
| 外部システム | なし |
| 関連情報 | INF-MF-09 (リスク) |
| 関連画面 | SCR-MF-11 (プロジェクトトラッキング画面) |

## 前提条件

- なし

## 基本フロー

1. システムはプロジェクトの進捗情報を表示する
2. アクターはマイルストーンを確認する
3. アクターは成果を確認する
4. アクターはリスク一覧を確認する

## 結果

プロジェクトの状況が確認できる。
