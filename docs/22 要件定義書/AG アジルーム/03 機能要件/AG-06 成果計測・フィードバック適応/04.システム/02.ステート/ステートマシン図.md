# ステートマシン図

成果計測・フィードバックによる適応業務領域（AG-06）のステートマシン図をPlantUMLで定義します。

## 改善アクションの状態遷移

```plantuml
@startuml
title 改善アクション - ステートマシン図

state "未着手\nPending" as Pending
state "進行中\nInProgress" as InProgress
state "完了\nCompleted" as Completed
state "中止\nCancelled" as Cancelled

[*] --> Pending
Pending --> InProgress : 改善アクションを更新する\n(UC-MF-011)
InProgress --> Completed : 改善アクションを更新する\n(UC-MF-011)
InProgress --> Cancelled : 改善アクションを更新する\n(UC-MF-011)
@enduml
```
