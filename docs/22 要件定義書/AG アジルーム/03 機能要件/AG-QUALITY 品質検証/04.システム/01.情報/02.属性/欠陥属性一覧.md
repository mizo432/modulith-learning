# 欠陥属性一覧

プロダクト品質・受入・性能検証業務領域で扱う「欠陥」の属性を定義します。

| 属性名             | 型          | PK | 必須 | 説明                           |
|--------------------|-------------|----|------|--------------------------------|
| defect_id          | SnowflakeID | *  | Y    | 欠陥の一意な識別子             |
| backlog_item_id    | UUID        |    | Y    | 関連するバックログ項目の識別子 |
| test_run_id        | UUID        |    | N    | 関連するテスト実行結果の識別子 |
| title              | String      |    | Y    | 欠陥のタイトル                 |
| description        | Text        |    | Y    | 欠陥の詳細説明                 |
| reproduction_steps | Text        |    | Y    | 再現手順                       |
| severity           | Enum        |    | Y    | 影響度                         |
| status             | Enum        |    | Y    | 現在の状態                     |
| created_at         | DateTime    |    | Y    | 作成日時                       |
| updated_at         | DateTime    |    | Y    | 最終更新日時                   |
