# テスト実行結果属性一覧

プロダクト品質・受入・性能検証業務領域で扱う「テスト実行結果」の属性を定義します。

| 属性名        | 型          | PK | 必須 | 説明                             |
|---------------|-------------|----|------|----------------------------------|
| test_run_id   | SnowflakeID | *  | Y    | テスト実行結果の一意な識別子     |
| test_case_id  | UUID        |    | Y    | 関連するテストケースの識別子     |
| sprint_id     | UUID        |    | Y    | 関連するスプリントの識別子       |
| executed_by   | UUID        |    | Y    | 実行者の識別子                   |
| result        | Enum        |    | Y    | 実行結果（成功、失敗、スキップ） |
| actual_result | Text        |    | N    | 実際の結果                       |
| executed_at   | DateTime    |    | Y    | 実行日時                         |
| created_at    | DateTime    |    | Y    | 作成日時                         |
| updated_at    | DateTime    |    | Y    | 最終更新日時                     |
