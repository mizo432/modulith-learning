# 性能テスト結果属性一覧

プロダクト品質・受入・性能検証業務領域で扱う「性能テスト結果」の属性を定義します。

| 属性名             | 型          | PK | 必須 | 説明                           |
|--------------------|-------------|----|------|--------------------------------|
| performance_run_id | SnowflakeID | *  | Y    | 性能テスト結果の一意な識別子   |
| project_id         | UUID        |    | Y    | 所属プロジェクトの識別子       |
| backlog_item_id    | UUID        |    | N    | 関連するバックログ項目の識別子 |
| sprint_id          | UUID        |    | Y    | 関連するスプリントの識別子     |
| title              | String      |    | Y    | 性能テストのタイトル           |
| description        | Text        |    | N    | 性能テストの詳細説明           |
| load_condition     | Text        |    | N    | 負荷条件                       |
| pass_criteria      | Text        |    | Y    | 合格基準                       |
| result             | Text        |    | Y    | 実行結果                       |
| executed_at        | DateTime    |    | Y    | 実行日時                       |
| created_at         | DateTime    |    | Y    | 作成日時                       |
| updated_at         | DateTime    |    | Y    | 最終更新日時                   |
