# テストケース属性一覧

プロダクト品質・受入・性能検証業務領域で扱う「テストケース」の属性を定義します。

| 属性名          | 型          | PK | 必須 | 説明                           |
|-----------------|-------------|----|------|--------------------------------|
| test_case_id    | SnowflakeID | *  | Y    | テストケースの一意な識別子     |
| backlog_item_id | UUID        |    | Y    | 関連するバックログ項目の識別子 |
| title           | String      |    | Y    | テストケースのタイトル         |
| description     | Text        |    | N    | テストケースの詳細説明         |
| test_type       | Enum        |    | Y    | テスト種別                     |
| preconditions   | Text        |    | N    | 前提条件                       |
| steps           | Text        |    | Y    | 実行手順                       |
| expected_result | Text        |    | Y    | 期待結果                       |
| created_at      | DateTime    |    | Y    | 作成日時                       |
| updated_at      | DateTime    |    | Y    | 最終更新日時                   |
