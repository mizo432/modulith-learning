# 外部システム一覧

プロダクト品質・受入・性能検証業務領域で連携する外部システムを定義します。

| ID    | 外部システム名              | 連携内容                                                 |
|-------|-----------------------------|----------------------------------------------------------|
| ES-05 | テスト実行ツール            | テスト結果・カバレッジを取得し、テストケースと連携       |
| ES-06 | 性能テストツール（Gatling） | 性能テストの実行条件やレポートを取り込み、要求と関連付け |
