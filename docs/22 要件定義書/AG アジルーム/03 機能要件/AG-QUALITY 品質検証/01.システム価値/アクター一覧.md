# アクター一覧

プロダクト品質・受入・性能検証業務領域でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                 |
|--------|--------------------------|------------------------------------------------------|
| ACT-01 | 従業員                   | 業務シナリオに沿った受入テストに参加し、不具合を報告 |
| ACT-02 | プロダクトオーナー（PO） | 受入条件を確認し、インクリメントの価値を検証         |
| ACT-04 | 開発者                   | テストケースを管理し、欠陥を記録・対応               |
| ACT-05 | トラッキング担当         | 品質状況・テスト結果・欠陥情報を参照                 |
| ACT-06 | システム管理者           | セキュリティ・品質リスクを管理                       |
