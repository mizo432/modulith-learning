# 要求一覧

プロダクト品質・受入・性能検証業務領域の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                              | 優先度 |
|----------|------------------------------|-------------------------------------------------------------------|--------|
| FR-QL-01 | Definition of Done管理       | チームの完成基準を定義・共有する                                  | MVP    |
| FR-QL-02 | 欠陥管理                     | 再現手順、影響度、状態、関連項目を管理する                        | MVP    |
| FR-QL-03 | テストケース管理             | 要求や受入条件に関連づけたテストケースを管理する                  | 次期   |
| FR-QL-04 | 受入テスト・シナリオテスト   | 業務シナリオに沿った期待結果と確認結果を記録する                  | 次期   |
| FR-QL-05 | テスト実行・結果管理         | 手動・自動テストの実行結果を保存・追跡する                        | 次期   |
| FR-QL-06 | 性能要件・負荷シナリオ管理   | p95等の性能要件、負荷条件、合格基準を管理する                     | 次期   |
| FR-QL-07 | Gatling連携                  | Gatlingの実行条件やレポートを取り込み、要求やリリースと関連づける | 拡張   |
| FR-QL-08 | セキュリティ・品質リスク管理 | 品質・セキュリティ上のリスクと対応を記録する                      | 次期   |

## 非機能要求

| ID        | 要求名           | 概要                                         |
|-----------|------------------|----------------------------------------------|
| NFR-QL-01 | テスト結果の保持 | テスト実行結果を長期保持・参照可能にする     |
| NFR-QL-02 | 外部ツール連携   | 外部テストツールとのデータ連携を安定して行う |
