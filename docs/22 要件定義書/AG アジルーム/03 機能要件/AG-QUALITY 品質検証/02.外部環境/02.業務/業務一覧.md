# 業務一覧

プロダクト品質・受入・性能検証業務を定義します。

| ID        | 業務名                       | 概要                                             | 主なアクター           |
|-----------|------------------------------|--------------------------------------------------|------------------------|
| BUC-QL-01 | 完成の定義の管理             | チームの品質基準を定義・共有・更新する           | ACT-03, ACT-04         |
| BUC-QL-02 | テストケースの作成・管理     | 要求や受入条件に関連づけたテストケースを管理する | ACT-02, ACT-04         |
| BUC-QL-03 | 受入テスト・シナリオ検証     | 業務シナリオに沿った期待結果と確認結果を記録する | ACT-01, ACT-02, ACT-04 |
| BUC-QL-04 | 欠陥の記録・対応             | 再現手順・影響度・状態を管理し、対応を追跡する   | ACT-01, ACT-02, ACT-04 |
| BUC-QL-05 | 性能検証                     | 性能要件・負荷条件を満たすか検証する             | ACT-04                 |
| BUC-QL-06 | セキュリティ・品質リスク管理 | 品質・セキュリティ上のリスクと対応を記録する     | ACT-04, ACT-06         |
