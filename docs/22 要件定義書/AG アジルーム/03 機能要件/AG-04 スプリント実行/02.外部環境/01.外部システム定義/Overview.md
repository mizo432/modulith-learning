# 外部システム定義 Overview

スプリント実行業務領域（AG-04）が連携する外部システムを定義します。

## 概要

スプリント実行は、チームがスプリント目標を共有し、作業計画を日々適応させながら、完成の定義を満たすインクリメントを形成する業務領域です。本業務領域では、Sprint Goal・Sprint Backlog・作業ボード・障害などの情報はAgiloom内で管理するため、外部システムとの直接的な連携はありません。

## 外部システム一覧

本業務領域で連携する外部システムはありません。

| ID       | 外部システム名 | 連携内容 |
|----------|----------------|----------|
| （なし） | -              | -        |

## 補足

- スプリント実行で管理する情報（Sprint Goal、Sprint Backlog、作業状態、障害など）は、Agiloom内の他の業務領域（バックログ管理、品質検証、成果適応）と連携しますが、これらはシステム内部の連携であり、外部システム連携には該当しません。
- 将来的に、ソース管理システム（Git）やCI/CDツールとの連携により、スプリント項目とコード変更・ビルド結果・デプロイ状況を関連付けることが検討される場合がありますが、現時点ではMVP範囲外です。
