# BUC-SP-02 スプリント実行・日々の適応

## 概要

設計・実装・テスト・統合を行い、日々計画を調整する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:スプリントを開始する;
:毎日の進捗を確認する;

repeat
  :設計を行う;
  :実装を行う;
  :テストを行う;
  :統合を行う;
  
  :進捗を更新する;
  :問題を特定する;
  
  if (問題があるか?) then (はい)
    :問題を記録する;
    :対応策を検討する;
    else (いいえ)
    :そのまま進む;
    endif
repeat while (スプリント終了か?) is (いいえ)

:スプリント結果をまとめする;

stop
@enduml
```
