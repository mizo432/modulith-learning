# BUC-SP-04 スプリント進捗の共有

## 概要

作業状態・リスク・依存関係を正確に共有する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:作業状態を確認する;
:リスクを確認する;
:依存関係を確認する;

:進捗情報を整理する;
:共有方法を選択する;

if (共有方法は?) then (デイリーミーティング)
  :デイリーミーティングを実施する;
else (ダッシュボード)
  :ダッシュボードを更新する;
else (レポート)
  :レポートを作成する;
  endif

:進捗情報を共有する;
:フィードバックを収集する;

if (アクションが必要か?) then (はい)
  :アクションアイテムを記録する;
  :担当者を割り当てる;
  endif

:共有結果を記録する;

stop
@enduml
```
