# BUC-SP-05 インクリメントの完成確認

## 概要

完成の定義を満たすインクリメントを確認・提示する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:完成の定義を確認する;
:開発済みの機能を確認する;

:機能テストを実行する;
:品質チェックを行う;
:ドキュメントを確認する;

if (完成の定義を満たすか?) then (はい)
  :インクリメントを完成とする;
  :提示準備を行う;
else (いいえ)
  :不足事項を特定する;
  :修正を依頼する;
  :再確認を行う;
  endif

:インクリメントを提示する;
:結果を記録する;

stop
@enduml
```
