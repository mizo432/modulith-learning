# 用語集（イテレーションダッシュボード）

イテレーションダッシュボード機能に関連する用語を定義します。

## ビジネス用語

| 用語ID | 用語 | 分類 | 説明 |
|--------|------|------|------|
| TERM-IDB-001 | イテレーションダッシュボード | ビジネス | スプリントの進捗・成果・リスクを可視化する画面 |
| TERM-IDB-002 | Sprint Goal | ビジネス | スプリントの目的。チームが達成すべき目標 |
| TERM-IDB-003 | Burndown Chart | ビジネス | 残作業量の推移をグラフで表示するチャート |
| TERM-IDB-004 | Burnup Chart | ビジネス | 完了量とスコープの推移をグラフで表示するチャート |
| TERM-IDB-005 | Story Points | ビジネス | User Storyの相対的な見積り単位 |
| TERM-IDB-006 | スコープ変更 | ビジネス | Sprint Backlogへの追加・削除・変更 |
| TERM-IDB-007 | ブロッカー | ビジネス | 作業を阻害する要因 |
| TERM-IDB-008 | ベロシティ | ビジネス | チームのスプリントあたりの完了量 |
| TERM-IDB-009 | Sprint Planning Snapshot | ビジネス | Sprint Planning完了時の計画情報のスナップショット |
| TERM-IDB-010 | 残作業量 | ビジネス | 未完了の作業の合計量 |

## システム用語

| 用語ID | 用語 | 分類 | 説明 |
|--------|------|------|------|
| TERM-IDB-011 | Sprint Metrix | システム | ダッシュボード用集計メトリクス |
| TERM-IDB-012 | Task Work Log | システム | Taskの作業実績記録 |
| TERM-IDB-013 | Sprint Scope Change | システム | スコープ変更イベント |
| TERM-IDB-014 | UC-IDB | システム | イテレーションダッシュボードのユースケースIDプレフィックス |
| TERM-IDB-015 | SCR-029 | システム | イテレーションダッシュボード画面のID |
