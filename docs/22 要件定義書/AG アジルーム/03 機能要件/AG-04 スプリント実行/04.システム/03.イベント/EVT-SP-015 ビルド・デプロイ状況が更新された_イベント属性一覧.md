# イベント属性一覧

ビルド・デプロイ状況が更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-015 |
| イベント名 | ビルド・デプロイ状況が更新された |
| 説明 | CI/CDパイプラインのビルド・デプロイ状況が取得された |
| 関連ユースケース | UC-SP-019 |
| 発生元 | 外部システム |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | backlog_item_id | String | はい | - | 一意 | 関連するBacklog項目の識別子 |
| 5 | build_status | Enum | はい | - | - | ビルドの状況（成功/失敗/実行中） |
| 6 | build_url | String | いいえ | - | 最大1000文字 | ビルド結果のURL |
| 7 | deploy_status | Enum | いいえ | - | - | デプロイの状況（成功/失敗/実行中） |
| 8 | deploy_url | String | いいえ | - | 最大1000文字 | デプロイ結果のURL |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | CI/CDフック受信 | 外部システム | CI/CDツールからのフック受信 | ビルド・デプロイ状況の更新 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
