# イベント属性一覧

スプリントが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-002 |
| イベント名 | スプリントが更新された |
| 説明 | スプリントの期間・状態・チーム情報が修正された |
| 関連ユースケース | UC-SP-002 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 更新されたSprintの識別子 |
| 4 | sprint_name | String | はい | - | 最大255文字 | Sprintの名前 |
| 5 | start_date | Date | いいえ | - | end_date以前 | Sprintの開始日 |
| 6 | end_date | Date | いいえ | - | start_date以降 | Sprintの終了日 |
| 7 | status | Enum | いいえ | - | - | 更新された状態 |
| 8 | updated_by | String | はい | - | - | Sprintを更新したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint更新ボタンクリック | 手動 | POまたはSMがSprintを更新ボタンをクリック | Sprint情報の修正 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | sprint_id | String | はい | 更新されたSprintの識別子 |
| 2 | sprint_name | String | いいえ | Sprintの名前 |
| 3 | start_date | Date | いいえ | Sprintの開始日 |
| 4 | end_date | Date | いいえ | Sprintの終了日 |
| 5 | status | Enum | いいえ | 更新された状態 |
| 6 | updated_by | String | はい | 更新者 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | Sprintエンティティの更新 | Sprintデータをデータベースに更新 | UC-SP-002 | Sprint情報の永続化 |
| 2 | アクティビティの記録 | Sprint更新のアクティビティを記録 | - | 監査証跡の記録 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 期間の整合性 | start_date, end_date | end_date >= start_date | Sprintの終了日は開始日以降でなければならない |
| 2 | 更新者権限 | updated_by | POまたはSMのみ | Sprintの更新はPOとSMのみ可能 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 期間終了日の検証 | end_date | end_date >= start_date | Sprintの終了日は開始日以降に設定してください |
