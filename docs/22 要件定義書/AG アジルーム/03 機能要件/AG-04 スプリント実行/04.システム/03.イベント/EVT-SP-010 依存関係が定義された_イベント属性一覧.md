# イベント属性一覧

依存関係が定義されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-010 |
| イベント名 | 依存関係が定義された |
| 説明 | 作業間の依存関係が定義された |
| 関連ユースケース | UC-SP-012 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | dependency_id | String | はい | - | 一意 | 定義された依存関係の識別子 |
| 4 | source_item_id | String | はい | - | 一意 | 依存元のBacklog項目の識別子 |
| 5 | target_item_id | String | はい | - | 一意 | 依存先のBacklog項目の識別子 |
| 6 | dependency_type | Enum | はい | - | - | 依存関係の種類 |
| 7 | description | String | いいえ | - | 最大1000文字 | 依存関係の説明 |
| 8 | created_by | String | はい | - | - | 依存関係を定義したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 依存関係定義ボタンクリック | 手動 | 開発者またはSMが依存関係を定義ボタンをクリック | 依存関係の定義 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | dependency_id | String | はい | 定義された依存関係の識別子 |
| 2 | source_item_id | String | はい | 依存元のBacklog項目の識別子 |
| 3 | target_item_id | String | はい | 依存先のBacklog項目の識別子 |
| 4 | dependency_type | Enum | はい | 依存関係の種類 |
| 5 | description | String | いいえ | 依存関係の説明 |
| 6 | created_by | String | はい | 定義者 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 依存関係エンティティの作成 | 依存関係データをデータベースに保存 | UC-SP-012 | 依存関係の永続化 |
| 2 | アクティビティの記録 | 依存関係定義のアクティビティを記録 | - | 監査証跡の記録 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 定義者権限 | created_by | 開発者またはSMのみ | 依存関係の定義は開発者とSMのみ可能 |
| 2 | 循環参照の禁止 | source_item_id, target_item_id | 循環参照にならない | 循環する依存関係は定義不可 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 依存元・依存先の有効性 | source_item_id, target_item_id | 両方とも存在する | 有効なBacklog項目を選択してください |
| 2 | 自己参照の禁止 | source_item_id, target_item_id | 異なる項目である | 自分自身への依存は定義できません |
