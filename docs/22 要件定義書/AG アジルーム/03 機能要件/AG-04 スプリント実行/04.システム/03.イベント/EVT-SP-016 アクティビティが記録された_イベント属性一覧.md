# イベント属性一覧

アクティビティが記録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-016 |
| イベント名 | アクティビティが記録された |
| 説明 | 作業状態変更、コメント追加などのアクティビティが記録された |
| 関連ユースケース | UC-SP-008 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | actor_id | String | はい | - | 一意 | アクティビティを実行したユーザーの識別子 |
| 5 | activity_type | Enum | はい | - | - | アクティビティの種類 |
| 6 | description | String | いいえ | - | 最大1000文字 | アクティビティの説明 |
| 7 | target_item_id | String | いいえ | - | - | 対象となるBacklog項目の識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | アクティビティ発生 | システム内部 | 作業状態変更やコメント追加などのイベントが発生 | アクティビティの自動記録 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
