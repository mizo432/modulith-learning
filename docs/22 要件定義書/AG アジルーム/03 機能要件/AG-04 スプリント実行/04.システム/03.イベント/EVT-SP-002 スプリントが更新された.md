# スプリントが更新された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-002 |
| イベント名 | スプリントが更新された |
| 説明 | スプリントの期間・状態・チーム情報が修正された |
| 関連ユースケース | UC-SP-002 |
| 関連情報 | INF-SP-01 |
| 集約 | スプリント |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| スプリント名 | 文字列 | はい | スプリントの名前 |
| 状態 | 選択 | はい | 更新された状態 |
