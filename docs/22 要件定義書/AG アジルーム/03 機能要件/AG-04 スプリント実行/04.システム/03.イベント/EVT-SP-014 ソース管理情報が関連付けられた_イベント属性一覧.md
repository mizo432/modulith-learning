# イベント属性一覧

ソース管理情報が関連付けられたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-014 |
| イベント名 | ソース管理情報が関連付けられた |
| 説明 | コミット・ブランチ・PRがスプリント作業と関連付けられた |
| 関連ユースケース | UC-SP-018 |
| 発生元 | 外部システム |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | backlog_item_id | String | はい | - | 一意 | 関連するBacklog項目の識別子 |
| 5 | commit_hash | String | いいえ | - | 最大64文字 | 関連するコミットハッシュ |
| 6 | branch_name | String | いいえ | - | 最大255文字 | 関連するブランチ名 |
| 7 | pull_request_url | String | いいえ | - | 最大1000文字 | 関連するPRのURL |
| 8 | linked_by | String | はい | - | - | ソース管理情報を関連付けたユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Gitフック受信 | 外部システム | Gitリポジトリからのフック受信 | コミットやPRの関連付け |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

| 4 | branch_name | String | いいえ | 関連するブランチ名 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | ソース管理情報の保存 | ソース管理情報をデータベースに保存 | UC-SP-018 | 関連付けの永続化 |
| 2 | アクティビティの記録 | ソース管理情報関連付けのアクティビティを記録 | - | 監査証跡の記録 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | Sprintの存在 | sprint_id | 対象Sprintが存在する | 既存のSprintにのみ関連付け可能 |
| 2 | Backlog項目の存在 | backlog_item_id | 対象Backlog項目が存在する | 既存のBacklog項目にのみ関連付け可能 |
