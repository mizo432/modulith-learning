# イベント属性一覧

デイリースクラムが記録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-013 |
| イベント名 | デイリースクラムが記録された |
| 説明 | Sprint Goalに向けた状況確認と計画調整が記録された |
| 関連ユースケース | UC-SP-016 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | scrum_date | Date | はい | - | - | Daily Scrumの実施日 |
| 5 | participant_ids | String | はい | - | - | 参加したメンバーの識別子リスト |
| 6 | yesterday_work | String | いいえ | - | 最大2000文字 | 昨日達成した事項 |
| 7 | today_work | String | いいえ | - | 最大2000文字 | 今日行う予定の事項 |
| 8 | blockers | String | いいえ | - | 最大1000文字 | 直面している障害 |
| 9 | goal_status | String | いいえ | - | 最大2000文字 | Sprint Goalに向けた進捗状況 |
| 10 | plan_adjustment | String | いいえ | - | 最大1000文字 | 計画の調整内容 |
| 11 | created_by | String | はい | - | - | Daily Scrumを記録したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Daily Scrum記録ボタンクリック | 手動 | 開発者がDaily Scrumを記録ボタンをクリック | Daily Scrumの記録 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | Daily Scrumエンティティの作成 | Daily Scrumデータをデータベースに保存 | UC-SP-016 | Daily Scrumの永続化 |
| 2 | アクティビティの記録 | Daily Scrumのアクティビティを記録 | - | 監査証跡の記録 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 記録者権限 | created_by | 開発チームのみ | Daily Scrumの記録は開発チームのみ可能 |
| 2 | 日付の一意性 | scrum_date | 同じ日付の記録は1回のみ | 同日の重複記録は不可 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 日付の一意性チェック | scrum_date | 同じ日付の記録が存在しない | 同じ日付の記録は既に存在します |
| 2 | 参加者の必須入力 | participant_ids | 選択数 >= 1 | 少なくとも1人の参加者を選択してください |
