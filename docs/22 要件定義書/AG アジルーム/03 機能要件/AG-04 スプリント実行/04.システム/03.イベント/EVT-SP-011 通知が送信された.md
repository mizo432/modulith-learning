# 通知が送信された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-011 |
| イベント名 | 通知が送信された |
| 説明 | メンション、担当変更、期限、判断待ちなどが通知された |
| 関連ユースケース | UC-SP-013 |
| 関連情報 | INF-SP-06 |
| 集約 | 通知 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 送信先 | 文字列 | はい | 通知の送信先 |
| 種類 | 選択 | はい | 通知の種類 |
| 内容 | テキスト | はい | 通知の内容 |
