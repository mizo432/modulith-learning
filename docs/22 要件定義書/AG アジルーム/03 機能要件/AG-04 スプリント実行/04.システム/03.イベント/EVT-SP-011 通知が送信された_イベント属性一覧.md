# イベント属性一覧

通知が送信されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-011 |
| イベント名 | 通知が送信された |
| 説明 | メンション、担当変更、期限、判断待ちなどが通知された |
| 関連ユースケース | UC-SP-013 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | notification_id | String | はい | - | 一意 | 送信された通知の識別子 |
| 4 | recipient_id | String | はい | - | 一意 | 通知先のユーザーの識別子 |
| 5 | title | String | はい | - | 最大255文字 | 通知のタイトル |
| 6 | content | String | はい | - | 最大2000文字 | 通知の内容 |
| 7 | type | Enum | はい | - | - | 通知の種類 |
| 8 | sender_id | String | はい | - | - | 通知を送信したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 通知送信トリガー | システム内部 | メンションや担当変更などのイベントが発生 | 通知の自動送信 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | notification_id | String | はい | 送信された通知の識別子 |
| 2 | recipient_id | String | はい | 通知先のユーザーの識別子 |
| 3 | title | String | はい | 通知のタイトル |
| 4 | content | String | はい | 通知の内容 |
| 5 | type | Enum | はい | 通知の種類 |
| 6 | sender_id | String | はい | 送信者 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 通知エンティティの作成 | 通知データをデータベースに保存 | UC-SP-013 | 通知の永続化 |
| 2 | 通知の配信 | 通知をユーザーに配信 | - | メールやプッシュ通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 通知先の有効性 | recipient_id | 対象ユーザーが存在する | 有効なユーザーにのみ通知可能 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 通知タイトルの必須入力 | title | 文字数 > 0 | 通知のタイトルを入力してください |
| 2 | 通知内容の必須入力 | content | 文字数 > 0 | 通知の内容を入力してください |
