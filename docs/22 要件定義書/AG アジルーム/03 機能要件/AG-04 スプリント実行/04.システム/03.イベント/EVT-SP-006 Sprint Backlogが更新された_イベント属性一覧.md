# イベント属性一覧

Sprint Backlogが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-006 |
| イベント名 | Sprint Backlogが更新された |
| 説明 | 作業の状態・担当・依存関係が修正された |
| 関連ユースケース | UC-SP-007 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | backlog_item_id | String | はい | - | 一意 | 更新されたBacklog項目の識別子 |
| 5 | status | Enum | いいえ | - | - | 更新された状態 |
| 6 | assignee_id | String | いいえ | - | - | 更新された担当者の識別子 |
| 7 | updated_by | String | はい | - | - | Sprint Backlogを更新したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint Backlog更新ボタンクリック | 手動 | 開発者またはSMがSprint Backlogを更新ボタンをクリック | Sprint Backlogの修正 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベント処理フロー

## 制約事項
