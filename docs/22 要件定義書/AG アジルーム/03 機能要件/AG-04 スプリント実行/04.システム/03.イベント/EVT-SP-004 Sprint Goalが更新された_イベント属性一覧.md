# イベント属性一覧

Sprint Goalが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-004 |
| イベント名 | Sprint Goalが更新された |
| 説明 | スプリントの目的が修正・更新された |
| 関連ユースケース | UC-SP-005 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | goal_description | String | はい | - | 最大2000文字 | 更新されたSprint Goalの説明 |
| 5 | related_items | String | いいえ | - | - | 関連するバックログ項目のリスト |
| 6 | updated_by | String | はい | - | - | Sprint Goalを更新したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint Goal更新ボタンクリック | 手動 | POまたはSMがSprint Goalを更新ボタンをクリック | Sprint Goalの修正 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

イベントが発生した際に送信されるデータ構造を定義します。

| 2 | goal_description | String | はい | 更新されたSprint Goalの説明 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | Sprint Goalエンティティの更新 | Sprint Goalデータをデータベースに更新 | UC-SP-005 | Sprint Goalの永続化 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
