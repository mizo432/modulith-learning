# イベント属性一覧

スプリントが作成されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-001 |
| イベント名 | スプリントが作成された |
| 説明 | スプリント期間、状態、チームが定義されて登録された |
| 関連ユースケース | UC-SP-001 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 作成されたSprintの識別子 |
| 4 | sprint_name | String | はい | - | 最大255文字 | Sprintの名前 |
| 5 | start_date | Date | はい | - | end_date以前 | Sprintの開始日 |
| 6 | end_date | Date | はい | - | start_date以降 | Sprintの終了日 |
| 7 | team_id | String | はい | - | - | 担当チームの識別子 |
| 8 | status | Enum | はい | 計画済み | - | Sprintの初期状態 |
| 9 | created_by | String | はい | - | - | Sprintを作成したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint作成ボタンクリック | 手動 | POまたはSMがSprintを作成ボタンをクリック | 新規Sprintの登録 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | sprint_id | String | はい | 作成されたSprintの識別子 |
| 2 | sprint_name | String | はい | Sprintの名前 |
| 3 | start_date | Date | はい | Sprintの開始日 |
| 4 | end_date | Date | はい | Sprintの終了日 |
| 5 | team_id | String | はい | 担当チームの識別子 |
| 6 | status | Enum | はい | Sprintの初期状態 |
| 7 | created_by | String | はい | 作成者 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | Sprintエンティティの作成 | Sprintデータをデータベースに保存 | UC-SP-001 | 新規Sprintの永続化 |
| 2 | アクティビティの記録 | Sprint作成のアクティビティを記録 | - | 監査証跡の記録 |
| 3 | 通知の送信 | 関連メンバーにSprint作成を通知 | UC-SP-013 | チームへの通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 期間の整合性 | start_date, end_date | end_date >= start_date | Sprintの終了日は開始日以降でなければならない |
| 2 | 作成者権限 | created_by | POまたはSMのみ | Sprintの作成はPOとSMのみ可能 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 期間終了日の検証 | end_date | end_date >= start_date | Sprintの終了日は開始日以降に設定してください |
| 2 | Sprint名の必須入力 | sprint_name | 文字数 > 0 | Sprint名を入力してください |
