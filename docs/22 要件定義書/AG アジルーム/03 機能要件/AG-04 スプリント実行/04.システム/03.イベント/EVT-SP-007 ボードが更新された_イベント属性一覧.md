# イベント属性一覧

ボードが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-007 |
| イベント名 | ボードが更新された |
| 説明 | カンバンボード上で作業の状態が移動された |
| 関連ユースケース | UC-SP-008 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | backlog_item_id | String | はい | - | 一意 | 状態が変更されたBacklog項目の識別子 |
| 5 | old_status | Enum | はい | - | - | 変更前の状態 |
| 6 | new_status | Enum | はい | - | - | 変更後の状態 |
| 7 | updated_by | String | はい | - | - | ボードを更新したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | ドラッグ＆ドロップ完了 | 手動 | 開発者がカードをドラッグ＆ドロップして状態を変更 | 作業状態の移動 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |

| 1 | sprint_id | String | はい | 関連するSprintの識別子 |
| 2 | backlog_item_id | String | はい | 状態が変更されたBacklog項目の識別子 |
| 3 | old_status | Enum | はい | 変更前の状態 |
| 4 | new_status | Enum | はい | 変更後の状態 |
| 5 | updated_by | String | はい | 更新者 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | Backlog項目の状態更新 | Backlog項目の状態をデータベースに更新 | UC-SP-008 | 状態変更の永続化 |
| 2 | アクティビティの記録 | 状態変更のアクティビティを記録 | - | 監査証跡の記録 |
| 3 | 通知の送信 | 状態変更を関連メンバーに通知 | UC-SP-013 | チームへの通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 更新者権限 | updated_by | 開発者またはSMのみ | ボードの更新は開発者とSMのみ可能 |
| 2 | 状態遷移の妥当性 | old_status, new_status | 有効な状態遷移である | 許可されていない状態遷移は不可 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 状態遷移の検証 | old_status, new_status | 有効な遷移である | 許可されていない状態遷移です |
| 2 | 完成の定義チェック | new_status | 完了にする場合はDoDを満たす | 完成の定義を満たしてから完了にしてください |
