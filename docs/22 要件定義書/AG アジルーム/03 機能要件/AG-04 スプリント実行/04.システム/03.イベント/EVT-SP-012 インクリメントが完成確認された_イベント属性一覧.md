# イベント属性一覧

インクリメントが完成確認されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-012 |
| イベント名 | インクリメントが完成確認された |
| 説明 | 完成の定義を満たすインクリメントが確認・提示された |
| 関連ユースケース | UC-SP-015 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | backlog_item_id | String | はい | - | 一意 | 完成確認されたBacklog項目の識別子 |
| 5 | confirmed_by | String | はい | - | - | 完成確認を行ったユーザーの識別子 |
| 6 | confirmation_notes | String | いいえ | - | 最大1000文字 | 確認時の備考 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 完成確認ボタンクリック | 手動 | POまたはSMが完成確認ボタンをクリック | インクリメントの確認 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | sprint_id | String | はい | 関連するSprintの識別子 |
| 2 | backlog_item_id | String | はい | 完成確認されたBacklog項目の識別子 |
| 3 | confirmed_by | String | はい | 確認者 |
| 4 | confirmation_notes | String | いいえ | 確認時の備考 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | Backlog項目の状態更新 | Backlog項目の状態を完了に更新 | UC-SP-015 | 完成確認の永続化 |
| 2 | アクティビティの記録 | 完成確認のアクティビティを記録 | - | 監査証跡の記録 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 確認者権限 | confirmed_by | POまたはSMのみ | 完成確認はPOとSMのみ可能 |
| 2 | 完成の定義 | backlog_item_id | Definition of Doneを満たす | DoDを満たさない項目は完成確認不可 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 完成の定義チェック | backlog_item_id | DoDを満たす | 完成の定義を満たしてから確認してください |
