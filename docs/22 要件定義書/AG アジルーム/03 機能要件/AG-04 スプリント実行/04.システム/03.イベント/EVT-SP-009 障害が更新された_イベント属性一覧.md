# イベント属性一覧

障害が更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-009 |
| イベント名 | 障害が更新された |
| 説明 | 障害の解消状況・担当が修正された |
| 関連ユースケース | UC-SP-010 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | impediment_id | String | はい | - | 一意 | 更新された障害の識別子 |
| 4 | status | Enum | いいえ | - | - | 更新された状態 |
| 5 | assignee_id | String | いいえ | - | - | 更新された担当者の識別子 |
| 6 | resolved_at | DateTime | いいえ | - | - | 解消日時 |
| 7 | updated_by | String | はい | - | - | 障害を更新したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 障害更新ボタンクリック | 手動 | 開発者またはSMが障害を更新ボタンをクリック | 障害の修正 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | impediment_id | String | はい | 更新された障害の識別子 |
| 2 | status | Enum | いいえ | 更新された状態 |
| 3 | assignee_id | String | いいえ | 更新された担当者の識別子 |
| 4 | resolved_at | DateTime | いいえ | 解消日時 |
| 5 | updated_by | String | はい | 更新者 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 障害エンティティの更新 | 障害データをデータベースに更新 | UC-SP-010 | 障害の永続化 |
| 2 | アクティビティの記録 | 障害更新のアクティビティを記録 | - | 監査証跡の記録 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 更新者権限 | updated_by | 開発者またはSMのみ | 障害の更新は開発者とSMのみ可能 |
| 2 | 障害の存在 | impediment_id | 対象障害が存在する | 既存の障害のみ更新可能 |

## バリデーションルール

イベントデータの検証ルールを定義します。
