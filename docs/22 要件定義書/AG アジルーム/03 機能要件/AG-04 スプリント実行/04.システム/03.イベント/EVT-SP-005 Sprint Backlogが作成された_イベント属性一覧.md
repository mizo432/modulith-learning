# イベント属性一覧

Sprint Backlogが作成されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-005 |
| イベント名 | Sprint Backlogが作成された |
| 説明 | 選択項目、作業、状態、担当、依存関係が定義された |
| 関連ユースケース | UC-SP-006 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | backlog_items | String | はい | - | - | 選択されたバックログ項目のリスト |
| 5 | work_description | String | いいえ | - | 最大2000文字 | 作業の説明 |
| 6 | assignee_id | String | いいえ | - | - | 担当者の識別子 |
| 7 | created_by | String | はい | - | - | Sprint Backlogを作成したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint Backlog作成ボタンクリック | 手動 | POまたはSMがSprint Backlogを作成ボタンをクリック | Sprint Backlogの定義 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | sprint_id | String | はい | 関連するSprintの識別子 |
| 2 | backlog_items | String | はい | 選択されたバックログ項目のリスト |
| 3 | work_description | String | いいえ | 作業の説明 |
| 4 | assignee_id | String | いいえ | 担当者の識別子 |
| 5 | created_by | String | はい | 作成者 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | Sprint Backlogエンティティの作成 | Sprint Backlogデータをデータベースに保存 | UC-SP-006 | Sprint Backlogの永続化 |
| 2 | アクティビティの記録 | Sprint Backlog作成のアクティビティを記録 | - | 監査証跡の記録 |
| 3 | 通知の送信 | 関連メンバーにSprint Backlog作成を通知 | UC-SP-013 | チームへの通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 作成者権限 | created_by | POまたはSMのみ | Sprint Backlogの作成はPOとSMのみ可能 |
| 2 | Sprintの存在 | sprint_id | 対象Sprintが存在する | 既存のSprintにのみBacklogを作成可能 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | バックログ項目の必須入力 | backlog_items | 選択数 >= 1 | 少なくとも1つのバックログ項目を選択してください |
