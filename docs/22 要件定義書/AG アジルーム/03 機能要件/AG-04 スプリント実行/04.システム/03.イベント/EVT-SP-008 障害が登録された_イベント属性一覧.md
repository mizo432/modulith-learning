# イベント属性一覧

障害が登録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SP-008 |
| イベント名 | 障害が登録された |
| 説明 | 阻害要因、影響、担当が記録された |
| 関連ユースケース | UC-SP-009 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | event_id | String | はい | - | 一意 | イベントの一意な識別子 |
| 2 | occurred_at | DateTime | はい | - | - | イベントが発生した日時 |
| 3 | sprint_id | String | はい | - | 一意 | 関連するSprintの識別子 |
| 4 | impediment_id | String | はい | - | 一意 | 登録された障害の識別子 |
| 5 | title | String | はい | - | 最大255文字 | 障害のタイトル |
| 6 | description | String | はい | - | 最大2000文字 | 障害の詳細説明 |
| 7 | impact | String | いいえ | - | 最大1000文字 | 影響範囲 |
| 8 | assignee_id | String | いいえ | - | - | 担当者の識別子 |
| 9 | created_by | String | はい | - | - | 障害を登録したユーザーの識別子 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 障害登録ボタンクリック | 手動 | 開発者またはSMが障害を登録ボタンをクリック | 阻害要因の記録 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | sprint_id | String | はい | 関連するSprintの識別子 |
| 2 | impediment_id | String | はい | 登録された障害の識別子 |
| 3 | title | String | はい | 障害のタイトル |
| 4 | description | String | はい | 障害の詳細説明 |
| 5 | impact | String | いいえ | 影響範囲 |
| 6 | assignee_id | String | いいえ | 担当者の識別子 |
| 7 | created_by | String | はい | 登録者 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 障害エンティティの作成 | 障害データをデータベースに保存 | UC-SP-009 | 障害の永続化 |
| 2 | アクティビティの記録 | 障害登録のアクティビティを記録 | - | 監査証跡の記録 |
| 3 | 通知の送信 | 関連メンバーに障害登録を通知 | UC-SP-013 | チームへの通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 登録者権限 | created_by | 開発者またはSMのみ | 障害の登録は開発者とSMのみ可能 |
| 2 | Sprintの存在 | sprint_id | 対象Sprintが存在する | 既存のSprintにのみ障害を登録可能 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 障害タイトルの必須入力 | title | 文字数 > 0 | 障害のタイトルを入力してください |
| 2 | 障害説明の必須入力 | description | 文字数 > 0 | 障害の詳細説明を入力してください |
