# INF-SP-12 タスク種類_情報属性一覧

タスク種類の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SP-12 |
| 情報名 | タスク種類 |
| 情報種類 | 対照表 |
| 説明 | タスクの種類（Story実現、Urgent、技術的負債、保守、調査） |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | task_type_code | ✓ | String | 必須 | タスク種類のコード |
| 2 | task_type_name | | String | 必須 | タスク種類の名称 |
| 3 | description | | String | 任意 | 説明 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのタスク種類は、1つの作業カテゴリである |
| 同一性 (Sameness) | task_type_codeが同じであれば、同じタスク種類である |
| カテゴリ (Category) | タスクの種類分類 |

## 対照表データ

| task_type_code | task_type_name | description |
|----------------|----------------|-------------|
| STORY | Story実現のための開発Task | User Storyを実現するための開発作業 |
| URGENT | Urgent Task | 本番障害、セキュリティ脆弱性対応、データ修正、インフラ障害など |
| TECH_DEBT | 技術的負債の解消 | コード品質の改善やリファクタリング |
| MAINTENANCE | 保守・運用Task | 運用・保守に関する定期的な作業 |
| INVESTIGATION | 調査Task | 原因調査や技術検証などの探索的な作業 |
