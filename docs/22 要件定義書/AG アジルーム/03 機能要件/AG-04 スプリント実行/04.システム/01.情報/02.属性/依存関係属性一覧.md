# 依存関係属性一覧

スプリント実行とインクリメント形成業務領域で扱う「依存関係」の属性を定義します。

| 属性名           | 型          | PK | 必須 | 説明                           |
|------------------|-------------|----|------|--------------------------------|
| dependency_id    | SnowflakeID | *  | Y    | 依存関係の一意な識別子         |
| source_item_id   | SnowflakeID |    | Y    | 依存元のBacklog項目の識別子    |
| target_item_id   | SnowflakeID |    | Y    | 依存先のBacklog項目の識別子    |
| dependency_type  | Enum        |    | Y    | 依存関係の種類                 |
| description      | Text        |    | N    | 依存関係の説明                 |
| created_at       | DateTime    |    | Y    | 作成日時                       |
| updated_at       | DateTime    |    | Y    | 最終更新日時                   |
