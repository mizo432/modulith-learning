# INF-IDB-03 Task Work Log 情報属性一覧

## 情報概要

| 項目 | 値 |
|------|-----|
| 情報ID | INF-IDB-03 |
| 情報名 | Task Work Log |
| 情報種類 | イベント |
| 説明 | Taskの作業実績（時間記録）を記録する |
| 履歴管理要 | N |
| 証跡要 | N |
| 実現方法 | DB |

## 個体指定子（主キー）

| 属性名 | 型 | 必須/任意 | 説明 |
|--------|----|-----------|------|
| id | Long | 必須 | 作業実績の一意識別子 |

## 属性

| 属性名 | 型 | 必須/任意 | 説明 |
|--------|----|-----------|------|
| taskId | Long | 必須 | 関連するTaskのID |
| sprintId | Long | 必須 | 関連するSprintのID |
| workerId | String | 必須 | 作業担当者 |
| workedHours | Double | 必須 | 作業時間（時間単位） |
| workedDate | Date | 必須 | 作業日 |
| createdAt | DateTime | 必須 | 記録日時 |
| comment | String | 任意 | 作業内容のメモ |

## 関連情報

| 情報ID | 情報名 | 関係 | 説明 |
|--------|--------|------|------|
| INF-SP-10 | タスク | 1:N | 1つのTaskに複数の作業実績 |
| INF-SP-01 | スプリント | 1:N | 1つのSprintに複数の作業実績 |

## エンティティの3大要素

1. **単一性 (Oneness)**: 1回の作業記録
2. **同一性 (Sameness)**: id で一意に識別される
3. **カテゴリ (Category)**: Taskの作業実績
