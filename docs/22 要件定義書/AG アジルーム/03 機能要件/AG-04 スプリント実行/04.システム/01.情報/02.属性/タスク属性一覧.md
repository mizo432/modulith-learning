# タスク属性一覧

スプリント実行とインクリメント形成業務領域で扱う「タスク」の属性を定義します。

| 属性名                 | 型          | PK | 必須 | 説明                               |
|------------------------|-------------|----|------|------------------------------------|
| task_id                | SnowflakeID | *  | Y    | タスクの一意な識別子               |
| sprint_backlog_item_id | SnowflakeID |    | Y    | 関連するSprint Backlog項目の識別子 |
| title                  | String      |    | Y    | タスクのタイトル                   |
| description            | Text        |    | N    | タスクの詳細説明                   |
| estimated_hours        | Decimal     |    | N    | 推定作業時間                       |
| status                 | Enum        |    | Y    | 現在の状態                         |
| created_at             | DateTime    |    | Y    | 作成日時                           |
| updated_at             | DateTime    |    | Y    | 最終更新日時                       |
