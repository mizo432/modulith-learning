# INF-SP-10 タスク_情報属性一覧

タスクの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SP-10 |
| 情報名 | タスク |
| 情報種類 | リソース |
| 説明 | Sprintに直接所属する作業単位。User Storyとの関連は任意 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | task_id | ✓ | String | 必須 | タスクの一意な識別子（UUID） |
| 2 | sprint_id | | String | 必須 | 所属するSprintの識別子（FK） |
| 3 | backlog_item_id | | String | 任意 | 関連するUser Storyの識別子（FK、任意） |
| 4 | title | | String | 必須 | タスクのタイトル |
| 5 | description | | String | 任意 | タスクの詳細説明 |
| 6 | status | | Enum | 必須 | 作業状態（未着手、作業中、レビュー中、完了） |
| 7 | estimate | | Double | 任意 | 見積もり作業量（時間） |
| 8 | actual | | Double | 任意 | 実際の作業量（時間） |
| 9 | task_type | | Enum | 必須 | タスクの種類（Story実現、Urgent、技術的負債、保守、調査） |
| 10 | priority | | Integer | 任意 | 優先順位（数値が小さいほど優先度高） |
| 11 | created_at | | DateTime | 必須 | 作成日時 |
| 12 | updated_at | | DateTime | 必須 | 最終更新日時 |
| 13 | completed_at | | DateTime | 任意 | 完了日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのタスクは、Sprint内の1つの作業単位である |
| 同一性 (Sameness) | task_idが同じであれば、同じタスクである |
| カテゴリ (Category) | task_typeで分類（Story実現、Urgent、技術的負債、保守、調査） |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未着手 | タスクがまだ開始されていない状態 | - | 作業中 | UC-SP-021 Urgentタスクを更新する |
| 作業中 | タスクが実行中の状態 | 未着手 | レビュー中, 完了 | UC-SP-021 Urgentタスクを更新する |
| レビュー中 | タスクがレビュー待ちの状態 | 作業中 | 完了, 作業中 | UC-SP-021 Urgentタスクを更新する |
| 完了 | タスクが完了した状態 | 作業中, レビュー中 | - | UC-SP-021 Urgentタスクを更新する |
