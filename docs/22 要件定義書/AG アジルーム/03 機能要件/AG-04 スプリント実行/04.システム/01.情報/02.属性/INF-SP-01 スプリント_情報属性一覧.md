# 情報属性一覧

スプリントの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SP-01 |
| 情報名 | スプリント |
| 情報種類 | リソース |
| 説明 | スプリントの計画情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | スプリントの一意な識別子 |
| 2 | name | | String | 必須 | スプリントの名前 |
| 3 | startDate | | Date | 必須 | 開始日 |
| 4 | endDate | | Date | 必須 | 終了日 |
| 5 | goal | | String | 任意 | スプリントの目標 |
| 6 | status | | Enum | 必須 | 状態（計画, 実行中, 完了, キャンセル） |

## 単一性・同一性・カテゴリ

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのスプリントは、名前・期間の組み合わせで1つのスプリントを構成する |
| 同一性 (Sameness) | idが同じ場合、同じスプリントであると判断する |
| カテゴリ (Category) | スプリントの計画情報 |

## 状態遷移

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 計画 | スプリントが計画された状態 | - | 実行中 | スプリントを作成する |
| 実行中 | スプリントが進行中の状態 | 計画 | 完了, キャンセル | スプリントを更新する |
| 完了 | スプリントが完了した状態 | 実行中 | - | - |
| キャンセル | スプリントがキャンセルされた状態 | 実行中 | - | - |

## 関連情報

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-SP-02 | スプリントバックログ | 1対多 | スプリントは複数のタスクを持つ |
| INF-SP-03 | 進捗 | 1対多 | スプリントは複数の進捗記録を持つ |
| INF-SP-04 | バーンダウンチャート | 1対多 | スプリントは複数のチャートデータを持つ |
