# 情報属性一覧

バーンダウンチャートの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SP-04 |
| 情報名 | バーンダウンチャート |
| 情報種類 | リソース |
| 説明 | 進捗の可視化データ |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | チャートの一意な識別子 |
| 2 | sprintId | | Long | 必須 | 関連するスプリントのID |
| 3 | date | | Date | 必須 | 日付 |
| 4 | remainingPoints | | Integer | 必須 | 残りポイント |

## 単一性・同一性・カテゴリ

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのチャートデータは、スプリント・日付の組み合わせで1つのデータを構成する |
| 同一性 (Sameness) | idが同じ場合、同じチャートデータであると判断する |
| カテゴリ (Category) | スプリントの進捗可視化データ |

## 状態遷移

この情報は状態遷移を持ちません。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | - | - | - | - |
