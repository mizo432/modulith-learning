# アクティビティ属性一覧

スプリント実行とインクリメント形成業務領域で扱う「アクティビティ」の属性を定義します。

| 属性名          | 型          | PK | 必須 | 説明                           |
|-----------------|-------------|----|------|--------------------------------|
| activity_id     | SnowflakeID | *  | Y    | アクティビティの一意な識別子   |
| sprint_id       | SnowflakeID |    | Y    | 関連するスプリントの識別子     |
| actor_id        | UUID        |    | Y    | アクティビティを実行したユーザーの識別子 |
| activity_type   | Enum        |    | Y    | アクティビティの種類           |
| description     | Text        |    | N    | アクティビティの説明           |
| created_at      | DateTime    |    | Y    | 作成日時                       |
