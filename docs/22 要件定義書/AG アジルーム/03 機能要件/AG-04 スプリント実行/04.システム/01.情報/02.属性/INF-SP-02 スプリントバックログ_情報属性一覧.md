# 情報属性一覧

スプリントバックログの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SP-02 |
| 情報名 | スプリントバックログ |
| 情報種類 | リソース |
| 説明 | スプリントで実行するタスク |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | タスクの一意な識別子 |
| 2 | sprintId | | Long | 必須 | 関連するスプリントのID |
| 3 | title | | String | 必須 | タスクのタイトル |
| 4 | assignee | | String | 任意 | 担当者 |
| 5 | status | | Enum | 必須 | 状態（未着手, 作業中, 完了） |
| 6 | dependency | | String | 任意 | 依存関係 |

## 単一性・同一性・カテゴリ

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのタスクは、タイトル・スプリントの組み合わせで1つのタスクを構成する |
| 同一性 (Sameness) | idが同じ場合、同じタスクであると判断する |
| カテゴリ (Category) | スプリントのタスク情報 |

## 状態遷移

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未着手 | タスクが未着手の状態 | - | 作業中 | Sprint Backlogを更新する |
| 作業中 | タスクが作業中の状態 | 未着手 | 完了 | ボードを更新する |
| 完了 | タスクが完了した状態 | 作業中 | - | - |

## 関連情報

|------------|------------|------------|------|
| INF-SP-01 | スプリント | 多対1 | タスクは1つのスプリントに属する |
