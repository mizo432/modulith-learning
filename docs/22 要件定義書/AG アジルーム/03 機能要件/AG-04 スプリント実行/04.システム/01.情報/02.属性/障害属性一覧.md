# 障害属性一覧

スプリント実行とインクリメント形成業務領域で扱う「障害」の属性を定義します。

| 属性名          | 型          | PK | 必須 | 説明                           |
|-----------------|-------------|----|------|--------------------------------|
| impediment_id   | SnowflakeID | *  | Y    | 障害の一意な識別子             |
| sprint_id       | SnowflakeID |    | Y    | 関連するスプリントの識別子     |
| title           | String      |    | Y    | 障害のタイトル                 |
| description     | Text        |    | Y    | 障害の詳細説明                 |
| impact          | Text        |    | N    | 影響範囲                       |
| assignee_id     | UUID        |    | N    | 担当者の識別子                 |
| status          | Enum        |    | Y    | 現在の状態（新規、対応中、解消済み） |
| resolved_at     | DateTime    |    | N    | 解消日時                       |
| created_at      | DateTime    |    | Y    | 作成日時                       |
| updated_at      | DateTime    |    | Y    | 最終更新日時                   |
