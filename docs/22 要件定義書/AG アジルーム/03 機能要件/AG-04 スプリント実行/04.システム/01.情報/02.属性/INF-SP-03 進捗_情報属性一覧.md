# 情報属性一覧

進捗の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SP-03 |
| 情報名 | 進捗 |
| 情報種類 | リソース |
| 説明 | スプリントの進捗情報 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 進捗の一意な識別子 |
| 2 | sprintId | | Long | 必須 | 関連するスプリントのID |
| 3 | date | | Date | 必須 | 日付 |
| 4 | completedPoints | | Integer | 必須 | 完了ポイント |
| 5 | totalPoints | | Integer | 必須 | 総ポイント |

## 単一性・同一性・カテゴリ

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの進捗記録は、スプリント・日付の組み合わせで1つの記録を構成する |
| 同一性 (Sameness) | idが同じ場合、同じ進捗記録であると判断する |
| カテゴリ (Category) | スプリントの進捗情報 |

## 状態遷移
