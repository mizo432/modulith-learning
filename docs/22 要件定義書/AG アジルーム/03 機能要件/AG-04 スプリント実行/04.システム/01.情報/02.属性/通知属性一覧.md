# 通知属性一覧

スプリント実行とインクリメント形成業務領域で扱う「通知」の属性を定義します。

| 属性名          | 型          | PK | 必須 | 説明                                             |
|-----------------|-------------|----|------|--------------------------------------------------|
| id              | SnowflakeID | *  | Y    | 通知の一意な識別子                               |
| recipient_id    | UUID        |    | Y    | 受信者の識別子（従業員ID）                       |
| source_id       | UUID        |    | N    | 通知の送信元となるリソースのID（例: タスクID、スプリントID） |
| source_domain   | String      |    | Y    | 通知の送信元となる事業領域名（例: agiloom）      |
| title           | String      |    | Y    | 通知のタイトル（200文字以内）                    |
| content         | String      |    | Y    | 通知の本文（2000文字以内）                       |
| type            | Enum        |    | Y    | 通知種別（MENTION、ASSIGNEE_CHANGE、DUE_DATE、AWAITING_DECISION、APPROVAL_RESULT、JOB_EXECUTION_RESULT、SYSTEM、CUSTOM） |
| is_read         | Boolean     |    | Y    | 既読フラグ（デフォルト: false）                  |
| created_at      | DateTime    |    | Y    | 作成日時                                         |
| updated_at      | DateTime    |    | Y    | 最終更新日時                                     |
| deleted_at      | DateTime    |    | N    | 削除日時（論理削除用）                           |
