# 通知属性一覧

スプリント実行とインクリメント形成業務領域で扱う「通知」の属性を定義します。

| 属性名          | 型          | PK | 必須 | 説明                                             |
|-----------------|-------------|----|------|--------------------------------------------------|
| notification_id | SnowflakeID | *  | Y    | 通知の一意な識別子                               |
| recipient_id    | UUID        |    | Y    | 受信者の識別子                                   |
| project_id      | UUID        |    | Y    | 所属プロジェクトの識別子                         |
| title           | String      |    | Y    | 通知のタイトル                                   |
| content         | Text        |    | Y    | 通知の内容                                       |
| type            | Enum        |    | Y    | 通知種別（メンション、担当変更、期限、判断待ち） |
| is_read         | Boolean     |    | Y    | 既読フラグ                                       |
| created_at      | DateTime    |    | Y    | 作成日時                                         |
| updated_at      | DateTime    |    | Y    | 最終更新日時                                     |
