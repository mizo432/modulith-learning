# 情報一覧

スプリント実行とインクリメント形成業務領域で扱う情報を定義します。

| ID        | 情報名             | 情報種類 | 履歴管理要 | 実現方法   | 説明                                                   |
|-----------|--------------------|----------|------------|------------|--------------------------------------------------------|
| INF-SP-01 | スプリント         | リソース | Y          | DB         | スプリント期間、状態、チーム                           |
| INF-SP-02 | Sprint Goal        | リソース | Y          | DB         | スプリントの目的と関連項目                             |
| INF-SP-03 | Sprint Backlog項目 | リソース | Y          | DB         | 選択項目、作業、状態、担当                             |
| INF-SP-04 | 障害               | リソース | Y          | DB         | 阻害要因、影響、担当、解消状況                         |
| INF-SP-05 | 依存関係           | 対応表   | N          | DB         | 項目間・チーム間の依存                                 |
| INF-SP-06 | 通知               | イベント | N          | DB         | メンション、担当変更、期限、判断待ち                   |
| INF-SP-07 | アクティビティ     | イベント | N          | DB         | 作業状態変更、コメント追加など                         |
| INF-SP-08 | スプリント状態     | 対照表   | N          | DB and enum | 計画済み、実行中、完了、キャンセル                     |
| INF-SP-09 | 作業状態           | 対照表   | N          | DB and enum | 未着手、作業中、レビュー中、完了                       |
| INF-SP-10 | タスク             | リソース | N          | DB         | Sprint Backlog項目を分解した作業単位                   |
| INF-SP-11 | タスク割り当て     | 対応表   | N          | DB         | タスクと担当者の割り当て関係                           |
