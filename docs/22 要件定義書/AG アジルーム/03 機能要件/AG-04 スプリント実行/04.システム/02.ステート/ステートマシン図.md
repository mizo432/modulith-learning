# ステートマシン図

スプリント実行業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、AG-04 スプリント実行業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図（英語版）

```plantuml
@startuml
title Sprint Execution State Model Diagram
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

' Sprint states
state "Planned" as Planned_SP <<entry>>
state "InProgress" as InProgress_SP
state "Completed" as Completed_SP <<exit>>
state "Cancelled" as Cancelled_SP <<exit>>

' Sprint Backlog Item states
state "NotStarted" as NotStarted_SBI <<entry>>
state "InProgress" as InProgress_SBI
state "InReview" as InReview_SBI
state "Done" as Done_SBI <<exit>>

' Bug states
state "New" as New_BG <<entry>>
state "InProgress" as InProgress_BG
state "Resolved" as Resolved_BG <<exit>>

' Sprint transitions
Planned_SP --> InProgress_SP : Sprint Updated (UC-SP-002)
InProgress_SP --> Completed_SP : Sprint Updated (UC-SP-002)
InProgress_SP --> Cancelled_SP : Sprint Updated (UC-SP-002)

' Sprint Backlog Item transitions
NotStarted_SBI --> InProgress_SBI : Sprint Backlog Updated (UC-SP-007)
InProgress_SBI --> InReview_SBI : Board Updated (UC-SP-008)
InReview_SBI --> Done_SBI : Board Updated (UC-SP-008)
InReview_SBI --> InProgress_SBI : Board Updated (UC-SP-008)

' Bug transitions
New_BG --> InProgress_BG : Bug Updated (UC-SP-010)
InProgress_BG --> Resolved_BG : Bug Updated (UC-SP-010)
@enduml
```

## 3. 日本語版 状態遷移図

```plantuml

' Sprint Backlog項目 状態
state "未着手" as NotStarted_SBI <<entry>>
state "作業中" as InProgress_SBI
state "レビュー中" as InReview_SBI
state "完了" as Done_SBI <<exit>>

' 障害 状態
state "新規" as New_BG <<entry>>

' スプリント 遷移
Planned_SP --> InProgress_SP : スプリントを更新する (UC-SP-002)

' Sprint Backlog項目 遷移
NotStarted_SBI --> InProgress_SBI : Sprint Backlogを更新する (UC-SP-007)

@enduml
```

## 4. 状態一覧

| 状態名 (ID)       | 英語名        | 対象情報         | 説明                                     |
|-------------------|---------------|------------------|------------------------------------------|
| 計画済み (ST-SP-01) | Planned     | スプリント       | スプリントが作成され、計画が完了した     |
| 実行中 (ST-SP-02)  | InProgress  | スプリント       | スプリントが進行中                       |
| 完了 (ST-SP-03)    | Completed   | スプリント       | スプリントが終了し、成果が確認された     |
| キャンセル (ST-SP-04) | Cancelled | スプリント       | スプリントが中止された                   |
| 未着手 (ST-SP-05)  | NotStarted  | Sprint Backlog項目 | 作業が開始されていない                 |
| 作業中 (ST-SP-06)  | InProgress  | Sprint Backlog項目 | 実装・設計が進行中                     |
| レビュー中 (ST-SP-07) | InReview  | Sprint Backlog項目 | コードレビューやテスト中               |
| 完了 (ST-SP-08)    | Done        | Sprint Backlog項目 | 作業が完了し、Doneの基準を満たした       |
| 新規 (ST-SP-09)    | New         | 障害             | 報告されたが、まだ対応されていない       |
| 対応中 (ST-SP-10)  | InProgress  | 障害             | 解消のための対応が進行中                 |
| 解消済み (ST-SP-11) | Resolved   | 障害             | 障害が解消された                         |
