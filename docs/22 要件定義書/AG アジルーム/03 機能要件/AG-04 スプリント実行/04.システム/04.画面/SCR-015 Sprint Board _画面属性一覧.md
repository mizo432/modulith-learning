# 画面属性一覧

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-015 |
| 画面名 | Sprint Board / タスクボード |
| 説明 | Story・Taskの状態、作業中項目、ブロッカーを更新・確認する |
| 関連ユースケース | UC-SP-007, UC-SP-008, UC-SP-009, UC-SP-010, UC-SP-011, UC-SP-012, UC-SP-013, UC-SP-014, UC-SP-015, UC-SP-017, UC-SP-018, UC-SP-019 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Story名 | 表示 | String | はい | - | 最大255文字 | ユーザーストーリーの名前 |
| 2 | タスク名 | 表示 | String | はい | - | 最大255文字 | タスクの名前 |
| 3 | 状態 | 選択 | Enum | はい | - | 未着手/作業中/レビュー中/完了 | 作業の現在の状態 |
| 4 | 担当者 | 選択 | String | いいえ | - | - | 担当開発者 |
| 5 | 見積もり | 表示 | Double | いいえ | - | 0以上 | 作業の見積もり値 |
| 6 | 実際の作業時間 | 入力 | Double | いいえ | - | 0以上 | 実際の作業時間 |
| 7 | 進捗 | 表示 | Integer | いいえ | 0 | 0-100 | 作業の進捗率（%） |
| 8 | 障害 | 入力 | String | いいえ | - | 最大1000文字 | 阻害要因の内容 |
| 9 | 依存関係 | 表示 | String | いいえ | - | - | 依存する他の項目 |
| 10 | 通知対象 | 選択 | String | いいえ | - | - | 通知を送信する対象者 |
| 11 | ソース管理情報 | 入力 | String | いいえ | - | 最大500文字 | 関連するコミット・ブランチ・PR |
| 12 | ビルド状況 | 表示 | Enum | いいえ | - | 成功/失敗/実行中 | ビルド・デプロイの状況 |
| 13 | 備考 | 入力 | String | いいえ | - | 最大1000文字 | その他の補足情報 |
| 14 | Sprint名 | 表示 | String | はい | - | - | 現在のSprint名 |
| 15 | 進捗率 | 表示 | Integer | はい | 0 | 0-100 | Sprint全体の進捗率 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | Sprint名、期間、進捗率を表示 | Sprint名、進捗率 |
| 2 | ナビゲーション | ボードビュー、リストビューの切り替え | ビュー切り替えボタン |

| 4 | サイドバー | 障害一覧、依存関係、ビルド状況を表示 | 障害、依存関係、ビルド状況、ソース管理情報 |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | ドラッグ＆ドロップ | 状態 | 状態はドラッグ＆ドロップで変更可能 | UI制約 |
| 2 | 完成の定義 | 状態 | Done状態にするにはDefinition of Doneを満たす必要がある | バリデーション |
| 3 | 進捗率の範囲 | 進捗 | 進捗率は0-100の範囲で入力 | バリデーション |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 進捗率の範囲検証 | 進捗 | 0 <= 進捗 <= 100 | 進捗率は0-100の範囲で入力してください |
| 2 | 実際の作業時間の検証 | 実際の作業時間 | 実際の作業時間 >= 0 | 実際の作業時間は0以上で入力してください |
| 3 | 完成の定義チェック | 状態 | Definition of Doneを満たす | 完成の定義を満たしてから完了にしてください |
