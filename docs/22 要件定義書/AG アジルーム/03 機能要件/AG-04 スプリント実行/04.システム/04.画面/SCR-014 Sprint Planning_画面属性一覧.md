# 画面属性一覧

Sprint Planningの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-014 |
| 画面名 | Sprint Planning |
| 説明 | Sprint Goal、バックログ選択、容量・ベロシティ、タスク分解を協働で決める |
| 関連ユースケース | UC-SP-001, UC-SP-004, UC-SP-005, UC-SP-006 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Sprint名 | 入力 | String | はい | - | 最大255文字 | Sprintの名前 |
| 2 | 期間開始日 | 入力 | Date | はい | - | 終了日以前 | Sprintの開始日 |
| 3 | 期間終了日 | 入力 | Date | はい | - | 開始日以降 | Sprintの終了日 |
| 4 | チーム | 選択 | String | はい | - | - | 担当チーム |
| 5 | Sprint Goal | 入力 | String | はい | - | 最大2000文字 | Sprintの目的 |
| 6 | 選択Story | チェックボックス | String | はい | - | - | 選択されたStory |
| 7 | 容量 | 入力 | Integer | いいえ | - | 0以上 | チームの作業容量 |
| 8 | ベロシティ | 表示 | Integer | いいえ | - | 0以上 | チームのベロシティ |
| 9 | タスク | 入力 | String | いいえ | - | 最大500文字 | 分解したタスク |
| 10 | 担当者 | 選択 | String | いいえ | - | - | タスクの担当者 |
| 11 | 見積もり | 入力 | Double | いいえ | - | 0以上 | タスクの見積もり値 |
| 12 | 備考 | 入力 | String | いいえ | - | 最大1000文字 | その他の補足情報 |
| 13 | 関連項目 | 表示 | String | いいえ | - | - | 関連するバックログ項目のリスト |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | Sprint名、期間、チームを表示 | Sprint名、期間開始日、期間終了日、チーム |
| 2 | ナビゲーション | Sprint Goal、バックログ選択、タスク分解のタブ切り替え | タブボタン |
| 3 | メインコンテンツ | 選択したタブに対応する詳細情報を表示・編集 | Sprint Goal、選択Story、タスク、担当者、見積もり |
| 4 | サイドバー | ベロシティ、容量、選択済みStory一覧を表示 | ベロシティ、容量、選択Story、関連項目 |

## 画面操作

画面で実行可能な操作を定義します。

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | Sprintを作成 | ボタンクリック | 新規Sprintを登録する | SCR-013 |
| 2 | Sprint Goalを設定 | ボタンクリック | Sprintの目的を記録する | - |
| 3 | Sprint Goalを更新 | ボタンクリック | Sprintの目的を修正する | - |
| 4 | Sprint Backlogを作成 | ボタンクリック | 選択項目と作業を定義する | - |
| 5 | Storyを追加 | チェックボックス変更 | バックログからStoryを選択する | - |
| 6 | タスクを分解 | ボタンクリック | Storyをタスクに分解する | - |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 編集権限 | 全項目 | Sprint Planningの編集はプロダクトオーナーとスクラムマスターのみ可能 | 権限チェック |
| 2 | 容量の整合性 | 選択Story、容量 | 選択したStoryの見積もり合計はチームの容量を超えてはいけない | バリデーション |
| 3 | 期間の整合性 | 期間開始日、期間終了日 | Sprintの期間終了日は開始日以降でなければならない | バリデーション |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 期間終了日の検証 | 期間終了日 | 期間終了日 >= 期間開始日 | 期間終了日は開始日以降に設定してください |
| 2 | 容量の検証 | 選択Story、容量 | 選択Storyの見積もり合計 <= 容量 | 選択したStoryの見積もり合計は容量を超えています |
| 3 | Sprint Goalの必須入力 | Sprint Goal | 文字数 > 0 | Sprint Goalを入力してください |
| 4 | 選択Storyの必須入力 | 選択Story | 選択数 >= 1 | 少なくとも1つのStoryを選択してください |
