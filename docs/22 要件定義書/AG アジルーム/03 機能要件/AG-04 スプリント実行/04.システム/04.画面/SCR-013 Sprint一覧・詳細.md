# Sprint一覧・詳細

Sprint一覧・詳細画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-013 |
| 画面名           | Sprint一覧・詳細 |
| 説明             | Sprint期間、目標、選択Story、状態を確認する |
| 関連ユースケース | UC-SP-002, UC-SP-003 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、Sprint総数、進行中Sprintを表示 |
| 検索・フィルター | 状態、期間で検索・絞り込み |
| メインコンテンツ | Sprint一覧表または詳細情報を表示 |
| サイドバー | 状態別集計、ベロシティ推移を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Sprint名 | 文字列 | はい | Sprintの名前 |
| 2 | 期間開始日 | 日付 | はい | Sprintの開始日 |
| 3 | 期間終了日 | 日付 | はい | Sprintの終了日 |
| 4 | 状態 | 選択 | はい | 状態（計画、進行中、完了） |
| 5 | Sprint Goal | テキスト | いいえ | Sprintの目的 |
| 6 | 選択Story | 複数選択 | いいえ | 選択されたStory |
| 7 | チーム | 選択 | はい | 担当チーム |
| 8 | ベロシティ | 数値 | いいえ | チームのベロシティ |
| 9 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Sprintを更新 | Sprintの情報を修正する |
| 2 | Sprintを参照 | 現在のSprintの状況を確認する |
| 3 | 検索 | 条件に合致するSprintを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Sprintの編集はプロダクトオーナーとスクラムマスターのみ可能 |
| 2 | 期間の整合性 | Sprintの期間終了日は開始日以降でなければならない |
