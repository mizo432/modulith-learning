# Daily Scrum記録

Daily Scrum記録画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-016 |
| 画面名           | Daily Scrum記録 |
| 説明             | Sprint Goalに向けた状況、障害、計画調整を記録する |
| 関連ユースケース | UC-SP-016 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint名、日付、参加者を表示 |
| ナビゲーション | 記録一覧、新規記録の切り替え |
| メインコンテンツ | 日付ごとのDaily Scrum記録を表示・編集 |
| サイドバー | Sprint Goal、関連障害を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 日付 | 日付 | はい | Daily Scrumの実施日 |
| 2 | 参加者 | 複数選択 | はい | 参加したメンバー |
| 3 | 昨日の成果 | テキスト | いいえ | 昨日達成した事項 |
| 4 | 今日の計画 | テキスト | いいえ | 今日行う予定の事項 |
| 5 | 障害 | テキスト | いいえ | 直面している障害 |
| 6 | Sprint Goalへの状況 | テキスト | いいえ | Sprint Goalに向けた進捗状況 |
| 7 | 計画調整 | テキスト | いいえ | 計画の調整内容 |
| 8 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | デイリースクラムを記録 | 当日の記録を作成する |
| 2 | 記録を参照 | 過去の記録を確認する |
| 3 | 検索 | 日付やキーワードで検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Daily Scrumの記録は開発チームのみ可能 |
| 2 | 日付の一意性 | 同じ日付の記録は1回のみ |
