# 画面属性一覧

Daily Scrum記録の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-016 |
| 画面名 | Daily Scrum記録 |
| 説明 | Sprint Goalに向けた状況、障害、計画調整を記録する |
| 関連ユースケース | UC-SP-016 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 日付 | 入力 | Date | はい | 今日 | - | Daily Scrumの実施日 |
| 2 | 参加者 | 選択 | String | はい | - | - | 参加したメンバー |
| 3 | 昨日の成果 | 入力 | String | いいえ | - | 最大2000文字 | 昨日達成した事項 |
| 4 | 今日の計画 | 入力 | String | いいえ | - | 最大2000文字 | 今日行う予定の事項 |
| 5 | 障害 | 入力 | String | いいえ | - | 最大1000文字 | 直面している障害 |
| 6 | Sprint Goalへの状況 | 入力 | String | いいえ | - | 最大2000文字 | Sprint Goalに向けた進捗状況 |
| 7 | 計画調整 | 入力 | String | いいえ | - | 最大1000文字 | 計画の調整内容 |
| 8 | 備考 | 入力 | String | いいえ | - | 最大1000文字 | その他の補足情報 |
| 9 | Sprint名 | 表示 | String | はい | - | - | 現在のSprint名 |
| 10 | Sprint Goal | 表示 | String | はい | - | - | Sprintの目的 |
| 11 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 記録を検索するキーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

| 4 | サイドバー | Sprint Goal、関連障害を表示 | Sprint Goal、障害 |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 編集権限 | 全項目 | Daily Scrumの記録は開発チームのみ可能 | 権限チェック |
| 2 | 日付の一意性 | 日付 | 同じ日付の記録は1回のみ | バリデーション |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 日付の一意性チェック | 日付 | 同じ日付の記録が存在しない | 同じ日付の記録は既に存在します |
| 2 | 参加者の必須入力 | 参加者 | 選択数 >= 1 | 少なくとも1人の参加者を選択してください |
| 3 | 検索キーワードの文字数 | 検索キーワード | 文字数 <= 100 | 検索キーワードは100文字以内で入力してください |
