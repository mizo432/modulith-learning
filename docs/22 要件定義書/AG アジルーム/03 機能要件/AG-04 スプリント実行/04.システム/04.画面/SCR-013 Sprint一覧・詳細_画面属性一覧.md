# 画面属性一覧

Sprint一覧・詳細の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-013 |
| 画面名 | Sprint一覧・詳細 |
| 説明 | Sprint期間、目標、選択Story、状態を確認する |
| 関連ユースケース | UC-SP-002, UC-SP-003 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Sprint名 | 表示 | String | はい | - | 最大255文字 | Sprintの名前 |
| 2 | 期間開始日 | 表示 | Date | はい | - | 終了日以前 | Sprintの開始日 |
| 3 | 期間終了日 | 表示 | Date | はい | - | 開始日以降 | Sprintの終了日 |
| 4 | 状態 | 表示 | Enum | はい | - | 計画済み/実行中/完了/キャンセル | Sprintの現在の状態 |
| 5 | Sprint Goal | 表示 | String | いいえ | - | 最大2000文字 | Sprintの目的 |
| 6 | 選択Story | リンク | String | いいえ | - | - | 選択されたStory一覧（詳細画面へリンク） |
| 7 | チーム | 表示 | String | はい | - | - | 担当チーム名 |
| 8 | ベロシティ | 表示 | Integer | いいえ | - | 0以上 | チームのベロシティ |
| 9 | 備考 | 表示 | String | いいえ | - | 最大1000文字 | その他の補足情報 |
| 10 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | Sprintを検索するキーワード |
| 11 | 状態フィルター | 選択 | Enum | いいえ | すべて | - | 状態で絞り込む |
| 12 | 期間フィルター | 入力 | Date | いいえ | - | - | 期間で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | プロダクト名、Sprint総数、進行中Sprintを表示 | Sprint名、チーム |
| 2 | 検索・フィルター | 状態、期間で検索・絞り込み | 検索キーワード、状態フィルター、期間フィルター |
| 3 | メインコンテンツ | Sprint一覧表または詳細情報を表示 | Sprint名、期間開始日、期間終了日、状態、Sprint Goal、選択Story、ベロシティ、備考 |
| 4 | サイドバー | 状態別集計、ベロシティ推移を表示 | 状態、ベロシティ |

## 画面操作

画面で実行可能な操作を定義します。

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | Sprintを更新 | ボタンクリック | Sprintの情報を修正する | SCR-013 |
| 2 | Sprintを参照 | リンククリック | 現在のSprintの状況を確認する | SCR-013詳細 |
| 3 | 検索 | ボタンクリック | 条件に合致するSprintを検索する | - |
| 4 | フィルター適用 | 選択変更 | 状態・期間で絞り込む | - |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 編集権限 | 全項目 | Sprintの編集はプロダクトオーナーとスクラムマスターのみ可能 | 権限チェック |
| 2 | 期間の整合性 | 期間開始日、期間終了日 | Sprintの期間終了日は開始日以降でなければならない | バリデーション |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 期間終了日の検証 | 期間終了日 | 期間終了日 >= 期間開始日 | 期間終了日は開始日以降に設定してください |
| 2 | 検索キーワードの文字数 | 検索キーワード | 文字数 <= 100 | 検索キーワードは100文字以内で入力してください |
