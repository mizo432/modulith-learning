# SCR-029 イテレーションダッシュボード

## 画面概要

| 項目 | 値 |
|------|-----|
| 画面ID | SCR-029 |
| 画面名 | イテレーションダッシュボード |
| 説明 | スプリントの進捗・成果・リスクを可視化するダッシュボード画面 |
| 関連ユースケース | UC-IDB-001 ~ UC-IDB-015 |
| 主な利用者 | ACT-02, ACT-03, ACT-04, ACT-05 |

## 画面領域構成

| 領域名 | 説明 |
|--------|------|
| Sprint情報 | 期間、状態、チーム、Sprint Goal |
| Sprintサマリー | Story・Taskの進捗率、完了数、残作業量 |
| Sprint Goal達成状況 | Goalと関連Storyの完了状況 |
| Burndown Chart | 残作業量の推移グラフ |
| Burnup Chart | 完了量とスコープの推移グラフ |
| User Story進捗 | Storyごとの状態一覧 |
| Task進捗 | Taskの状態・残作業時間 |
| Sprint Scope Change | スコープ変更履歴 |
| リスク・ブロッカー | 未解決の障害・リスク |
| メトリクス比較 | 過去Sprintとの比較 |

## 画面項目一覧

| 項目名 | 項目タイプ | 型 | 必須/任意 | 初期値 | 制約 |
|--------|------------|----|-----------|--------|------|
| Sprint選択ドロップダウン | 選択 | String | 任意 | 現在実行中 | 作成済みのSprintのみ選択可能 |
| Sprint期間 | 表示 | DateRange | - | - | - |
| Sprint状態 | 表示 | Enum | - | - | 計画済み/実行中/完了/キャンセル |
| Sprint Goal | 表示 | String | - | - | - |
| Story完了率 | 表示 | Double | - | 0% | 0-100% |
| Task完了率 | 表示 | Double | - | 0% | 0-100% |
| 完了Story数 | 表示 | Integer | - | 0 | - |
| 完了Task数 | 表示 | Integer | - | 0 | - |
| 残作業時間 | 表示 | Double | - | 0 | - |
| Burndownデータ | 表示 | List | - | - | 日単位 |
| Burnupデータ | 表示 | List | - | - | 日単位 |
| Story一覧 | 表示 | List | - | - | 状態・見積り付き |
| Task一覧 | 表示 | List | - | - | 状態・残作業付き |
| スコープ変更一覧 | 表示 | List | - | - | 日付・内容付き |
| ブロッカー一覧 | 表示 | List | - | - | 未解決のみ強調 |

## 画面操作

| 操作名 | トリガー | 説明 | 遷移先画面 |
|--------|----------|------|------------|
| Sprint切り替え | ドロップダウン選択 | 対象Sprintを変更 | 同一画面 |
| Taskボード遷移 | ボタンクリック | Taskボードを表示 | SCR-015 |
| Sprint Review遷移 | ボタンクリック | Review画面を表示 | SCR-017 |
| Retrospective遷移 | ボタンクリック | Retrospective画面を表示 | SCR-022 |
