# UC-SP-012 依存関係を定義する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-012 |
| ユースケース名 | 依存関係を定義する |
| 英語名 | Define Dependency |
| 説明 | 作業間の依存関係を定義する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-02 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Backlog項目（INF-SP-03）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. 依存関係を定義する項目を選択する
3. 「依存関係を定義」ボタンをクリックする
4. 依存する項目と依存の種類（先行/後続）を選択する
5. 設定を保存する
6. システムが依存関係（INF-SP-05）を登録する
7. 設定完了メッセージを表示する

## 代替フロー

- **4a. 循環参照を検出する場合**
  - 循環参照が検出された場合、エラーメッセージを表示する
  - ユーザーは依存関係を修正して再試行する

## 後置条件

- 依存関係（INF-SP-05）がシステムに登録される
- イベント「EVT-SP-010 依存関係が定義された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-03 | Sprint Backlog項目 | 依存関係定義対象の情報 |
| INF-SP-05 | 依存関係 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-010 | 依存関係が定義された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 循環参照禁止 | 循環する依存関係は定義できない |
