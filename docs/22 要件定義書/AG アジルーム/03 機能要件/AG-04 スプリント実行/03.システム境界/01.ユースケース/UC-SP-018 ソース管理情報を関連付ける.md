# UC-SP-018 ソース管理情報を関連付ける

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-018 |
| ユースケース名 | ソース管理情報を関連付ける |
| 英語名 | Link Source Control Info |
| 説明 | コミット・ブランチ・PRをスプリント作業と関連付ける |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-02 |
| 外部システム | ES-03（ソース管理システム） |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Backlog項目（INF-SP-03）が既に存在すること
- ES-03（ソース管理システム）と連携していること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. ソース管理情報を関連付ける項目を選択する
3. 「ソース管理情報を関連付ける」ボタンをクリックする
4. コミット、ブランチ、またはPRを選択する
5. 関連付けを実行する
6. システムがES-03から情報を取得し、Sprint Backlog項目（INF-SP-03）と関連付ける
7. 関連付け完了メッセージを表示する

## 代替フロー

- **4a. ES-03接続エラーの場合**
  - ES-03への接続に失敗した場合、エラーメッセージを表示する
  - ユーザーは接続状況を確認して再試行する

## 後置条件

- ソース管理情報がSprint Backlog項目（INF-SP-03）と関連付けられる
- イベント「EVT-SP-014 ソース管理情報が関連付けられた」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-03 | Sprint Backlog項目 | 関連付け対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-014 | ソース管理情報が関連付けられた | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 外部システム連携 | ES-03（ソース管理システム）との連携が必要 |
| 2 | 接続権限 | ES-03への接続権限が必要 |
