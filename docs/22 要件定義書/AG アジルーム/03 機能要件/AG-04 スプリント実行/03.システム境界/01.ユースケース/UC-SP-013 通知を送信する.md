# UC-SP-013 通知を送信する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-013 |
| ユースケース名 | 通知を送信する |
| 英語名 | Send Notification |
| 説明 | メンション、担当変更、期限、判断待ちなどを通知する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-04 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. 通知を送信する項目を選択する
3. 「通知を送信」ボタンをクリックする
4. 通知先、通知内容、通知種類（メンション/担当変更/期限/判断待ち）を選択する
5. 送信ボタンをクリックする
6. システムが通知（INF-SP-06）を登録し、送信する
7. 送信完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 通知（INF-SP-06）がシステムに登録される
- 通知が選択されたユーザーに送信される
- イベント「EVT-SP-011 通知が送信された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-06 | 通知 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-011 | 通知が送信された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 通知先、通知内容は必須入力 |
| 2 | 通知種類 | メンション、担当変更、期限、判断待ちの4種類から選択 |
