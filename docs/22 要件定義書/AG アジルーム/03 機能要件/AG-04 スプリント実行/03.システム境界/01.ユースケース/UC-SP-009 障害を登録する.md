# UC-SP-009 障害を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-009 |
| ユースケース名 | 障害を登録する |
| 英語名 | Register Impediment |
| 説明 | 阻害要因、影響、担当を記録する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-03 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. 「障害を登録」ボタンをクリックする
3. 阻害要因、影響、担当を入力する
4. 入力を保存する
5. システムが障害（INF-SP-04）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 障害（INF-SP-04）がシステムに登録される
- イベント「EVT-SP-008 障害が登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-04 | 障害 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-008 | 障害が登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 阻害要因、影響は必須入力 |
| 2 | 文字数制限 | 阻害要因は1000文字以内 |
