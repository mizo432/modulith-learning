# UC-SP-001 スプリントを作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-001 |
| ユースケース名 | スプリントを作成する |
| 英語名 | Create Sprint |
| 説明 | スプリント期間、状態、チームを定義して登録する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-01 |
| 外部システム | - |
| 関連画面 | SCR-014（Sprint Planning） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「Sprint Planning」画面（SCR-014）にアクセスする
2. 「スプリントを作成」ボタンをクリックする
3. スプリント期間（開始日・終了日）、状態、チームを入力する
4. 入力を保存する
5. システムがスプリント（INF-SP-01）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- スプリント（INF-SP-01）がシステムに登録される
- イベント「EVT-SP-001 スプリントが作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-01 | スプリント | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-001 | スプリントが作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | スプリント期間、チームは必須入力 |
| 2 | 期間制限 | スプリント期間は2-4週間以内 |
