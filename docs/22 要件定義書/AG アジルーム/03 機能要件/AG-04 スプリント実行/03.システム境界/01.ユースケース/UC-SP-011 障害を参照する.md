# UC-SP-011 障害を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-011 |
| ユースケース名 | 障害を参照する |
| 英語名 | View Impediment |
| 説明 | 登録された障害の一覧・詳細を確認する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-03 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- 障害（INF-SP-04）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. システムが障害の一覧を表示する
3. ユーザーが特定の障害を選択する
4. システムが障害の詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 障害の一覧・詳細がユーザーに表示される
