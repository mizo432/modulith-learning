# UC-SP-016 デイリースクラムを記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-016 |
| ユースケース名 | デイリースクラムを記録する |
| 英語名 | Record Daily Scrum |
| 説明 | Sprint Goalに向けた状況確認と計画調整を記録する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-SP-02 |
| 外部システム | - |
| 関連画面 | SCR-016（Daily Scrum記録） |

## 前置条件

- ユーザーがシステムにログインしていること
- スプリント（INF-SP-01）が既に存在すること

## 基本フロー

1. ユーザーが「Daily Scrum記録」画面（SCR-016）にアクセスする
2. 「デイリースクラムを記録」ボタンをクリックする
3. Sprint Goalに向けた状況、障害、計画調整を入力する
4. 入力を保存する
5. システムがSprint Backlog項目（INF-SP-03）に記録を追加する
6. 記録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Sprint Backlog項目（INF-SP-03）に記録が追加される
- イベント「EVT-SP-013 デイリースクラムが記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-03 | Sprint Backlog項目 | 記録対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-013 | デイリースクラムが記録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | Sprint Goalに向けた状況は必須入力 |
| 2 | 文字数制限 | 状況は1000文字以内 |
