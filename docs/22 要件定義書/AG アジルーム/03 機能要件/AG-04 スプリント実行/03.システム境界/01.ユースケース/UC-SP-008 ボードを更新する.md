# UC-SP-008 ボードを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-008 |
| ユースケース名 | ボードを更新する |
| 英語名 | Update Board |
| 説明 | カンバンボード上で作業の状態を移動する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-02 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Backlog項目（INF-SP-03）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. 状態を移動する項目を選択する
3. 項目をドラッグ＆ドロップして状態を移動する
4. システムがSprint Backlog項目（INF-SP-03）の状態を更新する
5. システムがアクティビティ（INF-SP-07）を記録する
6. 更新完了メッセージを表示する

## 代替フロー

- **3a. 無効な状態遷移の場合**
  - 定義されていない状態遷移の場合、エラーメッセージを表示する
  - ユーザーは正しい状態を選択して再試行する

## 後置条件

- Sprint Backlog項目（INF-SP-03）の状態が更新される
- アクティビティ（INF-SP-07）が記録される
- イベント「EVT-SP-007 ボードが更新された」が発行される
- イベント「EVT-SP-016 アクティビティが記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-03 | Sprint Backlog項目 | 更新対象の情報 |
| INF-SP-07 | アクティビティ | 記録対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-007 | ボードが更新された | 基本フローステップ4完了後 |
| EVT-SP-016 | アクティビティが記録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 状態遷移 | 定義された状態遷移ルールに従う |
| 2 | ドラッグ＆ドロップ | 状態移動はドラッグ＆ドロップで操作 |
