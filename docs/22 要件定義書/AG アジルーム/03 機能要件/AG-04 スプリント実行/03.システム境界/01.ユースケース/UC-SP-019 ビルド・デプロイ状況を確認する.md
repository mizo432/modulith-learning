# UC-SP-019 ビルド・デプロイ状況を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-019 |
| ユースケース名 | ビルド・デプロイ状況を確認する |
| 英語名 | Check Build and Deploy Status |
| 説明 | CI/CDパイプラインのビルド・デプロイ状況を取得する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-02 |
| 外部システム | ES-04（CI/CDパイプライン） |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Backlog項目（INF-SP-03）が既に存在すること
- ES-04（CI/CDパイプライン）と連携していること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. ビルド・デプロイ状況を確認する項目を選択する
3. 「ビルド・デプロイ状況を確認」ボタンをクリックする
4. システムがES-04からビルド・デプロイ状況を取得する
5. システムがSprint Backlog項目（INF-SP-03）に状況を更新する
6. ユーザーが内容を確認する

## 代替フロー

- **4a. ES-04接続エラーの場合**
  - ES-04への接続に失敗した場合、エラーメッセージを表示する
  - ユーザーは接続状況を確認して再試行する

## 後置条件

- Sprint Backlog項目（INF-SP-03）にビルド・デプロイ状況が更新される
- イベント「EVT-SP-015 ビルド・デプロイ状況が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-03 | Sprint Backlog項目 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-015 | ビルド・デプロイ状況が更新された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 外部システム連携 | ES-04（CI/CDパイプライン）との連携が必要 |
| 2 | 接続権限 | ES-04への接続権限が必要 |
