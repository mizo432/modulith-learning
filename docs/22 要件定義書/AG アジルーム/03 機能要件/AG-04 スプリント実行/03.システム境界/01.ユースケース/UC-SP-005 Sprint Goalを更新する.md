# UC-SP-005 Sprint Goalを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-005 |
| ユースケース名 | Sprint Goalを更新する |
| 英語名 | Update Sprint Goal |
| 説明 | スプリントの目的を修正・更新する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-01 |
| 外部システム | - |
| 関連画面 | SCR-014（Sprint Planning） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Goal（INF-SP-02）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Planning」画面（SCR-014）にアクセスする
2. Sprint Goalを更新するスプリントを選択する
3. 「編集」ボタンをクリックする
4. スプリントの目的を修正する
5. 変更を保存する
6. システムがSprint Goal（INF-SP-02）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Sprint Goal（INF-SP-02）が更新される
- イベント「EVT-SP-004 Sprint Goalが更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-02 | Sprint Goal | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-004 | Sprint Goalが更新された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | スプリントの目的は必須入力 |
| 2 | 文字数制限 | 目的は500文字以内 |
