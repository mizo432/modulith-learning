# UC-SP-015 インクリメントを完成確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-015 |
| ユースケース名 | インクリメントを完成確認する |
| 英語名 | Confirm Increment Completion |
| 説明 | 完成の定義を満たすインクリメントを確認・提示する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-05 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Backlog項目（INF-SP-03）が既に存在すること
- 完成の定義（DoD）が既に定義されていること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. 完成確認対象の項目を選択する
3. 「完成確認」ボタンをクリックする
4. システムが完成の定義（DoD）との照合を行う
5. 完成確認が完了した場合、システムがSprint Backlog項目（INF-SP-03）の状態を更新する
6. 完成確認完了メッセージを表示する

## 代替フロー

- **4a. 完成の定義を満たさない場合**
  - 完成の定義を満たさない場合、エラーメッセージを表示する
  - ユーザーは未完了の項目を修正して再試行する

## 後置条件

- Sprint Backlog項目（INF-SP-03）の状態が更新される
- イベント「EVT-SP-012 インクリメントが完成確認された」が発行される

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-03 | Sprint Backlog項目 | 更新対象の情報 |

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-012 | インクリメントが完成確認された | 基本フローステップ5完了後 |

|------|----------|------|
