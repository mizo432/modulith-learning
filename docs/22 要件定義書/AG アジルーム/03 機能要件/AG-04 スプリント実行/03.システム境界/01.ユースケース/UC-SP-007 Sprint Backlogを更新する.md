# UC-SP-007 Sprint Backlogを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-007 |
| ユースケース名 | Sprint Backlogを更新する |
| 英語名 | Update Sprint Backlog |
| 説明 | 作業の状態・担当・依存関係を修正する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-02 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Backlog項目（INF-SP-03）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. Sprint Backlogを更新する項目を選択する
3. 「編集」ボタンをクリックする
4. 作業の状態、担当、依存関係を修正する
5. 変更を保存する
6. システムがSprint Backlog項目（INF-SP-03）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Sprint Backlog項目（INF-SP-03）が更新される
- イベント「EVT-SP-006 Sprint Backlogが更新された」が発行される
