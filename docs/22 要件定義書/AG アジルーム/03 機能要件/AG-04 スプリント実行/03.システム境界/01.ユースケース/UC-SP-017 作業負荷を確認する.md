# UC-SP-017 作業負荷を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-017 |
| ユースケース名 | 作業負荷を確認する |
| 英語名 | Check Workload |
| 説明 | チームの作業状況や割り込み傾向を把握する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 低 |
| ビジネスユースケース | BUC-SP-04 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- スプリント（INF-SP-01）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. 「作業負荷を確認」ボタンをクリックする
3. システムがチームメンバーごとの作業状況と割り込み傾向を表示する
4. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 作業負荷がユーザーに表示される
