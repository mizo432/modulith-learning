# UC-SP-004 Sprint Goalを設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-004 |
| ユースケース名 | Sprint Goalを設定する |
| 英語名 | Set Sprint Goal |
| 説明 | スプリントの目的と関連項目を記録・共有する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-01 |
| 外部システム | - |
| 関連画面 | SCR-014（Sprint Planning） |

## 前置条件

- ユーザーがシステムにログインしていること
- スプリント（INF-SP-01）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Planning」画面（SCR-014）にアクセスする
2. Sprint Goalを設定するスプリントを選択する
3. 「Sprint Goalを設定」ボタンをクリックする
4. スプリントの目的と関連項目を入力する
5. 入力を保存する
6. システムがSprint Goal（INF-SP-02）を登録する
7. 設定完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Sprint Goal（INF-SP-02）がシステムに登録される
- イベント「EVT-SP-003 Sprint Goalが設定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-01 | スプリント | 関連付ける情報 |
| INF-SP-02 | Sprint Goal | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-003 | Sprint Goalが設定された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | スプリントの目的は必須入力 |
| 2 | 文字数制限 | 目的は500文字以内 |
