# UC-SP-002 スプリントを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-002 |
| ユースケース名 | スプリントを更新する |
| 英語名 | Update Sprint |
| 説明 | スプリントの期間・状態・チーム情報を修正する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-01 |
| 外部システム | - |
| 関連画面 | SCR-013（Sprint一覧・詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- スプリント（INF-SP-01）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint一覧・詳細」画面（SCR-013）にアクセスする
2. 更新対象のスプリントを選択する
3. 「編集」ボタンをクリックする
4. 期間、状態、チーム情報を修正する
5. 変更を保存する
6. システムがスプリント（INF-SP-01）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- スプリント（INF-SP-01）が更新される
- イベント「EVT-SP-002 スプリントが更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-01 | スプリント | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-002 | スプリントが更新された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | スプリント期間、チームは必須入力 |
| 2 | 期間制限 | スプリント期間は2-4週間以内 |
