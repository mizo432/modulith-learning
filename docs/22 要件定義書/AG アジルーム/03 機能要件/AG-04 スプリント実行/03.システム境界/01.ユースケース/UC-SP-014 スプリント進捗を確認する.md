# UC-SP-014 スプリント進捗を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-014 |
| ユースケース名 | スプリント進捗を確認する |
| 英語名 | Check Sprint Progress |
| 説明 | 作業状態・リスク・依存関係を共有する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-04 |
| 外部システム | - |
| 関連画面 | SCR-015（Sprint Board / タスクボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- スプリント（INF-SP-01）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Board / タスクボード」画面（SCR-015）にアクセスする
2. 進捗を確認するスプリントを選択する
3. システムが作業状態、リスク、依存関係を表示する
4. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- スプリント進捗がユーザーに表示される
