# UC-SP-006 Sprint Backlogを作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-006 |
| ユースケース名 | Sprint Backlogを作成する |
| 英語名 | Create Sprint Backlog |
| 説明 | 選択項目、作業、状態、担当、依存関係を定義する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-01 |
| 外部システム | - |
| 関連画面 | SCR-014（Sprint Planning） |

## 前置条件

- ユーザーがシステムにログインしていること
- スプリント（INF-SP-01）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Planning」画面（SCR-014）にアクセスする
2. Sprint Backlogを作成するスプリントを選択する
3. 「Sprint Backlogを作成」ボタンをクリックする
4. 選択項目、作業、状態、担当、依存関係を定義する
5. 入力を保存する
6. システムがSprint Backlog項目（INF-SP-03）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Sprint Backlog項目（INF-SP-03）がシステムに登録される
- イベント「EVT-SP-005 Sprint Backlogが作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SP-01 | スプリント | 関連付ける情報 |
| INF-SP-03 | Sprint Backlog項目 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SP-005 | Sprint Backlogが作成された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 選択項目は必須入力 |
