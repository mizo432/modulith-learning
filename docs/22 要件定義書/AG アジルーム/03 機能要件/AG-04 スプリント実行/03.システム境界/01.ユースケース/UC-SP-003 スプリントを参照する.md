# UC-SP-003 スプリントを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SP-003 |
| ユースケース名 | スプリントを参照する |
| 英語名 | View Sprint |
| 説明 | 現在のスプリントの状況を確認する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-SP-01 |
| 外部システム | - |
| 関連画面 | SCR-013（Sprint一覧・詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- スプリント（INF-SP-01）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint一覧・詳細」画面（SCR-013）にアクセスする
2. システムがスプリントの一覧を表示する
3. ユーザーが特定のスプリントを選択する
4. システムがスプリントの詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- スプリントの詳細がユーザーに表示される
