# UC-SR-04 Review議題を設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SR-04 |
| ユースケース名 | Review議題を設定する |
| 英語名 | Set Review Agenda |
| 説明 | Sprint Reviewの議題を設定し、順序を整理する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SR-02（Sprint Review準備） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Reviewが開始されていること

## 基本フロー

1. ユーザーが「Sprint Review準備」画面（SR-02）の議題設定セクションにアクセスする
2. 議題を追加する
3. 議題の順序を設定する
4. 議題の説明を入力する
5. 議題を保存する
6. システムがReview議題（INF-SR-03）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **2a. 既存の議題テンプレートを使用する場合**
  - システムが議題テンプレート一覧を表示する
  - ユーザーがテンプレートを選択する
  - システムがテンプレートの議題を適用する

- **3a. 議題の順序を変更する場合**
  - ユーザーが議題の順序をドラッグ＆ドロップで変更する
  - システムが変更後の順序を保存する

## 後置条件

- Review議題（INF-SR-03）が登録される
- イベント「EVT-SR-004 Review議題が設定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SR-03 | Review議題 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SR-004 | Review議題が設定された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須議題 | Sprint Goalの確認と成果デモは必須議題として設定される |
| 2 | 順序管理 | 議題の順序はReviewの進行順序に従って設定する |
