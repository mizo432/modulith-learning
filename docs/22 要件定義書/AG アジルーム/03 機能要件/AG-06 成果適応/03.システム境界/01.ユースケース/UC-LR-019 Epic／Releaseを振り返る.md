# UC-LR-019 Epic／Releaseを振り返る

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-019 |
| ユースケース名 | Epic／Releaseを振り返る |
| 英語名 | Retrospect Epic/Release |
| 説明 | 複数スプリントにまたがる成果と学びを振り返る |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-LR-02 |
| 外部システム | - |
| 関連画面 | SCR-023（Epic / Release Retrospective） |

## 前置条件

- ユーザーがシステムにログインしていること
- EpicまたはReleaseが存在すること

## 基本フロー

1. ユーザーが「Epic / Release Retrospective」画面（SCR-023）にアクセスする
2. 対象EpicまたはReleaseを選択する
3. 計画対実績を比較する
4. スコープ変更を確認する
5. 品質指標を確認する
6. 依存関係の遅延を確認する
7. 成果と学びを記録する
8. システムがRetrospective記録（INF-LR-02）を保存する

## 代替フロー

- **3a. 計画データが存在しない場合**
  - システムが「計画データが見つかりません」を表示する
  - ユーザーは手動で計画情報を記載する

- **7a. 改善アクションを作成する場合**
  - ユーザーが改善アクションを新規作成する
  - 基本フローステップ8に進む

## 後置条件

- Retrospective記録（INF-LR-02）がシステムに登録される
- イベント「EVT-LR-013 Epic／Releaseが振り返られた」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-02 | Retrospective記録 | 作成対象の情報 |
| INF-LR-03 | 改善アクション | 関連する改善アクション |
| INF-LR-05 | プロジェクト状況 | 計画対実績の比較 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-013 | Epic／Releaseが振り返られた | 基本フローステップ8完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限 | Epic/Releaseの振り返りはPO（ACT-02）、SM（ACT-03）、開発者（ACT-04）のみ可能 |
| 2 | 対象範囲 | 複数スプリントにまたがるEpicまたはReleaseを対象とする |
