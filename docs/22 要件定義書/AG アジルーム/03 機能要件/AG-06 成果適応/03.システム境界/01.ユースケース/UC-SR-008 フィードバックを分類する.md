# UC-SR-08 フィードバックを分類する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SR-08 |
| ユースケース名 | フィードバックを分類する |
| 英語名 | Classify Feedback |
| 説明 | 収集したフィードバックを分類（新機能要望、既存機能改善、不具合等）する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SR-04（フィードバック評価） |

## 前置条件

- ユーザーがシステムにログインしていること
- フィードバックが記録されていること（UC-SR-07完了）

## 基本フロー

1. ユーザーが「フィードバック評価」画面（SR-04）にアクセスする
2. 未分類のフィードバック一覧を確認する
3. 対象フィードバックを選択する
4. フィードバックの内容と背景を確認する
5. 分類を選択する（新機能要望、既存機能改善、不具合、業務ルール変更、UI/UX改善、質問・確認、その他）
6. 分類を保存する
7. システムがフィードバックの分類情報を更新する
8. 保存完了メッセージを表示する

## 代替フロー

- **2a. バッチ分類する場合**
  - ユーザーが複数のフィードバックを選択する
  - 同じ分類を一括で適用する
  - システムが選択したフィードバックの分類を一括更新する

- **5a. AIによる分類支援を使用する場合**
  - システムがフィードバック内容に基づいて推奨分類を提案する
  - ユーザーが提案を確認し、採用または修正する

## 後置条件

- フィードバックの分類情報が更新される
- イベント「EVT-SR-008 フィードバックが分類された」が発行される
