# UC-SR-13 Sprint Reviewを終了する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SR-13 |
| ユースケース名 | Sprint Reviewを終了する |
| 英語名 | End Sprint Review |
| 説明 | フィードバックの記録状況と決定事項を確認し、Sprint Reviewを完了状態に変更する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SR-05（Sprint Review結果） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Reviewが実施中であること

## 基本フロー

1. ユーザーが「Sprint Review結果」画面（SR-05）にアクセスする
2. フィードバックの記録状況を確認する
3. 決定事項と継続確認事項を確認する
4. Sprint Goalの達成状況と根拠を記録する
5. Review結果を保存する
6. Reviewを完了状態に変更する
7. システムがSprint Review（INF-SR-01）の状態を「完了」に変更する
8. 完了メッセージを表示する

## 代替フロー

- **2a. 未記録のフィードバックが存在する場合**
  - システムが未記録のフィードバックがあることを通知する
  - ユーザーは記録を継続するか、そのまま終了するか選択する

- **3a. 未完了Storyが存在する場合**
  - システムが未完了Storyを表示する
  - ユーザーは未完了Storyの扱いを確認する

## 後置条件

- Sprint Review（INF-SR-01）の状態が「完了」になる
- Review結果が確定し、後から参照できる
- イベント「EVT-SR-013 Sprint Reviewが終了された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SR-01 | Sprint Review | 終了対象の情報 |
| INF-SR-05 | Reviewフィードバック | 確認対象の情報 |
| INF-SR-08 | Review決定事項 | 確認対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SR-013 | Sprint Reviewが終了された | 基本フローステップ7完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限 | POまたはSMのみがSprint Reviewを終了できる |
| 2 | 参照可能 | Review終了後も過去の結果を参照できる |
| 3 | Retrospective連携 | Review結果をSprint Retrospectiveの入力情報として利用できる |
