# UC-AD-011 成功指標を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-011 |
| ユースケース名 | 成功指標を更新する |
| 英語名 | Update Success Metric |
| 説明 | 成功指標の目標値・測定方法を修正する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-05 |
| 外部システム | - |
| 関連画面 | SCR-025（成功指標管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 成功指標（INF-AD-05）が既に存在すること

## 基本フロー

1. ユーザーが「成功指標管理」画面（SCR-025）にアクセスする
2. 更新対象の成功指標を選択する
3. 「編集」ボタンをクリックする
4. 目標値、測定方法、頻度を修正する
5. 変更を保存する
6. システムが成功指標（INF-AD-05）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 成功指標（INF-AD-05）が更新される
- イベント「EVT-AD-008 成功指標が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-05 | 成功指標 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-008 | 成功指標が更新された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 目標値、測定方法は必須入力 |
| 2 | 数値範囲 | 目標値は正の整数で入力 |
