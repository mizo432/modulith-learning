# UC-LR-012 判断待ち一覧を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-012 |
| ユースケース名 | 判断待ち一覧を確認する |
| 英語名 | View Pending Decisions |
| 説明 | 判断が必要な事項の期限・影響・担当を確認する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-04 |
| 外部システム | - |
| 関連画面 | SCR-001（プロジェクトダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- 判断待ち事項が存在すること

## 基本フロー

1. ユーザーが「プロジェクトダッシュボード」画面（SCR-001）にアクセスする
2. 「判断待ち一覧」タブを選択する
3. システムが判断待ち事項の一覧を表示する
4. ユーザーが期限や影響度でソートする（オプション）
5. ユーザーが特定の判断待ち事項を選択する
6. システムが判断待ち事項の詳細を表示する
7. ユーザーが背景情報や関連リスクを確認する

## 代替フロー

- **4a. ソートを行わない場合**
  - システムが登録順で判断待ち事項を表示する
  - 基本フローステップ5に進む

- **4b. フィルタ結果がない場合**
  - システムが「判断待ち事項はありません」を表示する
  - ユーザーは他のタブを確認する

## 後置条件

- 判断待ち一覧がユーザーに表示される
- イベント「EVT-LR-008 判断待ちが登録された」が発行される（新規判断待ちが追加された場合）

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示権限 | PO（ACT-02）とトラッキング担当（ACT-05）のみが判断待ち一覧を確認できる |
| 2 | ソート | 期限、影響度などでソート可能 |
