# UC-LR-003 Sprint Retrospectiveを記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-003 |
| ユースケース名 | Sprint Retrospectiveを記録する |
| 英語名 | Record Sprint Retrospective |
| 説明 | 学び、改善候補、決定事項を記録する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-02 |
| 外部システム | - |
| 関連画面 | SCR-022（Sprint Retrospective） |

## 前置条件

- ユーザーがシステムにログインしていること
- 対象Sprintが存在すること
- Sprintが終了していること

## 基本フロー

1. ユーザーが「Sprint Retrospective」画面（SCR-022）にアクセスする
2. 対象Sprintを選択する
3. 「Retrospectiveを記録」ボタンをクリックする
4. カテゴリ（Keep/Problem/Try）を選択する
5. 改善案の内容を入力する
6. 投票を行う
7. 改善案をアクション化する
8. システムがRetrospective記録（INF-LR-02）を保存する
9. 登録完了メッセージを表示する

## 代替フロー

- **4a. Keepカテゴリを選択した場合**
  - ユーザーが継続すべき良い実践を記録する
  - 基本フローステップ5に進む

- **4b. Problemカテゴリを選択した場合**
  - ユーザーが課題や問題を記録する
  - 基本フローステップ5に進む

- **4c. Tryカテゴリを選択した場合**
  - ユーザーが次回試す改善案を記録する
  - 基本フローステップ5に進む

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **7a. アクション化しない場合**
  - 改善案をアクション化せずに記録のみ保存する
  - 基本フローステップ8に進む

## 後置条件

- Retrospective記録（INF-LR-02）がシステムに登録される
- イベント「EVT-LR-002 Sprint Retrospectiveが記録された」が発行される

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Retrospectiveの記録はScrum Team（ACT-03, ACT-04）のみ可能 |
| 2 | カテゴリ必須 | Keep/Problem/Tryのいずれかのカテゴリを選択する必要がある |
| 3 | 文字数制限 | 改善案の内容は2000文字以内 |
| 4 | 投票制限 | 1人あたりの投票数は制限される |
