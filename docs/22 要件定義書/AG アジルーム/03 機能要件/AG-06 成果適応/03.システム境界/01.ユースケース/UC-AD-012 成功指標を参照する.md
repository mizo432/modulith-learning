# UC-AD-012 成功指標を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-012 |
| ユースケース名 | 成功指標を参照する |
| 英語名 | View Success Metric |
| 説明 | 成功指標の現状値・目標値・推移を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-05 |
| 外部システム | - |
| 関連画面 | SCR-025（成功指標管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 成功指標（INF-AD-05）が既に存在すること

## 基本フロー

1. ユーザーが「成功指標管理」画面（SCR-025）にアクセスする
2. システムが成功指標の一覧を表示する
3. ユーザーが特定の成功指標を選択する
4. システムが成功指標の詳細と推移を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 成功指標の詳細と推移がユーザーに表示される
