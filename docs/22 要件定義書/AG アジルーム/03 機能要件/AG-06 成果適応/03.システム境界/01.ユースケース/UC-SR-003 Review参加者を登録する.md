# UC-SR-03 Review参加者を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SR-03 |
| ユースケース名 | Review参加者を登録する |
| 英語名 | Register Review Participants |
| 説明 | Sprint Reviewの参加者（Scrum Team、ステークホルダー）を登録する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SR-02（Sprint Review準備） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Reviewが開始されていること

## 基本フロー

1. ユーザーが「Sprint Review準備」画面（SR-02）の参加者登録セクションにアクセスする
2. 参加者を選択または追加する
3. 参加者の役割（PO、SM、開発者、ステークホルダー）を設定する
4. 参加者を保存する
5. システムがReview参加者（INF-SR-02）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **2a. 既存の参加者を選択する場合**
  - システムが既存の参加者一覧を表示する
  - ユーザーが参加者を選択する

- **2b. 新規参加者を追加する場合**
  - ユーザーが新規参加者の情報を入力する
  - システムが新規参加者を追加する

## 後置条件

- Review参加者（INF-SR-02）が登録される
- イベント「EVT-SR-003 Review参加者が登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SR-02 | Review参加者 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SR-003 | Review参加者が登録された | 基本フローステップ4完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須参加者 | Scrum Teamは必須参加者として登録される |
| 2 | 役割設定 | 各参加者の役割を正しく設定する必要がある |
