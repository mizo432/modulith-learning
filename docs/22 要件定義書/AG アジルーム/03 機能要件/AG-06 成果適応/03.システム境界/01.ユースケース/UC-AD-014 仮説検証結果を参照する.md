## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-014 |
| ユースケース名 | 仮説検証結果を参照する |
| 英語名 | View Hypothesis Validation Result |
| 説明 | 仮説検証の結果を確認する |

## 前置条件

- ユーザーがシステムにログインしていること
- 仮説検証（INF-AD-06）が既に存在すること

## 基本フロー

1. ユーザーが「成功指標管理」画面（SCR-025）にアクセスする
2. システムが仮説検証の一覧を表示する
3. ユーザーが特定の仮説検証を選択する
4. システムが仮説検証の詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

## 後置条件
