# UC-LR-001 Sprint Reviewを記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-001 |
| ユースケース名 | Sprint Reviewを記録する |
| 英語名 | Record Sprint Review |
| 説明 | 成果、フィードバック、決定、未解決事項を記録する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SCR-017（Sprint Review） |

## 前置条件

- ユーザーがシステムにログインしていること
- 対象Sprintが存在すること
- Sprintが終了していること

## 基本フロー

1. ユーザーが「Sprint Review」画面（SCR-017）にアクセスする
2. 対象Sprintを選択する
3. Sprint Goalの達成状況を確認する
4. 完了・未完了Storyを確認する
5. 成果を記録する
6. フィードバックを記録する
7. 決定事項を記録する
8. 未解決事項を記録する
9. システムがSprint Review記録（INF-LR-01）を保存する
10. 登録完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **8a. 未解決事項がない場合**
  - 未解決事項の記録をスキップする
  - 基本フローステップ9に進む

## 後置条件

- Sprint Review記録（INF-LR-01）がシステムに登録される
- イベント「EVT-LR-001 Sprint Reviewが記録された」が発行される

| イベントID | イベント名 | 発生タイミング |

| EVT-LR-001 | Sprint Reviewが記録された | 基本フローステップ9完了後 |

| 番号 | 制約事項 | 説明 |
|------|----------|------|

| 2 | 権限 | Sprint Reviewの記録はScrum Teamのみ可能 |
