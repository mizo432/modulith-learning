# UC-LR-007 改善アクションを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-007 |
| ユースケース名 | 改善アクションを参照する |
| 英語名 | View Improvement Action |
| 説明 | 登録された改善アクションの一覧・詳細を確認する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発者）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-03 |
| 外部システム | - |
| 関連画面 | SCR-024（改善アクション管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 改善アクション（INF-LR-03）が既に存在すること

## 基本フロー

1. ユーザーが「改善アクション管理」画面（SCR-024）にアクセスする
2. システムが改善アクションの一覧を表示する
3. ユーザーが状態や担当者でフィルタリングする（オプション）
4. ユーザーが特定の改善アクションを選択する
5. システムが改善アクションの詳細を表示する
6. ユーザーが担当、期限、状態、進捗を確認する
7. ユーザーが関連するRetrospectiveを確認する

## 代替フロー

- **3a. フィルタリングを行わない場合**
  - システムがすべての改善アクションを一覧表示する
  - 基本フローステップ4に進む

- **3b. フィルタ結果がない場合**
  - システムが「該当する改善アクションが見つかりません」を表示する
  - ユーザーはフィルタ条件を変更して再試行する

## 後置条件

- 改善アクションの詳細がユーザーに表示される
