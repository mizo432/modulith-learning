# UC-LR-018 レポートを出力する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-018 |
| ユースケース名 | レポートを出力する |
| 英語名 | Export Report |
| 説明 | 権限と監査を考慮してレポートを出力する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-LR-07 |
| 外部システム | - |
| 関連画面 | SCR-025（プロダクトメトリクス） |

## 前置条件

- ユーザーがシステムにログインしていること
- レポート出力権限を持っていること

## 基本フロー

1. ユーザーが「プロダクトメトリクス」画面（SCR-025）にアクセスする
2. 「レポート出力」ボタンをクリックする
3. レポートの種類を選択する
4. 出力期間を指定する
5. 出力形式を選択する（PDF/Excel/CSV）
6. システムがレポートを生成する
7. システムがレポート（INF-LR-09）を保存する
8. ダウンロードリンクを表示する

## 代替フロー

- **3a. 複数のレポート種類がある場合**
  - ユーザーが複数のレポートを選択して一括出力する
  - 基本フローステップ4に進む

- **6a. レポート生成に失敗した場合**
  - システムがエラーメッセージを表示する
  - ユーザーは条件を変更して再試行する

## 後置条件

- レポート（INF-LR-09）がシステムに保存される
- イベント「EVT-LR-012 レポートが出力された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-09 | レポート | 作成対象の情報 |
| INF-LR-08 | 成果指標データ | レポートのデータソース |
| INF-LR-05 | プロジェクト状況 | レポートのデータソース |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-012 | レポートが出力された | 基本フローステップ7完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限 | レポート出力はPO（ACT-02）とトラッキング担当（ACT-05）のみ可能 |
| 2 | 監査 | レポート出力履歴は監査証跡として記録される |
| 3 | 出力形式 | PDF、Excel、CSVの形式をサポート |
