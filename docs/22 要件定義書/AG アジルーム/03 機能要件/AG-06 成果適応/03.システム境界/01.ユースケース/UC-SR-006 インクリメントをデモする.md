# UC-SR-06 インクリメントをデモする

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SR-06 |
| ユースケース名 | インクリメントをデモする |
| 英語名 | Demonstrate Increment |
| 説明 | 完成したインクリメントやデモ対象をデモし、説明や実施結果を記録する |
| 関連アクター | ACT-04（開発者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SR-03（Sprint Review実施） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Reviewが実施中であること
- デモ対象のインクリメントが準備されていること

## 基本フロー

1. ユーザーが「Sprint Review実施」画面（SR-03）のデモセクションにアクセスする
2. デモ対象のインクリメントを選択する
3. デモの説明を入力する
4. 実際に動作するインクリメントをデモする
5. デモの実施結果を記録する
6. システムがデモ情報（INF-SR-04）を保存する
7. 登録完了メッセージを表示する

## 代替フロー

- **2a. 複数のインクリメントをデモする場合**
  - ユーザーがデモ対象を順に選択する
  - 各インクリメントについてデモと記録を繰り返す

- **4a. デモが失敗した場合**
  - ユーザーがデモ失敗の理由を記録する
  - システムが失敗情報を保存する

## 後置条件

- デモ情報（INF-SR-04）が保存される
- イベント「EVT-SR-006 インクリメントがデモされた」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SR-04 | デモ対象インクリメント | デモ対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SR-006 | インクリメントがデモされた | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | Definition of Done | DoDを満たしていない作業をデモ対象として登録できない |
| 2 | デモ記録 | デモの説明や実施結果を記録できること |
