# UC-LR-008 改善効果を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-008 |
| ユースケース名 | 改善効果を確認する |
| 英語名 | Verify Improvement Effect |
| 説明 | 改善施策が品質、協働、価値提供に与えた影響を確認する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-LR-03 |
| 外部システム | - |
| 関連画面 | SCR-024（改善アクション管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 改善アクション（INF-LR-03）が「完了」状態であること

## 基本フロー

1. ユーザーが「改善アクション管理」画面（SCR-024）にアクセスする
2. 完了した改善アクションを選択する
3. システムが改善アクションの詳細を表示する
4. ユーザーが期待効果と実際の効果を比較する
5. 効果確認の結果を入力する
6. 効果の定量的指標を記録する（オプション）
7. 状態を「効果確認中」に変更する
8. システムが改善アクション（INF-LR-03）を更新する
9. 効果確認完了メッセージを表示する

## 代替フロー

- **4a. 効果が期待通りでない場合**
  - ユーザーが理由を記載する
  - 再改善の必要性を判断する
  - 基本フローステップ5に進む

- **6a. 定量的指標を記録しない場合**
  - 定性的評価のみで効果確認を行う
  - 基本フローステップ7に進む

## 後置条件

- 改善アクション（INF-LR-03）の状態が「効果確認中」になる
- 効果確認の結果が記録される
- イベント「EVT-LR-005 改善効果が確認された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-03 | 改善アクション | 効果確認対象の情報 |
| INF-LR-11 | 改善アクション状態 | 状態変更の参照 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-005 | 改善効果が確認された | 基本フローステップ8完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 対象制限 | 「完了」状態の改善アクションのみが効果確認の対象 |
| 2 | 権限 | 効果確認はScrum Team（ACT-03, ACT-04）のみ可能 |
