# UC-LR-010 プロジェクト進捗を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-010 |
| ユースケース名 | プロジェクト進捗を確認する |
| 英語名 | Check Project Progress |
| 説明 | 進捗、マイルストーン、成果、リスクを参照する |
| 関連アクター | ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-04 |
| 外部システム | - |
| 関連画面 | SCR-001（プロジェクトダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- プロジェクトが存在すること

## 基本フロー

1. ユーザーが「プロジェクトダッシュボード」画面（SCR-001）にアクセスする
2. 対象プロジェクトを選択する
3. システムが進捗状況を表示する
4. マイルストーンの実施状況を確認する
5. 成果物のステータスを確認する
6. リスク一覧を確認する

## 代替フロー

- **2a. 複数のプロジェクトが存在する場合**
  - ユーザーがフィルタ条件を指定してプロジェクトを絞り込む
  - 基本フローステップ3に進む

## 後置条件

- プロジェクトの進捗状況がユーザーに表示される
- イベント「EVT-LR-006 プロジェクト進捗が更新された」が発行される（進捗が変更された場合）

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-05 | プロジェクト状況 | 進捗、マイルストーン、成果、リスク |
| INF-LR-06 | リスク | 依存関係、課題、遅延リスク |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-006 | プロジェクト進捗が更新された | 進捗が変更された場合 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示権限 | トラッキング担当（ACT-05）のみが詳細な進捗を確認できる |
| 2 | リアルタイム更新 | 進捗情報はリアルタイムで更新される |
