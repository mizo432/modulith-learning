# UC-LR-021 稼働状況を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-021 |
| ユースケース名 | 稼働状況を確認する |
| 英語名 | Check Operation Status |
| 説明 | 監視・ログ基盤から稼働状況・エラー・ログを取得する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発者）、ACT-05（トラッキング担当） |
| 優先度 | 低 |
| ビジネスユースケース | BUC-LR-06 |
| 外部システム | ES-07（監視・ログ基盤） |
| 関連画面 | SCR-025（プロダクトメトリクス） |

## 前置条件

- ユーザーがシステムにログインしていること
- 監視・ログ基盤（ES-07）が利用可能であること

## 基本フロー

1. ユーザーが「プロダクトメトリクス」画面（SCR-025）にアクセスする
2. 「稼働状況」タブを選択する
3. システムが監視・ログ基盤（ES-07）からデータを取得する
4. 稼働率を表示する
5. エラー発生状況を表示する
6. ログの傾向を表示する
7. アラート履歴を表示する

## 代替フロー

- **3a. 監視・ログ基盤が利用できない場合**
  - システムがエラーメッセージを表示する
  - ユーザーは後で再試行する

- **4a. データが不足している場合**
  - システムが「データが不足しています」を表示する
  - ユーザーは期間を変更して再試行する

## 後置条件

- 稼働状況がユーザーに表示される
- イベント「EVT-LR-015 稼働状況が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-05 | プロジェクト状況 | 稼働状況データの参照 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-015 | 稼働状況が更新された | データが更新された場合 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 外部連携 | 監視・ログ基盤（ES-07）との連携が必要 |
| 2 | 権限 | PO（ACT-02）、開発者（ACT-04）、トラッキング担当（ACT-05）のみが確認できる |
