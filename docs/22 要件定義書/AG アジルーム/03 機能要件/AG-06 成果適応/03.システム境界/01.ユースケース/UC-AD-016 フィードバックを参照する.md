# UC-AD-016 フィードバックを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-016 |
| ユースケース名 | フィードバックを参照する |
| 英語名 | View Feedback |
| 説明 | 収集されたフィードバックの一覧・詳細を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-07 |
| 外部システム | - |
| 関連画面 | SCR-024（利用状況ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- フィードバック（INF-AD-07）が既に存在すること

## 基本フロー

1. ユーザーが「利用状況ダッシュボード」画面（SCR-024）にアクセスする
2. システムがフィードバックの一覧を表示する
3. ユーザーが特定のフィードバックを選択する
4. システムがフィードバックの詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- フィードバックの一覧・詳細がユーザーに表示される
