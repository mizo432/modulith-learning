# UC-LR-009 ダッシュボードを表示する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-009 |
| ユースケース名 | ダッシュボードを表示する |
| 英語名 | Display Dashboard |
| 説明 | ロールに応じた目標、作業、障害、判断待ちを表示する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発者）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-04 |
| 外部システム | - |
| 関連画面 | SCR-001（プロジェクトダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「プロジェクトダッシュボード」画面（SCR-001）にアクセスする
2. システムがユーザーのロールに応じた情報を取得する
3. 目標の進捗状況を表示する
4. 現在の作業一覧を表示する
5. 障害やブロッカーを表示する
6. 判断待ち事項を表示する
7. リスク一覧を表示する

## 代替フロー

- なし

## 後置条件

- ダッシュボードがユーザーに表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-04 | ダッシュボード | 表示構成の情報 |
| INF-LR-05 | プロジェクト状況 | 進捗、マイルストーン、成果、リスク |
| INF-LR-06 | リスク | 依存関係、課題、遅延リスク |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
