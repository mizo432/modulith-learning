# UC-AD-004 リリースノートを作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-004 |
| ユースケース名 | リリースノートを作成する |
| 英語名 | Create Release Note |
| 説明 | 変更内容、既知の問題、アップグレード手順を記録する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-AD-02 |
| 外部システム | - |
| 関連画面 | SCR-022（リリース計画） |

## 前置条件

- ユーザーがシステムにログインしていること
- リリース計画（INF-AD-01）が既に存在すること

## 基本フロー

1. ユーザーが「リリース計画」画面（SCR-022）にアクセスする
2. 「リリースノートを作成」ボタンをクリックする
3. 変更内容、既知の問題、アップグレード手順を入力する
4. 入力を保存する
5. システムがリリースノート（INF-AD-02）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- リリースノート（INF-AD-02）がシステムに登録される
- イベント「EVT-AD-003 リリースノートが作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-01 | リリース計画 | 関連付ける情報 |
| INF-AD-02 | リリースノート | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-003 | リリースノートが作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 変更内容は必須入力 |
| 2 | 文字数制限 | 変更内容は5000文字以内 |
