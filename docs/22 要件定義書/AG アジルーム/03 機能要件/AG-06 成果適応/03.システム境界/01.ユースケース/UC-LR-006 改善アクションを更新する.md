# UC-LR-006 改善アクションを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-006 |
| ユースケース名 | 改善アクションを更新する |
| 英語名 | Update Improvement Action |
| 説明 | 改善アクションの担当・期限・状態を修正する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-03 |
| 外部システム | - |
| 関連画面 | SCR-024（改善アクション管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 改善アクション（INF-LR-03）が既に存在すること

## 基本フロー

1. ユーザーが「改善アクション管理」画面（SCR-024）にアクセスする
2. 更新対象の改善アクションを選択する
3. システムが改善アクションの詳細を表示する
4. ユーザーが編集項目を入力する
5. 状態を変更する（未着手→実行中→完了→効果確認中）
6. 担当者を修正する（オプション）
7. 期限を修正する（オプション）
8. 進捗メモを記載する（オプション）
9. システムが改善アクション（INF-LR-03）を更新する
10. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **5a. 状態を変更しない場合**
  - 現在の状態を維持する
  - 基本フローステップ6に進む

## 後置条件

- 改善アクション（INF-LR-03）が更新される
- イベント「EVT-LR-004 改善アクションが更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-03 | 改善アクション | 更新対象の情報 |
| INF-LR-11 | 改善アクション状態 | 状態変更の参照 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-004 | 改善アクションが更新された | 基本フローステップ9完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 改善アクションの更新はScrum Team（ACT-03, ACT-04）のみ可能 |
| 2 | 状態遷移 | 状態は未着手→実行中→完了→効果確認中の順序で遷移する |
