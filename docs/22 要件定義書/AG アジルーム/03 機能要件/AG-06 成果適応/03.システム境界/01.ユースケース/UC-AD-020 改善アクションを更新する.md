# UC-AD-020 改善アクションを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-020 |
| ユースケース名 | 改善アクションを更新する |
| 英語名 | Update Improvement Action |
| 説明 | 改善アクションの進捗・状態を修正する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-08 |
| 外部システム | - |
| 関連画面 | SCR-026（レトロスペクティブ） |

## 前置条件

- ユーザーがシステムにログインしていること
- 改善アクション（INF-AD-09）が既に存在すること

## 基本フロー

1. ユーザーが「レトロスペクティブ」画面（SCR-026）にアクセスする
2. 更新対象の改善アクションを選択する
3. 「編集」ボタンをクリックする
4. 進捗、状態を修正する
5. 変更を保存する
6. システムが改善アクション（INF-AD-09）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 改善アクション（INF-AD-09）が更新される
- イベント「EVT-AD-013 改善アクションが更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-09 | 改善アクション | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-013 | 改善アクションが更新された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 進捗は必須入力 |
| 2 | 状態遷移 | 定義された状態遷移ルールに従う |
