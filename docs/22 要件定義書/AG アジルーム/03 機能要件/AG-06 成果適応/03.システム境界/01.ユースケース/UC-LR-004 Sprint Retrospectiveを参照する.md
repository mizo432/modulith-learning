# UC-LR-004 Sprint Retrospectiveを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-004 |
| ユースケース名 | Sprint Retrospectiveを参照する |
| 英語名 | View Sprint Retrospective |
| 説明 | 過去のRetrospectiveの内容を確認する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発者）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-02 |
| 外部システム | - |
| 関連画面 | SCR-022（Sprint Retrospective） |

## 前置条件

- ユーザーがシステムにログインしていること
- Retrospective記録（INF-LR-02）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Retrospective」画面（SCR-022）にアクセスする
2. システムがRetrospective記録の一覧を表示する
3. ユーザーが検索キーワードを入力して検索する（オプション）
4. ユーザーが特定のRetrospectiveを選択する
5. システムがRetrospectiveの詳細を表示する
6. ユーザーが学び、改善候補、決定事項を確認する
7. ユーザーが関連する改善アクションを確認する

## 代替フロー

- **3a. 検索を行わない場合**
  - システムがすべてのRetrospective記録を一覧表示する
  - 基本フローステップ4に進む

- **3b. 検索結果がない場合**
  - システムが「該当するRetrospectiveが見つかりません」を表示する
  - ユーザーは検索条件を変更して再試行する

## 後置条件

- Retrospectiveの詳細がユーザーに表示される
