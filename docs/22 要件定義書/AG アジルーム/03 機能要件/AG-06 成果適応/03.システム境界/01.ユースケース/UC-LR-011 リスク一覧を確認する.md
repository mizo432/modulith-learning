# UC-LR-011 リスク一覧を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-011 |
| ユースケース名 | リスク一覧を確認する |
| 英語名 | View Risk List |
| 説明 | 期限、影響、担当、次の対応が必要な事項を示す |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-04 |
| 外部システム | - |
| 関連画面 | SCR-001（プロジェクトダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- リスク（INF-LR-06）が存在すること

## 基本フロー

1. ユーザーが「プロジェクトダッシュボード」画面（SCR-001）にアクセスする
2. 「リスク一覧」タブを選択する
3. システムがリスクの一覧を表示する
4. ユーザーが影響度や期限でソートする（オプション）
5. ユーザーが特定のリスクを選択する
6. システムがリスクの詳細を表示する
7. ユーザーが対応状況や次のアクションを確認する

## 代替フロー

- **4a. ソートを行わない場合**
  - システムが登録順でリスクを表示する
  - 基本フローステップ5に進む

- **4b. フィルタ結果がない場合**
  - システムが「該当するリスクが見つかりません」を表示する
  - ユーザーはフィルタ条件を変更して再試行する

## 後置条件

- リスク一覧がユーザーに表示される
- イベント「EVT-LR-007 リスクが登録された」が発行される（新規リスクが追加された場合）

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-06 | リスク | 参照対象の情報 |
| INF-LR-05 | プロジェクト状況 | 関連するプロジェクト状況 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-007 | リスクが登録された | 新規リスクが追加された場合 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示権限 | PO（ACT-02）とトラッキング担当（ACT-05）のみがリスク一覧を確認できる |
| 2 | ソート | 影響度、期限、状態などでソート可能 |
