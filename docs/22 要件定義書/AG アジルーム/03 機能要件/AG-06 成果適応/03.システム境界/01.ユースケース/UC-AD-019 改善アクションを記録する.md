# UC-AD-019 改善アクションを記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-019 |
| ユースケース名 | 改善アクションを記録する |
| 英語名 | Record Improvement Action |
| 説明 | 改善アクション、担当者、期限を記録する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-08 |
| 外部システム | - |
| 関連画面 | SCR-026（レトロスペクティブ） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「レトロスペクティブ」画面（SCR-026）にアクセスする
2. 「改善アクションを記録」ボタンをクリックする
3. 改善アクション、担当者、期限を入力する
4. 入力を保存する
5. システムが改善アクション（INF-AD-09）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 改善アクション（INF-AD-09）がシステムに登録される
- イベント「EVT-AD-012 改善アクションが記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-09 | 改善アクション | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-012 | 改善アクションが記録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 改善アクション、担当者は必須入力 |
| 2 | 文字数制限 | 改善アクションは1000文字以内 |
