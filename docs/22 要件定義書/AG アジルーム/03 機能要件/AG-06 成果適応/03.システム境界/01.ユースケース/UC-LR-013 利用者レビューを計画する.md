# UC-LR-013 利用者レビューを計画する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-013 |
| ユースケース名 | 利用者レビューを計画する |
| 英語名 | Plan User Review |
| 説明 | 対象者、シナリオ、期限を設定する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-LR-05 |
| 外部システム | - |
| 関連画面 | SCR-017（Sprint Review） |

## 前置条件

- ユーザーがシステムにログインしていること
- レビュー対象の機能またはインクリメントが存在すること

## 基本フロー

1. ユーザーが「Sprint Review」画面（SCR-017）にアクセスする
2. 「利用者レビューを計画」ボタンをクリックする
3. レビュー対象の機能を選択する
4. 対象者を設定する
5. レビューシナリオを定義する
6. 期限を設定する
7. システムが利用者レビュー結果（INF-LR-07）を計画状態で作成する
8. 計画完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 利用者レビュー結果（INF-LR-07）が計画状態で作成される
- イベント「EVT-LR-009 利用者レビューが計画された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-07 | 利用者レビュー結果 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-009 | 利用者レビューが計画された | 基本フローステップ7完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 対象者、シナリオ、期限は必須入力 |
| 2 | 権限 | 利用者レビューの計画はPO（ACT-02）と従業員（ACT-01）のみ可能 |
