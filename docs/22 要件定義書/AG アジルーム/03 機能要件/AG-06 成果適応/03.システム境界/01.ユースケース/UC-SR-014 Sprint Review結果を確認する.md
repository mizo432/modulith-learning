# UC-SR-14 Sprint Review結果を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SR-14 |
| ユースケース名 | Sprint Review結果を確認する |
| 英語名 | View Sprint Review Results |
| 説明 | 完了したSprint Reviewの結果（Sprint Goal、完了・未完了Story、フィードバック、決定事項等）を参照する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発者）、ACT-05（ステークホルダー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SR-05（Sprint Review結果） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Reviewが完了していること（UC-SR-13完了）

## 基本フロー

1. ユーザーが「Sprint Review結果」画面（SR-05）にアクセスする
2. 対象Sprint Reviewを選択する
3. Sprint Goalと達成状況を確認する
4. Sprint Backlogの計画と実績を確認する
5. 完了Story・未完了Storyを確認する
6. デモ対象と成果を確認する
7. 参加者を確認する
8. フィードバック一覧を確認する
9. フィードバックの対応方針を確認する
10. 作成されたバックログ候補を確認する
11. 決定事項を確認する
12. 継続確認事項を確認する

## 代替フロー

- **2a. 複数のSprint Reviewを比較する場合**
  - ユーザーが複数のSprint Reviewを選択する
  - システムが選択したReviewの結果を比較表示する

- **8a. 過去のフィードバックを参照する場合**
  - ユーザーが過去のReviewのフィードバックを確認する
  - システムが過去のフィードバック一覧を表示する

## 後置条件

- Sprint Reviewの結果が参照される
- 後続のSprint PlanningやProduct Backlog Refinementで参照できる
