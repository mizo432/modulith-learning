# UC-AD-010 成功指標を定義する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-010 |
| ユースケース名 | 成功指標を定義する |
| 英語名 | Define Success Metric |
| 説明 | 目標値、測定方法、頻度を設定する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-05 |
| 外部システム | - |
| 関連画面 | SCR-025（成功指標管理） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「成功指標管理」画面（SCR-025）にアクセスする
2. 「成功指標を定義」ボタンをクリックする
3. 目標値、測定方法、頻度を入力する
4. 入力を保存する
5. システムが成功指標（INF-AD-05）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 成功指標（INF-AD-05）がシステムに登録される
- イベント「EVT-AD-007 成功指標が定義された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-05 | 成功指標 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-007 | 成功指標が定義された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 目標値、測定方法は必須入力 |
| 2 | 数値範囲 | 目標値は正の整数で入力 |
