# UC-AD-021 改善アクションを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-021 |
| ユースケース名 | 改善アクションを参照する |
| 英語名 | View Improvement Action |
| 説明 | 登録された改善アクションの一覧・詳細を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-08 |
| 外部システム | - |
| 関連画面 | SCR-026（レトロスペクティブ） |

## 前置条件

- ユーザーがシステムにログインしていること
- 改善アクション（INF-AD-09）が既に存在すること

## 基本フロー

1. ユーザーが「レトロスペクティブ」画面（SCR-026）にアクセスする
2. システムが改善アクションの一覧を表示する
3. ユーザーが特定の改善アクションを選択する
4. システムが改善アクションの詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 改善アクションの一覧・詳細がユーザーに表示される
