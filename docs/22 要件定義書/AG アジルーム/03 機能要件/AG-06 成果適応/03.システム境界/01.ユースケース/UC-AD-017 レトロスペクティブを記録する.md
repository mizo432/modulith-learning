# UC-AD-017 レトロスペクティブを記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-017 |
| ユースケース名 | レトロスペクティブを記録する |
| 英語名 | Record Retrospective |
| 説明 | スプリントの振り返り、改善アクションを記録する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-08 |
| 外部システム | - |
| 関連画面 | SCR-026（レトロスペクティブ） |

## 前置条件

- ユーザーがシステムにログインしていること
- スプリントが既に存在すること

## 基本フロー

1. ユーザーが「レトロスペクティブ」画面（SCR-026）にアクセスする
2. 「レトロスペクティブを記録」ボタンをクリックする
3. 振り返り内容、改善アクションを入力する
4. 入力を保存する
5. システムがレトロスペクティブ（INF-AD-08）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- レトロスペクティブ（INF-AD-08）がシステムに登録される
- イベント「EVT-AD-011 レトロスペクティブが記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-08 | レトロスペクティブ | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-011 | レトロスペクティブが記録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 振り返り内容は必須入力 |
| 2 | 文字数制限 | 振り返り内容は2000文字以内 |
