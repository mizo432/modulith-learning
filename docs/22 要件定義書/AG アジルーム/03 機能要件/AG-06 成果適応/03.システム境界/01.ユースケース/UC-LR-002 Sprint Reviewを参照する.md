# UC-LR-002 Sprint Reviewを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-002 |
| ユースケース名 | Sprint Reviewを参照する |
| 英語名 | View Sprint Review |
| 説明 | 過去のSprint Reviewの内容を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発者）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SCR-017（Sprint Review） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Review記録（INF-LR-01）が既に存在すること

## 基本フロー

1. ユーザーが「Sprint Review」画面（SCR-017）にアクセスする
2. システムがSprint Review記録の一覧を表示する
3. ユーザーが特定のSprint Reviewを選択する
4. システムがSprint Reviewの詳細を表示する
5. ユーザーが成果、フィードバック、決定事項を確認する
6. ユーザーが未解決事項を確認する

## 代替フロー

- **3a. 検索結果がない場合**
  - システムが「該当するSprint Reviewが見つかりません」を表示する
  - ユーザーは検索条件を変更して再試行する

## 後置条件

- Sprint Reviewの詳細がユーザーに表示される
