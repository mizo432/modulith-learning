# UC-AD-018 レトロスペクティブを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-018 |
| ユースケース名 | レトロスペクティブを参照する |
| 英語名 | View Retrospective |
| 説明 | 過去の振り返り・改善アクションを確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-08 |
| 外部システム | - |
| 関連画面 | SCR-026（レトロスペクティブ） |

## 前置条件

- ユーザーがシステムにログインしていること
- レトロスペクティブ（INF-AD-08）が既に存在すること

## 基本フロー

1. ユーザーが「レトロスペクティブ」画面（SCR-026）にアクセスする
2. システムがレトロスペクティブの一覧を表示する
3. ユーザーが特定のレトロスペクティブを選択する
4. システムがレトロスペクティブの詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- レトロスペクティブの詳細がユーザーに表示される
