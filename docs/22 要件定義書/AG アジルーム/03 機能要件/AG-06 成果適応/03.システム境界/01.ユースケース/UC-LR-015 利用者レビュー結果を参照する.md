# UC-LR-015 利用者レビュー結果を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-015 |
| ユースケース名 | 利用者レビュー結果を参照する |
| 英語名 | View User Review Results |
| 説明 | レビュー・試用の結果を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-LR-05 |
| 外部システム | - |
| 関連画面 | SCR-017（Sprint Review） |

## 前置条件

- ユーザーがシステムにログインしていること
- 利用者レビュー結果（INF-LR-07）が存在すること

## 基本フロー

1. ユーザーが「Sprint Review」画面（SCR-017）にアクセスする
2. 「利用者レビュー結果」タブを選択する
3. システムが利用者レビュー結果の一覧を表示する
4. ユーザーが特定のレビュー結果を選択する
5. システムがレビュー結果の詳細を表示する
6. ユーザーがフィードバックや評価を確認する

## 代替フロー

- **3a. 検索結果がない場合**
  - システムが「該当するレビュー結果が見つかりません」を表示する
  - ユーザーは検索条件を変更して再試行する

## 後置条件

- 利用者レビュー結果がユーザーに表示される
