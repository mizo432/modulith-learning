# UC-LR-016 Product Goal進捗を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-016 |
| ユースケース名 | Product Goal進捗を確認する |
| 英語名 | Check Product Goal Progress |
| 説明 | 成果指標とバックログ・リリースの関係を可視化する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-LR-06 |
| 外部システム | - |
| 関連画面 | SCR-025（プロダクトメトリクス） |

## 前置条件

- ユーザーがシステムにログインしていること
- Product Goalが設定されていること

## 基本フロー

1. ユーザーが「プロダクトメトリクス」画面（SCR-025）にアクセスする
2. 「Product Goal進捗」タブを選択する
3. システムがProduct Goalの進捗状況を表示する
4. 成果指標の達成状況を確認する
5. バックログとの関連を確認する
6. リリースとの関連を確認する

## 代替フロー

- なし

## 後置条件

- Product Goalの進捗状況がユーザーに表示される
