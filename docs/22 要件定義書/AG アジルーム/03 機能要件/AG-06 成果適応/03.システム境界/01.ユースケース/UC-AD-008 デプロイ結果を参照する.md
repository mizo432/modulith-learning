# UC-AD-008 デプロイ結果を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-008 |
| ユースケース名 | デプロイ結果を参照する |
| 英語名 | View Deploy Result |
| 説明 | デプロイの成功・失敗・ロールバック状況を確認する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-AD-03 |
| 外部システム | ES-04（CI/CDパイプライン） |
| 関連画面 | SCR-023（デプロイ管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- デプロイ結果（INF-AD-03）が既に存在すること

## 基本フロー

1. ユーザーが「デプロイ管理」画面（SCR-023）にアクセスする
2. システムがデプロイ結果の一覧を表示する
3. ユーザーが特定のデプロイ結果を選択する
4. システムがデプロイ結果の詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- デプロイ結果の詳細がユーザーに表示される
