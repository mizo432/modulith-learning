# UC-SR-07 ステークホルダーフィードバックを記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SR-07 |
| ユースケース名 | ステークホルダーフィードバックを記録する |
| 英語名 | Record Stakeholder Feedback |
| 説明 | ステークホルダーからのフィードバックを記録し、発言者・日時・関連Storyを紐付ける |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター）、ACT-05（ステークホルダー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SR-03（Sprint Review実施） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Reviewが実施中であること

## 基本フロー

1. ユーザーが「Sprint Review実施」画面（SR-03）のフィードバック登録セクションにアクセスする
2. フィードバック内容を入力する（意見・要望・質問・課題）
3. 発言者を登録する
4. 関連するStoryやFeatureを指定する（任意）
5. 必要に応じて資料を添付する
6. 補足情報を追加する（背景や具体例）
7. フィードバックを保存する
8. システムがReviewフィードバック（INF-SR-05）を登録する
9. 登録完了メッセージを表示する

## 代替フロー

- **4a. 特定のStoryに紐付かない場合**
  - 関連Storyを未設定のまま保存する
  - システムが関連Storyなしのフィードバックとして保存する

- **5a. 資料を添付する場合**
  - ユーザーが画像、資料、URLなどをアップロードする
  - システムが添付資料を保存する

## 後置条件

- Reviewフィードバック（INF-SR-05）が登録される
- フィードバックがSprint Reviewに紐付いて保存される
- イベント「EVT-SR-007 フィードバックが記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SR-05 | Reviewフィードバック | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SR-007 | フィードバックが記録された | 基本フローステップ8完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 関連Story | フィードバックは特定のStoryに紐付かない場合もあるため、関連Storyは任意 |
| 2 | 複数紐付け | フィードバックは複数のStory・Feature・Epicに関連付けられる |
| 3 | 発言者 | 発言者は必須入力 |
