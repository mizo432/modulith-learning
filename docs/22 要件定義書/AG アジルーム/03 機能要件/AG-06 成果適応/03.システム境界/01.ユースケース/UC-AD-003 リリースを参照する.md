# UC-AD-003 リリースを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-003 |
| ユースケース名 | リリースを参照する |
| 英語名 | View Release |
| 説明 | リリース計画・進捗・結果を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-AD-01 |
| 外部システム | - |
| 関連画面 | SCR-022（リリース計画） |

## 前置条件

- ユーザーがシステムにログインしていること
- リリース計画（INF-AD-01）が既に存在すること

## 基本フロー

1. ユーザーが「リリース計画」画面（SCR-022）にアクセスする
2. システムがリリース計画の一覧を表示する
3. ユーザーが特定のリリースを選択する
4. システムがリリース計画の詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- リリース計画の詳細がユーザーに表示される
