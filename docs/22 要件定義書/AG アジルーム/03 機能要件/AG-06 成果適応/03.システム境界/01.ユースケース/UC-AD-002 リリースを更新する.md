# UC-AD-002 リリースを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-002 |
| ユースケース名 | リリースを更新する |
| 英語名 | Update Release |
| 説明 | リリース計画を修正・更新する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-AD-01 |
| 外部システム | - |
| 関連画面 | SCR-022（リリース計画） |

## 前置条件

- ユーザーがシステムにログインしていること
- リリース計画（INF-AD-01）が既に存在すること

## 基本フロー

1. ユーザーが「リリース計画」画面（SCR-022）にアクセスする
2. 更新対象のリリースを選択する
3. 「編集」ボタンをクリックする
4. リリース対象、日付、依存関係を修正する
5. 変更を保存する
6. システムがリリース計画（INF-AD-01）を更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- リリース計画（INF-AD-01）が更新される
- イベント「EVT-AD-002 リリースが更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-01 | リリース計画 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-002 | リリースが更新された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | リリース対象、日付は必須入力 |
