# UC-AD-001 リリースを計画する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-001 |
| ユースケース名 | リリースを計画する |
| 英語名 | Plan Release |
| 説明 | リリース対象、日付、依存関係を定義する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-AD-01 |
| 外部システム | - |
| 関連画面 | SCR-022（リリース計画） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「リリース計画」画面（SCR-022）にアクセスする
2. 「リリースを計画」ボタンをクリックする
3. リリース対象、日付、依存関係を入力する
4. 入力を保存する
5. システムがリリース計画（INF-AD-01）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- リリース計画（INF-AD-01）がシステムに登録される
- イベント「EVT-AD-001 リリースが計画された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-01 | リリース計画 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-001 | リリースが計画された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | リリース対象、日付は必須入力 |
