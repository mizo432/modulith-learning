# UC-SR-12 Reviewの決定事項を記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-SR-12 |
| ユースケース名 | Reviewの決定事項を記録する |
| 英語名 | Record Review Decisions |
| 説明 | Review中の議論・決定事項を記録し、継続確認事項を整理する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-03（スクラムマスター） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-01 |
| 外部システム | - |
| 関連画面 | SR-03（Sprint Review実施） |

## 前置条件

- ユーザーがシステムにログインしていること
- Sprint Reviewが実施中であること

## 基本フロー

1. ユーザーが「Sprint Review実施」画面（SR-03）の決定事項セクションにアクセスする
2. 決定事項を入力する
3. 決定理由を記録する
4. 継続確認事項を入力する
5. 担当者や期限を設定する（任意）
6. 決定事項を保存する
7. システムがReview決定事項（INF-SR-08）を登録する
8. 登録完了メッセージを表示する

## 代替フロー

- **2a. 複数の決定事項を記録する場合**
  - ユーザーが決定事項を順に追加する
  - システムが各決定事項を保存する

- **4a. 継続確認事項がない場合**
  - 継続確認事項を未設定のまま保存する
  - システムが継続確認事項なしとして保存する

## 後置条件

- Review決定事項（INF-SR-08）が登録される
- イベント「EVT-SR-012 Reviewの決定事項が記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-SR-08 | Review決定事項 | 作成対象の情報 |
| INF-SR-09 | Reviewアクション | 継続確認事項の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-SR-012 | Reviewの決定事項が記録された | 基本フローステップ7完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 決定理由 | 決定事項には決定理由を記録する |
| 2 | 継続確認事項 | 継続確認事項は次のSprint PlanningやRetrospectiveで参照できる |
