# UC-LR-017 成果指標を測定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-017 |
| ユースケース名 | 成果指標を測定する |
| 英語名 | Measure Success Metrics |
| 説明 | リリース後の利用状況や成果指標を測定・分析する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-LR-06 |
| 外部システム | ES-07（監視・ログ基盤） |
| 関連画面 | SCR-025（プロダクトメトリクス） |

## 前置条件

- ユーザーがシステムにログインしていること
- 成功指標が定義されていること
- 監視・ログ基盤（ES-07）が利用可能であること

## 基本フロー

1. ユーザーが「プロダクトメトリクス」画面（SCR-025）にアクセスする
2. 「成果指標」タブを選択する
3. システムが監視・ログ基盤（ES-07）からデータを取得する
4. 利用状況の指標を計算する
5. 成果指標の達成状況を分析する
6. 結果を可視化する
7. システムが成果指標データ（INF-LR-08）を保存する

## 代替フロー

- **3a. 監視・ログ基盤が利用できない場合**
  - システムがエラーメッセージを表示する
  - ユーザーは後で再試行する

- **4a. データが不足している場合**
  - システムが「データが不足しています」を表示する
  - ユーザーは測定期間を変更して再試行する

## 後置条件

- 成果指標データ（INF-LR-08）が更新される
- イベント「EVT-LR-011 成果指標が測定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-08 | 成果指標データ | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-011 | 成果指標が測定された | 基本フローステップ7完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 外部連携 | 監視・ログ基盤（ES-07）との連携が必要 |
| 2 | 権限 | 成果指標の測定はPO（ACT-02）とトラッキング担当（ACT-05）のみ可能 |
