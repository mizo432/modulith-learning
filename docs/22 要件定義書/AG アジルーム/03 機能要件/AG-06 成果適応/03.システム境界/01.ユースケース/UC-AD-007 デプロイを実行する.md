# UC-AD-007 デプロイを実行する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-007 |
| ユースケース名 | デプロイを実行する |
| 英語名 | Execute Deploy |
| 説明 | 環境、バージョン、ロールバック手順を定義してデプロイする |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-AD-03 |
| 外部システム | ES-04（CI/CDパイプライン） |
| 関連画面 | SCR-023（デプロイ管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- リリース計画（INF-AD-01）が既に存在すること
- ES-04（CI/CDパイプライン）と連携していること

## 基本フロー

1. ユーザーが「デプロイ管理」画面（SCR-023）にアクセスする
2. 「デプロイを実行」ボタンをクリックする
3. 環境、バージョン、ロールバック手順を選択する
4. ES-04にデプロイを依頼する
5. ES-04からデプロイ結果を取得する
6. システムがデプロイ結果（INF-AD-03）を登録する
7. デプロイ完了メッセージを表示する

## 代替フロー

- **4a. ES-04接続エラーの場合**
  - ES-04への接続に失敗した場合、エラーメッセージを表示する
  - ユーザーは接続状況を確認して再試行する

## 後置条件

- デプロイ結果（INF-AD-03）がシステムに登録される
- イベント「EVT-AD-005 デプロイが実行された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-01 | リリース計画 | 関連付ける情報 |
| INF-AD-03 | デプロイ結果 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-005 | デプロイが実行された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 外部システム連携 | ES-04（CI/CDパイプライン）との連携が必要 |
| 2 | 接続権限 | ES-04への接続権限が必要 |
