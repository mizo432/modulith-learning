# UC-AD-015 フィードバックを収集する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-015 |
| ユースケース名 | フィードバックを収集する |
| 英語名 | Collect Feedback |
| 説明 | リリース後の利用者からのフィードバックを収集する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-07 |
| 外部システム | - |
| 関連画面 | SCR-024（利用状況ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「利用状況ダッシュボード」画面（SCR-024）にアクセスする
2. 「フィードバックを収集」ボタンをクリックする
3. フィードバックの内容、分類、評価を入力する
4. 入力を保存する
5. システムがフィードバック（INF-AD-07）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- フィードバック（INF-AD-07）がシステムに登録される
- イベント「EVT-AD-010 フィードバックが収集された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-07 | フィードバック | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-010 | フィードバックが収集された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | フィードバック内容は必須入力 |
| 2 | 文字数制限 | 内容は2000文字以内 |
