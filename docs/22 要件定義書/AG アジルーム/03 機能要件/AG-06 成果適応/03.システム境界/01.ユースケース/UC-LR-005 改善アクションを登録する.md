# UC-LR-005 改善アクションを登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-005 |
| ユースケース名 | 改善アクションを登録する |
| 英語名 | Register Improvement Action |
| 説明 | 改善の担当、期限、状態を定義して登録する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-LR-03 |
| 外部システム | - |
| 関連画面 | SCR-024（改善アクション管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- Retrospective記録（INF-LR-02）が存在すること（オプション）

## 基本フロー

1. ユーザーが「改善アクション管理」画面（SCR-024）にアクセスする
2. 「改善アクションを登録」ボタンをクリックする
3. 改善アクションのタイトルを入力する
4. 改善アクションの詳細を入力する
5. 担当者を設定する
6. 期限を設定する
7. 期待効果を記載する
8. 関連するRetrospectiveを紐付ける（オプション）
9. システムが改善アクション（INF-LR-03）を登録する
10. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **8a. Retrospectiveを紐付けない場合**
  - 独立した改善アクションとして登録する
  - 基本フローステップ9に進む

## 後置条件

- 改善アクション（INF-LR-03）がシステムに登録される
- 状態が「未着手」になる
- イベント「EVT-LR-003 改善アクションが登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-03 | 改善アクション | 作成対象の情報 |
| INF-LR-02 | Retrospective記録 | 関連する振り返り |
| INF-LR-10 | 改善アクションとRetrospective | アクションと振り返りの関連 |
| INF-LR-11 | 改善アクション状態 | 初期状態の設定 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-003 | 改善アクションが登録された | 基本フローステップ9完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | タイトル、担当者、期限は必須入力 |
| 2 | 権限 | 改善アクションの登録はScrum Team（ACT-03, ACT-04）のみ可能 |
| 3 | 初期状態 | 登録時の状態は「未着手」 |
