# UC-LR-014 利用者レビューを実行する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-LR-014 |
| ユースケース名 | 利用者レビューを実行する |
| 英語名 | Execute User Review |
| 説明 | 対象者にレビュー・試用に参加させ、結果を記録する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-LR-05 |
| 外部システム | - |
| 関連画面 | SCR-017（Sprint Review） |

## 前置条件

- ユーザーがシステムにログインしていること
- 利用者レビュー結果（INF-LR-07）が計画されていること

## 基本フロー

1. ユーザーが「Sprint Review」画面（SCR-017）にアクセスする
2. 計画された利用者レビューを選択する
3. 対象者にレビュー参加を通知する
4. 対象者がシナリオに従って試用を行う
5. レビュー結果を記録する
6. フィードバックを収集する
7. システムが利用者レビュー結果（INF-LR-07）を更新する
8. 完了メッセージを表示する

## 代替フロー

- **4a. 対象者が参加しない場合**
  - システムがリマインダーを送信する
  - 期限が過ぎた場合、レビューをキャンセルする

- **5a. 結果が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 利用者レビュー結果（INF-LR-07）が完了状態になる
- イベント「EVT-LR-010 利用者レビューが完了した」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-LR-07 | 利用者レビュー結果 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-LR-010 | 利用者レビューが完了した | 基本フローステップ7完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限 | 利用者レビューの実行はPO（ACT-02）と従業員（ACT-01）のみ可能 |
| 2 | 期限遵守 | 計画された期限内に実行する必要がある |
