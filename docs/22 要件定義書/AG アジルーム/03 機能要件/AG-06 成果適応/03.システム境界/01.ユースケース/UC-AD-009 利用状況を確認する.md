# UC-AD-009 利用状況を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-AD-009 |
| ユースケース名 | 利用状況を確認する |
| 英語名 | Check Usage |
| 説明 | 機能利用頻度、アクティブユーザー、アクセス傾向を把握する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-AD-04 |
| 外部システム | ES-07（分析システム） |
| 関連画面 | SCR-024（利用状況ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ES-07（分析システム）と連携していること

## 基本フロー

1. ユーザーが「利用状況ダッシュボード」画面（SCR-024）にアクセスする
2. 「利用状況を確認」ボタンをクリックする
3. ES-07から利用状況データを取得する
4. システムが利用状況（INF-AD-04）を登録する
5. ユーザーが内容を確認する

## 代替フロー

- **3a. ES-07接続エラーの場合**
  - ES-07への接続に失敗した場合、エラーメッセージを表示する
  - ユーザーは接続状況を確認して再試行する

## 後置条件

- 利用状況（INF-AD-04）がシステムに登録される
- イベント「EVT-AD-006 利用状況が確認された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-AD-04 | 利用状況 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-AD-006 | 利用状況が確認された | 基本フローステップ4完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 外部システム連携 | ES-07（分析システム）との連携が必要 |
| 2 | 接続権限 | ES-07への接続権限が必要 |
