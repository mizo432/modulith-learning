# BUC-LR-06 成果指標の測定・分析

## 概要

リリース後の利用状況や成果指標を測定・分析する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:測定対象の指標を特定する;
:測定方法を定義する;
:測定ツールを準備する;

:データを収集する;
:データを分析する;
:傾向を特定する;

if (目標達成か?) then (はい)
  :成功として記録する;
  :ベストプラクティスを記録する;
else (いいえ)
  :原因を分析する;
  :改善策を提案する;
  endif

:分析結果を記録する;
:関係者に共有する;

stop
@enduml
```
