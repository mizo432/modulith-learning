# BUC-LR-03 改善アクションの追跡・効果確認

## 概要

改善の担当・期限・状態を管理し、効果を確かめる。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:改善アクションを確認する;
:担当者を確認する;
:期限を確認する;

:進捗を追跡する;

if (期限近づいているか?) then (はい)
  :担当者に通知する;
  endif

if (完了か?) then (はい)
  :効果を確認する;
  if (効果が得られたか?) then (はい)
    :アクションを閉じる;
    :教訓を記録する;
  else (いいえ)
    :再検討を行う;
    endif
else (いいえ)
  :状態を更新する;
  endif

:追跡結果を記録する;

stop
@enduml
```
