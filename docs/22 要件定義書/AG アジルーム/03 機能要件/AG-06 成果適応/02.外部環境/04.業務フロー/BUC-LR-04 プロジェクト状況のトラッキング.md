# BUC-LR-04 プロジェクト状況のトラッキング

## 概要

進捗・マイルストーン・成果・リスクを確認・共有する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:プロジェクト情報を確認する;
:進捗状況を確認する;
:マイルストーンを確認する;
:成果を確認する;
:リスクを確認する;

:ダッシュボードを更新する;
:レポートを作成する;

if (異常があるか?) then (はい)
  :関係者に通知する;
  :対応策を検討する;
  else (いいえ)
  :そのまま進む;
  endif

:結果を共有する;

stop
@enduml
```
