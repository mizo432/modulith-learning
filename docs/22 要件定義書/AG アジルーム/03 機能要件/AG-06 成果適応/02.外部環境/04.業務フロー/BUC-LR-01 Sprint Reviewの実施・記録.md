# BUC-LR-01 Sprint Reviewの実施・記録

## 概要

インクリメントと成果を確認し、フィードバックを記録する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:レビュー準備を行う;
:参加者を招待する;
:インクリメントを提示する;
:成果を報告する;

:フィードバックを収集する;
:フィードバックを記録する;

:フィードバックを分類する;

if (アクションが必要か?) then (はい)
  :アクションアイテムを記録する;
  :担当者を割り当てる;
  endif

:レビュー結果をまとめする;
:関係者に共有する;

stop
@enduml
```
