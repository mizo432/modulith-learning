# BUC-AD-01 リリース計画の管理

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-AD-01 |
| BUC名            | リリース計画の管理 |
| 説明             | リリース対象、日付、依存関係を定義・管理する |
| 関連業務         | 成果適応 |
| 関連ユースケース | UC-AD-001, UC-AD-002, UC-AD-003 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-02     | プロダクトオーナー（PO） | リリース計画を策定し、進捗を管理 |
| 2    | ACT-04     | 開発者     | リリース計画に基づいて開発を進める |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | リリース計画策定 | リリース対象、日付、依存関係を定義する | ACT-02, ACT-04 |
| 2    | リリース計画更新 | リリース計画を修正・更新する | ACT-02, ACT-04 |
| 3    | リリース計画参照 | リリース計画・進捗・結果を確認する | ACT-02, ACT-04 |
