# BUC-LR-05 利用者レビュー・試用の実施

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-LR-05 |
| BUC名            | 利用者レビュー・試用の実施 |
| 説明             | 対象者にレビュー・試用に参加させ、結果を記録する |
| 関連業務         | 成果計測・フィードバックによる適応 |
| 関連ユースケース | UC-LR-013, UC-LR-014, UC-LR-015 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-01     | 従業員     | レビューに参加し、利用者視点のフィードバックを提供 |
| 2    | ACT-02     | プロダクトオーナー（PO） | 成果・フィードバックを検査し、目標・バックログを更新 |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | レビュー計画     | 対象者、シナリオ、期限を設定する | ACT-01, ACT-02 |
| 2    | レビュー実行     | 対象者にレビュー・試用に参加させ、結果を記録する | ACT-01, ACT-02 |
| 3    | レビュー結果参照 | レビュー・試用の結果を確認する | ACT-01, ACT-02 |
