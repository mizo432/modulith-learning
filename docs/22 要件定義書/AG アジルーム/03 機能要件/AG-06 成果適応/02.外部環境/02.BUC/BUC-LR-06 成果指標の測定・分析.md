# BUC-LR-06 成果指標の測定・分析

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-LR-06 |
| BUC名            | 成果指標の測定・分析 |
| 説明             | リリース後の利用状況や成果指標を測定・分析する |
| 関連業務         | 成果計測・フィードバックによる適応 |
| 関連ユースケース | UC-LR-016, UC-LR-017, UC-LR-020, UC-LR-021 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-02     | プロダクトオーナー（PO） | 成果・フィードバックを検査し、目標・バックログを更新 |
| 2    | ACT-04     | 開発者     | 改善を実行し、効果を確かめる |
| 3    | ACT-05     | トラッキング担当 | 進捗・成果・リスク・改善状況を参照 |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | Product Goal進捗確認 | 成果指標とバックログ・リリースの関係を可視化する | ACT-02, ACT-05 |
| 2    | 成果指標測定     | リリース後の利用状況や成果指標を測定・分析する | ACT-02, ACT-05 |
| 3    | 品質・性能Insights確認 | テスト、欠陥、性能の傾向をリリースや目標と関連づける | ACT-02, ACT-04, ACT-05 |
| 4    | 稼働状況確認     | 監視・ログ基盤から稼働状況・エラー・ログを取得する | ACT-02, ACT-04, ACT-05 |

## 制約事項

| 番号 | 制約事項 | 説明 |
