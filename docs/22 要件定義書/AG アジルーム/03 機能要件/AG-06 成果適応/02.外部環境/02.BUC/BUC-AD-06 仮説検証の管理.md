# BUC-AD-06 仮説検証の管理

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-AD-06 |
| BUC名            | 仮説検証の管理 |
| 説明             | 仮説、期待結果、検証結果を記録・管理する |
| 関連業務         | 成果適応 |
| 関連ユースケース | UC-AD-013, UC-AD-014 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-02     | プロダクトオーナー（PO） | 仮説を策定し、検証結果を確認 |
| 2    | ACT-04     | 開発者     | 検証を実行し、結果を記録 |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。
