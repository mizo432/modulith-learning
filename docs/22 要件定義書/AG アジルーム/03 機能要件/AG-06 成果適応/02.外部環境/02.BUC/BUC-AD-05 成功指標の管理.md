# BUC-AD-05 成功指標の管理

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-AD-05 |
| BUC名            | 成功指標の管理 |
| 説明             | 目標値、測定方法、頻度を設定・管理する |
| 関連業務         | 成果適応 |
| 関連ユースケース | UC-AD-010, UC-AD-011, UC-AD-012 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-02     | プロダクトオーナー（PO） | 成功指標を定義し、目標値を設定 |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | 成功指標定義 | 目標値、測定方法、頻度を設定する | ACT-02 |
| 2    | 成功指標更新 | 成功指標の目標値・測定方法を修正する | ACT-02 |
| 3    | 成功指標参照 | 成功指標の現状値・目標値・推移を確認する | ACT-02 |
