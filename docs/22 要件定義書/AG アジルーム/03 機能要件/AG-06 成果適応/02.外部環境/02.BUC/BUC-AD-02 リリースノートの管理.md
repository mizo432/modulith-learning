# BUC-AD-02 リリースノートの管理

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-AD-02 |
| BUC名            | リリースノートの管理 |
| 説明             | 変更内容、既知の問題、アップグレード手順を記録・管理する |
| 関連業務         | 成果適応 |
| 関連ユースケース | UC-AD-004, UC-AD-005, UC-AD-006 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-02     | プロダクトオーナー（PO） | リリースノートを策定し、公開を管理 |
| 2    | ACT-04     | 開発者     | 変更内容を記録し、アップグレード手順を記載 |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | リリースノート作成 | 変更内容、既知の問題、アップグレード手順を記録する | ACT-02, ACT-04 |
| 2    | リリースノート更新 | リリースノートを修正・更新する | ACT-02, ACT-04 |
| 3    | リリースノート参照 | 過去のリリースノートを確認する | ACT-02, ACT-04 |
