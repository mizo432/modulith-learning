# ES-07 監視・ログ基盤

外部システムの定義を記述します。

## 概要

| 項目           | 内容 |
|----------------|------|
| 外部システムID | ES-07 |
| 外部システム名 | 監視・ログ基盤 |
| 説明           | 稼働状況・エラー・ログを取得し、Insightsと連携 |
| 種類           | 監視システム |
| 接続方法       | API連携 |

## 接続情報

| 項目       | 内容 |
|------------|------|
| プロトコル | HTTPS |
| ポート     | 443 |
| 認証方式   | APIキー認証 |

## 連携内容

| 番号 | 連携項目 | 説明 |
|------|----------|------|
| 1    | 稼働状況取得 | システムの稼働状況（CPU使用率、メモリ使用率、ディスク使用率等）を取得する |
| 2    | エラーログ取得 | エラーログを取得し、分析に使用する |
| 3    | アクセスログ取得 | アクセスログを取得し、利用状況の分析に使用する |
| 4    | パフォーマンスデータ取得 | パフォーマンスデータ（レスポンスタイム、スループット等）を取得する |
| 5    | アラート通知 | 閾値を超えた場合にアラート通知を受け取る |

## 関連ユースケース

| 番号 | ユースケースID | ユースケース名 | 説明 |
|------|----------------|----------------|------|
| 1    | UC-LR-017      | 成果指標を測定する | リリース後の利用状況や成果指標を測定・分析する |
| 2    | UC-LR-020      | 品質・性能Insightsを確認する | テスト、欠陥、性能の傾向をリリースや目標と関連づける |
| 3    | UC-LR-021      | 稼働状況を確認する | 監視・ログ基盤から稼働状況・エラー・ログを取得する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | データのリアルタイム性 | 監視データはリアルタイムに取得する必要がある |
| 2    | 認証の必須性 | APIキー認証が必須である |
| 3    | データの正確性 | 取得されたデータは正確に記録する必要がある |
| 4    | エラーハンドリング | 接続失敗時のエラーハンドリングを実装する必要がある |
