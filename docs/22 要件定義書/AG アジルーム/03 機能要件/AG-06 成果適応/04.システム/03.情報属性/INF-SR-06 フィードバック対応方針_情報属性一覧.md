# INF-SR-06 フィードバック対応方針 情報属性一覧

フィードバック対応方針の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-06 |
| 情報名 | フィードバック対応方針 |
| 情報種類 | リソース |
| 説明 | 対応方針、判断理由、判断者 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | フィードバック対応方針の一意な識別子 |
| 2 | フィードバックID | | Long | 必須 | 関連するフィードバックのID |
| 3 | 対応方針 | | Enum | 必須 | 対応方針の種類（INF-SR-13参照） |
| 4 | 判断理由 | | String | 必須 | 判断の理由 |
| 5 | 判断者 | | String | 必須 | 判断を行った人物 |
| 6 | 作成日時 | | DateTime | 必須 | 作成日時 |
| 7 | 更新日時 | | DateTime | 任意 | 最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのフィードバックに対する対応方針が1つのエンティティ |
| 同一性 (Sameness) | フィードバックIDが同じ場合、同じ対応方針とみなす |
| カテゴリ (Category) | フィードバックへの対応方針を管理するビジネスエンティティ |
