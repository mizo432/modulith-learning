# INF-LR-03 改善アクション 情報属性一覧

改善アクションの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-LR-03 |
| 情報名 | 改善アクション |
| 情報種類 | リソース |
| 説明 | 改善の担当、期限、状態、効果 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | 改善アクションの一意な識別子 |
| 2 | タイトル | | String | 必須 | 改善アクションのタイトル |
| 3 | 説明 | | String | 任意 | 改善アクションの詳細説明 |
| 4 | 担当者 | | String | 必須 | 改善アクションの担当者 |
| 5 | 期限 | | Date | 必須 | 改善アクションの完了期限 |
| 6 | 状態 | | Enum | 必須 | 改善アクションの状態（INF-LR-11参照） |
| 7 | 効果 | | String | 任意 | 改善アクションの効果 |
| 8 | 関連Retrospective | | Long | 任意 | 関連するRetrospective記録のID |
| 9 | 作成日時 | | DateTime | 必須 | 改善アクションの作成日時 |
| 10 | 更新日時 | | DateTime | 任意 | 改善アクションの最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの改善アクションが1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じ改善アクションとみなす |
| カテゴリ (Category) | Retrospectiveで特定された改善を管理するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未着手 | 改善アクションがまだ着手されていない状態 | - | 実行中 | UC-LR-005 |
| 実行中 | 改善アクションが実行中の状態 | 未着手 | 完了 | UC-LR-006 |
| 完了 | 改善アクションが完了した状態 | 実行中 | 効果確認中 | UC-LR-006 |
| 効果確認中 | 改善アクションの効果を確認中の状態 | 完了 | - | UC-LR-008 |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-LR-02 | Retrospective記録 | 多対1 | 改善アクションは1つのRetrospective記録に関連 |
| INF-LR-10 | 改善アクションとRetrospective | 1対1 | 改善アクションとRetrospectiveの関連 |
| INF-LR-11 | 改善アクション状態 | 多対1 | 状態の対照表を参照 |
