# INF-SR-13 対応方針種類 情報属性一覧

対応方針種類の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-13 |
| 情報名 | 対応方針種類 |
| 情報種類 | 対照表 |
| 説明 | バックログに追加、既存Storyを変更、調査する、保留、対応しない、追加情報を確認 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | コード | ✓ | String | 必須 | 対応方針のコード |
| 2 | 名称 | | String | 必須 | 対応方針の名称 |
| 3 | 説明 | | String | 任意 | 対応方針の説明 |

## 列挙値

| コード | 名称 | 説明 |
|--------|------|------|
| ADD_BACKLOG | バックログに追加 | 新規バックログとして追加する |
| MODIFY_STORY | 既存Storyを変更 | 既存のStoryを変更する |
| INVESTIGATE | 調査する | 追加調査を行う |
| HOLD | 保留 | 一時的に保留する |
| NO_ACTION | 対応しない | 対応しない |
| NEED_INFO | 追加情報を確認 | 追加情報を確認する |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの対応方針コードが1つのエンティティ |
| 同一性 (Sameness) | コードが同じ場合、同じ対応方針とみなす |
| カテゴリ (Category) | フィードバックへの対応方針を定義する対照表 |
