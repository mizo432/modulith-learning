# INF-SR-10 Review議論 情報属性一覧

Review議論の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-10 |
| 情報名 | Review議論 |
| 情報種類 | リソース |
| 説明 | Review中の議論内容 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | Review議論の一意な識別子 |
| 2 | SprintReviewID | | Long | 必須 | 関連するSprint ReviewのID |
| 3 | 議論内容 | | String | 必須 | 議論の内容 |
| 4 | 発言者 | | String | 任意 | 発言者の名前 |
| 5 | 作成日時 | | DateTime | 必須 | 作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの議論が1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じ議論とみなす |
| カテゴリ (Category) | Sprint Review中の議論を記録するビジネスエンティティ |

## 関連情報

この情報と関連する他の情報をリストアップします。

|------------|------------|------------|------|
| INF-SR-01 | Sprint Review | 多対1 | 議論は1つのSprint Reviewに関連 |
