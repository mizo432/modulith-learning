# INF-SR-02 Review参加者 情報属性一覧

Review参加者の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-02 |
| 情報名 | Review参加者 |
| 情報種類 | リソース |
| 説明 | 参加者、役割、参加状況 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | Review参加者の一意な識別子 |
| 2 | SprintReviewID | | Long | 必須 | 関連するSprint ReviewのID |
| 3 | 参加者名 | | String | 必須 | 参加者の名前 |
| 4 | 役割 | | String | 必須 | 参加者の役割 |
| 5 | 参加状況 | | Boolean | 任意 | 参加の有無 |
| 6 | 作成日時 | | DateTime | 必須 | 作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのSprint Reviewに対する1つの参加者が1つのエンティティ |
| 同一性 (Sameness) | SprintReviewIDと参加者名の組み合わせが同じ場合、同じ参加者とみなす |
| カテゴリ (Category) | Sprint Reviewの参加者を管理するビジネスエンティティ |

この情報と関連する他の情報をリストアップします。

|------------|------------|------------|------|
| INF-SR-01 | Sprint Review | 多対1 | 参加者は1つのSprint Reviewに関連 |
