# INF-SR-07 バックログ候補 情報属性一覧

バックログ候補の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-07 |
| 情報名 | バックログ候補 |
| 情報種類 | リソース |
| 説明 | フィードバックから作成された新規Story・Feature・Epic候補 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | バックログ候補の一意な識別子 |
| 2 | フィードバックID | | Long | 必須 | 関連するフィードバックのID |
| 3 | 種類 | | String | 必須 | バックログの種類（Story/Feature/Epic） |
| 4 | タイトル | | String | 必須 | バックログ候補のタイトル |
| 5 | 説明 | | String | 任意 | バックログ候補の説明 |
| 6 | 優先度 | | Integer | 任意 | 優先度 |
| 7 | 作成日時 | | DateTime | 必須 | 作成日時 |
| 8 | 更新日時 | | DateTime | 任意 | 最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのバックログ候補が1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じバックログ候補とみなす |
| カテゴリ (Category) | フィードバックから作成されたバックログ候補を管理するビジネスエンティティ |
