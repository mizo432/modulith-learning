# INF-AD-07 フィードバック 情報属性一覧

フィードバックの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-AD-07 |
| 情報名 | フィードバック |
| 情報種類 | リソース |
| 説明 | リリース後の利用者からのフィードバック |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | フィードバックの一意な識別子 |
| 2 | 利用者名 | | String | 必須 | フィードバックを提供した利用者の名前 |
| 3 | フィードバック内容 | | String | 必須 | フィードバックの詳細な内容 |
| 4 | 分類 | | Enum | 任意 | フィードバックの分類（新機能要望、改善、不具合など） |
| 5 | 重要度 | | Enum | 任意 | フィードバックの重要度（高、中、低） |
| 6 | 関連機能 | | String | 任意 | 関連する機能名 |
| 7 | 状態 | | Enum | 必須 | フィードバックの状態（新規、対応中、完了、保留） |
| 8 | 対応コメント | | String | 任意 | 対応に関するコメント |
| 9 | 作成日時 | | DateTime | 必須 | フィードバックの作成日時 |
| 10 | 更新日時 | | DateTime | 任意 | フィードバックの最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのフィードバックが1つ |
| 同一性 (Sameness) | 利用者名とフィードバック内容と作成日時が同じ場合、同じフィードバックとみなす |
| カテゴリ (Category) | リリース後の利用者からのフィードバックを記録するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 新規 | フィードバックが新規に収集された状態 | - | 対応中 | UC-AD-015 |
| 対応中 | フィードバックの対応が進行中 | 新規 | 完了 / 保留 | UC-AD-015 |
| 完了 | フィードバックの対応が完了した状態 | 対応中 | - | UC-AD-015 |
| 保留 | フィードバックが保留中の状態 | 対応中 | 対応中 | UC-AD-015 |
