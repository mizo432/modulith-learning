| 項目 | 内容 |
|------|------|

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | レポートの一意な識別子 |
| 2 | タイトル | | String | 必須 | レポートのタイトル |
| 3 | 種類 | | String | 必須 | レポートの種類 |
| 4 | 出力日時 | | DateTime | 必須 | レポートの出力日時 |
| 5 | ファイルパス | | String | 必須 | レポートファイルのパス |
| 6 | 作成者 | | String | 任意 | レポートの作成者 |
| 7 | 説明 | | String | 任意 | レポートの説明 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのレポートが1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じレポートとみなす |
| カテゴリ (Category) | 出力されたレポートを管理するビジネスエンティティ |
