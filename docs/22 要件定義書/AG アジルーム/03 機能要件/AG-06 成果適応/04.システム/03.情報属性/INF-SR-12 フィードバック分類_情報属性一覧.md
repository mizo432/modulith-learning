# INF-SR-12 フィードバック分類 情報属性一覧

フィードバック分類の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-12 |
| 情報名 | フィードバック分類 |
| 情報種類 | 対照表 |
| 説明 | 新機能要望、既存機能改善、不具合、業務ルール変更、UI/UX改善、質問・確認、その他 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | コード | ✓ | String | 必須 | 分類のコード |
| 2 | 名称 | | String | 必須 | 分類の名称 |
| 3 | 説明 | | String | 任意 | 分類の説明 |

## 列挙値

| コード | 名称 | 説明 |
|--------|------|------|
| NEW_FEATURE | 新機能要望 | 新機能の要望 |
| IMPROVE_FEATURE | 既存機能改善 | 既存機能の改善要望 |
| BUG | 不具合 | 不具合の報告 |
| RULE_CHANGE | 業務ルール変更 | 業務ルールの変更要望 |
| UI_UX | UI/UX改善 | UI/UXの改善要望 |
| QUESTION | 質問・確認 | 質問や確認事項 |
| OTHER | その他 | その他のフィードバック |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの分類コードが1つのエンティティ |
| 同一性 (Sameness) | コードが同じ場合、同じ分類とみなす |
| カテゴリ (Category) | フィードバックの分類を定義する対照表 |
