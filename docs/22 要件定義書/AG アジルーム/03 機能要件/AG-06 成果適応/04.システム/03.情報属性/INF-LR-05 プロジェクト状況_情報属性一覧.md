# INF-LR-05 プロジェクト状況 情報属性一覧

プロジェクト状況の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-LR-05 |
| 情報名 | プロジェクト状況 |
| 情報種類 | リソース |
| 説明 | 進捗、マイルストーン、成果、リスク |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | プロジェクト状況の一意な識別子 |
| 2 | プロジェクト名 | | String | 必須 | プロジェクトの名前 |
| 3 | 進捗率 | | Double | 任意 | プロジェクトの進捗率（0-100） |
| 4 | マイルストーン | | String | 任意 | 現在のマイルストーン |
| 5 | 成果 | | String | 任意 | 達成した成果 |
| 6 | リスク数 | | Integer | 任意 | 現在のリスクの数 |
| 7 | 更新日時 | | DateTime | 必須 | 状況の最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのプロジェクトの状況が1つのエンティティ |
| 同一性 (Sameness) | プロジェクト名が同じ場合、同じ状況とみなす |
| カテゴリ (Category) | プロジェクトの進捗状況を管理するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 更新済 | プロジェクト状況が更新された状態 | - | - | UC-LR-010 |
