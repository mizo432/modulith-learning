# INF-AD-02 リリースノート 情報属性一覧

リリースノートの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-AD-02 |
| 情報名 | リリースノート |
| 情報種類 | リソース |
| 説明 | 変更内容、既知の問題、アップグレード手順 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | リリースノートの一意な識別子 |
| 2 | リリース名 | | String | 必須 | 関連するリリースの名前 |
| 3 | バージョン | | String | 必須 | リリースバージョン番号 |
| 4 | 変更内容 | | String | 必須 | 新機能、改善、修正などの変更内容 |
| 5 | 既知の問題 | | String | 任意 | 既知の問題や制限事項 |
| 6 | アップグレード手順 | | String | 任意 | アップグレード時の手順や注意事項 |
| 7 | 状態 | | Enum | 必須 | リリースノートの状態（ドラフト、公開） |
| 8 | 公開日時 | | DateTime | 任意 | リリースノートが公開された日時 |
| 9 | 作成者 | | String | 必須 | リリースノートを作成したユーザー |
| 10 | 作成日時 | | DateTime | 必須 | リリースノートの作成日時 |
| 11 | 更新日時 | | DateTime | 任意 | リリースノートの最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのリリースに対するリリースノートが1つ |
| 同一性 (Sameness) | リリース名とバージョンが同じ場合、同じリリースノートとみなす |
| カテゴリ (Category) | リリースの変更内容を記録するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| ドラフト | リリースノートが作成されたが未公開 | - | 公開 | UC-AD-004 |
| 公開 | リリースノートが公開された状態 | ドラフト | - | UC-AD-004 |
