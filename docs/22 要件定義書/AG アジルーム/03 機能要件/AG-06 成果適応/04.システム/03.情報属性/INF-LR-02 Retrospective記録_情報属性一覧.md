# INF-LR-02 Retrospective記録 情報属性一覧

Retrospective記録の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-LR-02 |
| 情報名 | Retrospective記録 |
| 情報種類 | リソース |
| 説明 | 学び、改善候補、決定事項 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | Retrospective記録の一意な識別子 |
| 2 | 対象Sprint | | String | 必須 | 対象となるSprintの識別子 |
| 3 | 開催日時 | | DateTime | 必須 | Retrospectiveの開催日時 |
| 4 | 学び | | String | 任意 | 得られた学び |
| 5 | 改善候補数 | | Integer | 任意 | 特定された改善候補の数 |
| 6 | 決定事項 | | String | 任意 | 決定された事項 |
| 7 | 作成日時 | | DateTime | 必須 | 記録の作成日時 |
| 8 | 更新日時 | | DateTime | 任意 | 記録の最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのSprintに対するRetrospective記録が1つ |
| 同一性 (Sameness) | 対象Sprintと開催日時が同じ場合、同じ記録とみなす |
| カテゴリ (Category) | Sprint Retrospectiveの結果を記録するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 作成済 | Retrospective記録が作成された状態 | - | 更新中 | UC-LR-003 |
| 更新中 | Retrospective記録が更新中の状態 | 作成済 | 完了 | UC-LR-003 |
| 完了 | Retrospective記録が完了した状態 | 更新中 | - | UC-LR-003 |
