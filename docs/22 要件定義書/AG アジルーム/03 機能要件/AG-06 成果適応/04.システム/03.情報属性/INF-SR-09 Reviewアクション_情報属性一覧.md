# INF-SR-09 Reviewアクション 情報属性一覧

Reviewアクションの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-09 |
| 情報名 | Reviewアクション |
| 情報種類 | リソース |
| 説明 | 継続確認事項、担当者、期限、状態 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | Reviewアクションの一意な識別子 |
| 2 | SprintReviewID | | Long | 必須 | 関連するSprint ReviewのID |
| 3 | 確認事項 | | String | 必須 | 継続確認する事項 |
| 4 | 担当者 | | String | 必須 | 担当者の名前 |
| 5 | 期限 | | Date | 必須 | 完了期限 |
| 6 | 状態 | | String | 必須 | アクションの状態 |
| 7 | 作成日時 | | DateTime | 必須 | 作成日時 |
| 8 | 更新日時 | | DateTime | 任意 | 最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのReviewアクションが1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じアクションとみなす |
| カテゴリ (Category) | Sprint Reviewで決定された継続確認事項を管理するビジネスエンティティ |
