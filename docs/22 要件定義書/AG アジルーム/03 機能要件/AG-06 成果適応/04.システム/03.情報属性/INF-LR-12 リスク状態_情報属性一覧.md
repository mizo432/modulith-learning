# INF-LR-12 リスク状態 情報属性一覧

リスク状態の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-LR-12 |
| 情報名 | リスク状態 |
| 情報種類 | 対照表 |
| 説明 | 新規、対応中、解消、受容 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | コード | ✓ | String | 必須 | 状態のコード |
| 2 | 名称 | | String | 必須 | 状態の名称 |
| 3 | 説明 | | String | 任意 | 状態の説明 |

## 列挙値

| コード | 名称 | 説明 |
|--------|------|------|
| NEW | 新規 | リスクが新規に特定された状態 |
| IN_PROGRESS | 対応中 | リスクへの対応中の状態 |
| RESOLVED | 解消 | リスクが解消された状態 |
| ACCEPTED | 受容 | リスクを受容した状態 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの状態コードが1つのエンティティ |
| 同一性 (Sameness) | コードが同じ場合、同じ状態とみなす |
| カテゴリ (Category) | リスクの状態を定義する対照表 |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-LR-06 | リスク | 1対多 | 複数のリスクが状態を参照 |
