# INF-AD-01 リリース計画 情報属性一覧

リリース計画の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-AD-01 |
| 情報名 | リリース計画 |
| 情報種類 | リソース |
| 説明 | リリース対象、日付、依存関係 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | リリース計画の一意な識別子 |
| 2 | リリース名 | | String | 必須 | リリースの名前 |
| 3 | 対象バージョン | | String | 必須 | リリース対象のバージョン番号 |
| 4 | 計画日付 | | Date | 必須 | 計画されたリリース日付 |
| 5 | 実際のリリース日付 | | Date | 任意 | 実際のリリース日付 |
| 6 | 状態 | | Enum | 必須 | リリース計画の状態（計画中、準備中、準備完了、実施中、完了） |
| 7 | 依存関係 | | String | 任意 | 他のリリースやプロジェクトとの依存関係 |
| 8 | 対象Epic | | String | 任意 | 対象となるEpicの識別子 |
| 9 | 対象Story数 | | Integer | 任意 | 対象となるStoryの数 |
| 10 | 作成者 | | String | 必須 | リリース計画を作成したユーザー |
| 11 | 作成日時 | | DateTime | 必須 | リリース計画の作成日時 |
| 12 | 更新日時 | | DateTime | 任意 | リリース計画の最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのリリースに対する計画が1つ |
| 同一性 (Sameness) | リリース名と対象バージョンが同じ場合、同じ計画とみなす |
| カテゴリ (Category) | リリースの計画情報を管理するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 計画中 | リリースが計画された状態 | - | 準備中 | UC-AD-001 |
| 準備中 | リリースの準備が進行中 | 計画中 | 準備完了 | UC-AD-002 |
| 準備完了 | リリースの準備が完了した状態 | 準備中 | 実施中 | UC-AD-007 |
| 実施中 | リリースが進行中 | 準備完了 | 完了 | UC-AD-007 |
| 完了 | リリースが完了した状態 | 実施中 | - | UC-AD-007 |
