# INF-SR-05 Reviewフィードバック 情報属性一覧

Reviewフィードバックの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-05 |
| 情報名 | Reviewフィードバック |
| 情報種類 | リソース |
| 説明 | フィードバック内容、発言者、分類、関連Story、添付資料 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | Reviewフィードバックの一意な識別子 |
| 2 | SprintReviewID | | Long | 必須 | 関連するSprint ReviewのID |
| 3 | フィードバック内容 | | String | 必須 | フィードバックの内容 |
| 4 | 発言者 | | String | 必須 | フィードバックの発言者 |
| 5 | 分類 | | Enum | 任意 | フィードバックの分類（INF-SR-12参照） |
| 6 | 関連Story | | String | 任意 | 関連するStoryの識別子 |
| 7 | 添付資料 | | String | 任意 | 添付資料のパス |
| 8 | 作成日時 | | DateTime | 必須 | 作成日時 |
| 9 | 更新日時 | | DateTime | 任意 | 最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのフィードバックが1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じフィードバックとみなす |
| カテゴリ (Category) | Sprint Reviewで収集したフィードバックを管理するビジネスエンティティ |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-SR-01 | Sprint Review | 多対1 | フィードバックは1つのSprint Reviewに関連 |
| INF-SR-06 | フィードバック対応方針 | 1対1 | フィードバックは1つの対応方針を持つ |
| INF-SR-12 | フィードバック分類 | 多対1 | 分類の対照表を参照 |
