# INF-SR-11 Sprint Review状態 情報属性一覧

Sprint Review状態の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-11 |
| 情報名 | Sprint Review状態 |
| 情報種類 | 対照表 |
| 説明 | 未準備、準備中、準備完了、開催中、完了 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | コード | ✓ | String | 必須 | 状態のコード |
| 2 | 名称 | | String | 必須 | 状態の名称 |
| 3 | 説明 | | String | 任意 | 状態の説明 |

## 列挙値

| コード | 名称 | 説明 |
|--------|------|------|
| NOT_PREPARED | 未準備 | Sprint Reviewがまだ準備されていない状態 |
| PREPARING | 準備中 | Sprint Reviewの準備中の状態 |
| PREPARED | 準備完了 | Sprint Reviewの準備が完了した状態 |
| IN_PROGRESS | 開催中 | Sprint Reviewが開催中の状態 |
| COMPLETED | 完了 | Sprint Reviewが完了した状態 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの状態コードが1つのエンティティ |
| 同一性 (Sameness) | コードが同じ場合、同じ状態とみなす |
| カテゴリ (Category) | Sprint Reviewの状態を定義する対照表 |
