# INF-AD-04 利用状況 情報属性一覧

利用状況の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-AD-04 |
| 情報名 | 利用状況 |
| 情報種類 | リソース |
| 説明 | 機能利用頻度、アクティブユーザー、アクセス傾向 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | 利用状況の一意な識別子 |
| 2 | 機能名 | | String | 必須 | 利用状況の対象となる機能名 |
| 3 | 測定期間開始 | | Date | 必須 | 測定期間の開始日 |
| 4 | 測定期間終了 | | Date | 必須 | 測定期間の終了日 |
| 5 | 利用頻度 | | Integer | 任意 | 機能の利用回数 |
| 6 | アクティブユーザー数 | | Integer | 任意 | アクティブなユーザー数 |
| 7 | アクセス傾向 | | String | 任意 | アクセスの傾向（増加、横ばい、減少） |
| 8 | 平均利用時間 | | Double | 任意 | 平均利用時間（分） |
| 9 | 作成日時 | | DateTime | 必須 | 利用状況データの作成日時 |
| 10 | 更新日時 | | DateTime | 任意 | 利用状況データの最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの機能の1測定期間に対する利用状況が1つ |
| 同一性 (Sameness) | 機能名と測定期間が同じ場合、同じ利用状況とみなす |
| カテゴリ (Category) | 機能の利用状況を記録するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 測定中 | 利用状況の測定が進行中 | - | 完了 | UC-AD-009 |
| 完了 | 利用状況の測定が完了した状態 | 測定中 | - | UC-AD-009 |
