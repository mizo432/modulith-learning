# INF-LR-06 リスク 情報属性一覧

リスクの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-LR-06 |
| 情報名 | リスク |
| 情報種類 | リソース |
| 説明 | 依存関係、課題、遅延リスク |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | リスクの一意な識別子 |
| 2 | タイトル | | String | 必須 | リスクのタイトル |
| 3 | 説明 | | String | 任意 | リスクの詳細説明 |
| 4 | 状態 | | Enum | 必須 | リスクの状態（INF-LR-12参照） |
| 5 | 影響度 | | String | 任意 | リスクの影響度 |
| 6 | 担当者 | | String | 任意 | リスクの担当者 |
| 7 | 期限 | | Date | 任意 | 対応期限 |
| 8 | 依存関係 | | String | 任意 | 依存する事項 |
| 9 | 作成日時 | | DateTime | 必須 | リスクの作成日時 |
| 10 | 更新日時 | | DateTime | 任意 | リスクの最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのリスクが1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じリスクとみなす |
| カテゴリ (Category) | プロジェクトのリスクを管理するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 新規 | リスクが新規に特定された状態 | - | 対応中 | UC-LR-011 |
| 対応中 | リスクへの対応中の状態 | 新規 | 解消, 受容 | UC-LR-011 |
| 解消 | リスクが解消された状態 | 対応中 | - | UC-LR-011 |
| 受容 | リスクを受容した状態 | 対応中 | - | UC-LR-011 |
