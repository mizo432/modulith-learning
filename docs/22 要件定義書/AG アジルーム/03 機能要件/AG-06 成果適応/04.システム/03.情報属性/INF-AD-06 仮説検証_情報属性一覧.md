# INF-AD-06 仮説検証 情報属性一覧

仮説検証の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-AD-06 |
| 情報名 | 仮説検証 |
| 情報種類 | リソース |
| 説明 | 仮説、期待結果、検証結果 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | 仮説検証の一意な識別子 |
| 2 | 仮説名 | | String | 必須 | 検証する仮説の名前 |
| 3 | 仮説内容 | | String | 必須 | 仮説の詳細な内容 |
| 4 | 期待結果 | | String | 必須 | 期待される結果 |
| 5 | 検証結果 | | String | 任意 | 実際の検証結果 |
| 6 | 状態 | | Enum | 必須 | 検証の状態（検証中、検証完了） |
| 7 | 検証方法 | | String | 任意 | 検証の方法や手順 |
| 8 | 検証期間開始 | | Date | 任意 | 検証期間の開始日 |
| 9 | 検証期間終了 | | Date | 任意 | 検証期間の終了日 |
| 10 | 作成者 | | String | 必須 | 仮説検証を作成したユーザー |
| 11 | 作成日時 | | DateTime | 必須 | 仮説検証の作成日時 |
| 12 | 更新日時 | | DateTime | 任意 | 仮説検証の最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの仮説に対する検証が1つ |
| 同一性 (Sameness) | 仮説名が同じ場合、同じ仮説検証とみなす |
| カテゴリ (Category) | 仮説の検証結果を記録するビジネスエンティティ |

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 検証中 | 仮説検証が進行中 | - | 検証完了 | UC-AD-013 |
| 検証完了 | 仮説検証が完了した状態 | 検証中 | - | UC-AD-013 |
