# INF-AD-03 デプロイ結果 情報属性一覧

デプロイ結果の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-AD-03 |
| 情報名 | デプロイ結果 |
| 情報種類 | リソース |
| 説明 | 環境、バージョン、ロールバック手順、成功・失敗 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | デプロイ結果の一意な識別子 |
| 2 | 環境 | | String | 必須 | デプロイ対象環境（開発、ステージング、本番など） |
| 3 | バージョン | | String | 必須 | デプロイしたバージョン番号 |
| 4 | 状態 | | Enum | 必須 | デプロイ結果の状態（デプロイ中、成功、失敗、ロールバック） |
| 5 | デプロイ開始日時 | | DateTime | 必須 | デプロイが開始された日時 |
| 6 | デプロイ終了日時 | | DateTime | 任意 | デプロイが終了した日時 |
| 7 | ロールバック手順 | | String | 任意 | ロールバック時の手順 |
| 8 | エラーメッセージ | | String | 任意 | デプロイ失敗時のエラーメッセージ |
| 9 | 実行者 | | String | 必須 | デプロイを実行したユーザー |
| 10 | 作成日時 | | DateTime | 必須 | デプロイ結果の作成日時 |
| 11 | 更新日時 | | DateTime | 任意 | デプロイ結果の最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1回のデプロイ実行に対する結果が1つ |
| 同一性 (Sameness) | 環境、バージョン、デプロイ開始日時が同じ場合、同じ結果とみなす |
| カテゴリ (Category) | デプロイの結果を記録するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| デプロイ中 | デプロイが進行中 | - | 成功 / 失敗 | UC-AD-007 |
| 成功 | デプロイが成功した状態 | デプロイ中 | - | UC-AD-007 |
| 失敗 | デプロイが失敗した状態 | デプロイ中 | ロールバック | UC-AD-007 |
| ロールバック | デプロイがロールバックされた状態 | 失敗 | - | UC-AD-007 |
