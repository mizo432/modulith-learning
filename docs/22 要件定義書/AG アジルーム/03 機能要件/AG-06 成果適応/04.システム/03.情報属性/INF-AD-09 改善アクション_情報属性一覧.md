# INF-AD-09 改善アクション 情報属性一覧

改善アクションの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-AD-09 |
| 情報名 | 改善アクション |
| 情報種類 | リソース |
| 説明 | 改善アクション、担当者、期限、状態 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | 改善アクションの一意な識別子 |
| 2 | アクション名 | | String | 必須 | 改善アクションの名前 |
| 3 | 内容 | | String | 必須 | 改善アクションの詳細な内容 |
| 4 | 担当者 | | String | 必須 | 担当者の名前 |
| 5 | 期限 | | Date | 必須 | 完了の期限日 |
| 6 | 状態 | | Enum | 必須 | 改善アクションの状態（未着手、実行中、完了、効果確認中） |
| 7 | 優先度 | | Enum | 任意 | 優先度（高、中、低） |
| 8 | 効果 | | String | 任意 | 改善による効果 |
| 9 | 関連レトロスペクティブ | | Long | 任意 | 関連するレトロスペクティブのID |
| 10 | 作成者 | | String | 必須 | 改善アクションを記録したユーザー |
| 11 | 作成日時 | | DateTime | 必須 | 改善アクションの作成日時 |
| 12 | 更新日時 | | DateTime | 任意 | 改善アクションの最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの改善アクションが1つ |
| 同一性 (Sameness) | アクション名と担当者と期限が同じ場合、同じ改善アクションとみなす |
| カテゴリ (Category) | 改善のためのアクションを管理するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未着手 | 改善アクションが登録されたが未着手 | - | 実行中 | UC-AD-019 |
| 実行中 | 改善アクションが実行中 | 未着手 | 完了 | UC-AD-020 |
| 完了 | 改善アクションが完了した状態 | 実行中 | 効果確認中 | UC-AD-020 |
| 効果確認中 | 改善の効果を確認中 | 完了 | - | UC-AD-020 |
