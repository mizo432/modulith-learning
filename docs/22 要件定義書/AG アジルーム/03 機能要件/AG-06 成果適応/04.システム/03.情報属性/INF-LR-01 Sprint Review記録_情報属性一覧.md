# INF-LR-01 Sprint Review記録 情報属性一覧

Sprint Review記録の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-LR-01 |
| 情報名 | Sprint Review記録 |
| 情報種類 | リソース |
| 説明 | 成果、フィードバック、決定、未解決事項 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | Sprint Review記録の一意な識別子 |
| 2 | 対象Sprint | | String | 必須 | 対象となるSprintの識別子 |
| 3 | 開催日時 | | DateTime | 必須 | Sprint Reviewの開催日時 |
| 4 | 成果 | | String | 任意 | Sprintで達成した成果の概要 |
| 5 | フィードバック数 | | Integer | 任意 | 収集したフィードバックの数 |
| 6 | 決定事項数 | | Integer | 任意 | 記録された決定事項の数 |
| 7 | 未解決事項 | | String | 任意 | 未解決の事項 |
| 8 | 作成日時 | | DateTime | 必須 | 記録の作成日時 |
| 9 | 更新日時 | | DateTime | 任意 | 記録の最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのSprintに対するSprint Review記録が1つ |
| 同一性 (Sameness) | 対象Sprintと開催日時が同じ場合、同じ記録とみなす |
| カテゴリ (Category) | Sprint Reviewの結果を記録するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 作成済 | Sprint Review記録が作成された状態 | - | 更新中 | UC-LR-001 |
| 更新中 | Sprint Review記録が更新中の状態 | 作成済 | 完了 | UC-LR-001 |
| 完了 | Sprint Review記録が完了した状態 | 更新中 | - | UC-LR-001 |
