## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | 関連の一意な識別子 |
| 2 | 改善アクションID | | Long | 必須 | 関連する改善アクションのID |
| 3 | RetrospectiveID | | Long | 必須 | 関連するRetrospectiveのID |
| 4 | 作成日時 | | DateTime | 必須 | 関連の作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの改善アクションと1つのRetrospectiveの関連が1つのエンティティ |
| 同一性 (Sameness) | 改善アクションIDとRetrospectiveIDの組み合わせが同じ場合、同じ関連とみなす |
| カテゴリ (Category) | 改善アクションとRetrospectiveの関連を管理する対応表 |
