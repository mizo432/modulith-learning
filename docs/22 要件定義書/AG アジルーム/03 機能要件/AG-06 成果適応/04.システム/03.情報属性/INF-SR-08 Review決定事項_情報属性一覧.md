# INF-SR-08 Review決定事項 情報属性一覧

Review決定事項の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-08 |
| 情報名 | Review決定事項 |
| 情報種類 | リソース |
| 説明 | 決定事項、決定理由 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | Review決定事項の一意な識別子 |
| 2 | SprintReviewID | | Long | 必須 | 関連するSprint ReviewのID |
| 3 | 決定事項 | | String | 必須 | 決定された事項 |
| 4 | 決定理由 | | String | 必須 | 決定の理由 |
| 5 | 作成日時 | | DateTime | 必須 | 作成日時 |
| 6 | 更新日時 | | DateTime | 任意 | 最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの決定事項が1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じ決定事項とみなす |
| カテゴリ (Category) | Sprint Reviewで決定された事項を管理するビジネスエンティティ |
