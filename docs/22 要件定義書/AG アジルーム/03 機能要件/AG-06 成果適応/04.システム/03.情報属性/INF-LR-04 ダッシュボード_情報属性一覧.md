## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | ダッシュボードの一意な識別子 |
| 2 | 表示構成名 | | String | 必須 | ダッシュボードの表示構成名 |
| 3 | 対象ロール | | String | 必須 | 表示対象のロール |
| 4 | 表示項目 | | String | 任意 | 表示する項目のリスト |
| 5 | 更新頻度 | | Integer | 任意 | 更新頻度（秒） |
| 6 | 作成日時 | | DateTime | 必須 | 作成日時 |
| 7 | 更新日時 | | DateTime | 任意 | 最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのロールに対するダッシュボード表示構成が1つ |
| 同一性 (Sameness) | 対象ロールが同じ場合、同じ表示構成とみなす |
| カテゴリ (Category) | ロールに応じたダッシュボード表示を定義するビジネスエンティティ |
