# INF-SR-03 Review議題 情報属性一覧

Review議題の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-03 |
| 情報名 | Review議題 |
| 情報種類 | リソース |
| 説明 | 議題、順序、説明 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | Review議題の一意な識別子 |
| 2 | SprintReviewID | | Long | 必須 | 関連するSprint ReviewのID |
| 3 | 議題名 | | String | 必須 | 議題の名前 |
| 4 | 順序 | | Integer | 必須 | 議題の順序 |
| 5 | 説明 | | String | 任意 | 議題の説明 |
| 6 | 作成日時 | | DateTime | 必須 | 作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのSprint Reviewに対する1つの議題が1つのエンティティ |
| 同一性 (Sameness) | SprintReviewIDと議題名の組み合わせが同じ場合、同じ議題とみなす |
| カテゴリ (Category) | Sprint Reviewの議題を管理するビジネスエンティティ |
