# INF-LR-08 成果指標データ 情報属性一覧

成果指標データの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-LR-08 |
| 情報名 | 成果指標データ |
| 情報種類 | リソース |
| 説明 | リリース後の利用状況や成果指標 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | 成果指標データの一意な識別子 |
| 2 | 指標名 | | String | 必須 | 成果指標の名前 |
| 3 | 測定値 | | Double | 必須 | 測定された値 |
| 4 | 測定日時 | | DateTime | 必須 | 測定日時 |
| 5 | 単位 | | String | 任意 | 指標の単位 |
| 6 | 目標値 | | Double | 任意 | 目標とする値 |
| 7 | 説明 | | String | 任意 | 指標の説明 |
| 8 | 更新日時 | | DateTime | 任意 | データの最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの成果指標の測定データが1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じデータとみなす |
| カテゴリ (Category) | リリース後の成果を測定するビジネスエンティティ |
