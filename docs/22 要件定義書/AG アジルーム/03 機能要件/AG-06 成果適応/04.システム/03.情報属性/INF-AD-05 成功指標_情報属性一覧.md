# INF-AD-05 成功指標 情報属性一覧

成功指標の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-AD-05 |
| 情報名 | 成功指標 |
| 情報種類 | リソース |
| 説明 | 目標値、測定方法、頻度、現状値 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | 成功指標の一意な識別子 |
| 2 | 指標名 | | String | 必須 | 成功指標の名前 |
| 3 | 目標値 | | Double | 必須 | 目標とする値 |
| 4 | 現状値 | | Double | 任意 | 現在の値 |
| 5 | 測定方法 | | String | 必須 | 測定の方法やツール |
| 6 | 測定頻度 | | Enum | 必須 | 測定の頻度（日次、週次、月次など） |
| 7 | 単位 | | String | 必須 | 値の単位 |
| 8 | 対象期間開始 | | Date | 任意 | 対象期間の開始日 |
| 9 | 対象期間終了 | | Date | 任意 | 対象期間の終了日 |
| 10 | 作成者 | | String | 必須 | 成功指標を定義したユーザー |
| 11 | 作成日時 | | DateTime | 必須 | 成功指標の作成日時 |
| 12 | 更新日時 | | DateTime | 任意 | 成功指標の最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの成功指標が1つ |
| 同一性 (Sameness) | 指標名が同じ場合、同じ成功指標とみなす |
| カテゴリ (Category) | リリースの成功を測定する指標を管理するビジネスエンティティ |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 定義済 | 成功指標が定義された状態 | - | 測定中 | UC-AD-010 |
| 測定中 | 成功指標の測定が進行中 | 定義済 | 達成 / 未達成 | UC-AD-011 |
| 達成 | 目標値を達成した状態 | 測定中 | - | UC-AD-011 |
| 未達成 | 目標値を未達成の状態 | 測定中 | 測定中 | UC-AD-011 |
