# INF-SR-04 デモ対象インクリメント 情報属性一覧

デモ対象インクリメントの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-SR-04 |
| 情報名 | デモ対象インクリメント |
| 情報種類 | リソース |
| 説明 | デモ対象となるインクリメント、説明、実施結果 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | デモ対象インクリメントの一意な識別子 |
| 2 | SprintReviewID | | Long | 必須 | 関連するSprint ReviewのID |
| 3 | インクリメント名 | | String | 必須 | デモ対象のインクリメント名 |
| 4 | 説明 | | String | 任意 | インクリメントの説明 |
| 5 | 実施結果 | | String | 任意 | デモの実施結果 |
| 6 | 作成日時 | | DateTime | 必須 | 作成日時 |
| 7 | 更新日時 | | DateTime | 任意 | 最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのSprint Reviewに対する1つのデモ対象が1つのエンティティ |
| 同一性 (Sameness) | SprintReviewIDとインクリメント名の組み合わせが同じ場合、同じデモ対象とみなす |
| カテゴリ (Category) | Sprint Reviewでデモするインクリメントを管理するビジネスエンティティ |
