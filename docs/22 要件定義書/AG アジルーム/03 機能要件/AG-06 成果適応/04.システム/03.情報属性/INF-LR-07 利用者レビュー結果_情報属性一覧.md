## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | ID | ✓ | Long | 必須 | 利用者レビュー結果の一意な識別子 |
| 2 | 対象者 | | String | 必須 | レビューの対象者 |
| 3 | シナリオ | | String | 必須 | 評価シナリオ |
| 4 | 期限 | | Date | 必須 | レビューの期限 |
| 5 | 結果 | | String | 任意 | レビューの結果 |
| 6 | 評価 | | Double | 任意 | 評価スコア |
| 7 | 作成日時 | | DateTime | 必須 | 結果の作成日時 |
| 8 | 更新日時 | | DateTime | 任意 | 結果の最終更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの利用者レビューの結果が1つのエンティティ |
| 同一性 (Sameness) | IDが同じ場合、同じ結果とみなす |
| カテゴリ (Category) | 利用者レビューの結果を記録するビジネスエンティティ |
