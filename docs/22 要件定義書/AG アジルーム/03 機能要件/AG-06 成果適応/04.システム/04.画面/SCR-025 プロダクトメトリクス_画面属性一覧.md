# 画面属性一覧

プロダクトメトリクスの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-025 |
| 画面名 | プロダクトメトリクス |
| 説明 | 成果指標、利用状況、フロー指標、品質の推移を確認する |
| 関連ユースケース | UC-LR-016, UC-LR-017, UC-LR-018, UC-LR-020, UC-LR-021 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 指標名 | 表示 | String | はい | - | - | 指標の名前 |
| 2 | 基準値 | 表示 | Double | はい | - | 0以上 | 現在の基準値 |
| 3 | 目標値 | 表示 | Double | はい | - | 0以上 | 目標値 |
| 4 | 測定値 | 表示 | Double | いいえ | - | 0以上 | 測定された値 |
| 5 | 推移グラフ | 表示 | String | いいえ | - | - | 指標の推移 |
| 6 | 品質Insights | 表示 | String | いいえ | - | - | 品質・性能の傾向 |
| 7 | 稼働状況 | 表示 | String | いいえ | - | - | 監視・ログ基盤からの情報 |
| 8 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
