# 画面属性一覧

Sprint Review記録の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-017 |
| 画面名 | Sprint Review記録 |
| 説明 | 成果、フィードバック、決定、未解決事項を記録する |
| 関連ユースケース | UC-LR-001, UC-LR-002, UC-LR-013, UC-LR-014, UC-LR-015 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Sprint名 | 表示 | String | はい | - | - | Review対象のSprint名 |
| 2 | 期間 | 表示 | Date | はい | - | - | Sprintの期間 |
| 3 | 成果 | 入力 | String | はい | - | 最大2000文字 | Sprintで達成した成果 |
| 4 | フィードバック | 入力 | String | はい | - | 最大2000文字 | ステークホルダーからのフィードバック |
| 5 | 決定事項 | 入力 | String | いいえ | - | 最大1000文字 | 会議で決定された事項 |
| 6 | 未解決事項 | 入力 | String | いいえ | - | 最大1000文字 | 未解決の課題や懸念事項 |
| 7 | 参加者 | 表示 | String | はい | - | - | 参加したメンバー |
| 8 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
