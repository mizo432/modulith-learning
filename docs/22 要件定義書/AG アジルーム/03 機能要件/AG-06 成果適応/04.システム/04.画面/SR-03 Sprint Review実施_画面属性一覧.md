# 画面属性一覧

Sprint Review実施の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SR-03 |
| 画面名 | Sprint Review実施 |
| 説明 | 成果デモ、フィードバック、議論内容を記録する |
| 関連ユースケース | UC-SR-005, UC-SR-006, UC-SR-007 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Sprint名 | 表示 | String | はい | - | - | 対象Sprintの名前 |
| 2 | Sprint Goal | 表示 | String | はい | - | - | Sprintの目標 |
| 3 | 達成状況 | 表示 | String | はい | - | - | Sprint Goalの達成状況 |
| 4 | 完了Story | 表示 | String | いいえ | - | - | 完了したStory |
| 5 | 未完了Story | 表示 | String | いいえ | - | - | 未完了のStory |
| 6 | デモ結果 | 入力 | String | いいえ | - | 最大2000文字 | デモの実施結果 |
| 7 | フィードバック | 入力 | String | いいえ | - | 最大1000文字 | ステークホルダーからのフィードバック |
| 8 | フィードバック種別 | 選択 | Enum | いいえ | - | - | フィードバックの種別 |
| 9 | 議論内容 | 入力 | String | いいえ | - | 最大2000文字 | 議論の内容 |
| 10 | 決定事項 | 入力 | String | いいえ | - | 最大1000文字 | 決定された事項 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

| 2 | 成果確認 | 完了・未完了Storyを表示 | 完了Story、未完了Story |
| 3 | デモ | デモ結果を記録 | デモ結果 |

| 5 | 議論・決定 | 議論と決定事項を記録 | 議論内容、決定事項 |
