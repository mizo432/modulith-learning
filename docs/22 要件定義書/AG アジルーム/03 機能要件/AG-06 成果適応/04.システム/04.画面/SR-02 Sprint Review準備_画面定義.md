# Sprint Review準備

Sprint Review準備画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SR-02 |
| 画面名           | Sprint Review準備 |
| 説明             | 成果、Sprint Goal、デモ対象、参加者、議題を準備する |
| 関連ユースケース | UC-SR-002, UC-SR-003, UC-SR-004 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint名、Sprint Goalを表示 |
| 準備情報 | 成果、デモ対象を入力 |
| 参加者・議題 | 参加者と議題を管理 |
| 開催情報 | 開催日時、備考を入力 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Sprint名 | 文字列 | はい | 対象Sprintの名前 |
| 2 | Sprint Goal | 文字列 | はい | Sprintの目標 |
| 3 | 成果 | テキスト | はい | Sprintで達成した成果 |
| 4 | デモ対象 | テキスト | いいえ | デモする対象 |
| 5 | 参加者 | 文字列 | いいえ | 参加者一覧 |
| 6 | 議題 | 文字列 | いいえ | 議題一覧 |
| 7 | 開催日時 | 日時 | はい | Sprint Reviewの開催日時 |
| 8 | 備考 | テキスト | いいえ | 備考 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 準備を保存 | Sprint Reviewの準備情報を保存する |
| 2 | 参加者を登録 | 参加者を登録する |
| 3 | 議題を設定 | 議題を設定する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Sprint Reviewの準備はPO、SM、開発者のみ可能 |
