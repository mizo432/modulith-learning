# 会議・意思決定管理

会議・意思決定管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-026 |
| 画面名           | 会議・意思決定管理 |
| 説明             | ステアリング会議等の議題、決定、アクション、課題を管理する |
| 関連ユースケース | - |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 会議名、日時、ステータスを表示 |
| ナビゲーション | 議題、決定事項、アクション、課題の切り替え |
| メインコンテンツ | 会議の詳細を表示・編集 |
| サイドバー | 参加者一覧、関連ドキュメントを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 会議名 | 文字列 | はい | 会議の名前 |
| 2 | 日時 | 日時 | はい | 会議の開催日時 |
| 3 | 議題 | テキスト | はい | 会議の議題 |
| 4 | 決定事項 | テキスト | いいえ | 決定された事項 |
| 5 | アクション | テキスト | いいえ | 決定されたアクション |
| 6 | 課題 | テキスト | いいえ | 発生した課題 |
| 7 | 参加者 | 文字列 | はい | 会議の参加者 |
| 8 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 会議を登録 | 新しい会議を登録する |
| 2 | 議題を設定 | 会議の議題を設定する |
| 3 | 決定事項を記録 | 決定された事項を記録する |
| 4 | アクションを記録 | 決定されたアクションを記録する |
| 5 | 会議を参照 | 過去の会議の内容を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 会議の編集はPO、SM、関係者のみ可能 |
| 2 | 参照権限 | 会議の参照はプロジェクトメンバー |
