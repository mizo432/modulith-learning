# 会議・意思決定管理

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-026 |
| 画面名           | 会議・意思決定管理 |
| 説明             | ステアリング会議等の議題、決定、アクション、課題を管理する |
| 関連ユースケース | - |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 会議名、日時、参加者情報 |
| 議題セクション | 議題の一覧と詳細を表示 |
| 決定セクション | 決定事項の一覧と詳細を表示 |
| アクションセクション | アクションアイテムの一覧と詳細を表示 |
| 課題セクション | 課題の一覧と詳細を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | 会議名 | String | 必須 | 会議の名前 |
| 2    | 日時 | DateTime | 必須 | 会議の日時 |
| 3    | 参加者 | String | 必須 | 参加者の一覧 |
| 4    | 議題 | String | 必須 | 議題の内容 |
| 5    | 決定事項 | String | 任意 | 決定事項の内容 |
| 6    | アクションアイテム | String | 任意 | アクションアイテムの内容 |
| 7    | 担当者 | String | 任意 | アクションアイテムの担当者 |
| 8    | 期限 | Date | 任意 | アクションアイテムの期限 |
| 9    | 課題 | String | 任意 | 課題の内容 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 新規会議作成 | 新たな会議を作成する |
| 2    | 議題追加 | 議題を追加する |
| 3    | 決定記録 | 決定事項を記録する |
| 4    | アクション追加 | アクションアイテムを追加する |
| 5    | 保存 | 会議の結果を保存する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 参加者の必須入力 | 会議には参加者を必ず設定する必要がある |
| 2    | 議題の必須入力 | 会議には議題を必ず設定する必要がある |
| 3    | 決定事項の記録義務 | 決定事項は必ず記録する必要がある |
