# 会議・意思決定管理

会議・意思決定管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-026 |
| 画面名           | 会議・意思決定管理 |
| 説明             | ステアリング会議等の議題、決定、アクション、課題を管理する |
| 関連ユースケース | (なし) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロジェクト名、会議総数、次回会議日を表示 |
| 検索・フィルター | 種類、日付で検索・絞り込み |
| メインコンテンツ | 会議一覧表または詳細情報を表示 |
| サイドバー | 決定事項、アクション一覧を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 会議名 | 文字列 | はい | 会議の名前 |
| 2 | 種類 | 選択 | はい | 会議の種類（ステアリング、定例、臨時） |
| 3 | 開催日 | 日付 | はい | 開催日 |
| 4 | 参加者 | 複数選択 | はい | 参加したメンバー |
| 5 | 議題 | テキスト | はい | 議題の内容 |
| 6 | 決定事項 | テキスト | いいえ | 決定された事項 |
| 7 | アクション | テキスト | いいえ | 決定されたアクション |
| 8 | 課題 | テキスト | いいえ | 発生した課題 |
| 9 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 会議を参照 | 登録された会議を確認する |
| 2 | 検索 | 条件に合致する会議を検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 閲覧権限 | 会議内容は参加者および関係者のみ閲覧可能 |
