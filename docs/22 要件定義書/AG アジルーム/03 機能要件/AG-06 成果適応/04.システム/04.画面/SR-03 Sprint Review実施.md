# Sprint Review実施

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SR-03 |
| 画面名           | Sprint Review実施 |
| 説明             | 成果デモ、フィードバック、議論内容を記録する |
| 関連ユースケース | UC-SR-005, UC-SR-006, UC-SR-007, UC-SR-012 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint情報、Review状態、終了ボタン |
| 成果確認セクション | Sprint Goalと達成状況、完了・未完了Storyを表示 |
| デモセクション | インクリメントのデモ結果を表示 |
| フィードバックセクション | 収集されたフィードバックを表示 |
| 議論セクション | Review中の議論内容を記録・表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | Sprint名 | String | 必須 | 対象Sprintの名前 |
| 2    | Sprint Goal | String | 必須 | Sprintの目標 |
| 3    | 達成状況 | String | 必須 | Sprint Goalの達成状況 |
| 4    | 完了Story | String | 必須 | 完了したStoryの一覧 |
| 5    | 未完了Story | String | 任意 | 未完了のStoryの一覧 |
| 6    | デモ対象 | String | 必須 | デモ対象となるインクリメント |
| 7    | デモ結果 | String | 任意 | デモの実施結果 |
| 8    | フィードバック | String | 必須 | 収集されたフィードバック |
| 9    | 発言者 | String | 必須 | フィードバックの発言者 |
| 10   | 議論内容 | String | 任意 | Review中の議論内容 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | デモ実行 | インクリメントのデモを実行する |
| 2    | フィードバック記録 | フィードバックを記録する |
| 3    | 議論記録 | 議論内容を記録する |
| 4    | 決定事項記録 | 決定事項を記録する |
| 5    | Review終了 | Sprint Reviewを終了する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | フィードバックの記録義務 | 収集したフィードバックは必ず記録する必要がある |
| 2    | 発言者の必須入力 | フィードバックには発言者を必ず記録する必要がある |
| 3    | Review状態の遷移 | Review状態は開催中→完了の順に遷移する |
