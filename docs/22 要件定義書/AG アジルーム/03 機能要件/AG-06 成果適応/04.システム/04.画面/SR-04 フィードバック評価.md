# フィードバック評価

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SR-04 |
| 画面名           | フィードバック評価 |
| 説明             | フィードバックを分類・評価し、対応方針を決める |
| 関連ユースケース | UC-SR-008, UC-SR-009, UC-SR-010, UC-SR-011 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 検索バー、フィルター、保存ボタン |
| フィードバック一覧セクション | 収集されたフィードバックの一覧を表示 |
| 分類セクション | フィードバックの分類結果を表示 |
| 対応方針セクション | 対応方針と判断理由を表示 |
| バックログ候補セクション | フィードバックから作成されたバックログ候補を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | フィードバック内容 | String | 必須 | フィードバックの内容 |
| 2    | 発言者 | String | 必須 | フィードバックの発言者 |
| 3    | 分類 | Enum | 必須 | 新機能要望、既存機能改善、不具合等 |
| 4    | 対応方針 | Enum | 必須 | バックログに追加、既存Storyを変更、調査する等 |
| 5    | 判断理由 | String | 必須 | 対応方針の判断理由 |
| 6    | 判断者 | String | 必須 | 対応方針を決定した人物 |
| 7    | バックログ候補 | String | 任意 | フィードバックから作成されたバックログ候補 |
| 8    | 関連Story | String | 任意 | 関連するStory |
| 9    | 添付資料 | File | 任意 | 添付された資料 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 分類変更 | フィードバックの分類を変更する |
| 2    | 対応方針決定 | 対応方針を決定する |
| 3    | バックログ候補作成 | フィードバックからバックログ候補を作成する |
| 4    | 既存Story更新 | 既存のStoryを更新する |
| 5    | 保存 | 評価結果を保存する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 分類の必須入力 | フィードバックには分類を必ず設定する必要がある |
| 2    | 対応方針の必須入力 | フィードバックには対応方針を必ず決定する必要がある |
| 3    | 判断理由の必須入力 | 対応方針には判断理由を必ず記録する必要がある |
