# Sprint Review準備

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SR-02 |
| 画面名           | Sprint Review準備 |
| 説明             | 成果、Sprint Goal、デモ対象、参加者、議題を準備する |
| 関連ユースケース | UC-SR-002, UC-SR-003, UC-SR-004 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint情報、準備状態、保存ボタン |
| Sprint Goalセクション | Sprint Goalと達成状況を表示 |
| デモ対象セクション | デモ対象となるインクリメントを表示 |
| 参加者セクション | 参加者の一覧と役割を表示 |
| 議題セクション | 議題の一覧と順序を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | Sprint名 | String | 必須 | 対象Sprintの名前 |
| 2    | Sprint Goal | String | 必須 | Sprintの目標 |
| 3    | 達成状況 | String | 必須 | Sprint Goalの達成状況 |
| 4    | デモ対象 | String | 必須 | デモ対象となるインクリメント |
| 5    | 参加者 | String | 必須 | 参加者の一覧 |
| 6    | 役割 | String | 必須 | 参加者の役割 |
| 7    | 議題 | String | 必須 | 議題の内容 |
| 8    | 順序 | Integer | 必須 | 議題の順序 |
| 9    | 準備状態 | Enum | 必須 | 未準備、準備中、準備完了 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 参加者追加 | 参加者を追加する |
| 2    | 議題追加 | 議題を追加する |
| 3    | 順序変更 | 議題の順序を変更する |
| 4    | 保存 | 準備内容を保存する |
| 5    | 準備完了 | 準備を完了状態に変更する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 参加者の必須入力 | 参加者を必ず設定する必要がある |
| 2    | 議題の必須入力 | 議題を必ず設定する必要がある |
| 3    | 準備状態の遷移 | 準備状態は未準備→準備中→準備完了の順に遷移する |
