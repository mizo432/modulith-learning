# 画面属性一覧

Sprint Review一覧の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SR-01 |
| 画面名 | Sprint Review一覧 |
| 説明 | 過去・現在のSprint Reviewの開催状況と結果を確認する |
| 関連ユースケース | UC-SR-014 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Sprint名 | 表示 | String | はい | - | - | Sprintの名前 |
| 2 | 開催日時 | 表示 | DateTime | はい | - | - | Sprint Reviewの開催日時 |
| 3 | 状態 | 表示 | Enum | はい | - | - | Sprint Reviewの状態（準備中、実施中、完了） |
| 4 | 成果概要 | 表示 | String | いいえ | - | - | Sprintで達成した成果の概要 |
| 5 | フィードバック数 | 表示 | Integer | いいえ | - | - | 収集したフィードバックの数 |
| 6 | 決定事項数 | 表示 | Integer | いいえ | - | - | 記録された決定事項の数 |
| 7 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 8 | 状態フィルター | 選択 | Enum | いいえ | - | - | 状態でのフィルター |
| 9 | 日付範囲 | 入力 | Date | いいえ | - | - | 日付範囲でのフィルター |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | 画面タイトルを表示 | - |
| 2 | 検索・フィルター | 検索とフィルター | 検索キーワード、状態フィルター、日付範囲 |
| 3 | リスト | Sprint Reviewの一覧を表示 | Sprint名、開催日時、状態、成果概要、フィードバック数、決定事項数 |

## 画面操作

画面で実行可能な操作を定義します。

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | Sprint Review結果を確認 | リンククリック | Sprint Reviewの詳細結果を確認する | SR-05 |
| 2 | 検索 | ボタンクリック | 条件に合致するSprint Reviewを検索する | - |
| 3 | フィルター | ボタンクリック | 条件でフィルターする | - |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 参照権限 | 全項目 | Sprint Reviewを参照する権限が必要 | 権限チェック |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 検索キーワードの文字数 | 検索キーワード | 文字数 <= 100 | 検索キーワードは100文字以内で入力してください |
