# 画面属性一覧

改善アクション管理の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-024 |
| 画面名 | 改善アクション管理 |
| 説明 | 改善アクションの担当、期限、状態、効果確認を管理する |
| 関連ユースケース | UC-LR-005, UC-LR-006, UC-LR-007, UC-LR-008 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | アクション名 | 入力 | String | はい | - | 最大255文字 | 改善アクション名 |
| 2 | 担当 | 入力 | String | はい | - | 最大255文字 | 担当者名 |
| 3 | 期限 | 入力 | Date | はい | - | - | 完了期限 |
| 4 | 状態 | 表示 | Enum | はい | - | 未着手/実行中/完了/効果確認中 | 進捗状態 |
| 5 | 効果 | 入力 | String | いいえ | - | 最大1000文字 | 改善効果 |
| 6 | 関連Retrospective | リンク | String | いいえ | - | - | 関連する振り返り |
| 7 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 8 | 状態フィルター | 選択 | Enum | いいえ | すべて | - | 状態で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | アクション総数、状態別集計を表示 | アクション名 |
| 2 | 検索・フィルター | 検索・絞り込み | 検索キーワード、状態フィルター |
| 3 | メインコンテンツ | 改善アクション一覧を表示・編集 | アクション名、担当、期限、状態、効果、関連Retrospective |

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | 改善アクションを登録 | ボタンクリック | 新しいアクションを登録する | SCR-024 |

| 5 | 検索 | ボタンクリック | 条件に合致するアクションを検索する | - |

## 制約事項

画面項目の制約条件を定義します。

|------|--------|----------|----------|------|

| 1 | アクション名の文字数 | アクション名 | 文字数 <= 255 | アクション名は255文字以内で入力してください |
