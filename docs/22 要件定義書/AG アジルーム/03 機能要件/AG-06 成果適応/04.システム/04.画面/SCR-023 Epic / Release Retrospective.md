# Epic / Release Retrospective

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-023 |
| 画面名           | Epic / Release Retrospective |
| 説明             | Epic・Releaseの計画対実績、品質、変更、学びを振り返る |
| 関連ユースケース | UC-LR-019 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Epic/Release情報、期間、関係者情報 |
| 計画対実績セクション | 計画と実績の比較を表示 |
| 品質セクション | 品質指標の推移を表示 |
| 変更セクション | 変更履歴を表示 |
| 学びセクション | 得られた学びを記録・表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | Epic/Release名 | String | 必須 | 対象Epic/Releaseの名前 |
| 2    | 期間 | Date | 必須 | Epic/Releaseの期間 |
| 3    | 計画内容 | String | 必須 | 計画した内容 |
| 4    | 実績内容 | String | 必須 | 実際の実績 |
| 5    | 品質指標 | Double | 必須 | 品質指標の数値 |
| 6    | 変更履歴 | String | 任意 | 変更の履歴 |
| 7    | 学び | String | 任意 | 得られた学び |
| 8    | 投稿者 | String | 必須 | 学びを投稿したユーザー |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 学び投稿 | 新たな学びを投稿する |
| 2    | 保存 | Retrospectiveの結果を保存する |
| 3    | エクスポート | 結果をエクスポートする |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 参加者の制限 | PO、チーム、関係者のみが参加できる |
| 2    | 計画対実績の必須入力 | 計画と実績は必ず入力する必要がある |
| 3    | 品質指標の正確性 | 品質指標は正確に記録する必要がある |
