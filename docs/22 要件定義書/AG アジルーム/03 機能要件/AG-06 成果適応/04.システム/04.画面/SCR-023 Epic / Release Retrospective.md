# Epic / Release Retrospective

Epic / Release Retrospective画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-023 |
| 画面名           | Epic / Release Retrospective |
| 説明             | Epic・Releaseの計画対実績、品質、変更、学びを振り返る |
| 関連ユースケース | UC-LR-019 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Epic/Release名、期間、参加者を表示 |
| ナビゲーション | 計画対実績、品質、変更、学びのタブ切り替え |
| メインコンテンツ | 選択したタブに対応する振り返り情報を表示・編集 |
| サイドバー | 関連Sprint、改善アクションを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 種類 | 選択 | はい | 種類（Epic、Release） |
| 2 | 名前 | 文字列 | はい | EpicまたはReleaseの名前 |
| 3 | 実施日 | 日付 | はい | Retrospectiveの実施日 |
| 4 | 参加者 | 複数選択 | はい | 参加したメンバー |
| 5 | 計画 | テキスト | いいえ | 当初の計画 |
| 6 | 実績 | テキスト | いいえ | 実際の実績 |
| 7 | 品質 | テキスト | いいえ | 品質の振り返り |
| 8 | 変更 | テキスト | いいえ | 発生した変更 |
| 9 | 学び | テキスト | いいえ | 得られた学び |
| 10 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Epic／Releaseを振り返る | 計画対実績や学びを振り返る |
| 2 | 振り返りを参照 | 過去の振り返り内容を確認する |
| 3 | 検索 | 条件に合致する振り返りを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 振り返りの記録はプロダクトオーナーとチームのみ可能 |
