# 画面属性一覧

Epic / Release Retrospectiveの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-023 |
| 画面名 | Epic / Release Retrospective |
| 説明 | Epic・Releaseの計画対実績、品質、変更、学びを振り返る |
| 関連ユースケース | UC-LR-019 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Epic/Release名 | 表示 | String | はい | - | - | 振り返り対象のEpicまたはRelease名 |
| 2 | 計画期間 | 表示 | Date | はい | - | - | 計画された期間 |
| 3 | 実績期間 | 表示 | Date | いいえ | - | - | 実際の期間 |
| 4 | 計画対実績 | 表示 | String | いいえ | - | - | 計画と実績の比較 |
| 5 | 品質指標 | 表示 | Double | いいえ | - | - | 品質の測定値 |
| 6 | 変更事項 | 入力 | String | いいえ | - | 最大2000文字 | 発生した変更事項 |
| 7 | 学び | 入力 | String | はい | - | 最大2000文字 | 得られた学び |
| 8 | 改善候補 | 入力 | String | いいえ | - | 最大1000文字 | 改善の候補 |
| 9 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | Epic/Release名、期間を表示 | Epic/Release名、計画期間、実績期間 |
| 2 | 検索・フィルター | 検索 | 検索キーワード |
| 3 | 計画対実績 | 計画と実績の比較を表示 | 計画対実績、品質指標 |
| 4 | メインコンテンツ | 振り返り内容を表示・編集 | 変更事項、学び、改善候補 |

## 画面操作

画面で実行可能な操作を定義します。

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | Epic/Releaseを振り返る | ボタンクリック | 複数スプリントにまたがる成果と学びを振り返る | SCR-023 |
| 2 | 検索 | ボタンクリック | 条件に合致する振り返りを検索する | - |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 編集権限 | 全項目 | 振り返りの編集はPO、チームのみ可能 | 権限チェック |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 学びの文字数 | 学び | 文字数 <= 2000 | 学びは2000文字以内で入力してください |
| 2 | 変更事項の文字数 | 変更事項 | 文字数 <= 2000 | 変更事項は2000文字以内で入力してください |
| 3 | 検索キーワードの文字数 | 検索キーワード | 文字数 <= 100 | 検索キーワードは100文字以内で入力してください |
