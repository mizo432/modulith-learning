# Epic / Release Retrospective

Epic / Release Retrospective画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-023 |
| 画面名           | Epic / Release Retrospective |
| 説明             | Epic・Releaseの計画対実績、品質、変更、学びを振り返る |
| 関連ユースケース | UC-LR-019 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Epic/Release名、期間を表示 |
| ナビゲーション | 計画対実績、品質、変更、学びの切り替え |
| メインコンテンツ | 振り返り内容を表示・編集 |
| サイドバー | 関連Sprint一覧を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Epic/Release名 | 文字列 | はい | 振り返り対象のEpicまたはRelease名 |
| 2 | 計画期間 | 日付 | はい | 計画された期間 |
| 3 | 実績期間 | 日付 | いいえ | 実際の期間 |
| 4 | 計画対実績 | 文字列 | いいえ | 計画と実績の比較 |
| 5 | 品質指標 | 数値 | いいえ | 品質の測定値 |
| 6 | 変更事項 | テキスト | いいえ | 発生した変更事項 |
| 7 | 学び | テキスト | はい | 得られた学び |
| 8 | 改善候補 | テキスト | いいえ | 改善の候補 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Epic/Releaseを振り返る | 複数スプリントにまたがる成果と学びを振り返る |
| 2 | 検索 | 条件に合致する振り返りを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 振り返りの編集はPO、チームのみ可能 |
| 2 | 参照権限 | 振り返りの参照はPO、チーム、関係者 |
