# 画面属性一覧

フィードバック評価の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SR-04 |
| 画面名 | フィードバック評価 |
| 説明 | フィードバックを分類・評価し、対応方針を決める |
| 関連ユースケース | UC-SR-008, UC-SR-009 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | フィードバックID | 表示 | String | はい | - | - | フィードバックの識別子 |
| 2 | フィードバック内容 | 表示 | String | はい | - | - | フィードバックの内容 |
| 3 | 提出者 | 表示 | String | はい | - | - | フィードバックを提出した人 |
| 4 | 分類 | 選択 | Enum | はい | - | - | フィードバックの分類（機能、品質、UX等） |
| 5 | 優先度 | 選択 | Enum | はい | - | - | 優先度（高、中、低） |
| 6 | 評価 | 入力 | String | いいえ | - | 最大1000文字 | フィードバックへの評価 |
| 7 | 対応方針 | 選択 | Enum | はい | - | - | 対応方針（対応、延期、見送り） |
| 8 | 判断理由 | 入力 | String | いいえ | - | 最大1000文字 | 対応方針の判断理由 |
| 9 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 10 | 分類フィルター | 選択 | Enum | いいえ | - | - | 分類でのフィルター |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | 画面タイトルを表示 | - |
| 2 | 検索・フィルター | 検索とフィルター | 検索キーワード、分類フィルター |
| 3 | フィードバック一覧 | フィードバックの一覧を表示 | フィードバックID、フィードバック内容、提出者 |
| 4 | 評価エリア | 分類・評価・対応方針を入力 | 分類、優先度、評価、対応方針、判断理由 |
