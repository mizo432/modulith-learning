# 画面属性一覧

Sprint Review結果の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SR-05 |
| 画面名 | Sprint Review結果 |
| 説明 | 決定事項、バックログ候補、未完了項目、結果を確認する |
| 関連ユースケース | UC-SR-014 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Sprint名 | 表示 | String | はい | - | - | 対象Sprintの名前 |
| 2 | 開催日時 | 表示 | DateTime | はい | - | - | Sprint Reviewの開催日時 |
| 3 | 決定事項 | 表示 | String | いいえ | - | - | 記録された決定事項 |
| 4 | バックログ候補 | リンク | String | いいえ | - | - | 作成されたバックログ候補 |
| 5 | 未完了項目 | 表示 | String | いいえ | - | - | 未完了の項目 |
| 6 | フィードバック一覧 | リンク | String | いいえ | - | - | 収集したフィードバック一覧 |
| 7 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
