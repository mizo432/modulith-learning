# Sprint Review一覧

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SR-01 |
| 画面名           | Sprint Review一覧 |
| 説明             | 過去・現在のSprint Reviewの開催状況と結果を確認する |
| 関連ユースケース | UC-SR-001, UC-SR-014 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 検索バー、フィルター、新規Review開始ボタン |
| Review一覧セクション | Sprint Reviewの一覧を表示（Sprint、日時、状態） |
| 結果概要セクション | 選択したReviewの結果概要を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | Sprint名 | String | 必須 | 対象Sprintの名前 |
| 2    | 開催日時 | DateTime | 必須 | Reviewの開催日時 |
| 3    | 状態 | Enum | 必須 | 未準備、準備中、準備完了、開催中、完了 |
| 4    | Sprint Goal | String | 必須 | Sprintの目標 |
| 5    | 完了Story数 | Integer | 必須 | 完了したStoryの数 |
| 6    | 未完了Story数 | Integer | 必須 | 未完了のStoryの数 |
| 7    | フィードバック数 | Integer | 必須 | 収集されたフィードバックの数 |
| 8    | 決定事項数 | Integer | 必須 | 記録された決定事項の数 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 新規Review開始 | 新たなSprint Reviewを開始する |
| 2    | Review詳細表示 | 選択したReviewの詳細を表示する |
| 3    | フィルター | 状態や期間でフィルターする |
| 4    | 検索 | Sprint名で検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 状態の表示 | 各Reviewの状態は正確に表示する必要がある |
| 2    | アクセス権限 | 権限のないReviewは表示しない |
| 3    | データのリアルタイム性 | Reviewの状態はリアルタイムに更新される |
