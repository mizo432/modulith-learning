# プロジェクト設定・権限

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-028 |
| 画面名           | プロジェクト設定・権限 |
| 説明             | プロジェクト設定、アクセス権、ワークフロー等を管理する |
| 関連ユースケース | - |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロジェクト名、設定カテゴリ選択 |
| 基本設定セクション | プロジェクトの基本情報（名前、説明、期間等）を表示 |
| アクセス権セクション | ユーザー・ロールのアクセス権限を管理 |
| ワークフローセクション | ワークフローの設定を管理 |
| 通知設定セクション | 通知の設定を管理 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | プロジェクト名 | String | 必須 | プロジェクトの名前 |
| 2    | 説明 | String | 任意 | プロジェクトの説明 |
| 3    | 開始日 | Date | 必須 | プロジェクトの開始日 |
| 4    | 終了日 | Date | 任意 | プロジェクトの終了日 |
| 5    | ユーザー | String | 必須 | アクセス権を設定するユーザー |
| 6    | ロール | String | 必須 | ユーザーのロール |
| 7    | 権限 | Enum | 必須 | 閲覧、編集、管理 |
| 8    | ワークフロー名 | String | 必須 | ワークフローの名前 |
| 9    | 通知種類 | Enum | 必須 | メール、プッシュ、システム |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 設定保存 | 設定を保存する |
| 2    | 権限追加 | アクセス権限を追加する |
| 3    | 権限削除 | アクセス権限を削除する |
| 4    | ワークフロー追加 | ワークフローを追加する |
| 5    | 通知設定変更 | 通知設定を変更する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 管理者権限 | プロジェクト設定は管理者のみが行える |
| 2    | 権限の必須入力 | アクセス権限を設定する際には権限を必ず指定する必要がある |
| 3    | ワークフローの整合性 | ワークフローの設定は整合性がある必要がある |
