# プロジェクト設定・権限

プロジェクト設定・権限画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-028 |
| 画面名           | プロジェクト設定・権限 |
| 説明             | プロジェクト設定、アクセス権、ワークフロー等を管理する |
| 関連ユースケース | (なし) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロジェクト名、最終更新日を表示 |
| ナビゲーション | 基本設定、アクセス権、ワークフローのタブ切り替え |
| メインコンテンツ | 選択したタブに対応する設定を表示・編集 |
| サイドバー | 変更履歴を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | プロジェクト名 | 文字列 | はい | プロジェクトの名前 |
| 2 | 説明 | テキスト | いいえ | プロジェクトの説明 |
| 3 | アクセス権 | 選択 | はい | アクセス権レベル（管理者、編集者、閲覧者） |
| 4 | ワークフロー | テキスト | いいえ | 定義されたワークフロー |
| 5 | 通知設定 | 選択 | いいえ | 通知の設定 |
| 6 | 変更履歴 | テキスト | いいえ | 設定の変更履歴 |
| 7 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 設定を参照 | 現在の設定を確認する |
| 2 | アクセス権を設定 | ユーザーのアクセス権を設定する |
| 3 | ワークフローを設定 | ワークフローを定義する |
| 4 | 変更履歴を参照 | 設定の変更履歴を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | プロジェクト設定の編集は管理者のみ可能 |
| 2 | 監査ログ | 設定変更は監査ログに記録される |
