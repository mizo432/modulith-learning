# プロジェクトダッシュボード

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-001 |
| 画面名           | プロジェクトダッシュボード |
| 説明             | プロジェクト状況、注意事項、次の意思決定を把握する |
| 関連ユースケース | UC-LR-009, UC-LR-010, UC-LR-011, UC-LR-012 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロジェクト名、現在のSprint情報、ユーザー情報 |
| 概要カード | 目標、作業、障害、判断待ちの概要を表示 |
| 進捗セクション | プロジェクトの進捗状況、マイルストーン、成果を表示 |
| リスクセクション | 期限、影響、担当、次の対応が必要なリスクを表示 |
| 判断待ちセクション | 判断が必要な事項の期限・影響・担当を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | プロジェクト名 | String | 必須 | 現在選択されているプロジェクトの名前 |
| 2    | Sprint情報 | String | 必須 | 現在のSprintの期間とGoal |
| 3    | 目標数 | Integer | 必須 | 現在の目標の数 |
| 4    | 作業数 | Integer | 必須 | 現在の作業の数 |
| 5    | 障害数 | Integer | 必須 | 現在の障害の数 |
| 6    | 判断待ち数 | Integer | 必須 | 現在の判断待ちの数 |
| 7    | 進捗率 | Double | 必須 | プロジェクトの進捗率（パーセント） |
| 8    | リスク一覧 | List | 任意 | リスクの一覧（期限、影響、担当） |
| 9    | 判断待ち一覧 | List | 任意 | 判断待ち事項の一覧（期限、影響、担当） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | プロジェクト切替 | 表示するプロジェクトを切替える |
| 2    | リスク詳細表示 | 選択したリスクの詳細を表示する |
| 3    | 判断待ち詳細表示 | 選択した判断待ち事項の詳細を表示する |
| 4    | 更新 | ダッシュボードのデータを更新する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | ロールベース表示 | ユーザーのロールに応じた情報のみを表示する |
| 2    | データのリアルタイム性 | ダッシュボードのデータはリアルタイムに更新される |
| 3    | アクセス権限 | 権限のない情報は表示しない |
