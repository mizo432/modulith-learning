# プロジェクトダッシュボード

プロジェクトダッシュボード画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-001 |
| 画面名           | プロジェクトダッシュボード |
| 説明             | ロールに応じた目標、作業、障害、判断待ちを表示する |
| 関連ユースケース | UC-LR-009, UC-LR-010, UC-LR-011, UC-LR-012 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロジェクト名、期間、ステータスを表示 |
| ナビゲーション | ダッシュボード、進捗、リスク、判断待ちの切り替え |
| メインコンテンツ | ロールに応じた目標、作業、障害、判断待ちを表示 |
| サイドバー | プロジェクト概要、チームメンバーを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | プロジェクト名 | 文字列 | はい | プロジェクトの名前 |
| 2 | 期間 | 日付 | はい | プロジェクトの期間 |
| 3 | ステータス | 選択 | はい | プロジェクトのステータス |
| 4 | 目標 | 文字列 | はい | プロジェクトの目標 |
| 5 | 作業 | 文字列 | いいえ | 現在の作業 |
| 6 | 障害 | 文字列 | いいえ | 発生している障害 |
| 7 | 判断待ち | 文字列 | いいえ | 判断が必要な事項 |
| 8 | リスク | 文字列 | いいえ | 識別されたリスク |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ダッシュボードを表示 | ロールに応じたダッシュボードを表示する |
| 2 | 進捗を確認 | プロジェクトの進捗状況を確認する |
| 3 | リスク一覧を確認 | 期限、影響、担当、次の対応が必要な事項を示す |
| 4 | 判断待ち一覧を確認 | 判断が必要な事項の期限・影響・担当を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 参照権限 | ダッシュボードの参照はプロジェクトメンバーのみ可能 |
| 2 | ロールベース表示 | 表示内容はユーザーのロールに応じて変化する |
