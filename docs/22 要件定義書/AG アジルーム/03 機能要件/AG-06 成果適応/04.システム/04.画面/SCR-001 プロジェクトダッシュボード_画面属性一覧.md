# 画面属性一覧

プロジェクトダッシュボードの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-001 |
| 画面名 | プロジェクトダッシュボード |
| 説明 | プロジェクト状況、注意事項、次の意思決定を把握する |
| 関連ユースケース | UC-LR-009, UC-LR-010, UC-LR-011, UC-LR-012 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | プロジェクト名 | 表示 | String | はい | - | - | プロジェクト名 |
| 2 | 進捗 | 表示 | Double | はい | - | 0-100 | 進捗率 |
| 3 | マイルストーン | 表示 | String | いいえ | - | 最大500文字 | 中間目標 |
| 4 | リスク | リンク | String | いいえ | - | - | 関連するリスク |
| 5 | 判断待ち | リンク | String | いいえ | - | - | 判断が必要な事項 |
| 6 | 役割 | 表示 | Enum | はい | - | PO/SM/開発者/テスト担当/トラッキング担当/管理者 | ユーザーの役割 |
| 7 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | プロジェクト名、役割を表示 | プロジェクト名、役割 |
| 2 | 検索・フィルター | 検索 | 検索キーワード |
| 3 | メインコンテンツ | ダッシュボードを表示 | 進捗、マイルストーン、リスク、判断待ち |
| 4 | サイドバー | 注意事項、次の意思決定を表示 | リスク、判断待ち |
