# Sprint Review記録

Sprint Review記録画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-017 |
| 画面名           | Sprint Review記録 |
| 説明             | 成果、フィードバック、決定、未解決事項を記録する |
| 関連ユースケース | UC-LR-001, UC-LR-002, UC-LR-013, UC-LR-014, UC-LR-015 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint名、期間、ステータスを表示 |
| ナビゲーション | Sprint Review記録、利用者レビューの切り替え |
| メインコンテンツ | 成果、フィードバック、決定事項、未解決事項を表示 |
| サイドバー | 参加者一覧、タイムラインを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Sprint名 | 文字列 | はい | Review対象のSprint名 |
| 2 | 期間 | 日付 | はい | Sprintの期間 |
| 3 | 成果 | テキスト | はい | Sprintで達成した成果 |
| 4 | フィードバック | テキスト | はい | ステークホルダーからのフィードバック |
| 5 | 決定事項 | テキスト | いいえ | 会議で決定された事項 |
| 6 | 未解決事項 | テキスト | いいえ | 未解決の課題や懸念事項 |
| 7 | 参加者 | 文字列 | はい | 参加したメンバー |
| 8 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Sprint Reviewを記録 | Sprint Reviewの内容を記録する |
| 2 | Sprint Reviewを参照 | 過去のSprint Reviewの内容を確認する |
| 3 | 利用者レビューを計画 | 利用者レビューの計画を行う |
| 4 | 利用者レビューを実行 | 計画された利用者レビューを実行する |
| 5 | 利用者レビュー結果を参照 | 利用者レビューの結果を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Sprint Reviewの記録はScrum Teamのみ可能 |
| 2 | 必須項目 | 成果、フィードバックは必須入力 |
