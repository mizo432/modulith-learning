# 改善アクション管理

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-024 |
| 画面名           | 改善アクション管理 |
| 説明             | 改善アクションの担当、期限、状態、効果確認を管理する |
| 関連ユースケース | UC-LR-005, UC-LR-006, UC-LR-007, UC-LR-008 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 検索バー、フィルター、新規登録ボタン |
| アクション一覧セクション | 改善アクションの一覧を表示（担当、期限、状態） |
| 詳細セクション | 選択した改善アクションの詳細を表示 |
| 効果確認セクション | 改善効果の確認結果を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | アクション名 | String | 必須 | 改善アクションの名前 |
| 2    | 担当者 | String | 必須 | 改善アクションの担当者 |
| 3    | 期限 | Date | 必須 | 改善アクションの期限 |
| 4    | 状態 | Enum | 必須 | 未着手、実行中、完了、効果確認中 |
| 5    | 内容 | String | 必須 | 改善アクションの内容 |
| 6    | 効果 | String | 任意 | 改善効果の確認結果 |
| 7    | 関連Retrospective | String | 任意 | 関連するRetrospective |
| 8    | 作成日時 | DateTime | 必須 | 作成日時 |
| 9    | 更新日時 | DateTime | 必須 | 最終更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 新規登録 | 新たな改善アクションを登録する |
| 2    | 編集 | 選択した改善アクションを編集する |
| 3    | 削除 | 選択した改善アクションを削除する |
| 4    | 状態変更 | 改善アクションの状態を変更する |
| 5    | 効果確認 | 改善効果を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 担当者の必須入力 | 改善アクションには担当者を必ず割り当てる必要がある |
| 2    | 期限の必須入力 | 改善アクションには期限を設定する必要がある |
| 3    | 状態遷移の制約 | 状態は未着手→実行中→完了→効果確認中の順に遷移する |
