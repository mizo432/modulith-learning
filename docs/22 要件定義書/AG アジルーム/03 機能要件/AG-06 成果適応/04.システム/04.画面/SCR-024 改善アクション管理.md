# 改善アクション管理

改善アクション管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-024 |
| 画面名           | 改善アクション管理 |
| 説明             | 改善アクションの担当、期限、状態、効果確認を管理する |
| 関連ユースケース | UC-LR-005, UC-LR-006, UC-LR-007, UC-LR-008 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロジェクト名、アクション総数、未完了数を表示 |
| 検索・フィルター | 状態、担当で検索・絞り込み |
| メインコンテンツ | 改善アクション一覧表または詳細情報を表示 |
| サイドバー | 状態別集計、効果確認結果を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | アクション名 | 文字列 | はい | 改善アクションの名前 |
| 2 | 内容 | テキスト | はい | 改善の詳細内容 |
| 3 | 担当者 | 選択 | はい | 担当メンバー |
| 4 | 期限 | 日付 | はい | 完了期限 |
| 5 | 状態 | 選択 | はい | 状態（未着手、進行中、完了） |
| 6 | 効果確認 | テキスト | いいえ | 改善施策の効果 |
| 7 | 関連Retrospective | 選択 | いいえ | 関連するRetrospective |
| 8 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 改善アクションを登録 | 新規の改善アクションを登録する |
| 2 | 改善アクションを更新 | アクションの担当・期限・状態を修正する |
| 3 | 改善アクションを参照 | 登録されたアクションを確認する |
| 4 | 改善効果を確認 | 改善施策が与えた影響を確認する |
| 5 | 検索 | 条件に合致するアクションを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 改善アクションの編集はチームとスクラムマスターのみ可能 |
| 2 | 期限の整合性 | 期限は現在日以降でなければならない |
