# 改善アクション管理

改善アクション管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-024 |
| 画面名           | 改善アクション管理 |
| 説明             | 改善アクションの担当、期限、状態、効果確認を管理する |
| 関連ユースケース | UC-LR-005, UC-LR-006, UC-LR-007, UC-LR-008 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 画面タイトル、検索バーを表示 |
| ナビゲーション | アクション一覧、効果確認の切り替え |
| メインコンテンツ | 改善アクションの一覧・詳細を表示・編集 |
| サイドバー | フィルター、ステータス集計を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | アクション名 | 文字列 | はい | 改善アクションの名前 |
| 2 | 担当者 | 文字列 | はい | 改善アクションの担当者 |
| 3 | 期限 | 日付 | はい | 改善アクションの期限 |
| 4 | 状態 | 選択 | はい | 改善アクションの状態（未着手、進行中、完了） |
| 5 | 優先度 | 選択 | はい | 優先度（高、中、低） |
| 6 | 内容 | テキスト | はい | 改善アクションの内容 |
| 7 | 効果 | テキスト | いいえ | 改善効果の記録 |
| 8 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 改善アクションを登録 | 改善の担当、期限、状態を定義して登録する |
| 2 | 改善アクションを更新 | 改善アクションの担当・期限・状態を修正する |
| 3 | 改善アクションを参照 | 登録された改善アクションの一覧・詳細を確認する |
| 4 | 改善効果を確認 | 改善施策が品質、協働、価値提供に与えた影響を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 改善アクションの編集は担当者とSMのみ可能 |
| 2 | 状態遷移制限 | 状態の遷移はルールに従う必要がある |
