# 画面属性一覧

Sprint Retrospectiveの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-022 |
| 画面名 | Sprint Retrospective |
| 説明 | Keep/Problem/Try等で改善案を出し、投票・アクション化する |
| 関連ユースケース | UC-LR-003, UC-LR-004 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Sprint名 | 表示 | String | はい | - | - | Retrospective対象のSprint名 |
| 2 | 学び | 入力 | String | はい | - | 最大2000文字 | 得られた学び |
| 3 | 改善候補 | 入力 | String | いいえ | - | 最大1000文字 | 改善の候補 |
| 4 | 決定事項 | 入力 | String | いいえ | - | 最大1000文字 | 決定された事項 |
| 5 | 改善アクション | リンク | String | いいえ | - | - | 関連する改善アクション |
| 6 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | Sprint名、Retrospective日付を表示 | Sprint名 |
| 2 | 検索・フィルター | 検索 | 検索キーワード |
| 3 | メインコンテンツ | Retrospective記録を表示・編集 | 学び、改善候補、決定事項、改善アクション |

## 画面操作

画面で実行可能な操作を定義します。

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | Sprint Retrospectiveを記録 | ボタンクリック | Retrospectiveを記録する | SCR-022 |
| 2 | Sprint Retrospectiveを参照 | リンククリック | 過去のRetrospectiveを確認する | SCR-022詳細 |
| 3 | 検索 | ボタンクリック | 条件に合致するRetrospectiveを検索する | - |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 編集権限 | 全項目 | Retrospectiveの編集はチーム、SMのみ可能 | 権限チェック |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 学びの文字数 | 学び | 文字数 <= 2000 | 学びは2000文字以内で入力してください |
| 2 | 検索キーワードの文字数 | 検索キーワード | 文字数 <= 100 | 検索キーワードは100文字以内で入力してください |
