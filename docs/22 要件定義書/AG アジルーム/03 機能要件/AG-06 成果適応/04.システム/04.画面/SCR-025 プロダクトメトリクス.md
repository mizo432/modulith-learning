# プロダクトメトリクス

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-025 |
| 画面名           | プロダクトメトリクス |
| 説明             | 成果指標、利用状況、フロー指標、品質の推移を確認する |
| 関連ユースケース | UC-LR-016, UC-LR-017, UC-LR-018, UC-LR-020, UC-LR-021 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロジェクト名、期間選択、メトリクス種類選択 |
| 成果指標セクション | 成果指標の推移をグラフで表示 |
| 利用状況セクション | 利用状況の推移をグラフで表示 |
| フロー指標セクション | フロー指標（リードタイム、サイクルタイム等）を表示 |
| 品質セクション | 品質指標（テスト、欠陥、性能）を表示 |
| 稼働状況セクション | 監視・ログ基盤からの稼働状況・エラー・ログを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | プロジェクト名 | String | 必須 | 現在選択されているプロジェクトの名前 |
| 2    | 期間 | Date | 必須 | 表示する期間 |
| 3    | 成果指標 | Double | 必須 | 成果指標の数値 |
| 4    | 利用状況 | Double | 必須 | 利用状況の数値 |
| 5    | リードタイム | Integer | 必須 | リードタイム（日数） |
| 6    | サイクルタイム | Integer | 必須 | サイクルタイム（日数） |
| 7    | テスト結果 | String | 任意 | テストの結果 |
| 8    | 欠陥数 | Integer | 必須 | 欠陥の数 |
| 9    | 性能指標 | Double | 必須 | 性能指標の数値 |
| 10   | 稼働率 | Double | 必須 | 稼働率（パーセント） |
| 11   | エラー数 | Integer | 必須 | エラーの数 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 期間変更 | 表示する期間を変更する |
| 2    | メトリクス切替 | 表示するメトリクスを切替える |
| 3    | エクスポート | メトリクスデータをエクスポートする |
| 4    | 更新 | メトリクスデータを更新する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 外部システム連携 | ES-07（監視・ログ基盤）との連携が必須 |
| 2    | データの正確性 | メトリクスデータは正確に記録する必要がある |
| 3    | アクセス権限 | 権限のないメトリクスは表示しない |
