# 画面属性一覧

Sprint Review準備の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SR-02 |
| 画面名 | Sprint Review準備 |
| 説明 | 成果、Sprint Goal、デモ対象、参加者、議題を準備する |
| 関連ユースケース | UC-SR-002 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Sprint名 | 表示 | String | はい | - | - | 対象Sprintの名前 |
| 2 | Sprint Goal | 表示 | String | はい | - | - | Sprintの目標 |
| 3 | 成果 | 入力 | String | はい | - | 最大2000文字 | Sprintで達成した成果 |
| 4 | デモ対象 | 入力 | String | いいえ | - | 最大1000文字 | デモする対象 |
| 5 | 参加者 | リンク | String | いいえ | - | - | 参加者一覧 |
| 6 | 議題 | リンク | String | いいえ | - | - | 議題一覧 |
| 7 | 開催日時 | 入力 | DateTime | はい | - | - | Sprint Reviewの開催日時 |
| 8 | 備考 | 入力 | String | いいえ | - | 最大500文字 | 備考 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
