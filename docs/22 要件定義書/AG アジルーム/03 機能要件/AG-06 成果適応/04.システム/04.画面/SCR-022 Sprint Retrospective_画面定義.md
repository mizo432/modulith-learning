# Sprint Retrospective

Sprint Retrospective画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-022 |
| 画面名           | Sprint Retrospective |
| 説明             | Keep/Problem/Try等で改善案を出し、投票・アクション化する |
| 関連ユースケース | UC-LR-003, UC-LR-004 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint名、期間、ステータスを表示 |
| ナビゲーション | Keep、Problem、Tryの切り替え |
| メインコンテンツ | 改善案の投稿、投票、アクション化を表示 |
| サイドバー | 参加者一覧、タイムラインを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Sprint名 | 文字列 | はい | 振り返り対象のSprint名 |
| 2 | 期間 | 日付 | はい | Sprintの期間 |
| 3 | カテゴリ | 選択 | はい | Keep、Problem、Try |
| 4 | 改善案 | テキスト | はい | 改善案の内容 |
| 5 | 投稿者 | 文字列 | はい | 改善案を投稿した人 |
| 6 | 投票数 | 数値 | いいえ | 改善案への投票数 |
| 7 | アクション化 | 真偽値 | いいえ | アクション化したかどうか |
| 8 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 改善案を投稿 | Keep/Problem/Tryの改善案を投稿する |
| 2 | 投票を行う | 改善案に投票する |
| 3 | アクション化する | 改善案をアクション化する |
| 4 | 振り返りを参照 | 過去のRetrospectiveの内容を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 改善案の投稿はScrum Teamのみ可能 |
| 2 | 投票制限 | 1人あたりの投票数は制限される |
