# チーム・組織管理

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-027 |
| 画面名           | チーム・組織管理 |
| 説明             | 社内部門、パートナー企業、メンバー、役割を管理する |
| 関連ユースケース | - |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 検索バー、フィルター、新規登録ボタン |
| 組織セクション | 社内部門、パートナー企業の一覧を表示 |
| メンバーセクション | メンバーの一覧と役割を表示 |
| 役割セクション | 役割の一覧と詳細を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | 組織名 | String | 必須 | 組織の名前 |
| 2    | 組織種類 | Enum | 必須 | 社内部門、パートナー企業 |
| 3    | メンバー名 | String | 必須 | メンバーの名前 |
| 4    | 役割 | String | 必須 | メンバーの役割 |
| 5    | 所属組織 | String | 必須 | メンバーが所属する組織 |
| 6    | 状態 | Enum | 必須 | 有効、無効 |
| 7    | 作成日時 | DateTime | 必須 | 作成日時 |
| 8    | 更新日時 | DateTime | 必須 | 最終更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 新規組織作成 | 新たな組織を作成する |
| 2    | メンバー追加 | メンバーを追加する |
| 3    | 役割変更 | メンバーの役割を変更する |
| 4    | 編集 | 選択した項目を編集する |
| 5    | 削除 | 選択した項目を削除する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 管理者権限 | 組織・メンバーの管理は管理者のみが行える |
| 2    | 役割の必須入力 | メンバーには役割を必ず割り当てる必要がある |
| 3    | 所属組織の必須入力 | メンバーには所属組織を必ず設定する必要がある |
