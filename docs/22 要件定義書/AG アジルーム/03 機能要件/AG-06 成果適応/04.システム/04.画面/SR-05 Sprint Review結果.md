# Sprint Review結果

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SR-05 |
| 画面名           | Sprint Review結果 |
| 説明             | 決定事項、バックログ候補、未完了項目、結果を確認する |
| 関連ユースケース | UC-SR-013, UC-SR-014 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint情報、Review状態、エクスポートボタン |
| 決定事項セクション | 決定事項の一覧と詳細を表示 |
| バックログ候補セクション | フィードバックから作成されたバックログ候補を表示 |
| 未完了項目セクション | 未完了のStoryと継続確認事項を表示 |
| 結果概要セクション | Sprint Goal、完了・未完了Story、フィードバック概要を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | Sprint名 | String | 必須 | 対象Sprintの名前 |
| 2    | Sprint Goal | String | 必須 | Sprintの目標 |
| 3    | 達成状況 | String | 必須 | Sprint Goalの達成状況 |
| 4    | 完了Story数 | Integer | 必須 | 完了したStoryの数 |
| 5    | 未完了Story数 | Integer | 必須 | 未完了のStoryの数 |
| 6    | 決定事項 | String | 必須 | 決定事項の内容 |
| 7    | 決定理由 | String | 任意 | 決定事項の理由 |
| 8    | バックログ候補 | String | 任意 | フィードバックから作成されたバックログ候補 |
| 9    | 継続確認事項 | String | 任意 | 継続して確認が必要な事項 |
| 10   | フィードバック概要 | String | 必須 | フィードバックの概要 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | エクスポート | 結果をエクスポートする |
| 2    | 詳細表示 | 選択した項目の詳細を表示する |
| 3    | フィルター | 種類でフィルターする |
| 4    | 検索 | キーワードで検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 完了状態の確認 | Reviewが完了状態であることを確認する必要がある |
| 2    | アクセス権限 | 権限のない情報は表示しない |
| 3    | データの正確性 | 結果データは正確に表示する必要がある |
