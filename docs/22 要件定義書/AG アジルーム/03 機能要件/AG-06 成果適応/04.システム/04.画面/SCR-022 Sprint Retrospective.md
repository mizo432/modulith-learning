# Sprint Retrospective

画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-022 |
| 画面名           | Sprint Retrospective |
| 説明             | Keep/Problem/Try等で改善案を出し、投票・アクション化する |
| 関連ユースケース | UC-LR-003, UC-LR-004 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint情報、Retrospectiveのタイトル、参加者情報 |
| カテゴリセクション | Keep/Problem/Try等のカテゴリ別に改善案を表示 |
| 投票セクション | 改善案への投票結果を表示 |
| アクションセクション | 投票結果に基づいて作成された改善アクションを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1    | Sprint情報 | String | 必須 | 対象Sprintの期間とGoal |
| 2    | Retrospectiveタイトル | String | 必須 | Retrospectiveのタイトル |
| 3    | カテゴリ | Enum | 必須 | Keep, Problem, Try等のカテゴリ |
| 4    | 改善案 | String | 必須 | 改善案の内容 |
| 5    | 投稿者 | String | 必須 | 改善案を投稿したユーザー |
| 6    | 投票数 | Integer | 必須 | 改善案への投票数 |
| 7    | アクションアイテム | String | 任意 | 改善案から作成されたアクションアイテム |
| 8    | 担当者 | String | 任意 | アクションアイテムの担当者 |
| 9    | 期限 | Date | 任意 | アクションアイテムの期限 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1    | 改善案投稿 | 新たな改善案を投稿する |
| 2    | 投票 | 改善案に投票する |
| 3    | アクション化 | 改善案を改善アクションとして登録する |
| 4    | 保存 | Retrospectiveの結果を保存する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 参加者の制限 | Scrum Teamのみが参加できる |
| 2    | カテゴリの必須入力 | 改善案はカテゴリを指定して投稿する必要がある |
| 3    | 投票の重複防止 | 1人1案のみ投票できる |
