# Sprint Retrospective

Sprint Retrospective画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-022 |
| 画面名           | Sprint Retrospective |
| 説明             | Keep/Problem/Try等で改善案を出し、投票・アクション化する |
| 関連ユースケース | UC-LR-003, UC-LR-004 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint名、実施日、参加者を表示 |
| ナビゲーション | Keep、Problem、Tryのタブ切り替え |
| メインコンテンツ | 改善案をカード形式で表示・編集 |
| サイドバー | 投票結果、アクション一覧を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Sprint名 | 文字列 | はい | 対象Sprintの名前 |
| 2 | 実施日 | 日付 | はい | Retrospectiveの実施日 |
| 3 | 参加者 | 複数選択 | はい | 参加したメンバー |
| 4 | カテゴリ | 選択 | はい | カテゴリ（Keep、Problem、Try） |
| 5 | 改善案 | テキスト | はい | 改善の内容 |
| 6 | 投稿者 | 選択 | はい | 投稿したメンバー |
| 7 | 投票数 | 数値 | いいえ | 投票数 |
| 8 | アクション化 | 選択 | いいえ | アクション化するかどうか |
| 9 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Sprint Retrospectiveを記録 | 改善案を記録する |
| 2 | Sprint Retrospectiveを参照 | 過去のRetrospectiveの内容を確認する |
| 3 | 投票する | 改善案に投票する |
| 4 | アクション化する | 改善案をアクションとして登録する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Retrospectiveの記録はチームとスクラムマスターのみ可能 |
