# チーム・組織管理

チーム・組織管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-027 |
| 画面名           | チーム・組織管理 |
| 説明             | 社内部門、パートナー企業、メンバー、役割を管理する |
| 関連ユースケース | - |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 組織名、メンバー数を表示 |
| ナビゲーション | 部門、パートナー、メンバー、役割の切り替え |
| メインコンテンツ | 組織構成を表示・編集 |
| サイドバー | 検索・フィルターを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 組織名 | 文字列 | はい | 組織の名前 |
| 2 | 部門 | 文字列 | はい | 部門名 |
| 3 | パートナー企業 | 文字列 | いいえ | パートナー企業名 |
| 4 | メンバー名 | 文字列 | はい | メンバーの名前 |
| 5 | 役割 | 選択 | はい | メンバーの役割 |
| 6 | 所属 | 文字列 | はい | 所属部門 |
| 7 | 状態 | 選択 | はい | メンバーの状態（アクティブ、非アクティブ） |
| 8 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 部門を追加 | 新しい部門を追加する |
| 2 | パートナーを登録 | パートナー企業を登録する |
| 3 | メンバーを追加 | 新しいメンバーを追加する |
| 4 | 役割を割り当て | メンバーに役割を割り当てる |
| 5 | 組織を参照 | 組織構成を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 組織管理の編集は管理者、SMのみ可能 |
| 2 | 参照権限 | 組織構成の参照はプロジェクトメンバー |
