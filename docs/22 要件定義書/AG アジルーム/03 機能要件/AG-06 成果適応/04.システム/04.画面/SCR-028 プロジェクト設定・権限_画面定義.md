# プロジェクト設定・権限

プロジェクト設定・権限画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-028 |
| 画面名           | プロジェクト設定・権限 |
| 説明             | プロジェクト設定、アクセス権、ワークフロー等を管理する |
| 関連ユースケース | - |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロジェクト名、設定項目を表示 |
| ナビゲーション | 基本設定、アクセス権、ワークフローの切り替え |
| メインコンテンツ | 設定項目を表示・編集 |
| サイドバー | ヘルプ、関連ドキュメントを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | プロジェクト名 | 文字列 | はい | プロジェクトの名前 |
| 2 | 基本設定 | テキスト | はい | プロジェクトの基本設定 |
| 3 | アクセス権 | 選択 | はい | アクセス権の設定 |
| 4 | ワークフロー | 選択 | はい | ワークフローの設定 |
| 5 | 通知設定 | 選択 | いいえ | 通知の設定 |
| 6 | バックアップ設定 | 選択 | いいえ | バックアップの設定 |
| 7 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 基本設定を編集 | プロジェクトの基本設定を編集する |
| 2 | アクセス権を設定 | アクセス権を設定する |
| 3 | ワークフローを設定 | ワークフローを設定する |
| 4 | 設定を保存 | 設定を保存する |
| 5 | 設定を参照 | 現在の設定を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 設定の編集は管理者のみ可能 |
| 2 | 参照権限 | 設定の参照は管理者、SM |
