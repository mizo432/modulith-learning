# ステートマシン図

成果適応業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、AG-06 成果適応業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図（英語版）

```plantuml
@startuml
title Outcome Adaptation State Model Diagram
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

' Improvement Action states
state "NotStarted" as NotStarted_IA <<entry>>
state "InProgress" as InProgress_IA
state "Completed" as Completed_IA <<exit>>
state "EffectVerifying" as EffectVerifying_IA
state "EffectConfirmed" as EffectConfirmed_IA <<exit>>

' Risk states
state "New" as New_RK <<entry>>
state "InProgress" as InProgress_RK
state "Resolved" as Resolved_RK <<exit>>
state "Accepted" as Accepted_RK <<exit>>

' User Review states
state "Planned" as Planned_UR <<entry>>
state "InProgress" as InProgress_UR
state "Completed" as Completed_UR <<exit>>

' Sprint Review states
state "NotPrepared" as NotPrepared_SR <<entry>>
state "Preparing" as Preparing_SR
state "Prepared" as Prepared_SR
state "InProgress" as InProgress_SR
state "Completed" as Completed_SR <<exit>>

' Improvement Action transitions
NotStarted_IA --> InProgress_IA : Improvement Action Updated (UC-LR-006)
InProgress_IA --> Completed_IA : Improvement Action Updated (UC-LR-006)
Completed_IA --> EffectVerifying_IA : Improvement Effect Verified (UC-LR-008)
EffectVerifying_IA --> EffectConfirmed_IA : Improvement Effect Verified (UC-LR-008)

' Risk transitions
New_RK --> InProgress_RK : Risk Updated (UC-LR-018)
InProgress_RK --> Resolved_RK : Risk Updated (UC-LR-018)
InProgress_RK --> Accepted_RK : Risk Updated (UC-LR-018)

' User Review transitions
Planned_UR --> InProgress_UR : User Review Executed (UC-LR-014)
InProgress_UR --> Completed_UR : User Review Executed (UC-LR-014)

' Sprint Review transitions
NotPrepared_SR --> Preparing_SR : Sprint Review Prepared (UC-SR-002)
Preparing_SR --> Prepared_SR : Sprint Review Prepared (UC-SR-002)
Prepared_SR --> InProgress_SR : Sprint Review Started (UC-SR-001)
InProgress_SR --> Completed_SR : Sprint Review Finished (UC-SR-013)
@enduml
```
