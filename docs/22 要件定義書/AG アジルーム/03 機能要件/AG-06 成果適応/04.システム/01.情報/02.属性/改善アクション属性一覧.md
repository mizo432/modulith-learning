# 改善アクション属性一覧

成果計測・フィードバックによる適応業務領域で扱う「改善アクション」の属性を定義します。

| 属性名           | 型          | PK | 必須 | 説明                               |
|------------------|-------------|----|------|------------------------------------|
| action_id        | SnowflakeID | *  | Y    | 改善アクションの一意な識別子       |
| retrospective_id | SnowflakeID |    | Y    | 関連するレトロスペクティブの識別子 |
| project_id       | UUID        |    | Y    | 所属プロジェクトの識別子           |
| owner_id         | UUID        |    | Y    | 担当者の識別子                     |
| title            | String      |    | Y    | 改善アクションのタイトル           |
| description      | Text        |    | Y    | 改善アクションの詳細説明           |
| status           | Enum        |    | Y    | 現在の状態                         |
| deadline         | Date        |    | N    | 期限                               |
| effect           | Text        |    | N    | 効果                               |
| created_at       | DateTime    |    | Y    | 作成日時                           |
| updated_at       | DateTime    |    | Y    | 最終更新日時                       |
