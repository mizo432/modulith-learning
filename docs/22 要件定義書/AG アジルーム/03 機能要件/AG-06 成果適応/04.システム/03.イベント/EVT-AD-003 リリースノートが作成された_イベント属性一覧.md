# イベント属性一覧

リリースノートが作成されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-003 |
| イベント名 | リリースノートが作成された |
| 説明 | 変更内容、既知の問題、アップグレード手順が記録された |
| 関連ユースケース | UC-AD-004 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | releaseNoteId | String | はい | - | 最大255文字 | リリースノートのID |
| 2 | リリース名 | String | はい | - | 最大255文字 | 関連するリリースの名前 |
| 3 | バージョン | String | はい | - | 最大100文字 | リリースバージョン番号 |
| 4 | 変更内容 | String | はい | - | 最大5000文字 | 変更内容 |
| 5 | 作成者 | String | はい | - | 最大255文字 | リリースノートを作成したユーザー |
| 6 | 作成日時 | DateTime | はい | - | - | リリースノートの作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | リリースノート作成完了 | システム内部 | リリースノートが作成されたとき | リリースノートの作成が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
