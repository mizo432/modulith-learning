# イベント属性一覧

既存Storyが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-011 |
| イベント名 | 既存Storyが更新された |
| 説明 | フィードバックに基づいて既存Storyが更新された |
| 関連ユースケース | UC-SR-011 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | storyId | String | はい | - | 最大255文字 | StoryのID |
| 2 | feedbackId | String | はい | - | 最大255文字 | 元となったフィードバックのID |
| 3 | 変更内容 | String | いいえ | - | 最大1000文字 | 変更内容 |
| 4 | 更新日時 | DateTime | はい | - | - | 更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Story更新完了 | システム内部 | 既存Storyが更新されたとき | Storyの更新が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

| 1 | storyId | String | はい | StoryのID |

| 3 | 変更内容 | String | いいえ | 変更内容 |
