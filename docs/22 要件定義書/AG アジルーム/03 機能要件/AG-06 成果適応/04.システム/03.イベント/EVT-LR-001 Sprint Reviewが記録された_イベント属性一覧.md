# イベント属性一覧

Sprint Reviewが記録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-001 |
| イベント名 | Sprint Reviewが記録された |
| 説明 | 成果、フィードバック、決定、未解決事項が記録された |
| 関連ユースケース | UC-LR-001 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 2 | 対象Sprint | String | はい | - | 最大255文字 | 対象となるSprintの識別子 |
| 3 | 開催日時 | DateTime | はい | - | - | Sprint Reviewの開催日時 |
| 4 | 成果 | String | いいえ | - | 最大2000文字 | Sprintで達成した成果 |
| 5 | フィードバック数 | Integer | いいえ | - | - | 収集したフィードバックの数 |
| 6 | 決定事項数 | Integer | いいえ | - | - | 記録された決定事項の数 |
| 7 | 未解決事項 | String | いいえ | - | 最大1000文字 | 未解決の事項 |
| 8 | 記録日時 | DateTime | はい | - | - | 記録された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint Review記録完了 | システム内部 | Sprint Reviewが記録されたとき | Sprint Reviewの記録が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
