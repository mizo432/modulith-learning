# 品質・性能Insightsが更新された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-014 |
| イベント名 | 品質・性能Insightsが更新された |
| 説明 | テスト、欠陥、性能の傾向がリリースや目標と関連づけられた |
| 関連ユースケース | UC-LR-020 |
| 関連情報 | INF-LR-05 |
| 集約 | プロジェクト状況 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| テスト傾向 | テキスト | いいえ | テストの傾向 |
| 欠陥傾向 | テキスト | いいえ | 欠陥の傾向 |
| 性能傾向 | テキスト | いいえ | 性能の傾向 |
| 関連リリース | 文字列 | いいえ | 関連するリリース |
