# イベント属性一覧

デプロイが実行されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-005 |
| イベント名 | デプロイが実行された |
| 説明 | 環境、バージョン、ロールバック手順を定義してデプロイされた |
| 関連ユースケース | UC-AD-007 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | deployResultId | String | はい | - | 最大255文字 | デプロイ結果のID |
| 2 | 環境 | String | はい | - | 最大100文字 | デプロイ対象環境 |
| 3 | バージョン | String | はい | - | 最大100文字 | デプロイしたバージョン番号 |
| 4 | 状態 | Enum | はい | - | - | デプロイ結果の状態 |
| 5 | 実行者 | String | はい | - | 最大255文字 | デプロイを実行したユーザー |
| 6 | デプロイ開始日時 | DateTime | はい | - | - | デプロイが開始された日時 |
| 7 | デプロイ終了日時 | DateTime | いいえ | - | - | デプロイが終了した日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | デプロイ実行完了 | システム内部 | デプロイが実行されたとき | デプロイの実行が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
