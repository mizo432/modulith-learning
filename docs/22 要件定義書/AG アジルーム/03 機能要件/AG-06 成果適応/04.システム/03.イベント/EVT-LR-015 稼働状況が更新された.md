# 稼働状況が更新された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-015 |
| イベント名 | 稼働状況が更新された |
| 説明 | 監視・ログ基盤から稼働状況・エラー・ログが取得された |
| 関連ユースケース | UC-LR-021 |
| 関連情報 | INF-LR-05 |
| 集約 | プロジェクト状況 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 稼働状況 | テキスト | はい | 現在の稼働状況 |
| エラー | テキスト | いいえ | 発生したエラー |
| ログ | テキスト | いいえ | 関連するログ |
