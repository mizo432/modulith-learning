# 成果指標が測定された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-011 |
| イベント名 | 成果指標が測定された |
| 説明 | リリース後の利用状況や成果指標が測定・分析された |
| 関連ユースケース | UC-LR-017 |
| 関連情報 | INF-LR-08 |
| 集約 | 成果指標データ |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 指標名 | 文字列 | はい | 測定された指標の名前 |
| 値 | 数値 | はい | 測定された値 |
| 分析結果 | テキスト | いいえ | 分析の結果 |
