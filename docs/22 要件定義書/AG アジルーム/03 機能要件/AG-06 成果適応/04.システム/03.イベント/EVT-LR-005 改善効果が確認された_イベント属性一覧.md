# イベント属性一覧

改善効果が確認されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-005 |
| イベント名 | 改善効果が確認された |
| 説明 | 改善施策が品質、協働、価値提供に与えた影響が確認された |
| 関連ユースケース | UC-LR-008 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | actionId | String | はい | - | 最大255文字 | 改善アクションのID |
| 2 | 効果 | String | いいえ | - | 最大1000文字 | 改善アクションの効果 |
| 3 | 品質影響 | String | いいえ | - | 最大500文字 | 品質への影響 |
| 4 | 協働影響 | String | いいえ | - | 最大500文字 | 協働への影響 |
| 5 | 価値提供影響 | String | いいえ | - | 最大500文字 | 価値提供への影響 |
| 6 | 確認日時 | DateTime | はい | - | - | 確認された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 改善効果確認完了 | システム内部 | 改善効果が確認されたとき | 改善効果の確認が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
