| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-003 |
| イベント名 | 改善アクションが登録された |
| 説明 | 改善の担当、期限、状態が定義されて登録された |

| 関連情報 | INF-LR-03 |
