# イベント属性一覧

Sprint Reviewが終了されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-013 |
| イベント名 | Sprint Reviewが終了された |
| 説明 | Sprint Reviewが完了状態に変更された |
| 関連ユースケース | UC-SR-013 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 2 | 終了日時 | DateTime | はい | - | - | 終了された日時 |
| 3 | 状態 | Enum | はい | 完了 | - | Sprint Reviewの状態 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint Review終了完了 | システム内部 | Sprint Reviewが終了されたとき | Sprint Reviewの終了が記録された |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
