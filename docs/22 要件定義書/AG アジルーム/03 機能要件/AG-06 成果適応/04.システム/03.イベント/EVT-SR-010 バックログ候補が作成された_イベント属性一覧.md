# イベント属性一覧

バックログ候補が作成されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-010 |
| イベント名 | バックログ候補が作成された |
| 説明 | フィードバックからバックログ候補が作成された |
| 関連ユースケース | UC-SR-010 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | backlogCandidateId | String | はい | - | 最大255文字 | バックログ候補のID |
| 2 | feedbackId | String | はい | - | 最大255文字 | 元となったフィードバックのID |
| 3 | タイトル | String | はい | - | 最大255文字 | バックログ候補のタイトル |
| 4 | 説明 | String | いいえ | - | 最大1000文字 | バックログ候補の詳細説明 |
| 5 | 優先度 | Enum | いいえ | - | - | 優先度 |
| 6 | 作成日時 | DateTime | はい | - | - | 作成された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | バックログ候補作成完了 | システム内部 | バックログ候補が作成されたとき | バックログ候補の作成が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
