# イベント属性一覧

利用者レビューが計画されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-009 |
| イベント名 | 利用者レビューが計画された |
| 説明 | 対象者、シナリオ、期限が設定された |
| 関連ユースケース | UC-LR-013 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | reviewId | String | はい | - | 最大255文字 | 利用者レビューのID |
| 2 | 対象者 | String | はい | - | 最大255文字 | レビューの対象者 |
| 3 | シナリオ | String | はい | - | 最大1000文字 | 評価シナリオ |
| 4 | 期限 | Date | はい | - | - | レビューの期限 |
| 5 | 計画日時 | DateTime | はい | - | - | 計画された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 利用者レビュー計画完了 | システム内部 | 利用者レビューが計画されたとき | 利用者レビューの計画が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

| 2 | 対象者 | String | はい | 対象者 |

| 4 | 期限 | Date | はい | 期限 |
