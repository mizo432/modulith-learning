# プロジェクト進捗が更新された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-006 |
| イベント名 | プロジェクト進捗が更新された |
| 説明 | 進捗、マイルストーン、成果、リスクが更新された |
| 関連ユースケース | UC-LR-010 |
| 関連情報 | INF-LR-05 |
| 集約 | プロジェクト状況 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 進捗 | テキスト | はい | 現在の進捗状況 |
| マイルストーン | テキスト | いいえ | 達成したマイルストーン |
| 成果 | テキスト | いいえ | 達成した成果 |
| リスク | テキスト | いいえ | 見込まれるリスク |
