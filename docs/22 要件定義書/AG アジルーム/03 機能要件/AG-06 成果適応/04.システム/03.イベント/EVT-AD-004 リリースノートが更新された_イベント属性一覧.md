# イベント属性一覧

リリースノートが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-004 |
| イベント名 | リリースノートが更新された |
| 説明 | リリースノートが修正・更新された |
| 関連ユースケース | UC-AD-005 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | releaseNoteId | String | はい | - | 最大255文字 | リリースノートのID |
| 2 | 更新内容 | String | はい | - | 最大5000文字 | 更新された内容 |
| 3 | 更新者 | String | はい | - | 最大255文字 | リリースノートを更新したユーザー |
| 4 | 更新日時 | DateTime | はい | - | - | リリースノートの更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | リリースノート更新完了 | システム内部 | リリースノートが更新されたとき | リリースノートの更新が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
