# 利用者レビューが完了した

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-010 |
| イベント名 | 利用者レビューが完了した |
| 説明 | 対象者にレビュー・試用に参加させ、結果が記録された |
| 関連ユースケース | UC-LR-014 |
| 関連情報 | INF-LR-07 |
| 集約 | 利用者レビュー結果 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 対象者 | 文字列 | はい | レビューに参加した対象者 |
| 結果 | テキスト | はい | レビューの結果 |
| フィードバック | テキスト | いいえ | 得られたフィードバック |
