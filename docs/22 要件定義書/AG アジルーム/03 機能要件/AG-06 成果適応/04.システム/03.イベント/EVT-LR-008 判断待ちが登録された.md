# 判断待ちが登録された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-008 |
| イベント名 | 判断待ちが登録された |
| 説明 | 判断が必要な事項の期限・影響・担当が登録された |
| 関連ユースケース | UC-LR-012 |
| 関連情報 | INF-LR-05 |
| 集約 | プロジェクト状況 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 事項 | テキスト | はい | 判断が必要な事項 |
| 期限 | 日付 | はい | 判断の期限 |
| 影響 | テキスト | いいえ | 影響範囲 |
| 担当 | 文字列 | いいえ | 担当者 |
