# 改善アクションが更新された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-004 |
| イベント名 | 改善アクションが更新された |
| 説明 | 改善アクションの担当・期限・状態が修正された |
| 関連ユースケース | UC-LR-006 |
| 関連情報 | INF-LR-03 |
| 集約 | 改善アクション |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| アクション | 文字列 | はい | 更新された改善アクション |
| 担当 | 文字列 | いいえ | 更新された担当者 |
| 期限 | 日付 | いいえ | 更新された期限 |
| 状態 | 選択 | いいえ | 更新された状態 |
