# イベント属性一覧

利用状況が確認されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-006 |
| イベント名 | 利用状況が確認された |
| 説明 | 機能利用頻度、アクティブユーザー、アクセス傾向が把握された |
| 関連ユースケース | UC-AD-009 |
| 発生元 | ES-07 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | usageId | String | はい | - | 最大255文字 | 利用状況のID |
| 2 | 機能名 | String | はい | - | 最大255文字 | 対象となる機能名 |
| 3 | 測定期間開始 | Date | はい | - | - | 測定期間の開始日 |
| 4 | 測定期間終了 | Date | はい | - | - | 測定期間の終了日 |
| 5 | 利用頻度 | Integer | いいえ | - | - | 機能の利用回数 |
| 6 | アクティブユーザー数 | Integer | いいえ | - | - | アクティブなユーザー数 |
| 7 | アクセス傾向 | String | いいえ | - | 最大100文字 | アクセスの傾向 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 利用状況測定完了 | 外部システム | 監視・ログ基盤から利用状況が取得されたとき | 利用状況の測定が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
