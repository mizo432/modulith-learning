# イベント属性一覧

リリースが計画されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-001 |
| イベント名 | リリースが計画された |
| 説明 | リリース対象、日付、依存関係が定義された |
| 関連ユースケース | UC-AD-001 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | releasePlanId | String | はい | - | 最大255文字 | リリース計画のID |
| 2 | リリース名 | String | はい | - | 最大255文字 | リリースの名前 |
| 3 | 対象バージョン | String | はい | - | 最大100文字 | リリース対象のバージョン番号 |
| 4 | 計画日付 | Date | はい | - | - | 計画されたリリース日付 |
| 5 | 依存関係 | String | いいえ | - | 最大1000文字 | 他のリリースやプロジェクトとの依存関係 |
| 6 | 作成者 | String | はい | - | 最大255文字 | リリース計画を作成したユーザー |
| 7 | 作成日時 | DateTime | はい | - | - | リリース計画の作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | リリース計画完了 | システム内部 | リリースが計画されたとき | リリース計画が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |

| 2 | リリース名 | String | はい | リリースの名前 |
| 3 | 対象バージョン | String | はい | 対象バージョン |
| 4 | 計画日付 | Date | はい | 計画日付 |
| 5 | 依存関係 | String | いいえ | 依存関係 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | リリース計画保存 | リリース計画をデータベースに保存 | UC-AD-001 | リリース計画の保存 |
| 2 | 通知送信 | 関係者に通知を送信 | - | リリース計画の通知 |

|------|----------|----------|------|------------------|
