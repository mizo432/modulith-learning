# イベント属性一覧

品質・性能Insightsが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-014 |
| イベント名 | 品質・性能Insightsが更新された |
| 説明 | テスト、欠陥、性能の傾向がリリースや目標と関連づけられた |
| 関連ユースケース | UC-LR-020 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | insightsId | String | はい | - | 最大255文字 | InsightsのID |
| 2 | テスト結果 | String | いいえ | - | 最大1000文字 | テストの結果 |
| 3 | 欠陥数 | Integer | いいえ | - | - | 発見された欠陥の数 |
| 4 | 性能指標 | String | いいえ | - | 最大500文字 | 性能の測定値 |
| 5 | 更新日時 | DateTime | はい | - | - | 更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 品質・性能Insights更新完了 | システム内部 | 品質・性能Insightsが更新されたとき | 更新が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | insightsId | String | はい | InsightsのID |
| 2 | テスト結果 | String | いいえ | テスト結果 |
| 3 | 欠陥数 | Integer | いいえ | 欠陥数 |
| 4 | 性能指標 | String | いいえ | 性能指標 |

| 1 | Insights保存 | Insightsをデータベースに保存 | UC-LR-020 | Insightsの保存 |
