# イベント属性一覧

プロジェクト進捗が更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-006 |
| イベント名 | プロジェクト進捗が更新された |
| 説明 | 進捗、マイルストーン、成果、リスクが更新された |
| 関連ユースケース | UC-LR-010 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | projectId | String | はい | - | 最大255文字 | プロジェクトのID |
| 2 | プロジェクト名 | String | はい | - | 最大255文字 | プロジェクトの名前 |
| 3 | 進捗率 | Double | いいえ | - | 0-100 | プロジェクトの進捗率 |
| 4 | マイルストーン | String | いいえ | - | 最大500文字 | 現在のマイルストーン |
| 5 | 成果 | String | いいえ | - | 最大1000文字 | 達成した成果 |
| 6 | リスク数 | Integer | いいえ | - | - | 現在のリスクの数 |
| 7 | 更新日時 | DateTime | はい | - | - | 更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | プロジェクト進捗更新完了 | システム内部 | プロジェクト進捗が更新されたとき | プロジェクト進捗の更新が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
