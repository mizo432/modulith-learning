| 項目 | 内容 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | metricId | String | はい | - | 最大255文字 | 成功指標のID |
| 2 | 指標名 | String | はい | - | 最大255文字 | 成功指標の名前 |
| 3 | 目標値 | Double | はい | - | - | 目標とする値 |
| 4 | 測定方法 | String | はい | - | 最大500文字 | 測定の方法 |
| 5 | 測定頻度 | Enum | はい | - | - | 測定の頻度 |
| 6 | 単位 | String | はい | - | 最大100文字 | 値の単位 |
| 7 | 作成者 | String | はい | - | 最大255文字 | 成功指標を定義したユーザー |
| 8 | 作成日時 | DateTime | はい | - | - | 成功指標の作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 成功指標定義完了 | システム内部 | 成功指標が定義されたとき | 成功指標の定義が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
