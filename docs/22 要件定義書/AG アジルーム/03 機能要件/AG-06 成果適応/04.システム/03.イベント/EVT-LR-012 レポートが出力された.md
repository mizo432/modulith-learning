# レポートが出力された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-012 |
| イベント名 | レポートが出力された |
| 説明 | 権限と監査を考慮してレポートが出力された |
| 関連ユースケース | UC-LR-018 |
| 関連情報 | INF-LR-09 |
| 集約 | レポート |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| レポート名 | 文字列 | はい | 出力されたレポートの名前 |
| 出力者 | 文字列 | はい | レポートを出力した人 |
| 種類 | 選択 | いいえ | レポートの種類 |
