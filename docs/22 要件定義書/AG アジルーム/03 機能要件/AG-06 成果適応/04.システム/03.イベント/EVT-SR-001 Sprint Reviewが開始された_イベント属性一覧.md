# イベント属性一覧

Sprint Reviewが開始されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-001 |
| イベント名 | Sprint Reviewが開始された |
| 説明 | 対象SprintのSprint Reviewが開始された |
| 関連ユースケース | UC-SR-001 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 2 | 対象Sprint | String | はい | - | 最大255文字 | 対象となるSprintの識別子 |
| 3 | 開始日時 | DateTime | はい | - | - | 開始された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint Review開始 | システム内部 | Sprint Reviewが開始されたとき | Sprint Reviewの開始が記録された |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |

| 1 | sprintReviewId | String | はい | Sprint ReviewのID |
| 2 | 対象Sprint | String | はい | 対象Sprint |
| 3 | 開始日時 | DateTime | はい | 開始日時 |
