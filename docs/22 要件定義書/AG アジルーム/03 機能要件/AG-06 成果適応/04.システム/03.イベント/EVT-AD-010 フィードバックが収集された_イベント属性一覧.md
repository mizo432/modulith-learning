# イベント属性一覧

フィードバックが収集されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-010 |
| イベント名 | フィードバックが収集された |
| 説明 | リリース後の利用者からのフィードバックが収集された |
| 関連ユースケース | UC-AD-015 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | feedbackId | String | はい | - | 最大255文字 | フィードバックのID |
| 2 | 利用者名 | String | はい | - | 最大255文字 | フィードバックを提供した利用者 |
| 3 | フィードバック内容 | String | はい | - | 最大2000文字 | フィードバックの詳細な内容 |
| 4 | 分類 | Enum | いいえ | - | - | フィードバックの分類 |
| 5 | 重要度 | Enum | いいえ | - | - | フィードバックの重要度 |
| 6 | 作成日時 | DateTime | はい | - | - | フィードバックの作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | フィードバック収集完了 | システム内部 | フィードバックが収集されたとき | フィードバックの収集が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
