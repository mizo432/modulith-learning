# イベント属性一覧

フィードバックの対応方針が決定されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-009 |
| イベント名 | フィードバックの対応方針が決定された |
| 説明 | フィードバックの対応方針と判断理由が決定された |
| 関連ユースケース | UC-SR-009 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | feedbackId | String | はい | - | 最大255文字 | フィードバックのID |
| 2 | 対応方針 | Enum | はい | - | - | 対応方針（対応、延期、見送り） |
| 3 | 判断理由 | String | いいえ | - | 最大1000文字 | 対応方針の判断理由 |
| 4 | 決定日時 | DateTime | はい | - | - | 決定された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 対応方針決定完了 | システム内部 | 対応方針が決定されたとき | 対応方針の決定が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
