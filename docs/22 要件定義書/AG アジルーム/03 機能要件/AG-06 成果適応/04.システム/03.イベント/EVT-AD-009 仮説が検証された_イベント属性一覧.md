# イベント属性一覧

仮説が検証されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-009 |
| イベント名 | 仮説が検証された |
| 説明 | 仮説、期待結果、検証結果が記録された |
| 関連ユースケース | UC-AD-013 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | hypothesisId | String | はい | - | 最大255文字 | 仮説検証のID |
| 2 | 仮説名 | String | はい | - | 最大255文字 | 検証する仮説の名前 |
| 3 | 仮説内容 | String | はい | - | 最大2000文字 | 仮説の詳細な内容 |
| 4 | 期待結果 | String | はい | - | 最大1000文字 | 期待される結果 |
| 5 | 検証結果 | String | いいえ | - | 最大2000文字 | 実際の検証結果 |
| 6 | 状態 | Enum | はい | - | - | 検証の状態 |
| 7 | 作成者 | String | はい | - | 最大255文字 | 仮説検証を作成したユーザー |
| 8 | 作成日時 | DateTime | はい | - | - | 仮説検証の作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 仮説検証完了 | システム内部 | 仮説が検証されたとき | 仮説検証が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
