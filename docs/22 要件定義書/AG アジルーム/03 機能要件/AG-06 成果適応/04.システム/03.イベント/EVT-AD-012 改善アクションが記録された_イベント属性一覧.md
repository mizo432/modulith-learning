# イベント属性一覧

改善アクションが記録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-012 |
| イベント名 | 改善アクションが記録された |
| 説明 | 改善アクション、担当者、期限が記録された |
| 関連ユースケース | UC-AD-019 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | actionId | String | はい | - | 最大255文字 | 改善アクションのID |
| 2 | アクション名 | String | はい | - | 最大255文字 | 改善アクションの名前 |
| 3 | 内容 | String | はい | - | 最大2000文字 | 改善アクションの詳細な内容 |
| 4 | 担当者 | String | はい | - | 最大255文字 | 担当者の名前 |
| 5 | 期限 | Date | はい | - | - | 完了の期限日 |
| 6 | 優先度 | Enum | いいえ | - | - | 優先度 |
| 7 | 作成者 | String | はい | - | 最大255文字 | 改善アクションを記録したユーザー |
| 8 | 作成日時 | DateTime | はい | - | - | 改善アクションの作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 改善アクション記録完了 | システム内部 | 改善アクションが記録されたとき | 改善アクションの記録が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
