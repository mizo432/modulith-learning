# イベント属性一覧

フィードバックが記録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-007 |
| イベント名 | フィードバックが記録された |
| 説明 | ステークホルダーからのフィードバックが記録された |
| 関連ユースケース | UC-SR-007 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | feedbackId | String | はい | - | 最大255文字 | フィードバックのID |
| 2 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 3 | 提出者 | String | はい | - | 最大255文字 | フィードバックを提出した人 |
| 4 | 内容 | String | はい | - | 最大1000文字 | フィードバックの内容 |
| 5 | 記録日時 | DateTime | はい | - | - | 記録された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | フィードバック記録完了 | システム内部 | フィードバックが記録されたとき | フィードバックの記録が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
