# イベント属性一覧

改善アクションが更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-013 |
| イベント名 | 改善アクションが更新された |
| 説明 | 改善アクションの進捗・状態が修正された |
| 関連ユースケース | UC-AD-020 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | actionId | String | はい | - | 最大255文字 | 改善アクションのID |
| 2 | 更新内容 | String | はい | - | 最大2000文字 | 更新された内容 |
| 3 | 状態 | Enum | はい | - | - | 更新後の状態 |
| 4 | 更新者 | String | はい | - | 最大255文字 | 改善アクションを更新したユーザー |
| 5 | 更新日時 | DateTime | はい | - | - | 改善アクションの更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 改善アクション更新完了 | システム内部 | 改善アクションが更新されたとき | 改善アクションの更新が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
