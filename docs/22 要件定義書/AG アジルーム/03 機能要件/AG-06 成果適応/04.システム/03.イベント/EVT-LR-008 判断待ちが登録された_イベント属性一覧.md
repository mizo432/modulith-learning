# イベント属性一覧

判断待ちが登録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-008 |
| イベント名 | 判断待ちが登録された |
| 説明 | 判断が必要な事項の期限・影響・担当が登録された |
| 関連ユースケース | UC-LR-012 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | pendingId | String | はい | - | 最大255文字 | 判断待ちのID |
| 2 | タイトル | String | はい | - | 最大255文字 | 判断待ちのタイトル |
| 3 | 説明 | String | いいえ | - | 最大1000文字 | 判断待ちの詳細説明 |
| 4 | 期限 | Date | はい | - | - | 判断の期限 |
| 5 | 影響度 | String | いいえ | - | 最大500文字 | 影響度 |
| 6 | 担当者 | String | はい | - | 最大255文字 | 判断の担当者 |
| 7 | 登録日時 | DateTime | はい | - | - | 登録された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 判断待ち登録完了 | システム内部 | 判断待ちが登録されたとき | 判断待ちの登録が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
