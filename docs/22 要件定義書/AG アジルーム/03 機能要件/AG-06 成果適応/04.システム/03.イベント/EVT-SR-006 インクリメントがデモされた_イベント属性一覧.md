# イベント属性一覧

インクリメントがデモされたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-006 |
| イベント名 | インクリメントがデモされた |
| 説明 | 完成したインクリメントがデモされ、実施結果が記録された |
| 関連ユースケース | UC-SR-006 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | demoId | String | はい | - | 最大255文字 | デモのID |
| 2 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 3 | デモ対象 | String | はい | - | 最大500文字 | デモした対象 |
| 4 | 実施結果 | String | いいえ | - | 最大1000文字 | デモの実施結果 |
| 5 | 実施日時 | DateTime | はい | - | - | 実施された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | デモ完了 | システム内部 | インクリメントがデモされたとき | デモが完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
