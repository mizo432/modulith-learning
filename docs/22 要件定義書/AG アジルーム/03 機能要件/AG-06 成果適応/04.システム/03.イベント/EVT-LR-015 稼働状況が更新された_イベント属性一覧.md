# イベント属性一覧

稼働状況が更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-015 |
| イベント名 | 稼働状況が更新された |
| 説明 | 監視・ログ基盤から稼働状況・エラー・ログが取得された |
| 関連ユースケース | UC-LR-021 |
| 発生元 | 外部システム |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | statusId | String | はい | - | 最大255文字 | 稼働状況のID |
| 2 | 稼働率 | Double | いいえ | - | 0-100 | 稼働率（%） |
| 3 | エラー数 | Integer | いいえ | - | - | エラーの数 |
| 4 | ログ概要 | String | いいえ | - | 最大1000文字 | ログの概要 |
| 5 | 更新日時 | DateTime | はい | - | - | 更新された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 稼働状況更新完了 | 外部システム | 監視・ログ基盤からデータが取得されたとき | 稼働状況の更新が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
