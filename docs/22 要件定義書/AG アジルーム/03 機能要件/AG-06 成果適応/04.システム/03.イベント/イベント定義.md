# イベント定義

成果計測・フィードバックによる適応業務領域で発生するドメインイベントの詳細を定義します。

イベントソーシングガイドラインに従い、過去形の名詞句で命名し、不変（Immutable）な値オブジェクトとして実装します。

## イベント属性の共通項目

すべてのイベントは以下の共通属性を持ちます：

| 属性名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| eventId | String | 必須 | イベントの一意な識別子 |
| occurredOn | DateTime | 必須 | イベントが発生した日時 |
| userId | String | 必須 | イベントをトリガーしたユーザーID |
| projectId | String | 必須 | 関連するプロジェクトID |
| sprintId | String | 任意 | 関連するSprint ID |

## イベントの制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 不変性 | イベントは一度作成されると変更できない（Immutable） |
| 2    | 過去形命名 | イベント名は過去形の名詞句で命名する |
| 3    | タイムスタンプ | すべてのイベントは発生日時を記録する |
| 4    | ユーザー追跡 | イベントをトリガーしたユーザーを追跡する |
