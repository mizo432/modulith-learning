# イベント属性一覧

レトロスペクティブが記録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-AD-011 |
| イベント名 | レトロスペクティブが記録された |
| 説明 | スプリントの振り返り、改善アクションが記録された |
| 関連ユースケース | UC-AD-017 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | retrospectiveId | String | はい | - | 最大255文字 | レトロスペクティブのID |
| 2 | 対象Sprint | String | はい | - | 最大255文字 | 振り返りの対象となるSprint |
| 3 | 開催日時 | DateTime | はい | - | - | レトロスペクティブの開催日時 |
| 4 | Keep項目 | String | いいえ | - | 最大2000文字 | 継続すべき事項 |
| 5 | Problem項目 | String | いいえ | - | 最大2000文字 | 改善すべき事項 |
| 6 | Try項目 | String | いいえ | - | 最大2000文字 | 次回試す事項 |
| 7 | 作成者 | String | はい | - | 最大255文字 | レトロスペクティブを記録したユーザー |
| 8 | 作成日時 | DateTime | はい | - | - | レトロスペクティブの作成日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生

- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
