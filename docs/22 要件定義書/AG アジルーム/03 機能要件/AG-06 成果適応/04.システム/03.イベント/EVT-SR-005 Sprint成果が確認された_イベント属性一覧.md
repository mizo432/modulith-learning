# イベント属性一覧

Sprint成果が確認されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-005 |
| イベント名 | Sprint成果が確認された |
| 説明 | Sprint Goalと達成状況、完了・未完了Storyが確認された |
| 関連ユースケース | UC-SR-005 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 2 | Sprint Goal | String | はい | - | 最大500文字 | Sprintの目標 |
| 3 | 達成状況 | String | はい | - | 最大1000文字 | 達成状況 |
| 4 | 完了Story数 | Integer | いいえ | - | - | 完了したStoryの数 |
| 5 | 未完了Story数 | Integer | いいえ | - | - | 未完了のStoryの数 |
| 6 | 確認日時 | DateTime | はい | - | - | 確認された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint成果確認完了 | システム内部 | Sprint成果が確認されたとき | 成果の確認が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
