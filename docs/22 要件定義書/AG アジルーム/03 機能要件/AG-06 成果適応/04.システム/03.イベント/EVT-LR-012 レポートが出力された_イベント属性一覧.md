# イベント属性一覧

レポートが出力されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-012 |
| イベント名 | レポートが出力された |
| 説明 | 権限と監査を考慮してレポートが出力された |
| 関連ユースケース | UC-LR-018 |
| 発生元 | 手動 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | reportId | String | はい | - | 最大255文字 | レポートのID |
| 2 | レポート名 | String | はい | - | 最大255文字 | レポートの名前 |
| 3 | 種類 | Enum | はい | - | - | レポートの種類 |
| 4 | 出力形式 | Enum | はい | - | - | 出力形式（PDF、Excel等） |
| 5 | 出力日時 | DateTime | はい | - | - | 出力された日時 |
| 6 | 出力者 | String | はい | - | 最大255文字 | 出力者の名前 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | レポート出力完了 | 手動 | レポートが出力されたとき | レポートの出力が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
