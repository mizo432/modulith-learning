# イベント属性一覧

Sprint Retrospectiveが記録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-002 |
| イベント名 | Sprint Retrospectiveが記録された |
| 説明 | 学び、改善候補、決定事項が記録された |
| 関連ユースケース | UC-LR-003 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | retrospectiveId | String | はい | - | 最大255文字 | RetrospectiveのID |
| 2 | 対象Sprint | String | はい | - | 最大255文字 | 対象となるSprintの識別子 |
| 3 | 開催日時 | DateTime | はい | - | - | Retrospectiveの開催日時 |
| 4 | 学び | String | いいえ | - | 最大2000文字 | 得られた学び |
| 5 | 改善候補数 | Integer | いいえ | - | - | 特定された改善候補の数 |
| 6 | 決定事項 | String | いいえ | - | 最大1000文字 | 決定された事項 |
| 7 | 記録日時 | DateTime | はい | - | - | 記録された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Retrospective記録完了 | システム内部 | Retrospectiveが記録されたとき | Retrospectiveの記録が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
