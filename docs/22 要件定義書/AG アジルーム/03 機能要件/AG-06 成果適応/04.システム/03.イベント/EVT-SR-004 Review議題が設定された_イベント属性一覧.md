# イベント属性一覧

Review議題が設定されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-004 |
| イベント名 | Review議題が設定された |
| 説明 | Sprint Reviewの議題が設定された |
| 関連ユースケース | UC-SR-004 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | agendaId | String | はい | - | 最大255文字 | 議題のID |
| 2 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 3 | 議題名 | String | はい | - | 最大255文字 | 議題の名前 |
| 4 | 説明 | String | いいえ | - | 最大1000文字 | 議題の詳細説明 |
| 5 | 設定日時 | DateTime | はい | - | - | 設定された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 議題設定完了 | システム内部 | 議題が設定されたとき | 議題の設定が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

| 2 | sprintReviewId | String | はい | Sprint ReviewのID |
| 3 | 議題名 | String | はい | 議題名 |
| 4 | 説明 | String | いいえ | 説明 |
