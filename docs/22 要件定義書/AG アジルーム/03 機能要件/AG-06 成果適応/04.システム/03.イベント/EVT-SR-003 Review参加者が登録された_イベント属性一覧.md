# イベント属性一覧

Review参加者が登録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-003 |
| イベント名 | Review参加者が登録された |
| 説明 | Sprint Reviewの参加者が登録された |
| 関連ユースケース | UC-SR-003 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | participantId | String | はい | - | 最大255文字 | 参加者のID |
| 2 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 3 | 名前 | String | はい | - | 最大255文字 | 参加者の名前 |
| 4 | 役割 | String | いいえ | - | 最大100文字 | 参加者の役割 |
| 5 | 登録日時 | DateTime | はい | - | - | 登録された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 参加者登録完了 | システム内部 | 参加者が登録されたとき | 参加者の登録が完了した |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
