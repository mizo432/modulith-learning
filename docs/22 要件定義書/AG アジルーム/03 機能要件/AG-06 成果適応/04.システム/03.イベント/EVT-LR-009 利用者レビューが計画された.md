# 利用者レビューが計画された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-LR-009 |
| イベント名 | 利用者レビューが計画された |
| 説明 | 対象者、シナリオ、期限が設定された |
| 関連ユースケース | UC-LR-013 |
| 関連情報 | INF-LR-07 |
| 集約 | 利用者レビュー結果 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 対象者 | 文字列 | はい | レビューの対象者 |
| シナリオ | テキスト | はい | レビューシナリオ |
| 期限 | 日付 | はい | レビューの期限 |
