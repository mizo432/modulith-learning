# イベント属性一覧

Sprint Reviewが準備されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-SR-002 |
| イベント名 | Sprint Reviewが準備された |
| 説明 | Sprint Reviewの準備情報が保存された |
| 関連ユースケース | UC-SR-002 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | sprintReviewId | String | はい | - | 最大255文字 | Sprint ReviewのID |
| 2 | 成果 | String | いいえ | - | 最大2000文字 | Sprintで達成した成果 |
| 3 | デモ対象 | String | いいえ | - | 最大1000文字 | デモする対象 |
| 4 | 準備日時 | DateTime | はい | - | - | 準備された日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Sprint Review準備完了 | システム内部 | Sprint Reviewの準備が完了したとき | 準備情報が保存された |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
