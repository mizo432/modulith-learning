# バリエーション条件図

AG-06 成果適応のシステムが動く「条件」と、それを成り立たせる「バリエーション」を表形式で定義します。

## バリエーション一覧

| ID      | バリエーション名   | 説明                                                     | 関連業務領域 |
|---------|--------------------|----------------------------------------------------------|--------------|
| VAR-009 | 改善アクション種別 | プロセス改善、ツール改善、スキル向上                     | AG-06        |
| VAR-010 | リスク種別         | 技術リスク、スケジュールリスク、リソースリスク           | AG-06        |
| VAR-011 | アクター種別       | 従業員、PO、SM、開発者、トラッキング担当、システム管理者 | 全体         |
| VAR-013 | フィードバック種別 | 機能、品質、UX、パフォーマンス                           | AG-06        |
| VAR-014 | 対応方針           | 対応、延期、見送り                                       | AG-06        |
| VAR-015 | Sprint Review状態  | 準備中、実施中、完了                                     | AG-06        |
| VAR-016 | 改善アクション状態 | 未着手、実行中、完了、効果確認中                         | AG-06        |
| VAR-017 | リスク状態         | 新規、対応中、解消、受容                                 | AG-06        |

## 条件一覧

| ID       | 条件名                       | 説明                                                       | 関連バリエーション | 関連ユースケース      | 業務ルール種類 |
|----------|------------------------------|------------------------------------------------------------|--------------------|-----------------------|----------------|
| COND-009 | 改善アクション追跡ルール     | 期限までに改善効果を確かめる                               | VAR-009, VAR-016   | UC-LR-008             | オペレーション |
| COND-010 | リスク対応ルール             | 許容範囲を超えるリスクは対応策を実行する                   | VAR-010, VAR-017   | UC-LR-011             | ポリシー       |
| COND-015 | 権限ベースの画面表示ルール   | ロールに応じた情報だけを表示する                           | VAR-011            | UC-LR-009             | ポリシー       |
| COND-016 | フィードバック分類ルール     | フィードバックを種別ごとに分類する                         | VAR-013            | UC-SR-008             | 意思決定支援   |
| COND-017 | 対応方針決定ルール           | フィードバックの優先度に基づいて対応方針を決定する         | VAR-014            | UC-SR-009             | 意思決定支援   |
| COND-018 | Sprint Review開始条件        | 準備情報が揃っていること                                   | VAR-015            | UC-SR-001             | ポリシー       |
| COND-019 | Sprint Review終了条件        | 決定事項が記録されていること                               | VAR-015            | UC-SR-013             | ポリシー       |
| COND-020 | 改善アクション期限ルール     | 期限を過ぎた改善アクションはエスカレーションする           | VAR-016            | UC-LR-006             | オペレーション |

## 条件とバリエーションの関連

| 条件ID   | 条件名                       | 関連バリエーションID | 詳細                                                   |
|----------|------------------------------|----------------------|--------------------------------------------------------|
| COND-009 | 改善アクション追跡ルール     | VAR-009, VAR-016     | 改善アクション種別ごとに効果確認の基準を定義           |
| COND-010 | リスク対応ルール             | VAR-010, VAR-017     | リスク種別ごとに対応策の優先度を定義                   |
| COND-015 | 権限ベースの画面表示ルール   | VAR-011              | アクター種別ごとに表示可能な情報を定義                 |
| COND-016 | フィードバック分類ルール     | VAR-013              | フィードバック種別ごとに分類基準を定義                 |
| COND-017 | 対応方針決定ルール           | VAR-014              | 対応方針の選択基準を定義                               |
| COND-018 | Sprint Review開始条件        | VAR-015              | 準備中状態から実施中状態への遷移条件                   |
| COND-019 | Sprint Review終了条件        | VAR-015              | 実施中状態から完了状態への遷移条件                     |
| COND-020 | 改善アクション期限ルール     | VAR-016              | 期限を過ぎた改善アクションのエスカレーションルール      |
