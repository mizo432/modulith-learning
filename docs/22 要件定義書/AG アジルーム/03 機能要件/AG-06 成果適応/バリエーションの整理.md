# バリエーションの整理

AG-06 成果適応で定義されたバリエーションを整理し、条件との関連を明確にします。

## バリエーション整理

| バリエーションID | バリエーション名   | 値のリスト                             | 関連条件                     | 説明                                                     |
|------------------|--------------------|----------------------------------------|------------------------------|----------------------------------------------------------|
| VAR-009          | 改善アクション種別 | プロセス改善、ツール改善、スキル向上   | COND-009                     | 改善アクションの種類を分類                               |
| VAR-010          | リスク種別         | 技術リスク、スケジュールリスク、リソースリスク | COND-010              | リスクの種類を分類                                       |
| VAR-011          | アクター種別       | 従業員、PO、SM、開発者、トラッキング担当、システム管理者 | COND-015 | システムの利用者ロールを分類                             |
| VAR-013          | フィードバック種別 | 機能、品質、UX、パフォーマンス         | COND-016                     | フィードバックの種類を分類                               |
| VAR-014          | 対応方針           | 対応、延期、見送り                     | COND-017                     | フィードバックへの対応方針を分類                         |
| VAR-015          | Sprint Review状態  | 準備中、実施中、完了                   | COND-018, COND-019           | Sprint Reviewの進行状態を分類                            |
| VAR-016          | 改善アクション状態 | 未着手、実行中、完了、効果確認中       | COND-009, COND-020           | 改善アクションの進行状態を分類                           |
| VAR-017          | リスク状態         | 新規、対応中、解消、受容               | COND-010                     | リスクの進行状態を分類                                   |

## バリエーションと条件の関連

| バリエーションID | 条件ID   | 関連内容                                                   |
|------------------|----------|------------------------------------------------------------|
| VAR-009          | COND-009 | 改善アクション種別ごとに効果確認の基準を定義               |
| VAR-010          | COND-010 | リスク種別ごとに対応策の優先度を定義                       |
| VAR-011          | COND-015 | アクター種別ごとに表示可能な情報を定義                     |
| VAR-013          | COND-016 | フィードバック種別ごとに分類基準を定義                     |
| VAR-014          | COND-017 | 対応方針の選択基準を定義                                   |
| VAR-015          | COND-018 | Sprint Reviewの開始条件を定義                              |
| VAR-015          | COND-019 | Sprint Reviewの終了条件を定義                              |
| VAR-016          | COND-009 | 改善アクション状態遷移のルールを定義                       |
| VAR-016          | COND-020 | 期限を過ぎた改善アクションのエスカレーションルールを定義   |
| VAR-017          | COND-010 | リスク状態遷移のルールを定義                               |

## バリエーションの拡張可能性

将来の拡張を考慮し、以下のバリエーションを追加検討します：

| 候補ID   | 候補名             | 説明                                                     |
|----------|--------------------|----------------------------------------------------------|
| VAR-018  | Retrospective種別  | Sprint、Epic、Releaseの振り返り種類を分類                |
| VAR-019  | 通知種別           | メール、プッシュ通知、システム内通知を分類               |
| VAR-020  | レポート種別       | 進捗レポート、品質レポート、リスクレポートを分類         |
