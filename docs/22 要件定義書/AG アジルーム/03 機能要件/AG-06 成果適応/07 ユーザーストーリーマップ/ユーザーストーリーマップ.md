# ユーザーストーリーマップ

AG-06 成果適応のユーザーストーリーマップを定義します。

## 概要

ユーザーストーリーマップは、ユーザーの活動（横軸）と優先度（縦軸）に基づいてストーリーを配置し、リリース計画との整合性を確認します。

## ユーザー活動（横軸）

| 番号 | 活動名 | 説明 |
|------|--------|------|
| 1 | Sprint Review実施 | Sprintの成果を確認し、フィードバックを収集する |
| 2 | Sprint Retrospective実施 | Sprintの振り返りを行い、改善案を整理する |
| 3 | 改善アクション管理 | 改善アクションを追跡し、効果を確認する |
| 4 | プロジェクト状況把握 | プロジェクトの進捗やリスクを把握する |
| 5 | 成果指標測定 | 成果指標を測定し、分析する |
| 6 | レポート出力 | 権限と監査を考慮してレポートを出力する |

## リリース計画

| リリース | 含まれるストーリー | 優先度 |
|----------|-------------------|--------|

| Release 3 | 活動5, 6 の低優先度ストーリー | 低 |

## ストーリースライス

各ストーリーは以下の基準でスライスされます：

1. **価値提供**: ユーザーに明確な価値を提供する最小単位
2. **独立性**: 他のストーリーに依存しない独立した単位
3. **テスト可能**: 完了基準が明確でテスト可能な単位
4. **見積もり**: 1スプリント内で完了可能なサイズ
