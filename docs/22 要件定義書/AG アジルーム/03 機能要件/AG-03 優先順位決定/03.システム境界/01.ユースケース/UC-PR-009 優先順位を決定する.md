# UC-PR-009 優先順位を決定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-009 |
| ユースケース名 | 優先順位を決定する |
| 英語名 | Decide Priority |
| 説明 | 計算結果を確認・調整して最終的な優先順位を決定する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-03 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 優先順位スコアが計算されていること

## 基本フロー

1. プロダクトオーナーが「Product Backlog」画面（SCR-010）にアクセスする
2. 計算された優先順位結果を確認する
3. 必要に応じて優先順位を手動で調整する
4. 「優先順位を決定」ボタンをクリックする
5. システムが最終的な優先順位を確定する
6. 決定完了メッセージを表示する

## 代替フロー

- **3a. 調整を行わない場合**
  - 計算結果をそのまま採用する
  - ステップ4に進む

## 後置条件

- 優先順位スコア（INF-PR-02）が確定される
- 優先順位変更履歴（INF-PR-09）が記録される
- イベント「EVT-PR-008 優先順位が決定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-02 | 優先順位スコア | 決定対象の情報 |
| INF-PR-09 | 優先順位変更履歴 | 変更理由の記録 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-008 | 優先順位が決定された | 基本フローステップ5完了後 |
| EVT-PR-014 | 優先順位が変更された | 基本フローステップ3完了後（調整時） |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 決定権限 | 優先順位の決定はプロダクトオーナーのみ |
| 2 | 変更理由の記録 | 手動調整の場合は理由を記録する |
