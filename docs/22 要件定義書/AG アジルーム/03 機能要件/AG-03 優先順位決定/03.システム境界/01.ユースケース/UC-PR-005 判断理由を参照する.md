# UC-PR-005 判断理由を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-005 |
| ユースケース名 | 判断理由を参照する |
| 英語名 | View Decision Reason |
| 説明 | 優先順位決定の背景を確認する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-03 |
| 外部システム | - |
| 関連画面 | SCR-012（受入条件・受入テスト） |

## 前置条件

- ユーザーがシステムにログインしていること
- 優先判断理由（INF-PR-05）が既に記録されていること

## 基本フロー

1. ユーザーが「受入条件・受入テスト」画面（SCR-012）にアクセスする
2. 判断理由を参照する項目を選択する
3. システムが優先判断理由（INF-PR-05）の詳細を表示する
4. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 優先判断理由の詳細がユーザーに表示される
