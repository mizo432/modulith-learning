# UC-PR-004 判断理由を記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-004 |
| ユースケース名 | 判断理由を記録する |
| 英語名 | Record Decision Reason |
| 説明 | 優先順位決定の根拠・決定者・影響範囲を記録する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-03 |
| 外部システム | - |
| 関連画面 | SCR-012（受入条件・受入テスト） |

## 前置条件

- ユーザーがシステムにログインしていること
- 優先順位（INF-PR-01）が既に設定されていること

## 基本フロー

1. ユーザーが「受入条件・受入テスト」画面（SCR-012）にアクセスする
2. 判断理由を記録する項目を選択する
3. 「判断理由を記録」ボタンをクリックする
4. 根拠、決定者、影響範囲を入力する
5. 入力を保存する
6. システムが優先判断理由（INF-PR-05）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 優先判断理由（INF-PR-05）がシステムに登録される
- イベント「EVT-PR-003 判断理由が記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-05 | 優先判断理由 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-003 | 判断理由が記録された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 根拠、決定者は必須入力 |
| 2 | 文字数制限 | 根拠は1000文字以内 |
