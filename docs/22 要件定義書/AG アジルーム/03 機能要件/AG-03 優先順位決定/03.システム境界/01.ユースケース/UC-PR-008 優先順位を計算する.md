# UC-PR-008 優先順位を計算する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-008 |
| ユースケース名 | 優先順位を計算する |
| 英語名 | Calculate Priority |
| 説明 | 評価結果に基づいて優先順位スコアを計算する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-03 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 評価基準が定義されていること
- 要求項目の評価が完了していること

## 基本フロー

1. プロダクトオーナーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「優先順位を計算」ボタンをクリックする
3. システムが評価基準に基づいて優先順位スコアを計算する
4. 計算結果を表示する
5. 計算完了メッセージを表示する

## 代替フロー

- **3a. 評価が未完了の項目がある場合**
  - 「評価が未完了の項目があります」メッセージを表示する
  - 未評価項目をリスト表示する

## 後置条件

- 優先順位スコア（INF-PR-02）が更新される
- イベント「EVT-PR-007 優先順位が計算された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-01 | 評価基準 | 計算に使用 |
| INF-PR-02 | 優先順位スコア | 計算結果 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-007 | 優先順位が計算された | 基本フローステップ4完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 計算式 | 評価基準の重み付けに基づいて計算 |
