# UC-PR-001 評価基準を定義する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-001 |
| ユースケース名 | 評価基準を定義する |
| 英語名 | Define Evaluation Criteria |
| 説明 | 優先順位付けの評価基準（価値、Kano、リスク、コスト）を定義する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-01 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 評価基準が未定義であること

## 基本フロー

1. プロダクトオーナーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「評価基準を定義」ボタンをクリックする
3. 価値、Kano、リスク、コストなどの評価項目を定義する
4. 各評価項目の重み付けを設定する
5. 入力を保存する
6. システムが評価基準（INF-PR-01）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **3a. 評価項目が不足している場合**
  - 必須評価項目が未定義の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 評価基準（INF-PR-01）がシステムに登録される
- イベント「EVT-PR-001 評価基準が定義された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-01 | 評価基準 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-001 | 評価基準が定義された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須評価項目 | 価値、Kano、リスク、コストは必須 |
| 2 | 重み付けの合計 | 重み付けの合計は100%でなければならない |
