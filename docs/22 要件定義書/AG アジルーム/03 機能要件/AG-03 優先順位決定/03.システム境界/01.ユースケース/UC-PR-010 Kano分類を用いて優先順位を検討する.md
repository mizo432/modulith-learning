# UC-PR-010 Kano分類を用いて優先順位を検討する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-010 |
| ユースケース名 | Kano分類を用いて優先順位を検討する |
| 英語名 | Consider Priority with Kano Classification |
| 説明 | Kano分類を他の価値・コスト・リスク情報と合わせて優先順位判断に活用する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-01 |
| 外部システム | - |
| 関連画面 | SCR-012（受入条件・受入テスト） |

## 前置条件

- ユーザーがシステムにログインしていること
- Kano分類結果（INF-PR-04）が既に存在すること
- 優先順位（INF-PR-01）が既に設定されていること

## 基本フロー

1. ユーザーが「受入条件・受入テスト」画面（SCR-012）にアクセスする
2. 「Kano分類を用いて優先順位を検討」ボタンをクリックする
3. システムがKano分類結果（INF-PR-04）と価値・コスト・リスク情報を統合表示する
4. ユーザーが統合結果を確認する
5. ユーザーが優先順位（INF-PR-01）を調整する
6. 変更を保存する
7. システムが優先順位（INF-PR-01）を更新する
8. 更新完了メッセージを表示する

## 代替フロー

- **5a. 優先順位を変更しない場合**
  - ユーザーは「変更なし」を選択する
  - システムは現在の優先順位を維持する

## 後置条件

- 優先順位（INF-PR-01）が更新される（変更がある場合）
- イベント「EVT-PR-007 Kano分類が優先順位に反映された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-01 | 優先順位 | 更新対象の情報 |
| INF-PR-04 | Kano分類結果 | 参照対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-007 | Kano分類が優先順位に反映された | 基本フローステップ7完了後 |
