# UC-PR-006 Kano質問票を作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-006 |
| ユースケース名 | Kano質問票を作成する |
| 英語名 | Create Kano Questionnaire |
| 説明 | 各要望について機能がある場合・ない場合の反応を対で定義する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-02 |
| 外部システム | - |
| 関連画面 | SCR-012（受入条件・受入テスト） |

## 前置条件

- ユーザーがシステムにログインしていること
- 評価対象の要望が既に存在すること

## 基本フロー

1. ユーザーが「受入条件・受入テスト」画面（SCR-012）にアクセスする
2. 「Kano質問票を作成」ボタンをクリックする
3. 評価対象の要望を選択する
4. 充足質問（機能がある場合の反応）を入力する
5. 不充足質問（機能がない場合の反応）を入力する
6. 入力を保存する
7. システムがKano質問票（INF-PR-02）を登録する
8. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Kano質問票（INF-PR-02）がシステムに登録される
- イベント「EVT-PR-004 Kano質問票が作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-02 | Kano質問票 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-004 | Kano質問票が作成された | 基本フローステップ7完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 充足質問、不充足質問は必須入力 |
| 2 | 質問ペア | 充足質問と不充足質問は対で定義する |
