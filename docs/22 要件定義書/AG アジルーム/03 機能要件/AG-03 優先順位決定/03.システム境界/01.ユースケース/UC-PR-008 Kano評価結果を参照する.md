# UC-PR-008 Kano評価結果を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-008 |
| ユースケース名 | Kano評価結果を参照する |
| 英語名 | View Kano Evaluation Result |
| 説明 | 要望のKano分類結果を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-02 |
| 外部システム | - |
| 関連画面 | SCR-012（受入条件・受入テスト） |

## 前置条件

- ユーザーがシステムにログインしていること
- Kano分類結果（INF-PR-04）が既に存在すること

## 基本フロー

1. ユーザーが「受入条件・受入テスト」画面（SCR-012）にアクセスする
2. Kano評価結果を参照する要望を選択する
3. システムがKano分類結果（INF-PR-04）を表示する
4. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- Kano分類結果がユーザーに表示される
