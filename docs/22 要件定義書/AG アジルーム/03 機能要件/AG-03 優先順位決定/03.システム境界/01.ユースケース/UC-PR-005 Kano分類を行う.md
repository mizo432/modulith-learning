# UC-PR-005 Kano分類を行う

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-005 |
| ユースケース名 | Kano分類を行う |
| 英語名 | Classify Kano Category |
| 説明 | 要求項目をKanoカテゴリに分類する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 分類対象の要求項目が存在すること

## 基本フロー

1. プロダクトオーナーが「Product Backlog」画面（SCR-010）にアクセスする
2. 分類対象の要求項目を選択する
3. Kanoカテゴリ（当たり前品質、一元品質、魅力的品質、無関心品質、逆品質）を選択する
4. 入力を保存する
5. システムがKano分類結果（INF-PR-03）を登録する
6. 分類完了メッセージを表示する

## 代替フロー

- **3a. Kanoカテゴリが未選択の場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Kano分類結果（INF-PR-03）が登録される
- イベント「EVT-PR-004 Kano分類が行われた」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-03 | Kano分類結果 | 作成対象の情報 |
| INF-PR-10 | Kanoカテゴリ | 対照表 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-004 | Kano分類が行われた | 基本フローステップ5完了後 |
