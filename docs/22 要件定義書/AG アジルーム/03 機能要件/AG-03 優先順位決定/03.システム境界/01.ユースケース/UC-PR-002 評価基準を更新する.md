# UC-PR-002 評価基準を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-002 |
| ユースケース名 | 評価基準を更新する |
| 英語名 | Update Evaluation Criteria |
| 説明 | 既存の評価基準を修正・更新する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-01 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 評価基準が既に定義されていること

## 基本フロー

1. プロダクトオーナーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「評価基準を更新」ボタンをクリックする
3. 評価項目や重み付けを修正する
4. 入力を保存する
5. システムが評価基準（INF-PR-01）を更新する
6. 更新完了メッセージを表示する

## 代替フロー

- **3a. 重み付けの合計が100%でない場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 評価基準（INF-PR-01）が更新される
- イベント「EVT-PR-002 評価基準が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-01 | 評価基準 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-002 | 評価基準が更新された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 重み付けの合計 | 重み付けの合計は100%でなければならない |
| 2 | 変更履歴の記録 | 変更理由・日時を記録する |
