# UC-PR-014 対応策を定義する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-014 |
| ユースケース名 | 対応策を定義する |
| 英語名 | Define Countermeasure |
| 説明 | リスクへの対応策を定義する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-04 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- リスクが既に特定されていること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 対応策を定義するリスクを選択する
3. 対応策の内容を入力する
4. 対応策の担当者を選択する
5. 入力を保存する
6. システムが対応策（INF-PR-08）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **3a. 対応策が未入力の場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 対応策（INF-PR-08）が登録される
- イベント「EVT-PR-013 対応策が定義された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-08 | 対応策 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-013 | 対応策が定義された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 対応策の内容は必須入力 |
