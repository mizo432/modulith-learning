# UC-PR-004 価値を評価する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-004 |
| ユースケース名 | 価値を評価する |
| 英語名 | Evaluate Value |
| 説明 | 要求項目のビジネス価値を評価する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 評価対象の要求項目が存在すること

## 基本フロー

1. プロダクトオーナーが「Product Backlog」画面（SCR-010）にアクセスする
2. 評価対象の要求項目を選択する
3. ビジネス価値のスコアを入力する
4. 入力を保存する
5. システムが優先順位スコア（INF-PR-02）を更新する
6. 評価完了メッセージを表示する

## 代替フロー

- **3a. スコアが範囲外の場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 優先順位スコア（INF-PR-02）が更新される
- イベント「EVT-PR-003 価値が評価された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-02 | 優先順位スコア | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-003 | 価値が評価された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | スコア範囲 | 価値スコアは1〜10の範囲 |
