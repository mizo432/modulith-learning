# UC-PR-011 依存関係を定義する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-011 |
| ユースケース名 | 依存関係を定義する |
| 英語名 | Define Dependency |
| 説明 | 要求間の依存関係を定義する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-04 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 依存関係の定義対象となる要求項目が存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 依存関係の定義対象の要求項目を選択する
3. 依存先の要求項目を選択する
4. 依存関係の種類（必須、推奨）を選択する
5. 入力を保存する
6. システムが依存関係（INF-PR-07）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **3a. 依存先が未選択の場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 依存関係（INF-PR-07）が登録される
- イベント「EVT-PR-010 依存関係が定義された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-07 | 依存関係 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-010 | 依存関係が定義された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 循環依存の禁止 | 循環する依存関係は定義できない |
