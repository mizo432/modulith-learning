# UC-PR-016 優先順位を可視化する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-016 |
| ユースケース名 | 優先順位を可視化する |
| 英語名 | Visualize Priority |
| 説明 | 優先順位の推移・比較を視覚的に表現する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 低 |
| ビジネスユースケース | BUC-PR-05 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- プロダクトオーナーがシステムにログインしていること
- 優先順位が決定されていること

## 基本フロー

1. プロダクトオーナーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「優先順位を可視化」ボタンをクリックする
3. 可視化の種類（グラフ、チャート）を選択する
4. システムが優先順位の推移・比較を表示する
5. 表示期間や条件を調整する

## 代替フロー

- **3a. グラフを選択した場合**
  - 優先順位の推移を折れ線グラフで表示する
- **3b. チャートを選択した場合**
  - 優先順位の分布を棒グラフで表示する

## 後置条件

- 優先順位の可視化結果が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-02 | 優先順位スコア | 可視化対象の情報 |
| INF-PR-09 | 優先順位変更履歴 | 推移表示に使用 |

## 関連イベント

関連イベントなし

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
