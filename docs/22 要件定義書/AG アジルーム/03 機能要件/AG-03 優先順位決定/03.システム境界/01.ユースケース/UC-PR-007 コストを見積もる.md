# UC-PR-007 コストを見積もる

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-007 |
| ユースケース名 | コストを見積もる |
| 英語名 | Estimate Cost |
| 説明 | 実装コスト・維持コストを見積もる |
| 関連アクター | ACT-04（開発者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- 開発者がシステムにログインしていること
- 見積もり対象の要求項目が存在すること

## 基本フロー

1. 開発者が「Product Backlog」画面（SCR-010）にアクセスする
2. 見積もり対象の要求項目を選択する
3. 実装コストと維持コストを入力する
4. 入力を保存する
5. システムがコスト見積り（INF-PR-05）を登録する
6. 見積もり完了メッセージを表示する

## 代替フロー

- **3a. コストが未入力の場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- コスト見積り（INF-PR-05）が登録される
- イベント「EVT-PR-006 コストが見積もられた」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-05 | コスト見積り | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-006 | コストが見積もられた | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | コスト単位 | コストは人日またはストーリーポイントで入力 |
