# UC-PR-007 Kano評価を実施する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-007 |
| ユースケース名 | Kano評価を実施する |
| 英語名 | Conduct Kano Evaluation |
| 説明 | Kano質問票に基づいて回答を収集し、品質カテゴリに分類する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-02 |
| 外部システム | - |
| 関連画面 | SCR-012（受入条件・受入テスト） |

## 前置条件

- ユーザーがシステムにログインしていること
- Kano質問票（INF-PR-02）が既に作成されていること

## 基本フロー

1. ユーザーが「受入条件・受入テスト」画面（SCR-012）にアクセスする
2. Kano評価を実施する質問票を選択する
3. 「Kano評価を実施」ボタンをクリックする
4. 各質問に対して回答（満足/当たり前/無関心/仕方ない/不満）を入力する
5. 回答を保存する
6. システムがKano回答（INF-PR-03）を登録し、品質カテゴリに分類する
7. システムがKano分類結果（INF-PR-04）を算出する
8. 評価完了メッセージを表示する

## 代替フロー

- **4a. 回答が不完全な場合**
  - 必須質問に回答がない場合、エラーメッセージを表示する
  - ユーザーは回答を修正して再試行する

## 後置条件

- Kano回答（INF-PR-03）がシステムに登録される
- Kano分類結果（INF-PR-04）がシステムに登録される
- イベント「EVT-PR-005 Kano評価が完了した」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-02 | Kano質問票 | 評価対象の情報 |
| INF-PR-03 | Kano回答 | 作成対象の情報 |
| INF-PR-04 | Kano分類結果 | 算出対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-005 | Kano評価が完了した | 基本フローステップ7完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須回答 | 全ての質問に回答が必要 |
| 2 | 分類カテゴリ | 当たり前品質、一元品質、魅力的品質、無関心品質、逆品質の5カテゴリ |
