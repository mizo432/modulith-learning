# UC-PR-009 価値・リスク・コストを比較する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-009 |
| ユースケース名 | 価値・リスク・コストを比較する |
| 英語名 | Compare Value, Risk, and Cost |
| 説明 | 要求の価値、リスク、コスト、依存関係を比較する |
| 関連アクター | ACT-02（プロダクトオーナー） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-01 |
| 外部システム | - |
| 関連画面 | SCR-012（受入条件・受入テスト） |

## 前置条件

- ユーザーがシステムにログインしていること
- 比較対象のバックログ項目が既に存在すること

## 基本フロー

1. ユーザーが「受入条件・受入テスト」画面（SCR-012）にアクセスする
2. 比較対象の項目を選択する
3. 「価値・リスク・コストを比較」ボタンをクリックする
4. システムが各項目の価値、リスク、コスト、依存関係を比較表示する
5. ユーザーが比較結果を確認する
6. システムが比較結果（INF-PR-01）を登録する

## 代替フロー

- なし

## 後置条件

- 比較結果（INF-PR-01）がシステムに登録される
- イベント「EVT-PR-006 価値・リスク・コストが比較された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-01 | 優先順位 | 比較結果を記録する情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-006 | 価値・リスク・コストが比較された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 比較項目 | 価値、リスク、コスト、依存関係の4項目を比較 |
