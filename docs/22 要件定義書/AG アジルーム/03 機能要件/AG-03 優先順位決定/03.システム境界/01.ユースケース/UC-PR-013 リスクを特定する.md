# UC-PR-013 リスクを特定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-013 |
| ユースケース名 | リスクを特定する |
| 英語名 | Identify Risk |
| 説明 | 要求項目に関連するリスクを特定する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-04 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- リスク特定対象の要求項目が存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. リスク特定対象の要求項目を選択する
3. リスクの内容を入力する
4. リスクの発生確率と影響度を設定する
5. 入力を保存する
6. システムがリスク評価結果（INF-PR-04）を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **3a. リスク内容が未入力の場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- リスク評価結果（INF-PR-04）が登録される
- イベント「EVT-PR-012 リスクが特定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-04 | リスク評価結果 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-012 | リスクが特定された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | リスク内容、発生確率、影響度は必須 |
