# UC-PR-006 リスクを評価する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-006 |
| ユースケース名 | リスクを評価する |
| 英語名 | Evaluate Risk |
| 説明 | 要求項目に関連するリスクを評価する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-02 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 評価対象の要求項目が存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 評価対象の要求項目を選択する
3. リスクの発生確率と影響度を評価する
4. リスクレベル（高、中、低）を設定する
5. 入力を保存する
6. システムがリスク評価結果（INF-PR-04）を登録する
7. 評価完了メッセージを表示する

## 代替フロー

- **4a. リスクレベルが未設定の場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- リスク評価結果（INF-PR-04）が登録される
- イベント「EVT-PR-005 リスクが評価された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-04 | リスク評価結果 | 作成対象の情報 |
| INF-PR-11 | リスクレベル | 対照表 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-005 | リスクが評価された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | リスクレベル | 高、中、低から選択 |
