# UC-PR-003 評価基準を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-003 |
| ユースケース名 | 評価基準を参照する |
| 英語名 | View Evaluation Criteria |
| 説明 | 定義された評価基準を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-01 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 評価基準が定義されていること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「評価基準を参照」ボタンをクリックする
3. システムが評価基準（INF-PR-01）を表示する
4. ユーザーが評価基準の内容を確認する

## 代替フロー

- **3a. 評価基準が未定義の場合**
  - 「評価基準が未定義です」メッセージを表示する
  - プロダクトオーナーに評価基準の定義を促す

## 後置条件

- 評価基準（INF-PR-01）が表示される

関連イベントなし
