# UC-PR-015 優先順位を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-015 |
| ユースケース名 | 優先順位を参照する |
| 英語名 | View Priority |
| 説明 | 優先順位の結果を参照・並べ替え・フィルタリングする |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-05 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 優先順位が決定されていること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 優先順位のリストを表示する
3. 必要に応じて並べ替えやフィルタリングを行う
4. 優先順位の詳細を確認する

## 代替フロー

- **3a. フィルタリング条件を入力した場合**
  - 条件に合致する要求項目のみを表示する
  - フィルタを解除して全件表示に戻せる

## 後置条件

- 優先順位スコア（INF-PR-02）が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-02 | 優先順位スコア | 参照対象の情報 |

## 関連イベント

関連イベントなし

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 参照権限 | 全ユーザーが優先順位を参照できる |
