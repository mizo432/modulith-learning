# UC-PR-017 変更履歴を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-017 |
| ユースケース名 | 変更履歴を確認する |
| 英語名 | View Change History |
| 説明 | 優先順位変更の履歴・理由を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-05 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 優先順位変更履歴が存在すること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 「変更履歴を確認」ボタンをクリックする
3. システムが優先順位変更履歴（INF-PR-09）を表示する
4. ユーザーが変更内容・理由・日時を確認する

## 代替フロー

- **3a. 変更履歴がない場合**
  - 「変更履歴はありません」メッセージを表示する

## 後置条件

- 優先順位変更履歴（INF-PR-09）が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-09 | 優先順位変更履歴 | 参照対象の情報 |

## 関連イベント

関連イベントなし

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 参照権限 | 全ユーザーが変更履歴を参照できる |
| 2 | 削除不可 | 変更履歴は削除できない |
