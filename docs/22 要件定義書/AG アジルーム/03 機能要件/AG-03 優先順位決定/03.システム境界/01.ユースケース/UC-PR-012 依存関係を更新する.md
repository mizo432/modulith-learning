# UC-PR-012 依存関係を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-012 |
| ユースケース名 | 依存関係を更新する |
| 英語名 | Update Dependency |
| 説明 | 依存関係情報を修正・更新する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-PR-04 |
| 外部システム | - |
| 関連画面 | SCR-010（Product Backlog） |

## 前置条件

- ユーザーがシステムにログインしていること
- 依存関係が既に定義されていること

## 基本フロー

1. ユーザーが「Product Backlog」画面（SCR-010）にアクセスする
2. 更新対象の依存関係を選択する
3. 依存先や依存関係の種類を修正する
4. 入力を保存する
5. システムが依存関係（INF-PR-07）を更新する
6. 更新完了メッセージを表示する

## 代替フロー

- **3a. 循環依存が生じる場合**
  - エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 依存関係（INF-PR-07）が更新される
- イベント「EVT-PR-011 依存関係が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-PR-07 | 依存関係 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-PR-011 | 依存関係が更新された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 循環依存の禁止 | 循環する依存関係は定義できない |
