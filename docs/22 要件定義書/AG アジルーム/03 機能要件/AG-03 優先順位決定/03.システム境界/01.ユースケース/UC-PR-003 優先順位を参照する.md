# UC-PR-003 優先順位を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-PR-003 |
| ユースケース名 | 優先順位を参照する |
| 英語名 | View Priority |
| 説明 | 現在の優先順位と変更履歴を確認する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-PR-01 |
| 外部システム | - |
| 関連画面 | SCR-012（受入条件・受入テスト） |

## 前置条件

- ユーザーがシステムにログインしていること
- 優先順位（INF-PR-01）が既に設定されていること

## 基本フロー

1. ユーザーが「受入条件・受入テスト」画面（SCR-012）にアクセスする
2. システムが優先順位の一覧を表示する
3. ユーザーが特定の項目を選択する
4. システムが優先順位の詳細と変更履歴を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 優先順位の詳細と変更履歴がユーザーに表示される
