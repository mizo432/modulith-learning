# イベント属性一覧

Kano分類が行われたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-004 |
| イベント名 | Kano分類が行われた |
| 説明 | 要求項目がKanoカテゴリに分類された |
| 関連ユースケース | UC-PR-005 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | Kano結果ID | String | はい | - | - | Kano分類結果の識別子 |
| 2 | 要求項目ID | String | はい | - | - | 評価対象の要求項目の識別子 |
| 3 | Kanoカテゴリ | Enum | はい | - | - | Kano分類結果 |
| 4 | 評価者 | String | はい | - | - | Kano評価を行った担当者 |
| 5 | 評価日時 | DateTime | はい | - | - | Kano評価の実施日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | Kano分類完了 | システム内部 | Kano分類結果が保存された | UC-PR-005完了後 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生
