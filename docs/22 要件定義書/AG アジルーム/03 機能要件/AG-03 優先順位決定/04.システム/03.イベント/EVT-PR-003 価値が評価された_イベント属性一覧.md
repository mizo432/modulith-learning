# イベント属性一覧

価値が評価されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-003 |
| イベント名 | 価値が評価された |
| 説明 | 要求項目のビジネス価値が評価された |
| 関連ユースケース | UC-PR-004 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | スコアID | String | はい | - | - | 優先順位スコアの識別子 |
| 2 | 要求項目ID | String | はい | - | - | 評価対象の要求項目の識別子 |
| 3 | 価値スコア | Integer | はい | - | 1〜10 | ビジネス価値の評価スコア |
| 4 | 評価者 | String | はい | - | - | 価値を評価した担当者 |
| 5 | 評価日時 | DateTime | はい | - | - | 価値評価の実施日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 価値評価完了 | システム内部 | 価値スコアが保存された | UC-PR-004完了後 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | scoreId | String | はい | 優先順位スコアの識別子 |
| 2 | requirementId | String | はい | 要求項目の識別子 |
| 3 | valueScore | Integer | はい | 価値スコア |
| 4 | evaluatedBy | String | はい | 評価者 |
| 5 | evaluatedAt | DateTime | はい | 評価日時 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 価値スコアの保存 | 価値スコアをデータベースに保存 | UC-PR-004 | 価値評価の永続化 |
| 2 | イベントの発行 | 価値が評価されたイベントを発行 | - | 他のモジュールに通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 必須属性 | スコアID、要求項目ID、価値スコア、評価者、評価日時 | 必須入力 | イベント発生時に必須 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 価値スコアの範囲チェック | 価値スコア | 1 <= 値 <= 10 | 価値スコアは1〜10の範囲で入力してください |
