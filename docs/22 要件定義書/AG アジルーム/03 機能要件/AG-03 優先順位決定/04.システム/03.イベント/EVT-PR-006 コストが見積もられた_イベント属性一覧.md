# イベント属性一覧

コストが見積もられたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-006 |
| イベント名 | コストが見積もられた |
| 説明 | 実装コスト・維持コストが見積もられた |
| 関連ユースケース | UC-PR-007 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | コストID | String | はい | - | - | コスト見積りの識別子 |
| 2 | 要求項目ID | String | はい | - | - | 見積もり対象の要求項目の識別子 |
| 3 | 実装コスト | Integer | はい | - | 1以上 | 実装に必要なコスト |
| 4 | 維持コスト | Integer | いいえ | - | 1以上 | 維持に必要なコスト |
| 5 | 見積もり者 | String | はい | - | - | コスト見積もりを行った担当者 |
| 6 | 見積もり日時 | DateTime | はい | - | - | コスト見積もりの実施日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | コスト見積もり完了 | システム内部 | コスト見積もりが保存された | UC-PR-007完了後 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | costId | String | はい | コスト見積りの識別子 |
| 2 | requirementId | String | はい | 要求項目の識別子 |
| 3 | implementationCost | Integer | はい | 実装コスト |
| 4 | maintenanceCost | Integer | いいえ | 維持コスト |
| 5 | estimatedBy | String | はい | 見積もり者 |
| 6 | estimatedAt | DateTime | はい | 見積もり日時 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | コスト見積りの保存 | コスト見積もりをデータベースに保存 | UC-PR-007 | コスト見積もりの永続化 |
| 2 | イベントの発行 | コストが見積もられたイベントを発行 | - | 他のモジュールに通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 必須属性 | コストID、要求項目ID、実装コスト、見積もり者、見積もり日時 | 必須入力 | イベント発生時に必須 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 実装コストの範囲チェック | 実装コスト | 値 >= 1 | 実装コストは1以上で入力してください |
