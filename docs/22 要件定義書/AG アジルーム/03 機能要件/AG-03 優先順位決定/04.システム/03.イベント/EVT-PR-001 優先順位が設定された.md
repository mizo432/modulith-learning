# 優先順位が設定された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-001 |
| イベント名 | 優先順位が設定された |
| 説明 | 価値・リスク・コストを踏まえてバックログ項目の順序が決まった |
| 関連ユースケース | UC-PR-001 |
| 関連情報 | INF-PR-01 |
| 集約 | 優先順位 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 項目 | 文字列 | はい | 優先順位を設定した項目 |
| 優先順位 | 数値 | はい | 設定された優先順位 |
| 価値 | 数値 | いいえ | 価値の評価値 |
| リスク | 数値 | いいえ | リスクの評価値 |
| コスト | 数値 | いいえ | コストの評価値 |
