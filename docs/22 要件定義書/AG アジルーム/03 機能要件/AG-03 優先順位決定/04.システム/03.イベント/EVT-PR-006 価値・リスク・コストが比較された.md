## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-006 |
| イベント名 | 価値・リスク・コストが比較された |
| 説明 | 要求の価値、リスク、コスト、依存関係が比較された |
| 関連ユースケース | UC-PR-009 |
| 関連情報 | INF-PR-01 |
