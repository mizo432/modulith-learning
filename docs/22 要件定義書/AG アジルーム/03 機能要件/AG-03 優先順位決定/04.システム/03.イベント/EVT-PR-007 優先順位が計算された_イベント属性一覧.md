# イベント属性一覧

優先順位が計算されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-007 |
| イベント名 | 優先順位が計算された |
| 説明 | 評価結果に基づいて優先順位スコアが計算された |
| 関連ユースケース | UC-PR-008 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | スコアID | String | はい | - | - | 優先順位スコアの識別子 |
| 2 | 要求項目ID | String | はい | - | - | 計算対象の要求項目の識別子 |
| 3 | 優先順位 | Integer | はい | - | - | 計算された優先順位 |
| 4 | 計算者 | String | はい | - | - | 優先順位を計算した担当者 |
| 5 | 計算日時 | DateTime | はい | - | - | 優先順位計算の実施日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 優先順位計算完了 | システム内部 | 優先順位スコアが計算された | UC-PR-008完了後 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | scoreId | String | はい | 優先順位スコアの識別子 |
| 2 | requirementId | String | はい | 要求項目の識別子 |
| 3 | priority | Integer | はい | 優先順位 |
| 4 | calculatedBy | String | はい | 計算者 |
| 5 | calculatedAt | DateTime | はい | 計算日時 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 優先順位スコアの保存 | 優先順位スコアをデータベースに保存 | UC-PR-008 | 優先順位計算の永続化 |
| 2 | イベントの発行 | 優先順位が計算されたイベントを発行 | - | 他のモジュールに通知 |
