# イベント属性一覧

投資判断が記録されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-009 |
| イベント名 | 投資判断が記録された |
| 説明 | 優先順位に基づく投資判断の理由が記録された |
| 関連ユースケース | UC-PR-010 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | 投資判断ID | String | はい | - | - | 投資判断の識別子 |
| 2 | 要求項目ID | String | はい | - | - | 投資判断対象の要求項目の識別子 |
| 3 | 投資判断種別 | Enum | はい | - | 投資、保留、却下 | 投資判断の種別 |
| 4 | 判断理由 | String | はい | - | - | 投資判断の理由 |
| 5 | 判断者 | String | はい | - | - | 投資判断を行った担当者 |
| 6 | 判断日時 | DateTime | はい | - | - | 投資判断の実施日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 投資判断記録完了 | システム内部 | 投資判断が保存された | UC-PR-010完了後 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | decisionId | String | はい | 投資判断の識別子 |
| 2 | requirementId | String | はい | 要求項目の識別子 |
| 3 | decisionType | Enum | はい | 投資判断種別 |
| 4 | reason | String | はい | 判断理由 |
| 5 | decidedBy | String | はい | 判断者 |
| 6 | decidedAt | DateTime | はい | 判断日時 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 投資判断の保存 | 投資判断をデータベースに保存 | UC-PR-010 | 投資判断の永続化 |
| 2 | イベントの発行 | 投資判断が記録されたイベントを発行 | - | 他のモジュールに通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 必須属性 | 投資判断ID、要求項目ID、投資判断種別、判断理由、判断者、判断日時 | 必須入力 | イベント発生時に必須 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|

| 2 | 判断理由の存在チェック | 判断理由 | 空でない | 判断理由は必須です |
