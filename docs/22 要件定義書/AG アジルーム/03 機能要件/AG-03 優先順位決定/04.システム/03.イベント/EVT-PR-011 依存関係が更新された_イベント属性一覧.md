# イベント属性一覧

依存関係が更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-011 |
| イベント名 | 依存関係が更新された |
| 説明 | 依存関係情報が修正・更新された |
| 関連ユースケース | UC-PR-012 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | 依存関係ID | String | はい | - | - | 依存関係の識別子 |
| 2 | 要求項目ID | String | はい | - | - | 依存元の要求項目の識別子 |
| 3 | 依存先ID | String | はい | - | - | 依存先の要求項目の識別子 |
| 4 | 依存関係種別 | Enum | はい | - | 必須、推奨 | 依存関係の種別 |
| 5 | 更新者 | String | はい | - | - | 依存関係を更新した担当者 |
| 6 | 更新日時 | DateTime | はい | - | - | 依存関係の更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 依存関係更新完了 | システム内部 | 依存関係が更新された | UC-PR-012完了後 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | dependencyId | String | はい | 依存関係の識別子 |
| 2 | requirementId | String | はい | 依存元の要求項目の識別子 |
| 3 | dependencyTargetId | String | はい | 依存先の要求項目の識別子 |
| 4 | dependencyType | Enum | はい | 依存関係種別 |
| 5 | updatedBy | String | はい | 更新者 |
| 6 | updatedAt | DateTime | はい | 更新日時 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 依存関係の更新 | 依存関係をデータベースに更新 | UC-PR-012 | 依存関係の永続化 |
| 2 | イベントの発行 | 依存関係が更新されたイベントを発行 | - | 他のモジュールに通知 |

## 制約事項

イベントの制約条件を定義します。

| 番号 | 制約名 | 対象属性 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 必須属性 | 依存関係ID、要求項目ID、依存先ID、依存関係種別、更新者、更新日時 | 必須入力 | イベント発生時に必須 |

## バリデーションルール

イベントデータの検証ルールを定義します。

| 番号 | ルール名 | 対象属性 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 依存関係種別の存在チェック | 依存関係種別 | 空でない | 依存関係種別は必須です |
