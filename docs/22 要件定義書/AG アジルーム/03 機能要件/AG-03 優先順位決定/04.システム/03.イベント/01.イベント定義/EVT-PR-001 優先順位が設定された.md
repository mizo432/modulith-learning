# EVT-PR-001 優先順位が設定された

## 概要

価値・リスク・コストを踏まえてバックログ項目の順序が決まったことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                           |
|------------------|------------------------------------------------------------------------------|
| イベントID       | EVT-PR-001                                                                   |
| イベント名       | 優先順位が設定された                                                         |
| 英語名           | `PrioritySet`                                                                |
| 集約             | 優先順位                                                                     |
| 関連ユースケース | UC-PR-001 優先順位を設定する                                                 |
| 関連情報         | INF-PR-01 優先順位                                                           |
| 発生条件         | プロダクトマネージャーが価値・リスク・コストを踏まえて優先順位を設定したとき |

## イベントペイロード

| プロパティ      | 型            | 必須 | 説明                                 |
|-----------------|---------------|------|--------------------------------------|
| `eventId`       | UUID          | ✓   | イベントを一意に識別するID           |
| `occurredAt`    | LocalDateTime | ✓   | イベントが発生した時刻               |
| `aggregateId`   | String        | ✓   | 関連する集約ルートのID               |
| `aggregateType` | String        | ✓   | "Priority"                           |
| `version`       | int           | ✓   | 集約のバージョン                     |
| `backlogItemId` | String        | ✓   | 優先順位を設定したバックログ項目のID |
| `priorityOrder` | int           | ✓   | 優先順位の順序番号                   |
| `valueScore`    | double        | ✗   | 価値スコア                           |
| `riskScore`     | double        | ✗   | リスクスコア                         |
| `costScore`     | double        | ✗   | コストスコア                         |
| `setBy`         | String        | ✓   | 設定者のアクターID                   |
| `reason`        | String        | ✗   | 優先順位の理由                       |

## 不変条件

- 一度記録されたイベントは変更・削除しない

## 関連イベント

| イベント                        | 関係             |
|---------------------------------|------------------|
| EVT-PR-002 優先順位が更新された | 更新時に発生     |
| EVT-PR-003 判断理由が記録された | 理由記録時に発生 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.priority.priorityDecision.spi.priority.event.PrioritySet`
