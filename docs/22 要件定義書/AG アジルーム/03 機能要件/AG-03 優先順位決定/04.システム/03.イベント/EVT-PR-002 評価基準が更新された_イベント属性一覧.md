# イベント属性一覧

評価基準が更新されたの属性をリストアップします。

## イベント概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-PR-002 |
| イベント名 | 評価基準が更新された |
| 説明 | 既存の評価基準が修正・更新された |
| 関連ユースケース | UC-PR-002 |
| 発生元 | システム内部 |

## イベント属性一覧

イベントが持つデータ属性を定義します。

| 番号 | 属性名 | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|----|------|--------|------|------|
| 1 | 評価基準ID | String | はい | - | - | 更新された評価基準の識別子 |
| 2 | 更新者 | String | はい | - | - | 評価基準を更新した担当者 |
| 3 | 更新日時 | DateTime | はい | - | - | 評価基準の更新日時 |
| 4 | 変更理由 | String | いいえ | - | - | 評価基準の変更理由 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## イベントトリガー

イベントが発生する条件を定義します。

| 番号 | トリガー名 | トリガー種類 | 条件 | 説明 |
|------|------------|--------------|------|------|
| 1 | 評価基準更新完了 | システム内部 | 評価基準が更新された | UC-PR-002完了後 |

## トリガー種類

トリガー種類は以下から選択します：

- **外部システム**: 外部システムからのメッセージ受信により発生
- **タイマー**: 指定された時間またはスケジュールにより発生
- **手動**: ユーザー操作により手動で発生
- **システム内部**: システム内部の処理結果により発生

## イベントペイロード

イベントが発生した際に送信されるデータ構造を定義します。

| 番号 | フィールド名 | 型 | 必須 | 説明 |
|------|--------------|----|------|------|
| 1 | criteriaId | String | はい | 評価基準の識別子 |
| 2 | updatedBy | String | はい | 更新者 |
| 3 | updatedAt | DateTime | はい | 更新日時 |
| 4 | reason | String | いいえ | 変更理由 |

## イベント処理フロー

イベント発生後の処理フローを定義します。

| 番号 | 処理ステップ | 処理内容 | 関連ユースケース | 説明 |
|------|--------------|----------|------------------|------|
| 1 | 評価基準の更新 | 評価基準をデータベースに更新 | UC-PR-002 | 評価基準の永続化 |
| 2 | イベントの発行 | 評価基準が更新されたイベントを発行 | - | 他のモジュールに通知 |
