# 情報属性一覧

評価基準の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-02 |
| 情報名 | 評価基準 |
| 情報種類 | リソース |
| 説明 | 優先順位の評価基準 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 評価基準の一意な識別子 |
| 2 | modelId | | Long | 必須 | 関連する優先順位モデルのID |
| 3 | name | | String | 必須 | 基準の名前 |
| 4 | category | | Enum | 必須 | カテゴリ（価値, Kano, リスク, コスト） |
| 5 | weight | | Double | 必須 | 重み |
| 6 | description | | String | 任意 | 説明 |

## 単一性・同一性・カテゴリ

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの評価基準は、名前・カテゴリの組み合わせで1つの基準を構成する |
| 同一性 (Sameness) | idが同じ場合、同じ評価基準であると判断する |
| カテゴリ (Category) | 優先順位の評価基準情報 |

## 状態遷移
