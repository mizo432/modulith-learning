# 情報属性一覧

優先順位モデルの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-01 |
| 情報名 | 優先順位モデル |
| 情報種類 | リソース |
| 説明 | 優先順位の計算モデル |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 優先順位モデルの一意な識別子 |
| 2 | name | | String | 必須 | モデルの名前 |
| 3 | formula | | String | 必須 | 計算式 |
| 4 | weight | | Double | 任意 | 重み |
| 5 | description | | String | 任意 | 説明 |

## 単一性・同一性・カテゴリ

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの優先順位モデルは、名前・計算式の組み合わせで1つのモデルを構成する |
| 同一性 (Sameness) | idが同じ場合、同じ優先順位モデルであると判断する |
| カテゴリ (Category) | 優先順位の計算モデル情報 |

## 状態遷移

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未評価 | 評価が開始されていない状態 | - | 評価中 | 価値を評価する |
| 評価中 | 評価が進行中の状態 | 未評価 | 確定 | 優先順位を計算する |
| 確定 | 優先順位が確定した状態 | 評価中 | - | - |
