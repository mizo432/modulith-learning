# 情報属性一覧

評価結果の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-03 |
| 情報名 | 評価結果 |
| 情報種類 | リソース |
| 説明 | 優先順位の評価結果 |

## 属性一覧

ER（エンティティ関係）モデルに基づき、主キー（個体指定子）と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | id | ✓ | Long | 必須 | 評価結果の一意な識別子 |
| 2 | modelId | | Long | 必須 | 関連する優先順位モデルのID |
| 3 | itemId | | String | 必須 | 評価対象の項目ID |
| 4 | value | | Double | 必須 | 価値スコア |
| 5 | kanoCategory | | Enum | 任意 | Kanoカテゴリ |
| 6 | risk | | Double | 任意 | リスクスコア |
| 7 | cost | | Double | 任意 | コスト |
| 8 | score | | Double | 必須 | 優先度スコア |

## 単一性・同一性・カテゴリ

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの評価結果は、項目ID・モデルIDの組み合わせで1つの結果を構成する |
| 同一性 (Sameness) | idが同じ場合、同じ評価結果であると判断する |
| カテゴリ (Category) | 優先順位の評価結果情報 |

## 状態遷移

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未評価 | 評価が開始されていない状態 | - | 評価中 | 価値を評価する |
| 評価中 | 評価が進行中の状態 | 未評価 | 確定 | 優先順位を計算する |
| 確定 | 優先順位が確定した状態 | 評価中 | - | - |
