# 優先判断理由属性一覧

価値・要求の優先順位決定業務領域で扱う「優先判断理由」の属性を定義します。

| 属性名          | 型          | PK | 必須 | 説明                           |
|-----------------|-------------|----|------|--------------------------------|
| decision_id     | SnowflakeID | *  | Y    | 優先判断理由の一意な識別子     |
| project_id      | UUID        |    | Y    | 所属プロジェクトの識別子       |
| backlog_item_id | SnowflakeID |    | N    | 関連するバックログ項目の識別子 |
| decided_by      | UUID        |    | Y    | 決定者の識別子                 |
| title           | String      |    | Y    | 判断事項のタイトル             |
| rationale       | Text        |    | Y    | 優先順位決定の根拠             |
| impact_scope    | Text        |    | N    | 影響範囲                       |
| decided_at      | DateTime    |    | Y    | 決定日時                       |
| created_at      | DateTime    |    | Y    | 作成日時                       |
| updated_at      | DateTime    |    | Y    | 最終更新日時                   |
