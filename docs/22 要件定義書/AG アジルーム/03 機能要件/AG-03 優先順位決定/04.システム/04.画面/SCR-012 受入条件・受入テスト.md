# 受入条件・受入テスト

受入条件・受入テスト画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-012 |
| 画面名           | 受入条件・受入テスト |
| 説明             | 受入条件とテストケースを定義し、実行結果と判定を記録する |
| 関連ユースケース | UC-PR-001, UC-PR-002, UC-PR-003, UC-PR-004, UC-PR-005, UC-PR-006, UC-PR-007, UC-PR-008, UC-PR-009, UC-PR-010 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、テストケース総数、実行済み数を表示 |
| 検索・フィルター | 状態、優先度で検索・絞り込み |
| メインコンテンツ | 受入条件とテストケースの一覧表または詳細情報を表示 |
| サイドバー | 状態別集計、優先順位別集計を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 関連Story | 選択 | はい | 関連するユーザーストーリー |
| 2 | 受入条件 | テキスト | はい | 期待される振る舞い |
| 3 | テストケース名 | 文字列 | はい | テストケースの名前 |
| 4 | テスト手順 | テキスト | はい | テストの実行手順 |
| 5 | 期待結果 | テキスト | はい | 期待される結果 |
| 6 | 実行結果 | テキスト | いいえ | 実際の実行結果 |
| 7 | 判定 | 選択 | いいえ | 判定結果（合格、不合格、未実行） |
| 8 | 優先順位 | 数値 | はい | 優先順位の値 |
| 9 | 判断理由 | テキスト | いいえ | 優先順位決定の根拠 |
| 10 | Kano分類 | 選択 | いいえ | Kano評価結果 |
| 11 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 優先順位を設定 | バックログ項目の優先順位を決める |
| 2 | 優先順位を更新 | 優先順位を再調整する |
| 3 | 優先順位を参照 | 現在の優先順位を確認する |
| 4 | 判断理由を記録 | 優先順位決定の根拠を記録する |
| 5 | 判断理由を参照 | 優先順位決定の背景を確認する |
| 6 | Kano質問票を作成 | 要望に対するKano質問票を定義する |
| 7 | Kano評価を実施 | 質問票に基づいて回答を収集・分類する |
| 8 | Kano評価結果を参照 | Kano分類結果を確認する |
| 9 | 価値・リスク・コストを比較する | 要求の価値、リスク、コストを比較する |
| 10 | Kano分類を用いて優先順位を検討する | Kano分類を優先順位判断に活用する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 優先順位の編集はプロダクトオーナーのみ可能 |
| 2 | 判定の必須 | テスト実行後は判定が必須 |
