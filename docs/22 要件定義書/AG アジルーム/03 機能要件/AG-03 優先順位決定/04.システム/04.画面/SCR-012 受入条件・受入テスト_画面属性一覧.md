## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 受入条件 | 入力 | String | はい | - | 最大2000文字 | 期待される振る舞い |
| 2 | テストケース | 入力 | String | はい | - | 最大1000文字 | テストケース名 |
| 3 | 実行結果 | 入力 | String | いいえ | - | 最大1000文字 | テスト実行結果 |
| 4 | 判定 | 選択 | Enum | いいえ | - | 合格/不合格/未実行 | テスト判定 |
| 5 | 優先順位 | 表示 | Integer | はい | - | 1以上 | 優先度 |
| 6 | 判断理由 | 入力 | String | いいえ | - | 最大1000文字 | 優先順位決定の根拠 |
| 7 | Kano分類 | 表示 | Enum | いいえ | - | 当たり前/一元/魅力的/無関心/逆 | Kano評価結果 |
| 8 | 価値 | 表示 | Double | いいえ | - | 0以上 | 価値スコア |
| 9 | リスク | 表示 | Double | いいえ | - | 0以上 | リスクスコア |
| 10 | コスト | 表示 | Double | いいえ | - | 0以上 | コストスコア |
| 11 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 12 | 判定フィルター | 選択 | Enum | いいえ | すべて | - | 判定で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
