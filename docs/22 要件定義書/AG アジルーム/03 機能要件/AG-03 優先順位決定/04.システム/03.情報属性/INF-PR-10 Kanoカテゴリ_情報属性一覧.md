# 情報属性一覧

Kanoカテゴリの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-10 |
| 情報名 | Kanoカテゴリ |
| 情報種類 | 対照表 |
| 説明 | 当たり前品質、一元品質、魅力的品質、無関心品質、逆品質 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | カテゴリコード | ✓ | String | はい | Kanoカテゴリのコード |
| 2 | カテゴリ名 | | String | はい | Kanoカテゴリの名前 |
| 3 | 説明 | | String | いいえ | Kanoカテゴリの説明 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのKanoカテゴリは1つのコードと名前の組み合わせ |
| 同一性 (Sameness) | カテゴリコードが同じ場合、同じKanoカテゴリである |
| カテゴリ (Category) | Kano評価のカテゴリマスター |

## 状態遷移

この情報は対照表であり、状態遷移はありません。
