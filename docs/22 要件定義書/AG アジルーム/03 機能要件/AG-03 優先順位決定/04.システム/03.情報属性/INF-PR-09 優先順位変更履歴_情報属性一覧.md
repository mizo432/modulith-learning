# 情報属性一覧

優先順位変更履歴の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-09 |
| 情報名 | 優先順位変更履歴 |
| 情報種類 | リソース |
| 説明 | 優先順位変更の履歴・理由 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | 変更履歴ID | ✓ | String | はい | 変更履歴の一意な識別子 |
| 2 | スコアID | | String | はい | 変更対象の優先順位スコアの識別子 |
| 3 | 変更前優先順位 | | Integer | はい | 変更前の優先順位 |
| 4 | 変更後優先順位 | | Integer | はい | 変更後の優先順位 |
| 5 | 変更理由 | | String | はい | 優先順位変更の理由 |
| 6 | 変更者 | | String | はい | 優先順位を変更した担当者 |
| 7 | 変更日時 | | DateTime | はい | 優先順位変更の実施日時 |
| 8 | 備考 | | String | いいえ | 変更履歴に関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの変更履歴は1回の優先順位変更の記録 |
| 同一性 (Sameness) | 変更履歴IDが同じ場合、同じ変更履歴である |
| カテゴリ (Category) | 優先順位変更の履歴 |
