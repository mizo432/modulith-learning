# 情報属性一覧

リスクレベルの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-11 |
| 情報名 | リスクレベル |
| 情報種類 | 対照表 |
| 説明 | 高、中、低 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | レベルコード | ✓ | String | はい | リスクレベルのコード |
| 2 | レベル名 | | String | はい | リスクレベルの名前 |
| 3 | 説明 | | String | いいえ | リスクレベルの説明 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのリスクレベルは1つのコードと名前の組み合わせ |
| 同一性 (Sameness) | レベルコードが同じ場合、同じリスクレベルである |
| カテゴリ (Category) | リスク評価のレベルマスター |

## 状態遷移

この情報は対照表であり、状態遷移はありません。
