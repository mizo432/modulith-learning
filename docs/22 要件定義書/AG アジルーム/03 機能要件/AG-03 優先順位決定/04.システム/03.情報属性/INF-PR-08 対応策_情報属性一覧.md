# 情報属性一覧

対応策の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-08 |
| 情報名 | 対応策 |
| 情報種類 | リソース |
| 説明 | リスクへの対応策 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | 対応策ID | ✓ | String | はい | 対応策の一意な識別子 |
| 2 | リスクID | | String | はい | 対応対象のリスクの識別子 |
| 3 | 対応策内容 | | String | はい | 対応策の詳細な説明 |
| 4 | 担当者 | | String | はい | 対応策の担当者 |
| 5 | 定義日時 | | DateTime | はい | 対応策の定義日時 |
| 6 | 完了日時 | | DateTime | いいえ | 対応策の完了日時 |
| 7 | 備考 | | String | いいえ | 対応策に関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの対応策は1つのリスクへの対応策 |
| 同一性 (Sameness) | 対応策IDが同じ場合、同じ対応策である |
| カテゴリ (Category) | リスクへの対応策 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未定義 | 対応策がまだ定義されていない | - | 定義済み | UC-PR-014 |
| 定義済み | 対応策が定義された | 未定義 | 定義済み | UC-PR-014 |
| 対応中 | 対応策が実施されている | 定義済み | 完了 | UC-PR-014 |
| 完了 | 対応策が完了した | 対応中 | 完了 | UC-PR-006 |
