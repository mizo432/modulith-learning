# 情報属性一覧

コスト見積りの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-05 |
| 情報名 | コスト見積り |
| 情報種類 | リソース |
| 説明 | 実装コスト・維持コストの見積もり |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | コストID | ✓ | String | はい | コスト見積りの一意な識別子 |
| 2 | 要求項目ID | | String | はい | 見積もり対象の要求項目の識別子 |
| 3 | 実装コスト | | Integer | はい | 実装に必要なコスト（人日またはストーリーポイント） |
| 4 | 維持コスト | | Integer | いいえ | 維持に必要なコスト（人日またはストーリーポイント） |
| 5 | 見積もり者 | | String | はい | コスト見積もりを行った担当者 |
| 6 | 見積もり日時 | | DateTime | はい | コスト見積もりの実施日時 |
| 7 | 更新日時 | | DateTime | いいえ | コスト見積もりの最終更新日時 |
| 8 | 備考 | | String | いいえ | コスト見積もりに関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのコスト見積りは1つの要求項目の実装・維持コスト |
| 同一性 (Sameness) | コストIDが同じ場合、同じコスト見積りである |
| カテゴリ (Category) | 実装コスト・維持コストの見積もり |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未見積もり | コスト見積もりがまだ行われていない | - | 見積もり済み | UC-PR-007 |
| 見積もり済み | コスト見積もりが完了した | 未見積もり | 見積もり済み | UC-PR-007 |
