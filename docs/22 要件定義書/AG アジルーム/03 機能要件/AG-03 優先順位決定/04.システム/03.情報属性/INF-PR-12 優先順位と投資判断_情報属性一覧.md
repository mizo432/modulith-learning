# 情報属性一覧

優先順位と投資判断の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-12 |
| 情報名 | 優先順位と投資判断 |
| 情報種類 | 対応表 |
| 説明 | 優先順位と投資判断の関連 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | 関連ID | ✓ | String | はい | 優先順位と投資判断の関連の一意な識別子 |
| 2 | スコアID | | String | はい | 優先順位スコアの識別子 |
| 3 | 投資判断ID | | String | はい | 投資判断の識別子 |
| 4 | 関連日時 | | DateTime | はい | 関連付けられた日時 |
| 5 | 備考 | | String | いいえ | 関連に関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの関連は1つの優先順位スコアと1つの投資判断の関連 |
| 同一性 (Sameness) | 関連IDが同じ場合、同じ関連である |
| カテゴリ (Category) | 優先順位と投資判断の関連 |

## 状態遷移

この情報は対応表であり、状態遷移はありません。
