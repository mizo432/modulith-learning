# 情報属性一覧

投資判断の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-06 |
| 情報名 | 投資判断 |
| 情報種類 | リソース |
| 説明 | 優先順位に基づく投資判断とその理由 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | 投資判断ID | ✓ | String | はい | 投資判断の一意な識別子 |
| 2 | 要求項目ID | | String | はい | 投資判断対象の要求項目の識別子 |
| 3 | 投資判断種別 | | Enum | はい | 投資、保留、却下 |
| 4 | 判断理由 | | String | はい | 投資判断の理由 |
| 5 | 判断者 | | String | はい | 投資判断を行った担当者 |
| 6 | 判断日時 | | DateTime | はい | 投資判断の実施日時 |
| 7 | 備考 | | String | いいえ | 投資判断に関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの投資判断は1つの要求項目の投資判断とその理由 |
| 同一性 (Sameness) | 投資判断IDが同じ場合、同じ投資判断である |
| カテゴリ (Category) | 優先順位に基づく投資判断 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未判断 | 投資判断がまだ行われていない | - | 判断済み | UC-PR-010 |
| 判断済み | 投資判断が完了した | 未判断 | 判断済み | UC-PR-010 |
