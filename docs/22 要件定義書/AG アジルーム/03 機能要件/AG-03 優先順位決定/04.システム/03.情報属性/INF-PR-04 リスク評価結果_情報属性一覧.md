# 情報属性一覧

リスク評価結果の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-04 |
| 情報名 | リスク評価結果 |
| 情報種類 | リソース |
| 説明 | リスクの特定・評価結果 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | リスクID | ✓ | String | はい | リスク評価結果の一意な識別子 |
| 2 | 要求項目ID | | String | はい | 評価対象の要求項目の識別子 |
| 3 | リスク内容 | | String | はい | リスクの詳細な説明 |
| 4 | 発生確率 | | Double | はい | リスクの発生確率（0〜1） |
| 5 | 影響度 | | Double | はい | リスクの発生時の影響度（1〜10） |
| 6 | リスクレベル | | Enum | はい | リスクレベル（INF-PR-11参照） |
| 7 | 特定者 | | String | はい | リスクを特定した担当者 |
| 8 | 特定日時 | | DateTime | はい | リスクの特定日時 |
| 9 | 更新日時 | | DateTime | いいえ | リスク評価の最終更新日時 |
| 10 | 備考 | | String | いいえ | リスク評価結果に関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのリスク評価結果は1つのリスクの特定・評価結果 |
| 同一性 (Sameness) | リスクIDが同じ場合、同じリスク評価結果である |
| カテゴリ (Category) | リスクの特定・評価結果 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未特定 | リスクがまだ特定されていない | - | 特定済み | UC-PR-013 |
| 特定済み | リスクが特定された | 未特定 | 特定済み | UC-PR-013 |
| 対応中 | リスクへの対応策が実施されている | 特定済み | 解決済み | UC-PR-014 |
| 解決済み | リスクが解消された | 対応中 | 解決済み | UC-PR-006 |
