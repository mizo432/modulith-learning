# 情報属性一覧

Kano分類結果の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-03 |
| 情報名 | Kano分類結果 |
| 情報種類 | リソース |
| 説明 | Kano評価の結果 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | Kano結果ID | ✓ | String | はい | Kano分類結果の一意な識別子 |
| 2 | 要求項目ID | | String | はい | 評価対象の要求項目の識別子 |
| 3 | Kanoカテゴリ | | Enum | はい | Kanoカテゴリ（INF-PR-10参照） |
| 4 | 評価者 | | String | はい | Kano評価を行った担当者 |
| 5 | 評価日時 | | DateTime | はい | Kano評価の実施日時 |
| 6 | 備考 | | String | いいえ | Kano分類結果に関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのKano分類結果は1つの要求項目のKano評価結果 |
| 同一性 (Sameness) | Kano結果IDが同じ場合、同じKano分類結果である |
| カテゴリ (Category) | Kano評価の結果 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未分類 | Kano分類がまだ行われていない | - | 分類済み | UC-PR-005 |
| 分類済み | Kano分類が完了した | 未分類 | 分類済み | UC-PR-005 |
