# 情報属性一覧

優先順位スコアの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-02 |
| 情報名 | 優先順位スコア |
| 情報種類 | リソース |
| 説明 | 評価結果に基づく優先順位スコア |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | スコアID | ✓ | String | はい | 優先順位スコアの一意な識別子 |
| 2 | 要求項目ID | | String | はい | 評価対象の要求項目の識別子 |
| 3 | 価値スコア | | Integer | はい | ビジネス価値の評価スコア（1〜10） |
| 4 | Kanoカテゴリ | | Enum | はい | Kano分類結果（INF-PR-10参照） |
| 5 | リスクレベル | | Enum | はい | リスクレベル（INF-PR-11参照） |
| 6 | コスト見積り | | Integer | はい | 実装コスト（人日またはストーリーポイント） |
| 7 | 優先順位 | | Integer | はい | 計算された優先順位 |
| 8 | 計算日時 | | DateTime | はい | 優先順位スコアの計算日時 |
| 9 | 決定日時 | | DateTime | いいえ | 優先順位が決定された日時 |
| 10 | 備考 | | String | いいえ | 優先順位スコアに関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの優先順位スコアは1つの要求項目の評価結果 |
| 同一性 (Sameness) | スコアIDが同じ場合、同じ優先順位スコアである |
| カテゴリ (Category) | 優先順位付けの評価結果 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未評価 | 要求項目の評価がまだ行われていない | - | 評価中 | UC-PR-004 |
| 評価中 | 要求項目の評価が行われている | 未評価 | 評価済み | UC-PR-006 |
| 評価済み | 要求項目の評価が完了した | 評価中 | 未決定 | UC-PR-008 |
| 未決定 | 優先順位がまだ決定されていない | 評価済み | 決定済み | UC-PR-009 |
| 決定済み | 優先順位が決定された | 未決定 | 決定済み | UC-PR-009 |
| 再検討中 | 優先順位の再検討が行われている | 決定済み | 決定済み | UC-PR-009 |
