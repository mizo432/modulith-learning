# 情報属性一覧

評価基準の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-01 |
| 情報名 | 評価基準 |
| 情報種類 | リソース |
| 説明 | 優先順位付けの評価基準（価値、Kano、リスク、コスト） |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | 評価基準ID | ✓ | String | はい | 評価基準の一意な識別子 |
| 2 | 評価項目名 | | String | はい | 評価項目の名前（価値、Kano、リスク、コスト） |
| 3 | 重み付け | | Double | はい | 評価項目の重み（合計100%） |
| 4 | 定義者 | | String | はい | 評価基準を定義した担当者 |
| 5 | 定義日時 | | DateTime | はい | 評価基準の定義日時 |
| 6 | 更新日時 | | DateTime | いいえ | 評価基準の最終更新日時 |
| 7 | 備考 | | String | いいえ | 評価基準に関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの評価基準は1つの評価項目と重み付けの組み合わせ |
| 同一性 (Sameness) | 評価基準IDが同じ場合、同じ評価基準である |
| カテゴリ (Category) | 優先順位付けの評価基準 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未定義 | 評価基準がまだ定義されていない | - | 定義済み | UC-PR-001 |
| 定義済み | 評価基準が定義された | 未定義 | 定義済み | UC-PR-001 |
| 更新中 | 評価基準が更新されている | 定義済み | 定義済み | UC-PR-002 |
