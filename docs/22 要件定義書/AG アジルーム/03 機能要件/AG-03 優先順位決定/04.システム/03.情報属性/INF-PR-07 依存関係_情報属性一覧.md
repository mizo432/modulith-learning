# 情報属性一覧

依存関係の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-PR-07 |
| 情報名 | 依存関係 |
| 情報種類 | リソース |
| 説明 | 要求間の依存関係 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | 依存関係ID | ✓ | String | はい | 依存関係の一意な識別子 |
| 2 | 要求項目ID | | String | はい | 依存元の要求項目の識別子 |
| 3 | 依存先ID | | String | はい | 依存先の要求項目の識別子 |
| 4 | 依存関係種別 | | Enum | はい | 必須、推奨 |
| 5 | 定義者 | | String | はい | 依存関係を定義した担当者 |
| 6 | 定義日時 | | DateTime | はい | 依存関係の定義日時 |
| 7 | 更新日時 | | DateTime | いいえ | 依存関係の最終更新日時 |
| 8 | 備考 | | String | いいえ | 依存関係に関する補足情報 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの依存関係は1つの要求項目間の依存関係 |
| 同一性 (Sameness) | 依存関係IDが同じ場合、同じ依存関係である |
| カテゴリ (Category) | 要求間の依存関係 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 未定義 | 依存関係がまだ定義されていない | - | 定義済み | UC-PR-011 |
| 定義済み | 依存関係が定義された | 未定義 | 定義済み | UC-PR-011 |
| 更新中 | 依存関係が更新されている | 定義済み | 定義済み | UC-PR-012 |
