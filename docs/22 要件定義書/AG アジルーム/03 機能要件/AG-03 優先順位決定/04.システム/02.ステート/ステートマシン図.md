# ステートマシン図

優先順位決定業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、AG-03 優先順位決定業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図（英語版）

```plantuml
@startuml
title Priority Decision State Model Diagram
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

' Evaluation Criteria states
state "Undefined" as Undefined_CR <<entry>>
state "Defined" as Defined_CR

' Priority Score states
state "Unevaluated" as Unevaluated_PS <<entry>>
state "Evaluating" as Evaluating_PS
state "Evaluated" as Evaluated_PS
state "Undecided" as Undecided_PS
state "Decided" as Decided_PS
state "Reconsidering" as Reconsidering_PS

' Risk states
state "Unidentified" as Unidentified_RK <<entry>>
state "Identified" as Identified_RK
state "Addressing" as Addressing_RK
state "Resolved" as Resolved_RK <<exit>>

' Evaluation Criteria transitions
Undefined_CR --> Defined_CR : Define Evaluation Criteria (UC-PR-001)
Defined_CR --> Defined_CR : Update Evaluation Criteria (UC-PR-002)

' Priority Score transitions
Unevaluated_PS --> Evaluating_PS : Evaluate Value (UC-PR-004)
Evaluating_PS --> Evaluated_PS : Evaluate Risk (UC-PR-006)
Evaluated_PS --> Undecided_PS : Calculate Priority (UC-PR-008)
Undecided_PS --> Decided_PS : Decide Priority (UC-PR-009)
Decided_PS --> Reconsidering_PS : Decide Priority (UC-PR-009)
Reconsidering_PS --> Decided_PS : Decide Priority (UC-PR-009)

' Risk transitions
Unidentified_RK --> Identified_RK : Identify Risk (UC-PR-013)
Identified_RK --> Addressing_RK : Define Countermeasure (UC-PR-014)
Addressing_RK --> Resolved_RK : Evaluate Risk (UC-PR-006)
@enduml
```

```plantuml
@startuml

' 優先順位スコア 遷移

Evaluated_PS --> Undecided_PS : 優先順位を計算する (UC-PR-008)
Undecided_PS --> Decided_PS : 優先順位を決定する (UC-PR-009)
Decided_PS --> Reconsidering_PS : 優先順位を決定する (UC-PR-009)
Reconsidering_PS --> Decided_PS : 優先順位を決定する (UC-PR-009)

Unidentified_RK --> Identified_RK : リスクを特定する (UC-PR-013)
Identified_RK --> Addressing_RK : 対応策を定義する (UC-PR-014)
Addressing_RK --> Resolved_RK : リスクを評価する (UC-PR-006)
@enduml
```
