# ステートマシン図

優先順位決定の状態遷移をPlantUMLで視覚化します。

## 評価の状態遷移

```plantuml
@startuml
skinparam state {
  BackgroundColor White
  BorderColor Black
  ArrowColor Black
}

state "未評価" as NotEvaluated
state "評価中" as Evaluating
state "確定" as Finalized

NotEvaluated --> Evaluating : UC-PR-004〜UC-PR-007\n価値/Kano/リスク/コストを評価
Evaluating --> Finalized : UC-PR-008, UC-PR-009\n優先順位を計算・決定

note right of NotEvaluated
  評価が開始されていない状態
end note

note right of Evaluating
  評価が進行中の状態
end note

note right of Finalized
  優先順位が確定した状態
end note
@enduml
```

## 状態一覧

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーUC |
|--------|------|--------|--------|-----------|
| 未評価 | 評価が開始されていない状態 | - | 評価中 | UC-PR-004〜UC-PR-007 |
| 評価中 | 評価が進行中の状態 | 未評価 | 確定 | UC-PR-008, UC-PR-009 |
| 確定 | 優先順位が確定した状態 | 評価中 | - | - |
