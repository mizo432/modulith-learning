# ステートマシン図

優先順位決定業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、AG-03 優先順位決定業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図（英語版）

```plantuml
@startuml
title Priority Decision State Model Diagram
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

' Kano Questionnaire states
state "Planned" as Planned_KQ <<entry>>
state "Collecting" as Collecting_KQ
state "Completed" as Completed_KQ <<exit>>

' Kano Classification Result states
state "Classified" as Classified_KC <<entry>>

' Priority Reason states
state "Decided" as Decided_PR <<entry>>

' Kano Questionnaire transitions
Planned_KQ --> Collecting_KQ : Kano Evaluation Conducted (UC-PR-007)
Collecting_KQ --> Completed_KQ : Kano Evaluation Conducted (UC-PR-007)

' Kano Classification transitions
Completed_KQ --> Classified_KC : Kano Evaluation Conducted (UC-PR-007)

' Priority Reason transitions
Decided_PR --> Decided_PR : Reason for Decision Recorded (UC-PR-004)
@enduml
```

## 4. 状態一覧

| 状態名 (ID)       | 英語名        | 対象情報     | 説明                                     |
|-------------------|---------------|--------------|------------------------------------------|
| 評価予定 (ST-PR-01) | Planned     | Kano質問票   | 質問票が作成され、回答収集が開始される予定 |
| 回答募集中 (ST-PR-02) | Collecting | Kano質問票   | 回答の収集が進行中                       |
| 回答完了 (ST-PR-03) | Completed   | Kano質問票   | 回答収集が完了し、分類処理が可能         |
| 分類済み (ST-PR-04) | Classified  | Kano分類結果 | 回答から品質カテゴリが導出された         |
| 判断済み (ST-PR-05) | Decided     | 優先判断理由 | POが優先順位の判断を記録した             |
