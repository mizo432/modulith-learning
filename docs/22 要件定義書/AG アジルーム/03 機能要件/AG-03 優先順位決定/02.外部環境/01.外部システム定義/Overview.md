# 外部システム定義 Overview

優先順位決定業務領域（AG-03）が連携する外部システムを定義します。

## 概要

優先順位決定は、限られた開発リソースを価値、ユーザー満足、リスク、コスト、学習効果に応じて配分する業務領域です。本業務領域では、Kano評価・優先順位・判断根拠などの情報はAgiloom内で管理するため、外部システムとの直接的な連携はありません。

## 外部システム一覧

本業務領域で連携する外部システムはありません。

| ID       | 外部システム名 | 連携内容 |
|----------|----------------|----------|
| （なし） | -              | -        |

## 補足

- 優先順位決定で管理する情報（Kano分類、優先順位、判断根拠など）は、Agiloom内の他の業務領域（バックログ管理、スプリント実行、成果適応）と連携しますが、これらはシステム内部の連携であり、外部システム連携には該当しません。
- 将来的に、外部アンケートツールとの連携により、Kano評価の回答収集を自動化することが検討される場合がありますが、現時点ではMVP範囲外です。
