# 外部システム定義 Overview

優先順位決定業務領域（AG-03）が連携する外部システムを定義します。

## 概要

優先順位決定は、価値、Kano品質、リスク、コストを踏まえて投資順を決める業務領域です。本業務領域では、優先順位評価基準、評価結果、依存関係などの情報はAgiloom内で管理するため、外部システムとの直接的な連携はありません。

## 外部システム一覧

本業務領域で連携する外部システムはありません。

| ID       | 外部システム名 | 連携内容 |
|----------|----------------|----------|
| （なし） | -              | -        |

## 補足

- 優先順位決定で管理する情報（評価基準、優先順位スコア、依存関係、リスクなど）は、Agiloom内の他の業務領域（バックログ管理、スプリント実行など）と連携しますが、これらはシステム内部の連携であり、外部システム連携には該当しません。
- 将来的に、外部プロジェクト管理ツール（Jiraなど）との連携が検討される場合がありますが、現時点ではMVP範囲外です。
