# BUC-PR-03 優先判断の記録・説明

## 概要

優先順位決定の根拠・決定者・影響範囲を記録する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:優先順位決定結果を確認する;
:決定の根拠を整理する;
:決定者を記録する;
:影響範囲を特定する;

:判断内容を記録する;
:説明文を作成する;

if (承認が必要か?) then (はい)
  :承認を申請する;
  :承認結果を待つ;
  if (承認されたか?) then (はい)
    :記録を確定する;
  else (いいえ)
    :修正意见を反映する;
    endif
  else (いいえ)
  :記録を確定する;
  endif

:関係者に共有する;

stop
@enduml
```
