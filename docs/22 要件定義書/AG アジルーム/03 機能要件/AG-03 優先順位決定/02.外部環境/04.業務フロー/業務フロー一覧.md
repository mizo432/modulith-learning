# 業務フロー一覧

優先順位決定業務領域（AG-03）の業務フローを定義します。

| ID       | 業務フロー名                 | 概要                                                     |
|----------|------------------------------|----------------------------------------------------------|
| BUC-PR-01 | 優先順位評価基準の定義       | 価値、Kano、リスク、コストなどの評価基準を定義・更新する |
| BUC-PR-02 | 要求項目の優先順位評価       | 要求項目に対して価値、Kano、リスク、コストを評価する     |
| BUC-PR-03 | 優先順位付けと投資判断       | 評価結果に基づいて優先順位を計算・決定し、投資判断を行う |
| BUC-PR-04 | 依存関係・リスクの管理       | 要求間の依存関係とリスクを管理し、優先順位に反映する     |
| BUC-PR-05 | 優先順位結果の可視化・追跡   | 優先順位の結果を可視化し、変更履歴を追跡する             |
