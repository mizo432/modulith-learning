# BUC-PR-01 優先順位の決定・更新

## 概要

価値・リスク・コストを踏まえてバックログ項目の順序を決める。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:優先順位付け対象の項目を確認する;
:各項目の価値を評価する;
:各項目のリスクを評価する;
:各項目のコストを評価する;

:評価結果を総合する;
:優先順位を決定する;

if (既存順序と異なるか?) then (はい)
  :順序を更新する;
  :変更理由を記録する;
  :関係者に通知する;
  else (いいえ)
  :そのまま進む;
  endif

:優先順位結果を記録する;
:関係者に共有する;

stop
@enduml
```
