# BUC-PR-04 依存関係・リスクの管理

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-PR-04 |
| BUC名            | 依存関係・リスクの管理 |
| 説明             | 要求間の依存関係とリスクを管理し、優先順位に反映する |
| 関連業務         | 優先順位決定 |
| 関連ユースケース | UC-PR-011, UC-PR-012, UC-PR-013, UC-PR-014 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-02     | プロダクトオーナー（PO） | 依存関係・リスクを特定し、優先順位に反映する |
| 2    | ACT-04     | 開発者       | 技術的な依存関係・リスク情報を提供する |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | 依存関係の特定   | 要求間の依存関係を特定する | ACT-02, ACT-04 |
| 2    | 依存関係の記録   | 依存関係をシステムに記録する | ACT-02, ACT-04 |
| 3    | リスクの特定     | 要求項目に関連するリスクを特定する | ACT-02, ACT-04 |
| 4    | リスクの評価     | リスクの発生確率・影響度を評価する | ACT-02, ACT-04 |
| 5    | 対応策の定義     | リスクへの対応策を定義する | ACT-02, ACT-04 |
| 6    | 依存関係・リスクの確認 | 依存関係・リスクの内容を確認する | ACT-01, ACT-02, ACT-05 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 依存関係の整合性 | 依存関係は双方向に記録する |
| 2    | リスクの定期的見直し | リスクは定期的に再評価する |
| 3    | 優先順位への反映 | 依存関係・リスクは優先順位計算に反映する |
