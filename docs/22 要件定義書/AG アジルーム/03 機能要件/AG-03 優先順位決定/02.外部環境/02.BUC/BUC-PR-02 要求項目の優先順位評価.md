# BUC-PR-02 要求項目の優先順位評価

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-PR-02 |
| BUC名            | 要求項目の優先順位評価 |
| 説明             | 要求項目に対して価値、Kano品質、リスク、コストを評価し、優先順位付けの材料とする |
| 関連業務         | 優先順位決定 |
| 関連ユースケース | UC-PR-004, UC-PR-005, UC-PR-006, UC-PR-007 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-02     | プロダクトオーナー（PO） | 要求項目の価値、リスク、コストを評価する |
| 2    | ACT-04     | 開発者       | コスト・依存関係情報を提供し、評価に参与する |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | 価値評価         | 要求項目がもたらすビジネス価値を評価する | ACT-02 |
| 2    | Kano分類評価     | 要求項目をKanoカテゴリに分類する | ACT-02 |
| 3    | リスク評価       | 要求項目に関連するリスクを評価する | ACT-02, ACT-04 |
| 4    | コスト評価       | 実装コスト・維持コストを見積もる | ACT-04 |
| 5    | 評価結果の確認   | 評価結果を確認・検証する | ACT-01, ACT-02, ACT-05 |
| 6    | 評価結果の更新   | 状況変化に応じて評価結果を修正する | ACT-02 |
