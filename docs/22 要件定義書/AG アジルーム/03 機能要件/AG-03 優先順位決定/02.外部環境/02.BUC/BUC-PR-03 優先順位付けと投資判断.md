# BUC-PR-03 優先順位付けと投資判断

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-PR-03 |
| BUC名            | 優先順位付けと投資判断 |
| 説明             | 評価結果に基づいて優先順位を計算・決定し、投資判断を行う |
| 関連業務         | 優先順位決定 |
| 関連ユースケース | UC-PR-008, UC-PR-009, UC-PR-010 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-02     | プロダクトオーナー（PO） | 優先順位を決定し、投資判断を行う |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | 優先順位の計算   | 評価結果に基づいて優先順位スコアを計算する | ACT-02 |
| 2    | 優先順位の決定   | 計算結果を確認・調整して最終的な優先順位を決定する | ACT-02 |
| 3    | 投資判断の記録   | 優先順位に基づく投資判断の理由を記録する | ACT-02 |
| 4    | 投資判断の確認   | 投資判断の内容を確認する | ACT-01, ACT-02, ACT-05 |
