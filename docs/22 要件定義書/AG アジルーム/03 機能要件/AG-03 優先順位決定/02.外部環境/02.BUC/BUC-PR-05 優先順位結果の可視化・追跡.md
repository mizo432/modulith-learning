# BUC-PR-05 優先順位結果の可視化・追跡

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-PR-05 |
| BUC名            | 優先順位結果の可視化・追跡 |
| 説明             | 優先順位の結果を可視化し、変更履歴を追跡して透明性を確保する |
| 関連業務         | 優先順位決定 |
| 関連ユースケース | UC-PR-015, UC-PR-016, UC-PR-017 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1    | ACT-01     | 従業員       | 優先順位結果を参照する |
| 2    | ACT-02     | プロダクトオーナー（PO） | 優先順位結果を確認・調整する |
| 3    | ACT-05     | トラッキング担当 | 優先順位変更履歴を追跡する |

> **注意**: ビジネスユースケースとビジネスアクターの関連付けは必須です。各BUCに対応するビジネスアクターを必ず指定してください。

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1    | 優先順位の参照   | 優先順位の結果を参照・並べ替え・フィルタリングする | ACT-01, ACT-02, ACT-05 |
| 2    | 優先順位の可視化 | 優先順位の推移・比較を視覚的に表現する | ACT-02 |
| 3    | 変更履歴の確認   | 優先順位変更の履歴・理由を確認する | ACT-01, ACT-02, ACT-05 |
| 4    | 優先順位の比較   | 異なる時点での優先順位を比較する | ACT-02 |

## 関連情報

| 番号 | 情報名 | 情報種類 | 説明 |
|------|--------|----------|------|

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1    | 透明性の確保 | 優先順位結果は全関係者が参照できる |
| 2    | 変更履歴の保持 | 優先順位変更の履歴は削除できない |
| 3    | 可視化の正確性 | 可視化は実際の優先順位と一致する |
