# バリエーション条件図

AG-03 優先順位決定のシステムが動く「条件」と、それを成り立たせる「バリエーション」を表形式で定義します。

## バリエーション一覧

| ID      | バリエーション名   | 説明                                                     | 関連業務領域 |
|---------|--------------------|----------------------------------------------------------|--------------|
| VAR-PR-001 | 評価基準種別     | 価値、Kano、リスク、コスト                               | AG-03        |
| VAR-PR-002 | Kanoカテゴリ     | 当たり前品質、一元品質、魅力的品質、無関心品質、逆品質   | AG-03        |
| VAR-PR-003 | リスクレベル     | 高、中、低                                               | AG-03        |
| VAR-PR-004 | 依存関係種別     | 必須、推奨                                               | AG-03        |
| VAR-PR-005 | 優先順位状態     | 未評価、評価中、評価済み、未決定、決定済み、再検討中     | AG-03        |
| VAR-PR-006 | 投資判断種別     | 投資、保留、却下                                         | AG-03        |

## 条件一覧

| ID       | 条件名                       | 説明                                                       | 関連バリエーション | 関連ユースケース      | 業務ルール種類 |
|----------|------------------------------|------------------------------------------------------------|--------------------|-----------------------|----------------|
| COND-PR-001 | 評価基準定義ルール       | 評価基準は価値、Kano、リスク、コストを含むこと             | VAR-PR-001         | UC-PR-001             | ポリシー       |
| COND-PR-002 | Kano分類ルール           | 要求項目はKanoカテゴリに分類すること                       | VAR-PR-002         | UC-PR-005             | ポリシー       |
| COND-PR-003 | リスク評価ルール         | リスクは発生確率と影響度を評価すること                     | VAR-PR-003         | UC-PR-006             | ポリシー       |
| COND-PR-004 | 優先順位計算ルール       | 評価基準の重み付けに基づいて優先順位を計算する             | VAR-PR-001, VAR-PR-005 | UC-PR-008       | オペレーション |
| COND-PR-005 | 優先順位決定ルール       | 優先順位の決定はプロダクトオーナーのみが行う               | VAR-PR-005         | UC-PR-009             | ポリシー       |
| COND-PR-006 | 依存関係定義ルール       | 循環依存は定義できない                                     | VAR-PR-004         | UC-PR-011             | 制約           |
| COND-PR-007 | 投資判断記録ルール       | 投資判断の理由を必ず記録する                               | VAR-PR-006         | UC-PR-010             | ポリシー       |
| COND-PR-008 | 変更履歴追跡ルール       | 優先順位変更の履歴・理由を追跡する                         | VAR-PR-005         | UC-PR-017             | オペレーション |

## 条件とバリエーションの関連

| 条件ID     | 条件名                       | 関連バリエーションID | 詳細                                                   |
|------------|------------------------------|----------------------|--------------------------------------------------------|
| COND-PR-001 | 評価基準定義ルール       | VAR-PR-001           | 評価基準種別ごとに定義基準を定義                       |
| COND-PR-002 | Kano分類ルール           | VAR-PR-002           | Kanoカテゴリの分類基準を定義                           |
| COND-PR-003 | リスク評価ルール         | VAR-PR-003           | リスクレベルの評価基準を定義                           |
| COND-PR-004 | 優先順位計算ルール       | VAR-PR-001, VAR-PR-005 | 評価基準と優先順位状態の関連を定義               |
| COND-PR-005 | 優先順位決定ルール       | VAR-PR-005           | 優先順位状態の遷移条件を定義                           |
| COND-PR-006 | 依存関係定義ルール       | VAR-PR-004           | 依存関係種別ごとに定義基準を定義                       |
| COND-PR-007 | 投資判断記録ルール       | VAR-PR-006           | 投資判断種別ごとに記録基準を定義                       |
| COND-PR-008 | 変更履歴追跡ルール       | VAR-PR-005           | 優先順位状態の変更履歴を追跡                           |
