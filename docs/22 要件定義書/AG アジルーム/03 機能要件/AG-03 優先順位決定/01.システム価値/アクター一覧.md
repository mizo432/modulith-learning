# アクター一覧

優先順位決定業務領域（AG-03）でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                 |
|--------|--------------------------|------------------------------------------------------|
| ACT-01 | 従業員                   | 優先順位結果を参照し、投資判断に参与                 |
| ACT-02 | プロダクトオーナー（PO） | 評価基準を定義し、優先順位を決定・更新               |
| ACT-04 | 開発者                   | コスト・依存関係情報を提供し、優先順位結果を参照     |
| ACT-05 | トラッキング担当         | 優先順位変更履歴・投資判断状況を参照                 |
