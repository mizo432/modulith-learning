# 要求一覧

価値・要求の優先順位決定業務領域（AG-03）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-PR-01 | 優先順位管理                 | 価値・リスク・コストを踏まえてバックログ項目の順序を決める | MVP    |
| FR-PR-02 | 判断理由記録                 | 優先順位決定の根拠・決定者・影響範囲を記録する             | MVP    |
| FR-PR-03 | Kano評価                     | Kano質問票を作成し、回答を収集して品質カテゴリに分類する   | 次期   |
| FR-PR-04 | 価値・リスク・コスト比較     | 要求の価値、リスク、コスト、依存関係を比較する             | 次期   |
| FR-PR-05 | Kano分類による優先順位検討   | Kano分類を他の価値・コスト・リスク情報と合わせて優先順位判断に活用する | 次期   |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-PR-01 | 検索性能                       | 大量のデータから迅速に検索できる       |
| NFR-PR-02 | 可視化                         | 情報を視覚的に表現できる               |
