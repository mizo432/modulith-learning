# システム価値

優先順位決定業務領域（AG-03）が実現すべき価値を定義します。

優先順位決定は、限られた開発リソースを価値、ユーザー満足、リスク、コスト、学習効果に応じて配分する業務領域です。Agiloomは、Kano分類、価値・コスト・リスク評価、Product Goalへの寄与度などを総合的に考慮し、POが判断理由を説明できるバックログ順序と投資判断を支援する基盤を提供します。

## 機能要求

- バックログ項目の優先順位設定・更新
- Kano質問票の作成・評価実施・結果参照
- Kano分類を用いた優先順位検討
- 優先判断の記録・説明（根拠・決定者・影響範囲）
- 価値・コスト・リスク情報の管理
- 優先順位の履歴追跡

## 非機能要求

- 判断の透明性（優先順位の根拠を後から確認できる）
- Kano評価の再現性（回答数・分布・分類根拠を保存）
- 自動決定の抑制（Kano分類だけで順位を決めず、POの判断を尊重）
- 優先順位変更の影響分析（順序変更が依存関係やスプリント計画に与える影響を示す）
