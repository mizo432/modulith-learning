# 要求一覧

価値・要求の優先順位決定業務領域の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                                   | 優先度 |
|----------|------------------------------|------------------------------------------------------------------------|--------|
| FR-PR-01 | 優先順位管理                 | 項目の順序、優先理由、変更履歴を管理する                               | MVP    |
| FR-PR-02 | Kano分類評価                 | 要望について充足・不充足質問を収集し、5カテゴリに分類する              | 次期   |
| FR-PR-03 | Kano質問票管理               | 各要望について機能がある場合・ない場合の反応を対で収集する             | 次期   |
| FR-PR-04 | 価値・リスク・コスト比較     | 要求の価値、リスク、コスト、依存関係を比較する                         | 次期   |
| FR-PR-05 | 判断理由記録                 | 優先順位決定の根拠、決定者、影響範囲を記録する                         | MVP    |
| FR-PR-06 | Kano分類を用いた優先順位検討 | Kano分類を他の価値・コスト・リスク情報と合わせて優先順位判断に活用する | 次期   |

## 非機能要求

| ID        | 要求名           | 概要                                     |
|-----------|------------------|------------------------------------------|
| NFR-PR-01 | 評価結果の再現性 | Kano評価などの結果を再現可能に保持する   |
| NFR-PR-02 | 判断履歴の保持   | 優先順位変更の履歴と理由を追跡可能にする |
