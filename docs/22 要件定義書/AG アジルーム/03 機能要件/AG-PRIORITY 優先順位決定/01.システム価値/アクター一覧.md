# アクター一覧

価値・要求の優先順位決定業務領域でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                           |
|--------|--------------------------|----------------------------------------------------------------|
| ACT-02 | プロダクトオーナー（PO） | 価値・リスク・コストを踏まえて優先順位を決定し、判断理由を記録 |
| ACT-05 | トラッキング担当         | 優先順位の状況・判断根拠を参照                                 |
