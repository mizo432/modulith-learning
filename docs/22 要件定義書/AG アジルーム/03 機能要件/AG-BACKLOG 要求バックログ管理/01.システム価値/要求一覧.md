# 要求一覧

要求・プロダクトバックログ管理業務領域の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                     | 概要                                                   | 優先度 |
|----------|----------------------------|--------------------------------------------------------|--------|
| FR-BL-01 | 課題・要望受付             | 従業員が課題、要望、利用場面、影響を登録できる         | MVP    |
| FR-BL-02 | フィードバック管理         | フィードバックを分類し、対応状況と判断理由を追跡する   | MVP    |
| FR-BL-03 | プロダクトバックログ管理   | Epic、Feature、Story、欠陥などを管理する               | MVP    |
| FR-BL-04 | バックログ階層・関連付け   | Product Goal、Epic、Feature、Story、Task間の関係を表す | MVP    |
| FR-BL-05 | 優先順位管理               | 項目の順序、優先理由、変更履歴を管理する               | MVP    |
| FR-BL-06 | 業務ルール・受入条件管理   | 業務上の期待、例外、受入条件を項目に記録する           | MVP    |
| FR-BL-07 | コメント・質問・メンション | 項目上で質問、回答、関係者通知を行う                   | MVP    |
| FR-BL-08 | バックログリファインメント | 項目の説明、分割、受入条件、依存関係、準備状況を整える | MVP    |
| FR-BL-09 | 変更履歴・トレーサビリティ | 要求、計画、テスト、リリースの関連と変更経緯を追跡する | MVP    |
| FR-BL-10 | Story Mapping              | ユーザー活動とストーリーを並べ、リリース範囲を検討する | 次期   |
| FR-BL-11 | 見積もり・不確実性管理     | チームの見積もり、リスク、未知事項を記録する           | 次期   |
| FR-BL-12 | 要求の重複・関連付け       | 類似要求や関連する課題、機能、テストを関連づける       | 次期   |
| FR-BL-13 | 意思決定記録               | 決定内容、根拠、決定者、影響範囲を記録する             | 次期   |

## 非機能要求

| ID        | 要求名           | 概要                                               |
|-----------|------------------|----------------------------------------------------|
| NFR-BL-01 | 項目検索         | バックログ項目を条件で検索可能にする               |
| NFR-BL-02 | 変更履歴保持     | 項目の変更履歴を保持・参照可能にする               |
| NFR-BL-03 | トレーサビリティ | 要求からテスト・リリースまでの関連を追跡可能にする |
