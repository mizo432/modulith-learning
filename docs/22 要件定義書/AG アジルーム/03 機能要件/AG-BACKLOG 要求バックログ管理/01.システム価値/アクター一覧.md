# アクター一覧

要求・プロダクトバックログ管理業務領域でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                         |
|--------|--------------------------|--------------------------------------------------------------|
| ACT-01 | 従業員                   | 課題・要望を登録し、業務ルールや受入条件に関する情報を提供   |
| ACT-02 | プロダクトオーナー（PO） | バックログ項目を作成・明確化・分割し、価値順に並べる         |
| ACT-04 | 開発者                   | 項目をリファインし、技術的な不確実性・依存関係・分割案を検討 |
| ACT-05 | トラッキング担当         | バックログの状況・優先順位・変更履歴を参照                   |
