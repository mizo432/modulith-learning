# バックログ項目属性一覧

要求・プロダクトバックログ管理業務領域で扱う「バックログ項目」の属性を定義します。

| 属性名              | 型          | PK | 必須 | 説明                                           |
|---------------------|-------------|----|------|------------------------------------------------|
| backlog_item_id     | SnowflakeID | *  | Y    | バックログ項目の一意な識別子                   |
| project_id          | UUID        |    | Y    | 所属プロジェクトの識別子                       |
| product_goal_id     | UUID        |    | N    | 関連するプロダクト目標の識別子                 |
| parent_item_id      | UUID        |    | N    | 親項目の識別子（階層構造）                     |
| title               | String      |    | Y    | 項目のタイトル                                 |
| description         | Text        |    | N    | 項目の詳細説明                                 |
| item_type           | Enum        |    | Y    | 項目種別（Epic, Feature, Story, Task, Defect） |
| priority            | Enum        |    | N    | 優先度                                         |
| status              | Enum        |    | Y    | 現在の状態                                     |
| assignee_id         | UUID        |    | N    | 担当者の識別子                                 |
| reporter_id         | UUID        |    | N    | 報告者の識別子                                 |
| estimated_points    | Integer     |    | N    | 推定ストーリーポイント                         |
| acceptance_criteria | Text        |    | N    | 受入条件                                       |
| created_at          | DateTime    |    | Y    | 作成日時                                       |
| updated_at          | DateTime    |    | Y    | 最終更新日時                                   |
