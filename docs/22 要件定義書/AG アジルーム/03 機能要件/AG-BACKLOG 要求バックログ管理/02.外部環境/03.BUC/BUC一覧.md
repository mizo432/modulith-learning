# BUC一覧

要求バックログ管理のビジネスユースケース（BUC）一覧を定義します。

| ID        | BUC名                            | 概要                                                           | 主なアクター   | 関連業務 | 関連ユースケース |
|-----------|----------------------------------|----------------------------------------------------------------|----------------|----------|------------------|
| BUC-BL-01 | 課題・要望の受付・記録           | 従業員から課題・要望を受け付け、背景・影響とともに記録する     | ACT-01, ACT-02 |          |                  |
| BUC-BL-02 | バックログ項目の作成・明確化     | 課題や仮説をEpic・Feature・Storyに変換し、受入条件を明確にする | ACT-02, ACT-04 |          |                  |
| BUC-BL-03 | バックログリファインメント       | 項目の説明・分割・受入条件・依存関係・準備状況を整える         | ACT-02, ACT-04 |          |                  |
| BUC-BL-04 | バックログの優先順位管理         | 項目の順序・優先理由を管理し、変更履歴を追跡する               | ACT-02         |          |                  |
| BUC-BL-05 | フィードバックの対応・追跡       | フィードバックを分類し、対応状況と判断理由を追跡する           | ACT-01, ACT-02 |          |                  |
| BUC-BL-06 | 要求の関連付け・トレーサビリティ | 要求・計画・テスト・リリースの関連と変更経緯を追跡する         | ACT-02, ACT-04 |          |                  |
