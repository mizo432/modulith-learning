# 要求一覧

スプリント実行とインクリメント形成業務領域の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                     | 概要                                                 | 優先度 |
|----------|----------------------------|------------------------------------------------------|--------|
| FR-SP-01 | スプリント管理             | スプリント期間、状態、チームを管理する               | MVP    |
| FR-SP-02 | Sprint Goal管理            | スプリントの目的と関連項目を記録・共有する           | MVP    |
| FR-SP-03 | Sprint Backlog・ボード管理 | 選択項目、作業、状態、担当、依存関係を管理する       | MVP    |
| FR-SP-04 | 障害・依存関係管理         | 阻害要因、影響、担当、解消状況を追跡する             | MVP    |
| FR-SP-05 | 通知・アクティビティ       | メンション、担当変更、期限、判断待ちなどを通知する   | MVP    |
| FR-SP-06 | デイリースクラム支援       | Sprint Goalに向けた状況確認と計画調整を支援する      | 次期   |
| FR-SP-07 | 作業負荷・割り込みの把握   | チームの作業状況や割り込み傾向を改善の材料として示す | 拡張   |

## 非機能要求

| ID        | 要求名           | 概要                                         |
|-----------|------------------|----------------------------------------------|
| NFR-SP-01 | リアルタイム更新 | 作業状態の変更をリアルタイムで反映する       |
| NFR-SP-02 | 通知配信         | 関連するアクターにタイムリーに通知を配信する |
