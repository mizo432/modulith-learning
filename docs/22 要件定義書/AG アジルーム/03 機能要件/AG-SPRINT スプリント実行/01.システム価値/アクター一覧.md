# アクター一覧

スプリント実行とインクリメント形成業務領域でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                  |
|--------|--------------------------|-------------------------------------------------------|
| ACT-02 | プロダクトオーナー（PO） | Sprint Goalを確認し、価値や優先順位について質問に回答 |
| ACT-03 | スクラムマスター（SM）   | スクラムイベントを支援し、障害解消を促進              |
| ACT-04 | 開発者                   | Sprint Backlogを作成・管理し、インクリメントを作成    |
| ACT-05 | トラッキング担当         | スプリントの進捗・障害・成果を参照                    |
