# 業務領域一覧

Agiloomの機能要件を6つのコアサブドメインに基づいて業務領域に分割します。

| ID    | 業務領域名                         | 概要                                                     | 優先度 |
|-------|------------------------------------|----------------------------------------------------------|--------|
| AG-01 | プロダクトディスカバリー           | ユーザー課題を理解し、価値ある機会・目標・仮説を定める   | 中核   |
| AG-02 | 要求・プロダクトバックログ管理     | 課題や仮説を実行可能な項目に変換し、価値順に管理する     | 中核   |
| AG-03 | 価値・要求の優先順位決定           | 価値、Kano品質、リスク、コストを踏まえて投資順を決める   | 中核   |
| AG-04 | スプリント実行とインクリメント形成 | チームの計画と協働を通じて、利用可能な成果を継続的に作る | 中核   |
| AG-05 | プロダクト品質・受入・性能検証     | 期待価値と品質を検証し、安全に利用できる成果を届ける     | 中核   |
| AG-06 | 成果計測・フィードバックによる適応 | 利用結果と学びを目標・バックログ・戦略へ戻す             | 中核   |
