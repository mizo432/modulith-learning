# 外部システム定義 Overview

品質検証業務領域（AG-05）が連携する外部システムを定義します。

## 概要

品質検証は、開発成果が要求・受入条件・品質基準を満たし、ユーザーにとって安全で有用かを検証する業務領域です。本業務領域では、Definition of Done・テストケース・欠陥・性能要件などの情報はAgiloom内で管理します。拡張機能として、Gatlingとの連携により性能テストレポートを取り込むことが想定されます。

## 外部システム一覧

| ID    | 外部システム名 | 連携内容                                       |
|-------|----------------|------------------------------------------------|
| ES-08 | Gatling        | 性能テストの実行条件やレポートを取り込み、要求やリリースと関連づける |

## 補足

- 品質検証で管理する情報（テストケース、受入テスト、欠陥、性能要件など）は、Agiloom内の他の業務領域（バックログ管理、スプリント実行、成果適応）と連携しますが、これらはシステム内部の連携であり、外部システム連携には該当しません。
- Gatling連携は拡張機能であり、MVP範囲外です。将来的にCI/CDツールとの連携により、テスト実行結果を自動取得することが検討される場合があります。
