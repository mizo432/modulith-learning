# ES-08 Gatling 外部システム定義

## 概要

| 項目           | 内容                                                     |
|----------------|----------------------------------------------------------|
| 外部システムID | ES-08                                                    |
| 外部システム名 | Gatling                                                  |
| 説明           | 性能テストの実行条件やレポートを取り込み、要求やリリースと関連づける |
| 種類           | 性能テストツール                                         |
| 接続方法       | API連携（REST）                                          |

## 接続情報

| 項目       | 内容             |
|------------|------------------|
| プロトコル | HTTPS            |
| ポート     | 443              |
| 認証方式   | API Key          |

## 連携内容

| 番号 | 連携項目         | 説明                                                         |
|------|------------------|--------------------------------------------------------------|
| 1    | レポート取り込み | Gatlingの実行結果レポート（JSON）をAgiloomに取り込む          |
| 2    | 実行条件設定     | 性能テストの負荷条件をGatlingに送信                          |
| 3    | 結果関連付け     | 取り込んだレポートを要求やリリースと関連づける                |

## 制約事項

| 番号 | 制約事項         | 説明                                                         |
|------|------------------|--------------------------------------------------------------|
| 1    | MVP範囲外        | Gatling連携は拡張機能であり、MVP範囲外                       |
| 2    | レポート形式     | JSON形式のレポートのみ対応                                   |
| 3    | 連携頻度         | 手動トリガーによる連携（自動連携は将来検討）                 |
