# BUC-QL-04 欠陥の記録・対応

## 概要

再現手順・影響度・状態を管理し、対応を追跡する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:欠陥を特定する;
:欠陥を記録する;
:再現手順を記録する;
:影響度を評価する;
:優先度を設定する;

:担当者を割り当てる;
:修正を行う;

if (修正完了か?) then (はい)
  :修正を検証する;
  if (検証合格か?) then (はい)
    :欠陥を閉じる;
  else (いいえ)
    :再オープンする;
    endif
else (いいえ)
  :対応状況を更新する;
  endif

:対応結果を記録する;

stop
@enduml
```
