# BUC-QL-06 セキュリティ・品質リスク管理

## 概要

品質・セキュリティ上のリスクと対応を記録する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:リスクを特定する;
:リスクを分類する;
:発生確率を評価する;
:影響度を評価する;
:リスクレベルを算出する;

:対応策を策定する;
:担当者を割り当てる;
:期限を設定する;

:対応状況を追跡する;

if (リスクが解消か?) then (はい)
  :リスクを閉じる;
else (いいえ)
  :対応状況を更新する;
  if (エスカレーションが必要か?) then (はい)
    :関係者に報告する;
    endif
  endif

:リスク管理結果を記録する;

stop
@enduml
```
