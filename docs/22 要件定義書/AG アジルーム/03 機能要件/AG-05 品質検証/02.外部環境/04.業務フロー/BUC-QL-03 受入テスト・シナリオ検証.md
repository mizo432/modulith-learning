# BUC-QL-03 受入テスト・シナリオ検証

## 概要

業務シナリオに沿った期待結果と確認結果を記録する。

## アクティビティ図

```plantuml
@startuml
skinparam activity {
  BackgroundColor White
  BorderColor Black
}

start

:テスト対象のシナリオを確認する;
:テスト環境を準備する;
:テストデータを設定する;

:テストを実行する;
:確認結果を記録する;

if (テスト結果は?) then (合格)
  :合格として記録する;
else (不合格)
  :不具合を記録する;
  :再テストを計画する;
  endif

:テスト結果をまとめする;
:関係者に報告する;

stop
@enduml
```
