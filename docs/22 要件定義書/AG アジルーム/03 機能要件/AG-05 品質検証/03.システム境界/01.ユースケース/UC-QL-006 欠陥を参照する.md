# UC-QL-006 欠陥を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-006 |
| ユースケース名 | 欠陥を参照する |
| 英語名 | View Defect |
| 説明 | 登録された欠陥の一覧・詳細を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-QL-04 |
| 外部システム | - |
| 関連画面 | SCR-020（シナリオテスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 欠陥（INF-QL-04）が既に存在すること

## 基本フロー

1. ユーザーが「シナリオテスト管理」画面（SCR-020）にアクセスする
2. システムが欠陥の一覧を表示する
3. ユーザーが特定の欠陥を選択する
4. システムが欠陥の詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 欠陥の一覧・詳細がユーザーに表示される
