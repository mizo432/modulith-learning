# UC-QL-016 Gatlingレポートを取り込む

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-016 |
| ユースケース名 | Gatlingレポートを取り込む |
| 英語名 | Import Gatling Report |
| 説明 | Gatlingの実行条件やレポートを取り込み、要求やリリースと関連づける |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 低 |
| ビジネスユースケース | BUC-QL-05 |
| 外部システム | ES-06（性能テストシステム） |
| 関連画面 | SCR-021（性能テスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ES-06（性能テストシステム）と連携していること

## 基本フロー

1. ユーザーが「性能テスト管理」画面（SCR-021）にアクセスする
2. 「Gatlingレポートを取り込む」ボタンをクリックする
3. ES-06からGatlingの実行条件やレポートを取得する
4. 要求やリリースと関連付ける
5. 入力を保存する
6. システムが性能テスト結果（INF-QL-06）を登録する
7. 取り込み完了メッセージを表示する

## 代替フロー

- **3a. ES-06接続エラーの場合**
  - ES-06への接続に失敗した場合、エラーメッセージを表示する
  - ユーザーは接続状況を確認して再試行する

## 後置条件

- 性能テスト結果（INF-QL-06）がシステムに登録される
- イベント「EVT-QL-011 Gatlingレポートが取り込まれた」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-QL-06 | 性能テスト結果 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-QL-011 | Gatlingレポートが取り込まれた | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 外部システム連携 | ES-06（性能テストシステム）との連携が必要 |
| 2 | 接続権限 | ES-06への接続権限が必要 |
