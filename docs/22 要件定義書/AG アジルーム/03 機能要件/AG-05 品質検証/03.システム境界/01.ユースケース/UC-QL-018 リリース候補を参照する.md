# UC-QL-018 リリース候補を参照する

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-018 |
| ユースケース名 | リリース候補を参照する |
| 英語名 | View Release Candidate |
| 説明 | リリース候補の評価結果を確認する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |

## 前置条件

- ユーザーがシステムにログインしていること
- リリース候補評価（INF-QL-07）が既に存在すること

## 基本フロー

1. ユーザーが「Release Readiness」画面（SCR-019）にアクセスする
2. システムがリリース候補評価の一覧を表示する
3. ユーザーが特定のリリース候補を選択する
4. システムがリリース候補評価の詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし
