# UC-QL-011 テスト結果を記録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-011 |
| ユースケース名 | テスト結果を記録する |
| 英語名 | Record Test Result |
| 説明 | 手動・自動テストの実行結果を保存・追跡する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-QL-03 |
| 外部システム | ES-05（テスト実行システム） |
| 関連画面 | SCR-020（シナリオテスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- テストケース（INF-QL-02）が既に存在すること

## 基本フロー

1. ユーザーが「シナリオテスト管理」画面（SCR-020）にアクセスする
2. 「テスト結果を記録」ボタンをクリックする
3. テスト結果（成功/失敗）、実行環境、実行時間を入力する
4. ES-05から自動テスト結果を取得する（自動テストの場合）
5. 結果を保存する
6. システムがテスト実行結果（INF-QL-03）を登録する
7. 記録完了メッセージを表示する

## 代替フロー

- **4a. ES-05接続エラーの場合**
  - ES-05への接続に失敗した場合、エラーメッセージを表示する
  - ユーザーは手動で結果を入力して再試行する

## 後置条件

- テスト実行結果（INF-QL-03）がシステムに登録される
- イベント「EVT-QL-008 テスト結果が記録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-QL-02 | テストケース | 関連付ける情報 |
| INF-QL-03 | テスト実行結果 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-QL-008 | テスト結果が記録された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | テスト結果は必須入力 |
| 2 | 外部システム連携 | ES-05（テスト実行システム）との連携が必要 |
