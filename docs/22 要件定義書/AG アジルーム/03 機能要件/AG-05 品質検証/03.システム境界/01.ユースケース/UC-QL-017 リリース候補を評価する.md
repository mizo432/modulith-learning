# UC-QL-017 リリース候補を評価する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-017 |
| ユースケース名 | リリース候補を評価する |
| 英語名 | Evaluate Release Candidate |
| 説明 | リリース候補の品質・リスク・依存関係を評価する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-QL-06 |
| 外部システム | - |
| 関連画面 | SCR-019（Release Readiness） |

## 前置条件

- ユーザーがシステムにログインしていること
- リリース候補が既に存在すること

## 基本フロー

1. ユーザーが「Release Readiness」画面（SCR-019）にアクセスする
2. 「リリース候補を評価」ボタンをクリックする
3. 品質、リスク、依存関係を評価する
4. 評価結果を入力する
5. 入力を保存する
6. システムがリリース候補評価（INF-QL-07）を登録する
7. 評価完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- リリース候補評価（INF-QL-07）がシステムに登録される
- イベント「EVT-QL-012 リリース候補が評価された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-QL-07 | リリース候補評価 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-QL-012 | リリース候補が評価された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 品質、リスク、依存関係は必須評価 |
