# UC-QL-015 性能テスト結果を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-015 |
| ユースケース名 | 性能テスト結果を参照する |
| 英語名 | View Performance Test Result |
| 説明 | 性能テストのレポートを確認する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-QL-05 |
| 外部システム | ES-06（性能テストシステム） |
| 関連画面 | SCR-021（性能テスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 性能テスト結果（INF-QL-06）が既に存在すること

## 基本フロー

1. ユーザーが「性能テスト管理」画面（SCR-021）にアクセスする
2. システムが性能テスト結果の一覧を表示する
3. ユーザーが特定の性能テスト結果を選択する
4. システムが性能テスト結果の詳細とレポートを表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- 性能テスト結果の詳細とレポートがユーザーに表示される
