# UC-QL-009 テストケースを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-009 |
| ユースケース名 | テストケースを参照する |
| 英語名 | View Test Case |
| 説明 | 登録されたテストケースの一覧・詳細を確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-QL-02 |
| 外部システム | - |
| 関連画面 | SCR-020（シナリオテスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- テストケース（INF-QL-02）が既に存在すること

## 基本フロー

1. ユーザーが「シナリオテスト管理」画面（SCR-020）にアクセスする
2. システムがテストケースの一覧を表示する
3. ユーザーが特定のテストケースを選択する
4. システムがテストケースの詳細を表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- テストケースの一覧・詳細がユーザーに表示される
