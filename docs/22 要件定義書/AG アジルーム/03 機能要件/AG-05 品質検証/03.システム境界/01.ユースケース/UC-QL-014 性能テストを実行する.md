# UC-QL-014 性能テストを実行する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-014 |
| ユースケース名 | 性能テストを実行する |
| 英語名 | Execute Performance Test |
| 説明 | 性能要件・負荷条件を満たすか検証する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-QL-05 |
| 外部システム | ES-06（性能テストシステム） |
| 関連画面 | SCR-021（性能テスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- 性能要件（INF-QL-05）が既に定義されていること
- ES-06（性能テストシステム）と連携していること

## 基本フロー

1. ユーザーが「性能テスト管理」画面（SCR-021）にアクセスする
2. 「性能テストを実行」ボタンをクリックする
3. 負荷プロファイルを選択する
4. ES-06にテスト実行を依頼する
5. ES-06からテスト結果を取得する
6. システムが性能テスト結果（INF-QL-06）を登録する
7. 実行完了メッセージを表示する

## 代替フロー

- **4a. ES-06接続エラーの場合**
  - ES-06への接続に失敗した場合、エラーメッセージを表示する
  - ユーザーは接続状況を確認して再試行する

## 後置条件

- 性能テスト結果（INF-QL-06）がシステムに登録される
- イベント「EVT-QL-010 性能テストが実行された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-QL-05 | 性能要件 | 参照対象の情報 |
| INF-QL-06 | 性能テスト結果 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-QL-010 | 性能テストが実行された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 外部システム連携 | ES-06（性能テストシステム）との連携が必要 |
| 2 | 接続権限 | ES-06への接続権限が必要 |
