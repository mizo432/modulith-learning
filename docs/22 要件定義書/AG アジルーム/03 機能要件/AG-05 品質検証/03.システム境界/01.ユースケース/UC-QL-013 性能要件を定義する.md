# UC-QL-013 性能要件を定義する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-013 |
| ユースケース名 | 性能要件を定義する |
| 英語名 | Define Performance Requirement |
| 説明 | p95等の性能要件、負荷条件、合格基準を設定する |
| 関連アクター | ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-QL-05 |
| 外部システム | - |
| 関連画面 | SCR-021（性能テスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「性能テスト管理」画面（SCR-021）にアクセスする
2. 「性能要件を定義」ボタンをクリックする
3. p95等の性能要件、負荷条件、合格基準を入力する
4. 入力を保存する
5. システムが性能要件（INF-QL-05）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 性能要件（INF-QL-05）がシステムに登録される
- イベント「EVT-QL-009 性能要件が定義された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-QL-05 | 性能要件 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-QL-009 | 性能要件が定義された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 性能要件、負荷条件、合格基準は必須入力 |
| 2 | 数値範囲 | p95は正の整数で入力 |
