# UC-QL-004 欠陥を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-004 |
| ユースケース名 | 欠陥を登録する |
| 英語名 | Register Defect |
| 説明 | 再現手順、影響度、状態、関連項目を記録する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-QL-04 |
| 外部システム | - |
| 関連画面 | SCR-020（シナリオテスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「シナリオテスト管理」画面（SCR-020）にアクセスする
2. 「欠陥を登録」ボタンをクリックする
3. 再現手順、影響度、状態、関連項目を入力する
4. 入力を保存する
5. システムが欠陥（INF-QL-04）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 欠陥（INF-QL-04）がシステムに登録される
- イベント「EVT-QL-003 欠陥が登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-QL-04 | 欠陥 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-QL-003 | 欠陥が登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 再現手順、影響度は必須入力 |
| 2 | 文字数制限 | 再現手順は2000文字以内 |
