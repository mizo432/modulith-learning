# UC-QL-012 テスト結果を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-012 |
| ユースケース名 | テスト結果を参照する |
| 英語名 | View Test Result |
| 説明 | テスト実行結果・カバレッジを確認する |
| 関連アクター | ACT-01（従業員）、ACT-02（プロダクトオーナー）、ACT-04（開発チーム）、ACT-05（トラッキング担当） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-QL-03 |
| 外部システム | ES-05（テスト実行システム） |
| 関連画面 | SCR-019（Release Readiness） |

## 前置条件

- ユーザーがシステムにログインしていること
- テスト実行結果（INF-QL-03）が既に存在すること

## 基本フロー

1. ユーザーが「Release Readiness」画面（SCR-019）にアクセスする
2. システムがテスト実行結果の一覧を表示する
3. ユーザーが特定のテスト結果を選択する
4. システムがテスト実行結果の詳細とカバレッジを表示する
5. ユーザーが内容を確認する

## 代替フロー

- なし

## 後置条件

- テスト実行結果の詳細とカバレッジがユーザーに表示される
