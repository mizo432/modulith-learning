# UC-QL-007 テストケースを作成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-007 |
| ユースケース名 | テストケースを作成する |
| 英語名 | Create Test Case |
| 説明 | 要求や受入条件に関連づけたテストケースを定義する |
| 関連アクター | ACT-02（プロダクトオーナー）、ACT-04（開発チーム） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-QL-02 |
| 外部システム | - |
| 関連画面 | SCR-020（シナリオテスト管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- バックログ項目が既に存在すること

## 基本フロー

1. ユーザーが「シナリオテスト管理」画面（SCR-020）にアクセスする
2. 「テストケースを作成」ボタンをクリックする
3. テストケース名、手順、期待結果、関連項目を入力する
4. 入力を保存する
5. システムがテストケース（INF-QL-02）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- テストケース（INF-QL-02）がシステムに登録される
- イベント「EVT-QL-005 テストケースが作成された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-QL-02 | テストケース | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-QL-005 | テストケースが作成された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | テストケース名、手順、期待結果は必須入力 |
| 2 | 文字数制限 | 手順は2000文字以内 |
