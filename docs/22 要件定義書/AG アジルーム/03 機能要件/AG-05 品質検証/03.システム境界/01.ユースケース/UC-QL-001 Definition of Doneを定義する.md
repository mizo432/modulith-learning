# UC-QL-001 Definition of Doneを定義する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-QL-001 |
| ユースケース名 | Definition of Doneを定義する |
| 英語名 | Define Definition of Done |
| 説明 | チームの完成基準を定義・共有する |
| 関連アクター | ACT-03（スクラムマスター）、ACT-04（開発チーム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-QL-01 |
| 外部システム | - |
| 関連画面 | SCR-019（Release Readiness） |

## 前置条件

- ユーザーがシステムにログインしていること

## 基本フロー

1. ユーザーが「Release Readiness」画面（SCR-019）にアクセスする
2. 「Definition of Doneを定義」ボタンをクリックする
3. 完成基準の項目（コードレビュー、テスト、ドキュメントなど）を入力する
4. 入力を保存する
5. システムがDefinition of Done（INF-QL-01）を登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- Definition of Done（INF-QL-01）がシステムに登録される
- イベント「EVT-QL-001 Definition of Doneが定義された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-QL-01 | Definition of Done | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-QL-001 | Definition of Doneが定義された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 完成基準の項目は必須入力 |
| 2 | 文字数制限 | 各項目は500文字以内 |
