# 要求一覧

プロダクト品質・受入・性能検証業務領域（AG-05）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-QL-01 | Definition of Done管理       | チームの完成基準を定義・更新・参照する                   | MVP    |
| FR-QL-02 | 欠陥管理                     | 再現手順、影響度、状態、関連項目を記録・更新・参照する   | MVP    |
| FR-QL-03 | テストケース管理             | 要求や受入条件に関連づけたテストケースを定義・更新・参照する | 次期   |
| FR-QL-04 | 受入テスト実行               | 業務シナリオに沿った期待結果と確認結果を記録する          | 次期   |
| FR-QL-05 | テスト結果記録               | 手動・自動テストの実行結果を保存・追跡する               | 次期   |
| FR-QL-06 | 性能要件定義                 | p95等の性能要件、負荷条件、合格基準を設定する            | 次期   |
| FR-QL-07 | 性能テスト実行               | 性能要件・負荷条件を満たすか検証する                     | 次期   |
| FR-QL-08 | Gatlingレポート取り込み      | Gatlingの実行条件やレポートを取り込み、要求やリリースと関連づける | 拡張   |
| FR-QL-09 | セキュリティリスク管理       | 品質・セキュリティ上のリスクと対応を記録・更新・参照する | 次期   |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-QL-01 | テスト実行性能                 | 大量のテストケースを効率的に実行できる |
| NFR-QL-02 | 外部システム連携               | テスト実行ツールや性能テストツールと連携できる |
| NFR-QL-03 | 監査機能                       | テスト結果や欠陥情報を追跡できる       |
