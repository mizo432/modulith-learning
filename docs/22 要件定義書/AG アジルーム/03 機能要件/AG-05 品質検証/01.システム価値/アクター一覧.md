# アクター一覧

プロダクト品質・受入・性能検証業務領域（AG-05）でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                 |
|--------|--------------------------|------------------------------------------------------|
| ACT-01 | 従業員                   | レビューに参加し、利用者視点のフィードバックを提供   |
| ACT-02 | プロダクトオーナー（PO） | 成果・フィードバックを検査し、目標・バックログを更新 |
| ACT-03 | スクラムマスター（SM）   | レトロスペクティブを支援し、改善アクションを追跡     |
| ACT-04 | 開発者                   | 改善を実行し、効果を確かめる                         |
| ACT-05 | トラッキング担当         | 進捗・成果・リスク・改善状況を参照                   |
| ACT-06 | システム管理者           | セキュリティリスクを管理                             |
