# 情報一覧

プロダクト品質・受入・性能検証業務領域で扱う情報を定義します。

| ID        | 情報名                   | 情報種類 | 履歴管理要 | 実現方法   | 説明                                                   |
|-----------|--------------------------|----------|------------|------------|--------------------------------------------------------|
| INF-QL-01 | Definition of Done       | リソース | Y          | DB         | チームの完成基準                                       |
| INF-QL-02 | テストケース             | リソース | Y          | DB         | 要求や受入条件に関連づけたテストケース                 |
| INF-QL-03 | テスト実行結果           | リソース | Y          | DB         | 手動・自動テストの実行結果                             |
| INF-QL-04 | 欠陥                     | リソース | Y          | DB         | 再現手順、影響度、状態                                 |
| INF-QL-05 | 性能要件                 | リソース | Y          | DB         | p95等の性能要件、負荷条件、合格基準                    |
| INF-QL-06 | 性能テスト結果           | リソース | Y          | DB         | 性能テストの実行結果                                   |
| INF-QL-07 | セキュリティ・品質リスク | リソース | Y          | DB         | 品質・セキュリティ上のリスクと対応                     |
| INF-QL-08 | テストケースと項目       | 対応表   | N          | DB         | テストケースとバックログ項目の関連                     |
| INF-QL-09 | 欠陥と項目               | 対応表   | N          | DB         | 欠陥と関連するバックログ項目                           |
| INF-QL-10 | テスト種別               | 対照表   | N          | DB and enum | 単体、統合、シナリオ、受入、性能                       |
| INF-QL-11 | 欠陥状態                 | 対照表   | N          | DB and enum | 新規、対応中、修正済み、クローズド、却下               |
| INF-QL-12 | 影響度                   | 対照表   | N          | DB and enum | 致命、重大、通常、軽微                                 |
