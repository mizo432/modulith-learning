# Release Planning

Release Planning画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-018 |
| 画面名           | Release Planning |
| 説明             | Release範囲、マイルストーン、依存関係、予測、リスクを管理する |
| 関連ユースケース | (なし) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、Release総数、予定Releaseを表示 |
| 検索・フィルター | 状態、期間で検索・絞り込み |
| メインコンテンツ | Release一覧表または詳細情報を表示 |
| サイドバー | マイルストーン、依存関係、リスクを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Release名 | 文字列 | はい | Releaseの名前 |
| 2 | バージョン | 文字列 | はい | バージョン番号 |
| 3 | 予定リリース日 | 日付 | はい | 予定のリリース日 |
| 4 | 状態 | 選択 | はい | 状態（計画、準備中、リリース済み） |
| 5 | 範囲 | テキスト | はい | Releaseに含まれる範囲 |
| 6 | マイルストーン | テキスト | いいえ | 中間目標 |
| 7 | 依存関係 | 複数選択 | いいえ | 依存する他のRelease |
| 8 | 予測 | テキスト | いいえ | 予測される成果 |
| 9 | リスク | テキスト | いいえ | 見込まれるリスク |
| 10 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Releaseを参照 | 登録されたReleaseを確認する |
| 2 | 検索 | 条件に合致するReleaseを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | バージョンの一意性 | 同じバージョン番号は重複登録できない |
