# シナリオテスト管理

シナリオテスト管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-020 |
| 画面名           | シナリオテスト管理 |
| 説明             | 複数Storyを横断する業務シナリオ、手順、実行履歴を管理する |
| 関連ユースケース | UC-QL-004, UC-QL-005, UC-QL-006, UC-QL-007, UC-QL-008, UC-QL-009, UC-QL-010, UC-QL-011 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、テストケース総数、実行済み数を表示 |
| 検索・フィルター | 状態、種類で検索・絞り込み |
| メインコンテンツ | テストケース一覧表または詳細情報を表示 |
| サイドバー | 状態別集計、欠陥一覧を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | テストケース名 | 文字列 | はい | テストケースの名前 |
| 2 | 関連Story | 複数選択 | いいえ | 関連するユーザーストーリー |
| 3 | 受入条件 | テキスト | はい | 関連する受入条件 |
| 4 | テスト手順 | テキスト | はい | テストの実行手順 |
| 5 | 期待結果 | テキスト | はい | 期待される結果 |
| 6 | 実行結果 | テキスト | いいえ | 実際の実行結果 |
| 7 | 判定 | 選択 | いいえ | 判定結果（合格、不合格、未実行） |
| 8 | 欠陥 | テキスト | いいえ | 発見された欠陥 |
| 9 | 欠陥状態 | 選択 | いいえ | 欠陥の状態（新規、修正中、解決） |
| 10 | 影響度 | 選択 | いいえ | 欠陥の影響度（大、中、小） |
| 11 | 再現手順 | テキスト | いいえ | 欠陥の再現手順 |
| 12 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 欠陥を登録 | 発見された欠陥を記録する |
| 2 | 欠陥を更新 | 欠陥の状態や対応状況を更新する |
| 3 | 欠陥を参照 | 登録された欠陥を確認する |
| 4 | テストケースを作成 | 新規テストケースを定義する |
| 5 | テストケースを更新 | 既存のテストケースを修正する |
| 6 | テストケースを参照 | 登録されたテストケースを確認する |
| 7 | 受入テストを実行する | 業務シナリオに沿ってテストを実行する |
| 8 | テスト結果を記録する | テスト実行結果を保存する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 判定の必須 | テスト実行後は判定が必須 |
| 2 | 欠陥の関連 | 不合格の場合は欠陥登録が必須 |
