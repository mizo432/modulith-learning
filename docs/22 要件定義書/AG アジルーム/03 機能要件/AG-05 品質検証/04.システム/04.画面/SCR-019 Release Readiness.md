# Release Readiness

Release Readiness画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-019 |
| 画面名           | Release Readiness |
| 説明             | 品質・性能・運用・依存関係などのリリース準備状況を評価する |
| 関連ユースケース | UC-QL-001, UC-QL-002, UC-QL-003, UC-QL-012, UC-QL-017, UC-QL-018, UC-QL-019 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Release名、バージョン、準備状況を表示 |
| ナビゲーション | 品質、性能、セキュリティ、依存関係のタブ切り替え |
| メインコンテンツ | 選択したタブに対応する評価結果を表示 |
| サイドバー | Definition of Done、テスト結果概要を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Release名 | 文字列 | はい | 対象Releaseの名前 |
| 2 | バージョン | 文字列 | はい | バージョン番号 |
| 3 | Definition of Done | テキスト | はい | 完成の定義 |
| 4 | 品質評価 | 選択 | いいえ | 品質の評価結果（合格、不合格、未評価） |
| 5 | 性能評価 | 選択 | いいえ | 性能の評価結果（合格、不合格、未評価） |
| 6 | セキュリティリスク | テキスト | いいえ | 残存するセキュリティリスク |
| 7 | リスク状態 | 選択 | いいえ | リスクの状態（未対応、対応中、解決） |
| 8 | テスト結果 | テキスト | いいえ | テスト実行結果の概要 |
| 9 | 依存関係 | 複数選択 | いいえ | 依存する外部システム |
| 10 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Definition of Doneを定義する | 完成基準を定義する |
| 2 | Definition of Doneを更新する | 完成基準を修正する |
| 3 | Definition of Doneを参照する | 現在の完成基準を確認する |
| 4 | テスト結果を参照する | テスト実行結果を確認する |
| 5 | セキュリティリスクを登録する | 品質・セキュリティ上のリスクを記録する |
| 6 | セキュリティリスクを更新する | リスクの対応状況を更新する |
| 7 | セキュリティリスクを参照する | 登録されたリスクを確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 評価の必須 | リリースするには全評価項目が合格である必要がある |
