# 画面属性一覧

Release Readinessの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-019 |
| 画面名 | Release Readiness |
| 説明 | 品質・性能・運用・依存関係などのリリース準備状況を評価する |
| 関連ユースケース | UC-QL-001, UC-QL-002, UC-QL-003, UC-QL-012, UC-QL-017, UC-QL-018, UC-QL-019 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | Definition of Done | 入力 | String | はい | - | 最大2000文字 | 完成基準 |
| 2 | テスト結果 | リンク | String | いいえ | - | - | テスト実行結果 |
| 3 | セキュリティリスク | リンク | String | いいえ | - | - | セキュリティ・品質リスク |
| 4 | 準備状況 | 表示 | Enum | はい | - | 未評価/準備中/準備完了 | リリース準備状況 |
| 5 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

|------|--------|------|--------------|
