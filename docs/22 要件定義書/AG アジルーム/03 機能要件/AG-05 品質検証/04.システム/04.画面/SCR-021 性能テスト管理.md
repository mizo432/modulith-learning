# 性能テスト管理

性能テスト管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-021 |
| 画面名           | 性能テスト管理 |
| 説明             | 性能要件、負荷プロファイル、実行、測定結果、評価を管理する |
| 関連ユースケース | UC-QL-013, UC-QL-014, UC-QL-015, UC-QL-016 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | プロダクト名、性能テスト総数、最新実行結果を表示 |
| 検索・フィルター | 状態、種類で検索・絞り込み |
| メインコンテンツ | 性能テスト一覧表または詳細情報を表示 |
| サイドバー | 性能要件、Gatlingレポート概要を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | テスト名 | 文字列 | はい | 性能テストの名前 |
| 2 | 性能要件 | テキスト | はい | 性能の要件（例: p95応答時間） |
| 3 | 負荷条件 | テキスト | はい | 負荷テストの条件 |
| 4 | 合格基準 | テキスト | はい | 合格の基準値 |
| 5 | 実行日 | 日付 | いいえ | テストの実行日 |
| 6 | 実行結果 | テキスト | いいえ | テストの実行結果 |
| 7 | 評価 | 選択 | いいえ | 評価結果（合格、不合格、未実行） |
| 8 | Gatlingレポート | 文字列 | いいえ | Gatlingレポートの参照 |
| 9 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 性能要件を定義する | 性能要件と合格基準を設定する |
| 2 | 性能テストを実行する | 性能テストを実行する |
| 3 | 性能テスト結果を参照する | 性能テストのレポートを確認する |
| 4 | Gatlingレポートを取り込む | Gatlingの実行結果を取り込む |
| 5 | 検索 | 条件に合致するテストを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 合格基準の必須 | 性能要件には合格基準が必須 |
