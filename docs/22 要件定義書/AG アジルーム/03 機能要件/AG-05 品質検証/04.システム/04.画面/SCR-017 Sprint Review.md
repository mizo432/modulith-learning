# Sprint Review

Sprint Review画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-017 |
| 画面名           | Sprint Review |
| 説明             | 成果を確認し、フィードバックとバックログ候補を記録する |
| 関連ユースケース | UC-LR-001, UC-LR-002, UC-LR-013, UC-LR-014, UC-LR-015 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | Sprint名、期間、参加者を表示 |
| ナビゲーション | 成果、フィードバック、バックログ候補のタブ切り替え |
| メインコンテンツ | 選択したタブに対応する詳細情報を表示・編集 |
| サイドバー | 関連Sprint、利用者レビューを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | Sprint名 | 文字列 | はい | 対象Sprintの名前 |
| 2 | 実施日 | 日付 | はい | Reviewの実施日 |
| 3 | 参加者 | 複数選択 | はい | 参加したメンバー |
| 4 | 成果 | テキスト | はい | 達成した成果 |
| 5 | フィードバック | テキスト | いいえ | 得られたフィードバック |
| 6 | 決定事項 | テキスト | いいえ | 決定された事項 |
| 7 | 未解決事項 | テキスト | いいえ | 未解決の事項 |
| 8 | バックログ候補 | テキスト | いいえ | 新規バックログ候補 |
| 9 | 利用者レビュー対象者 | 文字列 | いいえ | レビュー対象者 |
| 10 | 利用者レビューシナリオ | テキスト | いいえ | レビューシナリオ |
| 11 | 利用者レビュー結果 | テキスト | いいえ | レビュー結果 |
| 12 | 備考 | テキスト | いいえ | その他の補足情報 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | Sprint Reviewを記録 | 成果とフィードバックを記録する |
| 2 | Sprint Reviewを参照 | 過去のReviewの内容を確認する |
| 3 | 利用者レビューを計画する | レビュー対象者やシナリオを設定する |
| 4 | 利用者レビューを実行する | レビューを実施し結果を記録する |
| 5 | 利用者レビュー結果を参照する | レビュー結果を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | Sprint Reviewの記録はプロダクトオーナーとチームのみ可能 |
| 2 | 実施日の一意性 | 同じSprintの実施日は1回のみ |
