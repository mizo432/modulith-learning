# 画面属性一覧

シナリオテスト管理の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-020 |
| 画面名 | シナリオテスト管理 |
| 説明 | 複数Storyを横断する業務シナリオ、手順、実行履歴を管理する |
| 関連ユースケース | UC-QL-004, UC-QL-005, UC-QL-006, UC-QL-007, UC-QL-008, UC-QL-009, UC-QL-010, UC-QL-011 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | シナリオ名 | 入力 | String | はい | - | 最大255文字 | テストシナリオ名 |
| 2 | 手順 | 入力 | String | はい | - | 最大2000文字 | テスト手順 |
| 3 | 期待結果 | 入力 | String | はい | - | 最大1000文字 | 期待される結果 |
| 4 | 確認結果 | 入力 | String | いいえ | - | 最大1000文字 | 実際の確認結果 |
| 5 | 判定 | 選択 | Enum | いいえ | - | 合格/不合格/未実行 | テスト判定 |
| 6 | 欠陥 | リンク | String | いいえ | - | - | 関連する欠陥 |
| 7 | テストケース | リンク | String | いいえ | - | - | 関連するテストケース |
| 8 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |
| 9 | 判定フィルター | 選択 | Enum | いいえ | すべて | - | 判定で絞り込む |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
