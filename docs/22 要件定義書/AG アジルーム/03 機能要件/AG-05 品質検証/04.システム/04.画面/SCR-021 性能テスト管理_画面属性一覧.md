# 画面属性一覧

性能テスト管理の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-021 |
| 画面名 | 性能テスト管理 |
| 説明 | 性能要件、負荷プロファイル、実行、測定結果、評価を管理する |
| 関連ユースケース | UC-QL-013, UC-QL-014, UC-QL-015, UC-QL-016 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 性能要件 | 入力 | String | はい | - | 最大1000文字 | p95等の性能要件 |
| 2 | 負荷条件 | 入力 | String | はい | - | 最大500文字 | 負荷プロファイル |
| 3 | 合格基準 | 入力 | Double | はい | - | 0以上 | 合格基準値 |
| 4 | 測定結果 | 表示 | Double | いいえ | - | 0以上 | 測定された値 |
| 5 | 評価 | 表示 | Enum | いいえ | - | 合格/不合格/未実行 | 性能評価 |
| 6 | Gatlingレポート | リンク | String | いいえ | - | - | Gatlingの実行レポート |
| 7 | 検索キーワード | 入力 | String | いいえ | - | 最大100文字 | 検索キーワード |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
