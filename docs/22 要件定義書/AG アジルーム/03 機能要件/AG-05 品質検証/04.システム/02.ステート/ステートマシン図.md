# ステートマシン図

品質検証業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、AG-05 品質検証業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図（英語版）

```plantuml
@startuml
title Quality Verification State Model Diagram
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

' Defect states
state "New" as New_DF <<entry>>
state "Confirmed" as Confirmed_DF
state "InProgress" as InProgress_DF
state "Fixed" as Fixed_DF
state "Closed" as Closed_DF <<exit>>
state "Rejected" as Rejected_DF <<exit>>

' Test Case states
state "Preparing" as Preparing_TC <<entry>>
state "Active" as Active_TC
state "Inactive" as Inactive_TC <<exit>>

' Test Execution Result states
state "Scheduled" as Scheduled_TR <<entry>>
state "Running" as Running_TR
state "Passed" as Passed_TR <<exit>>
state "Failed" as Failed_TR <<exit>>

' Defect transitions
New_DF --> Confirmed_DF : Defect Updated (UC-QL-005)
Confirmed_DF --> InProgress_DF : Defect Updated (UC-QL-005)
InProgress_DF --> Fixed_DF : Defect Updated (UC-QL-005)
Fixed_DF --> Closed_DF : Defect Updated (UC-QL-005)
Confirmed_DF --> Rejected_DF : Defect Updated (UC-QL-005)

' Test Case transitions
Preparing_TC --> Active_TC : Test Case Updated (UC-QL-008)
Active_TC --> Inactive_TC : Test Case Updated (UC-QL-008)

' Test Execution Result transitions
Scheduled_TR --> Running_TR : Test Results Recorded (UC-QL-011)
Running_TR --> Passed_TR : Test Results Recorded (UC-QL-011)
Running_TR --> Failed_TR : Test Results Recorded (UC-QL-011)
@enduml
```

## 4. 状態一覧

| 状態名 (ID)       | 英語名        | 対象情報         | 説明                                     |
|-------------------|---------------|------------------|------------------------------------------|
| 新規 (ST-QL-01)   | New           | 欠陥             | 報告されたが、まだ確認されていない       |
| 確認済み (ST-QL-02) | Confirmed   | 欠陥             | 再現性が確認され、対応が決定された       |
| 対応中 (ST-QL-03)  | InProgress   | 欠陥             | 修正作業が進行中                         |
| 修正済み (ST-QL-04) | Fixed       | 欠陥             | 修正が完了し、検証待ち                   |
| クローズド (ST-QL-05) | Closed    | 欠陥             | 修正が検証され、完了した                 |
| 却下 (ST-QL-06)   | Rejected      | 欠陥             | 欠陥ではないと判断された                 |
| 準備中 (ST-QL-07)  | Preparing    | テストケース     | 作成中またはレビュー中                   |
| 有効 (ST-QL-08)   | Active        | テストケース     | 実行可能な状態                           |
| 無効 (ST-QL-09)   | Inactive      | テストケース     | 不要になったまたは古いテストケース       |
| 実行予定 (ST-QL-10) | Scheduled   | テスト実行結果   | テストが計画されたが、まだ実行されていない |
| 実行中 (ST-QL-11)  | Running      | テスト実行結果   | テスト実行が進行中                       |
| 合格 (ST-QL-12)   | Passed        | テスト実行結果   | テストが合格した                         |
| 不合格 (ST-QL-13)  | Failed       | テスト実行結果   | テストが不合格だった                     |
