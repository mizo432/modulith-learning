# 性能テストが実行された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-QL-010 |
| イベント名 | 性能テストが実行された |
| 説明 | 性能要件・負荷条件を満たすか検証された |
| 関連ユースケース | UC-QL-014 |
| 関連情報 | INF-QL-06 |
| 集約 | 性能テスト結果 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 性能要件 | 文字列 | はい | 関連する性能要件 |
| 結果 | 選択 | はい | テスト結果（合格、不合格） |
| 測定値 | テキスト | いいえ | 測定された値 |
