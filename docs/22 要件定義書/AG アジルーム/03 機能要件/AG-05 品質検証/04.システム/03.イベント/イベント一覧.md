# イベント一覧

プロダクト品質・受入・性能検証業務領域で発生するドメインイベントを定義します。

イベントソーシングガイドラインに従い、過去形の名詞句で命名し、不変（Immutable）な値オブジェクトとして実装します。

| EVT-QL-004 | 欠陥が更新された               | 欠陥の状態・対応状況・解決方法が修正された                              | UC-QL-005        | INF-QL-04 | 欠陥                     |
