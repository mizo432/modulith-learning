イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-QL-008 |
| イベント名 | テスト結果が記録された |
| 説明 | 手動・自動テストの実行結果が保存・追跡された |
| 関連ユースケース | UC-QL-011 |
| 関連情報 | INF-QL-03 |
