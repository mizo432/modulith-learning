# 外部システム一覧

ロードマップ管理業務領域（AG-07）で連携する外部システムを定義します。

ロードマップ管理は既存のプランニング情報（スプリント・リリース・機能・ストーリー）を参照しますが、外部システムとの連携は不要です。PNGエクスポートはシステム内で完結します。

|----------------|----------------|------|--------------|
