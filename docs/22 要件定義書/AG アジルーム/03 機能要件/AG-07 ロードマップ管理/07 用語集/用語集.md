# 用語集

ロードマップ管理業務領域（AG-07）の用語を定義します。

## ビジネス用語

| 用語 | 説明 |
|------|------|
| ロードマップ | プロダクトの機能進化を時間軸上で計画・可視化する図。チームやステークホルダーと共有するためのツール |
| ライブロードマップ | プランニング情報から自動的に生成されるロードマップ。プロジェクト作成時にデフォルトで作成される |
| スナップショット | 指定した時点でのライブロードマップの状態をキャプチャしたもの。内容は変更不可 |
| 編集可能ロードマップ | 手動で自由に描画・編集できるロードマップ。代替案を検討するために使用 |
| 機能 | プロダクトの機能単位。アクティブな機能は実線の長方形で、非アクティブな機能は破線で表示 |
| アクティブ | あるスプリント内で、その機能に関連するストーリーポイントが少なくとも1つ計画済みまたは完了している状態 |
| スプリント | 開発期間。ロードマップの最上部に表示 |
| リリース | プロダクトのリリース期間。ロードマップはすべてのリリース期間にわたって展開 |
| ストーリー | 機能に関連する作業単位。完了したストーリーの割合で進捗を表示 |
| イベント | プロダクトの重要な日程をマークするもの。プロダクト全体または特定の機能に関連 |
| 時間軸 | ロードマップの横軸。スクロール・ピンチ・ドロップダウンでスケールを調整可能 |
| 作業期間 | 編集可能ロードマップで機能に設定する期間。追加・移動・拡張が可能 |
| PNGエクスポート | ロードマップをPNG画像として出力する機能。iceScrum外でも共有可能 |

## システム用語

| 用語 | 説明 |
|------|------|
| ロードマップ種類 | ロードマップの種類を識別するコード。ライブ・スナップショット・編集可能の3種類 |
| 機能の非表示 | 現時点では関係のない機能をロードマップから非表示にする設定 |
| 進捗状況 | 現在進行中の期間について、完了したストーリーの割合を表示 |
| ステータスバー | 各機能のアクティブな期間ごとに、計画されているストーリーの数を表示するバー |
| 今日の日付 | ロードマップに表示される細い黄色の縦線。現在の日付を示す |
| イベント形状 | イベントの表示形状。分類に応じて選択可能 |
