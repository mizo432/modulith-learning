# 概要

本ドキュメントは、ロードマップ管理業務領域（AG-07）の機能要件の概要を定義します。

ロードマップ管理は、プロダクトの機能進化を計画し、チームやステークホルダーと共有するためのロードマップを作成・管理する業務領域です。ライブロードマップ、スナップショット、編集可能ロードマップの3種類をサポートし、PNGエクスポートによる共有を可能にします。

## RDRA 4レイヤー

1. **システム価値レイヤー**: ロードマップ管理が実現すべき価値とアクターを定義する
2. **外部環境レイヤー**: 業務、BUC、アクティビティを定義する
3. **システム境界レイヤー**: ユースケース、画面、イベントを定義する
4. **システムレイヤー**: 情報、状態、条件、バリエーションを定義する
