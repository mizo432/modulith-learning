# システム価値

ロードマップ管理業務領域（AG-07）が実現すべき価値を定義します。

ロードマップ管理は、プロダクトの機能進化を時間軸上で可視化し、チームやステークホルダーと共有するための基盤を提供します。ライブロードマップによりリアルタイムのプランニング状況を把握でき、スナップショットで戦略変更の履歴を追跡でき、編集可能ロードマップで代替案を検討できます。PNGエクスポートによりiceScrum外でも簡単に共有できるため、プロダクトのビジョンを定義・共有するのを支援します。

## 機能要求

- ライブロードマップの自動生成と表示
- ロードマップのスナップショット取得
- 編集可能ロードマップの作成・編集
- ロードマップ上のイベント追加・管理
- 機能のアクティブ/非アクティブ表示
- 時間軸のスクロール・ズーム操作
- 機能の非表示設定
- ロードマップのPNGエクスポート
- スプリント・リリースの可視化
- 機能の進捗状況表示

## 非機能要求

- リアルタイム反映（ライブロードマップはプランニング情報と連動）
- 視認性（時間軸上でスプリント・リリース・機能を明確に区別）
- 共有性（PNGエクスポートで外部共有可能）
- 柔軟性（複数のロードマップを並行管理可能）
- スナップショットの不変性（一度取得したスナップショットは変更不可）
