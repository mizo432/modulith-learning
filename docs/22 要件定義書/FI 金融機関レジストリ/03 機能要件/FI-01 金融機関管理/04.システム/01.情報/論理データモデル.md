# 論理データモデル

## 概要

FI-01 金融機関管理業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    FINANCIAL_INSTITUTION
    {
        string FINANCIAL_INSTITUTION_ID PK "金融機関ID"
        string 名前 "名前"
        string コード "コード"
        string 支店 "支店"
        string 状態 "状態"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(金融機関)"
        enum variation "バリエーション(金融機関タイプ)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| 金融機関 | FINANCIAL_INSTITUTION_ID | string | true | 金融機関ID |
