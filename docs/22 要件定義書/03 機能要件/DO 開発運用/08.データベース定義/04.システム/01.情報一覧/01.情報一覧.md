# 情報一覧

システムが扱う情報をリストアップします。

## 情報

| 番号 | 情報名       | 情報種類 | 説明                                                 | 関連ユースケース | 履歴管理要 | 証跡要 | 実現方法 |
|------|--------------|----------|------------------------------------------------------|------------------|------------|--------|----------|
| 01   | データベース | リソース | 接続対象のデータベース情報                           | UC-01            | N          | N      | DB       |
| 02   | スキーマ     | リソース | データベース内のスキーマ情報                         | UC-02            | N          | N      | DB       |
| 03   | テーブル     | リソース | スキーマ内のテーブル情報                             | UC-03, UC-04     | N          | N      | DB       |
| 04   | View         | リソース | スキーマ内のView情報                                 | UC-03, UC-05     | N          | N      | DB       |
| 05   | カラム       | 対応表   | テーブルまたはViewのカラム情報                       | UC-04, UC-05     | N          | N      | DB       |
| 06   | インデックス | 対応表   | テーブルまたはマテリアライズドViewのインデックス情報 | UC-04, UC-05     | N          | N      | DB       |

## 情報モデル

```
データベース
  └── スキーマ
        ├── テーブル
        │     ├── カラム
        │     └── インデックス
        └── View
              ├── カラム
              └── インデックス (マテリアライズドViewの場合)
```
