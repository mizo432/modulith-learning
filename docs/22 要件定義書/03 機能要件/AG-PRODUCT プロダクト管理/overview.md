# プロダクト管理 機能要件概要

## 概要

本ドキュメントは、プロダクト管理業務領域の機能要件の概要を定義します。
プロダクトの作成、一覧取得、名前変更、アーカイブなどのプロダクトライフサイクル管理をサポートします。

## RDRA 4レイヤー

1. **システム価値レイヤー**: プロダクト管理の要求、アクター、外部システム
2. **システム外部環境レイヤー**: プロダクト管理業務、BUC、アクティビティ
3. **システム境界レイヤー**: プロダクト管理ユースケース、アクター
4. **システムレイヤー**: プロダクト情報、状態、画面
