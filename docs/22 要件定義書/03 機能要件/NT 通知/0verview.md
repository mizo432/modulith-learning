# 概要

本ドキュメントは、通知事業領域の機能要件の概要を定義します。
システムからの通知配信と管理機能を提供します。

## 事業領域情報

| 項目           | 値           |
|----------------|--------------|
| 事業領域コード | NT           |
| 事業領域区分   | 汎用         |
| 事業領域名     | 通知         |
| 事業領域英名   | Notification |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 通知業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義
