# アクター一覧

アジルーム（Agiloom）でシステムと相互作用するアクターを定義します。

## アクター

| アクターID | アクター名         | 説明                                                                     |
|------------|--------------------|--------------------------------------------------------------------------|
| AC-001     | プロダクトオーナー | プロダクトのビジョンとバックログを管理する役割                           |
| AC-002     | スクラムマスター   | Scrumプロセスの促進と障害の除去を担当する役割                            |
| AC-003     | 開発チームメンバー | 開発作業を実行するチームメンバー                                         |
| AC-004     | ステークホルダー   | プロダクトの利害関係者。レビュー等に参与                                 |
| AC-005     | 従業員             | 各種ダッシュボードの参照権限。コメント権限。                             |
| AC-006     | システム管理者     | プロダクトの初期登録・アーカイブ、チーム編成、役割割り当てを管理する役割 |
