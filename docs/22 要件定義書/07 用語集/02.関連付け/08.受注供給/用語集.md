# 購買事業 用語集

購買事業で使用される用語を定義します。

## 用語

| 用語         | 説明                                       |
|--------------|--------------------------------------------|
| 資材         | 農業に必要な肥料、農薬などの供給品         |
| 組合員       | JAに加入する農家や利用者                   |
| 受注         | 組合員からの資材注文                       |
| 配送         | 注文された資材を倉庫から店舗へ搬送すること |
| 供給         | 組合員に資材を交付すること                 |
| 発注         | 本店への資材注文                           |
| 荷受         | 本店からの資材を受け取る処理               |
| 受入         | 資材を在庫として登録する処理               |
| 棚卸         | 実際の在庫とシステム上の在庫を照合すること |
| 未収金       | 組合員から未回収の金銭                     |
| 未払金       | 本店に未支払いの金銭                       |
| 本店         | 資材を供給する上位組織                     |
| 店舗         | 組合員に資材を供給する拠点                 |
| 倉庫         | 資材を保管する施設                         |
| 会計システム | 会計処理を行う既存システム                 |
