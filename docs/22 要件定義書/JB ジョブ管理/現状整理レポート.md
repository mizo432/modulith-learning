### 2.2 整合性問題（1項目）

#### バリエーション条件図とバリエーション一覧の不一致

| 項目 | バリエーション条件図 | バリエーション一覧 | 差異 |
|-----|---------------------|-------------------|------|
| 件数 | 11種類 | 7種類 | 4種類差分 |
| 名称 | ジョブ種別、実行タイプ、サーバー種別、ジョブ実行状態、起動タイプ、会社タイプ、店舗タイプ、通知方法、通知条件、ファイル種別、操作タイプ | ジョブタイプ、実行モード、権限レベル、復旧タイプ、通知チャネル、会社タイプ、店舗タイプ | 名称も不一致 |

**詳細な差異:**

| バリエーション条件図にあるが、一覧にない | 一覧にあるが、条件図にない |
|----------------------------------------|--------------------------|
| ジョブ種別（定期・手動・API起動） | 権限レベル |
| 実行タイプ（単一・分散） | 復旧タイプ |
| サーバー種別（本番・検証・開発） | - |
| ジョブ実行状態（待機中・実行中・成功・失敗・結果不明・キャンセル済み） | - |
| 起動タイプ（スケジュール・手動・API） | - |
| 通知方法（メール・SMS・システム通知） | - |
| 通知条件（成功時・失敗時・結果不明時・実行開始時） | - |
| ファイル種別（CSV・JSON・XML・ZIP） | - |
| 操作タイプ（手動起動・再実行・途中再開・キャンセル・設定変更・権限変更） | - |

**共通するバリエーション:**
- 会社タイプ（本社・支社・関連会社）
- 店舗タイプ（直営店・フランチャイズ・アウトレット）

**推奨対応:**
- バリエーション条件図とバリエーション一覧を統合し、一貫性のある定義にすること
- バリエーション一覧に欠けている4種類（ジョブ種別、実行タイプ、サーバー種別、ジョブ実行状態など）を追加するか、条件図から不要なものを削除するか判断すること
