# UC-JB-011 スケジュールを登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-011 |
| ユースケース名 | スケジュールを登録する |
| 英語名 | Register Schedule |
| 説明 | 実行日時、繰り返し条件、対象ジョブ、有効期間を設定する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-JB-02 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-011（スケジュール登録・編集） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 対象ジョブ定義が存在すること
- スケジュール登録・編集画面（SCR-JB-011）にアクセスできること

## 基本フロー

1. 運用管理者が「スケジュール登録・編集」画面（SCR-JB-011）にアクセスする
2. 新規登録モードで画面を開く
3. 実行日時、繰り返し条件、対象ジョブ、有効期間を入力する
4. 入力を保存する
5. システムがジョブ定義（INF-JB-01）にスケジュール情報をPostgreSQL（ES-02）に永続化する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- スケジュール情報がシステムに登録される
- イベント「EVT-JB-010 スケジュールが登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-01 | ジョブ定義 | スケジュール設定対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-010 | スケジュールが登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 実行日時、対象ジョブは必須入力 |
| 2 | 有効期間 | 有効期間開始は終了より前であること |
