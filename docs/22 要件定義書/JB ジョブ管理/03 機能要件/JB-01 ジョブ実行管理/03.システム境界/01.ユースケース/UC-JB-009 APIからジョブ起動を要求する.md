# UC-JB-009 APIからジョブ起動を要求する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-009 |
| ユースケース名 | APIからジョブ起動を要求する |
| 英語名 | Launch Job via API |
| 説明 | 個別業務システムからAPI経由でジョブ起動を要求する |
| 関連アクター | AC-02（業務システム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-02 |
| 外部システム | ES-01（業務アプリケーションサーバー）、ES-02（PostgreSQL） |
| 関連画面 | - |

## 前置条件

- APIエンドポイントが利用可能であること
- 起動対象のジョブ定義が存在すること
- API認証情報が有効であること

## 基本フロー

1. 業務システム（AC-02）がAPIエンドポイントにジョブ起動要求を送信する
2. システムがAPI認証を確認する
3. システムが重複起動防止（RL-JB-01）と同時実行枠制御（RL-JB-02）を確認する
4. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）に記録する
5. 業務アプリケーションサーバー（ES-01）に実行を依頼する
6. APIレスポンスを返す

## 代替フロー

- **2a. API認証失敗の場合**
  - 認証エラーを返す

- **3a. 重複起動の場合**
  - 既に実行中のジョブの場合、エラーレスポンスを返す

- **3b. 同時実行枠超過の場合**
  - 同時実行枠を超過する場合、エラーレスポンスを返す

## 後置条件

- ジョブ実行（INF-JB-04）がシステムに登録される
- イベント「EVT-JB-008 API経由でジョブ起動が要求された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-01 | ジョブ定義 | 起動対象のジョブ情報 |
| INF-JB-04 | ジョブ実行 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-008 | API経由でジョブ起動が要求された | 基本フローステップ4完了後 |
| EVT-JB-012 | ジョブ実行が開始された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | API認証 | API呼び出しには認証が必要 |
| 2 | 重複起動防止 | 実行IDを冪等性キーとして二重起動を抑止 |
| 3 | 同時実行枠 | 同時に実行できるジョブの上限数を制御 |
