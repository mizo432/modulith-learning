# UC-JB-024 監査ログを確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-024 |
| ユースケース名 | 監査ログを確認する |
| 英語名 | View Audit Log |
| 説明 | 起動、設定変更、権限変更、復旧操作などの操作履歴を確認する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-08 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-026（監査ログ一覧） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 監査ログが存在すること

## 基本フロー

1. 運用管理者が「監査ログ一覧」画面（SCR-JB-026）にアクセスする
2. 検索条件を指定して監査ログを検索する
3. システムが監査ログ（INF-JB-11）をPostgreSQL（ES-02）から取得する
4. 起動、設定変更、権限変更、復旧操作などの操作履歴を一覧表示する

## 代替フロー

- **2a. 検索条件を指定しない場合**
  - 全監査ログを一覧表示する

## 後置条件

- 監査ログが表示される
