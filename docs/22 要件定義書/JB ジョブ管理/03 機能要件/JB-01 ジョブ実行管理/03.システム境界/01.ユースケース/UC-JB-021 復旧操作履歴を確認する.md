# UC-JB-021 復旧操作履歴を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-021 |
| ユースケース名 | 復旧操作履歴を確認する |
| 英語名 | View Recovery History |
| 説明 | 再実行・再開・キャンセルの操作者・理由・日時を確認する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-JB-05 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-016（復旧操作履歴一覧） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 復旧操作履歴が存在すること

## 基本フロー

1. 運用管理者が「復旧操作履歴一覧」画面（SCR-JB-016）にアクセスする
2. 検索条件を指定して復旧操作履歴を検索する
3. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）から取得する
4. 再実行・再開・キャンセルの操作者・理由・日時を一覧表示する

## 代替フロー

- **2a. 検索条件を指定しない場合**
  - 全復旧操作履歴を一覧表示する

## 後置条件

- 復旧操作履歴が表示される
