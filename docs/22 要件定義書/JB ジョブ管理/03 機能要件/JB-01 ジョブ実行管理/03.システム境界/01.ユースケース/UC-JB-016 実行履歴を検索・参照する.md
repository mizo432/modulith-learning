# UC-JB-016 実行履歴を検索・参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-016 |
| ユースケース名 | 実行履歴を検索・参照する |
| 英語名 | Search Execution History |
| 説明 | 期間・ジョブ・会社・店舗・状態などで履歴を検索・参照する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-04 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-005（ジョブ実行履歴一覧）、SCR-JB-006（ジョブ実行履歴詳細） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 実行履歴が存在すること

## 基本フロー

1. 運用管理者が「ジョブ実行履歴一覧」画面（SCR-JB-005）にアクセスする
2. 検索条件（期間・ジョブ・会社・店舗・状態）を指定する
3. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）から検索する
4. 検索結果を一覧表示する
5. 一覧から対象履歴を選択し、「ジョブ実行履歴詳細」（SCR-JB-006）に遷移する
6. 実行結果、実行時間、処理件数、再実行履歴を表示する

## 代替フロー

- **2a. 検索条件を指定しない場合**
  - 全履歴を一覧表示する

## 後置条件

- 実行履歴が表示される
