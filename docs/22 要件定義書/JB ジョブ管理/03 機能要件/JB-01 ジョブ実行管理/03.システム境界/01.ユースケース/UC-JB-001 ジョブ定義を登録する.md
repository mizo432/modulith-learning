# UC-JB-001 ジョブ定義を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-001 |
| ユースケース名 | ジョブ定義を登録する |
| 英語名 | Register Job Definition |
| 説明 | ジョブコード、パラメータ仕様、実行制約などを新規登録する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-01 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-009（ジョブ定義登録・編集） |

## 前置条件

- 運用管理者がシステムにログインしていること
- ジョブ定義登録画面（SCR-JB-009）にアクセスできること

## 基本フロー

1. 運用管理者が「ジョブ定義登録・編集」画面（SCR-JB-009）にアクセスする
2. 新規登録モードで画面を開く
3. ジョブコード、パラメータ仕様、実行制約などを入力する
4. 入力を保存する
5. システムがジョブ定義（INF-JB-01）をPostgreSQL（ES-02）に永続化する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **5a. 重複ジョブコードの場合**
  - 既に存在するジョブコードの場合、エラーメッセージを表示する
  - ユーザーは別のジョブコードを入力して再試行する

## 後置条件

- ジョブ定義（INF-JB-01）がシステムに登録される
- イベント「EVT-JB-001 ジョブ定義が登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-01 | ジョブ定義 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-001 | ジョブ定義が登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | ジョブコードは必須入力 |
| 2 | 一意性 | ジョブコードは重複不可 |
| 3 | 文字数制限 | ジョブコードは50文字以内 |
