# UC-JB-007 ユーザー・権限を管理する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-007 |
| ユースケース名 | ユーザー・権限を管理する |
| 英語名 | Manage User Permissions |
| 説明 | ユーザーのロール、会社・店舗の参照権限を設定する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-07 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-023（ユーザー一覧）、SCR-JB-024（ユーザー・権限編集） |

## 前置条件

- 運用管理者がシステムにログインしていること
- ユーザー一覧画面（SCR-JB-023）にアクセスできること

## 基本フロー

1. 運用管理者が「ユーザー一覧」画面（SCR-JB-023）にアクセスする
2. 権限設定対象のユーザーを選択する
3. 「ユーザー・権限編集」画面（SCR-JB-024）に遷移する
4. ロール、会社・店舗の参照権限を設定する
5. 設定を保存する
6. システムが会社権限（INF-JB-07）と店舗権限（INF-JB-08）をPostgreSQL（ES-02）に永続化する
7. 設定完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- ユーザーの権限設定が更新される
- イベント「EVT-JB-006 ユーザー権限が設定された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-07 | 会社権限 | 設定対象の情報 |
| INF-JB-08 | 店舗権限 | 設定対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-006 | ユーザー権限が設定された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | ロールは必須設定 |
| 2 | 権限の階層 | 会社権限と店舗権限は階層的に設定 |
