# UC-JB-025 会社別実行状況・履歴を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-025 |
| ユースケース名 | 会社別実行状況・履歴を参照する |
| 英語名 | View Company Execution Status |
| 説明 | 自社に属するジョブの実行状況・履歴を参照する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-JB-04 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-005（ジョブ実行履歴一覧）、SCR-JB-006（ジョブ実行履歴詳細） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 会社権限（INF-JB-07）が設定されていること

## 基本フロー

1. 運用管理者が「ジョブ実行履歴一覧」画面（SCR-JB-005）にアクセスする
2. 会社を指定して検索する
3. システムが会社権限（INF-JB-07）と会社・店舗権限フィルタ（RL-JB-07）を確認する
4. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）から取得する
5. 自社に属するジョブの実行状況・履歴を一覧表示する

## 代替フロー

- **2a. 会社を指定しない場合**
  - 権限のある全会社のジョブを表示する

## 後置条件

- 会社別実行状況・履歴が表示される
