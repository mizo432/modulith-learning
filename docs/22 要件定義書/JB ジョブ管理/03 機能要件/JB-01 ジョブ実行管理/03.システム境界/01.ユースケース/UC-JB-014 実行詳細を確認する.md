# UC-JB-014 実行詳細を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-014 |
| ユースケース名 | 実行詳細を確認する |
| 英語名 | View Execution Detail |
| 説明 | 実行状態、実行先、パラメータ、処理件数、エラー情報を確認する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-03 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-003（ジョブ実行詳細） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 確認対象のジョブ実行が存在すること

## 基本フロー

1. 運用管理者が「ジョブ実行詳細」画面（SCR-JB-003）にアクセスする
2. 確認対象のジョブ実行を選択する
3. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）から取得する
4. 実行状態、実行先、パラメータ、処理件数、エラー情報を表示する

## 代替フロー

- **2a. 対象が見つからない場合**
  - エラーメッセージを表示する

## 後置条件

- ジョブ実行の詳細情報が表示される
