# UC-JB-027 会社・店舗を管理する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-027 |
| ユースケース名 | 会社・店舗を管理する |
| 英語名 | Manage Company and Store |
| 説明 | 会社と店舗の登録、所属関係の管理を行う |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-JB-07 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-025（会社・店舗管理） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 会社・店舗管理画面（SCR-JB-025）にアクセスできること

## 基本フロー

1. 運用管理者が「会社・店舗管理」画面（SCR-JB-025）にアクセスする
2. 会社または店舗の新規登録、編集、削除を行う
3. 所属関係を設定する
4. 入力を保存する
5. システムが会社権限（INF-JB-07）と店舗権限（INF-JB-08）をPostgreSQL（ES-02）に永続化する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 会社・店舗情報がシステムに登録される
- イベント「EVT-JB-020 会社・店舗が登録された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-07 | 会社権限 | 作成対象の情報 |
| INF-JB-08 | 店舗権限 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-020 | 会社・店舗が登録された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 会社名、店舗名は必須入力 |
| 2 | 所属関係 | 店舗は会社に所属する必要がある |
