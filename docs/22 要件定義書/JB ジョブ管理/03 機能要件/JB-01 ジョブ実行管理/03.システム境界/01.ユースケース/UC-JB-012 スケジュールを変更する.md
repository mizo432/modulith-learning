# UC-JB-012 スケジュールを変更する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-012 |
| ユースケース名 | スケジュールを変更する |
| 英語名 | Modify Schedule |
| 説明 | 既存のスケジュール設定を修正する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-JB-02 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-011（スケジュール登録・編集） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 変更対象のスケジュール設定が存在すること

## 基本フロー

1. 運用管理者が「スケジュール登録・編集」画面（SCR-JB-011）にアクセスする
2. 変更対象のスケジュールを選択する
3. 実行日時、繰り返し条件などを修正する
4. 変更内容を保存する
5. システムがジョブ定義（INF-JB-01）をPostgreSQL（ES-02）に更新する
6. 変更完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- スケジュール設定が更新される
- イベント「EVT-JB-011 スケジュールが変更された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-01 | ジョブ定義 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-011 | スケジュールが変更された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 有効期間 | 有効期間開始は終了より前であること |
