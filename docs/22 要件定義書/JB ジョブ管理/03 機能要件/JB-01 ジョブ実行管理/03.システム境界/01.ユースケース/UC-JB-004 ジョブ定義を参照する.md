# UC-JB-004 ジョブ定義を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-004 |
| ユースケース名 | ジョブ定義を参照する |
| 英語名 | View Job Definition |
| 説明 | 登録済みジョブの定義内容・バージョン・配備状況を確認する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-01 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-007（ジョブ定義一覧）、SCR-JB-008（ジョブ定義詳細） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 登録済みジョブ定義が存在すること

## 基本フロー

1. 運用管理者が「ジョブ定義一覧」画面（SCR-JB-007）にアクセスする
2. 検索条件を指定してジョブ定義を検索する
3. 一覧から対象ジョブ定義を選択する
4. 「ジョブ定義詳細」画面（SCR-JB-008）に遷移する
5. システムがジョブ定義（INF-JB-01）をPostgreSQL（ES-02）から取得する
6. ジョブ定義の詳細情報を表示する

## 代替フロー

- **2a. 検索条件を指定しない場合**
  - 全ジョブ定義を一覧表示する

## 後置条件

- ジョブ定義の詳細情報が表示される
