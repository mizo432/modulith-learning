# UC-JB-017 APIから実行状態を照会する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-017 |
| ユースケース名 | APIから実行状態を照会する |
| 英語名 | Query Execution Status via API |
| 説明 | 個別業務システムからAPI経由で実行状態・結果を照会する |
| 関連アクター | AC-02（業務システム） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-03 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | - |

## 前置条件

- APIエンドポイントが利用可能であること
- API認証情報が有効であること

## 基本フロー

1. 業務システム（AC-02）がAPIエンドポイントに実行状態照会要求を送信する
2. システムがAPI認証を確認する
3. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）から取得する
4. 実行状態・結果をAPIレスポンスとして返す

## 代替フロー

- **2a. API認証失敗の場合**
  - 認証エラーを返す

- **3a. 対象が見つからない場合**
  - NotFoundエラーを返す

## 後置条件

- 実行状態・結果が返される
