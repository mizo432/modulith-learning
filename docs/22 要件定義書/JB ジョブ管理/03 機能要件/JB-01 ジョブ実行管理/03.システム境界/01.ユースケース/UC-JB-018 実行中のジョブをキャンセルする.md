# UC-JB-018 実行中のジョブをキャンセルする

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-018 |
| ユースケース名 | 実行中のジョブをキャンセルする |
| 英語名 | Cancel Running Job |
| 説明 | 実行中のジョブにキャンセルを要求する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-05 |
| 外部システム | ES-01（業務アプリケーションサーバー）、ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-015（キャンセル確認画面） |

## 前置条件

- 運用管理者がシステムにログインしていること
- キャンセル対象の実行中ジョブが存在すること

## 基本フロー

1. 運用管理者が「キャンセル確認画面」（SCR-JB-015）にアクセスする
2. キャンセル対象のジョブを選択する
3. キャンセルの影響を確認する
4. 「キャンセル」ボタンをクリックする
5. システムが業務アプリケーションサーバー（ES-01）にキャンセルを依頼する
6. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）に更新する
7. キャンセル完了メッセージを表示する

## 代替フロー

- **4a. キャンセルをキャンセルした場合**
  - キャンセルボタンをクリックした場合、処理を中止する

## 後置条件

- ジョブ実行（INF-JB-04）がキャンセル状態に更新される
- イベント「EVT-JB-016 ジョブがキャンセルされた」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-04 | ジョブ実行 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-016 | ジョブがキャンセルされた | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 確認必須 | キャンセルには確認ダイアログが必要 |
