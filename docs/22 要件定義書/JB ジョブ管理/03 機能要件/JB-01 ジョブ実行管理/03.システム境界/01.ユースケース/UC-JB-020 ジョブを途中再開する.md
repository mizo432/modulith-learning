# UC-JB-020 ジョブを途中再開する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-020 |
| ユースケース名 | ジョブを途中再開する |
| 英語名 | Resume Job from Checkpoint |
| 説明 | チェックポイントからジョブを再開する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-05 |
| 外部システム | ES-01（業務アプリケーションサーバー）、ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-014（途中再開確認画面） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 再開対象のジョブが存在すること
- 途中再開可否判定（RL-JB-05）が通過すること

## 基本フロー

1. 運用管理者が「途中再開確認画面」（SCR-JB-014）にアクセスする
2. 再開対象のジョブを選択する
3. 再開可否、チェックポイント、再開位置を確認する
4. 「再開」ボタンをクリックする
5. システムが途中再開可否判定（RL-JB-05）を確認する
6. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）に記録する
7. 業務アプリケーションサーバー（ES-01）に再開を依頼する
8. 再開完了メッセージを表示する

## 代替フロー

- **5a. 再開不可の場合**
  - 再開できない理由を表示する
  - ユーザーは処理を中止する

## 後置条件

- 新しいジョブ実行（INF-JB-04）がシステムに登録される
- イベント「EVT-JB-018 ジョブが途中再開された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-04 | ジョブ実行 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-018 | ジョブが途中再開された | 基本フローステップ6完了後 |
| EVT-JB-012 | ジョブ実行が開始された | 基本フローステップ7完了後 |

| 番号 | 制約事項 | 説明 |
|------|----------|------|
