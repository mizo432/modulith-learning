# UC-JB-013 実行状況を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-013 |
| ユースケース名 | 実行状況を確認する |
| 英語名 | Check Execution Status |
| 説明 | 実行中・待機中・異常終了などの状態をリアルタイムで確認する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-03 |
| 外部システム | ES-01（業務アプリケーションサーバー）、ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-001（ダッシュボード）、SCR-JB-002（ジョブ実行状況一覧）、SCR-JB-003（ジョブ実行詳細） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 実行中のジョブが存在すること

## 基本フロー

1. 運用管理者が「ダッシュボード」画面（SCR-JB-001）にアクセスする
2. システムがジョブ実行（INF-JB-04）と実行イベント（INF-JB-06）をPostgreSQL（ES-02）から取得する
3. 実行中・成功・失敗件数、異常発生状況を表示する
4. 運用管理者が詳細を確認する場合、「ジョブ実行状況一覧」（SCR-JB-002）に遷移する
5. 一覧から対象ジョブを選択し、「ジョブ実行詳細」（SCR-JB-003）に遷移する
6. 実行状態、実行先、パラメータ、エラー情報を表示する

## 代替フロー

- **4a. 詳細を確認しない場合**
  - ダッシュボードで確認を終了する

## 後置条件

- ジョブ実行状況が表示される
