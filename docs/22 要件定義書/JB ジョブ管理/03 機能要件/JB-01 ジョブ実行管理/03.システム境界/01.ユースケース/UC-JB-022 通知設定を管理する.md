# UC-JB-022 通知設定を管理する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-022 |
| ユースケース名 | 通知設定を管理する |
| 英語名 | Manage Notification Settings |
| 説明 | 通知条件、通知先、通知対象ジョブを設定する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-JB-06 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-022（通知設定） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 通知設定画面（SCR-JB-022）にアクセスできること

## 基本フロー

1. 運用管理者が「通知設定」画面（SCR-JB-022）にアクセスする
2. 通知条件、通知先、通知対象ジョブを設定する
3. 設定を保存する
4. システムが通知設定（INF-JB-09）をPostgreSQL（ES-02）に永続化する
5. 設定完了メッセージを表示する

## 代替フロー

- **2a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 通知設定（INF-JB-09）がシステムに登録される
