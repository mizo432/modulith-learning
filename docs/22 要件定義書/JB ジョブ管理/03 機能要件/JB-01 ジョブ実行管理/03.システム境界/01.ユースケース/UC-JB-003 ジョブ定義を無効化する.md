# UC-JB-003 ジョブ定義を無効化する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-003 |
| ユースケース名 | ジョブ定義を無効化する |
| 英語名 | Disable Job Definition |
| 説明 | ジョブ定義を無効化して新規実行を不可にする |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-01 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-008（ジョブ定義詳細） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 無効化対象のジョブ定義が存在すること
- ジョブ定義詳細画面（SCR-JB-008）にアクセスできること

## 基本フロー

1. 運用管理者が「ジョブ定義詳細」画面（SCR-JB-008）にアクセスする
2. 無効化対象のジョブ定義を選択する
3. 「無効化」ボタンをクリックする
4. 無効化確認ダイアログを表示する
5. 運用管理者が確認する
6. システムがジョブ定義（INF-JB-01）をPostgreSQL（ES-02）に更新する
7. 無効化完了メッセージを表示する

## 代替フロー

- **4a. 無効化をキャンセルした場合**
  - キャンセルボタンをクリックした場合、処理を中止する

## 後置条件

- ジョブ定義（INF-JB-01）が無効化される
- イベント「EVT-JB-003 ジョブ定義が無効化された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-01 | ジョブ定義 | 無効化対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-003 | ジョブ定義が無効化された | 基本フローステップ6完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 実行中ジョブ | 実行中のジョブは即時無効化されない |
| 2 | 確認必須 | 無効化には確認ダイアログが必要 |
