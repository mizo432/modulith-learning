# UC-JB-002 ジョブ定義を変更する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-002 |
| ユースケース名 | ジョブ定義を変更する |
| 英語名 | Modify Job Definition |
| 説明 | 既存のジョブ定義のパラメータ・実行条件を修正する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-01 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-009（ジョブ定義登録・編集） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 変更対象のジョブ定義が存在すること
- ジョブ定義登録画面（SCR-JB-009）にアクセスできること

## 基本フロー

1. 運用管理者が「ジョブ定義登録・編集」画面（SCR-JB-009）にアクセスする
2. 変更対象のジョブ定義を選択する
3. パラメータ仕様、実行条件などを修正する
4. 変更内容を保存する
5. システムがジョブ定義（INF-JB-01）をPostgreSQL（ES-02）に更新する
6. 変更完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- ジョブ定義（INF-JB-01）が更新される
- イベント「EVT-JB-002 ジョブ定義が変更された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-01 | ジョブ定義 | 更新対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-002 | ジョブ定義が変更された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | ジョブコードは変更不可 |
| 2 | バージョン管理 | 変更ごとにバージョンが更新される |
