# UC-JB-010 スケジュールに従ってジョブを起動する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-010 |
| ユースケース名 | スケジュールに従ってジョブを起動する |
| 英語名 | Launch Job by Schedule |
| 説明 | 設定された実行日時・条件に従ってジョブを起動する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-02 |
| 外部システム | ES-01（業務アプリケーションサーバー）、ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-010（スケジュール一覧）、SCR-JB-011（スケジュール登録・編集） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 起動対象のジョブ定義が存在すること
- スケジュール設定が存在すること

## 基本フロー

1. システムが設定された実行日時・条件を確認する
2. 実行条件が満たされた場合、ジョブ起動処理を開始する
3. システムが重複起動防止（RL-JB-01）と同時実行枠制御（RL-JB-02）を確認する
4. システムがジョブ実行（INF-JB-04）をPostgreSQL（ES-02）に記録する
5. 業務アプリケーションサーバー（ES-01）に実行を依頼する

## 代替フロー

- **3a. 重複起動の場合**
  - 既に実行中のジョブの場合、スキップする

- **3b. 同時実行枠超過の場合**
  - 同時実行枠を超過する場合、待機する

## 後置条件

- ジョブ実行（INF-JB-04）がシステムに登録される
- イベント「EVT-JB-009 スケジュール起動が実行された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-01 | ジョブ定義 | 起動対象のジョブ情報 |
| INF-JB-04 | ジョブ実行 | 作成対象の情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-009 | スケジュール起動が実行された | 基本フローステップ4完了後 |
| EVT-JB-012 | ジョブ実行が開始された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 重複起動防止 | 実行IDを冪等性キーとして二重起動を抑止 |
| 2 | 同時実行枠 | 同時に実行できるジョブの上限数を制御 |
| 3 | バージョン互換性 | 実行時のジョブバージョンとサーバーの互換性を確認 |
