# UC-JB-023 通知を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-023 |
| ユースケース名 | 通知を確認する |
| 英語名 | View Notifications |
| 説明 | 成功・異常終了などの通知を確認する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-JB-06 |
| 外部システム | ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-021（通知一覧） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 通知が存在すること

## 基本フロー

1. 運用管理者が「通知一覧」画面（SCR-JB-021）にアクセスする
2. システムが通知設定（INF-JB-09）をPostgreSQL（ES-02）から取得する
3. 成功・異常終了などの通知を一覧表示する
4. 運用管理者が通知を確認する

## 代替フロー

- **2a. 通知がない場合**
  - 「通知はありません」メッセージを表示する

## 後置条件

- 通知一覧が表示される
