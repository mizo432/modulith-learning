# UC-JB-006 サーバー配備情報を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-JB-006 |
| ユースケース名 | サーバー配備情報を更新する |
| 英語名 | Update Server Deployment |
| 説明 | サーバー情報やジョブ配備状況・バージョンを修正する |
| 関連アクター | AC-01（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-JB-01 |
| 外部システム | ES-01（業務アプリケーションサーバー）、ES-02（PostgreSQL） |
| 関連画面 | SCR-JB-019（ジョブ配備状況一覧） |

## 前置条件

- 運用管理者がシステムにログインしていること
- 更新対象のサーバー配備情報が存在すること

## 基本フロー

1. 運用管理者が「ジョブ配備状況一覧」画面（SCR-JB-019）にアクセスする
2. 更新対象の配備情報を選択する
3. サーバー情報やジョブ配備状況・バージョンを修正する
4. 変更内容を保存する
5. システムがジョブ配備（INF-JB-02）をPostgreSQL（ES-02）に更新する
6. 更新完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- ジョブ配備（INF-JB-02）が更新される
- イベント「EVT-JB-005 サーバー配備情報が更新された」が発行される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-JB-02 | ジョブ配備 | 更新対象の情報 |
| INF-JB-03 | アプリケーションサーバー | 関連するサーバー情報 |

## 関連イベント

| イベントID | イベント名 | 発生タイミング |
|------------|------------|----------------|
| EVT-JB-005 | サーバー配備情報が更新された | 基本フローステップ5完了後 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | バージョン互換性 | 変更後のバージョン互換性を確認 |
