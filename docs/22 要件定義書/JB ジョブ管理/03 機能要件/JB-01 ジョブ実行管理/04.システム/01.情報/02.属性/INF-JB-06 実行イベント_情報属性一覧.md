# 情報属性一覧

実行イベントの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-06 |
| 情報名 | 実行イベント |
| 情報種類 | イベント |
| 説明 | 状態遷移・実行イベント |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | eventId | Y | String | Y | イベントID（一意識別子） |
| 2 | executionId | N | String | Y | 実行ID（外部キー） |
| 3 | eventType | N | Enum | Y | イベントタイプ（開始/終了/状態変更/エラー/チェックポイント） |
| 4 | previousState | N | Enum | N | 遷移前の状態 |
| 5 | newState | N | Enum | Y | 遷移後の状態 |
| 6 | message | N | String | N | イベントメッセージ |
| 7 | occurredAt | N | DateTime | Y | 発生日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのイベントIDが1つの実行イベントを表す |
| 同一性 (Sameness) | イベントIDが同じ場合、同じイベントであると判断する |
| カテゴリ (Category) | ジョブ実行中に発生するイベントの記録。状態遷移、エラー発生、チェックポイントなどを記録する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | イベントは不変の記録であり状態遷移を持たない | - | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-04 | ジョブ実行 | N:1 | 複数のイベントは1つの実行に属する |
