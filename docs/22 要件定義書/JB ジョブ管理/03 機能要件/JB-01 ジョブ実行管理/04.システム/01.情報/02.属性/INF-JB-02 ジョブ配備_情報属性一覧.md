# 情報属性一覧

ジョブ配備の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-02 |
| 情報名 | ジョブ配備 |
| 情報種類 | 対応表 |
| 説明 | サーバーごとの配備状況・バージョン |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | deploymentId | Y | String | Y | 配備ID（一意識別子） |
| 2 | jobCode | N | String | Y | ジョブコード（外部キー） |
| 3 | host | N | String | Y | サーバーホスト名 |
| 4 | port | N | Integer | Y | サーバーポート番号 |
| 5 | protocol | N | String | Y | プロトコル（HTTP/HTTPS等） |
| 6 | deploymentVersion | N | String | Y | 配備バージョン |
| 7 | deployedAt | N | DateTime | Y | 配備日時 |
| 8 | status | N | Enum | Y | 配備ステータス（配備済み/配備中/失敗） |
| 9 | createdAt | N | DateTime | Y | 作成日時 |
| 10 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの配備IDが1つのジョブとサーバーの配備関係を表す |
| 同一性 (Sameness) | 配備IDが同じ場合、同じ配備情報であると判断する |
| カテゴリ (Category) | ジョブ定義とアプリケーションサーバーとの配備関係。バージョン情報とステータスを含む |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 配備中 | 配備処理が進行中 | start | 配備済み, 失敗 | UC-JB-005 サーバー配備情報を登録する |
| 配備済み | 配備が完了し実行可能 | 配備中 | 配備中 | UC-JB-006 サーバー配備情報を更新する |
| 失敗 | 配備が失敗 | 配備中 | 配備中 | UC-JB-005 サーバー配備情報を登録する |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-01 | ジョブ定義 | N:1 | 複数の配備は1つのジョブ定義を参照 |
| INF-JB-03 | アプリケーションサーバー | N:1 | 複数の配備は1つのサーバーを参照 |
