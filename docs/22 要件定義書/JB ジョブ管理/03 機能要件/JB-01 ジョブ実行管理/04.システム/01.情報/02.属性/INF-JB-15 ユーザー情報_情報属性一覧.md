# 情報属性一覧

ユーザー情報の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-15 |
| 情報名 | ユーザー情報 |
| 情報種類 | リソース |
| 説明 | ユーザー名、ロール、所属会社・店舗 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | userId | Y | String | Y | ユーザーID（一意識別子） |
| 2 | username | N | String | Y | ユーザー名 |
| 3 | role | N | Enum | Y | ロール（システム管理者/運用管理者/会社運用担当者/店舗担当者） |
| 4 | enabled | N | Boolean | Y | 有効フラグ |
| 5 | createdAt | N | DateTime | Y | 作成日時 |
| 6 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのユーザーIDが1つのユーザーを表す |
| 同一性 (Sameness) | ユーザーIDが同じ場合、同じユーザーであると判断する |
| カテゴリ (Category) | システムを利用するユーザーの情報。ロールと有効状態を管理する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 有効 | ユーザーが有効でログイン可能 | start | 無効 | UC-JB-007 ユーザー・権限を管理する |
| 無効 | ユーザーが無効でログイン不可 | 有効 | 有効 | UC-JB-007 ユーザー・権限を管理する |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-07 | 会社権限 | 1:N | 1つのユーザーは複数の会社権限を持つ |
| INF-JB-08 | 店舗権限 | 1:N | 1つのユーザーは複数の店舗権限を持つ |
| INF-JB-11 | 監査ログ | 1:N | 1つのユーザーは複数の監査ログを生成する |
