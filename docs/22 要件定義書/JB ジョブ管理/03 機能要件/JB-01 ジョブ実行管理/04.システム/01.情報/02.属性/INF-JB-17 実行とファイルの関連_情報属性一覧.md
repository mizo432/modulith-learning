# 情報属性一覧

実行とファイルの関連の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-17 |
| 情報名 | 実行とファイルの関連 |
| 情報種類 | 対応表 |
| 説明 | ジョブ実行と入力・出力ファイルの対応関係 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | relationId | Y | String | Y | 関連ID（一意識別子） |
| 2 | executionId | N | String | Y | 実行ID（外部キー） |
| 3 | fileId | N | String | Y | ファイルID（外部キー） |
| 4 | fileType | N | Enum | Y | ファイルタイプ（入力/出力） |
| 5 | description | N | String | N | 説明 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの関連IDが1つの実行とファイルの対応関係を表す |
| 同一性 (Sameness) | 関連IDが同じ場合、同じ対応関係であると判断する |
| カテゴリ (Category) | ジョブ実行とファイルの入出力関係。どの実行がどのファイルを入力・出力したかを記録する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | 対応表は状態遷移を持たない | - | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-04 | ジョブ実行 | N:1 | 複数の関連は1つの実行を参照 |
| INF-JB-10 | アップロードファイル | N:1 | 複数の関連は1つのファイルを参照 |
