# 情報属性一覧

通知履歴の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-16 |
| 情報名 | 通知履歴 |
| 情報種類 | イベント |
| 説明 | 通知配信日時、宛先、配信結果 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | notificationHistoryId | Y | String | Y | 通知履歴ID（一意識別子） |
| 2 | notificationSettingId | N | String | Y | 通知設定ID（外部キー） |
| 3 | executionId | N | String | Y | 実行ID（外部キー） |
| 4 | jobCode | N | String | Y | ジョブコード |
| 5 | executionState | N | Enum | Y | 実行状態（成功/失敗/結果不明） |
| 6 | destination | N | String | Y | 通知先 |
| 7 | channel | N | Enum | Y | 通知チャネル（メール/Slack/LINE等） |
| 8 | sentAt | N | DateTime | Y | 配信日時 |
| 9 | deliveryStatus | N | Enum | Y | 配信ステータス（成功/失敗） |
| 10 | errorMessage | N | String | N | エラーメッセージ |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの通知履歴IDが1回の通知配信を表す |
| 同一性 (Sameness) | 通知履歴IDが同じ場合、同じ通知履歴であると判断する |
| カテゴリ (Category) | 通知の配信記録。いつ誰にどのような通知が配信されたかを追跡する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | 通知履歴は不変の記録であり状態遷移を持たない | - | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-09 | 通知設定 | N:1 | 複数の通知履歴は1つの通知設定に属する |
| INF-JB-04 | ジョブ実行 | N:1 | 複数の通知履歴は1つの実行に属する |
