# 情報属性一覧

スケジュール定義の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-13 |
| 情報名 | スケジュール定義 |
| 情報種類 | リソース |
| 説明 | 実行日時、繰り返し条件、タイムゾーン、有効期間 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | scheduleId | Y | String | Y | スケジュールID（一意識別子） |
| 2 | jobCode | N | String | Y | ジョブコード（外部キー） |
| 3 | executionDateTime | N | DateTime | N | 単発実行日時 |
| 4 | cronExpression | N | String | N | Cron式（繰り返し実行の場合） |
| 5 | timezone | N | String | N | タイムゾーン |
| 6 | startDate | N | Date | Y | 開始日 |
| 7 | endDate | N | Date | N | 終了日 |
| 8 | enabled | N | Boolean | Y | 有効フラグ |
| 9 | createdAt | N | DateTime | Y | 作成日時 |
| 10 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのスケジュールIDが1つのスケジュール定義を表す |
| 同一性 (Sameness) | スケジュールIDが同じ場合、同じスケジュールであると判断する |
| カテゴリ (Category) | ジョブの定期実行を定義するスケジュール。単発実行と繰り返し実行の両方をサポートする |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 有効 | スケジュールが有効で発火可能 | start | 無効 | UC-JB-012 スケジュールを変更する |
| 無効 | スケジュールが無効で発火不可 | 有効 | 有効 | UC-JB-012 スケジュールを変更する |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-01 | ジョブ定義 | N:1 | 複数のスケジュールは1つのジョブ定義を参照 |
| INF-JB-14 | スケジュール発火記録 | 1:N | 1つのスケジュールから複数の発火記録が生成される |
