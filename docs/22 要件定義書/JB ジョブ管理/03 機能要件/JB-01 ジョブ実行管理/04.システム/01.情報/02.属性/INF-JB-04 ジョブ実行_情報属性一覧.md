# 情報属性一覧

ジョブ実行の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-04 |
| 情報名 | ジョブ実行 |
| 情報種類 | リソース |
| 説明 | 実行状態・結果・履歴 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | executionId | Y | String | Y | 実行ID（一意識別子） |
| 2 | jobCode | N | String | Y | ジョブコード（外部キー） |
| 3 | jobVersion | N | String | Y | ジョブバージョン |
| 4 | host | N | String | Y | 実行先サーバーホスト |
| 5 | port | N | Integer | Y | 実行先サーバーポート |
| 6 | protocol | N | String | Y | プロトコル |
| 7 | executionState | N | Enum | Y | 実行状態（待機中/実行中/成功/失敗/結果不明） |
| 8 | executionParameter | N | String | N | 実行パラメータ（JSON形式） |
| 9 | checkpointPosition | N | String | N | チェックポイント位置 |
| 10 | checkpointTimestamp | N | DateTime | N | チェックポイントタイムスタンプ |
| 11 | processedCount | N | Long | N | 処理件数 |
| 12 | errorCode | N | String | N | エラーコード |
| 13 | errorMessage | N | String | N | エラーメッセージ |
| 14 | errorLocation | N | String | N | エラー発生箇所 |
| 15 | errorOccurredAt | N | DateTime | N | エラー発生日時 |
| 16 | startedAt | N | DateTime | N | 開始日時 |
| 17 | finishedAt | N | DateTime | N | 終了日時 |
| 18 | companyCode | N | String | N | 対象会社コード |
| 19 | storeCode | N | String | N | 対象店舗コード |
| 20 | createdAt | N | DateTime | Y | 作成日時 |
| 21 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの実行IDが1回のジョブ実行を表す |
| 同一性 (Sameness) | 実行IDが同じ場合、同じ実行であると判断する |
| カテゴリ (Category) | ジョブの1回の実行記録。状態、パラメータ、結果、エラー情報、チェックポイントを含む |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 待機中 | 実行待ち | start | 実行中 | UC-JB-008, UC-JB-009, UC-JB-010 |
| 実行中 | 実行中 | 待機中 | 成功, 失敗, 結果不明 | - |
| 成功 | 正常終了 | 実行中 | - | - |
| 失敗 | 異常終了 | 実行中 | 待機中 | UC-JB-019 ジョブを再実行する |
| 結果不明 | 結果が不明 | 実行中 | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-01 | ジョブ定義 | N:1 | 複数の実行は1つのジョブ定義を参照 |
| INF-JB-03 | アプリケーションサーバー | N:1 | 複数の実行は1つのサーバーで実行される |
| INF-JB-06 | 実行イベント | 1:N | 1つの実行に複数のイベントが発生する |
| INF-JB-10 | アップロードファイル | 1:N | 1つの実行に複数のファイルが関連する |
| INF-JB-11 | 監査ログ | 1:N | 1つの実行に対して複数の監査ログが記録される |
| INF-JB-17 | 実行とファイルの関連 | 1:N | 1つの実行に複数のファイル関連が紐づく |
