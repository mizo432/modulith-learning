# 情報属性一覧

実行枠の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-05 |
| 情報名 | 実行枠 |
| 情報種類 | リソース |
| 説明 | 同時実行枠の管理 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | slotId | Y | String | Y | 枠ID（一意識別子） |
| 2 | maxSlots | N | Integer | Y | 最大同時実行枠数 |
| 3 | usedSlots | N | Integer | Y | 使用中の枠数 |
| 4 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの枠IDが1つの実行枠リソースを表す |
| 同一性 (Sameness) | 枠IDが同じ場合、同じ実行枠であると判断する |
| カテゴリ (Category) | ジョブの同時実行数を制御する枠管理。最大枠数と使用中枠数を追跡する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | 実行枠は状態遷移を持たず、枠数の増減のみ管理する | - | - | - |
