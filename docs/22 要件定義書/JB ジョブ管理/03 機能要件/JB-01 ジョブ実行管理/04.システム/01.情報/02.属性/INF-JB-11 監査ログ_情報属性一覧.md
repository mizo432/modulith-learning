# 情報属性一覧

監査ログの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-11 |
| 情報名 | 監査ログ |
| 情報種類 | イベント |
| 説明 | 手動起動・再実行・再開などの操作記録 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | auditLogId | Y | String | Y | 監査ログID（一意識別子） |
| 2 | operationType | N | Enum | Y | 操作タイプ（手動起動/再実行/再開/キャンセル/設定変更/権限変更） |
| 3 | userId | N | String | Y | 操作者ID |
| 4 | username | N | String | Y | 操作者名 |
| 5 | operationDateTime | N | DateTime | Y | 操作日時 |
| 6 | operationReason | N | String | N | 操作理由 |
| 7 | targetJobCode | N | String | N | 対象ジョブコード |
| 8 | targetExecutionId | N | String | N | 対象実行ID |
| 9 | result | N | String | N | 操作結果 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの監査ログIDが1つの操作記録を表す |
| 同一性 (Sameness) | 監査ログIDが同じ場合、同じ記録であると判断する |
| カテゴリ (Category) | システム上の操作履歴の記録。誰がいつ何を操作したかを追跡する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | 監査ログは不変の記録であり状態遷移を持たない | - | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-04 | ジョブ実行 | N:1 | 複数の監査ログは1つの実行を対象とする |
| INF-JB-15 | ユーザー情報 | N:1 | 複数の監査ログは1つのユーザーが操作する |
