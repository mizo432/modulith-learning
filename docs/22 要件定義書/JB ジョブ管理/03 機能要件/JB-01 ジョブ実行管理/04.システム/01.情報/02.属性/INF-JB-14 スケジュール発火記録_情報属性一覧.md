# 情報属性一覧

スケジュール発火記録の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-14 |
| 情報名 | スケジュール発火記録 |
| 情報種類 | イベント |
| 説明 | スケジュールに基づく発火日時・対象ジョブの記録 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | fireRecordId | Y | String | Y | 発火記録ID（一意識別子） |
| 2 | scheduleId | N | String | Y | スケジュールID（外部キー） |
| 3 | jobCode | N | String | Y | ジョブコード |
| 4 | firedAt | N | DateTime | Y | 発火日時 |
| 5 | executionId | N | String | N | 関連する実行ID |
| 6 | status | N | Enum | Y | 発火ステータス（成功/失敗） |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの発火記録IDが1回のスケジュール発火を表す |
| 同一性 (Sameness) | 発火記録IDが同じ場合、同じ発火記録であると判断する |
| カテゴリ (Category) | スケジュールに基づくジョブ発火の記録。いつどのジョブが発火したかを追跡する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | 発火記録は不変の記録であり状態遷移を持たない | - | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-13 | スケジュール定義 | N:1 | 複数の発火記録は1つのスケジュールに属する |
| INF-JB-04 | ジョブ実行 | N:1 | 複数の発火記録は1つの実行を参照 |
