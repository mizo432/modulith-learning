# 情報属性一覧

店舗権限の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-08 |
| 情報名 | 店舗権限 |
| 情報種類 | 対応表 |
| 説明 | 店舗単位の権限 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | userId | Y | String | Y | ユーザーID（複合PK） |
| 2 | storeCode | Y | String | Y | 店舗コード（複合PK） |
| 3 | permissionLevel | N | Enum | Y | 権限レベル（参照/編集/管理） |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | ユーザーIDと店舗コードの組み合わせが1つの店舗権限を表す |
| 同一性 (Sameness) | ユーザーIDと店舗コードが同じ場合、同じ権限であると判断する |
| カテゴリ (Category) | ユーザーと店舗の対応関係。店舗単位の参照・編集権限を管理する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | 権限は状態遷移を持たず、権限レベルの変更のみ行われる | - | - | - |
