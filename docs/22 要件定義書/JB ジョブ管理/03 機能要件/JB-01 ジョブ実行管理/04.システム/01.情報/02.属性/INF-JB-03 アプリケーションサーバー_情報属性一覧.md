# 情報属性一覧

アプリケーションサーバーの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-03 |
| 情報名 | アプリケーションサーバー |
| 情報種類 | リソース |
| 説明 | 業務アプリケーションサーバー情報 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | serverId | Y | String | Y | サーバーID（一意識別子） |
| 2 | host | N | String | Y | ホスト名 |
| 3 | port | N | Integer | Y | ポート番号 |
| 4 | protocol | N | String | Y | プロトコル（HTTP/HTTPS等） |
| 5 | serverName | N | String | Y | サーバー名 |
| 6 | environment | N | Enum | Y | 環境（本番/ステージング/開発） |
| 7 | status | N | Enum | Y | 稼働状況（稼働中/停止中/メンテナンス中） |
| 8 | healthCheckUrl | N | String | N | ヘルスチェックURL |
| 9 | lastHealthCheckAt | N | DateTime | N | 最終ヘルスチェック日時 |
| 10 | maxConcurrentJobs | N | Integer | Y | 最大同時実行ジョブ数 |
| 11 | createdAt | N | DateTime | Y | 作成日時 |
| 12 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのサーバーIDが1つのアプリケーションサーバーを表す |
| 同一性 (Sameness) | サーバーIDが同じ場合、同じサーバーであると判断する |
| カテゴリ (Category) | ジョブを実行する業務アプリケーションサーバー。稼働状況、ヘルスチェック情報、同時実行制限を含む |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 稼働中 | サーバーが稼働しジョブ受付可能 | start | 停止中, メンテナンス中 | - |
| 停止中 | サーバーが停止中 | 稼働中 | 稼働中 | - |
| メンテナンス中 | サーバーがメンテナンス中 | 稼働中 | 稼働中 | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-02 | ジョブ配備 | 1:N | 1つのサーバーに複数のジョブが配備される |
| INF-JB-04 | ジョブ実行 | 1:N | 1つのサーバーで複数のジョブ実行が行われる |
