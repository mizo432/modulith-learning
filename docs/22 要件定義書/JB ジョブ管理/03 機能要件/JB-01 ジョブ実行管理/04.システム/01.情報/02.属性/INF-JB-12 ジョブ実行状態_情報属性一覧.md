# 情報属性一覧

ジョブ実行状態の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-12 |
| 情報名 | ジョブ実行状態 |
| 情報種類 | 対照表 |
| 説明 | 待機中、実行中、成功、失敗、結果不明 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | statusCode | Y | String | Y | 状態コード（一意識別子） |
| 2 | statusName | N | String | Y | 状態名 |
| 3 | description | N | String | N | 説明 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの状態コードが1つの実行状態を表す |
| 同一性 (Sameness) | 状態コードが同じ場合、同じ状態であると判断する |
| カテゴリ (Category) | ジョブ実行の状態を定義するマスターデータ。待機中、実行中、成功、失敗、結果不明の5種類 |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | 対照表は状態遷移を持たないマスターデータ | - | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-04 | ジョブ実行 | 1:N | 1つの状態は複数の実行で参照される |

## 値一覧

| 状態コード | 状態名 | 説明 |
|------------|--------|------|
| PENDING | 待機中 | 実行待ちの状態 |
| RUNNING | 実行中 | 実行中の状態 |
| SUCCESS | 成功 | 正常終了した状態 |
| FAILURE | 失敗 | 異常終了した状態 |
| UNKNOWN | 結果不明 | 結果が不明な状態 |
