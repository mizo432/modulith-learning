# 情報属性一覧

ジョブ定義の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-01 |
| 情報名 | ジョブ定義 |
| 情報種類 | リソース |
| 説明 | ジョブコード、パラメータ、実行条件、バージョン |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | jobCode | Y | String | Y | ジョブコード（一意識別子） |
| 2 | jobName | N | String | Y | ジョブ名 |
| 3 | description | N | String | N | 説明 |
| 4 | parameterSpec | N | String | Y | パラメータ仕様（JSON形式） |
| 5 | maxConcurrentExecutions | N | Integer | Y | 最大同時実行数 |
| 6 | timeoutSeconds | N | Integer | Y | タイムアウト秒数 |
| 7 | retryCount | N | Integer | N | リトライ回数 |
| 8 | version | N | String | Y | バージョン番号 |
| 9 | enabled | N | Boolean | Y | 有効フラグ |
| 10 | createdAt | N | DateTime | Y | 作成日時 |
| 11 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのジョブコードが1つのジョブ定義を表す |
| 同一性 (Sameness) | ジョブコードが同じ場合、同じジョブ定義であると判断する |
| カテゴリ (Category) | ジョブ実行管理における実行対象の定義。パラメータ仕様、実行制約、バージョン情報を含む |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 有効 | ジョブ定義が有効で実行可能 | start | 無効 | UC-JB-003 ジョブ定義を無効化する |
| 無効 | ジョブ定義が無効化され新規実行不可 | 有効 | 有効 | UC-JB-002 ジョブ定義を変更する |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-02 | ジョブ配備 | 1:N | 1つのジョブ定義は複数のサーバーに配備される |
| INF-JB-04 | ジョブ実行 | 1:N | 1つのジョブ定義は複数の実行を持つ |
| INF-JB-09 | 通知設定 | 1:N | 1つのジョブ定義に複数の通知設定が紐づく |
| INF-JB-13 | スケジュール定義 | 1:N | 1つのジョブ定義に複数のスケジュールが紐づく |
