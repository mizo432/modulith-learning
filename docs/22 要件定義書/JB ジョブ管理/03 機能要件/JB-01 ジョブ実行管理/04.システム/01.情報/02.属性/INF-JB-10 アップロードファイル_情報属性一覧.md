# 情報属性一覧

アップロードファイルの属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-10 |
| 情報名 | アップロードファイル |
| 情報種類 | リソース |
| 説明 | S3/MinIO上のファイル参照情報 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | fileId | Y | String | Y | ファイルID（一意識別子） |
| 2 | fileName | N | String | Y | ファイル名 |
| 3 | filePath | N | String | Y | ストレージ上のパス |
| 4 | fileSize | N | Long | Y | ファイルサイズ（バイト） |
| 5 | contentType | N | String | N | MIMEタイプ |
| 6 | storageProvider | N | Enum | Y | ストレージプロバイダ（S3/MinIO） |
| 7 | bucketName | N | String | Y | バケット名 |
| 8 | uploadedAt | N | DateTime | Y | アップロード日時 |
| 9 | createdAt | N | DateTime | Y | 作成日時 |
| 10 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つのファイルIDが1つのアップロードファイルを表す |
| 同一性 (Sameness) | ファイルIDが同じ場合、同じファイルであると判断する |
| カテゴリ (Category) | S3/MinIOにアップロードされたファイルの参照情報。ジョブ実行の入出力ファイルとして使用される |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| - | ファイルは状態遷移を持たず、アップロード・削除のみ行われる | - | - | - |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-04 | ジョブ実行 | N:1 | 複数のファイルは1つの実行に関連する |
| INF-JB-17 | 実行とファイルの関連 | 1:N | 1つのファイルは複数の実行と関連する |
