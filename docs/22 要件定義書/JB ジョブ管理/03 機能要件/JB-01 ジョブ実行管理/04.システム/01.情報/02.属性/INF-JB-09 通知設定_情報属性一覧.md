# 情報属性一覧

通知設定の属性をリストアップします。

## 情報概要

| 項目 | 内容 |
|------|------|
| 情報ID | INF-JB-09 |
| 情報名 | 通知設定 |
| 情報種類 | リソース |
| 説明 | 通知情報 |

## 属性一覧

TM（T字形ER）モデルに基づき、個体指定子と属性を定義します。

| 番号 | 属性名 | 個体指定子 | 型 | 必須 | 説明 |
|------|--------|------------|----|------|------|
| 1 | notificationSettingId | Y | String | Y | 通知設定ID（一意識別子） |
| 2 | jobCode | N | String | N | ジョブコード（null: 全ジョブ対象） |
| 3 | onSuccess | N | Boolean | Y | 成功時に通知するフラグ |
| 4 | onFailure | N | Boolean | Y | 失敗時に通知するフラグ |
| 5 | onUnknown | N | Boolean | N | 結果不明時に通知するフラグ |
| 6 | destination | N | String | Y | 通知先（メール/Slackチャンネル等） |
| 7 | channel | N | Enum | Y | 通知チャネル（メール/Slack/LINE等） |
| 8 | enabled | N | Boolean | Y | 有効フラグ |
| 9 | createdAt | N | DateTime | Y | 作成日時 |
| 10 | updatedAt | N | DateTime | Y | 更新日時 |

## 属性の型

属性の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）

## 単一性・同一性・カテゴリ

エンティティの3大要素について定義します：

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 1つの通知設定IDが1つの通知設定を表す |
| 同一性 (Sameness) | 通知設定IDが同じ場合、同じ通知設定であると判断する |
| カテゴリ (Category) | ジョブ実行結果に基づく通知の設定。条件、宛先、チャネルを定義する |

## 状態遷移

この情報が持つ状態と遷移を定義します（該当する場合）。

| 状態名 | 説明 | 遷移元 | 遷移先 | トリガーとなるユースケース |
|--------|------|--------|--------|--------------------------|
| 有効 | 通知設定が有効 | start | 無効 | UC-JB-022 通知設定を管理する |
| 無効 | 通知設定が無効 | 有効 | 有効 | UC-JB-022 通知設定を管理する |

## 関連情報

この情報と関連する他の情報をリストアップします。

| 関連情報ID | 関連情報名 | 関係の種類 | 説明 |
|------------|------------|------------|------|
| INF-JB-01 | ジョブ定義 | N:1 | 複数の通知設定は1つのジョブ定義を参照（nullの場合は全ジョブ） |
| INF-JB-16 | 通知履歴 | 1:N | 1つの通知設定から複数の通知履歴が生成される |
