# 論理データモデル

## 概要

JB-01 ジョブ実行管理業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    JOB_DEFINITION
    {
        string JOB_DEFINITION_ID PK "ジョブ定義ID"
        string コード "コード"
        string パラメータ "パラメータ"
        string 実行条件 "実行条件"
        string バージョン "バージョン"
        string 状態 "状態"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(ジョブ定義)"
        enum variation "バリエーション(ジョブタイプ)"
        string created_at "作成日"
        string updated_at "更新日"
    }

    JOB_EXECUTION
    {
        string JOB_EXECUTION_ID PK "ジョブ実行ID"
        string 状態 "状態"
        string 開始時刻 "開始時刻"
        string 終了時刻 "終了時刻"
        string 結果 "結果"
        string エラー "エラー"
        string 作成日 "作成日"
        string state "状態(ジョブ実行)"
        enum variation "バリエーション(ジョブ実行状態)"
        string created_at "作成日"
        string updated_at "更新日"
    }
    JOB_DEFINITION }|--|| JOB_EXECUTION : ジョブ定義
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| ジョブ定義 | JOB_DEFINITION_ID | string | true | ジョブ定義ID |
| ジョブ実行 | JOB_EXECUTION_ID | string | true | ジョブ実行ID |
