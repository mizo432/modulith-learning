# バリエーション・条件図 - JB ジョブ実行管理

本ファイルは、JBジョブ実行管理システムのバリエーションと条件を表形式で定義したものです。

- **バリエーション** はビジネス上に登場する値であり、重要なビジネスルールの基準になるような情報です。
- **条件** は単純なものは「名前つけられた条件」としてまとめ、バリエーションの組み合わせで条件が決まるものは条件ごとに表形式で表現します。

## 1. バリエーション

### ジョブ種別

| バリエーション名 | 説明                                           |
|------------------|------------------------------------------------|
| 定期ジョブ       | スケジュールに従って定期的に実行されるジョブ   |
| 手動ジョブ       | 手動で起動するジョブ                           |
| API起動ジョブ    | 外部システムからAPI経由で起動するジョブ        |

### 実行タイプ

| バリエーション名 | 説明                                               |
|------------------|----------------------------------------------------|
| 単一実行         | 1つのサーバーで実行するジョブ                      |
| 分散実行         | 複数のサーバーで並列実行するジョブ                 |

### サーバー種別

| バリエーション名 | 説明                                     |
|------------------|------------------------------------------|
| 本番サーバー     | 本番環境の業務アプリケーションサーバー   |
| 検証サーバー     | 検証環境の業務アプリケーションサーバー   |
| 開発サーバー     | 開発環境の業務アプリケーションサーバー   |

### ジョブ実行状態

| バリエーション名 | 説明                                   |
|------------------|----------------------------------------|
| 待機中           | 実行を待っている状態                   |
| 実行中           | 現在実行中の状態                       |
| 成功             | 正常に完了した状態                     |
| 失敗             | 異常終了した状態                       |
| 結果不明         | 実行結果が確認できない状態             |
| キャンセル済み   | キャンセルされた状態                   |

### 起動タイプ

| バリエーション名 | 説明                                     |
|------------------|------------------------------------------|
| スケジュール起動 | スケジュールに従って起動したジョブ       |
| 手動起動         | 手動で起動したジョブ                     |
| API起動          | API経由で起動したジョブ                  |

### 会社タイプ

| バリエーション名 | 説明                           |
|------------------|--------------------------------|
| 本社             | 本社会社                       |
| 支社             | 支社会社                       |
| 関連会社         | 関連会社                       |

### 店舗タイプ

| バリエーション名 | 説明                           |
|------------------|--------------------------------|
| 直営店           | 直営店舗                       |
| フランチャイズ   | フランチャイズ店舗             |
| アウトレット     | アウトレット店舗               |

### 通知方法

| バリエーション名 | 説明                           |
|------------------|--------------------------------|
| メール           | メール通知                     |
| SMS              | SMS通知                        |
| システム通知     | システム内通知                 |

### 通知条件

| バリエーション名 | 説明                                   |
|------------------|----------------------------------------|
| 成功時           | ジョブが正常に完了した場合             |
| 失敗時           | ジョブが異常終了した場合               |
| 結果不明時       | ジョブの結果が不明確になった場合       |
| 実行開始時       | ジョブ実行が開始した場合               |

### ファイル種別

| バリエーション名 | 説明                           |
|------------------|--------------------------------|
| CSV              | CSVファイル                    |
| JSON             | JSONファイル                   |
| XML              | XMLファイル                    |
| ZIP              | 圧縮ファイル                   |

### 操作タイプ

| バリエーション名 | 説明                                   |
|------------------|----------------------------------------|
| 手動起動         | 手動でのジョブ起動操作                 |
| 再実行           | ジョブの再実行操作                     |
| 途中再開         | チェックポイントからの再開操作         |
| キャンセル       | 実行中のジョブのキャンセル操作         |
| 設定変更         | ジョブ設定の変更操作                   |
| 権限変更         | 権限設定の変更操作                     |

## 2. 名前つけられた式

| 名前           | 式                                 | 説明                           |
|----------------|------------------------------------|--------------------------------|
| 実行期限       | 起動日時 + 実行タイムアウト        | ジョブ実行の期限               |
| 再実行間隔     | 前回の終了日時 + 再実行待機時間    | 再実行可能なまでの待機時間     |

## 3. 条件

### 同時実行制限: 条件

ジョブ種別と実行タイプによる同時実行数の制限を定義します。

| ジョブ種別 \ 実行タイプ | 単一実行 | 分散実行       |
|-------------------------|----------|----------------|
| 定期ジョブ              | 1        | サーバー数×1   |
| 手動ジョブ              | 1        | 不可           |
| API起動ジョブ           | 1        | 不可           |

### 権限範囲: 条件

会社タイプによる参照可能な範囲を定義します。

| 会社タイプ | 参照範囲                           |
|------------|------------------------------------|
| 本社       | 全会社・全店舗                     |
| 支社       | 自社および所属店舗                 |
| 関連会社   | 自社のみ                           |

### 通知対象: 条件

ジョブ実行状態と通知条件による通知方法を定義します。

| ジョブ実行状態 \ 通知条件 | 成功時     | 失敗時         | 結果不明時     | 実行開始時   |
|---------------------------|------------|----------------|----------------|--------------|
| 待機中                    | -          | -              | -              | システム通知 |
| 実行中                    | -          | -              | -              | -            |
| 成功                      | メール     | -              | -              | -            |
| 失敗                      | -          | メール, SMS    | -              | -            |
| 結果不明                  | -          | -              | メール, SMS    | -            |
| キャンセル済み            | -          | -              | -              | -            |

## 4. 補足

- バリエーション・条件図は、RDRAの「システムレイヤー」で使用する表形式のモデルです。
- 条件はユースケース複合図で `control` アイコンとして参照されます。
- 3軸以上の組み合わせでもマトリックス形式で表現可能です。
