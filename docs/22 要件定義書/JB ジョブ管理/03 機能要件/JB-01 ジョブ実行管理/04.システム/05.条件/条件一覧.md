# 条件一覧

ジョブ実行管理業務領域のビジネスルール（条件）を定義します。

| 条件ID   | 条件名                       | 英語名                      | 種類         | 説明                                                   | 関連ユースケース |
|----------|------------------------------|-----------------------------|--------------|--------------------------------------------------------|------------------|
| RL-JB-01 | 重複起動防止                 | Idempotency Check           | ポリシー     | 実行IDを冪等性キーとして同じ要求による二重起動を抑止   | UC-JB-008, UC-JB-009 |
| RL-JB-02 | 同時実行枠制御               | Concurrent Execution Limit  | ポリシー     | 同時に実行できるジョブの上限数を制御                   | UC-JB-008〜UC-JB-010 |
| RL-JB-03 | 実行権限チェック             | Execution Permission Check  | ポリシー     | ジョブ実行の権限を確認                                 | UC-JB-008, UC-JB-009 |
| RL-JB-04 | 再実行可否判定               | Re-execution Eligibility    | 意思決定支援 | 再実行可能な状態か判定                                 | UC-JB-019        |
| RL-JB-05 | 途中再開可否判定             | Resume Eligibility          | 意思決定支援 | チェックポイントから再開可能か判定                     | UC-JB-020        |
| RL-JB-06 | 結果不明時復旧ルール         | Unknown Result Recovery     | ポリシー     | 結果不明時に無条件で再実行しない                       | UC-JB-019        |
| RL-JB-07 | 会社・店舗権限フィルタ       | Company Store Filter        | ポリシー     | 会社・店舗単位で参照範囲を制限                         | UC-JB-025, UC-JB-026 |
| RL-JB-08 | バージョン互換性チェック     | Version Compatibility       | ポリシー     | 実行時のジョブバージョンとサーバーの互換性を確認       | UC-JB-008〜UC-JB-010 |
