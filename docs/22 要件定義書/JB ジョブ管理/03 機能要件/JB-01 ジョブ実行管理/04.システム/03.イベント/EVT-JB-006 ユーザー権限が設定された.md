# ユーザー権限が設定された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-006 |
| イベント名 | ユーザー権限が設定された |
| 説明 | ユーザーのロール、会社・店舗の参照権限が設定された |
| 関連ユースケース | UC-JB-007 |
| 関連情報 | INF-JB-07, INF-JB-08 |
| 集約 | 権限 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ユーザーID | 文字列 | はい | 権限が設定されたユーザーの識別子 |
| ロール | 文字列 | はい | 設定されたロール |
| 会社権限 | 文字列 | いいえ | 設定された会社単位の権限 |
| 店舗権限 | 文字列 | いいえ | 設定された店舗単位の権限 |
