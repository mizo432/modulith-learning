# スケジュール起動が実行された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-009 |
| イベント名 | スケジュール起動が実行された |
| 説明 | 設定された実行日時・条件に従ってジョブが起動された |
| 関連ユースケース | UC-JB-010 |
| 関連情報 | INF-JB-04 |
| 集約 | ジョブ実行 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | スケジュール起動されたジョブの識別コード |
| スケジュールID | 文字列 | はい | 実行されたスケジュールの識別子 |
