# ジョブが途中再開された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-018 |
| イベント名 | ジョブが途中再開された |
| 説明 | チェックポイントからジョブが再開された |
| 関連ユースケース | UC-JB-020 |
| 関連情報 | INF-JB-04, INF-JB-06 |
| 集約 | ジョブ実行 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | 再開されたジョブの識別コード |
| 元の実行ID | 文字列 | はい | 再開前のジョブ実行ID |
| 新しい実行ID | 文字列 | はい | 再開後のジョブ実行ID |
| チェックポイント | テキスト | はい | 再開元のチェックポイント情報 |
| 再開ユーザー | 文字列 | はい | 再開を要求したユーザー |
