# スケジュールが登録された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-010 |
| イベント名 | スケジュールが登録された |
| 説明 | 実行日時、繰り返し条件、対象ジョブ、有効期間が設定された |
| 関連ユースケース | UC-JB-011 |
| 関連情報 | INF-JB-01 |
| 集約 | ジョブ定義 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | スケジュールが設定されたジョブの識別コード |
| 実行日時 | 日付 | はい | 設定された実行日時 |
| 繰り返し条件 | テキスト | いいえ | 繰り返し実行の条件 |
| 有効期間開始 | 日付 | いいえ | スケジュールの有効期間開始日 |
| 有効期間終了 | 日付 | いいえ | スケジュールの有効期間終了日 |
