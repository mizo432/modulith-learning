# ジョブ実行が成功した

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-013 |
| イベント名 | ジョブ実行が成功した |
| 説明 | ジョブが正常に完了した |
| 関連ユースケース | - |
| 関連情報 | INF-JB-04, INF-JB-06 |
| 集約 | ジョブ実行 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | 成功したジョブの識別コード |
| 実行ID | 文字列 | はい | ジョブ実行の一意な識別子 |
| 実行時間 | 数値 | いいえ | 実行に要した時間（秒） |
