# スケジュールが変更された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-011 |
| イベント名 | スケジュールが変更された |
| 説明 | 既存のスケジュール設定が修正された |
| 関連ユースケース | UC-JB-012 |
| 関連情報 | INF-JB-01 |
| 集約 | ジョブ定義 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | スケジュールが変更されたジョブの識別コード |
| 変更内容 | テキスト | はい | 変更されたスケジュール設定の詳細 |
