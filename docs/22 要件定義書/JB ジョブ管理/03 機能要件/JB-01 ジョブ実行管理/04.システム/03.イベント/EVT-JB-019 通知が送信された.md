# 通知が送信された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-019 |
| イベント名 | 通知が送信された |
| 説明 | 成功・異常終了などの通知が送信された |
| 関連ユースケース | UC-JB-022 |
| 関連情報 | INF-JB-09 |
| 集約 | 通知設定 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | 通知対象のジョブの識別コード |
| 実行ID | 文字列 | はい | 通知対象のジョブ実行ID |
| 通知タイプ | 選択 | はい | 通知のタイプ（成功、失敗、結果不明など） |
| 送信先 | 文字列 | はい | 通知の送信先 |
