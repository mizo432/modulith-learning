# ジョブがキャンセルされた

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-016 |
| イベント名 | ジョブがキャンセルされた |
| 説明 | 実行中のジョブがキャンセルされた |
| 関連ユースケース | UC-JB-018 |
| 関連情報 | INF-JB-04, INF-JB-06 |
| 集約 | ジョブ実行 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | キャンセルされたジョブの識別コード |
| 実行ID | 文字列 | はい | ジョブ実行の一意な識別子 |
| キャンセルユーザー | 文字列 | はい | キャンセルを実行したユーザー |
