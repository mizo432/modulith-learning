# 会社・店舗が登録された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-020 |
| イベント名 | 会社・店舗が登録された |
| 説明 | 会社と店舗の登録、所属関係が管理された |
| 関連ユースケース | UC-JB-027 |
| 関連情報 | INF-JB-07, INF-JB-08 |
| 集約 | 権限 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| 会社名 | 文字列 | はい | 登録された会社名 |
| 店舗名 | 文字列 | いいえ | 登録された店舗名 |
| 所属関係 | テキスト | いいえ | 会社と店舗の所属関係 |
