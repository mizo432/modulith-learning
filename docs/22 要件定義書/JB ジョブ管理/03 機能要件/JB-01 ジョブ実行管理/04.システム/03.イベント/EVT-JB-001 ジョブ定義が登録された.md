# ジョブ定義が登録された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-001 |
| イベント名 | ジョブ定義が登録された |
| 説明 | ジョブコード、パラメータ仕様、実行制約などが新規登録された |
| 関連ユースケース | UC-JB-001 |
| 関連情報 | INF-JB-01 |
| 集約 | ジョブ定義 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | ジョブの一意な識別コード |
| パラメータ仕様 | テキスト | いいえ | ジョブ実行時のパラメータ仕様 |
| 実行制約 | テキスト | いいえ | 実行時の制約条件 |
| バージョン | 文字列 | いいえ | ジョブ定義のバージョン |
