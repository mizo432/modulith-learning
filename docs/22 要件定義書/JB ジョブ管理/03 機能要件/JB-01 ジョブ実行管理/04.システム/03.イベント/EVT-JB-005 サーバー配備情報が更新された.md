# サーバー配備情報が更新された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-005 |
| イベント名 | サーバー配備情報が更新された |
| 説明 | サーバー情報やジョブ配備状況・バージョンが修正された |
| 関連ユースケース | UC-JB-006 |
| 関連情報 | INF-JB-02, INF-JB-03 |
| 集約 | ジョブ配備 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| サーバー名 | 文字列 | はい | 更新されたサーバー名 |
| ジョブコード | 文字列 | はい | 更新されたジョブの識別コード |
| 変更内容 | テキスト | はい | 変更された配備状況・バージョンの詳細 |
