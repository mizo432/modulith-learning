# ジョブ実行が開始された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-012 |
| イベント名 | ジョブ実行が開始された |
| 説明 | ジョブ実行が待機中から実行中に遷移した |
| 関連ユースケース | UC-JB-008, UC-JB-009, UC-JB-010 |
| 関連情報 | INF-JB-04, INF-JB-06 |
| 集約 | ジョブ実行 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | 実行が開始されたジョブの識別コード |
| 実行ID | 文字列 | はい | ジョブ実行の一意な識別子 |
| 起動方法 | 選択 | はい | 起動方法（手動、API、スケジュール） |
