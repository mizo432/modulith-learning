# サーバー配備情報が登録された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-004 |
| イベント名 | サーバー配備情報が登録された |
| 説明 | 業務アプリケーションサーバーとジョブの配備情報が登録された |
| 関連ユースケース | UC-JB-005 |
| 関連情報 | INF-JB-02, INF-JB-03 |
| 集約 | ジョブ配備 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| サーバー名 | 文字列 | はい | 配備先のサーバー名 |
| ジョブコード | 文字列 | はい | 配備されたジョブの識別コード |
| バージョン | 文字列 | いいえ | 配備されたバージョン |
