# ジョブが再実行された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-017 |
| イベント名 | ジョブが再実行された |
| 説明 | 異常終了したジョブが最初から再実行された |
| 関連ユースケース | UC-JB-019 |
| 関連情報 | INF-JB-04, INF-JB-06 |
| 集約 | ジョブ実行 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | 再実行されたジョブの識別コード |
| 元の実行ID | 文字列 | はい | 再実行前のジョブ実行ID |
| 新しい実行ID | 文字列 | はい | 再実行後のジョブ実行ID |
| 再実行ユーザー | 文字列 | はい | 再実行を要求したユーザー |
