# ジョブが手動起動された

イベントの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| イベントID | EVT-JB-007 |
| イベント名 | ジョブが手動起動された |
| 説明 | 運用管理者が対象ジョブを指定して手動起動した |
| 関連ユースケース | UC-JB-008 |
| 関連情報 | INF-JB-04 |
| 集約 | ジョブ実行 |

## 属性

| 項目名 | 型 | 必須 | 説明 |
|--------|----|------|------|
| ID | 文字列 | はい | イベントの一意な識別子 |
| 発生日時 | 日付 | はい | イベントが発生した日時 |
| ジョブコード | 文字列 | はい | 起動されたジョブの識別コード |
| 起動ユーザー | 文字列 | はい | 手動起動したユーザーの識別子 |
| パラメータ | テキスト | いいえ | 起動時に指定されたパラメータ |
