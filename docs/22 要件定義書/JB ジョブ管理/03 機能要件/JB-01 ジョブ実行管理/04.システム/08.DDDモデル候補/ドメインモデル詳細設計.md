# ドメインモデル詳細設計

JBジョブ管理の8つのアグリゲートごとに、エンティティ、値オブジェクト、リポジトリ、ドメインサービスの詳細を定義します。

## 1. AG-JB-01: ジョブ定義 (JobDefinition)

**サブドメイン:** SD-JB-01: ジョブ定義管理 (コアドメイン)  
**関連情報:** INF-JB-01 (ジョブ定義)  
**関連イベント:** EVT-JB-001, EVT-JB-002, EVT-JB-003

### 1.1 エンティティ

#### JobDefinition (ジョブ定義)

| 項目 | 説明 |
|------|------|
| ID | JobCode (ジョブコード) |
| 概要 | ジョブのコード、パラメータ、実行条件、バージョンを管理するルートエンティティ |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| jobCode | JobCode | Y | ジョブを一意に識別するコード |
| jobName | String | Y | ジョブ名 |
| description | String | N | 説明 |
| parameterSpec | ParameterSpec | Y | パラメータの仕様定義 |
| executionConstraint | ExecutionConstraint | Y | 同時実行数、タイムアウトなどの制約 |
| version | JobVersion | Y | バージョン番号 |
| enabled | Boolean | Y | 有効フラグ |
| createdAt | LocalDateTime | Y | 作成日時 |
| updatedAt | LocalDateTime | Y | 更新日時 |

**ドメインメソッド**

| メソッド名 | 説明 |
|-----------|------|
| changeParameterSpec(ParameterSpec) | パラメータ仕様を変更 |
| changeExecutionConstraint(ExecutionConstraint) | 実行制約を変更 |
| disable() | ジョブ定義を無効化 |
| enable() | ジョブ定義を有効化 |

### 1.2 値オブジェクト

#### JobCode (ジョブコード)

| 項目 | 説明 |
|------|------|
| 概要 | ジョブを一意に識別するコード |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| value | String | Y | ジョブコードの値 (最大50文字) |

**制約**
- 半角英数字とアンダースコアのみ使用可能
- 最大50文字

#### ParameterSpec (パラメータ仕様)

| 項目 | 説明 |
|------|------|
| 概要 | パラメータの仕様定義 |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| parameters | List<ParameterItem> | Y | パラメータ項目のリスト |

**ParameterItem**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| name | String | Y | パラメータ名 |
| type | String | Y | データ型 |
| required | Boolean | Y | 必須フラグ |
| defaultValue | String | N | デフォルト値 |
| description | String | N | 説明 |

#### ExecutionConstraint (実行制約)

| 項目 | 説明 |
|------|------|
| 概要 | 同時実行数、タイムアウトなどの制約 |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| maxConcurrentExecutions | Integer | Y | 最大同時実行数 |
| timeoutSeconds | Integer | Y | タイムアウト秒数 |
| retryCount | Integer | N | リトライ回数 |

#### JobVersion (ジョブバージョン)

| 項目 | 説明 |
|------|------|
| 概要 | バージョン番号 |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| version | String | Y | バージョン番号 (例: 1.0.0) |

### 1.3 リポジトリ

#### JobDefinitionRepository

| メソッド名 | 説明 |
|-----------|------|
| findById(JobCode) | ジョブコードで検索 |
| findAll() | 全件取得 |
| findByEnabled(Boolean) | 有効フラグで検索 |
| save(JobDefinition) | 保存 |
| delete(JobDefinition) | 削除 |

## 4. AG-JB-04: ジョブ実行 (JobExecution)

**サブドメイン:** SD-JB-02: ジョブ実行制御 (コアドメイン)  
**関連情報:** INF-JB-04 (ジョブ実行), INF-JB-05 (実行枠), INF-JB-06 (実行イベント)  
**関連イベント:** EVT-JB-007~009, EVT-JB-012~018  
**関連ビジネスルール:** RL-JB-01~06

### 4.1 エンティティ

#### JobExecution (ジョブ実行)

| 項目 | 説明 |
|------|------|
| ID | ExecutionId (実行ID) |
| 概要 | 実行状態・結果・履歴を管理するルートエンティティ |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| executionId | ExecutionId | Y | 実行を一意に識別するID |
| jobCode | JobCode | Y | 実行対象のジョブコード |
| jobVersion | JobVersion | Y | 実行時のジョブバージョン |
| serverAddress | ServerAddress | Y | 実行先のサーバーアドレス |
| executionState | ExecutionState | Y | 実行状態 |
| executionParameter | ExecutionParameter | N | 実行時のパラメータ |
| checkpoint | Checkpoint | N | チェックポイント位置 |
| processedCount | ProcessedCount | N | 処理した件数 |
| errorInfo | ErrorInfo | N | エラー情報 |
| startedAt | LocalDateTime | N | 開始日時 |
| finishedAt | LocalDateTime | N | 終了日時 |
| createdAt | LocalDateTime | Y | 作成日時 |
| updatedAt | LocalDateTime | Y | 更新日時 |

**ドメインメソッド**

| メソッド名 | 説明 |
|-----------|------|
| start() | 実行を開始 (待機中 → 実行中) |
| succeed() | 実行を成功 (実行中 → 成功) |
| fail(ErrorInfo) | 実行を失敗 (実行中 → 失敗) |
| cancel() | 実行をキャンセル (実行中 → キャンセル済み) |
| reExecute() | 再実行 (失敗 → 待機中) |
| resume() | 途中再開 (失敗 → 実行中) |
| markUnknown() | 結果不明 (実行中 → 結果不明) |

#### ExecutionSlot (実行枠)

| 項目 | 説明 |
|------|------|
| ID | SlotId (枠ID) |
| 概要 | 同時実行枠を管理 |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| slotId | SlotId | Y | 実行枠を一意に識別するID |
| maxSlots | Integer | Y | 最大同時実行枠数 |
| usedSlots | Integer | Y | 使用中の枠数 |
| updatedAt | LocalDateTime | Y | 更新日時 |

**ドメインメソッド**

| メソッド名 | 説明 |
|-----------|------|
| acquire() | 実行枠を取得 |
| release() | 実行枠を解放 |
| isAvailable() | 実行枠が利用可能か判定 |

### 4.2 値オブジェクト

#### ExecutionId (実行ID)

| 項目 | 説明 |
|------|------|
| 概要 | 実行を一意に識別するID |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| value | UUID | Y | 実行ID |

#### ExecutionState (実行状態)

| 項目 | 説明 |
|------|------|
| 概要 | ジョブ実行の状態 |

**値一覧**

| 値 | 説明 |
|----|------|
| PENDING | 待機中 |
| RUNNING | 実行中 |
| SUCCESS | 成功 |
| FAILURE | 失敗 |
| UNKNOWN | 結果不明 |
| RE_EXECUTED | 再実行済み |
| RESUMED | 再開済み |
| CANCELLED | キャンセル済み |

#### ExecutionParameter (実行パラメータ)

| 項目 | 説明 |
|------|------|
| 概要 | 実行時のパラメータ |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| parameters | Map<String, String> | Y | パラメータのキー値ペア |

#### Checkpoint (チェックポイント)

| 項目 | 説明 |
|------|------|
| 概要 | 途中再開のためのチェックポイント位置 |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| position | String | Y | チェックポイントの位置 |
| timestamp | LocalDateTime | Y | チェックポイントのタイムスタンプ |

#### ProcessedCount (処理件数)

| 項目 | 説明 |
|------|------|
| 概要 | 処理した件数 |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| count | Long | Y | 処理件数 |

#### ErrorInfo (エラー情報)

| 項目 | 説明 |
|------|------|
| 概要 | エラーコード、メッセージ、発生箇所 |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| errorCode | String | Y | エラーコード |
| errorMessage | String | Y | エラーメッセージ |
| errorLocation | String | N | 発生箇所 |
| occurredAt | LocalDateTime | Y | 発生日時 |

#### SlotId (枠ID)

| 項目 | 説明 |
|------|------|
| 概要 | 実行枠を一意に識別するID |

**プロパティ**

| プロパティ名 | 型 | 必須 | 説明 |
|-------------|-----|------|------|
| value | UUID | Y | 枠ID |

### 4.3 リポジトリ

#### JobExecutionRepository

| メソッド名 | 説明 |
|-----------|------|
| findById(ExecutionId) | 実行IDで検索 |
| findByJobCode(JobCode) | ジョブコードで検索 |
| findByState(ExecutionState) | 実行状態で検索 |
