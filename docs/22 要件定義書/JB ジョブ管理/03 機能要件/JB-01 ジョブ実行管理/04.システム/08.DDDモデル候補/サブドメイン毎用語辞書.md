# サブドメイン毎用語辞書

JBジョブ管理の4つのサブドメインごとに用語を整理します。

## 1. SD-JB-01: ジョブ定義管理

**サブドメイン:** ジョブ定義管理 (Job Definition Management)  
**種類:** コアドメイン

| ID     | 用語名             | 説明                                                     |
|--------|--------------------|----------------------------------------------------------|
| TERM-02 | ジョブ定義         | ジョブのコード、パラメータ、実行条件、バージョンの情報   |
| TERM-14 | 配備               | ジョブ定義をサーバーに配置する状態                       |

---

## 2. SD-JB-02: ジョブ実行制御

**サブドメイン:** ジョブ実行制御 (Job Execution Control)  
**種類:** コアドメイン

| ID     | 用語名             | 説明                                                     |
|--------|--------------------|----------------------------------------------------------|
| TERM-01 | ジョブ             | 業務システムに組み込まれたバッチ処理や定期処理           |
| TERM-03 | ジョブ実行         | ジョブの実行状態・結果・履歴                             |
| TERM-05 | 同時実行枠         | 同時に実行できるジョブの上限数                           |
| TERM-06 | 再実行             | 失敗したジョブを最初から再度実行する操作                 |
| TERM-07 | 途中再開           | チェックポイントからジョブを再開する操作                 |
| TERM-08 | チェックポイント   | ジョブ実行の進捗を保存し、再開時に利用する情報           |
| TERM-09 | 冪等性             | 同じ操作を何度実行しても結果が同じである性質             |
| TERM-11 | 実行イベント       | ジョブ実行中の状態遷移を記録するイベント                 |
| TERM-15 | 結果不明           | 起動APIタイムアウトなどで実行結果が判らない状態          |
| TERM-18 | 重複起動防止       | 実行IDを冪等性キーとして同じ要求による二重起動を抑止するルール |
| TERM-19 | 実行権限チェック   | ジョブ実行時にユーザーの権限を確認するルール             |
| TERM-20 | バージョン互換性   | 実行時のジョブバージョンとサーバーの互換性を確認するルール |

---

## 3. SD-JB-03: 実行監視

**サブドメイン:** 実行監視 (Execution Monitoring)  
**種類:** サポートリングドメイン

| ID     | 用語名             | 説明                                                     |
|--------|--------------------|----------------------------------------------------------|
| TERM-10 | 監査ログ           | 操作履歴を記録し、追跡可能性を確保するログ               |
| TERM-12 | 通知設定           | ジョブ実行結果に基づく通知の条件と宛先                   |

---

## 4. SD-JB-04: 権限管理

**サブドメイン:** 権限管理 (Permission Management)  
**種類:** サポートリングドメイン

| ID     | 用語名             | 説明                                                     |
|--------|--------------------|----------------------------------------------------------|
| TERM-13 | 権限管理           | システム・会社・店舗単位での参照・操作権限の制御         |

---

## 5. 共通用語

複数のサブドメインで使用する共通の用語です。

| ID     | 用語名             | 説明                                                     | 関連サブドメイン |
|--------|--------------------|----------------------------------------------------------|------------------|
| TERM-04 | 実行先サーバー     | ジョブを実行する業務アプリケーションサーバー             | SD-JB-01, SD-JB-02 |
| TERM-16 | ビジネスルール     | システムの動作を制約する条件やポリシー                   | 全サブドメイン |
| TERM-17 | バリエーション     | ビジネスルールを成り立たせるための変数や分類             | 全サブドメイン |

---
