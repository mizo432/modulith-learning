# サブドメイン毎ユースケース図

JBジョブ管理の4つのサブドメインごとにユースケース図をPlantUMLで定義します。

## 1. SD-JB-01: ジョブ定義管理

**サブドメイン:** ジョブ定義管理 (Job Definition Management)  
**種類:** コアドメイン  
**関連BUC:** BUC-JB-01  
**ユースケース:** UC-JB-001~006, UC-JB-011~012 (8件)

### ユースケース一覧

| ユースケースID | ユースケース名 | アクター | 画面 |
|----------------|----------------|----------|------|
| UC-JB-001 | ジョブ定義を登録する | AC-01 | SCR-JB-009 |
| UC-JB-002 | ジョブ定義を変更する | AC-01 | SCR-JB-009 |
| UC-JB-003 | ジョブ定義を無効化する | AC-01 | SCR-JB-008 |
| UC-JB-004 | ジョブ定義を参照する | AC-01 | SCR-JB-007, SCR-JB-008 |
| UC-JB-005 | サーバー配備情報を登録する | AC-01 | SCR-JB-019 |
| UC-JB-006 | サーバー配備情報を更新する | AC-01 | SCR-JB-019 |
| UC-JB-011 | スケジュールを登録する | AC-01 | SCR-JB-011 |
| UC-JB-012 | スケジュールを変更する | AC-01 | SCR-JB-011 |

### PlantUML ユースケース図

```plantuml
@startuml
left to right direction
skinparam packageStyle rectangle

actor "運用管理者\n(AC-01)" as AC01

package "SD-JB-01: ジョブ定義管理" {
  usecase "ジョブ定義を登録する\n(UC-JB-001)" as UC001
  usecase "ジョブ定義を変更する\n(UC-JB-002)" as UC002
  usecase "ジョブ定義を無効化する\n(UC-JB-003)" as UC003
  usecase "ジョブ定義を参照する\n(UC-JB-004)" as UC004
  usecase "サーバー配備情報を登録する\n(UC-JB-005)" as UC005
  usecase "サーバー配備情報を更新する\n(UC-JB-006)" as UC006
  usecase "スケジュールを登録する\n(UC-JB-011)" as UC011
  usecase "スケジュールを変更する\n(UC-JB-012)" as UC012
}

AC01 --> UC001
AC01 --> UC002
AC01 --> UC003
```
