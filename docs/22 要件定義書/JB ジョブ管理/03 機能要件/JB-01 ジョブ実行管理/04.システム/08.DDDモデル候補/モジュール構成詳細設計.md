# モジュール構成詳細設計

JBジョブ管理の4つのモジュールの境界、依存関係、パッケージ構成、通信方法を詳細に定義します。

## 1. モジュール構成概要

| モジュール名 | サブドメイン | 種類 | 概要 |
|-------------|--------------|------|------|
| job-definition | SD-JB-01 | コアドメイン | ジョブ定義・配備・スケジュールの管理 |
| job-execution | SD-JB-02 | コアドメイン | ジョブ実行制御・状態管理 |
| execution-monitoring | SD-JB-03 | サポートリングドメイン | 実行監視・通知 |
| permission-management | SD-JB-04 | サポートリングドメイン | 権限管理・監査ログ |

## 2. モジュール間の依存関係

```
┌─────────────────────┐
│  job-definition     │ (コアドメイン)
│                     │
│  AG-JB-01 ジョブ定義│
│  AG-JB-02 ジョブ配備│
│  AG-JB-03 スケジュール│
└─────────┬───────────┘
          │ 依存 (ジョブ定義情報を参照)
          ▼
┌─────────────────────┐
│  job-execution      │ (コアドメイン)
│                     │
│  AG-JB-04 ジョブ実行│
└─────────┬───────────┘
          │ 連携 (実行結果を通知)
          ▼
┌─────────────────────┐
│  execution-monitoring│ (サポートリングドメイン)
│                     │
│  AG-JB-05 通知設定  │
└─────────────────────┘

┌─────────────────────┐
│  permission-management│ (サポートリングドメイン)
│                     │
│  AG-JB-06 権限      │
│  AG-JB-07 会社      │
│  AG-JB-08 監査ログ  │
└─────────────────────┘
```

### 2.1 依存関係一覧

| 依存元モジュール | 依存先モジュール | 依存種類 | 説明 |
|-----------------|-----------------|----------|------|
| job-execution | job-definition | 一方向 | ジョブ実行時にジョブ定義情報を参照 |
| job-execution | permission-management | 一方向 | 実行権限チェック |
| execution-monitoring | job-execution | 一方向 | 実行結果を監視 |
| execution-monitoring | permission-management | 一方向 | 通知権限チェック |
| permission-management | (なし) | - | 独立したモジュール |
| job-definition | (なし) | - | 独立したモジュール |

### 2.2 依存関係の制約

- モジュール間の依存は、ドメインイベントを介して行う
- 直接のAPI呼び出しは、同じモジュール内でのみ許可
- 跨モジュールのデータアクセスは、リポジトリインターフェースを介して行う

## 3. モジュール内のパッケージ構成

各モジュールは、DDDのレイヤードアーキテクチャに従って構成します。

## 4. モジュール間の通信方法

### 4.1 ドメインイベントによる通信

モジュール間の通信は、ドメインイベントを介して行います。

| イベント名 | 発行元モジュール | 購読先モジュール | 説明 |
|-----------|-----------------|-----------------|------|
| JobExecutionStartedEvent | job-execution | execution-monitoring | ジョブ実行開始を通知 |
| JobExecutionSucceededEvent | job-execution | execution-monitoring | ジョブ実行成功を通知 |
| JobExecutionFailedEvent | job-execution | execution-monitoring | ジョブ実行失敗を通知 |
| JobExecutionUnknownEvent | job-execution | execution-monitoring | ジョブ実行結果不明を通知 |
| JobCancelledEvent | job-execution | execution-monitoring | ジョブキャンセルを通知 |
| JobReExecutedEvent | job-execution | execution-monitoring | ジョブ再実行を通知 |
| JobResumedEvent | job-execution | execution-monitoring | ジョブ再開を通知 |

### 4.2 リポジトリインターフェースによる通信

job-executionモジュールは、job-definitionモジュールのリポジトリインターフェースを参照して、ジョブ定義情報を取得します。

| インターフェース | 定義モジュール | 参照モジュール | 説明 |
|-----------------|---------------|---------------|------|
| JobDefinitionRepository | job-definition | job-execution | ジョブ定義情報を取得 |

### 4.3 ドメインサービスによる通信

job-executionモジュールは、permission-managementモジュールのドメインサービスを参照して、権限チェックを行います。

| サービス | 定義モジュール | 参照モジュール | 説明 |
|---------|---------------|---------------|------|
| ExecutionPermissionCheckService | permission-management | job-execution | 実行権限をチェック |
| CompanyStoreFilterService | permission-management | execution-monitoring | 会社・店舗でフィルタ |

## 5. モジュール境界の制約

### 5.1 依存性逆転の原則

- モジュール間の依存は、インターフェースを介して行う
- 実装の詳細は、モジュール内に閉じる
- 跨モジュールのデータアクセスは、リポジトリインターフェースを介して行う

### 5.2 ドメインイベントの制約

- ドメインイベントは、発行元モジュールで定義する
- 購読先モジュールは、イベントのインターフェースのみを参照する
- イベントの処理は、非同期で行う

### 5.3 データベースの制約

- 各モジュールは、独立したデータベーススキーマを持つ
- 跨モジュールのデータ参照は、APIを介して行う
- 直接のデータベース参照は、同じモジュール内でのみ許可
