# インフラストラクチャ設計

JBジョブ管理のインフラストラクチャ構成、外部システム連携、通知チャネルを詳細に定義します。

## 1. インフラストラクチャ構成概要

```
┌─────────────────────────────────────────────────────────────┐
│                        Frontend                             │
│                     (Webブラウザ)                            │
└────────────────────────────┬────────────────────────────────┘
                             │ HTTP/HTTPS
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                     Backend (Spring Boot)                   │
│                                                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────┐  │
│  │job-definition│  │job-execution │  │execution-monitor │  │
│  │  モジュール   │  │  モジュール   │  │   モジュール     │  │
│  └──────────────┘  └──────────────┘  └──────────────────┘  │
│                                                             │
│  ┌──────────────┐                                           │
│  │permission-   │                                           │
│  │management    │                                           │
│  │  モジュール   │                                           │
│  └──────────────┘                                           │
└────┬─────────────┬──────────────┬────────────────┬──────────┘
     │             │              │                │
     │ HTTPS       │ HTTPS        │ JDBC           │ HTTPS
     ▼             ▼              ▼                ▼
┌──────────┐ ┌──────────┐  ┌──────────┐    ┌──────────┐
│ 業務アプリ │ │ 業務アプリ │  │PostgreSQL│    │  S3/MinIO│
│ サーバーA │ │ サーバーB │  │          │    │          │
└──────────┘ └──────────┘  └──────────┘    └──────────┘
```

## 2. データベース接続

### 2.1 PostgreSQL

**概要:** 定義・状態・履歴・監査ログの永続化

| 項目 | 値 |
|------|-----|
| データベース種類 | PostgreSQL |
| 接続プロトコル | JDBC |
| 接続プール | HikariCP |
| スキーマ | jb_job_management |

**接続設定**

| プロパティ | 説明 |
|-----------|------|
| spring.datasource.url | JDBC接続URL |
| spring.datasource.username | データベースユーザー名 |
| spring.datasource.password | データベースパスワード |
| spring.datasource.hikari.maximum-pool-size | 最大接続数 |
| spring.datasource.hikari.minimum-idle | 最小アイドル接続数 |

**Flywayマイグレーション**

| 項目 | 値 |
|------|-----|
| マイグレーションツール | Flyway |
| マイグレーションテーブル | flyway_schema_history |
| マイグレーション場所 | classpath:db/migration |

## 3. 業務アプリケーションサーバー連携

### 3.1 概要

**概要:** ジョブの実行を担当するREST APIを提供

| 項目 | 値 |
|------|-----|
| 通信プロトコル | HTTPS |
| 通信形式 | JSON |
| 認証方式 | Bearer Token (JWT) |
| タイムアウト | 30秒 |

### 3.2 APIエンドポイント

#### ジョブ起動API

| エンドポイント | HTTPメソッド | 説明 |
|---------------|-------------|------|
| /api/jobs/{jobCode}/start | POST | ジョブを起動 |

**リクエスト**

| ヘッダー | 値 |
|---------|-----|
| Authorization | Bearer {token} |
| Content-Type | application/json |

**リクエストボディ**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| executionId | String | Y | 実行ID |
| jobVersion | String | Y | ジョブバージョン |
| parameters | Object | N | 実行パラメータ |

**レスポンス**

| ステータスコード | 説明 |
|-----------------|------|
| 200 OK | 起動成功 |
| 400 Bad Request | リクエストエラー |
| 401 Unauthorized | 認証エラー |
| 500 Internal Server Error | サーバーエラー |

#### ジョブ状態照会API

| エンドポイント | HTTPメソッド | 説明 |
|---------------|-------------|------|
| /api/jobs/{jobCode}/status | GET | ジョブ状態を照会 |

**レスポンスボディ**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| executionId | String | 実行ID |
| status | String | 実行状態 |
| progress | Integer | 進捗率 |

#### ジョブキャンセルAPI

| エンドポイント | HTTPメソッド | 説明 |
|---------------|-------------|------|
| /api/jobs/{jobCode}/cancel | POST | ジョブをキャンセル |

### 3.3 サーバー登録

業務アプリケーションサーバーは、job_deploymentテーブルに登録されます。

| カラム | 説明 |
|--------|------|
| host | サーバーのホスト名 |
| port | サーバーのポート番号 |
| protocol | 通信プロトコル (http/https) |

### 3.4 エラーハンドリング

| エラー種類 | 対応 |
|-----------|------|
| タイムアウト | 結果不明状態に遷移 |
| 接続失敗 | 再試行（最大3回） |
| 認証エラー | 管理者に通知 |

## 4. S3/MinIO連携

### 4.1 概要

**概要:** 入力ファイルなどのオブジェクト保管

| 項目 | 値 |
|------|-----|
| ストレージ種類 | S3 / MinIO |
| 通信プロトコル | HTTPS |
| 認証方式 | AWS Signature v4 |

### 4.2 接続設定

| プロパティ | 説明 |
|-----------|------|
| aws.s3.endpoint | S3/MinIOエンドポイント |
| aws.s3.bucket | バケット名 |
| aws.s3.region | リージョン |
| aws.s3.access-key | アクセスキー |
| aws.s3.secret-key | シークレットキー |

### 4.3 ファイル操作

#### ファイルアップロード

| メソッド | 説明 |
|---------|------|
| uploadFile(key, file) | ファイルをアップロード |

#### ファイルダウンロード

| メソッド | 説明 |
|---------|------|
| downloadFile(key) | ファイルをダウンロード |

#### ファイル削除

| メソッド | 説明 |
|---------|------|
| deleteFile(key) | ファイルを削除 |

### 4.4 ファイル参照情報

アップロードファイルは、INF-JB-10（アップロードファイル）として管理されます。

| カラム | 説明 |
|--------|------|
| file_key | S3/MinIO上のファイルキー |
| file_name | ファイル名 |
| file_size | ファイルサイズ |
| content_type | コンテンツタイプ |
| uploaded_at | アップロード日時 |

## 5. 通知チャネル連携

### 5.1 メール通知

**概要:** メールによる通知

| 項目 | 値 |
|------|-----|
| プロトコル | SMTP |
| 暗号化 | TLS |

**接続設定**

| プロパティ | 説明 |
|-----------|------|
| spring.mail.host | SMTPサーバーホスト |
| spring.mail.port | SMTPサーバーポート |
| spring.mail.username | SMTPユーザー名 |
| spring.mail.password | SMTPパスワード |
| spring.mail.properties.mail.smtp.auth | 認証フラグ |
| spring.mail.properties.mail.smtp.starttls.enable | TLS有効フラグ |

**通知テンプレート**

| テンプレート名 | 説明 |
|---------------|------|
| job_success | ジョブ成功通知 |
| job_failure | ジョブ失敗通知 |
| job_unknown | ジョブ結果不明通知 |

### 5.2 Slack通知

**概要:** Slackによる通知

| 項目 | 値 |
|------|-----|
| API種類 | Incoming Webhook |
| 通信プロトコル | HTTPS |

**接続設定**

| プロパティ | 説明 |
|-----------|------|
| slack.webhook.url | Webhook URL |
| slack.channel | 通知チャンネル |

**通知フォーマット**

| フィールド | 説明 |
|-----------|------|
| text | 通知テキスト |
| attachments | 通知詳細 |
| color | 通知カラー（成功: good, 失敗: danger） |

### 5.3 Webhook通知

**概要:** 外部システムへのWebhook通知

| 項目 | 値 |
|------|-----|
| 通信プロトコル | HTTPS |
| 通信形式 | JSON |

**接続設定**

| プロパティ | 説明 |
|-----------|------|
| webhook.url | Webhook URL |
| webhook.timeout | タイムアウト秒数 |
| webhook.retry-count | リトライ回数 |

**通知ペイロード**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| event_type | String | イベントタイプ |
| execution_id | String | 実行ID |
| job_code | String | ジョブコード |
| status | String | 実行状態 |
| timestamp | String | タイムスタンプ |

## 6. インフラストラクチャ設計まとめ

| 外部システム | 通信プロトコル | 用途 |
|-------------|---------------|------|
| PostgreSQL | JDBC | データ永続化 |
| 業務アプリケーションサーバー | HTTPS | ジョブ実行 |
| S3/MinIO | HTTPS | ファイル保管 |
| SMTPサーバー | SMTP/TLS | メール通知 |
| Slack | HTTPS | Slack通知 |
| Webhook | HTTPS | 外部システム通知 |
