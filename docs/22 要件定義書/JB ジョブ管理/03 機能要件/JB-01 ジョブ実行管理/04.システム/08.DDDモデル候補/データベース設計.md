# データベース設計

JBジョブ管理のテーブル定義、インデックス、制約を定義します。

## 1. テーブル一覧

| テーブル名 | 説明 | モジュール |
|-----------|------|-----------|
| job_definition | ジョブ定義 | job-definition |
| job_deployment | ジョブ配備 | job-definition |
| schedule | スケジュール | job-definition |
| job_execution | ジョブ実行 | job-execution |
| execution_slot | 実行枠 | job-execution |
| notification_setting | 通知設定 | execution-monitoring |
| user_permission | ユーザー権限 | permission-management |
| company | 会社 | permission-management |
| store | 店舗 | permission-management |
| audit_log | 監査ログ | permission-management |

## 2. テーブル定義

### 2.1 job_definition (ジョブ定義)

**アグリゲート:** AG-JB-01  
**モジュール:** job-definition

| カラム名 | 型 | NotNull | Unique | 説明 |
|---------|-----|---------|--------|------|
| job_code | VARCHAR(50) | Y | Y | ジョブコード (PK) |
| job_name | VARCHAR(100) | Y | N | ジョブ名 |
| description | TEXT | N | N | 説明 |
| parameter_spec | JSON | Y | N | パラメータ仕様 |
| max_concurrent_executions | INTEGER | Y | N | 最大同時実行数 |
| timeout_seconds | INTEGER | Y | N | タイムアウト秒数 |
| retry_count | INTEGER | N | N | リトライ回数 |
| version | VARCHAR(20) | Y | N | バージョン番号 |
| enabled | BOOLEAN | Y | N | 有効フラグ |
| created_at | TIMESTAMP | Y | N | 作成日時 |
| updated_at | TIMESTAMP | Y | N | 更新日時 |

**インデックス**

| インデックス名 | カラム | 種類 |
|---------------|--------|------|
| pk_job_definition | job_code | 主キー |
| idx_job_definition_enabled | enabled | 通常 |
