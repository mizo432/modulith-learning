# ステート一覧

ジョブ実行管理業務領域で扱う状態を定義します。

| ID       | 状態名       | 対象情報   | 説明                                     |
|----------|--------------|------------|------------------------------------------|
| ST-JB-01 | 待機中     | ジョブ実行 | ジョブ実行が開始される前                 |
| ST-JB-02 | 実行中     | ジョブ実行 | ジョブが実行されている                   |
| ST-JB-03 | 成功       | ジョブ実行 | ジョブが正常に完了                       |
| ST-JB-04 | 失敗       | ジョブ実行 | ジョブが異常終了                         |
| ST-JB-05 | 結果不明   | ジョブ実行 | 起動APIタイムアウトなどで結果が不明       |
| ST-JB-06 | 再実行済み | ジョブ実行 | 最初から再実行された                     |
| ST-JB-07 | 再開済み   | ジョブ実行 | チェックポイントから再開された           |
| ST-JB-08 | キャンセル済み | ジョブ実行 | 実行中のジョブがキャンセルされた         |
