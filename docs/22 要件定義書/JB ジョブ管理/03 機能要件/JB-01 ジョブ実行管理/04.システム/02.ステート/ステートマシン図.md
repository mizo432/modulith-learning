# JB-01 ジョブ実行管理 ステートマシン図

ジョブ実行管理の状態遷移を情報毎にPlantUMLで視覚化します。

## 情報毎のステートマシン図

各情報の状態遷移は以下の個別ファイルで管理しています。

| 情報       | ステートマシン図                                                 | 状態数 |
|------------|------------------------------------------------------------------|--------|
| ジョブ定義 | [ステートマシン図_ジョブ定義.md](ステートマシン図_ジョブ定義.md) | 2      |
| ジョブ実行 | [ステートマシン図_ジョブ実行.md](ステートマシン図_ジョブ実行.md) | 8      |

## 状態モデル一覧

### ジョブ定義

| 状態モデル | 状態        | 遷移UC    | 説明                      |
|------------|-------------|-----------|---------------------------|
| ジョブ定義 | 有効 → 無効 | UC-JB-003 | ジョブ定義の有効/無効管理 |

### ジョブ実行

| 状態モデル | 状態                    | 遷移UC    | 説明                                |
|------------|-------------------------|-----------|-------------------------------------|
| ジョブ実行 | 待機中 → 実行中         | UC-JB-004 | ジョブを実行する                    |
| ジョブ実行 | 実行中 → 成功           | UC-JB-005 | ジョブが成功する                    |
| ジョブ実行 | 実行中 → 失敗           | UC-JB-005 | ジョブが失敗する                    |
| ジョブ実行 | 実行中 → 結果不明       | UC-JB-005 | 起動APIタイムアウトなどで結果が不明 |
| ジョブ実行 | 実行中 → キャンセル済み | UC-JB-006 | 実行中のジョブをキャンセルする      |
| ジョブ実行 | 失敗 → 待機中           | UC-JB-007 | ジョブを再実行する                  |
| ジョブ実行 | 失敗 → 再実行済み       | UC-JB-007 | 最初から再実行する                  |
| ジョブ実行 | 失敗 → 再開済み         | UC-JB-008 | チェックポイントから再開する        |
