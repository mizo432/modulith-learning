# ステートマシン図

ジョブ実行管理業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、JB-JB-01 ジョブ実行管理業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図（英語版）

```plantuml
@startuml
title Job Execution Management State Model Diagram
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

state "Pending" as Pending <<entry>>
state "Running" as Running
state "Success" as Success <<exit>>
state "Failed" as Failed <<exit>>
state "ResultUnknown" as ResultUnknown <<exit>>
state "Cancelled" as Cancelled <<exit>>
state "ReExecuted" as ReExecuted
state "Resumed" as Resumed

Pending --> Running : Job Execution Started (EVT-JB-012)
Running --> Success : Job Execution Succeeded (EVT-JB-013)
Running --> Failed : Job Execution Failed (EVT-JB-014)
Running --> ResultUnknown : Job Execution Result Unknown (EVT-JB-015)
Running --> Cancelled : Job Cancelled (EVT-JB-016)
Failed --> Running : Job Re-executed (EVT-JB-017)
ResultUnknown --> Running : Job Re-executed (EVT-JB-017)
Failed --> Running : Job Resumed from Checkpoint (EVT-JB-018)
ResultUnknown --> Running : Job Resumed from Checkpoint (EVT-JB-018)
@enduml
```

## 4. 状態一覧

| 状態名 (ID)       | 英語名        | 説明                                     |
|-------------------|---------------|------------------------------------------|
| 待機中 (ST-JB-01) | Pending       | ジョブ実行が開始される前                 |
| 実行中 (ST-JB-02) | Running       | ジョブが実行されている                   |
| 成功 (ST-JB-03)   | Success       | ジョブが正常に完了                       |
| 失敗 (ST-JB-04)   | Failed        | ジョブが異常終了                         |
| 結果不明 (ST-JB-05) | ResultUnknown | 起動APIタイムアウトなどで結果が不明       |
| キャンセル済み (ST-JB-08) | Cancelled | 実行中のジョブがキャンセルされた         |
| 再実行済み (ST-JB-06) | ReExecuted | 最初から再実行された                     |
| 再開済み (ST-JB-07) | Resumed     | チェックポイントから再開された           |
