# 実行ログ・エラー詳細

実行ログ・エラー詳細画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-004 |
| 画面名           | 実行ログ・エラー詳細 |
| 説明             | ログ、エラー内容、発生箇所、関連イベントを確認 |
| 関連ユースケース | UC-JB-015 (実行ログ・エラー詳細を確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 基本情報エリア | 実行ID、ジョブコード、エラー概要 |
| ログエリア | 実行ログの一覧表示 |
| エラー詳細エリア | エラー内容、スタックトレース、発生箇所 |
| 関連イベントエリア | 関連する実行イベントの一覧 |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 実行ID | テキスト | - | 実行ID |
| 2 | ジョブコード | テキスト | - | ジョブコード |
| 3 | エラーコード | テキスト | - | エラーコード |
| 4 | エラーメッセージ | テキスト | - | エラーメッセージ |
| 5 | エラー発生日時 | 日時 | - | エラーが発生した日時 |
| 6 | エラー発生箇所 | テキスト | - | エラーが発生したクラス・メソッド |
| 7 | スタックトレース | テキスト | - | スタックトレース全文 |
| 8 | ログレベル | ドロップダウン | - | ログレベル（INFO、WARN、ERROR） |
| 9 | ログ一覧 | テーブル | - | 実行ログの一覧 |
| 10 | ログ日時 | 日時 | - | ログ出力日時 |
| 11 | ログメッセージ | テキスト | - | ログメッセージ |
| 12 | 関連イベント一覧 | テーブル | - | 関連する実行イベント |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ログ検索 | ログレベル・キーワードで検索 |
| 2 | ログ詳細表示 | 選択したログの詳細を表示 |
| 3 | エラー詳細表示 | エラーの詳細情報を表示 |
| 4 | 一覧へ戻る | ジョブ実行詳細画面へ戻る |
| 5 | ログダウンロード | ログをファイルとしてダウンロード |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | ログ保持期間 | 30日間のログを表示 |
| 3 | 表示件数 | 1ページあたり100件を表示 |
| 4 | ダウンロード制限 | 1ファイルあたり最大10MB |
