# アプリケーションサーバー一覧

アプリケーションサーバー一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-017 |
| 画面名           | アプリケーションサーバー一覧 |
| 説明             | サーバーの稼働状況、接続状態、受付可否を表示 |
| 関連ユースケース | UC-JB-005 (アプリケーションサーバーを確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールドと検索ボタン |
| メインエリア | アプリケーションサーバー一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_サーバー名 | テキスト | いいえ | サーバー名で検索 |
| 2 | 検索_稼働状況 | ドロップダウン | いいえ | 稼働状況（稼働中、停止中）で検索 |
| 3 | 検索_接続状態 | ドロップダウン | いいえ | 接続状態（接続可能、接続不可）で検索 |
| 4 | 一覧_サーバーID | テキスト | - | サーバーID |
| 5 | 一覧_サーバー名 | テキスト | - | サーバー名 |
| 6 | 一覧_稼働状況 | ステータス | - | 稼働状況（稼働中、停止中） |
| 7 | 一覧_接続状態 | ステータス | - | 接続状態（接続可能、接続不可） |
| 8 | 一覧_受付可否 | ステータス | - | 受付可否（受付可能、受付不可） |
| 9 | 一覧_稼働中ジョブ数 | 数値 | - | 現在稼働中のジョブ数 |
| 10 | 一覧_対応バージョン | テキスト | - | 対応するジョブバージョン |
| 11 | 一覧_最終接続日時 | 日時 | - | 最終接続日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で検索実行 |
| 2 | 初期化 | 検索条件を初期化 |
| 3 | 詳細表示 | 選択したサーバーの詳細画面へ遷移 |
| 4 | ソート | 列ヘッダークリックでソート |
| 5 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 参照のみ | 編集・操作は不可 |
