# 監査ログ一覧

監査ログ一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-026 |
| 画面名           | 監査ログ一覧 |
| 説明             | 起動、設定変更、権限変更、復旧操作などを検索・参照 |
| 関連ユースケース | UC-JB-024 (監査ログを確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールドと検索ボタン |
| メインエリア | 監査ログ一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_期間 | 日付範囲 | いいえ | 操作期間で検索 |
| 2 | 検索_操作タイプ | ドロップダウン | いいえ | 操作タイプで検索 |
| 3 | 検索_操作者 | テキスト | いいえ | 操作者で検索 |
| 4 | 検索_ジョブコード | テキスト | いいえ | ジョブコードで検索 |
| 5 | 一覧_ログID | テキスト | - | ログID |
| 6 | 一覧_操作日時 | 日時 | - | 操作日時 |
| 7 | 一覧_操作タイプ | テキスト | - | 操作タイプ（起動、設定変更、権限変更、復旧操作など） |
| 8 | 一覧_操作者 | テキスト | - | 操作者 |
| 9 | 一覧_ジョブコード | テキスト | - | 関連するジョブコード |
| 10 | 一覧_操作内容 | テキスト | - | 操作内容の詳細 |
| 11 | 一覧_対象リソース | テキスト | - | 対象となったリソース |
| 12 | 一覧_結果 | ステータス | - | 操作結果（成功、失敗） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で検索実行 |
| 2 | 初期化 | 検索条件を初期化 |
| 3 | 詳細表示 | 選択したログの詳細を表示 |
| 4 | ソート | 列ヘッダークリックでソート |
| 5 | ページ移動 | ページネーションでページ移動 |
| 6 | エクスポート | 検索結果をCSVとしてエクスポート |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 参照のみ | 編集・操作は不可 |
| 4 | 検索結果制限 | 検索結果は最大1000件まで表示 |
| 5 | エクスポート制限 | 1回あたり最大1000件をエクスポート |
| 6 | ログ保持期間 | 180日間のログを表示 |
