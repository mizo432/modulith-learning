# スケジュール一覧

スケジュール一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-010 |
| 画面名           | スケジュール一覧 |
| 説明             | スケジュールの検索、有効・無効状態の確認 |
| 関連ユースケース | UC-JB-010 (スケジュールを一覧で確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールドと検索ボタン |
| メインエリア | スケジュール一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_ジョブコード | テキスト | いいえ | ジョブコードで検索 |
| 2 | 検索_状態 | ドロップダウン | いいえ | 状態（有効、無効）で検索 |
| 3 | 検索_実行日時 | 日付範囲 | いいえ | 実行日時に検索 |
| 4 | 一覧_スケジュールID | テキスト | - | スケジュールID |
| 5 | 一覧_ジョブコード | テキスト | - | ジョブコード |
| 6 | 一覧_ジョブ名 | テキスト | - | ジョブ名 |
| 7 | 一覧_状態 | ステータス | - | 状態（有効、無効） |
| 8 | 一覧_実行日時 | 日時 | - | 次回実行日時 |
| 9 | 一覧_繰り返し条件 | テキスト | - | 繰り返し条件（Cron式など） |
| 10 | 一覧_有効期間 | テキスト | - | 有効期間 |
| 11 | 一覧_最終更新日時 | 日時 | - | 最終更新日時 |
| 12 | 一覧_最終更新者 | テキスト | - | 最終更新者 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で検索実行 |
| 2 | 初期化 | 検索条件を初期化 |
| 3 | 編集 | スケジュール登録・編集画面へ遷移 |
| 4 | 有効/無効切替 | スケジュールの有効・無効を切替 |
| 5 | ソート | 列ヘッダークリックでソート |
| 6 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 編集権限 | 運用管理者のみ編集可能 |
