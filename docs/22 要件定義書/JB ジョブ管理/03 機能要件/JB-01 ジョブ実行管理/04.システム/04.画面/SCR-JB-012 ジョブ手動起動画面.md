# ジョブ手動起動画面

ジョブ手動起動画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-012 |
| 画面名           | ジョブ手動起動画面 |
| 説明             | 対象ジョブ、実行パラメータ、対象会社・店舗を指定して起動 |
| 関連ユースケース | UC-JB-008 (手動でジョブを起動する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 基本情報エリア | 対象ジョブ、実行パラメータなどの入力 |
| 対象情報エリア | 対象会社・店舗の入力 |
| 操作エリア | 起動、キャンセルボタン |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 対象ジョブ | ドロップダウン | はい | 起動するジョブ |
| 2 | 実行パラメータ | テキスト | いいえ | 実行時のパラメータ |
| 3 | 対象会社 | ドロップダウン | いいえ | 対象会社 |
| 4 | 対象店舗 | ドロップダウン | いいえ | 対象店舗 |
| 5 | 実行ID | テキスト | いいえ | 実行ID（冪等性キー） |
| 6 | 実行先サーバー | ドロップダウン | いいえ | 実行先サーバー（自動選択の場合空） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 起動 | ジョブを起動 |
| 2 | キャンセル | 起動をキャンセルして一覧へ戻る |
| 3 | パラメータ確認 | 入力したパラメータを確認 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 必須項目 | 対象ジョブは必須 |
| 3 | 実行ID | 実行IDは一意であること |
| 4 | 同時実行枠 | 同時実行枠を超えている場合は起動不可 |
| 5 | バージョン互換性 | 実行先サーバーとジョブのバージョンが互換性があること |
