# ジョブ実行状況一覧

ジョブ実行状況一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-002 |
| 画面名           | ジョブ実行状況一覧 |
| 説明             | 実行中・待機中・異常終了などを検索・一覧表示 |
| 関連ユースケース | UC-JB-013 (ジョブ実行状況を一覧で確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールドと検索ボタン |
| メインエリア | 実行状況一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_ジョブコード | テキスト | いいえ | ジョブコードで検索 |
| 2 | 検索_状態 | ドロップダウン | いいえ | 状態（実行中、待機中、成功、失敗、結果不明）で検索 |
| 3 | 検索_期間 | 日付範囲 | いいえ | 実行開始期間で検索 |
| 4 | 検索_会社 | ドロップダウン | いいえ | 会社で検索 |
| 5 | 検索_店舗 | ドロップダウン | いいえ | 店舗で検索 |
| 6 | 一覧_実行ID | テキスト | - | 実行ID |
| 7 | 一覧_ジョブコード | テキスト | - | ジョブコード |
| 8 | 一覧_ジョブ名 | テキスト | - | ジョブ名 |
| 9 | 一覧_状態 | ステータス | - | 実行状態（色分け表示） |
| 10 | 一覧_実行開始日時 | 日時 | - | 実行開始日時 |
| 11 | 一覧_実行終了日時 | 日時 | - | 実行終了日時 |
| 12 | 一覧_実行先サーバー | テキスト | - | 実行先サーバー名 |
| 13 | 一覧_処理件数 | 数値 | - | 処理件数 |
| 14 | 一覧_エラー概要 | テキスト | - | エラー概要（失敗時のみ） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で検索実行 |
| 2 | 初期化 | 検索条件を初期化 |
| 3 | 詳細表示 | 選択した実行の詳細画面へ遷移 |
| 4 | ソート | 列ヘッダークリックでソート |
| 5 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 状態色分け | 実行中（青）、成功（緑）、失敗（赤）、結果不明（黄）、待機中（灰） |
| 4 | 検索結果制限 | 検索結果は最大1000件まで表示 |
