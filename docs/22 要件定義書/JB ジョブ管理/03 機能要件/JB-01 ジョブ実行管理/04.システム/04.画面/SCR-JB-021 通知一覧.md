# 通知一覧

通知一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-021 |
| 画面名           | 通知一覧 |
| 説明             | 成功・異常終了などの通知を確認 |
| 関連ユースケース | UC-JB-023 (通知を一覧で確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールドと検索ボタン |
| メインエリア | 通知一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_期間 | 日付範囲 | いいえ | 通知期間で検索 |
| 2 | 検索_通知タイプ | ドロップダウン | いいえ | 通知タイプ（成功、失敗、結果不明）で検索 |
| 3 | 検索_ジョブコード | テキスト | いいえ | ジョブコードで検索 |
| 4 | 検索_未読/既読 | ドロップダウン | いいえ | 未読/既読で検索 |
| 5 | 一覧_通知ID | テキスト | - | 通知ID |
| 6 | 一覧_通知日時 | 日時 | - | 通知日時 |
| 7 | 一覧_通知タイプ | テキスト | - | 通知タイプ（成功、失敗、結果不明） |
| 8 | 一覧_ジョブコード | テキスト | - | ジョブコード |
| 9 | 一覧_ジョブ名 | テキスト | - | ジョブ名 |
| 10 | 一覧_実行ID | テキスト | - | 実行ID |
| 11 | 一覧_通知メッセージ | テキスト | - | 通知メッセージ |
| 12 | 一覧_通知先 | テキスト | - | 通知先 |
| 13 | 一覧_読了状態 | ステータス | - | 読了状態（未読、既読） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で検索実行 |
| 2 | 初期化 | 検索条件を初期化 |
| 3 | 既読にする | 選択した通知を既読にする |
| 4 | 全件既読 | 全通知を既読にする |
| 5 | 詳細表示 | 選択した通知の詳細を表示 |
| 6 | ソート | 列ヘッダークリックでソート |
| 7 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 未読強調 | 未読の通知は太字で表示 |
