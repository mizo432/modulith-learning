# ダッシュボード

ダッシュボード画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-001 |
| 画面名           | ダッシュボード |
| 説明             | 実行中・成功・失敗件数、異常発生状況、要対応ジョブを表示 |
| 関連ユースケース | UC-JB-013 (ジョブ実行状況を一覧で確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー（ダッシュボード、実行監視、ジョブ定義、スケジュール、サーバー、通知、権限、監査ログ） |
| メインエリア | 統計カード、要対応ジョブ一覧、最近の実行状況 |
| フッター | バージョン情報 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 実行中件数 | 数値 | - | 現在実行中のジョブ件数 |
| 2 | 成功件数 | 数値 | - | 今日成功したジョブ件数 |
| 3 | 失敗件数 | 数値 | - | 今日失敗したジョブ件数 |
| 4 | 結果不明件数 | 数値 | - | 今日結果不明のジョブ件数 |
| 5 | 待機中件数 | 数値 | - | 待機中のジョブ件数 |
| 6 | 要対応ジョブ一覧 | テーブル | - | 失敗・結果不明で対応が必要なジョブの一覧 |
| 7 | 最近の実行状況 | テーブル | - | 直近の実行結果一覧 |
| 8 | 異常アラート | テキスト | - | 発生している異常の概要 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 更新 | ダッシュボードの情報を手動で更新 |
| 2 | ジョブ詳細へ遷移 | 要対応ジョブ一覧からジョブ実行詳細画面へ遷移 |
| 3 | 実行状況一覧へ遷移 | 最近の実行状況からジョブ実行状況一覧画面へ遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 自動更新間隔 | ダッシュボードは30秒ごとに自動更新 |
| 2 | 権限チェック | 運用管理者のみアクセス可能 |
| 3 | データ範囲 | 成功・失敗件数は当日分を表示 |
