# 会社・店舗管理

会社・店舗管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-025 |
| 画面名           | 会社・店舗管理 |
| 説明             | 会社と店舗の登録、所属関係の管理 |
| 関連ユースケース | UC-JB-027 (会社・店舗権限を管理する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| タブエリア | 会社一覧タブ、店舗一覧タブ |
| 会社一覧エリア | 会社の一覧表示・検索・登録・編集 |
| 店舗一覧エリア | 店舗の一覧表示・検索・登録・編集 |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_会社名 | テキスト | いいえ | 会社名で検索 |
| 2 | 検索_店舗名 | テキスト | いいえ | 店舗名で検索 |
| 3 | 会社_会社ID | テキスト | - | 会社ID |
| 4 | 会社_会社名 | テキスト | - | 会社名 |
| 5 | 会社_会社タイプ | テキスト | - | 会社タイプ（本社、支社など） |
| 6 | 会社_状態 | ステータス | - | 状態（有効、無効） |
| 7 | 店舗_店舗ID | テキスト | - | 店舗ID |
| 8 | 店舗_店舗名 | テキスト | - | 店舗名 |
| 9 | 店舗_所属会社 | テキスト | - | 所属会社 |
| 10 | 店舗_店舗タイプ | テキスト | - | 店舗タイプ（直営店、フランチャイズなど） |
| 11 | 店舗_状態 | ステータス | - | 状態（有効、無効） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 会社検索 | 入力した条件で会社を検索 |
| 2 | 店舗検索 | 入力した条件で店舗を検索 |
| 3 | 会社登録 | 会社を登録 |
| 4 | 会社編集 | 会社情報を編集 |
| 5 | 店舗登録 | 店舗を登録 |
| 6 | 店舗編集 | 店舗情報を編集 |
| 7 | ソート | 列ヘッダークリックでソート |
| 8 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 会社一意性 | 会社名は一意であること |
| 4 | 店舗一意性 | 店舗名は一意であること |
