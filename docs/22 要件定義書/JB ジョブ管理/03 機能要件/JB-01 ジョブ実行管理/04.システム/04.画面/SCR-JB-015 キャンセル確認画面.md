# キャンセル確認画面

キャンセル確認画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-015 |
| 画面名           | キャンセル確認画面 |
| 説明             | 対象実行とキャンセルの影響を確認して要求 |
| 関連ユースケース | UC-JB-018 (実行中のジョブをキャンセルする) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 対象実行情報エリア | 実行ID、ジョブコード、実行状態などの情報 |
| キャンセル影響エリア | キャンセルによる影響の説明 |
| 実行理由エリア | キャンセルの理由入力 |
| 操作エリア | キャンセル実行、戻るボタン |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 実行ID | テキスト | - | 実行ID |
| 2 | ジョブコード | テキスト | - | ジョブコード |
| 3 | ジョブ名 | テキスト | - | ジョブ名 |
| 4 | 実行状態 | ステータス | - | 実行状態（実行中） |
| 5 | 実行開始日時 | 日時 | - | 実行開始日時 |
| 6 | 実行経過時間 | 数値 | - | 実行にかかった時間（秒） |
| 7 | 実行先サーバー | テキスト | - | 実行先サーバー名 |
| 8 | キャンセル影響 | テキスト | - | キャンセルによる影響の説明 |
| 9 | 実行理由 | テキスト | はい | キャンセルの理由 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | キャンセル実行 | ジョブのキャンセルを実行 |
| 2 | 戻る | キャンセルを中止して一覧へ戻る |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | キャンセル可否 | 実行中の状態のみキャンセル可能 |
| 3 | 必須項目 | 実行理由は必須 |
| 4 | 二度の確認 | キャンセル実行前に二度の確認ダイアログを表示 |
