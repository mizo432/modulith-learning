# アプリケーションサーバー詳細

アプリケーションサーバー詳細画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-018 |
| 画面名           | アプリケーションサーバー詳細 |
| 説明             | サーバー情報、ヘルスチェック、稼働中ジョブ、対応バージョンを表示 |
| 関連ユースケース | UC-JB-005 (アプリケーションサーバーを確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 基本情報エリア | サーバーID、サーバー名、稼働状況などの基本情報 |
| ヘルスチェックエリア | ヘルスチェック結果、最終チェック日時 |
| 稼働中ジョブエリア | 現在稼働中のジョブ一覧 |
| バージョン情報エリア | 対応バージョン情報 |
| フッター | 更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 一覧へ戻る | アプリケーションサーバー一覧画面へ戻る |
