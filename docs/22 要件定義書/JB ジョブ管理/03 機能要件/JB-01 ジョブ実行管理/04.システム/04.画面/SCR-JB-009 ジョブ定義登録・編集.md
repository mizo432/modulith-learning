# ジョブ定義登録・編集

ジョブ定義登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-009 |
| 画面名           | ジョブ定義登録・編集 |
| 説明             | ジョブコード、パラメータ仕様、実行制約などを登録・変更 |
| 関連ユースケース | UC-JB-001 (ジョブ定義を登録する)、UC-JB-002 (ジョブ定義を変更する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 基本情報エリア | ジョブコード、ジョブ名、状態などの基本情報入力 |
| 仕様情報エリア | パラメータ、同時実行数、タイムアウトなどの仕様の入力 |
| 通知設定エリア | 通知条件、通知先などの設定入力 |
| 操作エリア | 保存、キャンセルボタン |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ジョブコード | テキスト | はい | ジョブコード（一意） |
| 2 | ジョブ名 | テキスト | はい | ジョブ名 |
| 3 | 状態 | ドロップダウン | はい | 状態（有効、無効） |
| 4 | ジョブタイプ | ドロップダウン | はい | ジョブタイプ |
| 5 | 説明 | テキスト | いいえ | ジョブの説明 |
| 6 | パラメータ仕様 | テキスト | いいえ | パラメータの仕様 |
| 7 | 同時実行数 | 数値 | はい | 同時に実行できる最大数 |
| 8 | タイムアウト | 数値 | はい | タイムアウト時間（秒） |
| 9 | チェックポイント有効 | チェックボックス | いいえ | チェックポイントの有効/無効 |
| 10 | 通知条件 | ドロップダウン | いいえ | 通知を送信する条件 |
| 11 | 通知先 | テキスト | いいえ | 通知先のメールアドレス等 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 保存 | 入力した情報を保存 |
| 2 | キャンセル | 編集をキャンセルして一覧へ戻る |
| 3 | 入力チェック | 入力値を検証 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | ジョブコード一意性 | ジョブコードは一意であること |
| 3 | 必須項目 | ジョブコード、ジョブ名、状態、ジョブタイプ、同時実行数、タイムアウトは必須 |
| 4 | 同時実行数範囲 | 1〜10の範囲で入力 |
| 5 | タイムアウト範囲 | 60〜86400秒の範囲で入力 |
