# ジョブ実行履歴詳細

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-006 |
| 画面名           | ジョブ実行履歴詳細 |
| 説明             | 実行結果、実行時間、処理件数、再実行履歴を参照 |
