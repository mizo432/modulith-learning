# ジョブ配備状況一覧

ジョブ配備状況一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-019 |
| 画面名           | ジョブ配備状況一覧 |
| 説明             | サーバーごとのジョブ配備状況、バージョン、実行可否を確認 |
| 関連ユースケース | UC-JB-005 (アプリケーションサーバーを確認する)、UC-JB-006 (ジョブ配備状況を確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールドと検索ボタン |
| メインエリア | ジョブ配備状況一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_ジョブコード | テキスト | いいえ | ジョブコードで検索 |
| 2 | 検索_サーバー名 | テキスト | いいえ | サーバー名で検索 |
| 3 | 検索_実行可否 | ドロップダウン | いいえ | 実行可否（実行可能、実行不可）で検索 |
| 4 | 一覧_ジョブコード | テキスト | - | ジョブコード |
| 5 | 一覧_ジョブ名 | テキスト | - | ジョブ名 |
| 6 | 一覧_サーバー名 | テキスト | - | サーバー名 |
| 7 | 一覧_配備バージョン | テキスト | - | 配備されたバージョン |
| 8 | 一覧_最新バージョン | テキスト | - | 最新のジョブバージョン |
| 9 | 一覧_実行可否 | ステータス | - | 実行可否（実行可能、実行不可） |
| 10 | 一覧_配備日時 | 日時 | - | 配備日時 |
| 11 | 一覧_バージョン互換性 | ステータス | - | バージョン互換性（互換、非互換） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で検索実行 |
| 2 | 初期化 | 検索条件を初期化 |
| 3 | 詳細表示 | 選択した配備の詳細画面へ遷移 |
| 4 | ソート | 列ヘッダークリックでソート |
| 5 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 参照のみ | 編集・操作は不可 |
