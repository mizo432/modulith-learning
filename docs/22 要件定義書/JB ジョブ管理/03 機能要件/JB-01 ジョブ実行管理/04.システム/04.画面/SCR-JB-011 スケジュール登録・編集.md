# スケジュール登録・編集

スケジュール登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-011 |
| 画面名           | スケジュール登録・編集 |
| 説明             | 実行日時、繰り返し条件、対象ジョブ、有効期間を設定 |
| 関連ユースケース | UC-JB-011 (スケジュールを登録する)、UC-JB-012 (スケジュールを変更する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 基本情報エリア | 対象ジョブ、状態などの基本情報入力 |
| スケジュール情報エリア | 実行日時、繰り返し条件、有効期間の入力 |
| 操作エリア | 保存、キャンセルボタン |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 対象ジョブ | ドロップダウン | はい | 対象となるジョブ |
| 2 | 状態 | ドロップダウン | はい | 状態（有効、無効） |
| 3 | 実行日時 | 日時 | はい | 初回実行日時 |
| 4 | 繰り返し条件 | テキスト | いいえ | 繰り返し条件（Cron式） |
| 5 | 有効期間開始 | 日付 | いいえ | 有効期間の開始日 |
| 6 | 有効期間終了 | 日付 | いいえ | 有効期間の終了日 |
| 7 | 実行パラメータ | テキスト | いいえ | 実行時のパラメータ |
| 8 | 対象会社 | ドロップダウン | いいえ | 対象会社 |
| 9 | 対象店舗 | ドロップダウン | いいえ | 対象店舗 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 保存 | 入力した情報を保存 |
| 2 | キャンセル | 編集をキャンセルして一覧へ戻る |
| 3 | Cron式検証 | Cron式の妥当性を検証 |
| 4 | 次回実行日時確認 | 設定した条件に基づく次回実行日時を表示 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 必須項目 | 対象ジョブ、状態、実行日時は必須 |
| 3 | Cron式形式 | Cron式は標準的な形式であること |
| 4 | 有効期間 | 有効期間終了は有効期間開始より後であること |
