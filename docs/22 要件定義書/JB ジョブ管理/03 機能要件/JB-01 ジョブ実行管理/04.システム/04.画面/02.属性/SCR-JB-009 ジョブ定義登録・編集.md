# 画面属性一覧

ジョブ定義登録・編集の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-009 |
| 画面名 | ジョブ定義登録・編集 |
| 説明 | ジョブコード、パラメータ仕様、実行制約などを登録・変更 |
| 関連ユースケース | UC-JB-001, UC-JB-002 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ジョブコード | 入力 | String | 必須 | - | 50文字以内 | ジョブの一意な識別子 |
| 2 | ジョブ名 | 入力 | String | 必須 | - | 100文字以内 | ジョブの名前 |
| 3 | 説明 | 入力 | String | 任意 | - | 500文字以内 | ジョブの説明 |
| 4 | パラメータ | 入力 | String | 任意 | - | 1000文字以内 | ジョブのパラメータ仕様 |
| 5 | 同時実行数 | 入力 | Integer | 必須 | 1 | 1-10 | 許可される同時実行数 |
| 6 | 実行タイムアウト | 入力 | Integer | 必須 | 3600 | 60-86400 | 実行タイムアウト（秒） |
| 7 | 再実行待機時間 | 入力 | Integer | 任意 | 300 | 0-3600 | 再実行待機時間（秒） |
| 8 | 有効フラグ | チェックボックス | Boolean | 必須 | true | - | 有効かどうか |
| 9 | 保存 | ボタン | - | - | - | - | ジョブ定義を保存 |
| 10 | キャンセル | ボタン | - | - | - | - | 編集をキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
