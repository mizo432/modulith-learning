# 画面属性一覧

通知設定の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-022 |
| 画面名 | 通知設定 |
| 説明 | 通知条件、通知先、通知対象ジョブを設定 |
| 関連ユースケース | UC-JB-019 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 通知対象ジョブ | 選択 | String | 必須 | - | - | 通知対象のジョブ |
| 2 | 通知条件 | 選択 | Enum | 必須 | - | 通知条件 | 通知を送信する条件 |
| 3 | 通知方法 | 選択 | Enum | 必須 | - | 通知方法 | 通知の送信方法 |
| 4 | 通知先 | 入力 | String | 必須 | - | 200文字以内 | 通知の送信先 |
| 5 | 有効フラグ | チェックボックス | Boolean | 必須 | true | - | 有効かどうか |
| 6 | 保存 | ボタン | - | - | - | - | 通知設定を保存 |
| 7 | キャンセル | ボタン | - | - | - | - | 編集をキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
