# 画面属性一覧

ジョブ配備状況一覧の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-019 |
| 画面名 | ジョブ配備状況一覧 |
| 説明 | サーバーごとのジョブ配備状況、バージョン、実行可否を確認 |
| 関連ユースケース | UC-JB-018 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ジョブ名 | 入力 | String | 任意 | - | 50文字以内 | ジョブ名で検索 |
| 2 | サーバー名 | 入力 | String | 任意 | - | 50文字以内 | サーバー名で検索 |
| 3 | 検索 | ボタン | - | - | - | - | 検索条件を適用 |
| 4 | 一覧 | 表示 | String | - | - | - | 配備状況の一覧表示 |
| 5 | ページネーション | 表示 | Integer | - | - | - | ページ送りコントロール |
| 6 | ソート | 選択 | String | 任意 | ジョブ名 | - | ソート項目を選択 |
| 7 | 詳細 | リンク | - | - | - | - | 配備詳細画面へ遷移 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | 検索条件 | 検索条件入力領域 | ジョブ名, サーバー名, 検索 |
| 2 | 一覧 | 配備状況一覧表示 | 一覧, ソート |
| 3 | ページネーション | ページ送りコントロール | ページネーション |
| 4 | 操作 | 実行操作ボタン | 詳細 |

## 画面操作

画面で実行可能な操作を定義します。

| 番号 | 操作名 | トリガー | 説明 | 遷移先画面 |
|------|--------|----------|------|------------|
| 1 | 検索 | 検索ボタン | 検索条件を適用して一覧を更新 | - |
| 2 | ソート変更 | ソート選択 | ソート項目を変更 | - |
| 3 | 詳細表示 | 詳細リンク | 選択した配備の詳細を表示 | SCR-JB-020 |

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | ジョブ名文字数制限 | ジョブ名 | 50文字以内 | ジョブ名の入力文字数を制限 |
| 2 | サーバー名文字数制限 | サーバー名 | 50文字以内 | サーバー名の入力文字数を制限 |

## バリデーションルール

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|

| 2 | サーバー名文字数 | サーバー名 | 50文字以内 | サーバー名は50文字以内で入力してください |
