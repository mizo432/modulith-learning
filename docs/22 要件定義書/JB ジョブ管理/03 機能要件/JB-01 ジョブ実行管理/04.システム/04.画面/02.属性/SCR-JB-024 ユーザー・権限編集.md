# 画面属性一覧

ユーザー・権限編集の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-024 |
| 画面名 | ユーザー・権限編集 |
| 説明 | ロール、会社、店舗の参照権限を設定 |
| 関連ユースケース | UC-JB-021, UC-JB-022 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ユーザー名 | 表示 | String | - | - | - | ユーザーの名前 |
| 2 | メールアドレス | 入力 | String | 必須 | - | 200文字以内 | メールアドレス |
| 3 | ロール | 選択 | Enum | 必須 | - | ロール | ユーザーのロール |
| 4 | 参照可能会社 | 選択 | String | 任意 | - | 複数選択可 | 参照可能な会社 |
| 5 | 参照可能店舗 | 選択 | String | 任意 | - | 複数選択可 | 参照可能な店舗 |
| 6 | 有効フラグ | チェックボックス | Boolean | 必須 | true | - | 有効かどうか |
| 7 | 保存 | ボタン | - | - | - | - | ユーザー情報を保存 |
| 8 | キャンセル | ボタン | - | - | - | - | 編集をキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
