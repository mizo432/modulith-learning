# 画面属性一覧

ジョブ実行詳細の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-003 |
| 画面名 | ジョブ実行詳細 |
| 説明 | 実行状態、実行先、実行時間、パラメータ、処理件数、エラー情報を表示 |
| 関連ユースケース | UC-JB-010 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 実行ID | 表示 | String | - | - | - | 実行の一意な識別子 |
| 2 | ジョブ名 | 表示 | String | - | - | - | 実行されたジョブの名前 |
| 3 | 実行状態 | 表示 | Enum | - | - | ジョブ実行状態 | 現在の実行状態 |
| 4 | 起動日時 | 表示 | DateTime | - | - | - | ジョブが起動された日時 |
| 5 | 終了日時 | 表示 | DateTime | - | - | - | ジョブが終了した日時 |
| 6 | 実行時間 | 表示 | Integer | - | - | - | 実行に要した時間（秒） |
| 7 | 実行先サーバー | 表示 | String | - | - | - | 実行されたサーバー名 |
| 8 | パラメータ | 表示 | String | - | - | - | 実行時に使用されたパラメータ |
| 9 | 処理件数 | 表示 | Long | - | - | - | 処理されたデータ件数 |
| 10 | エラー情報 | 表示 | String | - | - | - | エラーが発生した場合の詳細 |
| 11 | 実行ログ | リンク | - | - | - | - | 実行ログ詳細画面へ遷移 |
| 12 | 再実行 | ボタン | - | - | - | - | この実行を再実行 |
| 13 | キャンセル | ボタン | - | - | - | - | 実行中のジョブをキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

| 4 | 実行結果 | 実行結果情報 | 処理件数, エラー情報 |
