キャンセル確認画面の属性をリストアップします。

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-015 |
| 画面名 | キャンセル確認画面 |

| 関連ユースケース | UC-JB-015 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 実行ID | 表示 | String | - | - | - | 実行の識別子 |
| 2 | ジョブ名 | 表示 | String | - | - | - | 実行されたジョブの名前 |
| 3 | 実行状態 | 表示 | Enum | - | - | ジョブ実行状態 | 現在の実行状態 |
| 4 | 実行開始日時 | 表示 | DateTime | - | - | - | 実行が開始された日時 |
| 5 | キャンセルの影響 | 表示 | String | - | - | - | キャンセルによる影響 |
| 6 | 実行理由 | 入力 | String | 必須 | - | 500文字以内 | キャンセルの理由 |
| 7 | キャンセル実行 | ボタン | - | - | - | - | キャンセルを実行 |
| 8 | 戻る | ボタン | - | - | - | - | キャンセルを中止 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
