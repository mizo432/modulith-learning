# 画面属性一覧

再実行確認画面の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-013 |
| 画面名 | 再実行確認画面 |
| 説明 | 元の実行内容、再実行条件、影響、実行理由を確認 |
| 関連ユースケース | UC-JB-013 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 元の実行ID | 表示 | String | - | - | - | 元の実行の識別子 |
| 2 | ジョブ名 | 表示 | String | - | - | - | 実行されたジョブの名前 |
| 3 | 元の実行日時 | 表示 | DateTime | - | - | - | 元の実行日時 |
| 4 | 元の実行結果 | 表示 | Enum | - | - | ジョブ実行状態 | 元の実行結果 |
| 5 | 再実行条件 | 表示 | String | - | - | - | 再実行の条件 |
| 6 | 影響 | 表示 | String | - | - | - | 再実行による影響 |
| 7 | 実行理由 | 入力 | String | 必須 | - | 500文字以内 | 再実行の理由 |
| 8 | 再実行 | ボタン | - | - | - | - | 再実行を実行 |
| 9 | キャンセル | ボタン | - | - | - | - | 再実行をキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
