# 画面属性一覧

ジョブ実行状況一覧の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-002 |
| 画面名 | ジョブ実行状況一覧 |
| 説明 | 実行中・待機中・異常終了などを検索・一覧表示 |
| 関連ユースケース | UC-JB-010 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 状態 | 選択 | Enum | 任意 | 全て | ジョブ実行状態 | 実行状態でフィルタ |
| 2 | ジョブ名 | 入力 | String | 任意 | - | 50文字以内 | ジョブ名で検索 |
| 3 | 会社 | 選択 | String | 任意 | 全て | - | 会社でフィルタ |
| 4 | 店舗 | 選択 | String | 任意 | 全て | - | 店舗でフィルタ |
| 5 | 検索 | ボタン | - | - | - | - | 検索条件を適用 |
| 6 | 一覧 | 表示 | String | - | - | - | 実行状況の一覧表示 |
| 7 | ページネーション | 表示 | Integer | - | - | - | ページ送りコントロール |
| 8 | ソート | 選択 | String | 任意 | 起動日時 | - | ソート項目を選択 |
| 9 | 詳細 | リンク | - | - | - | - | 実行詳細画面へ遷移 |
| 10 | 再実行 | ボタン | - | - | - | - | 選択したジョブを再実行 |
| 11 | キャンセル | ボタン | - | - | - | - | 実行中のジョブをキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | 検索条件 | 検索条件入力領域 | 状態, ジョブ名, 会社, 店舗, 検索 |
| 2 | 一覧 | 実行状況一覧表示 | 一覧, ソート |
| 3 | ページネーション | ページ送りコントロール | ページネーション |

|------|--------|----------|------|------------|

| 3 | 詳細表示 | 詳細リンク | 選択した実行の詳細を表示 | SCR-JB-003 |
| 4 | 再実行 | 再実行ボタン | 選択したジョブを再実行 | SCR-JB-013 |
| 5 | キャンセル | キャンセルボタン | 実行中のジョブをキャンセル | SCR-JB-015 |
