# 画面属性一覧

ジョブ定義詳細の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-008 |
| 画面名 | ジョブ定義詳細 |
| 説明 | ジョブ仕様、パラメータ、同時実行数、通知設定を確認 |
| 関連ユースケース | UC-JB-005 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ジョブコード | 表示 | String | - | - | - | ジョブの一意な識別子 |
| 2 | ジョブ名 | 表示 | String | - | - | - | ジョブの名前 |
| 3 | 説明 | 表示 | String | - | - | - | ジョブの説明 |
| 4 | 状態 | 表示 | Enum | - | - | ジョブ状態 | 現在の状態 |
| 5 | バージョン | 表示 | String | - | - | - | 現在のバージョン |
| 6 | パラメータ | 表示 | String | - | - | - | ジョブのパラメータ仕様 |
| 7 | 同時実行数 | 表示 | Integer | - | - | - | 許可される同時実行数 |
| 8 | 通知設定 | 表示 | String | - | - | - | 通知の設定内容 |
| 9 | 配備状況 | 表示 | String | - | - | - | サーバーへの配備状況 |
| 10 | 編集 | ボタン | - | - | - | - | ジョブ定義を編集 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
