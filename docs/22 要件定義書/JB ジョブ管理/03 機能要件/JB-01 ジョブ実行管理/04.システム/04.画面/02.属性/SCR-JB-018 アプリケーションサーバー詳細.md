# 画面属性一覧

アプリケーションサーバー詳細の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-018 |
| 画面名 | アプリケーションサーバー詳細 |
| 説明 | サーバー情報、ヘルスチェック、稼働中ジョブ、対応バージョンを表示 |
| 関連ユースケース | UC-JB-017 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | サーバー名 | 表示 | String | - | - | - | サーバーの名前 |
| 2 | ホスト名 | 表示 | String | - | - | - | サーバーのホスト名 |
| 3 | ポート番号 | 表示 | Integer | - | - | - | サーバーのポート番号 |
| 4 | 稼働状態 | 表示 | Enum | - | - | 稼働/停止 | 現在の稼働状態 |
| 5 | 接続状態 | 表示 | Enum | - | - | 接続/切断 | 現在の接続状態 |
| 6 | 受付可否 | 表示 | Boolean | - | - | - | ジョブの受付が可能かどうか |
| 7 | ヘルスチェック | 表示 | String | - | - | - | 最新のヘルスチェック結果 |
| 8 | 稼働中ジョブ | 表示 | String | - | - | - | 現在稼働中のジョブ一覧 |
| 9 | 対応バージョン | 表示 | String | - | - | - | 対応するジョブのバージョン |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
