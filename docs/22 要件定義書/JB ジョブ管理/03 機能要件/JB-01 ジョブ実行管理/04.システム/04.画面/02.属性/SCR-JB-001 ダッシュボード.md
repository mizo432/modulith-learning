# 画面属性一覧

ダッシュボードの属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-001 |
| 画面名 | ダッシュボード |
| 説明 | 実行中・成功・失敗件数、異常発生状況、要対応ジョブを表示 |
| 関連ユースケース | UC-JB-010, UC-JB-011 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 期間選択 | 選択 | Date | 必須 | 今日 | - | 表示期間を選択 |
| 2 | 実行中件数 | 表示 | Integer | - | - | - | 現在実行中のジョブ件数 |
| 3 | 成功件数 | 表示 | Integer | - | - | - | 期間内の成功件数 |
| 4 | 失敗件数 | 表示 | Integer | - | - | - | 期間内の失敗件数 |
| 5 | 結果不明件数 | 表示 | Integer | - | - | - | 期間内の結果不明件数 |
| 6 | 待機中件数 | 表示 | Integer | - | - | - | 現在待機中のジョブ件数 |
| 7 | 異常発生状況 | 表示 | String | - | - | - | 最近の異常発生状況の概要 |
| 8 | 要対応ジョブ一覧 | 表示 | String | - | - | - | 対応が必要なジョブの一覧 |
| 9 | 再実行 | ボタン | - | - | - | - | 選択したジョブを再実行 |
| 10 | ジョブ実行状況一覧 | リンク | - | - | - | - | ジョブ実行状況一覧画面へ遷移 |
| 11 | ジョブ実行履歴一覧 | リンク | - | - | - | - | ジョブ実行履歴一覧画面へ遷移 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
