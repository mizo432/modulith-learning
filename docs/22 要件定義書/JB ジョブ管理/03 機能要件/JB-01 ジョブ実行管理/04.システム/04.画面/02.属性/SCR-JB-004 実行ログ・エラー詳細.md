# 画面属性一覧

実行ログ・エラー詳細の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-004 |
| 画面名 | 実行ログ・エラー詳細 |
| 説明 | ログ、エラー内容、発生箇所、関連イベントを確認 |
| 関連ユースケース | UC-JB-010 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 実行ID | 表示 | String | - | - | - | 実行の一意な識別子 |
| 2 | ログレベル | 選択 | Enum | 任意 | 全て | ログレベル | ログレベルでフィルタ |
| 3 | 検索キーワード | 入力 | String | 任意 | - | 100文字以内 | ログ内容で検索 |
| 4 | 検索 | ボタン | - | - | - | - | 検索条件を適用 |
| 5 | ログ一覧 | 表示 | String | - | - | - | ログの一覧表示 |
| 6 | エラー内容 | 表示 | String | - | - | - | エラーの詳細内容 |
| 7 | 発生箇所 | 表示 | String | - | - | - | エラーが発生した箇所 |
| 8 | 関連イベント | 表示 | String | - | - | - | 関連するイベント一覧 |
| 9 | ページネーション | 表示 | Integer | - | - | - | ページ送りコントロール |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
