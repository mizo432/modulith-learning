# 画面属性一覧

ジョブ配備詳細の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-020 |
| 画面名 | ジョブ配備詳細 |
| 説明 | ジョブとサーバーの対応関係、バージョン互換性を確認 |
| 関連ユースケース | UC-JB-018 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ジョブコード | 表示 | String | - | - | - | ジョブの一意な識別子 |
| 2 | ジョブ名 | 表示 | String | - | - | - | ジョブの名前 |
| 3 | サーバー名 | 表示 | String | - | - | - | サーバーの名前 |
| 4 | 配備バージョン | 表示 | String | - | - | - | 配備されたバージョン |
| 5 | 配備日時 | 表示 | DateTime | - | - | - | 配備された日時 |
| 6 | バージョン互換性 | 表示 | Boolean | - | - | - | バージョンが互換かどうか |
| 7 | 実行可否 | 表示 | Boolean | - | - | - | 実行が可能かどうか |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
