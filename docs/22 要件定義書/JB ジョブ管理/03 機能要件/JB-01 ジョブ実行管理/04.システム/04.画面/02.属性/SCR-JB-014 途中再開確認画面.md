## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 実行ID | 表示 | String | - | - | - | 実行の識別子 |
| 2 | ジョブ名 | 表示 | String | - | - | - | 実行されたジョブの名前 |
| 3 | 再開可否 | 表示 | Boolean | - | - | - | 再開が可能かどうか |
| 4 | チェックポイント | 表示 | String | - | - | - | 保存されたチェックポイント |
| 5 | 再開位置 | 表示 | String | - | - | - | 再開する位置 |
| 6 | 実行理由 | 入力 | String | 必須 | - | 500文字以内 | 再開の理由 |
| 7 | 再開 | ボタン | - | - | - | - | 途中再開を実行 |
| 8 | キャンセル | ボタン | - | - | - | - | 再開をキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
