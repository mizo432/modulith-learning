# 画面属性一覧

ジョブ手動起動画面の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-012 |
| 画面名 | ジョブ手動起動画面 |
| 説明 | 対象ジョブ、実行パラメータ、対象会社・店舗を指定して起動 |
| 関連ユースケース | UC-JB-012 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 対象ジョブ | 選択 | String | 必須 | - | - | 起動対象のジョブ |
| 2 | 実行パラメータ | 入力 | String | 任意 | - | 1000文字以内 | 実行時のパラメータ |
| 3 | 対象会社 | 選択 | String | 任意 | 全て | - | 実行対象の会社 |
| 4 | 対象店舗 | 選択 | String | 任意 | 全て | - | 実行対象の店舗 |
| 5 | 起動 | ボタン | - | - | - | - | ジョブを起動 |
| 6 | キャンセル | ボタン | - | - | - | - | 起動をキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

## 画面レイアウト

画面の領域構成を定義します。

| 番号 | 領域名 | 説明 | 含まれる項目 |
|------|--------|------|--------------|
| 1 | ヘッダー | 画面タイトル | - |
| 2 | 基本情報 | 起動の基本情報 | 対象ジョブ, 実行パラメータ |
| 3 | 対象範囲 | 実行対象の範囲 | 対象会社, 対象店舗 |
| 4 | 操作 | 実行操作ボタン | 起動, キャンセル |
