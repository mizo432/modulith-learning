# 画面属性一覧

スケジュール登録・編集の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-011 |
| 画面名 | スケジュール登録・編集 |
| 説明 | 実行日時、繰り返し条件、対象ジョブ、有効期間を設定 |
| 関連ユースケース | UC-JB-006, UC-JB-007 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | 対象ジョブ | 選択 | String | 必須 | - | - | 実行対象のジョブ |
| 2 | 実行日時 | 入力 | DateTime | 必須 | - | - | 初回実行日時 |
| 3 | 繰り返し条件 | 入力 | String | 任意 | - | 100文字以内 | Cron式などの繰り返し条件 |
| 4 | 有効期間開始 | 入力 | Date | 必須 | - | - | 有効期間の開始日 |
| 5 | 有効期間終了 | 入力 | Date | 任意 | - | - | 有効期間の終了日 |
| 6 | 有効フラグ | チェックボックス | Boolean | 必須 | true | - | 有効かどうか |
| 7 | 保存 | ボタン | - | - | - | - | スケジュールを保存 |
| 8 | キャンセル | ボタン | - | - | - | - | 編集をキャンセル |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード

|------|--------|------|--------------|

| 3 | 繰り返し条件 | 繰り返し条件の設定 | 繰り返し条件 |
| 4 | 有効期間 | 有効期間の設定 | 有効期間開始, 有効期間終了 |
| 5 | 状態 | 状態の設定 | 有効フラグ |
| 6 | 操作 | 実行操作ボタン | 保存, キャンセル |

## 画面操作

|------|--------|----------|------|------------|

## 制約事項

画面項目の制約条件を定義します。

| 番号 | 制約名 | 対象項目 | 制約内容 | 説明 |
|------|--------|----------|----------|------|
| 1 | 繰り返し条件文字数制限 | 繰り返し条件 | 100文字以内 | 繰り返し条件の入力文字数を制限 |
| 2 | 有効期間終了日 | 有効期間終了 | 有効期間開始日以降 | 有効期間終了日は開始日以降とする |

入力値の検証ルールを定義します。

| 番号 | ルール名 | 対象項目 | 条件 | エラーメッセージ |
|------|----------|----------|------|------------------|
| 1 | 対象ジョブ必須 | 対象ジョブ | 空でないこと | 対象ジョブを選択してください |
| 2 | 実行日時必須 | 実行日時 | 空でないこと | 実行日時を入力してください |
| 3 | 有効期間開始必須 | 有効期間開始 | 空でないこと | 有効期間開始日を入力してください |
| 4 | Cron式形式 | 繰り返し条件 | Cron式の形式 | 正しいCron式を入力してください |
