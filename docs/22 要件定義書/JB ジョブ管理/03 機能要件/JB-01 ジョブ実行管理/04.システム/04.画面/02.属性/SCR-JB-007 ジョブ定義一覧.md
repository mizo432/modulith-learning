# 画面属性一覧

ジョブ定義一覧の属性をリストアップします。

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面ID | SCR-JB-007 |
| 画面名 | ジョブ定義一覧 |
| 説明 | 登録済みジョブの検索、状態、バージョン、配備状況の確認 |
| 関連ユースケース | UC-JB-004 |

## 画面項目一覧

画面に表示・入力される項目を定義します。

| 番号 | 項目名 | 項目タイプ | 型 | 必須 | 初期値 | 制約 | 説明 |
|------|--------|------------|----|------|--------|------|------|
| 1 | ジョブ名 | 入力 | String | 任意 | - | 50文字以内 | ジョブ名で検索 |
| 2 | 状態 | 選択 | Enum | 任意 | 全て | ジョブ状態 | 状態でフィルタ |
| 3 | 検索 | ボタン | - | - | - | - | 検索条件を適用 |
| 4 | 一覧 | 表示 | String | - | - | - | ジョブ定義の一覧表示 |
| 5 | ページネーション | 表示 | Integer | - | - | - | ページ送りコントロール |
| 6 | ソート | 選択 | String | 任意 | ジョブ名 | - | ソート項目を選択 |
| 7 | 詳細 | リンク | - | - | - | - | ジョブ定義詳細画面へ遷移 |
| 8 | 編集 | ボタン | - | - | - | - | ジョブ定義を編集 |
| 9 | 削除 | ボタン | - | - | - | - | ジョブ定義を削除 |

## 項目タイプ

項目タイプは以下から選択します：

- **表示**: 画面に表示のみされる項目
- **入力**: ユーザーが入力する項目
- **選択**: ドロップダウンやラジオボタンなどで選択する項目
- **チェックボックス**: 真偽値を選択する項目
- **ボタン**: 操作を実行するボタン
- **リンク**: 他の画面や外部リソースへのリンク

## 項目の型

項目の型は以下から選択します：

- **String**: 文字列
- **Integer**: 整数
- **Long**: 長整数
- **Double**: 浮動小数点
- **Boolean**: 真偽値
- **Date**: 日付
- **DateTime**: 日時
- **Enum**: 列挙型（対照表を参照）
- **File**: ファイルアップロード
