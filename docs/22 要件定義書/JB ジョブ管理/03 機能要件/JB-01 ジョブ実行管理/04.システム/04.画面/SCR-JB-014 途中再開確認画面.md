# 途中再開確認画面

途中再開確認画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-014 |
| 画面名           | 途中再開確認画面 |
| 説明             | 再開可否、チェックポイント、再開位置を確認 |
| 関連ユースケース | UC-JB-020 (ジョブをチェックポイントから再開する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 元の実行情報エリア | 実行ID、ジョブコード、エラー内容などの元の実行情報 |
| チェックポイント情報エリア | チェックポイント位置、再開位置などの情報 |
| 実行理由エリア | 再開の理由入力 |
| 操作エリア | 途中再開、キャンセルボタン |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 元の実行ID | テキスト | - | 元の実行ID |
| 2 | ジョブコード | テキスト | - | ジョブコード |
| 3 | ジョブ名 | テキスト | - | ジョブ名 |
| 4 | 元の実行状態 | ステータス | - | 元の実行状態（失敗、結果不明） |
| 5 | エラーコード | テキスト | - | エラーコード |
| 6 | エラーメッセージ | テキスト | - | エラーメッセージ |
| 7 | チェックポイント位置 | テキスト | - | 最後のチェックポイント位置 |
| 8 | チェックポイント日時 | 日時 | - | チェックポイント保存日時 |
| 9 | 再開位置 | テキスト | - | 再開する位置 |
| 10 | 再開パラメータ | テキスト | いいえ | 再開時のパラメータ |
| 11 | 実行理由 | テキスト | はい | 再開の理由 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 途中再開 | チェックポイントからジョブを再開 |
| 2 | キャンセル | 再開をキャンセルして一覧へ戻る |
| 3 | パラメータ編集 | 再開パラメータを編集 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 再開可否 | チェックポイントがある場合のみ再開可能 |
| 3 | 必須項目 | 実行理由は必須 |
| 4 | 同時実行枠 | 同時実行枠を超えている場合は再開不可 |
