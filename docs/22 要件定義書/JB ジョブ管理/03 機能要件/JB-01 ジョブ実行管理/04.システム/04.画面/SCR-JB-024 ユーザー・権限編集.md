# ユーザー・権限編集

ユーザー・権限編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-024 |
| 画面名           | ユーザー・権限編集 |
| 説明             | ロール、会社、店舗の参照権限を設定 |
| 関連ユースケース | UC-JB-007 (ユーザー権限を管理する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 基本情報エリア | ユーザー名、表示名、状態などの基本情報入力 |
| 権限情報エリア | ロール、会社、店舗の参照権限設定 |
| 操作エリア | 保存、キャンセルボタン |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ユーザーID | テキスト | - | ユーザーID（変更不可） |
| 2 | ユーザー名 | テキスト | はい | ユーザー名 |
| 3 | 表示名 | テキスト | はい | 表示名 |
| 4 | 状態 | ドロップダウン | はい | 状態（有効、無効） |
| 5 | ロール | ドロップダウン | はい | ロール（運用管理者など） |
| 6 | 参照権限_会社 | チェックボックスリスト | いいえ | 参照可能な会社（全選択可能） |
| 7 | 参照権限_店舗 | チェックボックスリスト | いいえ | 参照可能な店舗（全選択可能） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 保存 | 入力した情報を保存 |
| 2 | キャンセル | 編集をキャンセルして一覧へ戻る |
| 3 | 全会社選択 | 全会社を選択 |
| 4 | 全会社解除 | 全会社の選択を解除 |
| 5 | 全店舗選択 | 全店舗を選択 |
| 6 | 全店舗解除 | 全店舗の選択を解除 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 必須項目 | ユーザー名、表示名、状態、ロールは必須 |
| 3 | 自分自身の権限 | 自分自身の権限を変更する場合は確認ダイアログを表示 |
