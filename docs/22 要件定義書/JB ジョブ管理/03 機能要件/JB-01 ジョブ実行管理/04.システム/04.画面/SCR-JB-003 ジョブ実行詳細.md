# ジョブ実行詳細

ジョブ実行詳細画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-003 |
| 画面名           | ジョブ実行詳細 |
| 説明             | 実行状態、実行先、実行時間、パラメータ、処理件数、エラー情報を表示 |
| 関連ユースケース | UC-JB-013 (ジョブ実行状況を一覧で確認する)、UC-JB-014 (ジョブ実行詳細を確認する) |

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 基本情報エリア | 実行ID、ジョブコード、状態などの基本情報 |
| 実行情報エリア | 実行先サーバー、実行時間、パラメータ、処理件数 |
| エラー情報エリア | エラー内容、発生箇所（失敗時のみ） |
| 操作エリア | 再実行、途中再開、キャンセルなどの操作ボタン |
| フッター | 更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 更新 | 詳細情報を手動で更新 |
| 2 | ログ詳細へ遷移 | 実行ログ・エラー詳細画面へ遷移 |
| 3 | 再実行 | 再実行確認画面へ遷移（失敗・結果不明時のみ） |
| 4 | 途中再開 | 途中再開確認画面へ遷移（チェックポイントがある場合） |
| 5 | キャンセル | キャンセル確認画面へ遷移（実行中のみ） |
| 6 | 一覧へ戻る | ジョブ実行状況一覧画面へ戻る |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
