# 通知設定

通知設定画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-022 |
| 画面名           | 通知設定 |
| 説明             | 通知条件、通知先、通知対象ジョブを設定 |
| 関連ユースケース | UC-JB-022 (通知設定を変更する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 通知条件エリア | 通知を送信する条件の設定 |
| 通知先エリア | 通知先の設定 |
| 対象ジョブエリア | 通知対象となるジョブの設定 |
| 操作エリア | 保存、キャンセルボタン |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 通知条件_成功 | チェックボックス | いいえ | 成功時に通知を送信 |
| 2 | 通知条件_失敗 | チェックボックス | はい | 失敗時に通知を送信 |
| 3 | 通知条件_結果不明 | チェックボックス | はい | 結果不明時に通知を送信 |
| 4 | 通知先_メール | テキスト | いいえ | メールアドレス |
| 5 | 通知先_Slack | テキスト | いいえ | Slackチャンネル |
| 6 | 通知先_Webhook | テキスト | いいえ | WebhookURL |
| 7 | 対象ジョブ | チェックボックスリスト | いいえ | 通知対象となるジョブ（全選択可能） |
| 8 | 通知期間_開始 | 時刻 | いいえ | 通知開始時刻 |
| 9 | 通知期間_終了 | 時刻 | いいえ | 通知終了時刻 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 保存 | 入力した情報を保存 |
| 2 | キャンセル | 編集をキャンセルして一覧へ戻る |
| 3 | テスト送信 | テスト通知を送信 |
| 4 | 全ジョブ選択 | 全ジョブを選択 |
| 5 | 全ジョブ解除 | 全ジョブの選択を解除 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 必須項目 | 通知条件_失敗、通知条件_結果不明のいずれかは必須 |
| 3 | 通知先 | メール、Slack、Webhookのいずれかは必須 |
| 4 | 時刻範囲 | 通知期間終了は通知期間開始より後であること |
