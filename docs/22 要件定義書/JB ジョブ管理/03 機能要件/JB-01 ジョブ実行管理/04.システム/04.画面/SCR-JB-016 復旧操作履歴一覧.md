# 復旧操作履歴一覧

復旧操作履歴一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-016 |
| 画面名           | 復旧操作履歴一覧 |
| 説明             | 再実行・再開・キャンセルの操作者、理由、日時を確認 |
| 関連ユースケース | UC-JB-021 (復旧操作履歴を確認する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールドと検索ボタン |
| メインエリア | 復旧操作履歴一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_期間 | 日付範囲 | いいえ | 操作期間で検索 |
| 2 | 検索_操作タイプ | ドロップダウン | いいえ | 操作タイプ（再実行、途中再開、キャンセル）で検索 |
| 3 | 検索_ジョブコード | テキスト | いいえ | ジョブコードで検索 |
| 4 | 検索_操作者 | テキスト | いいえ | 操作者で検索 |
| 5 | 一覧_操作ID | テキスト | - | 操作ID |
| 6 | 一覧_操作日時 | 日時 | - | 操作日時 |
| 7 | 一覧_操作タイプ | テキスト | - | 操作タイプ（再実行、途中再開、キャンセル） |
| 8 | 一覧_ジョブコード | テキスト | - | ジョブコード |
| 9 | 一覧_元の実行ID | テキスト | - | 元の実行ID |
| 10 | 一覧_操作者 | テキスト | - | 操作者 |
| 11 | 一覧_操作理由 | テキスト | - | 操作理由 |
| 12 | 一覧_結果 | ステータス | - | 操作結果（成功、失敗） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で検索実行 |
| 2 | 初期化 | 検索条件を初期化 |
| 3 | ソート | 列ヘッダークリックでソート |
| 4 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 参照のみ | 編集・操作は不可 |
