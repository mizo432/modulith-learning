# 再実行確認画面

再実行確認画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-JB-013 |
| 画面名           | 再実行確認画面 |
| 説明             | 元の実行内容、再実行条件、影響、実行理由を確認 |
| 関連ユースケース | UC-JB-019 (ジョブを最初から再実行する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 元の実行情報エリア | 実行ID、ジョブコード、エラー内容などの元の実行情報 |
| 再実行条件エリア | 再実行時のパラメータ、実行先サーバーなどの条件 |
| 実行理由エリア | 再実行の理由入力 |
| 操作エリア | 再実行、キャンセルボタン |
| フッター | 更新日時 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 元の実行ID | テキスト | - | 元の実行ID |
| 2 | ジョブコード | テキスト | - | ジョブコード |
| 3 | ジョブ名 | テキスト | - | ジョブ名 |
| 4 | 元の実行状態 | ステータス | - | 元の実行状態（失敗、結果不明） |
| 5 | エラーコード | テキスト | - | エラーコード |
| 6 | エラーメッセージ | テキスト | - | エラーメッセージ |
| 7 | 元の実行パラメータ | テキスト | - | 元の実行パラメータ |
| 8 | 再実行パラメータ | テキスト | いいえ | 再実行時のパラメータ（元のパラメータを継承） |
| 9 | 実行先サーバー | ドロップダウン | いいえ | 実行先サーバー（自動選択の場合空） |
| 10 | 実行理由 | テキスト | はい | 再実行の理由 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 再実行 | ジョブを再実行 |
| 2 | キャンセル | 再実行をキャンセルして一覧へ戻る |
| 3 | パラメータ編集 | 再実行パラメータを編集 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 運用管理者のみアクセス可能 |
| 2 | 再実行可否 | 失敗・結果不明の状態のみ再実行可能 |
| 3 | 必須項目 | 実行理由は必須 |
| 4 | 同時実行枠 | 同時実行枠を超えている場合は再実行不可 |
