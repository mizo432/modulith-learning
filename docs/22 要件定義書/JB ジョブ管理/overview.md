# 概要

本ドキュメントは、JB ジョブ管理（Jobloom）事業領域の要件定義の概要です。

Jobloom（ジョブルーム）は、複数の業務システムに組み込まれたジョブを、統一的に起動・監視・管理するための分散ジョブ実行・運用管理システムです。

## 事業領域情報

- 事業領域コード: JB
- 事業領域名: ジョブ管理
- 事業領域英名: Jobloom
- 区分: コア

## RDRA 4レイヤー

1. システム価値レイヤー: 要求、アクター、外部システム
2. 外部環境レイヤー: 業務、BUC、アクティビティ
3. システム境界レイヤー: ユースケース、画面、イベント
4. システムレイヤー: 情報、状態、条件、バリエーション
