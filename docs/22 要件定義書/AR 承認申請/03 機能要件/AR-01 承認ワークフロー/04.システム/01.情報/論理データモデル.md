# 論理データモデル

## 概要

AR-01 承認ワークフロー業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    APPROVAL_REQUEST
    {
        string APPROVAL_REQUEST_ID PK "承認リクエストID"
        string タイトル "タイトル"
        string 内容 "内容"
        string 申請者 "申請者"
        string 承認者 "承認者"
        string 状態 "状態"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(承認リクエスト)"
        enum variation "バリエーション(承認状態)"
        string created_at "作成日"
        string updated_at "更新日"
    }

    APPROVAL_FLOW
    {
        string APPROVAL_FLOW_ID PK "承認フローID"
        string ステップ "ステップ"
        string 担当者 "担当者"
        string 状態 "状態"
        string 作成日 "作成日"
        string created_at "作成日"
        string updated_at "更新日"
    }
    APPROVAL_FLOW }|--|| APPROVAL_REQUEST : 承認フロー
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| 承認リクエスト | APPROVAL_REQUEST_ID | string | true | 承認リクエストID |
| 承認フロー | APPROVAL_FLOW_ID | string | true | 承認フローID |
