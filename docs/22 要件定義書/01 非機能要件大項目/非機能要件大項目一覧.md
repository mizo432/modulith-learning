# 非機能要件大項目

## 概要

本ドキュメントは、アジルームシステムで扱う非機能要件の大項目（カテゴリ）を定義します。

## 非機能要件大項目一覧

| 番号 | 大項目       | 英名            | 説明                                                       |
|------|--------------|-----------------|------------------------------------------------------------|
| 01   | 性能         | Performance     | システムの応答時間、スループット、同時接続数などの性能要件 |
| 02   | 可用性       | Availability    | システムの稼働率、障害復旧時間などの可用性要件             |
| 03   | セキュリティ | Security        | 認証、認可、データ保護などのセキュリティ要件               |
| 04   | 拡張性       | Scalability     | 利用者数増加や機能追加に対応する拡張性要件                 |
| 05   | 互換性       | Compatibility   | ブラウザ、デバイス、外部システムとの互換性要件             |
| 06   | 保守性       | Maintainability | 障害対応、機能追加、バグ修正の容易さ                       |
| 07   | 使いやすさ   | Usability       | 学習の容易さ、操作の直感性、アクセシビリティ               |
