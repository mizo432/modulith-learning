# 業務一覧

帳票基盤管理業務領域（EF-01）の業務を定義します。

| ID        | 業務名                           | 概要                                                   | 主なアクター                   |
|-----------|----------------------------------|--------------------------------------------------------|--------------------------------|
| BUC-EF-01 | システム環境の管理               | システム環境、共通設定、環境別接続情報を管理する         | ACT-EF-01                      |
| BUC-EF-02 | 業務システムの管理               | 連携する業務システムの登録・管理を行う                 | ACT-EF-01, ACT-EF-03           |
| BUC-EF-03 | ストレージの管理                 | S3・MinIOによるファイル保存・取得を管理する            | ACT-EF-01                      |
| BUC-EF-04 | アクセス制御の管理               | 組織・利用者・業務システム・帳票単位の権限を制御する     | ACT-EF-01, ACT-EF-04           |
| BUC-EF-05 | 組織・利用者の管理               | 組織、部門、利用者、ロールを管理する                   | ACT-EF-02                      |
| BUC-EF-06 | 外部APIの管理                   | API認証、利用制限、API公開を管理する                 | ACT-EF-01                      |
| BUC-EF-07 | システム設定の管理               | 共通設定、環境設定、各種マスタを管理する               | ACT-EF-01                      |
