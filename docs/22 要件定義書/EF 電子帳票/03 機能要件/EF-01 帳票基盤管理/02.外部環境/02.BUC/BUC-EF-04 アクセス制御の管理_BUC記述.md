# BUC-EF-04 アクセス制御の管理

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-EF-04 |
| BUC名            | アクセス制御の管理 |
| 説明             | 組織・利用者・業務システム・帳票単位の権限を制御する |
| 関連業務         | アクセス制御管理 |
| 関連ユースケース | UC-EF-010, UC-EF-011, UC-EF-012 |

| 番号 | アクターID | アクター名 | 役割 |

| 1 | ACT-EF-01 | システム管理者 | アクセス制御ポリシーを設定・管理する |
| 2 | ACT-EF-04 | 運用管理者 | アクセス制御ポリシーを設定・監視する |

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1 | ポリシー情報入力 | 組織・利用者・業務システム・帳票単位の権限ポリシーを入力 | ACT-EF-01, ACT-EF-04 |
| 2 | ポリシー保存 | アクセス制御ポリシーを保存 | ACT-EF-01, ACT-EF-04 |
