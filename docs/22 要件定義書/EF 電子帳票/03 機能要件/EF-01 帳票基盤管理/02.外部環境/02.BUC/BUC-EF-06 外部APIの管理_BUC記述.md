# BUC-EF-06 外部APIの管理

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-EF-06 |
| BUC名            | 外部APIの管理 |
| 説明             | API認証、利用制限、API公開を管理する |
| 関連業務         | 外部API管理 |
| 関連ユースケース | UC-EF-018, UC-EF-019, UC-EF-020 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1 | ACT-EF-01 | システム管理者 | 外部APIキーを発行・管理する |

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1 | APIキー発行 | 外部API利用のためのキーを発行 | ACT-EF-01 |
| 2 | 利用制限設定 | APIの利用制限を設定 | ACT-EF-01 |
| 3 | APIキー確認 | 登録されたAPIキーを確認 | ACT-EF-01 |
| 4 | APIキー無効化 | 発行したAPIキーを無効化 | ACT-EF-01 |

## 関連情報

| 番号 | 情報名 | 情報種類 | 説明 |
|------|--------|----------|------|
| 1 | APIキー | リソース | 外部API利用のためのキー |

| 番号 | 状態名 | 説明 |

| 2 | 無効 | APIキーが利用できない状態 |
