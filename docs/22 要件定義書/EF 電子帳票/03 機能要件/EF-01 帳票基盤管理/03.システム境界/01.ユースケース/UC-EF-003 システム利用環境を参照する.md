# UC-EF-003 システム利用環境を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-003 |
| ユースケース名 | システム利用環境を参照する |
| 英語名 | View System Environment |
| 説明 | システム管理者が登録されたシステム環境設定を確認する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-01 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「システム利用環境」タブを選択する
3. システムが登録されたシステム利用環境一覧を表示する
4. ユーザーが対象の環境を選択する
5. システムが環境の詳細情報を表示する

## 代替フロー

- **3a. 環境が登録されていない場合**
  - 「環境が登録されていません」というメッセージを表示する
  - ユーザーは環境を登録するか、他の操作を行う

## 後置条件

- システム利用環境情報が表示される
