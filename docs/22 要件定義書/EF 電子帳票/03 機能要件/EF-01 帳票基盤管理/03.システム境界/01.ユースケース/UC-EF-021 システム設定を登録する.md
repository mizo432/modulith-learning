# UC-EF-021 システム設定を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-021 |
| ユースケース名 | システム設定を登録する |
| 英語名 | Register System Settings |
| 説明 | システム管理者が共通設定、環境設定、各種マスタを登録する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-07 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「システム設定」タブを選択する
3. 「設定を登録」ボタンをクリックする
4. 設定カテゴリ（共通設定、環境設定、マスタなど）を選択する
5. 設定項目、値、説明を入力する
6. 入力を保存する
7. システムがシステム設定を登録する
8. 登録完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **5b. 重複した設定項目の場合**
  - 既に同じ設定項目が存在する場合、エラーメッセージを表示する
  - ユーザーは設定を更新するか、他の操作を行う

## 後置条件

- システム設定がシステムに登録される
- 設定が反映される

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 設定カテゴリ、設定項目、値は必須入力 |
| 2 | 重複禁止 | 同じ設定項目は登録できない |
| 3 | 権限制限 | システム管理者のみ設定登録可能 |
