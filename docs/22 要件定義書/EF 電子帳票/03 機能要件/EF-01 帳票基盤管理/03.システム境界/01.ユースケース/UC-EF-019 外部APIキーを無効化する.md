# UC-EF-019 外部APIキーを無効化する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-019 |
| ユースケース名 | 外部APIキーを無効化する |
| 英語名 | Invalidate External API Key |
| 説明 | システム管理者が発行したAPIキーを無効化する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-06 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること
- 無効化対象のAPIキーが存在すること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「外部API管理」タブを選択する
3. システムが登録されたAPIキー一覧を表示する
4. ユーザーが無効化対象のAPIキーを選択する
5. 「APIキーを無効化」ボタンをクリックする
6. 無効化確認ダイアログを表示する
7. ユーザーが確認する
8. システムがAPIキーを無効化する
9. 無効化完了メッセージを表示する

## 代替フロー

- **6a. 無効化をキャンセルした場合**
  - ユーザーがキャンセルを選択する
  - ユースケースを終了する

## 後置条件

- APIキーがシステムで無効化される
- 無効化されたAPIキーは利用できなくなる
