# UC-EF-011 アクセス制御ポリシーを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-011 |
| ユースケース名 | アクセス制御ポリシーを更新する |
| 英語名 | Update Access Control Policy |
| 説明 | システム管理者または運用管理者が既存の権限ポリシーを修正する |
| 関連アクター | ACT-EF-01（システム管理者）、ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-04 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者または運用管理者の権限を持っていること
- 更新対象のアクセス制御ポリシーが存在すること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「アクセス制御」タブを選択する
3. 更新対象のポリシーを選択する
4. 「ポリシーを更新」ボタンをクリックする
5. 適用対象、権限レベル、条件などを修正する
6. 入力を保存する
7. システムがアクセス制御ポリシーを更新する
8. 更新完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **5b. 競合するポリシーが存在する場合**
  - 競合するポリシーがある場合、警告メッセージを表示する
  - ユーザーは競合を解決するか、上書きするかどうかを選択する

## 後置条件

- アクセス制御ポリシーがシステムに更新される
- 権限設定が反映される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-04 | アクセス制御ポリシー | 更新対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 適用対象、権限レベルは必須入力 |
| 2 | 権限の継承 | 組織階層に応じて権限が継承される |
| 3 | 競合解決 | 競合するポリシーが存在する場合、優先度が高い方が適用される |
