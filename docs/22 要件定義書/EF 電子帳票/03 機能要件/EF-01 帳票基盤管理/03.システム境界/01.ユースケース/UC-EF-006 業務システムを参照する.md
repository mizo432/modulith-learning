# UC-EF-006 業務システムを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-006 |
| ユースケース名 | 業務システムを参照する |
| 英語名 | View Business System |
| 説明 | システム管理者または業務システム担当者が登録された業務システム一覧・詳細を確認する |
| 関連アクター | ACT-EF-01（システム管理者）、ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-02 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者または業務システム担当者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「業務システム」タブを選択する
3. システムが登録された業務システム一覧を表示する
4. ユーザーが対象の業務システムを選択する
5. システムが業務システムの詳細情報を表示する

## 代替フロー

- **3a. 業務システムが登録されていない場合**
  - 「業務システムが登録されていません」というメッセージを表示する
  - ユーザーは業務システムを登録するか、他の操作を行う

## 後置条件

- 業務システム情報が表示される
