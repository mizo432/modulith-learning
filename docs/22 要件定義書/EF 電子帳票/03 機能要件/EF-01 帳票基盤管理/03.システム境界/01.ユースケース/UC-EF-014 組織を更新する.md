# UC-EF-014 組織を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-014 |
| ユースケース名 | 組織を更新する |
| 英語名 | Update Organization |
| 説明 | 組織管理者が既存の組織情報を修正する |
| 関連アクター | ACT-EF-02（組織管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-05 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが組織管理者の権限を持っていること
- 更新対象の組織が存在すること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「組織管理」タブを選択する
3. 更新対象の組織を選択する
4. 「組織を更新」ボタンをクリックする
5. 組織名、部門名、親組織などを修正する
6. 組織の担当者を修正する（任意）
7. 入力を保存する
8. システムが組織情報を更新する
9. 更新完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **5b. 重複した組織名の場合**
  - 同じ親組織配下に同じ組織名が存在する場合、エラーメッセージを表示する
  - ユーザーは別の組織名を入力して再試行する

## 後置条件

- 組織情報がシステムに更新される
- 組織階層が更新される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-05 | 組織情報 | 更新対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 組織名は必須入力 |
| 2 | 階層制限 | 組織の階層は最大5階層まで |
| 3 | 重複禁止 | 同じ親組織配下で同じ組織名は登録できない |
