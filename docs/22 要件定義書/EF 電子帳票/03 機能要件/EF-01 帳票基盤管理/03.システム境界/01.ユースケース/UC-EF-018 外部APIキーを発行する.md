# UC-EF-018 外部APIキーを発行する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-018 |
| ユースケース名 | 外部APIキーを発行する |
| 英語名 | Issue External API Key |
| 説明 | システム管理者が外部API利用のためのキーを発行する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-06 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「外部API管理」タブを選択する
3. 「APIキーを発行」ボタンをクリックする
4. キー名、有効期間、権限レベル（読み取り専用、読み書き、管理等）を入力する
5. 適用対象（業務システム、帳票種類など）を設定する（任意）
6. 入力を保存する
7. システムがAPIキーを発行する
8. 発行されたAPIキーとシークレットを表示する（初回のみ表示）
9. 発行完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- APIキーがシステムに登録される
- 発行されたAPIキーが利用可能になる

| 3 | 有効期間 | 有効期間が過ぎると自動的に無効化される |
