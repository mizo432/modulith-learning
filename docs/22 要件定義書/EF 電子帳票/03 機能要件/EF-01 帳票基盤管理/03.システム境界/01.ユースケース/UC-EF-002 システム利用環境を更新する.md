# UC-EF-002 システム利用環境を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-002 |
| ユースケース名 | システム利用環境を更新する |
| 英語名 | Update System Environment |
| 説明 | システム管理者が既存のシステム環境設定を修正する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-01 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること
- 更新対象のシステム利用環境が存在すること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「システム利用環境」タブを選択する
3. 更新対象の環境を選択する
4. 「環境を更新」ボタンをクリックする
5. 環境名、環境タイプ、接続情報などを修正する
6. 共通設定（タイムゾーン、言語、通貨など）を修正する
7. 入力を保存する
8. システムがシステム利用環境情報を更新する
9. 更新完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **5b. 重複した環境名の場合**
  - 他环境与同じ環境名に変更しようとした場合、エラーメッセージを表示する
  - ユーザーは別の環境名を入力して再試行する

## 後置条件

- システム利用環境情報がシステムに更新される
- 環境設定が反映される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-01 | システム利用環境情報 | 更新対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 環境名、環境タイプは必須入力 |
| 2 | 環境タイプの制限 | 本番、ステージング、開発のいずれかを選択 |
| 3 | 重複禁止 | 同じ環境名は登録できない |
