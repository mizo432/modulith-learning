# UC-EF-001 システム利用環境を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-001 |
| ユースケース名 | システム利用環境を登録する |
| 英語名 | Register System Environment |
| 説明 | システム管理者がシステム環境、共通設定、環境別接続情報を登録する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-01 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「システム利用環境」タブを選択する
3. 「環境を登録」ボタンをクリックする
4. 環境名、環境タイプ（本番/ステージング/開発）、接続情報を入力する
5. 共通設定（タイムゾーン、言語、通貨など）を入力する
6. 入力を保存する
7. システムがシステム利用環境情報を登録する
8. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **4b. 重複した環境名の場合**
  - 既に同じ環境名が存在する場合、エラーメッセージを表示する
  - ユーザーは別の環境名を入力して再試行する

## 後置条件

- システム利用環境情報がシステムに登録される
- 環境設定が反映される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-01 | システム利用環境情報 | 作成対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 環境名、環境タイプは必須入力 |
| 2 | 環境タイプの制限 | 本番、ステージング、開発のいずれかを選択 |
| 3 | 重複禁止 | 同じ環境名は登録できない |
