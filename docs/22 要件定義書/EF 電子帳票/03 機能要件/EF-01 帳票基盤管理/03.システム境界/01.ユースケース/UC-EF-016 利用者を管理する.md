# UC-EF-016 利用者を管理する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-016 |
| ユースケース名 | 利用者を管理する |
| 英語名 | Manage Users |
| 説明 | 組織管理者が利用者の登録・更新・参照を行う |
| 関連アクター | ACT-EF-02（組織管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-05 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが組織管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「利用者管理」タブを選択する
3. システムが登録された利用者一覧を表示する
4. ユーザーが「利用者を登録」ボタンをクリックするか、既存の利用者を選択する
5. 利用者名、メールアドレス、所属組織、ロールを入力する
6. 入力を保存する
7. システムが利用者情報を登録・更新する
8. 完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **5b. 重複したメールアドレスの場合**
  - 既に同じメールアドレスが存在する場合、エラーメッセージを表示する
  - ユーザーは別のメールアドレスを入力して再試行する

## 後置条件

- 利用者情報がシステムに登録・更新される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-06 | 利用者情報 | 作成・更新対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 利用者名、メールアドレス、所属組織は必須入力 |
| 2 | 重複禁止 | 同じメールアドレスは登録できない |
| 3 | 権限制限 | 組織管理者のみ利用者管理可能 |
