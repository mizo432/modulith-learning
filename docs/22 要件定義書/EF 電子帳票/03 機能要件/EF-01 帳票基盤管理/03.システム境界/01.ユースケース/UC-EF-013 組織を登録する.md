# UC-EF-013 組織を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-013 |
| ユースケース名 | 組織を登録する |
| 英語名 | Register Organization |
| 説明 | 組織管理者が組織、部門を階層構造で登録する |
| 関連アクター | ACT-EF-02（組織管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-05 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが組織管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「組織管理」タブを選択する
3. 「組織を登録」ボタンをクリックする
4. 組織名、部門名、親組織（任意）を入力する
5. 組織の担当者（任意）を設定する
6. 入力を保存する
7. システムが組織情報を登録する
8. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **4b. 重複した組織名の場合**
  - 同じ親組織配下に同じ組織名が存在する場合、エラーメッセージを表示する
  - ユーザーは別の組織名を入力して再試行する

## 後置条件

- 組織情報がシステムに登録される
- 組織階層が更新される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-05 | 組織情報 | 作成対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 組織名は必須入力 |
| 2 | 階層制限 | 組織の階層は最大5階層まで |
| 3 | 重複禁止 | 同じ親組織配下で同じ組織名は登録できない |
