# UC-EF-023 システム設定を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-023 |
| ユースケース名 | システム設定を参照する |
| 英語名 | View System Settings |
| 説明 | システム管理者が登録されたシステム設定を確認する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-07 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「システム設定」タブを選択する
3. システムが登録されたシステム設定一覧を表示する
4. ユーザーが対象の設定を選択する
5. システムが設定の詳細情報を表示する

## 代替フロー

- **3a. 設定が登録されていない場合**
  - 「設定が登録されていません」というメッセージを表示する
  - ユーザーは設定を登録するか、他の操作を行う

## 後置条件

- システム設定が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |

| INF-EF-09 | システム設定情報 | 参照対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |

| 2 | 権限制限 | システム管理者のみ参照可能 |
