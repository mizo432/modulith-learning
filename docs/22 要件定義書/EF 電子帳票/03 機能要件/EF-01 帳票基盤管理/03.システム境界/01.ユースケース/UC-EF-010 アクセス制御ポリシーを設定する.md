# UC-EF-010 アクセス制御ポリシーを設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-010 |
| ユースケース名 | アクセス制御ポリシーを設定する |
| 英語名 | Configure Access Control Policy |
| 説明 | システム管理者または運用管理者が組織・利用者・業務システム・帳票単位の権限ポリシーを設定する |
| 関連アクター | ACT-EF-01（システム管理者）、ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-04 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者または運用管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「アクセス制御」タブを選択する
3. 「ポリシーを設定」ボタンをクリックする
4. 適用対象（組織、利用者、業務システム、帳票種類）を選択する
5. 権限レベル（閲覧、編集、削除、管理）を設定する
6. 条件（期間、IPアドレス制限など）を設定する（任意）
7. 入力を保存する
8. システムがアクセス制御ポリシーを登録する
9. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **4b. 競合するポリシーが存在する場合**
  - 競合するポリシーがある場合、警告メッセージを表示する
  - ユーザーは競合を解決するか、上書きするかどうかを選択する

## 後置条件

- アクセス制御ポリシーがシステムに登録される
- 権限設定が反映される

| 情報ID | 情報名 | 使用目的 |

| INF-EF-04 | アクセス制御ポリシー | 作成対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 適用対象、権限レベルは必須入力 |
| 2 | 権限の継承 | 組織階層に応じて権限が継承される |
| 3 | 競合解決 | 競合するポリシーが存在する場合、優先度が高い方が適用される |
