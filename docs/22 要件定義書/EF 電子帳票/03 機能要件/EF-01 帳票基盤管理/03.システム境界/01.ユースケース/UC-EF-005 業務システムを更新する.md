# UC-EF-005 業務システムを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-005 |
| ユースケース名 | 業務システムを更新する |
| 英語名 | Update Business System |
| 説明 | システム管理者または業務システム担当者が既存の業務システム情報を修正する |
| 関連アクター | ACT-EF-01（システム管理者）、ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-02 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者または業務システム担当者の権限を持っていること
- 更新対象の業務システムが存在すること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「業務システム」タブを選択する
3. 更新対象の業務システムを選択する
4. 「業務システムを更新」ボタンをクリックする
5. システム名、システムタイプ、接続情報などを修正する
6. 連携設定（APIエンドポイント、認証情報など）を修正する
7. 入力を保存する
8. システムが業務システム情報を更新する
9. 更新完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 業務システム情報がシステムに更新される
- 連携設定が反映される

## 関連情報
