# UC-EF-012 アクセス制御ポリシーを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-012 |
| ユースケース名 | アクセス制御ポリシーを参照する |
| 英語名 | View Access Control Policy |
| 説明 | システム管理者または運用管理者が登録された権限ポリシーを確認する |
| 関連アクター | ACT-EF-01（システム管理者）、ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-04 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者または運用管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「アクセス制御」タブを選択する
3. システムが登録されたアクセス制御ポリシー一覧を表示する
4. ユーザーが対象のポリシーを選択する
5. システムがポリシーの詳細情報を表示する

## 代替フロー

- **3a. ポリシーが登録されていない場合**
  - 「ポリシーが登録されていません」というメッセージを表示する
  - ユーザーはポリシーを設定するか、他の操作を行う

## 後置条件

- アクセス制御ポリシーが表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-04 | アクセス制御ポリシー | 参照対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のあるポリシーのみ表示 |
| 2 | 権限制限 | システム管理者または運用管理者のみ参照可能 |
