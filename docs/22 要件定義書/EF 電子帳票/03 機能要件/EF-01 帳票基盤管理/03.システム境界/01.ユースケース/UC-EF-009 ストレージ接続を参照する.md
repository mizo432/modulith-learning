# UC-EF-009 ストレージ接続を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-009 |
| ユースケース名 | ストレージ接続を参照する |
| 英語名 | View Storage Connection |
| 説明 | システム管理者が登録されたストレージ接続情報を確認する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-03 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「ストレージ管理」タブを選択する
3. システムが登録されたストレージ接続一覧を表示する
4. ユーザーが対象のストレージ接続を選択する
5. システムがストレージ接続の詳細情報を表示する（アクセスキー、シークレットキーはマスク表示）

## 代替フロー

- **3a. ストレージ接続が登録されていない場合**
  - 「ストレージ接続が登録されていません」というメッセージを表示する
  - ユーザーはストレージ接続を設定するか、他の操作を行う

## 後置条件

- ストレージ接続情報が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-03 | ストレージ接続情報 | 参照対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | アクセスキー、シークレットキーはマスク表示 |
| 2 | 権限制限 | システム管理者のみ参照可能 |
