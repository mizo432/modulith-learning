# UC-EF-022 システム設定を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-022 |
| ユースケース名 | システム設定を更新する |
| 英語名 | Update System Settings |
| 説明 | システム管理者が既存のシステム設定を修正する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-07 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること
- 更新対象のシステム設定が存在すること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「システム設定」タブを選択する
3. 更新対象の設定を選択する
4. 「設定を更新」ボタンをクリックする
5. 設定値、説明などを修正する
6. 入力を保存する
7. システムがシステム設定を更新する
8. 更新完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- システム設定がシステムに更新される
- 設定が反映される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-09 | システム設定情報 | 更新対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 設定カテゴリ、設定項目、値は必須入力 |
| 2 | 権限制限 | システム管理者のみ設定更新可能 |
