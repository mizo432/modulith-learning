# UC-EF-004 業務システムを登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-004 |
| ユースケース名 | 業務システムを登録する |
| 英語名 | Register Business System |
| 説明 | システム管理者または業務システム担当者が連携する業務システムを登録する |
| 関連アクター | ACT-EF-01（システム管理者）、ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-02 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者または業務システム担当者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「業務システム」タブを選択する
3. 「業務システムを登録」ボタンをクリックする
4. システムID、システム名、システムタイプ、接続情報を入力する
5. 連携設定（APIエンドポイント、認証情報など）を入力する
6. 入力を保存する
7. システムが業務システム情報を登録する
8. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **4b. 重複したシステムIDの場合**
  - 既に同じシステムIDが存在する場合、エラーメッセージを表示する
  - ユーザーは別のシステムIDを入力して再試行する

## 後置条件

- 業務システム情報がシステムに登録される
- 連携設定が反映される

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | システムID、システム名は必須入力 |
| 2 | システムIDの形式 | 半角英数字とハイフンのみ使用可能 |
| 3 | 重複禁止 | 同じシステムIDは登録できない |
