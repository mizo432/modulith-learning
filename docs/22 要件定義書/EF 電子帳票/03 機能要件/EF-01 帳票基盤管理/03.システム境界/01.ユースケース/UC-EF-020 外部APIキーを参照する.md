# UC-EF-020 外部APIキーを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-020 |
| ユースケース名 | 外部APIキーを参照する |
| 英語名 | View External API Key |
| 説明 | システム管理者が登録されたAPIキー一覧・詳細を確認する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-06 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「外部API管理」タブを選択する
3. システムが登録されたAPIキー一覧を表示する
4. ユーザーが対象のAPIキーを選択する
5. システムがAPIキーの詳細情報を表示する（シークレットはマスク表示）

## 代替フロー

- **3a. APIキーが登録されていない場合**
  - 「APIキーが登録されていません」というメッセージを表示する
  - ユーザーはAPIキーを発行するか、他の操作を行う

## 後置条件

- APIキー情報が表示される
