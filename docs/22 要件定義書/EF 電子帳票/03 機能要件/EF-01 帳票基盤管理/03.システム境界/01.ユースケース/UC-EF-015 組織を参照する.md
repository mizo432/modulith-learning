# UC-EF-015 組織を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-015 |
| ユースケース名 | 組織を参照する |
| 英語名 | View Organization |
| 説明 | 組織管理者が登録された組織一覧・詳細を確認する |
| 関連アクター | ACT-EF-02（組織管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-05 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが組織管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「組織管理」タブを選択する
3. システムが登録された組織一覧を階層構造で表示する
4. ユーザーが対象の組織を選択する
5. システムが組織の詳細情報を表示する

## 代替フロー

- **3a. 組織が登録されていない場合**
  - 「組織が登録されていません」というメッセージを表示する
  - ユーザーは組織を登録するか、他の操作を行う

## 後置条件

- 組織情報が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-05 | 組織情報 | 参照対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある組織のみ表示 |
| 2 | 権限制限 | 組織管理者のみ参照可能 |
