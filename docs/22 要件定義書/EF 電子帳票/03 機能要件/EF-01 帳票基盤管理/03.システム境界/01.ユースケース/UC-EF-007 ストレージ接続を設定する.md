# UC-EF-007 ストレージ接続を設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-007 |
| ユースケース名 | ストレージ接続を設定する |
| 英語名 | Configure Storage Connection |
| 説明 | システム管理者がS3・MinIOの接続情報を設定する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-03 |
| 外部システム | ES-EF-01（Amazon S3）、ES-EF-02（MinIO） |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「ストレージ管理」タブを選択する
3. 「ストレージ接続を設定」ボタンをクリックする
4. ストレージタイプ（S3/MinIO）を選択する
5. エンドポイント、アクセスキー、シークレットキー、バケット名を入力する
6. 接続テストを実行する
7. 入力を保存する
8. システムがストレージ接続情報を登録する
9. 登録完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **6a. 接続テストに失敗した場合**
  - エラーメッセージを表示する
  - ユーザーは接続情報を修正して再試行する

## 後置条件

- ストレージ接続情報がシステムに登録される
- ストレージへの接続が確立される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-03 | ストレージ接続情報 | 作成対象の情報 |

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | ストレージタイプ、エンドポイント、アクセスキー、シークレットキー、バケット名は必須入力 |
| 2 | 接続テスト | 保存前に接続テストが成功していること |
