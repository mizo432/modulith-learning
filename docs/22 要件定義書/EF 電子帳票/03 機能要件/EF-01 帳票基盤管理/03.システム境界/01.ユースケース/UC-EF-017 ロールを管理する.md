# UC-EF-017 ロールを管理する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-017 |
| ユースケース名 | ロールを管理する |
| 英語名 | Manage Roles |
| 説明 | 組織管理者がロールの定義と利用者への割り当てを管理する |
| 関連アクター | ACT-EF-02（組織管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-05 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが組織管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「ロール管理」タブを選択する
3. システムが登録されたロール一覧を表示する
4. ユーザーが「ロールを登録」ボタンをクリックするか、既存のロールを選択する
5. ロール名、説明、権限（機能ごとのアクセス権）を入力する
6. 利用者にロールを割り当てる（任意）
7. 入力を保存する
8. システムがロール情報を登録・更新する
9. 完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **5b. 重複したロール名の場合**
  - 既に同じロール名が存在する場合、エラーメッセージを表示する
  - ユーザーは別のロール名を入力して再試行する

## 後置条件

- ロール情報がシステムに登録・更新される
- 利用者へのロール割り当てが反映される

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | ロール名、権限は必須入力 |
| 2 | 重複禁止 | 同じロール名は登録できない |
| 3 | 権限制限 | 組織管理者のみロール管理可能 |
