# EF-01 帳票基盤管理

## 概要

本ドキュメントは、帳票基盤管理業務領域（EF-01）の機能要件を定義します。

システム環境、業務システム、ストレージ、アクセス制御、組織・利用者、外部API、システム設定の管理を行い、電子帳票基盤の運用基盤を提供します。

## 含まれるFeature

| ID  | Feature名       | 概要                           |
|-----|----------------|-------------------------------|
| F01 | システム利用環境管理  | システム環境、共通設定、環境別接続情報の管理       |
| F02 | 業務システム管理    | 連携する業務システムの登録・管理             |
| F12 | ストレージ管理     | S3・MinIOによるファイル保存・取得         |
| F13 | アクセス制御      | 組織・利用者・業務システム・帳票単位の権限制御      |
| F15 | 外部API管理     | API認証、利用制限、API公開管理           |
| F17 | 組織・利用者管理    | 組織、部門、利用者、ロールの管理             |
| F20 | システム設定管理    | 共通設定、環境設定、各種マスタ管理            |
