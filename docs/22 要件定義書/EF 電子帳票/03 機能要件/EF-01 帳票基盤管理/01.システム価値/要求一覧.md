# 要求一覧

帳票基盤管理業務領域（EF-01）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-EF-01 | システム利用環境管理         | システム環境、共通設定、環境別接続情報を管理する           | MVP    |
| FR-EF-02 | 業務システム管理             | 連携する業務システムの登録・更新・参照する                 | MVP    |
| FR-EF-03 | ストレージ管理               | S3・MinIOによるファイル保存・取得を管理する               | MVP    |
| FR-EF-04 | アクセス制御                 | 組織・利用者・業務システム・帳票単位の権限を制御する       | MVP    |
| FR-EF-05 | 外部API管理                 | API認証、利用制限、API公開を管理する                     | MVP    |
| FR-EF-06 | 組織管理                    | 組織、部門の階層構造を管理する                           | MVP    |
| FR-EF-07 | 利用者管理                  | 利用者の登録・更新・参照する                             | MVP    |
| FR-EF-08 | ロール管理                  | ロールの定義と利用者への割り当てを管理する               | MVP    |
| FR-EF-09 | システム設定管理            | 共通設定、環境設定、各種マスタを管理する                 | MVP    |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-EF-01 | アクセス制御の完全性           | 不正アクセスを防止する                 |
| NFR-EF-02 | 設定変更の監査証跡             | 変更履歴を追跡できる                   |
| NFR-EF-03 | 業務システム間のデータ分離     | system_id による識別・検索制御         |
