# アクター一覧

帳票基盤管理業務領域（EF-01）でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                 |
|--------|--------------------------|------------------------------------------------------|
| ACT-EF-01 | システム管理者         | システム環境、ストレージ、外部API、システム設定を管理   |
| ACT-EF-02 | 組織管理者             | 組織、部門、利用者、ロールを管理                     |
| ACT-EF-03 | 業務システム担当者     | 連携する業務システムの登録・管理を行う               |
| ACT-EF-04 | 運用管理者             | アクセス制御ポリシーを設定・監視する                 |
