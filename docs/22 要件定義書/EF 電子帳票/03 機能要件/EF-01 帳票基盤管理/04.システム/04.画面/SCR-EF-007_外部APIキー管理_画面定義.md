# 外部APIキー管理

外部APIキー管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-007 |
| 画面名           | 外部APIキー管理 |
| 説明             | 外部システム連携用のAPIキーを管理する |
| 関連ユースケース | UC-EF-020, UC-EF-021 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | APIキー名、検索バーを表示 |
| メインコンテンツ | 外部APIキーの一覧をテーブル表示 |
| サイドバー | APIキー統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | APIキーID | テキスト | はい | 外部APIキーの識別子 |
| 2 | システムID | テキスト | はい | 関連する業務システムの識別子 |
| 3 | APIキー名 | テキスト | はい | APIキー名 |
| 4 | 有効期限 | 日付 | いいえ | 有効期限 |
| 5 | 最終利用日時 | 日付 | いいえ | 最終利用日時 |
| 6 | 状態 | 選択 | はい | 状態（有効、無効） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | APIキーを発行 | 新しい外部APIキーを発行する |
| 2 | APIキーを無効化 | 外部APIキーを無効化する |
| 3 | APIキーを参照 | 登録されたAPIキーの詳細を確認する |
| 4 | APIキーを検索 | 条件に合致するAPIキーを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | APIキー管理はシステム管理者のみ可能 |
| 2 | 参照権限 | APIキー参照はシステム管理者のみ |
