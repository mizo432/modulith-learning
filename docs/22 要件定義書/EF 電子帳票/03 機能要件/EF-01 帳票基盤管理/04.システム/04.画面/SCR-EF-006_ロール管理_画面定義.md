# ロール管理

ロール管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-006 |
| 画面名           | ロール管理 |
| 説明             | システム内の権限ロールを管理する |
| 関連ユースケース | UC-EF-018 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | ロール名、検索バーを表示 |
| メインコンテンツ | ロールの一覧をテーブル表示 |
| サイドバー | 権限統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ロールID | テキスト | はい | ロールの識別子 |
| 2 | ロール名 | テキスト | はい | ロール名 |
| 3 | ロール種類 | 選択 | はい | ロール種類（管理者、利用者、閲覧者等） |
| 4 | 権限セット | テキスト | はい | 権限セット（JSON形式） |
| 5 | 状態 | 選択 | はい | 状態（有効、無効） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ロールを変更 | ロール定義を変更する |
| 2 | ロールを参照 | 登録されたロールの詳細を確認する |
| 3 | ロールを検索 | 条件に合致するロールを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ロール変更はシステム管理者のみ可能 |
| 2 | 参照権限 | ロール参照は全利用者 |
