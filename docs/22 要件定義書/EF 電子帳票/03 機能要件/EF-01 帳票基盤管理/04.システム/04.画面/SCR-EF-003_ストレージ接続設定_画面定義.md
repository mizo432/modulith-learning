# ストレージ接続設定

ストレージ接続設定画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-003 |
| 画面名           | ストレージ接続設定 |
| 説明             | 外部ストレージの接続設定を確認・管理する |
| 関連ユースケース | UC-EF-007, UC-EF-008 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | ストレージ名、検索バーを表示 |
| メインコンテンツ | ストレージ接続設定の一覧をテーブル表示 |
| サイドバー | ストレージ統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ストレージID | テキスト | はい | ストレージ接続の識別子 |
| 2 | ストレージ名 | テキスト | はい | ストレージ名 |
| 3 | ストレージ種類 | 選択 | はい | ストレージ種類（Amazon S3、MinIO等） |
| 4 | エンドポイントURL | テキスト | はい | エンドポイントURL |
| 5 | バケット名 | テキスト | はい | バケット名 |
| 6 | 状態 | 選択 | はい | 状態（有効、無効） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ストレージを設定 | 新しいストレージ接続を設定する |
| 2 | ストレージを更新 | 既存のストレージ設定を更新する |
| 3 | ストレージを参照 | 登録されたストレージの詳細を確認する |
| 4 | 接続テスト | ストレージ接続を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | ストレージ設定の編集はシステム管理者のみ可能 |
| 2 | 参照権限 | ストレージ設定の参照はシステム管理者のみ |
