# システム設定

システム設定画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-008 |
| 画面名           | システム設定 |
| 説明             | システム全体の各種設定を管理する |
| 関連ユースケース | UC-EF-023 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 設定名、検索バーを表示 |
| メインコンテンツ | システム設定の一覧をテーブル表示 |
| サイドバー | カテゴリ別統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 設定ID | テキスト | はい | システム設定の識別子 |
| 2 | 設定キー | テキスト | はい | 設定キー |
| 3 | 設定値 | テキスト | はい | 設定値 |
| 4 | カテゴリ | 選択 | はい | カテゴリ（保存期間、通知、セキュリティ等） |
| 5 | データ型 | 選択 | はい | データ型（String、Integer、Boolean等） |
| 6 | 状態 | 選択 | はい | 状態（有効、無効） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 設定を変更 | システム設定を変更する |
| 2 | 設定を参照 | 登録された設定の詳細を確認する |
| 3 | 設定を検索 | 条件に合致する設定を検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | システム設定の変更はシステム管理者のみ可能 |
| 2 | 参照権限 | システム設定の参照は全利用者 |
