# 組織・利用者管理

組織・利用者管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-005 |
| 画面名           | 組織・利用者管理 |
| 説明             | 組織・部署・利用者の情報を管理する |
| 関連ユースケース | UC-EF-012, UC-EF-013, UC-EF-015, UC-EF-016 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 組織名、検索バーを表示 |
| メインコンテンツ | 組織・利用者の一覧をタブ表示 |
| サイドバー | 組織階層図を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 組織ID | テキスト | はい | 組織の識別子 |
| 2 | 組織名 | テキスト | はい | 組織名 |
| 3 | 親組織ID | テキスト | いいえ | 親組織の識別子 |
| 4 | 利用者ID | テキスト | はい | 利用者の識別子 |
| 5 | ログインID | テキスト | はい | ログインID |
| 6 | 氏名 | テキスト | はい | 氏名 |
| 7 | メールアドレス | テキスト | いいえ | メールアドレス |
| 8 | 状態 | 選択 | はい | 状態（有効、無効、ロック） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 組織を登録 | 新しい組織を登録する |
| 2 | 組織を更新 | 既存の組織情報を更新する |
| 3 | 利用者を登録 | 新しい利用者を登録する |
| 4 | 利用者を更新 | 既存の利用者情報を更新する |
| 5 | 利用者を検索 | 条件に合致する利用者を検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 組織・利用者管理はシステム管理者のみ可能 |
| 2 | 参照権限 | 組織・利用者参照は全利用者 |
