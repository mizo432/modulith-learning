# 論理データモデル

## 概要

EF-01 帳票基盤管理業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    FORM_DEFINITION
    {
        string FORM_DEFINITION_ID PK "帳票定義ID"
        string 種類 "種類"
        string レイアウト "レイアウト"
        string テンプレート "テンプレート"
        string 状態 "状態"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(帳票定義)"
        enum variation "バリエーション(帳票種類)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| 帳票定義 | FORM_DEFINITION_ID | string | true | 帳票定義ID |
