# EVT-EF-15 システム設定が変更された

## 概要

システム設定が変更されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-15                                                          |
| イベント名       | システム設定が変更された                                           |
| 英語名           | `SystemSettingChanged`                                             |
| 集約             | システム設定 (SystemSetting)                                       |
| 関連ユースケース | UC-EF-023 システム設定を変更する                                   |
| 関連情報         | INF-EF-09 システム設定                                             |
| 発生条件         | 管理者がシステム設定を変更したとき                                 |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "SystemSetting"                          |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `settingId`       | String         | ✓   | システム設定の一意な識別子               |
| `settingKey`      | String         | ✓   | 設定キー                                 |
| `category`        | String         | ✓   | カテゴリ                                 |
| `changedBy`       | String         | ✓   | 変更者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-01 システム利用環境が登録された | 関連する環境登録時に発生     |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formFoundation.spi.systemSetting.event.SystemSettingChanged`
