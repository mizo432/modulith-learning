# EVT-EF-11 利用者が更新された

## 概要

利用者情報が更新されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-11                                                          |
| イベント名       | 利用者が更新された                                                 |
| 英語名           | `UserUpdated`                                                      |
| 集約             | 利用者 (User)                                                      |
| 関連ユースケース | UC-EF-016 利用者を更新する                                         |
| 関連情報         | INF-EF-06 利用者                                                   |
| 発生条件         | 管理者が利用者情報を更新したとき                                   |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "User"                                   |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `userId`          | String         | ✓   | 利用者の一意な識別子                     |
| `userName`        | String         | ✗   | 氏名                                     |
| `orgId`           | String         | ✗   | 所属組織の識別子                         |
| `updatedBy`       | String         | ✓   | 更新者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-10 利用者が登録された     | 登録時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formFoundation.spi.user.event.UserUpdated`
