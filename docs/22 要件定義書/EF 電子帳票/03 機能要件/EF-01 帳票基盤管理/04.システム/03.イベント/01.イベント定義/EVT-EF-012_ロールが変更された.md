# EVT-EF-12 ロールが変更された

## 概要

ロール定義が変更されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-12                                                          |
| イベント名       | ロールが変更された                                                 |
| 英語名           | `RoleChanged`                                                      |
| 集約             | ロール (Role)                                                      |
| 関連ユースケース | UC-EF-018 ロールを変更する                                         |
| 関連情報         | INF-EF-07 ロール                                                   |
| 発生条件         | 管理者がロール定義を変更したとき                                   |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "Role"                                   |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `roleId`          | String         | ✓   | ロールの一意な識別子                     |
| `roleName`        | String         | ✓   | ロール名                                 |
| `roleType`        | String         | ✓   | ロール種類                               |
| `changedBy`       | String         | ✓   | 変更者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-10 利用者が登録された     | 関連する利用者登録時に発生   |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formFoundation.spi.role.event.RoleChanged`
