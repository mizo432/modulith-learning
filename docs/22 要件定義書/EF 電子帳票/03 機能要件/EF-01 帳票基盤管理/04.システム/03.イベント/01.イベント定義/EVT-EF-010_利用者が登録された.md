# EVT-EF-10 利用者が登録された

## 概要

利用者が新規登録されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-10                                                          |
| イベント名       | 利用者が登録された                                                 |
| 英語名           | `UserRegistered`                                                   |
| 集約             | 利用者 (User)                                                      |
| 関連ユースケース | UC-EF-015 利用者を登録する                                         |
| 関連情報         | INF-EF-06 利用者                                                   |
| 発生条件         | 管理者が利用者を新規登録したとき                                   |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "User"                                   |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `userId`          | String         | ✓   | 利用者の一意な識別子                     |
| `loginId`         | String         | ✓   | ログインID                               |
| `userName`        | String         | ✓   | 氏名                                     |
| `orgId`           | String         | ✗   | 所属組織の識別子                         |
| `registeredBy`    | String         | ✓   | 登録者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-11 利用者が更新された     | 更新時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formFoundation.spi.user.event.UserRegistered`
