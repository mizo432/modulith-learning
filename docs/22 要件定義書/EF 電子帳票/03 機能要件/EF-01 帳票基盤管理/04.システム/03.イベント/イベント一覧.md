## イベント種類

| 種類 | 説明 |
|------|------|
| ドメインイベント | ドメイン内の重要な状態変化を通知するイベント |
| 統合イベント | モジュール間で情報を共有するイベント |

## 集約一覧

| 集約 | 説明 |
|------|------|
| SystemEnvironment | システム利用環境の集約ルート |
| BusinessSystem | 業務システムの集約ルート |
| StorageConnection | ストレージ接続の集約ルート |
| AccessControlPolicy | アクセス制御ポリシーの集約ルート |
| Organization | 組織の集約ルート |
| User | 利用者の集約ルート |
| Role | ロールの集約ルート |
| ExternalApiKey | 外部APIキーの集約ルート |
| SystemSetting | システム設定の集約ルート |
