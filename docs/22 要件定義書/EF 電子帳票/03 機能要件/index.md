# EF 電子帳票 機能要件

## 概要

本ドキュメントは、電子帳票（EF）の機能要件を定義します。

シングルテナント構成で、1企業・組織が複数の業務システムから共通利用する電子帳票基盤です。

## 業務領域一覧

| 番号 | 業務領域コード | 業務領域名 | 説明 |
|------|----------------|------------|------|
| 01 | EF-01 | [帳票基盤管理](EF-01%20帳票基盤管理/index.md) | システム環境、業務システム、ストレージ、アクセス制御、組織・利用者、外部API、システム設定の管理 |
| 02 | EF-02 | [帳票管理](EF-02%20帳票管理/index.md) | 帳票定義、帳票生成、帳票登録・取込、帳票情報・バージョン・状態の管理 |
| 03 | EF-03 | [帳票利用](EF-03%20帳票利用/index.md) | 帳票配信、閲覧・プレビュー、検索、承認・確認 |
| 04 | EF-04 | [保管・アーカイブ](EF-04%20保管・アーカイブ/index.md) | 帳票保管・廃棄、アーカイブポリシー・対象・処理・復元管理 |
| 05 | EF-05 | [運用・監査](EF-05%20運用・監査/index.md) | 通知管理、監査・証跡、運用管理、帳票分析・統計、アーカイブ運用管理 |
