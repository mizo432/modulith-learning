# EF-05 運用・監査

## 概要

本ドキュメントは、運用・監査業務領域（EF-05）の機能要件を定義します。

通知管理、監査・証跡、運用管理、帳票分析・統計、アーカイブ運用管理を行い、システムの適切な運用と監査証跡の確保を実現します。

## 含まれるFeature

| ID  | Feature名       | 概要                           |
|-----|----------------|-------------------------------|
| F14 | 通知管理        | メール、システム内通知、Webhook通知        |
| F16 | 監査・証跡管理     | 操作履歴、閲覧履歴、ダウンロード履歴           |
| F18 | 運用管理        | 処理監視、エラー管理、再処理               |
| F19 | 帳票分析・統計     | 帳票件数、配信状況、利用状況の分析            |
| F25 | アーカイブ運用管理   | アーカイブ・復元の監視、エラー確認、再実行        |
