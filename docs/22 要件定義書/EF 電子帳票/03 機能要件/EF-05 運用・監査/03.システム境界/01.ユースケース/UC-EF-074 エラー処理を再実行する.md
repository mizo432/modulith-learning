# UC-EF-074 エラー処理を再実行する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-074 |
| ユースケース名 | エラー処理を再実行する |
| 英語名 | Retry Error Process |
| 説明 | 運用管理者が失敗した処理を再実行する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-23 |
| 外部システム | - |
| 関連画面 | SCR-014（運用エラー一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること
- 再実行対象のエラーが存在すること

## 基本フロー

1. ユーザーが「運用エラー一覧」画面（SCR-014）にアクセスする
2. 再実行対象のエラーを選択する
3. 「再実行」ボタンをクリックする
4. 再実行確認ダイアログを表示する
5. ユーザーが確認する
6. システムが処理を再実行する
7. 再実行結果を表示する

## 代替フロー

- **2a. エラーが存在しない場合**
  - 「エラーがありません」というメッセージを表示する
  - ユーザーは他の操作を行う

- **4a. 再実行をキャンセルした場合**
  - ユーザーがキャンセルを選択する
  - ユースケースを終了する

- **6a. 再実行に失敗した場合**
  - エラーメッセージを表示する
  - ユーザーは再実行するか、他の操作を行う

## 後置条件

- 処理が再実行される
- 再実行結果が記録される
