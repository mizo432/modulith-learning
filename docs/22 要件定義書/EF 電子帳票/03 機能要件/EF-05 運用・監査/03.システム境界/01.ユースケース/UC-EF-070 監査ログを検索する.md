# UC-EF-070 監査ログを検索する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-070 |
| ユースケース名 | 監査ログを検索する |
| 英語名 | Search Audit Logs |
| 説明 | 監査担当者が利用者、操作種別、日時などの条件で監査ログを検索する |
| 関連アクター | ACT-EF-08（監査担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-22 |
| 外部システム | - |
| 関連画面 | SCR-015（監査ログ一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが監査担当者の権限を持っていること

## 基本フロー

1. ユーザーが「監査ログ一覧」画面（SCR-015）にアクセスする
2. 検索条件（利用者、操作種別、日時など）を入力する
3. 「検索」ボタンをクリックする
4. システムが条件に一致する監査ログを検索する
5. 検索結果一覧を表示する

## 代替フロー

- **2a. 検索条件が入力されていない場合**
  - 全監査ログを表示するか、エラーメッセージを表示する
  - ユーザーは検索条件を入力して再試行する

- **4a. 検索結果がない場合**
  - 「検索結果がありません」というメッセージを表示する
  - ユーザーは別の条件で検索するか、他の操作を行う

## 後置条件

- 検索結果が表示される
