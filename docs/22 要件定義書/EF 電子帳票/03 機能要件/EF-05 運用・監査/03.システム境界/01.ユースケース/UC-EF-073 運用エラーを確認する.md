# UC-EF-073 運用エラーを確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-073 |
| ユースケース名 | 運用エラーを確認する |
| 英語名 | View Operational Errors |
| 説明 | 運用管理者が発生したエラーの内容・回数を確認する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-23 |
| 外部システム | - |
| 関連画面 | SCR-014（運用エラー一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること

## 基本フロー

1. ユーザーが「運用エラー一覧」画面（SCR-014）にアクセスする
2. システムが発生したエラー一覧を表示する
3. ユーザーが対象のエラーを選択する
4. システムがエラーの詳細情報を表示する

## 代替フロー

- **2a. エラーが存在しない場合**
  - 「エラーがありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 運用エラーが表示される

| 2 | 権限制限 | 運用管理者のみ参照可能 |
