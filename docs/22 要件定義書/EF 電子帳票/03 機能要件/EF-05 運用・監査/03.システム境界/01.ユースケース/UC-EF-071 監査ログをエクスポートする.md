# UC-EF-071 監査ログをエクスポートする

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-071 |
| ユースケース名 | 監査ログをエクスポートする |
| 英語名 | Export Audit Logs |
| 説明 | 監査担当者が監査ログをエクスポートする |
| 関連アクター | ACT-EF-08（監査担当者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-EF-22 |
| 外部システム | - |
| 関連画面 | SCR-015（監査ログ一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが監査担当者の権限を持っていること

## 基本フロー

1. ユーザーが「監査ログ一覧」画面（SCR-015）にアクセスする
2. エクスポート対象の監査ログを選択する
3. 「エクスポート」ボタンをクリックする
4. エクスポート形式（CSV、Excelなど）を選択する
5. システムが監査ログをエクスポートする
6. エクスポート完了メッセージを表示する

## 代替フロー

- **2a. 監査ログが存在しない場合**
  - 「監査ログがありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 監査ログがエクスポートされる
