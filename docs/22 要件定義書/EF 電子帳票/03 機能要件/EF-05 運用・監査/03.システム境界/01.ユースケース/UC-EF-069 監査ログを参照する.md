# UC-EF-069 監査ログを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-069 |
| ユースケース名 | 監査ログを参照する |
| 英語名 | View Audit Logs |
| 説明 | 監査担当者が操作履歴、閲覧履歴、ダウンロード履歴を確認する |
| 関連アクター | ACT-EF-08（監査担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-22 |
| 外部システム | - |
| 関連画面 | SCR-015（監査ログ一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが監査担当者の権限を持っていること

## 基本フロー

1. ユーザーが「監査ログ一覧」画面（SCR-015）にアクセスする
2. システムが監査ログ一覧を表示する
3. ユーザーが対象のログを選択する
4. システムがログの詳細情報を表示する

## 代替フロー

- **2a. 監査ログが存在しない場合**
  - 「監査ログがありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 監査ログが表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-15 | 監査ログ | 参照対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のあるログのみ表示 |
| 2 | 権限制限 | 監査担当者のみ参照可能 |
