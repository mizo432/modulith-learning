# UC-EF-066 通知設定を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-066 |
| ユースケース名 | 通知設定を登録する |
| 英語名 | Register Notification Settings |
| 説明 | システム管理者がメール、システム内通知、Webhook通知の設定を登録する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-21 |
| 外部システム | - |
| 関連画面 | SCR-009（組織・利用者管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「組織・利用者管理」画面（SCR-009）にアクセスする
2. 「通知設定」タブを選択する
3. 「通知設定を登録」ボタンをクリックする
4. 通知タイプ（メール、システム内通知、Webhook）を選択する
5. 通知条件、送信先、メッセージテンプレートを入力する
6. 入力を保存する
7. システムが通知設定を登録する
8. 登録完了メッセージを表示する

## 代替フロー

- **5a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 通知設定がシステムに登録される
