# UC-EF-076 帳票分析レポートを生成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-076 |
| ユースケース名 | 帳票分析レポートを生成する |
| 英語名 | Generate Form Analytics Report |
| 説明 | 分析担当者が集計期間を指定して分析レポートを生成する |
| 関連アクター | ACT-EF-09（分析担当者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-EF-24 |
| 外部システム | - |
| 関連画面 | SCR-016（帳票分析ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが分析担当者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票分析ダッシュボード」画面（SCR-016）にアクセスする
2. 「レポートを生成」ボタンをクリックする
3. 集計期間、レポートタイプなどを指定する
4. 「生成」ボタンをクリックする
5. システムが分析レポートを生成する
6. レポートを表示またはダウンロードする

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 分析レポートが生成される
