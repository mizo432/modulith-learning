# UC-EF-079 アーカイブエラーを確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-079 |
| ユースケース名 | アーカイブエラーを確認する |
| 英語名 | View Archive Errors |
| 説明 | 運用管理者がアーカイブ・復元処理で発生したエラーを確認する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-25 |
| 外部システム | - |
| 関連画面 | SCR-014（運用エラー一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること

## 基本フロー

1. ユーザーが「運用エラー一覧」画面（SCR-014）にアクセスする
2. 「アーカイブエラー」タブを選択する
3. システムがアーカイブ・復元処理で発生したエラー一覧を表示する
4. ユーザーが対象のエラーを選択する
5. システムがエラーの詳細情報を表示する

## 代替フロー

- **3a. エラーが存在しない場合**
  - 「エラーがありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- アーカイブエラーが表示される
