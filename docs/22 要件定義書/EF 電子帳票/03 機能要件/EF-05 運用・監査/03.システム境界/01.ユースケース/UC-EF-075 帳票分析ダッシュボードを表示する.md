# UC-EF-075 帳票分析ダッシュボードを表示する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-075 |
| ユースケース名 | 帳票分析ダッシュボードを表示する |
| 英語名 | Display Form Analytics Dashboard |
| 説明 | 分析担当者が帳票件数、配信状況、利用状況の統計を表示する |
| 関連アクター | ACT-EF-09（分析担当者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-EF-24 |
| 外部システム | - |
| 関連画面 | SCR-016（帳票分析ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが分析担当者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票分析ダッシュボード」画面（SCR-016）にアクセスする
2. システムが帳票件数、配信状況、利用状況の統計を表示する
3. ユーザーが統計データを確認する

## 代替フロー

- **2a. 統計データが存在しない場合**
  - 「統計データがありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 帳票分析ダッシュボードが表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-18 | 帳票分析データ | 表示対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限制限 | 分析担当者のみ参照可能 |
