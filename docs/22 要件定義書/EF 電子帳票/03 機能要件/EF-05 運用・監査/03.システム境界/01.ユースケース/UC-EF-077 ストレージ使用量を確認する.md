# UC-EF-077 ストレージ使用量を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-077 |
| ユースケース名 | ストレージ使用量を確認する |
| 英語名 | View Storage Usage |
| 説明 | 分析担当者が通常・アーカイブ・プレビューのストレージ使用量を確認する |
| 関連アクター | ACT-EF-09（分析担当者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-EF-24 |
| 外部システム | - |
| 関連画面 | SCR-016（帳票分析ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが分析担当者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票分析ダッシュボード」画面（SCR-016）にアクセスする
2. 「ストレージ使用量」タブを選択する
3. システムが通常・アーカイブ・プレビューのストレージ使用量を表示する
4. ユーザーがストレージ使用量を確認する

## 代替フロー

- **3a. ストレージ使用量データが存在しない場合**
  - 「ストレージ使用量データがありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- ストレージ使用量が表示される
