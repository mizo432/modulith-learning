# UC-EF-078 アーカイブ処理を監視する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-078 |
| ユースケース名 | アーカイブ処理を監視する |
| 英語名 | Monitor Archive Process |
| 説明 | 運用管理者がアーカイブ・復元処理の進捗・状態を監視する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-25 |
| 外部システム | - |
| 関連画面 | SCR-010（アーカイブ管理ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること

## 基本フロー

1. ユーザーが「アーカイブ管理ダッシュボード」画面（SCR-010）にアクセスする
2. 「アーカイブ監視」タブを選択する
3. システムがアーカイブ・復元処理の進捗・状態を表示する
4. ユーザーが対象の処理を選択する
5. システムが処理の詳細情報を表示する

## 代替フロー

- **3a. 処理履歴がない場合**
  - 「処理履歴がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- アーカイブ処理状況が表示される
