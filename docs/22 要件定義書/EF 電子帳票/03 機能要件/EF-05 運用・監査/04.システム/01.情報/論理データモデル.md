# 論理データモデル

## 概要

EF-05 運用・監査業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    AUDIT_LOG
    {
        string AUDIT_LOG_ID PK "監査ログID"
        string 操作者 "操作者"
        string 日時 "日時"
        string 操作内容 "操作内容"
        string 対象 "対象"
        string 作成日 "作成日"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| 監査ログ | AUDIT_LOG_ID | string | true | 監査ログID |
