# アーカイブ運用監視

アーカイブ運用監視画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-030 |
| 画面名           | アーカイブ運用監視 |
| 説明             | アーカイブ運用の状況を確認・監視する |
| 関連ユースケース | UC-EF-075 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 運用名、検索バーを表示 |
| メインコンテンツ | アーカイブ運用の一覧をテーブル表示 |
| サイドバー | 運用統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 運用ID | テキスト | はい | アーカイブ運用の識別子 |
| 2 | 運用種類 | 選択 | はい | 運用種類（アーカイブ監視、復元監視等） |
| 3 | 運用名 | テキスト | はい | 運用名 |
| 4 | 状態 | 選択 | はい | 状態（正常、警告、エラー等） |
| 5 | アーカイブ件数 | 数値 | いいえ | アーカイブ件数 |
| 6 | 復元件数 | 数値 | いいえ | 復元件数 |
| 7 | エラーメッセージ | テキスト | いいえ | エラーメッセージ |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 運用状況を確認 | アーカイブ運用の状況を確認する |
| 2 | 運用エラーを解決 | 運用エラーを解決する |
| 3 | 運用を検索 | 条件に合致する運用を検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 運用管理はシステム管理者のみ可能 |
| 2 | 参照権限 | 運用状況の参照は全利用者 |
