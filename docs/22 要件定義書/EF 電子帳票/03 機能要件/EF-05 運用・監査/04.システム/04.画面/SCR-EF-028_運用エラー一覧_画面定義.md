# 運用エラー一覧

運用エラー一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-028 |
| 画面名           | 運用エラー一覧 |
| 説明             | 運用エラーの一覧を確認・対応する |
| 関連ユースケース | UC-EF-070, UC-EF-071 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | エラー名、検索バーを表示 |
| メインコンテンツ | 運用エラーの一覧をテーブル表示 |
| サイドバー | エラー統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 運用ID | テキスト | はい | 運用管理の識別子 |
| 2 | 運用種類 | 選択 | はい | 運用種類（システム監視、エラー処理等） |
| 3 | 運用名 | テキスト | はい | 運用名 |
| 4 | 状態 | 選択 | はい | 状態（正常、警告、エラー等） |
| 5 | エラーメッセージ | テキスト | いいえ | エラーメッセージ |
| 6 | 解決者 | テキスト | いいえ | 解決者の利用者ID |
| 7 | 解決日時 | 日付 | いいえ | 解決日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 運用エラーを解決 | 運用エラーを解決する |
| 2 | 運用エラーを参照 | 登録されたエラーの詳細を確認する |
| 3 | 運用エラーを検索 | 条件に合致するエラーを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 運用エラーの解決はシステム管理者のみ可能 |
| 2 | 参照権限 | 運用エラーの参照は全利用者 |
