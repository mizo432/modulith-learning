# 監査ログ一覧

監査ログ一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-027 |
| 画面名           | 監査ログ一覧 |
| 説明             | システム操作の監査ログを確認する |
| 関連ユースケース | UC-EF-068 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 操作者、検索バーを表示 |
| メインコンテンツ | 監査ログの一覧をテーブル表示 |
| サイドバー | 監査統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 監査ログID | テキスト | はい | 監査ログの識別子 |
| 2 | 操作者 | テキスト | はい | 操作者の利用者ID |
| 3 | 操作種類 | 選択 | はい | 操作種類（作成、更新、削除、閲覧等） |
| 4 | 操作対象種類 | 選択 | はい | 操作対象種類（帳票、設定等） |
| 5 | 操作対象ID | テキスト | はい | 操作対象の識別子 |
| 6 | IPアドレス | テキスト | いいえ | 操作元のIPアドレス |
| 7 | 操作日時 | 日付 | はい | 操作実行日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 監査ログを参照 | 登録された監査ログの詳細を確認する |
| 2 | 監査ログを検索 | 条件に合致する監査ログを検索する |
| 3 | 監査ログをエクスポート | 監査ログをエクスポートする |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 参照権限 | 監査ログの参照はシステム管理者のみ可能 |
| 2 | データ表示 | 利用者の権限に基づいてデータをフィルタリング |
