# 通知設定

通知設定画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-026 |
| 画面名           | 通知設定 |
| 説明             | 通知の種類・宛先・トリガーを設定する |
| 関連ユースケース | UC-EF-066 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 通知名、検索バーを表示 |
| メインコンテンツ | 通知設定の一覧をテーブル表示 |
| サイドバー | 通知統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 通知ID | テキスト | はい | 通知設定の識別子 |
| 2 | 利用者ID | テキスト | いいえ | 通知対象利用者の識別子 |
| 3 | 通知種類 | 選択 | はい | 通知種類（メール、システム内通知等） |
| 4 | イベント種類 | 選択 | はい | 通知イベント種類（帳票生成、承認完了等） |
| 5 | 有効フラグ | チェック | はい | 通知有効フラグ |
| 6 | 状態 | 選択 | はい | 状態（有効、無効） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 通知設定を変更 | 通知設定を変更する |
| 2 | 通知設定を参照 | 登録された設定の詳細を確認する |
| 3 | 通知設定を検索 | 条件に合致する設定を検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 通知設定の変更はシステム管理者のみ可能 |
| 2 | 参照権限 | 通知設定の参照は全利用者 |
