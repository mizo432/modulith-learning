# 帳票分析ダッシュボード

帳票分析ダッシュボード画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-029 |
| 画面名           | 帳票分析ダッシュボード |
| 説明             | 帳票利用の統計情報を確認する |
| 関連ユースケース | UC-EF-073 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 分析期間、更新ボタンを表示 |
| メインコンテンツ | 帳票統計グラフ・チャートを表示 |
| サイドバー | 分析フィルターを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 分析ID | テキスト | はい | 帳票分析の識別子 |
| 2 | 分析種類 | 選択 | はい | 分析種類（生成件数、閲覧統計等） |
| 3 | 分析期間 | 選択 | はい | 分析期間（日次、週次、月次等） |
| 4 | 開始日 | 日付 | はい | 分析開始日 |
| 5 | 終了日 | 日付 | はい | 分析終了日 |
| 6 | 生成件数 | 数値 | はい | 帳票生成件数 |
| 7 | 閲覧件数 | 数値 | はい | 帳票閲覧件数 |
| 8 | 承認件数 | 数値 | はい | 承認完了件数 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 分析データを更新 | 帳票分析データを更新する |
| 2 | 分析期間を変更 | 分析期間を変更する |
| 3 | 分析データをエクスポート | 分析データをエクスポートする |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 参照権限 | 分析ダッシュボードの参照はシステム管理者・運用担当者 |
| 2 | データ表示 | 利用者の権限に基づいてデータをフィルタリング |
