# EVT-EF-46 アーカイブ運用にエラーが発生した

## 概要

アーカイブ運用にエラーが発生したことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-46                                                          |
| イベント名       | アーカイブ運用にエラーが発生した                                   |
| 英語名           | `ArchiveOperationError`                                            |
| 集約             | アーカイブ運用 (ArchiveOperation)                                  |
| 関連ユースケース | UC-EF-075 アーカイブ運用を監視する                                 |
| 関連情報         | INF-EF-29 アーカイブ運用                                           |
| 発生条件         | アーカイブ運用にエラーが発生したとき                               |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "ArchiveOperation"                       |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `archiveOpsId`    | String         | ✓   | アーカイブ運用の一意な識別子             |
| `operationType`   | String         | ✓   | 運用種類                                 |
| `errorMessage`    | String         | ✓   | エラーメッセージ                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-45 アーカイブ運用に警告が発生した | 警告時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.operationAudit.spi.archiveOperation.event.ArchiveOperationError`
