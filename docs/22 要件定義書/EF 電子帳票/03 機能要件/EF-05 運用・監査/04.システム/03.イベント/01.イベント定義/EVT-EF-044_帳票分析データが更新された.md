# EVT-EF-44 帳票分析データが更新された

## 概要

帳票分析データが更新されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-44                                                          |
| イベント名       | 帳票分析データが更新された                                         |
| 英語名           | `FormAnalyticsUpdated`                                             |
| 集約             | 帳票分析 (FormAnalytics)                                           |
| 関連ユースケース | UC-EF-073 帳票分析データを更新する                                 |
| 関連情報         | INF-EF-28 帳票分析                                                 |
| 発生条件         | 帳票分析データが更新されたとき                                     |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "FormAnalytics"                          |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `analysisId`      | String         | ✓   | 帳票分析の一意な識別子                   |
| `analysisType`    | String         | ✓   | 分析種類                                 |
| `analysisPeriod`  | String         | ✓   | 分析期間                                 |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-41 監査ログが記録された   | 記録時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.operationAudit.spi.formAnalytics.event.FormAnalyticsUpdated`
