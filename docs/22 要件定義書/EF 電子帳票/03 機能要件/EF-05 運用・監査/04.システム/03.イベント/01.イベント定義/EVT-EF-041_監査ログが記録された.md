# EVT-EF-41 監査ログが記録された

## 概要

監査ログが記録されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-41                                                          |
| イベント名       | 監査ログが記録された                                               |
| 英語名           | `AuditLogRecorded`                                                 |
| 集約             | 監査ログ (AuditLog)                                                |
| 関連ユースケース | UC-EF-068 監査ログを記録する                                       |
| 関連情報         | INF-EF-26 監査ログ                                                 |
| 発生条件         | システム操作が監査ログに記録されたとき                             |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "AuditLog"                               |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `auditLogId`      | String         | ✓   | 監査ログの一意な識別子                   |
| `userId`          | String         | ✓   | 操作者の利用者ID                         |
| `actionType`      | String         | ✓   | 操作種類                                 |
| `targetType`      | String         | ✓   | 操作対象種類                             |
| `targetId`        | String         | ✓   | 操作対象の識別子                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-40 通知設定が変更された   | 変更時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.operationAudit.spi.auditLog.event.AuditLogRecorded`
