# BUC-EF-22 監査・証跡管理

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-EF-22 |
| BUC名            | 監査・証跡管理 |
| 説明             | 操作履歴、閲覧履歴、ダウンロード履歴を記録・参照する |
| 関連業務         | 監査管理 |
| 関連ユースケース | UC-EF-069, UC-EF-070, UC-EF-071 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1 | ACT-EF-08 | 監査担当者 | 監査ログ、操作履歴を確認・分析する |

## アクティビティ

| 番号 | アクティビティ名 | 説明 | 担当アクター |
|------|------------------|------|--------------|
| 1 | 監査ログ参照 | 操作履歴、閲覧履歴、ダウンロード履歴を確認 | ACT-EF-08 |
| 2 | 監査ログ検索 | 利用者、操作種別、日時などの条件で監査ログを検索 | ACT-EF-08 |
| 3 | 監査ログエクスポート | 監査ログをエクスポート | ACT-EF-08 |
