# 要求一覧

運用・監査業務領域（EF-05）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-EF-24 | 通知管理                     | メール、システム内通知、Webhook通知を管理する             | MVP    |
| FR-EF-25 | 監査・証跡管理               | 操作履歴、閲覧履歴、ダウンロード履歴を記録・参照する     | MVP    |
| FR-EF-26 | 運用管理                     | 処理監視、エラー管理、再処理を行う                       | MVP    |
| FR-EF-27 | 帳票分析・統計               | 帳票件数、配信状況、利用状況を分析する                   | 次期   |
| FR-EF-28 | アーカイブ運用管理           | アーカイブ・復元の監視、エラー確認、再実行を行う         | MVP    |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-EF-13 | 監査ログの完全性               | 改ざん防止                             |
| NFR-EF-14 | 通知の信頼性                   | 欠落しない                             |
| NFR-EF-15 | 分析データの集計性能           | リアルタイムに近い集計                 |
