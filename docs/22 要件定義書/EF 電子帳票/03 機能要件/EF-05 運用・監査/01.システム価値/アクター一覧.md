# アクター一覧

運用・監査業務領域（EF-05）でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                 |
|--------|--------------------------|------------------------------------------------------|
| ACT-EF-01 | システム管理者         | 通知設定、システム設定を管理                         |
| ACT-EF-04 | 運用管理者             | 処理監視、エラー管理、再処理、アーカイブ運用を管理   |
| ACT-EF-08 | 監査担当者             | 監査ログ、操作履歴を確認・分析する                   |
| ACT-EF-09 | 管理者                 | 帳票分析・統計を確認する                             |
