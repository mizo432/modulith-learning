# UC-EF-047 帳票を承認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-047 |
| ユースケース名 | 帳票を承認する |
| 英語名 | Approve Form |
| 説明 | 承認者が帳票の内容を確認して承認する |
| 関連アクター | ACT-EF-07（承認者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-15 |
| 外部システム | - |
| 関連画面 | SCR-006（承認詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが承認者の権限を持っていること
- 承認対象の帳票が存在すること

## 基本フロー

1. ユーザーが「承認詳細」画面（SCR-006）にアクセスする
2. 承認対象の帳票を選択する
3. 帳票の内容を確認する
4. 「承認」ボタンをクリックする
5. 承認コメントを入力する（任意）
6. 承認を実行する
7. システムが帳票のステータスを「承認済み」に変更する
8. 承認完了メッセージを表示する

## 代替フロー

- **2a. 帳票が見つからない場合**
  - エラーメッセージを表示する
  - ユーザーは他の帳票を選択するか、他の操作を行う

## 後置条件

- 帳票のステータスが「承認済み」に変更される
- 承認履歴が記録される
