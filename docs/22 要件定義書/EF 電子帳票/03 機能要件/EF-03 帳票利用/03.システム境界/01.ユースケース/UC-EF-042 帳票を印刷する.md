# UC-EF-042 帳票を印刷する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-042 |
| ユースケース名 | 帳票を印刷する |
| 英語名 | Print Form |
| 説明 | 帳票利用者が帳票を印刷する |
| 関連アクター | ACT-EF-06（帳票利用者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-13 |
| 外部システム | - |
| 関連画面 | SCR-003（帳票詳細・プレビュー） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票利用者の権限を持っていること
- 印刷対象の帳票が存在すること

## 基本フロー

1. ユーザーが「帳票詳細・プレビュー」画面（SCR-003）にアクセスする
2. 印刷対象の帳票を選択する
3. 「印刷」ボタンをクリックする
4. システムが印刷ダイアログを表示する
5. ユーザーが印刷設定（プリンター、ページ範囲など）を選択する
6. 印刷を実行する

## 代替フロー

- **2a. 帳票が見つからない場合**
  - エラーメッセージを表示する
  - ユーザーは他の帳票を選択するか、他の操作を行う

- **5a. 印刷をキャンセルした場合**
  - ユーザーがキャンセルを選択する
  - ユースケースを終了する

## 後置条件

- 帳票が印刷される
