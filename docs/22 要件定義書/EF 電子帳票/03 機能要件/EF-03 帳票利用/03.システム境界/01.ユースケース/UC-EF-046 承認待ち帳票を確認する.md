# UC-EF-046 承認待ち帳票を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-046 |
| ユースケース名 | 承認待ち帳票を確認する |
| 英語名 | View Pending Approval Forms |
| 説明 | 承認者が承認待ちの帳票一覧を確認する |
| 関連アクター | ACT-EF-07（承認者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-15 |
| 外部システム | - |
| 関連画面 | SCR-005（承認待ち一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが承認者の権限を持っていること

## 基本フロー

1. ユーザーが「承認待ち一覧」画面（SCR-005）にアクセスする
2. システムが承認待ちの帳票一覧を表示する
3. ユーザーが対象の帳票を選択する
4. システムが帳票の詳細情報を表示する

## 代替フロー

- **2a. 承認待ちの帳票がない場合**
  - 「承認待ちの帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 承認待ちの帳票一覧が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-11 | 帳票情報 | 表示対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある帳票のみ表示 |
| 2 | 権限制限 | 承認者のみ参照可能 |
