# UC-EF-039 帳票をページ移動する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-039 |
| ユースケース名 | 帳票をページ移動する |
| 英語名 | Navigate Form Pages |
| 説明 | 帳票利用者がプレビューでページを移動する |
| 関連アクター | ACT-EF-06（帳票利用者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-13 |
| 外部システム | - |
| 関連画面 | SCR-003（帳票詳細・プレビュー） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票利用者の権限を持っていること
- 帳票がプレビュー表示されていること

## 基本フロー

1. ユーザーがプレビュー表示されている帳票でページ移動操作を行う
2. システムが指定されたページを表示する

## 代替フロー

- **1a. 存在しないページを指定した場合**
  - エラーメッセージを表示する
  - ユーザーは正しいページ番号を指定する

## 後置条件

- 指定されたページが表示される
