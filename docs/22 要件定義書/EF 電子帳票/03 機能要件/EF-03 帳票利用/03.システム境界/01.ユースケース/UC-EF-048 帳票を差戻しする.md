# UC-EF-048 帳票を差戻しする

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-048 |
| ユースケース名 | 帳票を差戻しする |
| 英語名 | Return Form |
| 説明 | 承認者が帳票を申請者に差戻しする |
| 関連アクター | ACT-EF-07（承認者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-15 |
| 外部システム | - |
| 関連画面 | SCR-006（承認詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが承認者の権限を持っていること
- 差戻し対象の帳票が存在すること

## 基本フロー

1. ユーザーが「承認詳細」画面（SCR-006）にアクセスする
2. 差戻し対象の帳票を選択する
3. 帳票の内容を確認する
4. 「差戻し」ボタンをクリックする
5. 差戻し理由を入力する
6. 差戻しを実行する
7. システムが帳票のステータスを「差戻し」に変更する
8. 差戻し完了メッセージを表示する

## 代替フロー

- **2a. 帳票が見つからない場合**
  - エラーメッセージを表示する
  - ユーザーは他の帳票を選択するか、他の操作を行う

- **5a. 差戻し理由が入力されていない場合**
  - エラーメッセージを表示する
  - ユーザーは差戻し理由を入力して再試行する

## 後置条件

- 帳票のステータスが「差戻し」に変更される
- 差戻し履歴が記録される
