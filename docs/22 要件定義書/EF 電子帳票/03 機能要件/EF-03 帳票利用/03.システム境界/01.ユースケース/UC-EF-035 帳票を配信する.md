# UC-EF-035 帳票を配信する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-035 |
| ユースケース名 | 帳票を配信する |
| 英語名 | Distribute Form |
| 説明 | 帳票管理者が利用者・組織・取引先へ帳票を配信する |
| 関連アクター | ACT-EF-05（帳票管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-12 |
| 外部システム | - |
| 関連画面 | SCR-001（ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票管理者の権限を持っていること
- 配信対象の帳票が存在すること

## 基本フロー

1. ユーザーが「ダッシュボード」画面（SCR-001）にアクセスする
2. 「帳票を配信」ボタンをクリックする
3. 配信対象の帳票を選択する
4. 配信先（利用者、組織、取引先）を選択する
5. 配信メッセージを入力する（任意）
6. 配信を実行する
7. システムが帳票を配信先に配信する
8. 配信完了メッセージを表示する

## 代替フロー

- **3a. 帳票が選択されていない場合**
  - エラーメッセージを表示する
  - ユーザーは帳票を選択して再試行する

- **4a. 配信先が選択されていない場合**
  - エラーメッセージを表示する
  - ユーザーは配信先を選択して再試行する

## 後置条件

- 帳票が配信先に配信される
- 配信履歴が記録される
