# UC-EF-049 帳票を却下する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-049 |
| ユースケース名 | 帳票を却下する |
| 英語名 | Reject Form |
| 説明 | 承認者が帳票を却下する |
| 関連アクター | ACT-EF-07（承認者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-15 |
| 外部システム | - |
| 関連画面 | SCR-006（承認詳細） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが承認者の権限を持っていること
- 却下対象の帳票が存在すること

## 基本フロー

1. ユーザーが「承認詳細」画面（SCR-006）にアクセスする
2. 却下対象の帳票を選択する
3. 帳票の内容を確認する
4. 「却下」ボタンをクリックする
5. 却下理由を入力する
6. 却下を実行する
7. システムが帳票のステータスを「却下」に変更する
8. 却下完了メッセージを表示する

## 代替フロー

- **2a. 帳票が見つからない場合**
  - エラーメッセージを表示する
  - ユーザーは他の帳票を選択するか、他の操作を行う

- **5a. 却下理由が入力されていない場合**
  - エラーメッセージを表示する
  - ユーザーは却下理由を入力して再試行する

## 後置条件

- 帳票のステータスが「却下」に変更される
- 却下履歴が記録される

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 却下理由は必須入力 |
| 2 | 権限制限 | 承認者のみ却下可能 |
| 3 | 不可逆操作 | 一度却下した帳票は却下取り消しできない |
