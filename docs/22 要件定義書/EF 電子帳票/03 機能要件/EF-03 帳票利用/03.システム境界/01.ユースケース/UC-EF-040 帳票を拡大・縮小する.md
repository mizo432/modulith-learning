# UC-EF-040 帳票を拡大・縮小する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-040 |
| ユースケース名 | 帳票を拡大・縮小する |
| 英語名 | Zoom Form |
| 説明 | 帳票利用者がプレビューで表示倍率を変更する |
| 関連アクター | ACT-EF-06（帳票利用者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-13 |
| 外部システム | - |
| 関連画面 | SCR-003（帳票詳細・プレビュー） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票利用者の権限を持っていること
- 帳票がプレビュー表示されていること

## 基本フロー

1. ユーザーがプレビュー表示されている帳票で拡大・縮小操作を行う
2. システムが指定された倍率で帳票を表示する

## 代替フロー

- **1a. 範囲外の倍率を指定した場合**
  - 最小・最大倍率に制限する
  - ユーザーは適切な倍率を指定する

## 後置条件

- 指定された倍率で帳票が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-11 | 帳票情報 | プレビュー対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある帳票のみ表示 |
| 2 | 倍率制限 | 最小25%、最大400% |
