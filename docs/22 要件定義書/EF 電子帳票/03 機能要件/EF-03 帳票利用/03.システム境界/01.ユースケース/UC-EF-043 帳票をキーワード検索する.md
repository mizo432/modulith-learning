# UC-EF-043 帳票をキーワード検索する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-043 |
| ユースケース名 | 帳票をキーワード検索する |
| 英語名 | Search Forms by Keyword |
| 説明 | 帳票利用者がキーワードで帳票を検索する |
| 関連アクター | ACT-EF-06（帳票利用者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-14 |
| 外部システム | - |
| 関連画面 | SCR-004（帳票検索） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票利用者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票検索」画面（SCR-004）にアクセスする
2. キーワードを入力する
3. 「検索」ボタンをクリックする
4. システムがキーワードに一致する帳票を検索する
5. 検索結果一覧を表示する

## 代替フロー

- **2a. キーワードが入力されていない場合**
  - エラーメッセージを表示する
  - ユーザーはキーワードを入力して再試行する

- **4a. 検索結果がない場合**
  - 「検索結果がありません」というメッセージを表示する
  - ユーザーは別のキーワードで検索するか、他の操作を行う

## 後置条件

- 検索結果が表示される
