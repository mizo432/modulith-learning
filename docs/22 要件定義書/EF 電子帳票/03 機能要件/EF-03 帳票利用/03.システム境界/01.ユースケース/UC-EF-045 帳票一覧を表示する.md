# UC-EF-045 帳票一覧を表示する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-045 |
| ユースケース名 | 帳票一覧を表示する |
| 英語名 | Display Form List |
| 説明 | 帳票利用者が閲覧可能な帳票を一覧表示する |
| 関連アクター | ACT-EF-06（帳票利用者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-14 |
| 外部システム | - |
| 関連画面 | SCR-002（帳票一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票利用者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票一覧」画面（SCR-002）にアクセスする
2. システムが閲覧可能な帳票一覧を表示する
3. ユーザーが対象の帳票を選択する
4. システムが帳票の詳細情報を表示する

## 代替フロー

- **2a. 帳票が存在しない場合**
  - 「帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 帳票一覧が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-11 | 帳票情報 | 表示対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある帳票のみ表示 |
| 2 | 権限制限 | 帳票利用者のみ参照可能 |
