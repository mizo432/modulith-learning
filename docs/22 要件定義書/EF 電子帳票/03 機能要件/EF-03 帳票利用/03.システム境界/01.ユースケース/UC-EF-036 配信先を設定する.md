# UC-EF-036 配信先を設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-036 |
| ユースケース名 | 配信先を設定する |
| 英語名 | Configure Distribution Destination |
| 説明 | 帳票管理者が帳票の配信先（利用者・組織）を設定する |
| 関連アクター | ACT-EF-05（帳票管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-12 |
| 外部システム | - |
| 関連画面 | SCR-001（ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票管理者の権限を持っていること

## 基本フロー

1. ユーザーが「ダッシュボード」画面（SCR-001）にアクセスする
2. 「配信先設定」ボタンをクリックする
3. 配信対象の帳票を選択する
4. 配信先（利用者、組織、取引先）を追加する
5. 配信条件（期間、頻度など）を設定する（任意）
6. 入力を保存する
7. システムが配信先設定を登録する
8. 登録完了メッセージを表示する

## 代替フロー

- **3a. 帳票が選択されていない場合**
  - エラーメッセージを表示する
  - ユーザーは帳票を選択して再試行する

- **4a. 配信先が選択されていない場合**
  - エラーメッセージを表示する
  - ユーザーは配信先を選択して再試行する

## 後置条件

- 配信先設定がシステムに登録される
