# UC-EF-037 配信状況を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-037 |
| ユースケース名 | 配信状況を確認する |
| 英語名 | View Distribution Status |
| 説明 | 帳票管理者が帳票の配信状況を確認する |
| 関連アクター | ACT-EF-05（帳票管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-12 |
| 外部システム | - |
| 関連画面 | SCR-001（ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票管理者の権限を持っていること

## 基本フロー

1. ユーザーが「ダッシュボード」画面（SCR-001）にアクセスする
2. 「配信状況」タブを選択する
3. システムが配信状況一覧を表示する（配信日、配信先、配信ステータスなど）
4. ユーザーが対象の配信を選択する
5. システムが配信の詳細情報を表示する

## 代替フロー

- **3a. 配信履歴が存在しない場合**
  - 「配信履歴がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 配信状況が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-12 | 配信履歴 | 参照対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある配信履歴のみ表示 |
| 2 | 権限制限 | 帳票管理者のみ参照可能 |
