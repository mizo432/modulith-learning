# UC-EF-041 帳票をダウンロードする

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-041 |
| ユースケース名 | 帳票をダウンロードする |
| 英語名 | Download Form |
| 説明 | 帳票利用者が帳票ファイルをダウンロードする |
| 関連アクター | ACT-EF-06（帳票利用者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-13 |
| 外部システム | - |
| 関連画面 | SCR-003（帳票詳細・プレビュー） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票利用者の権限を持っていること
- ダウンロード対象の帳票が存在すること

## 基本フロー

1. ユーザーが「帳票詳細・プレビュー」画面（SCR-003）にアクセスする
2. ダウンロード対象の帳票を選択する
3. 「ダウンロード」ボタンをクリックする
4. システムが帳票ファイルをダウンロードする
5. ダウンロード完了メッセージを表示する

## 代替フロー

- **2a. 帳票が見つからない場合**
  - エラーメッセージを表示する
  - ユーザーは他の帳票を選択するか、他の操作を行う

- **3a. アーカイブ済み帳票の場合**
  - システムが自動復元を開始する
  - 復元完了後にダウンロードする

## 後置条件

- 帳票ファイルがダウンロードされる
- ダウンロード履歴が記録される
