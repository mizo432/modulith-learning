# ダッシュボード

ダッシュボード画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-015 |
| 画面名           | ダッシュボード |
| 説明             | 帳票の概要・通知・統計を確認する |
| 関連ユースケース | UC-EF-035, UC-EF-038, UC-EF-040 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | ユーザー名、通知アイコンを表示 |
| メインコンテンツ | 帳票統計、最近の帳票、通知一覧を表示 |
| サイドバー | クイックアクセスメニューを表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 帳票総数 | 数値 | はい | 帳票の総数 |
| 2 | 承認待ち数 | 数値 | はい | 承認待ちの帳票数 |
| 3 | 最近の帳票 | リスト | はい | 最近生成された帳票一覧 |
| 4 | 通知一覧 | リスト | はい | 未読通知一覧 |
| 5 | 統計グラフ | グラフ | はい | 帳票生成統計グラフ |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 帳票一覧へ | 帳票一覧画面に遷移する |
| 2 | 承認待ち一覧へ | 承認待ち一覧画面に遷移する |
| 3 | 通知を確認 | 通知を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 参照権限 | ダッシュボードの参照は全利用者 |
| 2 | データ表示 | 利用者の権限に基づいてデータをフィルタリング |
