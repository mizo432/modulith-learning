# 承認待ち一覧

承認待ち一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-019 |
| 画面名           | 承認待ち一覧 |
| 説明             | 承認待ちの帳票一覧を確認する |
| 関連ユースケース | UC-EF-045, UC-EF-046, UC-EF-047 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 承認者名、検索バーを表示 |
| メインコンテンツ | 承認待ちの帳票一覧をテーブル表示 |
| サイドバー | 承認統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 承認ID | テキスト | はい | 承認・確認の識別子 |
| 2 | 帳票ID | テキスト | はい | 承認対象の帳票識別子 |
| 3 | 帳票タイトル | テキスト | はい | 帳票タイトル |
| 4 | 承認者 | テキスト | はい | 承認者の利用者ID |
| 5 | 承認状態 | 選択 | はい | 承認状態（保留中、承認済み、拒否済み等） |
| 6 | 要求日時 | 日付 | はい | 承認要求日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 承認を完了 | 承認を完了する |
| 2 | 承認を却下 | 承認を却下する |
| 3 | 承認詳細を確認 | 承認対象の帳票詳細を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 承認操作は承認者のみ可能 |
| 2 | 参照権限 | 承認待ち一覧の参照は承認者 |
