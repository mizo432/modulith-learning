# 論理データモデル

## 概要

EF-03 帳票利用業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    FORM_DELIVERY
    {
        string FORM_DELIVERY_ID PK "帳票配信ID"
        string 宛先 "宛先"
        string 日時 "日時"
        string 状態 "状態"
        string 作成日 "作成日"
        string state "状態(帳票配信)"
        enum variation "バリエーション(配信状態)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| 帳票配信 | FORM_DELIVERY_ID | string | true | 帳票配信ID |
