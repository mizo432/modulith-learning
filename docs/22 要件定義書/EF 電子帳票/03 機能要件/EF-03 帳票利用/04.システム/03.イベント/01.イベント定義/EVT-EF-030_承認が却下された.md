# EVT-EF-30 承認が却下された

## 概要

帳票の承認が却下されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-30                                                          |
| イベント名       | 承認が却下された                                                   |
| 英語名           | `ApprovalRejected`                                                 |
| 集約             | 承認・確認 (Approval)                                              |
| 関連ユースケース | UC-EF-047 承認を却下する                                           |
| 関連情報         | INF-EF-18 承認・確認                                               |
| 発生条件         | 承認者が帳票の承認を却下したとき                                   |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "Approval"                               |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `approvalId`      | String         | ✓   | 承認・確認の一意な識別子                 |
| `formId`          | String         | ✓   | 承認対象の帳票識別子                     |
| `approverId`      | String         | ✓   | 承認者の利用者ID                         |
| `rejectionComment`| String         | ✗   | 却下コメント                             |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-28 承認が要求された       | 要求時に発生                 |
| EVT-EF-29 承認が完了した         | 承認完了時に発生             |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formUsage.spi.approval.event.ApprovalRejected`
