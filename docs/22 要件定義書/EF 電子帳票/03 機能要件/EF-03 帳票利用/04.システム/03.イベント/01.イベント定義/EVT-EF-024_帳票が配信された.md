# EVT-EF-24 帳票が配信された

## 概要

帳票が配信されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-24                                                          |
| イベント名       | 帳票が配信された                                                   |
| 英語名           | `FormDelivered`                                                    |
| 集約             | 帳票配信 (FormDelivery)                                            |
| 関連ユースケース | UC-EF-035 帳票を配信する                                           |
| 関連情報         | INF-EF-15 帳票配信                                                 |
| 発生条件         | 帳票が配信されたとき                                               |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "FormDelivery"                           |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `deliveryId`      | String         | ✓   | 帳票配信の一意な識別子                   |
| `formId`          | String         | ✓   | 配信対象の帳票識別子                     |
| `recipientId`     | String         | ✓   | 配信先利用者の識別子                     |
| `deliveryType`    | String         | ✓   | 配信種類                                 |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-25 帳票配信が失敗した     | 失敗時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formUsage.spi.formDelivery.event.FormDelivered`
