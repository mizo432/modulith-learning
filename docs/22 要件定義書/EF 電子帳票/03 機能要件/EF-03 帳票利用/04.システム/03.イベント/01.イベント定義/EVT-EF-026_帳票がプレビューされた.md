# EVT-EF-26 帳票がプレビューされた

## 概要

帳票がプレビューされたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-26                                                          |
| イベント名       | 帳票がプレビューされた                                             |
| 英語名           | `FormPreviewed`                                                    |
| 集約             | 帳票プレビュー (FormPreview)                                       |
| 関連ユースケース | UC-EF-038 帳票をプレビューする                                     |
| 関連情報         | INF-EF-16 帳票プレビュー                                           |
| 発生条件         | 利用者が帳票をプレビューしたとき                                   |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "FormPreview"                            |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `previewId`       | String         | ✓   | 帳票プレビューの一意な識別子             |
| `formId`          | String         | ✓   | プレビュー対象の帳票識別子               |
| `userId`          | String         | ✓   | プレビューした利用者の識別子             |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-27 帳票が検索された       | 検索後にプレビュー時に発生   |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formUsage.spi.formPreview.event.FormPreviewed`
