# EVT-EF-27 帳票が検索された

## 概要

帳票が検索されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-27                                                          |
| イベント名       | 帳票が検索された                                                   |
| 英語名           | `FormSearched`                                                     |
| 集約             | 帳票検索 (FormSearch)                                              |
| 関連ユースケース | UC-EF-040 帳票を検索する                                           |
| 関連情報         | INF-EF-17 帳票検索                                                 |
| 発生条件         | 利用者が帳票を検索したとき                                         |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "FormSearch"                             |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `searchId`        | String         | ✓   | 帳票検索の一意な識別子                   |
| `userId`          | String         | ✓   | 検索を実行した利用者の識別子             |
| `searchKeywords`  | String         | ✓   | 検索キーワード                           |
| `resultCount`     | int            | ✓   | 検索結果件数                             |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-26 帳票がプレビューされた | 検索後にプレビュー時に発生   |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formUsage.spi.formSearch.event.FormSearched`
