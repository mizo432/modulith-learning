# EF-03 帳票利用

## 概要

本ドキュメントは、帳票利用業務領域（EF-03）の機能要件を定義します。

帳票配信、閲覧・プレビュー、検索、承認・確認を行い、利用者が帳票を日常的に利用するための機能を提供します。

## 含まれるFeature

| ID  | Feature名       | 概要                           |
|-----|----------------|-------------------------------|
| F07 | 帳票配信        | 利用者・組織・取引先への帳票配信             |
| F08 | 帳票閲覧・プレビュー  | PDF・Office文書のプレビュー、印刷、ダウンロード |
| F09 | 帳票検索        | 属性検索、条件検索、全文検索               |
| F10 | 承認・確認       | 帳票の承認、差戻し、確認状況管理             |
