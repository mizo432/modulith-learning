# 要求一覧

帳票利用業務領域（EF-03）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-EF-14 | 帳票配信                     | 利用者・組織・取引先への帳票を配信する                   | MVP    |
| FR-EF-15 | 帳票プレビュー               | PDF・Office文書をブラウザでプレビュー表示する            | MVP    |
| FR-EF-16 | 帳票検索                     | 属性検索、条件検索、全文検索を行う                       | MVP    |
| FR-EF-17 | 承認・確認                   | 帳票の承認、差戻し、却下、確認状況管理を行う             | MVP    |
| FR-EF-18 | Office文書変換               | Word・Excel・PowerPointをPDFに変換して表示する          | MVP    |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-EF-07 | プレビューの表示速度           | ブラウザ内で迅速に表示                 |
| NFR-EF-08 | 検索性能                       | 大量帳票でも迅速に絞り込める           |
| NFR-EF-09 | アーカイブ自動復元             | 利用者に意識させない復元               |
