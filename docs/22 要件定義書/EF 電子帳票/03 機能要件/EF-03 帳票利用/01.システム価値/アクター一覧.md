# アクター一覧

帳票利用業務領域（EF-03）でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                 |
|--------|--------------------------|------------------------------------------------------|
| ACT-EF-05 | 帳票管理者             | 帳票の配信先を設定・管理する                         |
| ACT-EF-06 | 帳票利用者             | 帳票を検索・閲覧・ダウンロードする                   |
| ACT-EF-07 | 承認者                 | 帳票を確認・承認・差戻し・却下する                   |
