# BUC-EF-12 帳票の配信

ビジネスユースケース（BUC）の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| BUC ID           | BUC-EF-12 |
| BUC名            | 帳票の配信 |
| 説明             | 利用者・組織・取引先への帳票を配信する |
| 関連業務         | 帳票配信 |
| 関連ユースケース | UC-EF-035, UC-EF-036, UC-EF-037 |

## ビジネスアクター

| 番号 | アクターID | アクター名 | 役割 |
|------|------------|------------|------|
| 1 | ACT-EF-05 | 帳票管理者 | 帳票の配信先を設定・管理する |

| 番号 | アクティビティ名 | 説明 | 担当アクター |

| 3 | 配信状況確認 | 帳票の配信状況を確認 | ACT-EF-05 |
