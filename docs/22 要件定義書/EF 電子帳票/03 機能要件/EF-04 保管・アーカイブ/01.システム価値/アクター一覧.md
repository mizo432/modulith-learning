# アクター一覧

保管・アーカイブ業務領域（EF-04）でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                 |
|--------|--------------------------|------------------------------------------------------|
| ACT-EF-01 | システム管理者         | アーカイブポリシー、保存期間を設定・管理             |
| ACT-EF-04 | 運用管理者             | アーカイブ処理、復元処理を監視・管理                 |
| ACT-EF-05 | 帳票管理者             | 廃棄対象帳票を確認・承認する                         |
| ACT-EF-06 | 帳票利用者             | アーカイブ済み帳票を閲覧要求する                     |
