# 要求一覧

保管・アーカイブ業務領域（EF-04）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-EF-19 | 帳票保管・廃棄管理           | 保存期間設定、廃棄対象確認・承認・処理を行う             | MVP    |
| FR-EF-20 | アーカイブポリシー管理       | 帳票種類ごとのアーカイブ条件を管理する                   | MVP    |
| FR-EF-21 | アーカイブ対象管理           | アーカイブ対象帳票の抽出・管理を行う                     | MVP    |
| FR-EF-22 | アーカイブ処理管理           | S3ストレージクラス変更、移行、完全性検証を行う           | MVP    |
| FR-EF-23 | 帳票自動復元管理             | アーカイブ済み帳票の自動復元を行う                       | MVP    |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-EF-10 | アーカイブ処理の信頼性         | データ完全性を確保                     |
| NFR-EF-11 | 復元の迅速性                   | 利用者の待機時間を最小化               |
| NFR-EF-12 | ストレージコストの最適化       | Glacier 等を活用                       |
