# UC-EF-054 アーカイブポリシーを登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-054 |
| ユースケース名 | アーカイブポリシーを登録する |
| 英語名 | Register Archive Policy |
| 説明 | システム管理者が帳票種類ごとのアーカイブ条件を定義する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-17 |
| 外部システム | - |
| 関連画面 | SCR-011（アーカイブポリシー管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「アーカイブポリシー管理」画面（SCR-011）にアクセスする
2. 「ポリシーを登録」ボタンをクリックする
3. 帳票種類、アーカイブ条件（保存期間、ストレージクラスなど）を入力する
4. 入力を保存する
5. システムがアーカイブポリシーを登録する
6. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- アーカイブポリシーがシステムに登録される
