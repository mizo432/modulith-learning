# UC-EF-050 保存期間を設定する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-050 |
| ユースケース名 | 保存期間を設定する |
| 英語名 | Configure Retention Period |
| 説明 | システム管理者が帳票種類ごとの保存期間、起算日を設定する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-16 |
| 外部システム | - |
| 関連画面 | SCR-008（帳票定義登録・編集） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票定義登録・編集」画面（SCR-008）にアクセスする
2. 対象の帳票定義を選択する
3. 「保存期間設定」タブを選択する
4. 保存期間（年数）、起算日（作成日、承認日など）を入力する
5. 入力を保存する
6. システムが保存期間設定を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 保存期間設定がシステムに登録される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-10 | 帳票定義情報 | 保存期間設定の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 保存期間、起算日は必須入力 |
| 2 | 権限制限 | システム管理者のみ設定可能 |
