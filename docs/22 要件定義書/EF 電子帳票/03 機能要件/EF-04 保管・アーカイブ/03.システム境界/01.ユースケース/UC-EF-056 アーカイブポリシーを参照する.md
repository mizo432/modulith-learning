# UC-EF-056 アーカイブポリシーを参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-056 |
| ユースケース名 | アーカイブポリシーを参照する |
| 英語名 | View Archive Policy |
| 説明 | システム管理者または運用管理者が登録されたアーカイブポリシーを確認する |
| 関連アクター | ACT-EF-01（システム管理者）、ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-17 |
| 外部システム | - |
| 関連画面 | SCR-011（アーカイブポリシー管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者または運用管理者の権限を持っていること

## 基本フロー

1. ユーザーが「アーカイブポリシー管理」画面（SCR-011）にアクセスする
2. システムが登録されたアーカイブポリシー一覧を表示する
3. ユーザーが対象のポリシーを選択する
4. システムがポリシーの詳細情報を表示する

## 代替フロー

- **2a. ポリシーが登録されていない場合**
  - 「ポリシーが登録されていません」というメッセージを表示する
  - ユーザーはポリシーを登録するか、他の操作を行う

## 後置条件

- アーカイブポリシーが表示される
