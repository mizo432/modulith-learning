# UC-EF-053 廃棄処理を実行する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-053 |
| ユースケース名 | 廃棄処理を実行する |
| 英語名 | Execute Disposal |
| 説明 | 運用管理者が承認された帳票を完全に削除する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-16 |
| 外部システム | - |
| 関連画面 | SCR-012（アーカイブ対象一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること
- 廃棄承認済みの帳票が存在すること

## 基本フロー

1. ユーザーが「アーカイブ対象一覧」画面（SCR-012）にアクセスする
2. 「廃棄対象」タブを選択する
3. 廃棄承認済みの帳票を選択する
4. 「廃棄処理を実行」ボタンをクリックする
5. 廃棄確認ダイアログを表示する
6. ユーザーが確認する
7. システムが帳票ファイルをストレージから完全に削除する
8. 帳票情報をデータベースから削除する
9. 廃棄完了メッセージを表示する

## 代替フロー

- **3a. 廃棄承認済みの帳票がない場合**
  - 「廃棄承認済みの帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

- **5a. 廃棄をキャンセルした場合**
  - ユーザーがキャンセルを選択する
  - ユースケースを終了する

## 後置条件

- 帳票ファイルがストレージから完全に削除される
- 帳票情報がデータベースから削除される
- 廃棄履歴が記録される

|------|----------|------|

| 3 | 権限制限 | 運用管理者のみ廃棄処理可能 |
