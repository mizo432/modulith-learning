# UC-EF-058 アーカイブ対象を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-058 |
| ユースケース名 | アーカイブ対象を確認する |
| 英語名 | View Archive Targets |
| 説明 | 運用管理者が抽出されたアーカイブ対象帳票を確認する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-18 |
| 外部システム | - |
| 関連画面 | SCR-012（アーカイブ対象一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること
- アーカイブ対象の帳票が抽出されていること

## 基本フロー

1. ユーザーが「アーカイブ対象一覧」画面（SCR-012）にアクセスする
2. 「アーカイブ対象」タブを選択する
3. システムがアーカイブ対象の帳票一覧を表示する
4. ユーザーが対象の帳票を選択する
5. システムが帳票の詳細情報を表示する

## 代替フロー

- **3a. アーカイブ対象の帳票がない場合**
  - 「アーカイブ対象の帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- アーカイブ対象の帳票一覧が表示される
