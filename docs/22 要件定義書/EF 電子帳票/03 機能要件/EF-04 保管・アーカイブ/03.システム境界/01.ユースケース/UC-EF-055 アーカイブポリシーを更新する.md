# UC-EF-055 アーカイブポリシーを更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-055 |
| ユースケース名 | アーカイブポリシーを更新する |
| 英語名 | Update Archive Policy |
| 説明 | システム管理者が既存のアーカイブポリシーを修正する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-17 |
| 外部システム | - |
| 関連画面 | SCR-011（アーカイブポリシー管理） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること
- 更新対象のアーカイブポリシーが存在すること

## 基本フロー

1. ユーザーが「アーカイブポリシー管理」画面（SCR-011）にアクセスする
2. 更新対象のポリシーを選択する
3. 「ポリシーを更新」ボタンをクリックする
4. 帳票種類、アーカイブ条件などを修正する
5. 入力を保存する
6. システムがアーカイブポリシーを更新する
7. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- アーカイブポリシーがシステムに更新される
