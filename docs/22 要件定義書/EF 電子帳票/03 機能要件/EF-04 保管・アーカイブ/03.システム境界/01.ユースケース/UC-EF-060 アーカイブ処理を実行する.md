# UC-EF-060 アーカイブ処理を実行する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-060 |
| ユースケース名 | アーカイブ処理を実行する |
| 英語名 | Execute Archive Process |
| 説明 | 運用管理者がS3ストレージクラスを変更してアーカイブ移行する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-19 |
| 外部システム | ES-EF-01（Amazon S3） |
| 関連画面 | SCR-010（アーカイブ管理ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること
- アーカイブ対象の帳票が存在すること

## 基本フロー

1. ユーザーが「アーカイブ管理ダッシュボード」画面（SCR-010）にアクセスする
2. 「アーカイブ処理」タブを選択する
3. 「アーカイブ処理を実行」ボタンをクリックする
4. システムがアーカイブ対象の帳票ファイルをS3ストレージクラスに変更する
5. 処理進捗を表示する
6. 処理完了メッセージを表示する

## 代替フロー

- **3a. アーカイブ対象の帳票がない場合**
  - 「アーカイブ対象の帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

- **4a. アーカイブ処理に失敗した場合**
  - エラーメッセージを表示する
  - ユーザーは再実行するか、他の操作を行う

## 後置条件

- 帳票ファイルがS3ストレージクラスに変更される
- アーカイブ処理履歴が記録される
