# UC-EF-062 完全性検証を行う

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-062 |
| ユースケース名 | 完全性検証を行う |
| 英語名 | Perform Integrity Verification |
| 説明 | 運用管理者がアーカイブ後のデータ完全性をチェックサムで検証する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-19 |
| 外部システム | ES-EF-01（Amazon S3） |
| 関連画面 | SCR-010（アーカイブ管理ダッシュボード） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること
- アーカイブ済みの帳票が存在すること

## 基本フロー

1. ユーザーが「アーカイブ管理ダッシュボード」画面（SCR-010）にアクセスする
2. 「完全性検証」タブを選択する
3. 「検証を実行」ボタンをクリックする
4. システムがアーカイブ済み帳票のチェックサムを検証する
5. 検証結果を表示する

## 代替フロー

- **3a. アーカイブ済みの帳票がない場合**
  - 「アーカイブ済みの帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

- **4a. 検証に失敗した場合**
  - エラーメッセージを表示する
  - ユーザーは再実行するか、他の操作を行う

## 後置条件

- 検証結果が表示される
- 検証履歴が記録される
