# UC-EF-059 アーカイブ対象を管理する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-059 |
| ユースケース名 | アーカイブ対象を管理する |
| 英語名 | Manage Archive Targets |
| 説明 | 運用管理者がアーカイブ対象の除外・追加を管理する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-18 |
| 外部システム | - |
| 関連画面 | SCR-012（アーカイブ対象一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること
- アーカイブ対象の帳票が抽出されていること

## 基本フロー

1. ユーザーが「アーカイブ対象一覧」画面（SCR-012）にアクセスする
2. 「アーカイブ対象」タブを選択する
3. 管理対象の帳票を選択する
4. 「除外」または「追加」ボタンをクリックする
5. 理由を入力する（任意）
6. 入力を保存する
7. システムがアーカイブ対象を更新する
8. 更新完了メッセージを表示する

## 代替フロー

- **3a. アーカイブ対象の帳票がない場合**
  - 「アーカイブ対象の帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- アーカイブ対象が更新される
