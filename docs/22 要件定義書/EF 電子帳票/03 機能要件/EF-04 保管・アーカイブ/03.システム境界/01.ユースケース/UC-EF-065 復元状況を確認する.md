# UC-EF-065 復元状況を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-065 |
| ユースケース名 | 復元状況を確認する |
| 英語名 | View Restoration Status |
| 説明 | 運用管理者または帳票利用者が復元処理の進捗・結果を確認する |
| 関連アクター | ACT-EF-04（運用管理者）、ACT-EF-06（帳票利用者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-20 |
| 外部システム | - |
| 関連画面 | SCR-013（復元要求一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者または帳票利用者の権限を持っていること

## 基本フロー

1. ユーザーが「復元要求一覧」画面（SCR-013）にアクセスする
2. システムが復元処理の進捗・結果を表示する
3. ユーザーが対象の復元処理を選択する
4. システムが復元処理の詳細情報を表示する

## 代替フロー

- **2a. 復元処理履歴がない場合**
  - 「復元処理履歴がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 復元状況が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-11 | 帳票情報 | 復元対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある復元処理のみ表示 |
| 2 | 権限制限 | 運用管理者または帳票利用者のみ参照可能 |
