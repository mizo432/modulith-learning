# UC-EF-052 廃棄を承認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-052 |
| ユースケース名 | 廃棄を承認する |
| 英語名 | Approve Disposal |
| 説明 | 帳票管理者が廃棄対象帳票を承認する |
| 関連アクター | ACT-EF-05（帳票管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-16 |
| 外部システム | - |
| 関連画面 | SCR-012（アーカイブ対象一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票管理者の権限を持っていること
- 廃棄対象の帳票が存在すること

## 基本フロー

1. ユーザーが「アーカイブ対象一覧」画面（SCR-012）にアクセスする
2. 「廃棄対象」タブを選択する
3. 廃棄対象の帳票を選択する
4. 「廃棄を承認」ボタンをクリックする
5. 承認コメントを入力する（任意）
6. 承認を実行する
7. システムが帳票のステータスを「廃棄承認済み」に変更する
8. 承認完了メッセージを表示する

## 代替フロー

- **3a. 廃棄対象の帳票がない場合**
  - 「廃棄対象の帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 帳票のステータスが「廃棄承認済み」に変更される
- 廃棄承認履歴が記録される
