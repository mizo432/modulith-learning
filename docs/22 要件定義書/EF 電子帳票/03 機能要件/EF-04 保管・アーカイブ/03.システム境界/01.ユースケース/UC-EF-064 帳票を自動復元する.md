# UC-EF-064 帳票を自動復元する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-064 |
| ユースケース名 | 帳票を自動復元する |
| 英語名 | Automatically Restore Form |
| 説明 | 運用管理者が復元要求に応じ、アーカイブ済み帳票を自動復元する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-20 |
| 外部システム | ES-EF-01（Amazon S3） |
| 関連画面 | SCR-013（復元要求一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること
- 復元要求が存在すること

## 基本フロー

1. ユーザーが「復元要求一覧」画面（SCR-013）にアクセスする
2. 「自動復元」ボタンをクリックする
3. システムが復元要求に応じ、アーカイブ済み帳票をS3から復元する
4. 処理進捗を表示する
5. 処理完了メッセージを表示する

## 代替フロー

- **2a. 復元要求がない場合**
  - 「復元要求がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

- **3a. 復元処理に失敗した場合**
  - エラーメッセージを表示する
  - ユーザーは再実行するか、他の操作を行う

## 後置条件

- アーカイブ済み帳票が復元される
- 復元履歴が記録される
