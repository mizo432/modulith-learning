# UC-EF-051 廃棄対象帳票を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-051 |
| ユースケース名 | 廃棄対象帳票を確認する |
| 英語名 | View Disposal Target Forms |
| 説明 | 帳票管理者が保存期限到来の帳票を抽出・確認する |
| 関連アクター | ACT-EF-05（帳票管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-16 |
| 外部システム | - |
| 関連画面 | SCR-012（アーカイブ対象一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票管理者の権限を持っていること

## 基本フロー

1. ユーザーが「アーカイブ対象一覧」画面（SCR-012）にアクセスする
2. 「廃棄対象」タブを選択する
3. システムが保存期限到来の帳票を抽出して一覧を表示する
4. ユーザーが対象の帳票を選択する
5. システムが帳票の詳細情報を表示する

## 代替フロー

- **3a. 廃棄対象の帳票がない場合**
  - 「廃棄対象の帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 廃棄対象の帳票一覧が表示される

| 2 | 権限制限 | 帳票管理者のみ参照可能 |
