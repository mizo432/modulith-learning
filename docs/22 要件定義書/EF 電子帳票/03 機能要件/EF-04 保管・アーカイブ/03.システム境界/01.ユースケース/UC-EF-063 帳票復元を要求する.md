# UC-EF-063 帳票復元を要求する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-063 |
| ユースケース名 | 帳票復元を要求する |
| 英語名 | Request Form Restoration |
| 説明 | 帳票利用者がアーカイブ済み帳票の復元を要求する |
| 関連アクター | ACT-EF-06（帳票利用者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-20 |
| 外部システム | - |
| 関連画面 | SCR-003（帳票詳細・プレビュー） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票利用者の権限を持っていること
- アーカイブ済みの帳票が存在すること

## 基本フロー

1. ユーザーが「帳票詳細・プレビュー」画面（SCR-003）にアクセスする
2. アーカイブ済みの帳票を選択する
3. システムが帳票がアーカイブ済みであることを通知する
4. 「復元を要求」ボタンをクリックする
5. システムが復元要求を登録する
6. 復元要求完了メッセージを表示する

## 代替フロー

- **2a. 帳票が見つからない場合**
  - エラーメッセージを表示する
  - ユーザーは他の帳票を選択するか、他の操作を行う

## 後置条件

- 復元要求がシステムに登録される
- 自動復元処理が開始される
