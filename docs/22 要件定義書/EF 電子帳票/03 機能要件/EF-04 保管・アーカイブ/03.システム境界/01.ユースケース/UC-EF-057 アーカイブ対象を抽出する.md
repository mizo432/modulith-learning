# UC-EF-057 アーカイブ対象を抽出する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-057 |
| ユースケース名 | アーカイブ対象を抽出する |
| 英語名 | Extract Archive Targets |
| 説明 | 運用管理者がアーカイブ条件に合致する帳票を抽出する |
| 関連アクター | ACT-EF-04（運用管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-18 |
| 外部システム | - |
| 関連画面 | SCR-012（アーカイブ対象一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが運用管理者の権限を持っていること
- アーカイブポリシーが登録されていること

## 基本フロー

1. ユーザーが「アーカイブ対象一覧」画面（SCR-012）にアクセスする
2. 「アーカイブ対象」タブを選択する
3. 「アーカイブ対象を抽出」ボタンをクリックする
4. システムがアーカイブ条件に合致する帳票を抽出する
5. 抽出結果を一覧表示する

## 代替フロー

- **4a. アーカイブ対象の帳票がない場合**
  - 「アーカイブ対象の帳票がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- アーカイブ対象の帳票が抽出される
