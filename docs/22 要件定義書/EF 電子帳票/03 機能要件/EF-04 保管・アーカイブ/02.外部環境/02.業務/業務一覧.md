# 業務一覧

保管・アーカイブ業務領域（EF-04）の業務を定義します。

| ID        | 業務名                           | 概要                                                   | 主なアクター                   |
|-----------|----------------------------------|--------------------------------------------------------|--------------------------------|
| BUC-EF-16 | 帳票保管・廃棄管理               | 保存期間設定、廃棄対象確認・承認・処理を行う             | ACT-EF-01, ACT-EF-05           |
| BUC-EF-17 | アーカイブポリシー管理           | 帳票種類ごとのアーカイブ条件を管理する                   | ACT-EF-01                      |
| BUC-EF-18 | アーカイブ対象管理               | アーカイブ対象帳票の抽出・管理を行う                     | ACT-EF-04                      |
| BUC-EF-19 | アーカイブ処理管理               | S3ストレージクラス変更、移行、完全性検証を行う           | ACT-EF-04                      |
| BUC-EF-20 | 帳票自動復元管理                 | アーカイブ済み帳票の自動復元を行う                       | ACT-EF-04, ACT-EF-06           |
