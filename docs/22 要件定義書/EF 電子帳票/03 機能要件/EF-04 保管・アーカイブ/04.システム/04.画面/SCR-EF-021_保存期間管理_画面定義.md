# 保存期間管理

保存期間管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-021 |
| 画面名           | 保存期間管理 |
| 説明             | 帳票種類ごとの保存期間を設定・管理する |
| 関連ユースケース | UC-EF-050, UC-EF-051 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 帳票種類、検索バーを表示 |
| メインコンテンツ | 保存期間の一覧をテーブル表示 |
| サイドバー | 保存期間統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 保存期間ID | テキスト | はい | 保存期間の識別子 |
| 2 | 帳票定義ID | テキスト | はい | 関連する帳票定義の識別子 |
| 3 | 保存期間 | 数値 | はい | 保存期間（月数） |
| 4 | 期間単位 | 選択 | はい | 期間単位（月、年等） |
| 5 | 保存ポリシー | 選択 | はい | 保存ポリシー（法的要件、業務要件等） |
| 6 | 状態 | 選択 | はい | 状態（有効、無効） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 保存期間を設定 | 帳票の保存期間を設定する |
| 2 | 保存期間を更新 | 既存の保存期間を更新する |
| 3 | 保存期間を参照 | 登録された保存期間の詳細を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 保存期間の設定はシステム管理者のみ可能 |
| 2 | 参照権限 | 保存期間の参照は全利用者 |
