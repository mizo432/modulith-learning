# EVT-EF-39 帳票復元が完了した

## 概要

アーカイブ帳票の復元が完了したことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-39                                                          |
| イベント名       | 帳票復元が完了した                                                 |
| 英語名           | `FormRestoreCompleted`                                             |
| 集約             | 帳票自動復元 (FormRestore)                                         |
| 関連ユースケース | UC-EF-061 帳票復元を要求する                                       |
| 関連情報         | INF-EF-24 帳票自動復元                                             |
| 発生条件         | アーカイブ帳票の復元が完了したとき                                 |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "FormRestore"                            |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `restoreId`       | String         | ✓   | 帳票自動復元の一意な識別子               |
| `formId`          | String         | ✓   | 復元対象の帳票識別子                     |
| `userId`          | String         | ✓   | 復元要求した利用者の識別子               |
| `restorePath`     | String         | ✓   | 復元先パス                               |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-38 帳票復元が要求された   | 要求時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.storageArchive.spi.formRestore.event.FormRestoreCompleted`
