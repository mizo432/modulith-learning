# EVT-EF-35 アーカイブ対象が確定した

## 概要

アーカイブ対象が確定したことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-35                                                          |
| イベント名       | アーカイブ対象が確定した                                           |
| 英語名           | `ArchiveTargetConfirmed`                                           |
| 集約             | アーカイブ対象 (ArchiveTarget)                                     |
| 関連ユースケース | UC-EF-057 アーカイブ対象を確定する                                 |
| 関連情報         | INF-EF-22 アーカイブ対象                                           |
| 発生条件         | アーカイブ対象が確定したとき                                       |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "ArchiveTarget"                          |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `archiveTargetId` | String         | ✓   | アーカイブ対象の一意な識別子             |
| `formId`          | String         | ✓   | アーカイブ対象の帳票識別子               |
| `archivePolicyId` | String         | ✓   | 適用するアーカイブポリシーの識別子       |
| `confirmedBy`     | String         | ✓   | 確定者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-34 アーカイブポリシーが変更された | ポリシー変更時に発生         |
| EVT-EF-036 アーカイブ処理が完了した | 処理完了時に発生             |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.storageArchive.spi.archiveTarget.event.ArchiveTargetConfirmed`
