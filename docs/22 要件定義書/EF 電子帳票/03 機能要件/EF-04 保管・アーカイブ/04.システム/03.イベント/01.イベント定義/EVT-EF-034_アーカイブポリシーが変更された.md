# EVT-EF-34 アーカイブポリシーが変更された

## 概要

アーカイブポリシーが変更されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-34                                                          |
| イベント名       | アーカイブポリシーが変更された                                     |
| 英語名           | `ArchivePolicyChanged`                                             |
| 集約             | アーカイブポリシー (ArchivePolicy)                                 |
| 関連ユースケース | UC-EF-055 アーカイブポリシーを変更する                             |
| 関連情報         | INF-EF-21 アーカイブポリシー                                       |
| 発生条件         | 管理者がアーカイブポリシーを変更したとき                           |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "ArchivePolicy"                          |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `archivePolicyId` | String         | ✓   | アーカイブポリシーの一意な識別子         |
| `policyName`      | String         | ✓   | ポリシー名                               |
| `changedBy`       | String         | ✓   | 変更者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-35 アーカイブ対象が確定した | 対象確定時に発生             |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.storageArchive.spi.archivePolicy.event.ArchivePolicyChanged`
