# EVT-EF-33 帳票が廃棄された

## 概要

帳票が廃棄されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-33                                                          |
| イベント名       | 帳票が廃棄された                                                   |
| 英語名           | `FormDisposed`                                                     |
| 集約             | 廃棄 (Disposal)                                                    |
| 関連ユースケース | UC-EF-053 帳票を廃棄する                                           |
| 関連情報         | INF-EF-20 廃棄                                                     |
| 発生条件         | 帳票が廃棄されたとき                                               |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "Disposal"                               |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `disposalId`      | String         | ✓   | 廃棄の一意な識別子                       |
| `formId`          | String         | ✓   | 廃棄対象の帳票識別子                     |
| `disposalReason`  | String         | ✓   | 廃棄理由                                 |
| `disposedBy`      | String         | ✓   | 廃棄実行者の利用者ID                     |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-32 保存期限が近づいた     | 期限接近時に発生             |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.storageArchive.spi.disposal.event.FormDisposed`
