# 論理データモデル

## 概要

EF-04 保管・アーカイブ業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    FORM_STORAGE
    {
        string FORM_STORAGE_ID PK "帳票保管ID"
        string 保存期間 "保存期間"
        string 廃棄候補 "廃棄候補"
        string 状態 "状態"
        string 作成日 "作成日"
        string state "状態(帳票保管)"
        enum variation "バリエーション(保管状態)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```
