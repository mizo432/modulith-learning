# アクター一覧

帳票管理業務領域（EF-02）でシステムと相互作用するアクターを定義します。

| ID     | アクター名               | 説明                                                 |
|--------|--------------------------|------------------------------------------------------|
| ACT-EF-01 | システム管理者         | 帳票定義、テンプレート、システム設定を管理           |
| ACT-EF-03 | 業務システム担当者     | 帳票の生成・登録・取込を行う                         |
| ACT-EF-05 | 帳票管理者             | 帳票情報、バージョン、状態を管理                     |
