# 論理データモデル

## 概要

EF-02 帳票管理業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    FORM
    {
        string FORM_ID PK "帳票ID"
        string 種類 "種類"
        string バージョン "バージョン"
        string 状態 "状態"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(帳票)"
        enum variation "バリエーション(帳票状態)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```
