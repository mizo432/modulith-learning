# EVT-EF-17 帳票定義が更新された

## 概要

帳票定義が更新されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-17                                                          |
| イベント名       | 帳票定義が更新された                                               |
| 英語名           | `FormDefinitionUpdated`                                            |
| 集約             | 帳票定義 (FormDefinition)                                          |
| 関連ユースケース | UC-EF-025 帳票定義を更新する                                       |
| 関連情報         | INF-EF-10 帳票定義                                                 |
| 発生条件         | 管理者が帳票定義を更新したとき                                     |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "FormDefinition"                         |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `formDefId`       | String         | ✓   | 帳票定義の一意な識別子                   |
| `formName`        | String         | ✗   | 帳票名                                   |
| `updatedBy`       | String         | ✓   | 更新者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-16 帳票定義が登録された   | 登録時に発生                 |
| EVT-EF-18 帳票定義が公開された   | 公開時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formManagement.spi.formDefinition.event.FormDefinitionUpdated`
