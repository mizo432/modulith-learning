# EVT-EF-23 帳票バージョンが作成された

## 概要

帳票の新しいバージョンが作成されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-23                                                          |
| イベント名       | 帳票バージョンが作成された                                         |
| 英語名           | `FormVersionCreated`                                               |
| 集約             | 帳票バージョン (FormVersion)                                       |
| 関連ユースケース | UC-EF-034 帳票バージョンを作成する                                 |
| 関連情報         | INF-EF-14 帳票バージョン                                           |
| 発生条件         | 帳票の新しいバージョンが作成されたとき                             |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "FormVersion"                            |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `versionId`       | String         | ✓   | 帳票バージョンの一意な識別子             |
| `formId`          | String         | ✓   | 関連する帳票の識別子                     |
| `versionNumber`   | int            | ✓   | バージョン番号                           |
| `createdBy`       | String         | ✓   | 作成者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-21 帳票が生成された       | 生成時に発生                 |
| EVT-EF-22 帳票が登録された       | 登録時に発生                 |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formManagement.spi.formVersion.event.FormVersionCreated`
