# EVT-EF-21 帳票が生成された

## 概要

帳票が生成されたことを表すドメインイベントです。

## イベント定義

| 項目             | 値                                                                 |
|------------------|--------------------------------------------------------------------|
| イベントID       | EVT-EF-21                                                          |
| イベント名       | 帳票が生成された                                                   |
| 英語名           | `FormGenerated`                                                    |
| 集約             | 帳票情報 (FormInfo)                                                |
| 関連ユースケース | UC-EF-031 帳票を生成する                                           |
| 関連情報         | INF-EF-13 帳票情報                                                 |
| 発生条件         | 帳票が生成されたとき                                               |

## イベントペイロード

| プロパティ        | 型             | 必須 | 説明                                     |
|-------------------|----------------|------|------------------------------------------|
| `eventId`         | UUID           | ✓   | イベントを一意に識別するID               |
| `occurredAt`      | LocalDateTime  | ✓   | イベントが発生した時刻                   |
| `aggregateId`     | String         | ✓   | 関連する集約ルートのID                   |
| `aggregateType`   | String         | ✓   | "FormInfo"                               |
| `version`         | int            | ✓   | 集約のバージョン                         |
| `formId`          | String         | ✓   | 帳票の一意な識別子                       |
| `formDefId`       | String         | ✓   | 関連する帳票定義の識別子                 |
| `systemId`        | String         | ✓   | 関連する業務システムの識別子             |
| `formTitle`       | String         | ✓   | 帳票タイトル                             |
| `storagePath`     | String         | ✓   | ストレージ上のファイルパス               |
| `generatedBy`     | String         | ✓   | 生成者の利用者ID                         |

## 不変条件

- 一度記録されたイベントは変更・削除しない
- 訂正が必要な場合は新しいイベントとして発行する

## 関連イベント

| イベント                        | 関係                         |
|---------------------------------|------------------------------|
| EVT-EF-22 帳票が登録された       | 登録時に発生                 |
| EVT-EF-23 帳票バージョンが作成された | バージョン作成時に発生       |

## 実装上の注意

- Java `record` 型で不変性を保証する
- `DomainEvent` インターフェースを実装する
- パッケージ配置: `undecided.electronicForm.formManagement.spi.formInfo.event.FormGenerated`
