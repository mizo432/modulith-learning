# 帳票バージョン管理

帳票バージョン管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-014 |
| 画面名           | 帳票バージョン管理 |
| 説明             | 帳票のバージョン履歴を管理する |
| 関連ユースケース | UC-EF-034 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 帳票名、検索バーを表示 |
| メインコンテンツ | 帳票バージョンの一覧をテーブル表示 |
| サイドバー | バージョン統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | バージョンID | テキスト | はい | 帳票バージョンの識別子 |
| 2 | 帳票ID | テキスト | はい | 関連する帳票の識別子 |
| 3 | バージョン番号 | 数値 | はい | バージョン番号 |
| 4 | 変更内容 | テキスト | いいえ | 変更内容の説明 |
| 5 | 変更者 | テキスト | はい | 変更者の利用者ID |
| 6 | 現在有効 | チェック | はい | 現在有効なバージョンフラグ |
| 7 | 作成日時 | 日付 | はい | 作成日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | バージョンを作成 | 新しい帳票バージョンを作成する |
| 2 | バージョンを参照 | 登録されたバージョンの詳細を確認する |
| 3 | バージョンを検索 | 条件に合致するバージョンを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | バージョン管理はシステム管理者・帳票管理者のみ可能 |
| 2 | 参照権限 | バージョン参照は全利用者 |
