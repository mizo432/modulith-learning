# 帳票テンプレート管理

帳票テンプレート管理画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-011 |
| 画面名           | 帳票テンプレート管理 |
| 説明             | 帳票テンプレートを管理する |
| 関連ユースケース | UC-EF-028 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | テンプレート名、検索バーを表示 |
| メインコンテンツ | 帳票テンプレートの一覧をテーブル表示 |
| サイドバー | テンプレート統計情報を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | テンプレートID | テキスト | はい | 帳票テンプレートの識別子 |
| 2 | 帳票定義ID | テキスト | はい | 関連する帳票定義の識別子 |
| 3 | テンプレート名 | テキスト | はい | テンプレート名 |
| 4 | ファイル形式 | 選択 | はい | ファイル形式（PDF、HTML、DOCX等） |
| 5 | バージョン | テキスト | はい | バージョン番号 |
| 6 | ファイルサイズ | 数値 | いいえ | ファイルサイズ（バイト） |
| 7 | 状態 | 選択 | はい | 状態（有効、無効） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | テンプレートをアップロード | 新しい帳票テンプレートをアップロードする |
| 2 | テンプレートを参照 | 登録されたテンプレートの詳細を確認する |
| 3 | テンプレートを検索 | 条件に合致するテンプレートを検索する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | テンプレート管理はシステム管理者・帳票管理者のみ可能 |
| 2 | 参照権限 | テンプレート参照は全利用者 |
