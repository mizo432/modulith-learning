# 帳票定義登録・編集

帳票定義登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-010 |
| 画面名           | 帳票定義登録・編集 |
| 説明             | 帳票定義を新規登録・編集する |
| 関連ユースケース | UC-EF-024, UC-EF-025 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 帳票名、保存ボタンを表示 |
| メインコンテンツ | 帳票定義のフォーム表示 |
| サイドバー | 関連テンプレート一覧を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 帳票種類 | 選択 | はい | 帳票種類（請求書、納品書等） |
| 2 | 帳票名 | テキスト | はい | 帳票名 |
| 3 | システムID | 選択 | はい | 関連する業務システム |
| 4 | レイアウト設定 | テキスト | いいえ | レイアウト設定（JSON形式） |
| 5 | 用紙サイズ | 選択 | いいえ | 用紙サイズ（A4、A3、B4等） |
| 6 | 印刷方向 | 選択 | いいえ | 印刷方向（縦、横） |
| 7 | 説明 | テキスト | いいえ | 帳票定義の説明 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 帳票定義を登録 | 新しい帳票定義を登録する |
| 2 | 帳票定義を更新 | 既存の帳票定義を更新する |
| 3 | 帳票定義を公開 | 帳票定義を公開する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 帳票定義の編集はシステム管理者・帳票管理者のみ可能 |
| 2 | 必須項目 | 帳票種類、帳票名、システムIDは必須 |
