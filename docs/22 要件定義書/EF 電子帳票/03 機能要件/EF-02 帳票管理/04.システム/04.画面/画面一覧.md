# 画面一覧

## 概要

本ファイルは、EF-02 帳票管理が提供する画面の一覧を定義します。

## 画面一覧

| 項番 | 画面ID | 画面名 | 主な利用者 | 画面の目的 |
|------|--------|--------|-----------|-----------|
| 01 | SCR-EF-009 | 帳票定義一覧 | システム管理者, 帳票管理者 | 帳票定義の一覧を確認・管理する |
| 02 | SCR-EF-010 | 帳票定義登録・編集 | システム管理者, 帳票管理者 | 帳票定義を新規登録・編集する |
| 03 | SCR-EF-011 | 帳票テンプレート管理 | システム管理者, 帳票管理者 | 帳票テンプレートを管理する |
| 04 | SCR-EF-012 | 帳票生成設定 | システム管理者, 帳票管理者 | 帳票生成時のパラメータを設定する |
| 05 | SCR-EF-013 | 帳票情報一覧 | 利用者 | 生成された帳票の一覧を確認する |
| 06 | SCR-EF-014 | 帳票バージョン管理 | システム管理者, 帳票管理者 | 帳票のバージョン履歴を管理する |

## 画面種類

| 種類 | 説明 |
|------|------|
| 一覧画面 | 情報の一覧表示・検索・ソートを行う画面 |
| 詳細画面 | 個別情報の詳細表示・編集を行う画面 |
| 設定画面 | システム設定やポリシー設定を行う画面 |

## 主な利用者

| 利用者 | 説明 |
|--------|------|
| システム管理者 | システム全体の設定・管理を行う管理者 |
| 帳票管理者 | 帳票定義・テンプレートの管理を行う担当者 |
| 利用者 | 帳票を利用する一般利用者 |
