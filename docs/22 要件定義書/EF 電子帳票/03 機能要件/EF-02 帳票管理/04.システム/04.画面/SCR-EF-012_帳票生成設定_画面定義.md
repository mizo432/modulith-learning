# 帳票生成設定

帳票生成設定画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-EF-012 |
| 画面名           | 帳票生成設定 |
| 説明             | 帳票生成時のパラメータを設定する |
| 関連ユースケース | UC-EF-030 |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | 設定名、保存ボタンを表示 |
| メインコンテンツ | 帳票生成設定のフォーム表示 |
| サイドバー | 関連帳票定義一覧を表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 帳票定義ID | 選択 | はい | 関連する帳票定義 |
| 2 | 出力形式 | 選択 | はい | 出力形式（PDF、HTML等） |
| 3 | 宛先種類 | 選択 | はい | 宛先種類（ストレージ、メール、API等） |
| 4 | 宛先設定 | テキスト | いいえ | 宛先設定（JSON形式） |
| 5 | 自動生成 | チェック | はい | 自動生成フラグ |
| 6 | 説明 | テキスト | いいえ | 生成設定の説明 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 生成設定を変更 | 帳票生成設定を変更する |
| 2 | 生成設定を参照 | 登録された設定の詳細を確認する |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 編集権限 | 生成設定の変更はシステム管理者・帳票管理者のみ可能 |
| 2 | 必須項目 | 帳票定義ID、出力形式、宛先種類は必須 |
