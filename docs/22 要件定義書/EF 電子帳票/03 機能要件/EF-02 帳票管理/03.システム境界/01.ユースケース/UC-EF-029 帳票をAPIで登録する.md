# UC-EF-029 帳票をAPIで登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-029 |
| ユースケース名 | 帳票をAPIで登録する |
| 英語名 | Register Form via API |
| 説明 | 業務システム担当者がAPI経由で帳票を登録する |
| 関連アクター | ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-10 |
| 外部システム | ES-EF-04（業務システム） |
| 関連画面 | - |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが業務システム担当者の権限を持っていること

## 基本フロー

1. 業務システムが帳票登録APIを呼び出す
2. 帳票ファイル、メタデータ（帳票種類、作成者、作成日など）を指定する
3. システムが帳票ファイルをストレージに保存する
4. 帳票情報をデータベースに登録する
5. 登録結果を返す

## 代替フロー

- **2a. 入力が不完全な場合**
  - 必須パラメータが不足している場合、エラーを返す
  - 業務システムは入力を修正して再試行する

- **3a. 帳票登録に失敗した場合**
  - エラーメッセージを返す
  - 業務システムはエラーを処理する

## 後置条件

- 帳票ファイルがストレージに保存される
- 帳票情報がデータベースに登録される

| 情報ID | 情報名 | 使用目的 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須パラメータ | 帳票ファイル、メタデータは必須 |
| 2 | ファイル形式 | PDF、Excel、Word、PowerPointに対応 |
| 3 | サイズ制限 | 帳票ファイルのサイズは100MB以内 |
