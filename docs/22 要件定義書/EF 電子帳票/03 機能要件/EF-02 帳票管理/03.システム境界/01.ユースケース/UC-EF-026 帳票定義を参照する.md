# UC-EF-026 帳票定義を参照する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-026 |
| ユースケース名 | 帳票定義を参照する |
| 英語名 | View Form Definition |
| 説明 | システム管理者または業務システム担当者が登録された帳票定義一覧・詳細を確認する |
| 関連アクター | ACT-EF-01（システム管理者）、ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-08 |
| 外部システム | - |
| 関連画面 | SCR-007（帳票定義一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者または業務システム担当者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票定義一覧」画面（SCR-007）にアクセスする
2. システムが登録された帳票定義一覧を表示する
3. ユーザーが対象の帳票定義を選択する
4. システムが帳票定義の詳細情報を表示する

## 代替フロー

- **2a. 帳票定義が登録されていない場合**
  - 「帳票定義が登録されていません」というメッセージを表示する
  - ユーザーは帳票定義を登録するか、他の操作を行う

## 後置条件

- 帳票定義情報が表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-10 | 帳票定義情報 | 参照対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある帳票定義のみ表示 |
| 2 | 権限制限 | システム管理者または業務システム担当者のみ参照可能 |
