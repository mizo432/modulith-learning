# UC-EF-034 帳票バージョンを管理する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-034 |
| ユースケース名 | 帳票バージョンを管理する |
| 英語名 | Manage Form Versions |
| 説明 | 帳票管理者が帳票のバージョン履歴を確認・管理する |
| 関連アクター | ACT-EF-05（帳票管理者） |
| 優先度 | 中 |
| ビジネスユースケース | BUC-EF-11 |
| 外部システム | - |
| 関連画面 | SCR-003（帳票詳細・プレビュー） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票管理者の権限を持っていること
- 対象の帳票が存在すること

## 基本フロー

1. ユーザーが「帳票詳細・プレビュー」画面（SCR-003）にアクセスする
2. 対象の帳票を選択する
3. 「バージョン履歴」タブを選択する
4. システムが帳票のバージョン履歴を表示する（バージョン番号、更新日、更新者など）
5. ユーザーが対象のバージョンを選択する
6. システムが選択したバージョンの帳票ファイルをプレビュー表示する

## 代替フロー

- **4a. バージョン履歴が存在しない場合**
  - 「バージョン履歴がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 帳票のバージョン履歴が表示される
- 選択したバージョンの帳票ファイルがプレビュー表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-11 | 帳票情報 | バージョン履歴の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある帳票のみ表示 |
| 2 | 権限制限 | 帳票管理者のみ参照可能 |
| 3 | バージョン管理 | 更新ごとにバージョンが自動記録される |
