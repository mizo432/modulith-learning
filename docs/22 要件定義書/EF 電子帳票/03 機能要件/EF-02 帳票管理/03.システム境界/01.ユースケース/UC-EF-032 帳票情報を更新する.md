# UC-EF-032 帳票情報を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-032 |
| ユースケース名 | 帳票情報を更新する |
| 英語名 | Update Form Information |
| 説明 | 帳票管理者が帳票のメタデータ、状態を更新する |
| 関連アクター | ACT-EF-05（帳票管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-11 |
| 外部システム | - |
| 関連画面 | SCR-002（帳票一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが帳票管理者の権限を持っていること
- 更新対象の帳票が存在すること

## 基本フロー

1. ユーザーが「帳票一覧」画面（SCR-002）にアクセスする
2. 更新対象の帳票を選択する
3. 「帳票情報を更新」ボタンをクリックする
4. 帳票のメタデータ（帳票名、説明、タグなど）を修正する
5. 帳票の状態（ドラフト、公開、アーカイブなど）を変更する（任意）
6. 入力を保存する
7. システムが帳票情報を更新する
8. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

## 後置条件

- 帳票情報がシステムに更新される
