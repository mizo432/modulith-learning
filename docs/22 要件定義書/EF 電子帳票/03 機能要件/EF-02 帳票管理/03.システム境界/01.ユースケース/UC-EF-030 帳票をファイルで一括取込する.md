# UC-EF-030 帳票をファイルで一括取込する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-030 |
| ユースケース名 | 帳票をファイルで一括取込する |
| 英語名 | Batch Import Forms |
| 説明 | 業務システム担当者がファイルアップロードにより帳票を一括取込する |
| 関連アクター | ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-10 |
| 外部システム | - |
| 関連画面 | SCR-002（帳票一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが業務システム担当者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票一覧」画面（SCR-002）にアクセスする
2. 「一括取込」ボタンをクリックする
3. 帳票ファイルをアップロードする（ZIPファイルまたは複数ファイル選択）
4. 取込オプション（帳票種類、メタデータなど）を指定する（任意）
5. 取込を開始する
6. システムがファイルを処理して帳票を登録する
7. 取込結果を表示する

## 代替フロー

- **3a. ファイル形式が不正な場合**
  - エラーメッセージを表示する
  - ユーザーは正しい形式のファイルをアップロードして再試行する

- **4a. 取込に失敗したファイルがある場合**
  - 失敗したファイルとエラー理由を表示する
  - ユーザーはエラーを修正して再試行する

## 後置条件

- 帳票ファイルがストレージに保存される
- 帳票情報がデータベースに登録される

|--------|--------|----------|

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | ファイル形式 | PDF、Excel、Word、PowerPoint、ZIPに対応 |
| 2 | サイズ制限 | 1ファイルあたり100MB以内 |
| 3 | 件数制限 | 1回の取込で最大1000件 |
