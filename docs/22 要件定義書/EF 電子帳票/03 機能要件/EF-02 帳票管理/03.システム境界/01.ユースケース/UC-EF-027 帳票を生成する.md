# UC-EF-027 帳票を生成する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-027 |
| ユースケース名 | 帳票を生成する |
| 英語名 | Generate Form |
| 説明 | 業務システム担当者がテンプレートとデータから帳票ファイルを生成する |
| 関連アクター | ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-09 |
| 外部システム | ES-EF-04（業務システム） |
| 関連画面 | - |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが業務システム担当者の権限を持っていること
- 帳票定義が存在すること

## 基本フロー

1. 業務システムが帳票生成APIを呼び出す
2. テンプレートID、データ、出力形式などを指定する
3. システムがテンプレートとデータを結合して帳票ファイルを生成する
4. 生成された帳票ファイルをストレージに保存する
5. 帳票情報をデータベースに登録する
6. 生成結果を返す

## 代替フロー

- **2a. 入力が不完全な場合**
  - 必須パラメータが不足している場合、エラーを返す
  - 業務システムは入力を修正して再試行する

- **3a. 帳票生成に失敗した場合**
  - エラーメッセージを返す
  - 業務システムはエラーを処理する

## 後置条件

- 帳票ファイルがストレージに保存される
- 帳票情報がデータベースに登録される

| 番号 | 制約事項 | 説明 |
