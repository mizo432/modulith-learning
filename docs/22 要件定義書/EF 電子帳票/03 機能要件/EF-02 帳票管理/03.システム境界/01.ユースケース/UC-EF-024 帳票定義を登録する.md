# UC-EF-024 帳票定義を登録する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-024 |
| ユースケース名 | 帳票定義を登録する |
| 英語名 | Register Form Definition |
| 説明 | システム管理者が帳票種類、レイアウト、テンプレートを登録する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-08 |
| 外部システム | - |
| 関連画面 | SCR-007（帳票定義一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること

## 基本フロー

1. ユーザーが「帳票定義一覧」画面（SCR-007）にアクセスする
2. 「帳票定義を登録」ボタンをクリックする
3. 帳票種類、帳票名、レイアウト、テンプレートファイルを入力する
4. 帳票のメタデータ（作成者、作成日、説明など）を入力する
5. 入力を保存する
6. システムが帳票定義を登録する
7. 登録完了メッセージを表示する

## 代替フロー

- **3a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **3b. 重複した帳票名の場合**
  - 既に同じ帳票名が存在する場合、エラーメッセージを表示する
  - ユーザーは別の帳票名を入力して再試行する

## 後置条件

- 帳票定義がシステムに登録される

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 帳票種類、帳票名、テンプレートファイルは必須入力 |
| 2 | 重複禁止 | 同じ帳票名は登録できない |
| 3 | ファイル形式 | テンプレートファイルはPDF、Excel、Word、PowerPointに対応 |
