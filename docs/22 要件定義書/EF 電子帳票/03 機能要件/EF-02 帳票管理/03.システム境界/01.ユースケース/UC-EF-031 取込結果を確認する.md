# UC-EF-031 取込結果を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-031 |
| ユースケース名 | 取込結果を確認する |
| 英語名 | View Import Result |
| 説明 | 業務システム担当者が一括取込の結果を確認する |
| 関連アクター | ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-10 |
| 外部システム | - |
| 関連画面 | SCR-002（帳票一覧） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが業務システム担当者の権限を持っていること
- 一括取込が実行されていること

## 基本フロー

1. ユーザーが「帳票一覧」画面（SCR-002）にアクセスする
2. 「取込結果」タブを選択する
3. システムが取込結果一覧を表示する（成功件数、失敗件数など）
4. ユーザーが対象の取込結果を選択する
5. システムが詳細な取込結果を表示する（成功したファイル、失敗したファイルとエラー理由）

## 代替フロー

- **3a. 取込結果が存在しない場合**
  - 「取込結果がありません」というメッセージを表示する
  - ユーザーは他の操作を行う

## 後置条件

- 取込結果が表示される
