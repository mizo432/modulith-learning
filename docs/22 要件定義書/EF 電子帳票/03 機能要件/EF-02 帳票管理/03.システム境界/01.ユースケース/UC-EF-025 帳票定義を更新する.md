# UC-EF-025 帳票定義を更新する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-025 |
| ユースケース名 | 帳票定義を更新する |
| 英語名 | Update Form Definition |
| 説明 | システム管理者が既存の帳票定義を修正する |
| 関連アクター | ACT-EF-01（システム管理者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-08 |
| 外部システム | - |
| 関連画面 | SCR-008（帳票定義登録・編集） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーがシステム管理者の権限を持っていること
- 更新対象の帳票定義が存在すること

## 基本フロー

1. ユーザーが「帳票定義一覧」画面（SCR-007）にアクセスする
2. 更新対象の帳票定義を選択する
3. 「帳票定義を更新」ボタンをクリックする
4. 帳票種類、帳票名、レイアウト、テンプレートファイルなどを修正する
5. 帳票のメタデータを修正する
6. 入力を保存する
7. システムが帳票定義を更新する
8. 更新完了メッセージを表示する

## 代替フロー

- **4a. 入力が不完全な場合**
  - 必須項目が未入力の場合、エラーメッセージを表示する
  - ユーザーは入力を修正して再試行する

- **4b. 重複した帳票名の場合**
  - 他帳票と同じ帳票名に変更しようとした場合、エラーメッセージを表示する
  - ユーザーは別の帳票名を入力して再試行する

## 後置条件

- 帳票定義がシステムに更新される
- バージョン履歴が記録される

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 必須項目 | 帳票種類、帳票名、テンプレートファイルは必須入力 |
| 2 | 重複禁止 | 同じ帳票名は登録できない |
| 3 | バージョン管理 | 更新ごとにバージョンが記録される |
