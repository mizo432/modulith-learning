# UC-EF-028 帳票生成結果を確認する

ユースケースの詳細を定義します。

## 概要

| 項目 | 内容 |
|------|------|
| ユースケースID | UC-EF-028 |
| ユースケース名 | 帳票生成結果を確認する |
| 英語名 | View Form Generation Result |
| 説明 | 業務システム担当者が生成された帳票ファイルを確認する |
| 関連アクター | ACT-EF-03（業務システム担当者） |
| 優先度 | 高 |
| ビジネスユースケース | BUC-EF-09 |
| 外部システム | - |
| 関連画面 | SCR-003（帳票詳細・プレビュー） |

## 前置条件

- ユーザーがシステムにログインしていること
- ユーザーが業務システム担当者の権限を持っていること
- 帳票が生成されていること

## 基本フロー

1. ユーザーが「帳票詳細・プレビュー」画面（SCR-003）にアクセスする
2. 生成された帳票を選択する
3. システムが帳票ファイルをプレビュー表示する
4. ユーザーが帳票内容を確認する

## 代替フロー

- **2a. 帳票が見つからない場合**
  - エラーメッセージを表示する
  - ユーザーは他の帳票を選択するか、他の操作を行う

## 後置条件

- 帳票ファイルがプレビュー表示される

## 関連情報

| 情報ID | 情報名 | 使用目的 |
|--------|--------|----------|
| INF-EF-11 | 帳票情報 | 確認対象の情報 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 表示制限 | 権限のある帳票のみ表示 |
| 2 | プレビュー | PDF.jsでブラウザ内表示、Office文書はPDF変換後表示 |
