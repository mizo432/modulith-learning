# 電子帳票 非機能要件

## 概要

本ドキュメントは、電子帳票（EF）事業領域の非機能要件を定義します。

## 非機能要件一覧

| 番号 | 項目 | 要件 | 説明 |
|------|------|------|------|
| NFR-01 | テナント構成 | シングルテナント | 1企業・組織が利用する構成 |
| NFR-02 | データベース | PostgreSQL | 関係データベースとしてPostgreSQLを使用 |
| NFR-03 | 本番ストレージ | Amazon S3 | 本番環境での帳票ファイル保存にAmazon S3を使用 |
| NFR-04 | 開発ストレージ | MinIO | 開発環境での帳票ファイル保存にMinIOを使用 |
| NFR-05 | 帳票プレビュー | PDF.js | ブラウザでの帳票プレビューにPDF.jsを使用 |
| NFR-06 | Office変換 | LibreOffice | Office文書のPDF変換にLibreOfficeを使用 |
| NFR-07 | アーカイブ方式 | アプリケーションによる移行制御 | アプリケーション側でアーカイブ移行を制御 |
| NFR-08 | 復元方式 | 利用者の閲覧要求による自動復元 | 利用者が閲覧を要求した際に自動復元 |
| NFR-09 | 業務システム識別 | system_idによる識別 | 帳票データに業務システムを識別する情報を持たせる |
| NFR-10 | 認証方式 | OIDC等 | OIDC等の標準認証プロトコルを使用 |
| NFR-11 | 権限管理 | 組織・部門・利用者・帳票単位 | 組織・部門・利用者・帳票単位の権限管理 |
| NFR-12 | アーカイブストレージクラス | Glacier Flexible Retrieval等 | アーカイブ用ストレージクラスとしてGlacier Flexible Retrievalを使用 |
| NFR-13 | 保存期間 | 帳票種類ごとに設定 | 帳票種類ごとに保存期間を設定可能 |
| NFR-14 | 監査ログの改ざん防止 | 監査ログは改ざんできないように保護 | 監査ログは改ざん防止措置を講じる |
| NFR-15 | 廃棄方式 | 廃棄承認・完全削除・復元不可 | 廃棄処理は承認が必要で、一度廃棄すると復元できない |
