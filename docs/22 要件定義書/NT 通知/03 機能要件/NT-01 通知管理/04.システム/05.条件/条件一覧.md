# 条件一覧

通知管理業務領域のビジネスルール（条件）を定義します。

| 条件ID   | 条件名               | 英語名                     | 種類         | 説明                                               | 関連ユースケース |
|----------|----------------------|----------------------------|--------------|----------------------------------------------------|------------------|
| RL-NT-01 | 通知の検索条件       | Notification Search Filter | 意思決定支援 | 受信者ID・通知タイプ・未読/既読で検索可能          | UC-NT-002, UC-NT-003 |
| RL-NT-02 | 既読マークの冪等性   | Read Mark Idempotency      | ポリシー     | 既に既読の通知を再度既読にしても問題ない           | UC-NT-004        |
| RL-NT-03 | 通知タイプの制約     | Notification Type Constraint | ポリシー | 通知タイプは定義された8種類のみ使用可能            | UC-NT-001        |
