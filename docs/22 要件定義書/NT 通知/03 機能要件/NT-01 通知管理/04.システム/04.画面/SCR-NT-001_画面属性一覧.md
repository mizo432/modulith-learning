# SCR-NT-001 画面属性一覧

## 画面概要

| 項目 | 値 |
|------|-----|
| 画面ID | SCR-NT-001 |
| 画面名 | 通知一覧画面 |
| 説明 | 通知の一覧を表示し、既読マークを行う画面 |
| 関連ユースケース | UC-NT-002, UC-NT-003, UC-NT-004 |

## 画面項目一覧

| 序号 | 項目名 | 項目タイプ | 型 | 必須/任意 | 初期値 | 制約 |
|------|--------|-----------|-----|-----------|--------|------|
| 1 | タイトル | 表示 | string | 必須 | - | 最大200文字 |
| 2 | 本文 | 表示 | string | 必須 | - | 最大2000文字 |
| 3 | 通知タイプ | 表示 | enum | 必須 | - | MENTION, ASSIGNEE_CHANGE, DUE_DATE, AWAITING_DECISION, APPROVAL_RESULT, JOB_EXECUTION_RESULT, SYSTEM, CUSTOM |
| 4 | 送信元事業領域 | 表示 | string | 必須 | - | 最大50文字 |
| 5 | 既読フラグ | 表示 | boolean | 必須 | false | - |
| 6 | 作成日時 | 表示 | datetime | 必須 | - | - |

## 画面レイアウト

| 領域名 | 説明 | 含まれる項目 |
|--------|------|-------------|
| 通知一覧領域 | 通知の一覧を表示する領域 | タイトル, 通知タイプ, 送信元事業領域, 既読フラグ, 作成日時 |
| 通知詳細領域 | 選択した通知の詳細を表示する領域 | タイトル, 本文, 通知タイプ, 送信元事業領域, 既読フラグ, 作成日時 |

## 画面操作

| 操作名 | トリガー | 説明 | 遷移先画面 |
|--------|---------|------|-----------|
| 通知一覧取得 | 画面表示 | 通知の一覧を取得して表示する | - |
| 未読通知一覧取得 | 画面表示 | 未読の通知の一覧を取得して表示する | - |
| 既読マーク | ボタンクリック | 選択した通知を既読にする | - |
