# INF-NT-01-01 通知 情報属性一覧

## 概要

| 項目 | 値 |
|------|-----|
| 情報ID | INF-NT-01-01 |
| 情報名 | 通知 |
| エンティティ名 | NOTIFICATION |
| 分類 | E (イベント) |

## 単一性・同一性・カテゴリ

| 要素 | 定義 |
|------|------|
| 単一性 (Oneness) | 通知は1つの通知イベントを表す |
| 同一性 (Sameness) | notification_idで一意に識別される |
| カテゴリ (Category) | 通知は通知管理の通知分類に属する |
