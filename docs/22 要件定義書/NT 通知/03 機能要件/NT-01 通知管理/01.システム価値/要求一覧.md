# 要求一覧

初期要望から抽出した機能要求と非機能要求を定義します。

## 機能要求

| ID | 要求名 | 概要 | 優先度 |
|----|--------|------|--------|
| FR-NT-01 | 通知送信 | 事業領域からシステム内通知を送信する | 高 |
| FR-NT-02 | 通知一覧取得 | 受信者ごとの通知を一覧で取得する | 高 |
| FR-NT-03 | 通知詳細取得 | 通知の詳細内容を取得する | 高 |
| FR-NT-04 | 未読通知取得 | 未読の通知を一覧で取得する | 高 |
| FR-NT-05 | 既読マーク | 通知を既読としてマークする | 高 |

## 非機能要求

| ID | 要求名 | 概要 |
|----|--------|------|
| NFR-NT-01 | 事業領域独立性 | 各事業領域は独立して通知を送信可能 |
| NFR-NT-02 | 永続化 | 通知履歴をデータベースに永続化する |
| NFR-NT-03 | ID生成 | Snowflake IDを用いて分散環境で一意なIDを生成する |
| NFR-NT-04 | 論理削除 | 通知は論理削除により削除日時を記録する |
