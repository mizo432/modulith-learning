# 論理データモデル

## 概要

ER-01 元号管理業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    ERA
    {
        string ERA_ID PK "元号ID"
        string 名称 "名称"
        string 英字略名 "英字略名"
        string 適用開始日 "適用開始日"
        string 適用終了日 "適用終了日"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(元号)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| 元号 | ERA_ID | string | true | 元号ID |
