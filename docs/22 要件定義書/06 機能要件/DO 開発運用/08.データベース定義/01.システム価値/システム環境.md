# システム環境

システムが動作する環境を定義します。

## 動作環境

| 項目                     | 内容                                    |
|--------------------------|-----------------------------------------|
| アプリケーションサーバー | Spring Boot                             |
| データベース             | PostgreSQL                              |
| キャッシュ               | インメモリキャッシュ（有効期間5分以内） |

## 外部システム連携

| 外部システム名 | 連携方法 | 説明                                       |
|----------------|----------|--------------------------------------------|
| データベース   | JDBC接続 | データベースメタデータを取得するための接続 |
