# ユーザーストーリーマップ

データベース定義のユーザーストーリーをマップします。

## ユーザーストーリーマップ

### 活動フェーズ: データベース参照

| 優先度 | ユーザーストーリー                       | ユースケース |
|--------|------------------------------------------|--------------|
| 高     | 開発者はデータベースの一覧を確認したい   | UC-01        |
| 高     | 開発者はスキーマの一覧を確認したい       | UC-02        |
| 高     | 開発者はテーブルとViewの一覧を確認したい | UC-03        |
| 高     | 開発者はテーブルの定義を確認したい       | UC-04        |
| 高     | 開発者はViewの定義を確認したい           | UC-05        |

## スライス

### スライス1: 基本機能

- UC-01 データベース一覧を取得する
- UC-02 スキーマ一覧を取得する
- UC-03 テーブル・View一覧を取得する

### スライス2: 詳細機能

- UC-04 テーブル定義を取得する
- UC-05 View定義を取得する
