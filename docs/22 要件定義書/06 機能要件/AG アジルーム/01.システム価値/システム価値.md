# システム価値

アジルーム（Agiloom）が実現すべき価値を定義します。

## 価値

Scrumに基づくアジャイルソフトウェア開発プロジェクトを効率的に管理し、チームの生産性と可視性を向上させる。

### 具体的な価値

1. **プロジェクトの可視性向上**: プロダクトからタスクまでの階層構造を明確にし、進捗状況をリアルタイムで把握できる。
2. **チーム協働の促進**: チームメンバーの役割を明確にし、スプリント計画から振り返りまでのフルサイクルをサポートする。
3. **アジャイルプラクティスの定着**:
   スプリントプランニング、デイリースクラム、レビュー、レトロスペクティブなどのScrumイベントをシステム化し、プラクティスの定着を支援する。
4. **データ駆動な意思決定**: 各レベルのダッシュボードにより、プロダクトオーナーやスクラムマスターがデータに基づいた意思決定を行える。
