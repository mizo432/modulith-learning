# 概要

本ドキュメントは、元号登録業務領域の機能要件の概要を定義します。
元号のマスターデータを管理する機能を提供します。

## 事業領域情報

| 項目         | 値       |
|--------------|----------|
| 事業領域     | 汎用     |
| 業務領域     | 元号登録 |
| 業務領域英名 | EraReg   |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 元号登録業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号  | ユースケース名         | 説明                               | 優先度 |
|-------|------------------------|------------------------------------|--------|
| UC-01 | 元号一覧を取得する     | 元号の一覧を取得する               | 高     |
| UC-02 | 元号を登録する         | 新規元号を登録する                 | 高     |
| UC-03 | 元号を更新する         | 既存元号を更新する                 | 高     |
| UC-04 | 元号を削除する         | 元号を削除する                     | 中     |
| UC-05 | 日付から元号を取得する | 指定日付に適用される元号を取得する | 高     |
| UC-06 | 現在の元号を取得する   | 現在有効な元号を取得する           | 高     |
