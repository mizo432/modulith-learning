# 概要

本ドキュメントは、税率登録業務領域の機能要件の概要を定義します。
税率のマスターデータを管理する機能を提供します。

## 事業領域情報

| 項目         | 値         |
|--------------|------------|
| 事業領域     | 関連付け   |
| 業務領域     | 税率登録   |
| 業務領域英名 | TaxRateReg |

## RDRA 4レイヤー

1. **システム価値レイヤー**: システムが実現すべき価値を定義
2. **外部環境レイヤー**: 税率登録業務とビジネスユースケースを定義
3. **システム境界レイヤー**: ユースケース、アクター、画面を定義
4. **システムレイヤー**: 情報、状態、イベントを定義

## 機能一覧

| 番号  | ユースケース名             | 説明                                           | 優先度 |
|-------|----------------------------|------------------------------------------------|--------|
| UC-01 | 税率一覧を取得する         | 税率の一覧を取得する                           | 高     |
| UC-02 | 税率を登録する             | 新規税率を登録する                             | 高     |
| UC-03 | 税率を更新する             | 既存税率を更新する                             | 高     |
| UC-04 | 税率を削除する             | 税率を削除する                                 | 中     |
| UC-05 | 日付から税率を取得する     | 指定日付に適用される税率を取得する             | 高     |
| UC-06 | 日付と種類で税率を取得する | 指定日付と税率種類区分に一致する税率を取得する | 高     |
| UC-07 | 有効な税率を取得する       | 現在有効な税率を種類区分で取得する             | 高     |
