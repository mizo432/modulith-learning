# 関連付け

## 概要

本ドキュメントは、関連付け（AS）事業領域の要件定義をまとめます。

AS 関連付けは、組織・部署・従業員・会社・店舗などの実体とその関連付けを管理する支援モジュールです。Party Roleパターンを採用し、実体(Party)とロール(Role)を分離することで柔軟な関連付け構造を実現します。

詳細は[概要](overview.md)を参照してください。
