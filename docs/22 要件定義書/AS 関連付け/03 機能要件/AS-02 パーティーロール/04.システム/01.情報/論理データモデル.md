# 論理データモデル

## 概要

AS-02 パーティーロール業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    PARTY_ROLE
    {
        string PARTY_ROLE_ID PK "PartyRoleID"
        string party "Party"
        string roleタイプ "Roleタイプ"
        string 有効期間 "有効期間"
        string 状態 "状態"
        string 作成日 "作成日"
        string state "状態(PartyRole)"
        enum variation "バリエーション(Roleタイプ)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```
