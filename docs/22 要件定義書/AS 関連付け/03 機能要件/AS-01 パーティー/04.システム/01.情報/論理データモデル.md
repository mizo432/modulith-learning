# 論理データモデル

## 概要

AS-01 パーティー業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    PARTY
    {
        string PARTY_ID PK "PartyID"
        string 名前 "名前"
        string タイプ "タイプ"
        string 識別子 "識別子"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(Party)"
        enum variation "バリエーション(Partyタイプ)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| Party | PARTY_ID | string | true | PartyID |
