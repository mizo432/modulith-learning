# ビジネスルール

## 概要

AS-01 パーティー業務領域のビジネスルールを定義します。

## ビジネスルール一覧

### BR-01 郵政バーコード値の生成ルール

住所を設定する際、郵送する郵便物に宛先毎に付与するカスタマバーコード値を生成・保持する。カスタマバーコード値は日本郵政の郵便バーコード仕様に従い、23桁で構成される。

#### 構成

| 項目 | 桁数 | 説明 |
|------|------|------|
| スタートコード | 1桁 | バーコードの開始を示す固定値 |
| 郵便番号 | 7桁 | ハイフンを除いた7桁の郵便番号 |
| 住所表示番号 | 13桁 | 町域名以降の住所をバーコードデータに変換した値 |
| チェックデジット | 1桁 | 郵便番号～住所表示番号の合計が19の倍数となるように生成 |
| ストップコード | 1桁 | バーコードの終了を示す固定値 |

#### 計算ルール

1. **スタートコード**: 固定値を1桁設定する。
2. **郵便番号**: 住所に紐づく7桁の郵便番号（ハイフン除く）を設定する。
3. **住所表示番号**: 町域名以降の住所要素（市・字・丁目・番地・号など）を日本郵政の住所表示番号変換表に従ってバーコードデータに変換し、13桁設定する。
4. **チェックデジット**: 郵便番号（7桁）＋住所表示番号（13桁）の各桁の合計を計算し、その合計が19の倍数となるような1桁の値を生成する。
   - 計算式: `チェックデジット = (19 - (郵便番号の各桁の和 + 住所表示番号の各桁の和) mod 19) mod 19`
5. **ストップコード**: 固定値を1桁設定する。

#### 参考

- [日本郵政 郵便番号・バーコードマニュアル](https://www.post.japanpost.jp/service/search/zipcode/zipmanual/p17.html)
