# AS-ORG-ROLE 組織ロール

## 概要

本ドキュメントは、AS-ORG-ROLE 組織ロールの機能要件を定義します。

組織ロール(OrganizationRole)は、組織・部署・会社・店舗に特化したロール管理業務領域です。階層構造や権限範囲を管理し、組織図の構築を可能にします。会社や店舗の管理、部署の階層関係、権限範囲の定義を担当します。

## 業務領域情報

- 業務領域コード: AS-04
- 業務領域名: 組織ロール
- 業務領域英名: OrganizationRole

## 主な責務

- 組織階層の管理
- 部署構造の管理
- 会社・店舗の管理
- 権限範囲の定義
