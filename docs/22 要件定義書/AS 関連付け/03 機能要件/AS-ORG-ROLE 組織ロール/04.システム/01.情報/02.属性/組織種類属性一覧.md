# 組織種類属性一覧

AS-ORG-ROLE 組織ロール業務領域で扱う「組織種類」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| org_type_code | Code     | *  | Y    | 組織種類コード               |
| name          | String   |    | Y    | 組織種類名                   |
| description   | Text     |    | N    | 組織種類の説明               |
| created_at    | DateTime |    | Y    | 作成日時                     |
