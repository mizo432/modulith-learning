# 会社属性一覧

AS-ORG-ROLE 組織ロール業務領域で扱う「会社」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| company_id    | SnowflakeID | * | Y  | 会社の一意な識別子           |
| org_id        | SnowflakeID |  | Y    | 組織の識別子                 |
| company_code  | String   |    | Y    | 会社コード                   |
| name          | String   |    | Y    | 会社名                       |
| representative | String  |    | N    | 代表者名                     |
| address       | String   |    | N    | 住所                         |
| phone         | String   |    | N    | 電話番号                     |
| fax           | String   |    | N    | ファックス番号               |
| email         | String   |    | N    | メールアドレス               |
| url           | String   |    | N    | URL                          |
| valid_from    | DateTime |    | Y    | 有効開始日                   |
| valid_to      | DateTime |    | N    | 有効終了日                   |
| description   | Text     |    | N    | 会社の説明                   |
| created_at    | DateTime |    | Y    | 作成日時                     |
| updated_at    | DateTime |    | Y    | 最終更新日時                 |
