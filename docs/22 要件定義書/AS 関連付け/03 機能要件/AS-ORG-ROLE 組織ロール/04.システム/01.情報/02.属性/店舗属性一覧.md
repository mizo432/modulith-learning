# 店舗属性一覧

AS-ORG-ROLE 組織ロール業務領域で扱う「店舗」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| store_id      | SnowflakeID | * | Y  | 店舗の一意な識別子           |
| org_id        | SnowflakeID |  | Y    | 組織の識別子                 |
| company_id    | SnowflakeID |  | Y    | 会社の識別子                 |
| store_code    | String   |    | Y    | 店舗コード                   |
| name          | String   |    | Y    | 店舗名                       |
| address       | String   |    | N    | 住所                         |
| phone         | String   |    | N    | 電話番号                     |
| fax           | String   |    | N    | ファックス番号               |
| email         | String   |    | N    | メールアドレス               |
| manager_name  | String   |    | N    | 店長名                       |
| valid_from    | DateTime |    | Y    | 有効開始日                   |
| valid_to      | DateTime |    | N    | 有効終了日                   |
| description   | Text     |    | N    | 店舗の説明                   |
| created_at    | DateTime |    | Y    | 作成日時                     |
| updated_at    | DateTime |    | Y    | 最終更新日時                 |
