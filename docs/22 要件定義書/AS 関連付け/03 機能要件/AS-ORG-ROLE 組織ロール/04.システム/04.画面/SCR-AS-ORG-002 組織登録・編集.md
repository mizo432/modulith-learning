# 組織登録・編集

組織登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-ORG-002 |
| 画面名           | 組織登録・編集 |
| 説明             | 新しい組織・部署の登録と既存組織の情報編集 |
| 関連ユースケース | UC-AS-ORG-001 (組織を登録する), UC-AS-ORG-002 (組織を更新する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 入力エリア | 組織情報入力フィールド |
| ボタンエリア | 登録・更新・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 組織_名前 | テキスト | はい | 組織名（最大100文字） |
| 2 | 組織_種類 | ドロップダウン | はい | 種類（組織、部署） |
| 3 | 組織_親組織 | ドロップダウン | いいえ | 親組織（階層構造） |
| 4 | 組織_説明 | テキストエリア | いいえ | 組織の説明（最大500文字） |
| 5 | 組織_メモ | テキストエリア | いいえ | メモ（最大500文字） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 登録 | 新しい組織を登録 |
| 2 | 更新 | 既存組織的信息を更新 |
| 3 | キャンセル | 編集をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | 名前一意性 | 同じ名前の組織は登録できない |
| 3 | 入力検証 | 必須項目の入力を検証する |
| 4 | 楽観ロック | 同時更新による不整合を防止する |
| 5 | 階層循環チェック | 循環参照にならないように検証する |
