# 組織変更履歴

組織変更履歴画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-ORG-009 |
| 画面名           | 組織変更履歴 |
| 説明             | 組織の変更履歴の確認 |
| 関連ユースケース | UC-AS-ORG-013 (組織変更履歴を取得する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールド |
| 一覧エリア | 組織変更履歴一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_組織ID | テキスト | いいえ | 組織IDで検索 |
| 2 | 検索_変更日時 | 日付範囲 | いいえ | 変更日時で検索 |
| 3 | 検索_変更タイプ | ドロップダウン | いいえ | 変更タイプでフィルタ（登録、更新、無効化、階層変更） |
| 4 | 履歴_ID | テキスト | - | 履歴ID |
| 5 | 履歴_組織名 | テキスト | - | 対象組織名 |
| 6 | 履歴_変更タイプ | テキスト | - | 変更タイプ（登録、更新、無効化、階層変更） |
| 7 | 履歴_変更日時 | 日時 | - | 変更日時 |
| 8 | 履歴_変更者 | テキスト | - | 変更者 |
| 9 | 履歴_変更内容 | テキスト | - | 変更内容の概要 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で履歴を検索 |
| 2 | ソート | 列ヘッダークリックでソート |
| 3 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者、システム運用者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 読み取り専用 | 履歴は読み取り専用 |
