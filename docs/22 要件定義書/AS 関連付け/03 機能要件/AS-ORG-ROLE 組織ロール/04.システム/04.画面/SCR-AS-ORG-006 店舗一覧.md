# 店舗一覧

店舗一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-ORG-006 |
| 画面名           | 店舗一覧 |
| 説明             | 店舗の検索・一覧表示（会社コードフィルタ対応） |
| 関連ユースケース | UC-AS-ORG-010 (店舗一覧を取得する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールド |
| 一覧エリア | 店舗一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_店舗名 | テキスト | いいえ | 店舗名で検索 |
| 2 | 検索_会社コード | ドロップダウン | いいえ | 会社コードでフィルタ |
| 3 | 検索_状態 | ドロップダウン | いいえ | 状態でフィルタ（有効、無効） |
| 4 | 店舗_ID | テキスト | - | 店舗ID |
| 5 | 店舗_店舗名 | テキスト | - | 店舗名 |
| 6 | 店舗_所属会社 | テキスト | - | 所属会社名 |
| 7 | 店舗_店舗タイプ | テキスト | - | 店舗タイプ（直営店、フランチャイズなど） |
| 8 | 店舗_状態 | ステータス | - | 状態（有効、無効） |
| 9 | 店舗_作成日時 | 日時 | - | 作成日時 |
| 10 | 店舗_更新日時 | 日時 | - | 最終更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で店舗を検索 |
| 2 | 編集 | 選択した店舗を編集画面に遷移 |
| 3 | ソート | 列ヘッダークリックでソート |
| 4 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者、JBジョブ管理、AGアジルームのみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | レスポンス時間 | 200ms以内で表示する |
