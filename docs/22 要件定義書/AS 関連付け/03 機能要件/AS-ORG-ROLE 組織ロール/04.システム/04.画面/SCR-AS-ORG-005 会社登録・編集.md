# 会社登録・編集

会社登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-ORG-005 |
| 画面名           | 会社登録・編集 |
| 説明             | 新しい会社の登録と既存会社の情報編集 |
| 関連ユースケース | UC-AS-ORG-004 (会社を登録する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 入力エリア | 会社情報入力フィールド |
| ボタンエリア | 登録・更新・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 会社_会社名 | テキスト | はい | 会社名（最大100文字） |
| 2 | 会社_会社タイプ | ドロップダウン | はい | 会社タイプ（本社、支社など） |
| 3 | 会社_住所 | テキスト | いいえ | 住所 |
| 4 | 会社_電話番号 | テキスト | いいえ | 電話番号 |
| 5 | 会社_メモ | テキストエリア | いいえ | メモ（最大500文字） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 登録 | 新しい会社を登録 |
| 2 | 更新 | 既存会社的信息を更新 |
| 3 | キャンセル | 編集をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | 名前一意性 | 同じ名前の会社は登録できない |
| 3 | 入力検証 | 必須項目の入力を検証する |
| 4 | 楽観ロック | 同時更新による不整合を防止する |
