# 店舗登録・編集

店舗登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-ORG-007 |
| 画面名           | 店舗登録・編集 |
| 説明             | 新しい店舗の登録と既存店舗の情報編集 |
| 関連ユースケース | UC-AS-ORG-005 (店舗を登録する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 入力エリア | 店舗情報入力フィールド |
| ボタンエリア | 登録・更新・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 店舗_店舗名 | テキスト | はい | 店舗名（最大100文字） |
| 2 | 店舗_所属会社 | ドロップダウン | はい | 所属会社 |
| 3 | 店舗_店舗タイプ | ドロップダウン | はい | 店舗タイプ（直営店、フランチャイズなど） |
| 4 | 店舗_住所 | テキスト | いいえ | 住所 |
| 5 | 店舗_電話番号 | テキスト | いいえ | 電話番号 |
| 6 | 店舗_メモ | テキストエリア | いいえ | メモ（最大500文字） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 登録 | 新しい店舗を登録 |
| 2 | 更新 | 既存店舗的信息を更新 |
| 3 | キャンセル | 編集をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | 名前一意性 | 同じ名前の店舗は登録できない |
| 3 | 入力検証 | 必須項目の入力を検証する |
| 4 | 楽観ロック | 同時更新による不整合を防止する |
