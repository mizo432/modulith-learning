# 画面一覧

AS-ORG-ROLE（組織ロール）業務領域が提供する画面をリストアップします。

## 一覧

| 画面ID    | 画面名                       | 主な利用者                 | 画面の目的                                                   |
|-----------|------------------------------|----------------------------|--------------------------------------------------------------|
| SCR-AS-ORG-001 | 組織一覧                     | 組織管理者                 | 組織・部署の検索・一覧表示・ページネーション                 |
| SCR-AS-ORG-002 | 組織登録・編集               | 組織管理者                 | 新しい組織・部署の登録と既存組織の情報編集                   |
| SCR-AS-ORG-003 | 組織詳細                     | 組織管理者、JBジョブ管理、AGアジルーム | 組織の詳細情報と階層構造の確認                               |
| SCR-AS-ORG-004 | 会社一覧                     | 組織管理者                 | 会社の検索・一覧表示                                         |
| SCR-AS-ORG-005 | 会社登録・編集               | 組織管理者                 | 新しい会社の登録と既存会社の情報編集                         |
| SCR-AS-ORG-006 | 店舗一覧                     | 組織管理者                 | 店舗の検索・一覧表示（会社コードフィルタ対応）               |
| SCR-AS-ORG-007 | 店舗登録・編集               | 組織管理者                 | 新しい店舗の登録と既存店舗の情報編集                         |
| SCR-AS-ORG-008 | 組織階層変更                 | 組織管理者                 | 組織の階層構造の変更                                         |
| SCR-AS-ORG-009 | 組織変更履歴                 | 組織管理者、システム運用者 | 組織の変更履歴の確認                                         |
