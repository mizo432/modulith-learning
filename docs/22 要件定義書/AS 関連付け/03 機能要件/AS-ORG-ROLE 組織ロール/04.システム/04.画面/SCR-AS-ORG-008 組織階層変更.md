# 組織階層変更

組織階層変更画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-ORG-008 |
| 画面名           | 組織階層変更 |
| 説明             | 組織の階層構造の変更 |
| 関連ユースケース | UC-AS-ORG-011 (組織階層を変更する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 組織情報エリア | 対象組織の情報表示 |
| 現在階層エリア | 現在の階層構造表示 |
| 変更後階層エリア | 変更後の親組織選択フィールド |
| ボタンエリア | 変更・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 組織_ID | テキスト | - | 対象組織ID |
| 2 | 組織_名前 | テキスト | - | 対象組織名 |
| 3 | 現在_親組織 | テキスト | - | 現在の親組織 |
| 4 | 変更後_親組織 | ドロップダウン | いいえ | 変更後の親組織（NULL可能） |
| 5 | 変更理由 | テキストエリア | いいえ | 変更理由（最大500文字） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 変更 | 組織の階層構造を変更 |
| 2 | キャンセル | 変更をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | 階層循環チェック | 循環参照にならないように検証する |
| 3 | トランザクション管理 | 階層変更は一貫性を持って実行する |
| 4 | 履歴記録 | 変更前の階層情報を履歴として記録する |
