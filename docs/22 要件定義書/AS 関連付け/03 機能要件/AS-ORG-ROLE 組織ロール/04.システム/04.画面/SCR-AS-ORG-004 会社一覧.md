# 会社一覧

会社一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-ORG-004 |
| 画面名           | 会社一覧 |
| 説明             | 会社の検索・一覧表示 |
| 関連ユースケース | UC-AS-ORG-009 (会社一覧を取得する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールド |
| 一覧エリア | 会社一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_会社名 | テキスト | いいえ | 会社名で検索 |
| 2 | 検索_状態 | ドロップダウン | いいえ | 状態でフィルタ（有効、無効） |
| 3 | 会社_ID | テキスト | - | 会社ID |
| 4 | 会社_会社名 | テキスト | - | 会社名 |
| 5 | 会社_会社タイプ | テキスト | - | 会社タイプ（本社、支社など） |
| 6 | 会社_状態 | ステータス | - | 状態（有効、無効） |
| 7 | 会社_作成日時 | 日時 | - | 作成日時 |
| 8 | 会社_更新日時 | 日時 | - | 最終更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で会社を検索 |
| 2 | 編集 | 選択した会社を編集画面に遷移 |
| 3 | ソート | 列ヘッダークリックでソート |
| 4 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者、JBジョブ管理、AGアジルームのみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | レスポンス時間 | 200ms以内で表示する |
