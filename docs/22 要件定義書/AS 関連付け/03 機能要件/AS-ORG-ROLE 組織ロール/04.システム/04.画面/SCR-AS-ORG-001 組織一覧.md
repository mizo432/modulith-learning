# 組織一覧

組織一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-ORG-001 |
| 画面名           | 組織一覧 |
| 説明             | 組織・部署の検索・一覧表示・ページネーション |
| 関連ユースケース | UC-AS-ORG-006 (組織を検索する), UC-AS-ORG-007 (組織一覧を取得する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールド |
| 一覧エリア | 組織一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_組織名 | テキスト | いいえ | 組織名で検索 |
| 2 | 検索_種類 | ドロップダウン | いいえ | 種類でフィルタ（組織、部署） |
| 3 | 検索_状態 | ドロップダウン | いいえ | 状態でフィルタ（有効、無効） |
| 4 | 組織_ID | テキスト | - | 組織ID |
| 5 | 組織_名前 | テキスト | - | 組織名 |
| 6 | 組織_種類 | テキスト | - | 種類（組織、部署） |
| 7 | 組織_親組織 | テキスト | - | 親組織名 |
| 8 | 組織_状態 | ステータス | - | 状態（有効、無効） |
| 9 | 組織_作成日時 | 日時 | - | 作成日時 |
| 10 | 組織_更新日時 | 日時 | - | 最終更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で組織を検索 |
| 2 | 詳細表示 | 選択した組織の詳細画面に遷移 |
| 3 | 編集 | 選択した組織を編集画面に遷移 |
| 4 | ソート | 列ヘッダークリックでソート |
| 5 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者、JBジョブ管理、AGアジルームのみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | レスポンス時間 | 200ms以内で表示する |
