# バリエーション・条件図

AS-ORG-ROLE 組織ロール業務領域のバリエーションと条件を定義します。

## 1. バリエーション

### 組織種類

| バリエーション名 | 説明 |
|------------------|------|
| 会社 | 会社組織 |
| 部署 | 部署組織 |
| 店舗 | 店舗組織 |

### 組織状態

| バリエーション名 | 説明 |
|------------------|------|
| 有効 | 現在有効な組織 |
| 無効 | 廃止された組織 |

## 2. 条件

### 組織登録制限: 条件

組織種類による登録時の制限を定義します。

| 組織種類 | 必須項目 | 追加制約 |
|----------|----------|----------|
| 会社 | 会社名、会社コード | 会社コード一意性チェック |
| 部署 | 部署名、親組織 | 親組織の有効性チェック |
| 店舗 | 店舗名、店舗コード、所属会社 | 店舗コード一意性チェック |

### 階層変更制限: 条件

組織状態による階層変更の制限を定義します。

| 組織状態 | 階層変更可能 | 子組織追加可能 |
|----------|--------------|----------------|
| 有効 | 可能 | 可能 |
| 無効 | 不可 | 不可 |

## 3. 補足

- バリエーション・条件図は、RDRAの「システムレイヤー」で使用する表形式のモデルです。
- 条件はユースケース複合図で `control` アイコンとして参照されます。
