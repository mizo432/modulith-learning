# AS-PERSON-ROLE 人ロール

## 概要

本ドキュメントは、AS-PERSON-ROLE 人ロールの機能要件を定義します。

人ロール(PersonRole)は、個人(従業員)に特化したロール管理業務領域です。従業員の所属組織・部署との関連付けを管理し、人事情報との連携を可能にします。部署変更履歴の追跡や、会社・店舗単位での権限範囲の管理を担当します。

## 業務領域情報

- 業務領域コード: AS-03
- 業務領域名: 人ロール
- 業務領域英名: PersonRole

## 主な責務

- 従業員の所属管理
- 部署変更履歴の管理
- 会社・店舗との関連付け
- 権限範囲の管理
