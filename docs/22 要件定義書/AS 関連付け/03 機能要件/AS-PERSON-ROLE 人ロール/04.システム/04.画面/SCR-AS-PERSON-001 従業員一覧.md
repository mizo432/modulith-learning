# 従業員一覧

従業員一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PERSON-001 |
| 画面名           | 従業員一覧 |
| 説明             | 従業員の検索・一覧表示・ページネーション |
| 関連ユースケース | UC-AS-PERSON-004 (従業員を検索する), UC-AS-PERSON-005 (従業員一覧を取得する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールド |
| 一覧エリア | 従業員一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_氏名 | テキスト | いいえ | 氏名で検索 |
| 2 | 検索_所属組織 | ドロップダウン | いいえ | 所属組織でフィルタ |
| 3 | 検索_状態 | ドロップダウン | いいえ | 状態でフィルタ（有効、無効） |
| 4 | 従業員_ID | テキスト | - | 従業員ID |
| 5 | 従業員_氏名 | テキスト | - | 氏名 |
| 6 | 従業員_所属組織 | テキスト | - | 所属組織名 |
| 7 | 従業員_状態 | ステータス | - | 状態（有効、無効） |
| 8 | 従業員_入社日 | 日付 | - | 入社日 |
| 9 | 従業員_更新日時 | 日時 | - | 最終更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で従業員を検索 |
| 2 | 詳細表示 | 選択した従業員の詳細画面に遷移 |
| 3 | 編集 | 選択した従業員を編集画面に遷移 |
| 4 | ソート | 列ヘッダークリックでソート |
| 5 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者、JBジョブ管理、AGアジルームのみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | レスポンス時間 | 200ms以内で表示する |
