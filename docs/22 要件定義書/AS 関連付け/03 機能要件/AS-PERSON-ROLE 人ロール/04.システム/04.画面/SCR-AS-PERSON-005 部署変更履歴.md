# 部署変更履歴

部署変更履歴画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PERSON-005 |
| 画面名           | 部署変更履歴 |
| 説明             | 従業員の部署変更履歴の確認 |
| 関連ユースケース | UC-AS-PERSON-008 (部署変更履歴を取得する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールド |
| 一覧エリア | 部署変更履歴一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_従業員ID | テキスト | いいえ | 従業員IDで検索 |
| 2 | 検索_変更日時 | 日付範囲 | いいえ | 変更日時で検索 |
| 3 | 履歴_ID | テキスト | - | 履歴ID |
| 4 | 履歴_従業員名 | テキスト | - | 対象従業員名 |
| 5 | 履歴_変更前組織 | テキスト | - | 変更前の所属組織 |
| 6 | 履歴_変更前部署 | テキスト | - | 変更前の所属部署 |
| 7 | 履歴_変更後組織 | テキスト | - | 変更後の所属組織 |
| 8 | 履歴_変更後部署 | テキスト | - | 変更後の所属部署 |
| 9 | 履歴_変更日時 | 日時 | - | 変更日時 |
| 10 | 履歴_変更者 | テキスト | - | 変更者 |
| 11 | 履歴_変更理由 | テキスト | - | 変更理由 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件で履歴を検索 |
| 2 | ソート | 列ヘッダークリックでソート |
| 3 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者、システム運用者のみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | 読み取り専用 | 履歴は読み取り専用 |
