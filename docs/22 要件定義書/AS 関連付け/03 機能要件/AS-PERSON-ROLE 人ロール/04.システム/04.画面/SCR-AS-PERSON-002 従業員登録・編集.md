# 従業員登録・編集

従業員登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PERSON-002 |
| 画面名           | 従業員登録・編集 |
| 説明             | 新しい従業員の登録と既存従業員の情報編集 |
| 関連ユースケース | UC-AS-PERSON-001 (従業員を登録する), UC-AS-PERSON-002 (従業員を更新する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 基本情報エリア | 従業員の基本情報入力フィールド |
| 所属情報エリア | 所属組織・部署選択フィールド |
| ボタンエリア | 登録・更新・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 従業員_氏名 | テキスト | はい | 氏名（最大100文字） |
| 2 | 従業員_ユーザー名 | テキスト | はい | ユーザー名（最大50文字） |
| 3 | 従業員_メールアドレス | メール | はい | メールアドレス |
| 4 | 従業員_電話番号 | テキスト | いいえ | 電話番号 |
| 5 | 所属_組織 | ドロップダウン | はい | 所属組織 |
| 6 | 所属_部署 | ドロップダウン | いいえ | 所属部署 |
| 7 | 有効期間_開始日 | 日付 | はい | 有効期間の開始日（入社日） |
| 8 | 有効期間_終了日 | 日付 | いいえ | 有効期間の終了日（退社日） |
| 9 | 従業員_メモ | テキストエリア | いいえ | メモ（最大500文字） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 登録 | 新しい従業員を登録（PartyとPersonRoleを自動作成） |
| 2 | 更新 | 既存従業員の情報を更新 |
| 3 | キャンセル | 編集をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | ユーザー名一意性 | 同じユーザー名の従業員は登録できない |
| 3 | 入力検証 | 必須項目の入力を検証する |
| 4 | 楽観ロック | 同時更新による不整合を防止する |
| 5 | トランザクション管理 | PartyとPersonRoleの作成は一貫性を持って実行する |
