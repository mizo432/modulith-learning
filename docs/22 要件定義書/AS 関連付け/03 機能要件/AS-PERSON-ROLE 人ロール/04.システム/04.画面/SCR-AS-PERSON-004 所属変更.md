# 所属変更

所属変更画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PERSON-004 |
| 画面名           | 所属変更 |
| 説明             | 従業員の所属組織・部署の変更 |
| 関連ユースケース | UC-AS-PERSON-007 (所属組織を変更する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 従業員情報エリア | 対象従業員の情報表示 |
| 現在所属エリア | 現在の所属組織・部署表示 |
| 変更後所属エリア | 変更後の所属組織・部署選択フィールド |
| 有効期間エリア | 有効期間入力フィールド |
| ボタンエリア | 変更・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 従業員_ID | テキスト | - | 対象従業員ID |
| 2 | 従業員_氏名 | テキスト | - | 対象従業員名 |
| 3 | 現在_組織 | テキスト | - | 現在の所属組織 |
| 4 | 現在_部署 | テキスト | - | 現在の所属部署 |
| 5 | 変更後_組織 | ドロップダウン | はい | 変更後の所属組織 |
| 6 | 変更後_部署 | ドロップダウン | いいえ | 変更後の所属部署 |
| 7 | 有効期間_開始日 | 日付 | はい | 変更の有効開始日 |
| 8 | 変更理由 | テキストエリア | いいえ | 変更理由（最大500文字） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 変更 | 所属組織・部署を変更 |
| 2 | キャンセル | 変更をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | 有効期間検証 | 開始日は過去の日付にできない |
| 3 | トランザクション管理 | 所属変更は一貫性を持って実行する |
| 4 | 履歴記録 | 変更前の所属情報を履歴として記録する |
