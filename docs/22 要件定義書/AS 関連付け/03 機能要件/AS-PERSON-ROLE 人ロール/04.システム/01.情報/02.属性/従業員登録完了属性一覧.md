# 従業員登録完了属性一覧

AS-PERSON-ROLE 人ロール業務領域で扱う「従業員登録完了」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| event_id      | SnowflakeID | * | Y  | イベントの一意な識別子       |
| person_id     | SnowflakeID |  | Y    | 従業員の識別子               |
| event_type    | Code     |    | Y    | イベントの種類               |
| event_time    | DateTime |    | Y    | イベント発生時刻             |
| payload       | JSON     |    | N    | イベントペイロード           |
