# 人ロール属性一覧

AS-PERSON-ROLE 人ロール業務領域で扱う「人ロール」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| person_role_id | SnowflakeID | * | Y | 人ロールの一意な識別子       |
| person_id     | SnowflakeID |  | Y    | 従業員の識別子               |
| role_id       | SnowflakeID |  | Y    | ロールの識別子               |
| valid_from    | DateTime |    | Y    | 有効開始日                   |
| valid_to      | DateTime |    | N    | 有効終了日                   |
| description   | Text     |    | N    | 人ロールの説明               |
| created_at    | DateTime |    | Y    | 作成日時                     |
| updated_at    | DateTime |    | Y    | 最終更新日時                 |
