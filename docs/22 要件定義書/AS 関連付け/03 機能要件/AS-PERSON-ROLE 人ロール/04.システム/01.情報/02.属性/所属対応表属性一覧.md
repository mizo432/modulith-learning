# 所属対応表属性一覧

AS-PERSON-ROLE 人ロール業務領域で扱う「所属対応表」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| membership_id | SnowflakeID | * | Y  | 所属対応表の一意な識別子     |
| person_id     | SnowflakeID |  | Y    | 従業員の識別子               |
| org_id        | SnowflakeID |  | Y    | 組織の識別子                 |
| is_primary    | Boolean  |    | Y    | 主所属フラグ                 |
| valid_from    | DateTime |    | Y    | 有効開始日                   |
| valid_to      | DateTime |    | N    | 有効終了日                   |
| description   | Text     |    | N    | 所属対応表の説明             |
| created_at    | DateTime |    | Y    | 作成日時                     |
| updated_at    | DateTime |    | Y    | 最終更新日時                 |
