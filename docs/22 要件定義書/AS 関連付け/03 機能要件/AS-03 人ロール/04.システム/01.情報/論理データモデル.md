# 論理データモデル

## 概要

AS-03 人ロール業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    PERSON_ROLE
    {
        string PERSON_ROLE_ID PK "PersonRoleID"
        string party "Party"
        string role "Role"
        string 組織 "組織"
        string 有効期間 "有効期間"
        string 状態 "状態"
        string 作成日 "作成日"
        string state "状態(PersonRole)"
        enum variation "バリエーション(PersonRoleタイプ)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```
