# 論理データモデル

## 概要

AS-04 組織ロール業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    ORGANIZATION_ROLE
    {
        string ORGANIZATION_ROLE_ID PK "OrganizationRoleID"
        string party "Party"
        string role "Role"
        string 有効期間 "有効期間"
        string 状態 "状態"
        string 作成日 "作成日"
        string state "状態(OrganizationRole)"
        enum variation "バリエーション(OrganizationRoleタイプ)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| OrganizationRole | ORGANIZATION_ROLE_ID | string | true | OrganizationRoleID |
