# AS-PARTY-ROLE パーティーロール

## 概要

本ドキュメントは、AS-PARTY-ROLE パーティーロールの機能要件を定義します。

パーティーロール(PartyRole)は、パーティーに付与されるロールの定義を管理する業務領域です。ロールの種類や属性を一元管理し、組織ロール・人ロールの共通基盤となります。パーティーとロールを分離することで、同じパーティーが複数のロールを持つことや、ロールの変更履歴を追跡することが可能になります。

## 業務領域情報

- 業務領域コード: AS-02
- 業務領域名: パーティーロール
- 業務領域英名: PartyRole

## 主な責務

- ロール定義の管理
- ロール属性の管理
- ロール有効期間の管理
- パーティーとの関連付け
