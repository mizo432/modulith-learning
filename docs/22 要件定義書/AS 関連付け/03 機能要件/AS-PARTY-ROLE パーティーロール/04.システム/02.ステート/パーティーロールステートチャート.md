# パーティーロール ステートチャート

パーティーロール情報の状態遷移を示します。

```plantuml
@startuml
skinparam state {
  BackgroundColor White
  BorderColor Black
}

state "有効" as active
state "無効" as inactive

[*] --> active
active --> inactive

note right of active
  ロールが有効な状態
end note

note right of inactive
  ロールが無効化された状態
end note
@enduml
```

## 状態一覧

| 状態ID | 状態名 | 説明 |
|--------|--------|------|
| ST-AS-PARTY-ROLE-001 | 有効 | ロールが有効な状態 |
| ST-AS-PARTY-ROLE-002 | 無効 | ロールが無効化された状態 |
