# ステートマシン図

AS-PARTY-ROLE パーティーロール業務領域で扱う情報の状態遷移を示す状態モデル図です。

## 1. 目的

本書は、AS-PARTY-ROLE パーティーロール業務領域のシステムレイヤーで扱う情報の状態遷移を示す状態モデル図（ステートマシン図）です。

## 2. PlantUML 状態遷移図

```plantuml
@startuml
title AS-PARTY-ROLE パーティーロール 状態遷移図
skinparam state {
  BackgroundColor #F8FAFC
  BorderColor #475569
  FontColor #0F172A
}
skinparam arrowColor #475569
skinparam shadowing false

state "有効 (Active)" as Active
state "無効 (Inactive)" as Inactive

[*] --> Active : UC-AS-PARTY-ROLE-001\nロール定義を登録する
Active --> Inactive : UC-AS-PARTY-ROLE-007\nパーティーからロールを解除する
@enduml
```

## 3. 状態一覧

| 状態名 (ID) | 英語名 | 説明 |
|-------------|--------|------|
| 有効 (ST-AS-PARTY-ROLE-001) | Active | ロールが有効な状態 |
| 無効 (ST-AS-PARTY-ROLE-002) | Inactive | ロールが無効化された状態 |

## 4. 遷移一覧

| 遷移ID | 元状態 | 遷移先状態 | トリガー | 関連ユースケース | 説明 |
|--------|--------|------------|----------|------------------|------|
| TR-AS-PARTY-ROLE-01 | [*] | 有効 | ロール定義登録 | UC-AS-PARTY-ROLE-001 | 新しいロール定義を登録すると有効状態になる |
| TR-AS-PARTY-ROLE-02 | 有効 | 無効 | ロール解除 | UC-AS-PARTY-ROLE-007 | パーティーからロールを解除すると無効状態になる |
