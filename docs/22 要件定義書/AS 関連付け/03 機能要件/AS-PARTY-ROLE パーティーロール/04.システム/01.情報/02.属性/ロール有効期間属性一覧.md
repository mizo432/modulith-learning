# ロール有効期間属性一覧

AS-PARTY-ROLE パーティーロール業務領域で扱う「ロール有効期間」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| period_id     | SnowflakeID | * | Y  | 有効期間の一意な識別子       |
| role_id       | SnowflakeID |  | Y    | ロールの識別子               |
| party_id      | SnowflakeID |  | Y    | パーティーの識別子           |
| valid_from    | DateTime |    | Y    | 有効開始日                   |
| valid_to      | DateTime |    | N    | 有効終了日                   |
| status        | Code     |    | Y    | ステータス（有効、無効など） |
| description   | Text     |    | N    | 有効期間の説明               |
| created_at    | DateTime |    | Y    | 作成日時                     |
| updated_at    | DateTime |    | Y    | 最終更新日時                 |
