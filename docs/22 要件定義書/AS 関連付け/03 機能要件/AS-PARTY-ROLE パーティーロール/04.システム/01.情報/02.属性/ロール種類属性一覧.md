# ロール種類属性一覧

AS-PARTY-ROLE パーティーロール業務領域で扱う「ロール種類」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| role_type_code | Code    | *  | Y    | ロール種類コード             |
| name          | String   |    | Y    | ロール種類名                 |
| description   | Text     |    | N    | ロール種類の説明             |
| created_at    | DateTime |    | Y    | 作成日時                     |
