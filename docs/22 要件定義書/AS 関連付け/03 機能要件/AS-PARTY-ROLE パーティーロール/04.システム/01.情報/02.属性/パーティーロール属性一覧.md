# パーティーロール属性一覧

AS-PARTY-ROLE パーティーロール業務領域で扱う「パーティーロール」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| role_id       | SnowflakeID | * | Y  | ロールの一意な識別子         |
| role_type     | Code     |    | Y    | ロールの種類（人ロール、組織ロールなど） |
| name          | String   |    | Y    | ロール名                     |
| code          | String   |    | N    | ロールコード                 |
| description   | Text     |    | N    | ロールの説明                 |
| valid_from    | DateTime |    | Y    | 有効開始日                   |
| valid_to      | DateTime |    | N    | 有効終了日                   |
| created_at    | DateTime |    | Y    | 作成日時                     |
| updated_at    | DateTime |    | Y    | 最終更新日時                 |
