# ロール付与完了属性一覧

AS-PARTY-ROLE パーティーロール業務領域で扱う「ロール付与完了」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| event_id      | SnowflakeID | * | Y  | イベントの一意な識別子       |
| role_id       | SnowflakeID |  | Y    | ロールの識別子               |
| party_id      | SnowflakeID |  | Y    | パーティーの識別子           |
| event_type    | Code     |    | Y    | イベントの種類               |
| event_time    | DateTime |    | Y    | イベント発生時刻             |
| payload       | JSON     |    | N    | イベントペイロード           |
