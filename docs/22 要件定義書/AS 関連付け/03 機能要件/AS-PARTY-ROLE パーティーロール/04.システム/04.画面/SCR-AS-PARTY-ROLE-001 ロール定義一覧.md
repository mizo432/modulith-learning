# ロール定義一覧

ロール定義一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PARTY-ROLE-001 |
| 画面名           | ロール定義一覧 |
| 説明             | ロール定義の検索・一覧表示・ページネーション |
| 関連ユースケース | UC-AS-PARTY-ROLE-003 (ロールを検索する), UC-AS-PARTY-ROLE-004 (ロール一覧を取得する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールド |
| 一覧エリア | ロール定義一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_ロール名 | テキスト | いいえ | ロール名で検索 |
| 2 | 検索_種類 | ドロップダウン | いいえ | 種類でフィルタ（PersonRole、OrganizationRole） |
| 3 | 検索_状態 | ドロップダウン | いいえ | 状態でフィルタ（有効、無効） |
| 4 | ロール_ID | テキスト | - | ロールID |
| 5 | ロール_名前 | テキスト | - | ロール名 |
| 6 | ロール_種類 | テキスト | - | 種類（PersonRole、OrganizationRole） |
| 7 | ロール_状態 | ステータス | - | 状態（有効、無効） |
| 8 | ロール_作成日時 | 日時 | - | 作成日時 |
| 9 | ロール_更新日時 | 日時 | - | 最終更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件でロールを検索 |
| 2 | 詳細表示 | 選択したロールの詳細画面に遷移 |
| 3 | 編集 | 選択したロールを編集画面に遷移 |
| 4 | ソート | 列ヘッダークリックでソート |
| 5 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者、JBジョブ管理、AGアジルームのみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | レスポンス時間 | 200ms以内で表示する |
