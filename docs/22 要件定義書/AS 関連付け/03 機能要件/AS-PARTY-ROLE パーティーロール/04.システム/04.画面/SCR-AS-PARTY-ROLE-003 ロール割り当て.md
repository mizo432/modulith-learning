# ロール割り当て

ロール割り当て画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PARTY-ROLE-003 |
| 画面名           | ロール割り当て |
| 説明             | パーティーへのロール付与・解除 |
| 関連ユースケース | UC-AS-PARTY-ROLE-006 (パーティーにロールを付与する), UC-AS-PARTY-ROLE-007 (パーティーからロールを解除する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| パーティー選択エリア | パーティー選択フィールド |
| ロール選択エリア | 付与するロール選択フィールド |
| 有効期間エリア | 有効期間入力フィールド |
| 現在のロール一覧エリア | 現在付与されているロールの一覧表示 |
| ボタンエリア | 付与・解除・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | パーティー_ID | テキスト | はい | 対象パーティーID |
| 2 | パーティー_名前 | テキスト | - | 対象パーティー名 |
| 3 | ロール_ID | ドロップダウン | はい | 付与するロール |
| 4 | 有効期間_開始日 | 日付 | はい | 有効期間の開始日 |
| 5 | 有効期間_終了日 | 日付 | いいえ | 有効期間の終了日 |
| 6 | 現在のロール_ロール名 | テキスト | - | 現在付与されているロール名 |
| 7 | 現在のロール_有効期間 | 期間 | - | 現在付与されているロールの有効期間 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | ロール付与 | 選択したロールをパーティーに付与 |
| 2 | ロール解除 | 選択したロールをパーティーから解除 |
| 3 | キャンセル | 編集をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | 有効期間検証 | 開始日は終了日より前であること |
| 3 | 重複チェック | 同じロールが重複して付与されないこと |
| 4 | トランザクション管理 | ロール付与・解除は一貫性を持って実行する |
