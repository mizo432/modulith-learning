# ロール定義登録・編集

ロール定義登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PARTY-ROLE-002 |
| 画面名           | ロール定義登録・編集 |
| 説明             | 新しいロール定義の登録と既存ロール定義の情報編集 |
| 関連ユースケース | UC-AS-PARTY-ROLE-001 (ロール定義を登録する), UC-AS-PARTY-ROLE-002 (ロール定義を更新する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 入力エリア | ロール定義情報入力フィールド |
| ボタンエリア | 登録・更新・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | ロール_名前 | テキスト | はい | ロール名（最大100文字） |
| 2 | ロール_種類 | ドロップダウン | はい | 種類（PersonRole、OrganizationRole） |
| 3 | ロール_説明 | テキストエリア | いいえ | ロールの説明（最大500文字） |
| 4 | ロール_メモ | テキストエリア | いいえ | メモ（最大500文字） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 登録 | 新しいロール定義を登録 |
| 2 | 更新 | 既存ロール定義を更新 |
| 3 | キャンセル | 編集をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | 名前一意性 | 同じ名前のロールは登録できない |
| 3 | 入力検証 | 必須項目の入力を検証する |
| 4 | 楽観ロック | 同時更新による不整合を防止する |
