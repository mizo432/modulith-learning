# AS-PARTY パーティー

## 概要

本ドキュメントは、AS-PARTY パーティーの機能要件を定義します。

パーティー(Party)は、Party Roleパターンの基盤となる概念で、組織・人・会社・店舗などの実体を抽象化したエンティティです。具体的なロール(組織ロール・人ロール)はパーティーを基盤として構築され、パーティー自体は実体の一意な識別と基本情報管理を担当します。

## 業務領域情報

- 業務領域コード: AS-01
- 業務領域名: パーティー
- 業務領域英名: Party

## 主な責務

- 実体の一意な識別
- 実体の基本情報管理
- 有効期間の管理
- ロールとの関連付け
