# パーティー ステートチャート

パーティー情報の状態遷移を示します。

```plantuml
@startuml
skinparam state {
  BackgroundColor White
  BorderColor Black
}

state "有効" as active
state "無効" as inactive

[*] --> active
active --> inactive

note right of active
  パーティーが有効な状態
end note

note right of inactive
  パーティーが無効化された状態
end note
@enduml
```

## 状態一覧

| 状態ID | 状態名 | 説明 |
|--------|--------|------|
| ST-AS-PARTY-001 | 有効 | パーティーが有効な状態 |
| ST-AS-PARTY-002 | 無効 | パーティーが無効化された状態 |
