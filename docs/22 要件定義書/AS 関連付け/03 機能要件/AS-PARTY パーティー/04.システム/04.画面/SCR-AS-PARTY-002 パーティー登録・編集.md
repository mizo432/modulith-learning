# パーティー登録・編集

パーティー登録・編集画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PARTY-002 |
| 画面名           | パーティー登録・編集 |
| 説明             | 新しいパーティーの登録と既存パーティーの情報編集 |
| 関連ユースケース | UC-AS-PARTY-001 (パーティーを登録する), UC-AS-PARTY-002 (パーティーを更新する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 入力エリア | パーティー情報入力フィールド |
| ボタンエリア | 登録・更新・キャンセルボタン |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | パーティー_名前 | テキスト | はい | パーティー名（最大100文字） |
| 2 | パーティー_種類 | ドロップダウン | はい | 種類（個人、法人） |
| 3 | パーティー_メールアドレス | メール | いいえ | メールアドレス |
| 4 | パーティー_電話番号 | テキスト | いいえ | 電話番号 |
| 5 | パーティー_メモ | テキストエリア | いいえ | メモ（最大500文字） |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 登録 | 新しいパーティーを登録 |
| 2 | 更新 | 既存パーティー的信息を更新 |
| 3 | キャンセル | 編集をキャンセルして一覧画面に遷移 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者のみアクセス可能 |
| 2 | 名前一意性 | 同じ名前のパーティーは登録できない |
| 3 | 入力検証 | 必須項目の入力を検証する |
| 4 | 楽観ロック | 同時更新による不整合を防止する |
