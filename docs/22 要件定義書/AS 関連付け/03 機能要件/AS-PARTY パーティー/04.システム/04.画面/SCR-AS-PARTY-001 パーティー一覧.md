# パーティー一覧

パーティー一覧画面の詳細を定義します。

## 概要

| 項目             | 内容 |
|------------------|------|
| 画面ID           | SCR-AS-PARTY-001 |
| 画面名           | パーティー一覧 |
| 説明             | パーティーの検索・一覧表示・ページネーション |
| 関連ユースケース | UC-AS-PARTY-004 (パーティーを検索する), UC-AS-PARTY-005 (パーティー一覧を取得する) |

## 画面レイアウト

| 領域 | 説明 |
|------|------|
| ヘッダー | システム名、ユーザー情報、ログアウトボタン |
| ナビゲーション | メニューバー |
| 検索エリア | 検索条件入力フィールド |
| 一覧エリア | パーティー一覧テーブル |
| フッター | ページネーション、件数表示 |

## 画面項目

| 番号 | 項目名 | 型 | 必須 | 説明 |
|------|--------|----|------|------|
| 1 | 検索_パーティー名 | テキスト | いいえ | パーティー名で検索 |
| 2 | 検索_種類 | ドロップダウン | いいえ | 種類でフィルタ（個人、法人） |
| 3 | 検索_状態 | ドロップダウン | いいえ | 状態でフィルタ（有効、無効） |
| 4 | パーティー_ID | テキスト | - | パーティーID |
| 5 | パーティー_名前 | テキスト | - | パーティー名 |
| 6 | パーティー_種類 | テキスト | - | 種類（個人、法人） |
| 7 | パーティー_状態 | ステータス | - | 状態（有効、無効） |
| 8 | パーティー_作成日時 | 日時 | - | 作成日時 |
| 9 | パーティー_更新日時 | 日時 | - | 最終更新日時 |

## 画面操作

| 番号 | 操作名 | 説明 |
|------|--------|------|
| 1 | 検索 | 入力した条件でパーティーを検索 |
| 2 | 詳細表示 | 選択したパーティーの詳細画面に遷移 |
| 3 | 編集 | 選択したパーティーを編集画面に遷移 |
| 4 | ソート | 列ヘッダークリックでソート |
| 5 | ページ移動 | ページネーションでページ移動 |

## 制約事項

| 番号 | 制約事項 | 説明 |
|------|----------|------|
| 1 | 権限チェック | 組織管理者、JBジョブ管理、AGアジルームのみアクセス可能 |
| 2 | 表示件数 | 1ページあたり50件を表示 |
| 3 | レスポンス時間 | 200ms以内で表示する |
