# パーティー属性一覧

AS-PARTY パーティー業務領域で扱う「パーティー」の属性を定義します。

| 属性名        | 型       | PK | 必須 | 説明                         |
|---------------|----------|----|------|------------------------------|
| party_id      | SnowflakeID | * | Y  | パーティーの一意な識別子     |
| party_type    | Code     |    | Y    | パーティーの種類（個人、法人、組織など） |
| name          | String   |    | Y    | パーティー名                 |
| code          | String   |    | N    | パーティーコード             |
| status        | Code     |    | Y    | ステータス（有効、無効など） |
| valid_from    | DateTime |    | Y    | 有効開始日                   |
| valid_to      | DateTime |    | N    | 有効終了日                   |
| description   | Text     |    | N    | パーティーの説明             |
| created_at    | DateTime |    | Y    | 作成日時                     |
| updated_at    | DateTime |    | Y    | 最終更新日時                 |
