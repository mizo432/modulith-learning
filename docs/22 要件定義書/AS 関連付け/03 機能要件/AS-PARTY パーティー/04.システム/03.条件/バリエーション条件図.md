# バリエーション・条件図

AS-PARTY パーティー業務領域のバリエーションと条件を定義します。

## 1. バリエーション

### パーティー種類

| バリエーション名 | 説明 |
|------------------|------|
| 個人 | 個人を表すパーティー |
| 法人 | 法人を表すパーティー |
| 組織 | 組織・部署を表すパーティー |

## 2. 条件

### パーティー登録制限: 条件

パーティー種類による登録時の制限を定義します。

| パーティー種類 | 必須項目 | 追加制約 |
|----------------|----------|----------|
| 個人 | 氏名、メールアドレス | メールアドレス一意性チェック |
| 法人 | 法人名、法人番号 | 法人番号一意性チェック |
| 組織 | 組織名 | 親組織の有効性チェック |

## 3. 補足

- バリエーション・条件図は、RDRAの「システムレイヤー」で使用する表形式のモデルです。
- 条件はユースケース複合図で `control` アイコンとして参照されます。
