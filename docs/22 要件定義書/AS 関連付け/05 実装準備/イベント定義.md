# イベント定義

AS関連付け（Association）事業領域のイベントを詳細に定義します。

## 概要

本ドキュメントでは、AS関連付けで発生するドメインイベントと外部システム連携イベントの詳細を定義します。イベントは、ユースケースの実行結果として発生し、他のモジュールや外部システムに状態変更を通知します。

## イベント分類

### ドメインイベント

ドメインイベントは、AS関連付け内部で発生する状態変更を通知するイベントです。

| カテゴリ | イベント数 | 説明 |
|---------|-----------|------|
| Party関連 | 5件 | パーティーの登録・更新・無効化・ロール付与・ロール解除 |
| 従業員関連 | 4件 | 従業員の登録・更新・退社・所属変更 |
| 組織関連 | 7件 | 組織・会社・店舗の登録・更新・廃止・階層変更・権限範囲定義 |
| ロール定義関連 | 4件 | ロール定義の登録・更新・パーティーへのロール付与・解除 |

### 外部システム連携イベント

外部システム連携イベントは、AS関連付けの状態変更を外部システムに通知するイベントです。

| 送信先 | イベント数 | 説明 |
|--------|-----------|------|
| JBジョブ管理 | 5件 | 会社・店舗・従業員・組織・所属の変更通知 |
| AGアジルーム | 5件 | 会社・店舗・従業員・組織・所属の変更通知 |

## イベント配信方針

### 配信方法

1. **同期配信**: 重要な状態変更は同期で配信し、失敗時はトランザクションをロールバック
   - 例: 従業員登録完了 → JBジョブ管理への通知
2. **非同期配信**: 通知系のイベントは非同期で配信し、失敗時はリトライ
   - 例: 組織情報変更通知 → AGアジルームへの通知

### リトライポリシー

- **最大リトライ回数**: 3回
- **リトライ間隔**: 指数バックオフ（1秒、2秒、4秒）
- **デッドレターキュー**: リトライ失敗時はDLQに格納し、手動対応

### イベント順序保証

- 同じエンティティに対するイベントは順序を保証
- 異なるエンティティ間のイベントは順序を保証しない
