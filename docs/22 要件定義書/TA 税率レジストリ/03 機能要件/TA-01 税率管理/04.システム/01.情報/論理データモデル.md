# 論理データモデル

## 概要

TA-01 税率管理業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    TAX_RATE
    {
        string TAX_RATE_ID PK "税率ID"
        string 名称 "名称"
        string 種類 "種類"
        number 税率 "税率"
        string 適用期間 "適用期間"
        string 状態 "状態"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(税率)"
        enum variation "バリエーション(税率種類)"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| 税率 | TAX_RATE_ID | string | true | 税率ID |
