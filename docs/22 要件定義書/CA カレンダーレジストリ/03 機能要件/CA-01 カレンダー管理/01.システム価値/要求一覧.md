# 要求一覧

カレンダー管理業務領域（CA-01）の機能要求と非機能要求を定義します。

## 機能要求

| ID       | 要求名                       | 概要                                                     | 優先度 |
|----------|------------------------------|----------------------------------------------------------|--------|
| FR-CA-01 | 祝日参照（日付指定）         | 指定された日付の祝日情報を取得する                         | MVP    |
| FR-CA-02 | 祝日参照（年指定）           | 指定された年の全祝日情報を日付昇順で取得する               | MVP    |
| FR-CA-03 | 祝日参照（期間指定）         | 指定された期間内の全祝日情報を日付昇順で取得する           | MVP    |
| FR-CA-04 | 祝日マスターインポート       | デジタル庁/内閣府の祝日CSVをバッチインポートする           | MVP    |
| FR-CA-05 | 祝日データUpsert             | インポート時に新規登録・既存更新を自動判定して処理する     | MVP    |
| FR-CA-06 | 営業日計算（日付算出）       | 基準日と営業日数から、該当する営業日（日付）を求める       | MVP    |
| FR-CA-07 | 営業日計算（日数算出）       | 2つの日付の間にある営業日数を求める                        | MVP    |

## 非機能要求

| ID        | 要求名                         | 概要                                   |
|-----------|--------------------------------|----------------------------------------|
| NFR-CA-01 | 祝日データの正確性             | デジタル庁/内閣府公式データとの整合    |
| NFR-CA-02 | バッチフォールトトレランス     | スキップ・リトライによる堅牢な処理     |
| NFR-CA-03 | 日付検索パフォーマンス         | インデックスによる高速検索             |
| NFR-CA-04 | CSVフォーマット柔軟性          | 複数ヘッダー形式に対応                 |
| NFR-CA-05 | 営業日計算の正確性             | 祝日・休業日を正しく除外した計算結果   |
