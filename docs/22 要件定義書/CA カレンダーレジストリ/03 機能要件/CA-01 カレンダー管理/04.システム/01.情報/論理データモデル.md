# 論理データモデル

## 概要

CA-01 カレンダー管理業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    CALENDAR
    {
        string CALENDAR_ID PK "カレンダーID"
        string 名前 "名前"
        string タイプ "タイプ"
        string 有効期間 "有効期間"
        string 作成日 "作成日"
        string 更新日 "更新日"
        string state "状態(カレンダー)"
        enum variation "バリエーション(カレンダータイプ)"
        string created_at "作成日"
        string updated_at "更新日"
    }

    HOLIDAY
    {
        string HOLIDAY_ID PK "祝日ID"
        string 日付 "日付"
        string 名前 "名前"
        string 作成日 "作成日"
        string created_at "作成日"
        string updated_at "更新日"
    }
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| カレンダー | CALENDAR_ID | string | true | カレンダーID |
| 祝日 | HOLIDAY_ID | string | true | 祝日ID |
