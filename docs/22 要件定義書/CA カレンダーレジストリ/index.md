# カレンダーレジストリ

## 概要

本ドキュメントは、カレンダーレジストリ（CA）事業領域の要件定義をまとめます。

カレンダーレジストリは、システム全体で利用する祝日・休日情報を一元管理する共通マスター管理モジュールです。デジタル庁/内閣府が公開する祝日データをCSVインポートにより取り込み、日付単位の検索・年単位の検索・期間検索を提供し、業務システムが正確な祝日判定を行える基盤を提供します。さらに、祝日・休業日を除外した営業日計算を提供し、Azure DevOps（アジルーム）などのプロジェクト管理ツールでスプリント終了日を算出する際に利用できます。
