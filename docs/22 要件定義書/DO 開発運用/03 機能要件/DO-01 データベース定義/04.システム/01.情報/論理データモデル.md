# 論理データモデル

## 概要

DO-01 データベース定義業務領域の論理データモデルをMermaid ER図で表現します。

## ER図

```mermaid
erDiagram
    DATABASE
    {
        string DATABASE_ID PK "データベースID"
        string 名前 "名前"
        string 説明 "説明"
        string 作成日 "作成日"
        string created_at "作成日"
        string updated_at "更新日"
    }

    SCHEMA
    {
        string SCHEMA_ID PK "スキーマID"
        string 名前 "名前"
        string データベース "データベース"
        string 作成日 "作成日"
        string created_at "作成日"
        string updated_at "更新日"
    }

    TABLE
    {
        string TABLE_ID PK "テーブルID"
        string 名前 "名前"
        string スキーマ "スキーマ"
        string 作成日 "作成日"
        string created_at "作成日"
        string updated_at "更新日"
    }
    DATABASE }|--|| SCHEMA : データベース
    SCHEMA }|--|| TABLE : スキーマ
```

## 論理データ一覧

| データ名 | 項目名 | タイプ | isKey | 説明 |
|----------|--------|--------|-------|------|
| データベース | DATABASE_ID | string | true | データベースID |
| スキーマ | SCHEMA_ID | string | true | スキーマID |
| テーブル | TABLE_ID | string | true | テーブルID |
