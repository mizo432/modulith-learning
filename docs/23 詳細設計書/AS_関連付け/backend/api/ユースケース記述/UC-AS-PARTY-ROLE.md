## UC-AS-PARTY-ROLE-001 ロール定義を登録する

### 概要

新しいロール定義を登録する。

### アクター

- 主要アクター: 組織管理者 (AC-AS-01)

### 目標

組織管理者が新しいロール定義を登録できること。

### 前提条件

- システムが起動していること
- ユーザーが認証されていること
- ユーザーにAS:WRITE権限があること

### トリガー

組織管理者がロール定義の登録をリクエストする

### 基本フロー

1. 組織管理者がロール定義の登録をリクエストする
2. システムがリクエストデータをバリデーションする
3. システムがロール定義を登録する
4. システムが登録結果を返す
5. ユースケースが完了する

### 代替フロー

A1 重複したコードが存在する場合

- システムがエラーレスポンスを返す (409 Conflict)
- ユースケースが完了する

### 後件条件

- ロール定義が登録される

### API仕様

| 項目             | 値                          |
|------------------|-----------------------------|
| HTTPメソッド     | POST                        |
| エンドポイント   | `/api/as/v1/roles`          |
| 認証             | 必要                        |
| 権限             | AS:WRITE                    |
| リクエストボディ | あり                        |

#### リクエスト例

```json
POST /api/as/v1/roles HTTP/1.1
Host: localhost:8080
Authorization: Bearer {token}
Content-Type: application/json
Accept: application/json

{
  "roleCode": "EMPLOYEE",
  "roleName": "従業員",
  "roleTypeCode": "PERSON",
  "description": "一般従業員ロール"
}
```

#### レスポンス例 (成功: 201 Created)

```json
{
  "data": {
    "roleId": 1,
    "roleCode": "EMPLOYEE",
    "roleName": "従業員",
    "roleTypeCode": "PERSON",
    "description": "一般従業員ロール",
    "validFrom": "2024-01-01T00:00:00Z",
    "createdAt": "2024-01-01T00:00:00Z"
  }
}
```

## UC-AS-PARTY-ROLE-003 ロールを検索する

### 概要

条件に合致するロールを検索する。

### アクター

- 主要アクター: 組織管理者 (AC-AS-01)、JBジョブ管理 (AC-AS-03)、AGアジルーム (AC-AS-04)

### 目標

アクターが条件に合致するロールを検索できること。

### 前提条件

- システムが起動していること
- ユーザーが認証されていること
- ユーザーにAS:READ権限があること

### トリガー

アクターがロールの検索をリクエストする

### 基本フロー

1. アクターがロールの検索をリクエストする
2. システムが検索条件に合致するロールを検索する
3. システムが検索結果を返す
4. ユースケースが完了する

### 後件条件

- 検索結果が返される

### API仕様

| 項目             | 値                              |
|------------------|---------------------------------|
| HTTPメソッド     | GET                             |
| エンドポイント   | `/api/as/v1/roles/search`       |
| 認証             | 必要                            |
| 権限             | AS:READ                         |
| クエリパラメータ | あり                            |

#### クエリパラメータ

| パラメータ     | 型     | 必須 | 説明             |
|---------------|--------|------|------------------|
| roleTypeCode  | String | いいえ | ロール種類コード   |
| roleName      | String | いいえ | ロール名（部分一致） |

#### リクエスト例

```
GET /api/as/v1/roles/search?roleTypeCode=PERSON&roleName=従業員 HTTP/1.1
Host: localhost:8080
Authorization: Bearer {token}
Accept: application/json
```

#### レスポンス例 (成功: 200 OK)

```json
{
  "data": [
    {
      "roleId": 1,
      "roleCode": "EMPLOYEE",
      "roleName": "従業員",
      "roleTypeCode": "PERSON"
    }
  ],
  "metadata": {
    "totalElements": 1
  }
}
```
