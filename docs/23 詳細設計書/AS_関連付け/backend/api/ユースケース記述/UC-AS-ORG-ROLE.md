## UC-AS-ORG-001 組織を登録する

### 概要

新しい組織・部署を登録する。

### アクター

- 主要アクター: 組織管理者 (AC-AS-01)

### 目標

組織管理者が新しい組織・部署を登録できること。

### 前提条件

- システムが起動していること
- ユーザーが認証されていること
- ユーザーにAS:WRITE権限があること

### トリガー

組織管理者が組織の登録をリクエストする

### 基本フロー

1. 組織管理者が組織の登録をリクエストする
2. システムがリクエストデータをバリデーションする
3. システムがPartyを自動作成する
4. システムがOrganizationRoleを自動作成する
5. システムが組織情報を登録する
6. システムが登録結果を返す
7. ユースケースが完了する

### 後件条件

- Party、OrganizationRole、組織が登録される

### API仕様

| 項目             | 値                             |
|------------------|--------------------------------|
| HTTPメソッド     | POST                           |
| エンドポイント   | `/api/as/v1/organizations`     |
| 認証             | 必要                           |
| 権限             | AS:WRITE                       |
| リクエストボディ | あり                           |

#### リクエスト例

```json
POST /api/as/v1/organizations HTTP/1.1
Host: localhost:8080
Authorization: Bearer {token}
Content-Type: application/json
Accept: application/json

{
  "organizationCode": "ORG001",
  "name": "開発部",
  "organizationTypeCode": "DEPARTMENT",
  "parentOrganizationId": null
}
```

#### レスポンス例 (成功: 201 Created)

```json
{
  "data": {
    "organizationId": 1,
    "partyId": 1,
    "organizationCode": "ORG001",
    "name": "開発部",
    "organizationTypeCode": "DEPARTMENT",
    "status": "ACTIVE",
    "createdAt": "2024-01-01T00:00:00Z"
  }
}
```

## UC-AS-ORG-013 組織変更履歴を取得する

### 概要

組織の変更履歴を取得する。

### アクター

- 主要アクター: 組織管理者 (AC-AS-01)、システム運用者 (AC-AS-02)

### 目標

アクターが組織の変更履歴を取得できること。

### 前提条件

- システムが起動していること
- ユーザーが認証されていること
- ユーザーにAS:READ権限があること

### トリガー

アクターが組織変更履歴の取得をリクエストする

### 基本フロー

1. アクターが組織変更履歴の取得をリクエストする
2. システムが組織変更履歴を取得する
3. システムが変更履歴を返す
4. ユースケースが完了する

### 後件条件

- 変更履歴が返される

### API仕様

| 項目             | 値                                        |
|------------------|-------------------------------------------|
| HTTPメソッド     | GET                                       |
| エンドポイント   | `/api/as/v1/organizations/{organizationId}/history` |
| 認証             | 必要                                      |
| 権限             | AS:READ                                   |
| クエリパラメータ | あり                                      |

#### レスポンス例 (成功: 200 OK)

```json
{
  "data": [
    {
      "historyId": 1,
      "organizationId": 1,
      "changeType": "UPDATE",
      "changedAt": "2024-01-02T00:00:00Z",
      "changedBy": "admin"
    }
  ],
  "metadata": {
    "pageSize": 10,
    "pageNumber": 0,
    "totalElements": 1,
    "totalPages": 1
  }
}
```
