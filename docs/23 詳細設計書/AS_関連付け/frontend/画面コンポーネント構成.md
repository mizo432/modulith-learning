# AS_関連付け 画面コンポーネント構成

## 概要

AS関連付け事業領域のフロントエンド画面コンポーネント構成を定義します。
21画面を4つの業務領域に分類し、各画面のコンポーネント構成を整理します。

## 1. 共通コンポーネント

すべての画面で使用する共通コンポーネントを定義します。

### 1.1 レイアウトコンポーネント

| コンポーネント名 | 説明 |
|------------------|------|
| `AppLayout` | アプリケーション全体のレイアウト（ヘッダー、サイドバー、メインコンテンツ） |
| `Header` | ヘッダー（ロゴ、ユーザー情報、ログアウト） |
| `Sidebar` | サイドバーナビゲーション（事業領域別メニュー） |
| `Breadcrumb` | パンくずリスト |

### 1.2 入力コンポーネント

| コンポーネント名 | 説明 |
|------------------|------|
| `TextField` | 単一行テキスト入力 |
| `TextArea` | 複数行テキスト入力 |
| `SelectField` | ドロップダウン選択 |
| `DatePicker` | 日付選択 |
| `Checkbox` | チェックボックス |
| `RadioGroup` | ラジオボタングループ |
| `SearchBar` | 検索バー |

### 1.3 表示コンポーネント

| コンポーネント名 | 説明 |
|------------------|------|
| `DataTable` | データテーブル（ソート、ページネーション対応） |
| `Card` | カード表示 |
| `Badge` | ステータスバッジ |
| `Avatar` | アバター表示 |
| `Timeline` | タイムライン表示（履歴表示用） |

### 1.4 アクションコンポーネント

| コンポーネント名 | 説明 |
|------------------|------|
| `Button` | ボタン（Primary, Secondary, Danger） |
| `Dialog` | ダイアログ（確認、エラー通知） |
| `Toast` | トースト通知（成功、エラー、警告） |
| `Pagination` | ページネーションコントロール |

## 6. コンポーネント共通仕様

### 6.1 レスポンシブデザイン

| ブレークポイント | 画面幅 | 説明 |
|------------------|--------|------|
| モバイル | 768px未満 | 単一カラムレイアウト |
| タブレット | 768px〜1024px | 2カラムレイアウト |
| デスクトップ | 1024px以上 | 3カラムレイアウト |

### 6.2 アクセシビリティ

- WCAG 2.1 Level AA準拠
- キーボードナビゲーション対応
- スクリーンリーダー対応
- 色盲対応パレット使用

### 6.3 ローカライズ

- 日本語（ja-JP）をデフォルト言語
- 英語（en-US）対応予定
- 日付・数値のローカライズフォーマット適用

## 7. 設計チェックリスト

設計時・実装時に以下の項目を確認してください。

- [ ] 共通コンポーネントが適切に再利用されている
- [ ] レスポンシブデザインが適用されている
- [ ] アクセシビリティ基準を満たしている
- [ ] ローカライズ対応が完了している
- [ ] コンポーネント間のデータフローが明確である
- [ ] エラー状態の表示が適切に定義されている
- [ ] ローディング状態の表示が適切に定義されている
