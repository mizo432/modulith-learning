# AS_関連付け ステート管理設計

## 概要

AS関連付け事業領域のフロントエンドステート管理設計を定義します。
Redux Toolkitを採用し、グローバルステートとローカルステートを適切に分離して管理します。

## 参照

- 画面コンポーネント構成: [画面コンポーネント構成.md](./画面コンポーネント構成.md)
- API外部設計: [backend/api/index.md](../backend/api/index.md)

---

## 1. ステート管理アーキテクチャ

### 1.1 採用技術

| 技術 | 説明 |
|------|------|
| Redux Toolkit | グローバルステート管理 |
| React Context | ローカルステート管理（テーマ設定など） |
| React Query | サーバーステート管理（キャッシュ、再取得） |
| Zustand | 軽量ステート管理（モーダル状態など） |

### 1.2 ステート分類

| ステート種別 | 管理方法 | 例 |
|--------------|----------|-----|
| グローバルステート | Redux Toolkit | ユーザー情報、権限設定 |
| サーバーステート | React Query | 従業員一覧、組織一覧 |
| ローカルステート | React useState | フォーム入力値、UI状態 |
| UIステート | Zustand | モーダル表示、トースト通知 |

## 2. Redux スライス設計

### 2.1 共通スライス

#### authSlice（認証状態）

| 状態 | 説明 |
|------|------|
| `user` | 現在ログイン中のユーザー情報 |
| `token` | 認証トークン |
| `permissions` | ユーザーの権限一覧 |

**アクション:**
- `login` - ログイン成功
- `logout` - ログアウト
- `updatePermissions` - 権限更新

#### uiSlice（UI状態）

| 状態 | 説明 |
|------|------|
| `sidebarOpen` | サイドバー開閉状態 |
| `theme` | テーマ（ライト/ダーク） |
| `language` | 言語設定 |

**アクション:**
- `toggleSidebar` - サイドバー切替
- `setTheme` - テーマ設定
- `setLanguage` - 言語設定

### 2.2 AS-PARTY スライス

#### partySlice（パーティー状態）

| 状態 | 説明 |
|------|------|
| `selectedParty` | 現在選択中のパーティー |
| `partyForm` | パーティーフォーム状態 |
| `partyFilters` | 検索フィルター状態 |

**アクション:**
- `selectParty` - パーティー選択
- `setPartyForm` - フォーム更新
- `setPartyFilters` - フィルター更新
- `resetPartyForm` - フォームリセット

### 2.3 AS-PARTY-ROLE スライス

#### roleSlice（ロール状態）

| 状態 | 説明 |
|------|------|
| `selectedRole` | 現在選択中のロール |
| `roleForm` | ロールフォーム状態 |
| `roleAssignment` | ロール割り当て状態 |

**アクション:**
- `selectRole` - ロール選択
- `setRoleForm` - フォーム更新
- `setRoleAssignment` - 割り当て更新
- `resetRoleForm` - フォームリセット

### 2.4 AS-PERSON-ROLE スライス

#### employeeSlice（従業員状態）

| 状態 | 説明 |
|------|------|
| `selectedEmployee` | 現在選択中の従業員 |
| `employeeForm` | 従業員フォーム状態 |
| `employeeFilters` | 検索フィルター状態 |
| `affiliationChange` | 所属変更状態 |

**アクション:**
- `selectEmployee` - 従業員選択
- `setEmployeeForm` - フォーム更新
- `setEmployeeFilters` - フィルター更新
- `setAffiliationChange` - 所属変更更新
- `resetEmployeeForm` - フォームリセット

### 2.5 AS-ORG-ROLE スライス

#### organizationSlice（組織状態）

| 状態 | 説明 |
|------|------|
| `selectedOrganization` | 現在選択中の組織 |
| `organizationForm` | 組織フォーム状態 |
| `organizationFilters` | 検索フィルター状態 |

**アクション:**
- `selectOrganization` - 組織選択
- `setOrganizationForm` - フォーム更新
- `setOrganizationFilters` - フィルター更新

## 3. React Query 設計

### 3.1 クエリキー定義

各エンティティのクエリキーを定義します。

| エンティティ | クエリキー | 説明 |
|--------------|------------|------|
| Party | `['parties']` | パーティー一覧 |
| Party | `['parties', id]` | パーティー詳細 |
| Party Role | `['partyRoles']` | パーティーロール一覧 |
| Party Role | `['partyRoles', id]` | パーティーロール詳細 |
| Employee | `['employees']` | 従業員一覧 |
| Employee | `['employees', id]` | 従業員詳細 |
| Organization | `['organizations']` | 組織一覧 |
| Organization | `['organizations', id]` | 組織詳細 |
| Company | `['companies']` | 会社一覧 |
| Company | `['companies', id]` | 会社詳細 |
| Store | `['stores']` | 店舗一覧 |
| Store | `['stores', id]` | 店舗詳細 |

### 3.2 クエリ関数定義

| エンティティ | 関数名 | 説明 |
|--------------|--------|------|
| Party | `useGetParties` | パーティー一覧取得 |
| Party | `useGetParty` | パーティー詳細取得 |
| Party | `useCreateParty` | パーティー作成 |
| Party | `useUpdateParty` | パーティー更新 |
| Party | `useDeleteParty` | パーティー削除 |
| Employee | `useGetEmployees` | 従業員一覧取得 |
| Employee | `useGetEmployee` | 従業員詳細取得 |
| Employee | `useCreateEmployee` | 従業員作成 |
| Employee | `useUpdateEmployee` | 従業員更新 |
| Employee | `useDeleteEmployee` | 従業員削除 |
| Organization | `useGetOrganizations` | 組織一覧取得 |
| Organization | `useGetOrganization` | 組織詳細取得 |
| Organization | `useCreateOrganization` | 組織作成 |
| Organization | `useUpdateOrganization` | 組織更新 |
| Organization | `useDeleteOrganization` | 組織削除 |

### 3.3 キャッシュ戦略

| エンティティ | キャッシュ有効期間 |  staleTime |
|--------------|-------------------|------------|
| Party | 5分 | 1分 |
| Employee | 3分 | 30秒 |
| Organization | 10分 | 2分 |
| Company | 30分 | 5分 |
| Store | 10分 | 2分 |

## 6. ミドルウェア設計

### 6.1 採用ミドルウェア

| ミドルウェア | 説明 |
|--------------|------|
| Redux Thunk | 非同期処理（API呼び出し） |
| Redux Logger | デバッグ用ログ出力（開発環境のみ） |

### 6.2 カスタムミドルウェア

| ミドルウェア | 説明 |
|--------------|------|

## 7. ステート永続化

### 7.1 永続化対象

| ステート | 永続化先 | 説明 |
|----------|----------|------|
| 認証情報 | localStorage | トークン、ユーザー情報 |
| UI設定 | localStorage | テーマ、言語、サイドバー状態 |
| フィルター | sessionStorage | 検索フィルター状態 |

### 7.2 永続化戦略

| 項目 | 設計 |
|------|------|
| 保存タイミング | アクション発生時 |
| 復元タイミング | アプリケーション起動時 |
| 暗号化 | 認証トークンは暗号化して保存 |

## 8. 設計チェックリスト

設計時・実装時に以下の項目を確認してください。

- [ ] グローバルステートとローカルステートが適切に分離されている
- [ ] サーバーステートはReact Queryで管理されている
- [ ] Reduxスライスが適切に分割されている
- [ ] セレクターが適切に定義されている
- [ ] キャッシュ戦略が適切に設定されている
- [ ] ミドルウェアが適切に適用されている
- [ ] ステート永続化が適切に実装されている
- [ ] デバッグ用ログが適切に出力されている
