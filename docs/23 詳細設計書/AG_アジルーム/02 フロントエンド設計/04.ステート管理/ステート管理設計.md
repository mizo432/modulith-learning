# ステート管理設計

AG-04スプリント実行のステート管理を設計します。

## 1. ステート管理の階層

| スコープ | 手法 | 使用場面 |
|----------|------|----------|
| **ローカル** | `useState` | フォーム入力値、フィルター条件、UI状態 |
| **複雑なローカル** | `useReducer` | カンバンボードのドラッグ＆ドロップ状態 |
| **グローバル** | Context API | 現在選択中のスプリント情報 |
| **サーバー状態** | axios + カスタムフック | APIデータ取得・キャッシュ |

## 2. グローバルステート（Context API）

### 2.1 SprintContext

現在選択中のスプリント情報を全画面で共有します。

```typescript
// contexts/SprintContext.tsx

interface SprintContextValue {
  currentSprint: Sprint | null;
  setCurrentSprint: (sprint: Sprint | null) => void;
  clearCurrentSprint: () => void;
}

const SprintContext = createContext<SprintContextValue | null>(null);

export function SprintProvider({ children }: { children: React.ReactNode }) {
  const [currentSprint, setCurrentSprint] = useState<Sprint | null>(null);

  const clearCurrentSprint = useCallback(() => {
    setCurrentSprint(null);
  }, []);

  const value = useMemo(
    () => ({ currentSprint, setCurrentSprint, clearCurrentSprint }),
    [currentSprint, clearCurrentSprint]
  );

  return (
    <SprintContext.Provider value={value}>
      {children}
    </SprintContext.Provider>
  );
}

export function useSprintContext(): SprintContextValue {
  const context = useContext(SprintContext);
  if (!context) {
    throw new Error('useSprintContext must be used within SprintProvider');
  }
  return context;
}
```

## 3. サーバー状態（カスタムフック）

各カスタムフックは `AsyncState<T>` パターンに従います。

```typescript
interface AsyncState<T> {
  data: T | null;
  loading: boolean;
  error: ApiError | null;
  refetch: () => Promise<void>;
}
```

### 3.1 useSprintList

スプリント一覧を取得・管理します。

```typescript
// hooks/useSprintList.ts

export function useSprintList(
  productId: number,
  query: SprintListQuery = {}
): AsyncState<PaginatedResponse<Sprint>> & {
  createSprint: (request: CreateSprintRequest) => Promise<Sprint>;
  updateSprint: (id: number, request: UpdateSprintRequest) => Promise<Sprint>;
} {
  const [state, setState] = useState<AsyncState<PaginatedResponse<Sprint>>>({
    data: null,
    loading: true,
    error: null,
    refetch: async () => {},
  });

  const fetchSprints = useCallback(async () => {
    setState((prev) => ({ ...prev, loading: true, error: null }));
    try {
      const data = await getSprints({ productId, ...query });
      setState({ data, loading: false, error: null, refetch: fetchSprints });
    } catch (e) {
      setState({ data: null, loading: false, error: handleApiError(e), refetch: fetchSprints });
    }
  }, [productId, query]);

  useEffect(() => {
    fetchSprints();
  }, [fetchSprints]);

  const createSprint = useCallback(async (request: CreateSprintRequest) => {
    const newSprint = await createSprintApi(request);
    await fetchSprints();
    return newSprint;
  }, [fetchSprints]);

  const updateSprint = useCallback(
    async (id: number, request: UpdateSprintRequest) => {
      const updated = await updateSprintApi(id, request);
      await fetchSprints();
      return updated;
    },
    [fetchSprints]
  );

  return { ...state, refetch: fetchSprints, createSprint, updateSprint };
}
```

## 5. カンバンボードのステート管理（useReducer）

SCR-015のドラッグ＆ドロップ状態は `useReducer` で管理します。

```typescript
// hooks/useDragAndDrop.ts

type BoardAction =
  | { type: 'INIT_BOARD'; payload: KanbanBoardState }
  | { type: 'DRAG_START'; payload: { taskId: number; sourceStatus: TaskStatus } }
  | { type: 'DRAG_END'; payload: { taskId: number; destinationStatus: TaskStatus } }
  | { type: 'UPDATE_TASK'; payload: Task }
  | { type: 'SET_LOADING'; payload: boolean };

function kanbanReducer(state: KanbanBoardState, action: BoardAction): KanbanBoardState {
  switch (action.type) {
    case 'INIT_BOARD':
      return action.payload;

    case 'DRAG_START':
      // ドラッグ開始時のUI更新
      return { ...state };

    case 'DRAG_END': {
      const { taskId, destinationStatus } = action.payload;
      const updatedColumns = state.columns.map((column) => {
        if (column.status === destinationStatus) {
          // タスクを移動先列に追加
          return { ...column, tasks: [...column.tasks, /* moved task */] };
        }
        if (column.tasks.some((t) => t.id === taskId)) {
          // タスクを移動元列から削除
          return { ...column, tasks: column.tasks.filter((t) => t.id !== taskId) };
        }
        return column;
      });
      return { ...state, columns: updatedColumns };
    }

    case 'UPDATE_TASK':
      return {
        ...state,
        columns: state.columns.map((column) => ({
          ...column,
          tasks: column.tasks.map((task) =>
            task.id === action.payload.id ? action.payload : task
          ),
        })),
      };

    case 'SET_LOADING':
      return { ...state, loading: action.payload };

    default:
      return state;
  }
}

export function useDragAndDrop(sprintId: number) {
  const [state, dispatch] = useReducer(kanbanReducer, {
    columns: [],
    loading: true,
    error: null,
  });

  const onDragEnd = useCallback(
    async (result: DropResult) => {
      if (!result.destination) return;
      const { draggableId, destination } = result;
      dispatch({
        type: 'DRAG_END',
        payload: {
          taskId: Number(draggableId),
          destinationStatus: destination.droppableId as TaskStatus,
        },
      });
      // API呼び出しで状態を永続化
      await updateTaskStatus(Number(draggableId), destination.droppableId);
    },
    [sprintId]
  );

  return { state, onDragEnd };
}
```

## 6. ステート管理のルール

1. **ローカルステート優先**: 可能な限りローカルステートで管理
2. **Contextの適切な使用**: 現在選択中のスプリントのみContextで管理
3. **カスタムフックでの抽象化**: API通信はカスタムフックでカプセル化
4. **不変性の尊重**: ステートの更新は常に新しいオブジェクトを返す
5. **useMemo/useCallback**: 参照安定化により不要な再レンダリングを防止
