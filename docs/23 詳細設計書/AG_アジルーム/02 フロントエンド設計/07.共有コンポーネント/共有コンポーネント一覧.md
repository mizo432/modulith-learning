# 共有コンポーネント一覧

AG-04スプリント実行の複数画面で再利用される共有コンポーネントを定義します。

## 1. StatusBadge

スプリント状態やタスク状態をバッジ形式で表示します。

```typescript
interface StatusBadgeProps {
  status: SprintStatus | TaskStatus | ImpedimentStatus;
  size?: 'small' | 'medium';
}
```

**UI構成**:
- Chip: MUIのChipコンポーネント
  - 状態に応じた色分け
    - PLANNED: グレー
    - ACTIVE: 青
    - COMPLETED: 緑
    - CANCELLED: 赤
    - TODO: グレー
    - IN_PROGRESS: 青
    - DONE: 緑
    - BLOCKED: 橙
    - NEW: 紫
    - RESOLVED: 緑

**使用画面**: SCR-013, SCR-015

---

## 2. AssigneeChip

担当者情報をチップ形式で表示します。

```typescript
interface AssigneeChipProps {
  assigneeId: number | null;
  assigneeName: string | null;
  avatarUrl?: string;
  size?: 'small' | 'medium';
  onClick?: () => void;
}
```

**UI構成**:
- Chip: MUIのChipコンポーネント
  - Avatar: 担当者アバター（初期文字表示）
  - Label: 担当者名
  - クリック可能時はカーソル変更

**使用画面**: SCR-013, SCR-015, SCR-016

---

## 3. ProgressBar

進捗率をプログレスバーで表示します。

```typescript
interface ProgressBarProps {
  value: number; // 0-100
  size?: 'small' | 'medium' | 'large';
  showLabel?: boolean;
  color?: 'primary' | 'success' | 'warning' | 'error';
}
```

**UI構成**:
- LinearProgress: MUIのLinearProgress
  - 値に応じた色分け
    - 0-30%: 赤
    - 31-70%: 橙
    - 71-100%: 緑
  - showLabel=true の場合はパーセント表示

**使用画面**: SCR-013, SCR-015

---

## 4. ImpedimentBadge

障害の存在を示すインジケーターを表示します。

```typescript
interface ImpedimentBadgeProps {
  count: number;
  onClick?: () => void;
}
```

**UI構成**:
- Badge: MUIのBadge
  - 障害数を表示
  - 障害がある場合は警告アイコン
  - クリック可能時はDialogを開く

**使用画面**: SCR-015, SCR-016

---

## 5. NotificationBadge

未読通知数をバッジで表示します。

```typescript
interface NotificationBadgeProps {
  unreadCount: number;
  onClick?: () => void;
  max?: number; // 最大表示数（例: 99+）
}
```

**UI構成**:
- Badge: MUIのBadge
  - 未読数を表示
  - maxを超えた場合は "max+" 表示
  - クリック可能時は通知一覧を開く

**使用画面**: SCR-015

---

## 6. CapacityIndicator

容量と選択済みポイントの比率を視覚的に表示します。

```typescript
interface CapacityIndicatorProps {
  capacity: number;
  selected: number;
  color?: 'primary' | 'warning' | 'error';
}
```

**UI構成**:
- Card: 容量表示カード
  - LinearProgress: 選択比率の表示
  - 数値表示: 選択済み / 容量
  - 容量超過時は赤色で警告

**使用画面**: SCR-014

---

## 7. BuildStatusIndicator

ビルド・デプロイの状況を表示します。

```typescript
interface BuildStatusIndicatorProps {
  status: BuildStatus | null;
  size?: 'small' | 'medium';
}
```

**UI構成**:
- Icon: 状態に応じたアイコン
  - SUCCESS: 緑のチェックマーク
  - FAILURE: 赤の×マーク
  - RUNNING: 回転中のローダー
  - null: グレーのダッシュ

**使用画面**: SCR-015

---

## 8. DependencyTypeIcon

依存関係の種類をアイコンで表示します。

```typescript
interface DependencyTypeIconProps {
  type: DependencyType;
  size?: 'small' | 'medium';
}
```

**UI構成**:
- Icon: 依存タイプに応じたアイコン
  - BLOCKS: 停止アイコン（赤）
  - REQUIRES: リンクアイコン（青）
  - RELATES_TO: 関連アイコン（グレー）

**使用画面**: SCR-015

---

## 9. SprintHeader

スプリントのヘッダー情報を共通表示します。

```typescript
interface SprintHeaderProps {
  sprint: Sprint;
  showProgress?: boolean;
  onEdit?: () => void;
}
```

**UI構成**:
- AppBar: ヘッダーバー
  - Sprint名
  - 期間（開始日〜終了日）
  - 状態バッジ
  - 進捗バー（showProgress=trueの場合）
  - 編集ボタン（PO/SMのみ）

**使用画面**: SCR-013, SCR-014, SCR-015, SCR-016

---

## 10. EmptyState

データがない状態を表示します。

```typescript
interface EmptyStateProps {
  title: string;
  description?: string;
  actionLabel?: string;
  onAction?: () => void;
}
```

**UI構成**:
- Box: センター配置
  - Icon: 空状態のアイコン
  - Typography: タイトル
  - Typography: 説明
  - Button: アクションボタン（任意）

**使用画面**: SCR-013, SCR-015, SCR-016
