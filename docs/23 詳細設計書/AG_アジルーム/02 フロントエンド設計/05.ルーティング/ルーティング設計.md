# ルーティング設計

AG-04スプリント実行のReact Router v6によるルート設計を定義します。

## 1. ルート構成

```
/products/:productId/sprints          → SprintListPage (SCR-013)
/products/:productId/sprints/new      → SprintPlanningPage (SCR-014)
/products/:productId/sprints/:sprintId/planning  → SprintPlanningPage (SCR-014)
/products/:productId/sprints/:sprintId/board     → SprintBoardPage (SCR-015)
/products/:productId/sprints/:sprintId/daily-scrum → DailyScrumPage (SCR-016)
```

## 2. ルート定義

```typescript
// routes/SprintRoutes.tsx

import { lazy, Suspense } from 'react';
import { Routes, Route, Navigate } from 'react-router-dom';
import { SprintProvider } from '../contexts/SprintContext';

// コードスプリット
const SprintListPage = lazy(() => import('../pages/sprint/SprintListPage'));
const SprintPlanningPage = lazy(() => import('../pages/sprint/SprintPlanningPage'));
const SprintBoardPage = lazy(() => import('../pages/sprint/SprintBoardPage'));
const DailyScrumPage = lazy(() => import('../pages/sprint/DailyScrumPage'));

function LoadingFallback() {
  return <CircularProgress />;
}

export function SprintRoutes() {
  return (
    <SprintProvider>
      <Suspense fallback={<LoadingFallback />}>
        <Routes>
          {/* SCR-013: Sprint一覧・詳細 */}
          <Route
            path="/products/:productId/sprints"
            element={<SprintListPage />}
          />

          {/* SCR-014: Sprint Planning（新規） */}
          <Route
            path="/products/:productId/sprints/new"
            element={<SprintPlanningPage />}
          />

          {/* SCR-014: Sprint Planning（既存） */}
          <Route
            path="/products/:productId/sprints/:sprintId/planning"
            element={<SprintPlanningPage />}
          />

          {/* SCR-015: Sprint Board */}
          <Route
            path="/products/:productId/sprints/:sprintId/board"
            element={<SprintBoardPage />}
          />

          {/* SCR-016: Daily Scrum記録 */}
          <Route
            path="/products/:productId/sprints/:sprintId/daily-scrum"
            element={<DailyScrumPage />}
          />

          {/* デフォルト: Sprint一覧へリダイレクト */}
          <Route
            path="*"
            element={<Navigate to="/sprints" replace />}
          />
        </Routes>
      </Suspense>
    </SprintProvider>
  );
}
```

## 3. パスパラメータ

| ルート | パスパラメータ | 説明 |
|--------|---------------|------|
| `/products/:productId/sprints` | `productId` | 所属プロダクトID |
| `/products/:productId/sprints/new` | `productId` | 所属プロダクトID |
| `/products/:productId/sprints/:sprintId/planning` | `productId`, `sprintId` | 所属プロダクトID、スプリントID |
| `/products/:productId/sprints/:sprintId/board` | `productId`, `sprintId` | 所属プロダクトID、スプリントID |
| `/products/:productId/sprints/:sprintId/daily-scrum` | `productId`, `sprintId` | 所属プロダクトID、スプリントID |

## 5. 画面遷移フロー

### 5.1 Sprint一覧からPlanningへ

```
SprintListPage (SCR-013)
  → 「新規Sprint作成」ボタンクリック
  → /products/:productId/sprints/new (SCR-014)
  → Sprint作成完了
  → /products/:productId/sprints/:sprintId/board (SCR-015)
```

### 5.2 Sprint一覧からBoardへ

```
SprintListPage (SCR-013)
  → Sprint名クリック
  → SprintDetail Drawer表示
  → 「Boardへ移動」ボタンクリック
  → /products/:productId/sprints/:sprintId/board (SCR-015)
```

### 5.3 BoardからDaily Scrumへ

```
SprintBoardPage (SCR-015)
  → 「Daily Scrum」ナビゲーションクリック
  → /products/:productId/sprints/:sprintId/daily-scrum (SCR-016)
```

## 7. ガードルート

認証が必要なルートは `ProtectedRoute` で保護します。

```typescript
// routes/ProtectedRoute.tsx

interface ProtectedRouteProps {
  children: React.ReactNode;
  requiredPermission?: string;
}

export function ProtectedRoute({ children, requiredPermission }: ProtectedRouteProps) {
  const isAuthenticated = useAuth();
  const hasPermission = usePermission(requiredPermission);

  if (!isAuthenticated) {
    return <Navigate to="/login" replace />;
  }

  if (requiredPermission && !hasPermission) {
    return <Navigate to="/forbidden" replace />;
  }

  return <>{children}</>;
}
```

## 8. 404ハンドリング

存在しないパスへのアクセスは `NotFound` ページで統一します。

```typescript
<Route path="*" element={<NotFound />} />
```
