# コンポーネント一覧

AG-04スプリント実行の4画面（SCR-013〜SCR-016）のコンポーネント構成を定義します。

## 1. SCR-013 Sprint一覧・詳細

**ページコンポーネント**: `SprintListPage`

Sprintの期間、目標、選択Story、状態を確認する画面です。

### 1.1 コンポーネント構成

| コンポーネント | 種類 | 説明 |
|---------------|------|------|
| `SprintListPage` | コンテナ | ページのルートコンポーネント |
| `SprintFilter` | プレゼンテーション | 検索・フィルター領域 |
| `SprintList` | プレゼンテーション | Sprint一覧表 |
| `SprintListItem` | プレゼンテーション | Sprint一行の表示 |
| `SprintDetail` | プレゼンテーション | Sprint詳細（Drawer表示） |
| `SprintStats` | プレゼンテーション | サイドバーの状態別集計 |

### 1.2 SprintListPage

```typescript
interface SprintListPageProps {
  productId: number;
}
```

**ステート**:
- `sprints`: Sprint[] - スプリント一覧
- `selectedSprint`: Sprint | null - 選択中のスプリント
- `filter`: SprintListQuery - フィルター条件
- `loading`: boolean - ローディング状態
- `detailOpen`: boolean - 詳細Drawerの開閉状態

**API連携**:
- `useSprintList(productId, filter)` - スプリント一覧取得
- `useSprint(sprintId)` - スプリント詳細取得

### 1.3 SprintFilter

```typescript
interface SprintFilterProps {
  keyword: string;
  status: SprintStatus | 'ALL';
  dateRange: { from: string; to: string };
  onKeywordChange: (keyword: string) => void;
  onStatusChange: (status: SprintStatus | 'ALL') => void;
  onDateRangeChange: (range: { from: string; to: string }) => void;
  onSearch: () => void;
  onReset: () => void;
}
```

**UI構成**:
- TextField: 検索キーワード（最大100文字）
- Select: 状態フィルター（すべて/計画済み/実行中/完了/キャンセル）
- DatePicker: 期間フィルター（開始日〜終了日）
- Button: 検索、リセット

### 1.4 SprintList

```typescript
interface SprintListProps {
  sprints: Sprint[];
  onSelect: (sprint: Sprint) => void;
  onEdit: (sprint: Sprint) => void;
  loading: boolean;
}
```

**UI構成**:
- Table: Sprint一覧表
  - 列: Sprint名、期間、状態、チーム、ベロシティ
  - 状態は `StatusBadge` で表示
  - Sprint名は `SprintDetail` へのリンク
- Pagination: ページネーション
- CircularProgress: ローディング中表示

### 1.5 SprintListItem

```typescript
interface SprintListItemProps {
  sprint: Sprint;
  onSelect: (sprint: Sprint) => void;
  onEdit: (sprint: Sprint) => void;
}
```

**UI構成**:
- TableRow: Sprint一行
  - Sprint名（リンク）
  - 期間（開始日〜終了日）
  - 状態（StatusBadge）
  - チーム名
  - ベロシティ

### 1.6 SprintDetail

```typescript
interface SprintDetailProps {
  sprint: Sprint | null;
  open: boolean;
  onClose: () => void;
  onEdit: () => void;
}
```

**UI構成**:
- Drawer: 右側からスライドイン
  - ヘッダー: Sprint名、状態
  - 基本情報: 期間、チーム、ベロシティ
  - Sprint Goal: 目的の表示
  - 選択Story: 選択されたStory一覧（リンク付き）
  - 備考: 補足情報
  - アクション: 編集ボタン（PO/SMのみ）

### 1.7 SprintStats

```typescript
interface SprintStatsProps {
  stats: SprintStats;
}
```

**UI構成**:
- Card: 状態別集計
  - 総数
  - 実行中
  - 完了
  - キャンセル
- LineChart: ベロシティ推移（簡易表示）

## 2. SCR-014 Sprint Planning

**ページコンポーネント**: `SprintPlanningPage`

Sprint Goal、バックログ選択、容量・ベロシティ、タスク分解を協働で決める画面です。

### 2.1 コンポーネント構成

| コンポーネント | 種類 | 説明 |
|---------------|------|------|
| `SprintPlanningPage` | コンテナ | ページのルートコンポーネント |
| `SprintPlanningForm` | プレゼンテーション | Sprint基本情報フォーム |
| `SprintGoalEditor` | プレゼンテーション | Sprint Goal編集領域 |
| `BacklogSelector` | プレゼンテーション | バックログからのStory選択 |
| `TaskBreakdown` | プレゼンテーション | タスク分解領域 |
| `VelocityPanel` | プレゼンテーション | ベロシティ・容量表示 |

### 2.2 SprintPlanningPage

```typescript
interface SprintPlanningPageProps {
  productId: number;
  sprintId?: number; // 既存スプリントの編集時
}
```

**ステート**:
- `sprint`: Sprint | null - 編集中的スプリント
- `goal`: string - Sprint Goal
- `selectedStories`: Task[] - 選択されたStory
- `tasks`: Task[] - 分解したタスク
- `capacity`: number - チームの容量
- `activeTab`: 'goal' | 'backlog' | 'tasks' - アクティブなタブ
- `loading`: boolean - ローディング状態
- `formErrors`: Record<string, string> - バリデーションエラー

**API連携**:
- `useSprint(sprintId)` - 既存スプリント取得
- `useCreateSprint()` - スプリント作成
- `useUpdateSprint()` - スプリント更新
- `useCreateSprintBacklog()` - Sprint Backlog作成

### 2.3 SprintPlanningForm

```typescript
interface SprintPlanningFormProps {
  sprint: Partial<Sprint>;
  onChange: (sprint: Partial<Sprint>) => void;
  errors: Record<string, string>;
}
```

**UI構成**:
- TextField: Sprint名（必須、最大255文字）
- DatePicker: 期間開始日（必須）
- DatePicker: 期間終了日（必須、開始日以降）
- Autocomplete: チーム選択（必須）
- TextField: 備考（最大1000文字）

**バリデーション**:
- 期間終了日 >= 期間開始日
- Sprint名の必須チェック

### 2.4 SprintGoalEditor

```typescript
interface SprintGoalEditorProps {
  goal: string;
  onChange: (goal: string) => void;
  error?: string;
}
```

**UI構成**:
- TextField: Sprint Goal（必須、最大2000文字、multiline）
- CharacterCounter: 文字数カウンター
- ErrorMessage: バリデーションエラー表示

### 2.5 BacklogSelector

```typescript
interface BacklogSelectorProps {
  availableStories: Task[];
  selectedStories: Task[];
  capacity: number;
  onToggle: (story: Task) => void;
  onCapacityChange: (capacity: number) => void;
  error?: string;
}
```

**UI構成**:
- CheckboxList: 利用可能なStory一覧
  - Story名、見積もり値を表示
  - 選択済みのStoryはハイライト
- TextField: 容量入力（数値）
- CapacityIndicator: 選択合計 / 容量 の表示
  - 容量超過時は赤色で警告

**バリデーション**:
- 選択Storyの見積もり合計 <= 容量
- 少なくとも1つのStoryを選択

### 2.6 TaskBreakdown

```typescript
interface TaskBreakdownProps {
  stories: Task[];
  tasks: Task[];
  onAddTask: (task: CreateTaskRequest) => void;
  onUpdateTask: (task: UpdateTaskRequest) => void;
  onDeleteTask: (taskId: number) => void;
}
```

**UI構成**:
- TreeView: Story → Task の階層表示
  - Storyノード: 展開/折りたたみ可能
  - Taskノード: 編集・削除可能
- TaskFormDialog: タスク追加・編集Dialog
  - TextField: タスク名（最大500文字）
  - Autocomplete: 担当者選択
  - TextField: 見積もり（数値）
- DragAndDrop: タスクの並び替え

### 2.7 VelocityPanel

```typescript
interface VelocityPanelProps {
  velocity: number | null;
  capacity: number;
  selectedPoints: number;
}
```

**UI構成**:
- Card: ベロシティ情報
  - 過去のベロシティ表示
  - 現在の容量
  - 選択済みポイント
  - 残り容量

## 3. SCR-015 Sprint Board / タスクボード

**ページコンポーネント**: `SprintBoardPage`

Story・Taskの状態、作業中項目、ブロッカーを更新・確認する画面です。

### 3.1 コンポーネント構成

| コンポーネント | 種類 | 説明 |
|---------------|------|------|
| `SprintBoardPage` | コンテナ | ページのルートコンポーネント |
| `KanbanBoard` | プレゼンテーション | カンバンボード全体 |
| `KanbanColumn` | プレゼンテーション | 状態ごとの列 |
| `TaskCard` | プレゼンテーション | ドラッグ可能なタスクカード |
| `TaskDetailDrawer` | プレゼンテーション | タスク詳細Drawer |
| `ImpedimentDialog` | プレゼンテーション | 障害登録・編集Dialog |
| `DependencyPanel` | プレゼンテーション | 依存関係表示・編集 |
| `BuildStatusPanel` | プレゼンテーション | ビルド状況表示 |

### 3.2 SprintBoardPage

```typescript
interface SprintBoardPageProps {
  sprintId: number;
}
```

**ステート**:
- `tasks`: Task[] - タスク一覧
- `impediments`: Impediment[] - 障害一覧
- `dependencies`: Dependency[] - 依存関係一覧
- `selectedTask`: Task | null - 選択中のタスク
- `viewMode`: 'board' | 'list' - ビューモード
- `impedimentDialogOpen`: boolean - 障害Dialogの開閉
- `loading`: boolean - ローディング状態

**API連携**:
- `useTasks(sprintId)` - タスク一覧取得
- `useImpediments(sprintId)` - 障害一覧取得
- `useDependencies(sprintId)` - 依存関係一覧取得

- `useCreateImpediment()` - 障害作成

### 3.3 KanbanBoard

### 3.4 KanbanColumn

### 3.5 TaskCard

```typescript

  onClick: () => void;
```

**UI構成**:
- Draggable: ドラッグ可能なカード
  - Card: タスクカード
    - タスク名
    - 担当者（AssigneeChip）
    - 見積もり値
    - 進捗（ProgressBar）

### 3.6 TaskDetailDrawer

```typescript

  task: Task | null;
  open: boolean;
  onClose: () => void;

  impediments: Impediment[];
```

**UI構成**:
- Drawer: 右側からスライドイン

  - 依存関係: 依存する・依存される項目

  - ビルド状況: CI/CDパイプラインの状況
  - アクション: 状態変更、担当変更、障害追加

## 4. SCR-016 Daily Scrum記録

**ページコンポーネント**: `DailyScrumPage`

Sprint Goalに向けた状況、障害、計画調整を記録する画面です。

### 4.1 コンポーネント構成

| コンポーネント | 種類 | 説明 |
|---------------|------|------|
| `DailyScrumPage` | コンテナ | ページのルートコンポーネント |
| `DailyScrumForm` | プレゼンテーション | デイリースクラム記録フォーム |
| `DailyScrumList` | プレゼンテーション | 記録一覧 |
| `DailyScrumItem` | プレゼンテーション | 1日の記録表示 |
| `ScrumGoalSidebar` | プレゼンテーション | Sprint Goal表示 |

### 4.2 DailyScrumPage

```typescript
interface DailyScrumPageProps {
  sprintId: number;
}
```

**ステート**:
- `scrums`: DailyScrum[] - 記録一覧
- `selectedDate`: string - 選択中の日付
- `editingScrum`: DailyScrum | null - 編集中的記録
- `keyword`: string - 検索キーワード
- `activeTab`: 'list' | 'new' - アクティブなタブ
- `loading`: boolean - ローディング状態

**API連携**:
- `useDailyScrumList(sprintId)` - 記録一覧取得
- `useCreateDailyScrum()` - 記録作成
- `useUpdateDailyScrum()` - 記録更新

### 4.3 DailyScrumForm

```typescript
interface DailyScrumFormProps {
  scrum?: DailyScrum; // 編集時の既存データ
  sprintId: number;
  onSubmit: (scrum: CreateDailyScrumRequest | UpdateDailyScrumRequest) => void;
  onCancel: () => void;
  errors: Record<string, string>;
}
```

**UI構成**:
- TextField: 日付（必須、初期値: 今日）
- Autocomplete: 参加者（必須、複数選択）
- TextField: 昨日の成果（最大2000文字、multiline）
- TextField: 今日の計画（最大2000文字、multiline）
- TextField: 障害（最大1000文字、multiline）
- TextField: Sprint Goalへの状況（最大2000文字、multiline）
- TextField: 計画調整（最大1000文字、multiline）
- TextField: 備考（最大1000文字、multiline）
- Actions: 保存、キャンセル

**バリデーション**:
- 同じ日付の記録は1回のみ
- 少なくとも1人の参加者を選択

### 4.4 DailyScrumList
