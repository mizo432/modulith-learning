# AG_アジルーム データベース設計

## 概要

アジルーム（Agiloom）事業領域のデータベース設計資材を格納します。
Scrumに基づくアジャイルソフトウェア開発プロジェクトの管理をシステム化するデータベース設計です。

## スキーマ情報

| 項目           | 値             |
|----------------|----------------|
| 事業領域コード | AG             |
| 事業領域名     | アジルーム     |
| 事業領域区分   | コア           |
| スキーマ名     | `undecided_ag` |

## テーブル概要

アジルームでは、以下の主要なエンティティ群を管理します：

### プロダクト管理系

| テーブル名           | 説明                         |
|:---------------------|:-----------------------------|
| `products`           | Scrumプロジェクトの基本情報  |
| `teams`              | プロダクトに属するチーム     |
| `team_members`       | チームメンバー情報           |
| `product_visions`    | プロダクトビジョン・成果指標 |
| `definition_of_done` | 完了の定義（DoD）            |

### バックログ・ストーリー系

| テーブル名                | 説明                           |
|:--------------------------|:-------------------------------|
| `epics`                   | 大規模な機能単位               |
| `features`                | エピックを分解したフィーチャー |
| `user_stories`            | ユーザーストーリー情報         |
| `product_backlogs`        | 優先順位付けされたバックログ   |
| `story_statuses`          | ユーザーストーリーの状態定義   |
| `user_story_dependencies` | ユーザーストーリー間の依存関係 |

### スプリント・タスク系

| テーブル名        | 説明                               |
|:------------------|:-----------------------------------|
| `sprints`         | スプリントの期間・目標情報         |
| `sprint_backlogs` | スプリントで実施するタスクのリスト |
| `tasks`           | 作業単位の情報                     |
| `daily_scrums`    | デイリースクラムの記録             |
| `sprint_reviews`  | スプリントレビューの記録           |
| `retrospectives`  | レトロスペクティブの記録           |

### リリース系

| テーブル名 | 説明         |
|:-----------|:-------------|
| `releases` | リリース情報 |

### プロダクト準備系

| テーブル名              | 説明                               |
|:------------------------|:-----------------------------------|
| `product_preparations`  | プロダクトの立ち上げ準備期間と状態 |
| `preparation_tasks`     | 準備作業項目                       |
| `preparation_decisions` | 技術・業務上の意思決定記録         |
| `preparation_risks`     | 技術的・業務的リスク情報           |
