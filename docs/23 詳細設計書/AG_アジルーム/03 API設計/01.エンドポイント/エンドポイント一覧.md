# エンドポイント一覧

AG-04スプリント実行の全エンドポイントを定義します。

## 1. スプリント (Sprints)

### 1.1 スプリント一覧を取得

- **エンドポイント**: `GET /api/v1/sprints`
- **ユースケース**: UC-SP-003 スプリントを参照する
- **説明**: 検索条件に一致するスプリントの一覧をページネーションで取得します。
- **認証**: 必須
- **認可**: 全ロール

#### クエリパラメータ

| パラメータ | 型 | 必須 | 説明 | デフォルト |
|-----------|-----|------|------|-----------|
| `productId` | integer | いいえ | プロダクトIDでフィルタ | - |
| `status` | string | いいえ | 状態でフィルタ (PLANNED, ACTIVE, COMPLETED, CANCELLED) | - |
| `keyword` | string | いいえ | 名称・目標のキーワード検索 | - |
| `startDateFrom` | string (date) | いいえ | 開始日からの範囲検索 | - |
| `startDateTo` | string (date) | いいえ | 開始日までの範囲検索 | - |
| `pageNumber` | integer | いいえ | ページ番号 (0起点) | 0 |
| `pageSize` | integer | いいえ | ページサイズ | 20 |
| `sort` | string | いいえ | ソート条件 | `createdAt,DESC` |

#### レスポンス (200 OK)

```json
{
  "data": [
    {
      "id": 1,
      "productId": 1,
      "sprintNumber": 1,
      "name": "Sprint 1",
      "goal": "ユーザー認証機能を実装",
      "startDate": "2024-01-01",
      "endDate": "2024-01-14",
      "status": "ACTIVE",
      "teamId": 1,
      "teamName": "チームA",
      "velocity": 30,
      "notes": null,
      "createdAt": "2023-12-25T09:00:00Z",
      "updatedAt": "2024-01-01T09:00:00Z"
    }
  ],
  "metadata": {
    "pageNumber": 0,
    "pageSize": 20,
    "totalElements": 1,
    "totalPages": 1
  }
}
```

### 1.2 スプリントを作成

- **エンドポイント**: `POST /api/v1/sprints`
- **ユースケース**: UC-SP-001 スプリントを作成する
- **説明**: 新しいスプリントを作成します。
- **認証**: 必須
- **認可**: PRODUCT_OWNER, SCRUM_MASTER

#### リクエストボディ

```json
{
  "productId": 1,
  "sprintNumber": 2,
  "name": "Sprint 2",
  "goal": "ダッシュボード機能を実装",
  "startDate": "2024-01-15",
  "endDate": "2024-01-28",
  "teamId": 1
}
```

#### バリデーション

| フィールド | 制約 | 説明 |
|-----------|------|------|
| `productId` | 必須 | プロダクトID |
| `sprintNumber` | 必須, 1以上 | スプリント番号 |
| `name` | 必須, 1-100文字 | スプリント名称 |
| `goal` | 1000文字以内 | スプリント目標 |
| `startDate` | 必須 | 開始日 |
| `endDate` | 必須, startDate以降 | 終了日 |
| `teamId` | 必須 | チームID |

#### レスポンス (201 Created)

```json
{
  "id": 2,
  "productId": 1,
  "sprintNumber": 2,
  "name": "Sprint 2",
  "goal": "ダッシュボード機能を実装",
  "startDate": "2024-01-15",
  "endDate": "2024-01-28",
  "status": "PLANNED",
  "teamId": 1,
  "teamName": "チームA",
  "velocity": null,
  "notes": null,
  "createdAt": "2024-01-10T10:00:00Z",
  "updatedAt": "2024-01-10T10:00:00Z"
}
```

#### エラーレスポンス

| ステータスコード | エラーコード | 説明 |
|-----------------|-------------|------|
| 400 | VALIDATION_ERROR | バリデーションエラー |
| 409 | DUPLICATE_SPRINT | 同じsprintNumberのスプリントが既に存在 |
| 404 | PRODUCT_NOT_FOUND | プロダクトが見つからない |
