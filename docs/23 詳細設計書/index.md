# 外部設計

## 概要

本システム的外部設計資材を格納します。外部設計（基本設計）は、要件定義で決定した要件を組み込んだシステムの具体的な仕様を定める工程です。

## 外部設計の内容

外部設計では以下の項目を定義します：

- **画面設計**: 画面レイアウト、画面遷移、ボタンやリンクの配置、メニュー構成
- **機能設計**: 機能の構造、入出力の設計、操作による機能の定義
- **データ設計**: データの定義、データフロー、データ整合性
- **インターフェース設計**: 外部システムとの連携方法、API仕様
- **帳票設計**: 帳票のレイアウト、出力形式（電子帳票事業領域の場合）
