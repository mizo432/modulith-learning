# Requirements

### Overview & Goals

フェーズ5として、EF電子帳票の5つの業務領域（EF-01〜EF-05）に04.システムディレクトリを创建します。AGアジルームの完成パターンに従って、各業務領域に04.システム配下のサブディレクトリ（01.情報、02.ステート、03.イベント、04.画面、08.DDDモデル候補）と07
用語集を作成します。

### Scope

**In Scope**:

- EF-01〜EF-05の5つの業務領域に04.システムディレクトリを创建
-

各04.システムに01.情報（情報一覧、情報ER図、02.属性）、02.ステート（ステート一覧、ステートマシン図）、03.イベント（イベント一覧、イベントER図、01.イベント定義）、04.画面（画面一覧、画面ER図、画面定義）、08.DDDモデル候補（DDDモデル候補）を创建

- 各業務領域に07 用語集を创建

**Out of Scope**:

- 04.システム配下の詳細ファイル（情報属性一覧、イベント詳細、画面定義詳細）の创建は今後のステップ

### User Stories

As a 要件定義者, I want EF電子帳票の各業務領域に04.システムディレクトリを作成する so that
システムレイヤーの要件を整理できる.

### Functional Requirements

- AGアジルームの04.システムの構成パターンに従って、EF電子帳票の5つの業務領域に04.システムを创建
- 各サブディレクトリにテンプレートファイル（情報一覧、情報ER図、ステート一覧、ステートマシン図、イベント一覧、イベントER図、画面一覧、画面ER図、DDDモデル候補）を作成
- 各業務領域に07 用語集を作成

# Technical Design

### Current Implementation

- EF電子帳票の5つの業務領域（EF-01〜EF-05）には04.システムディレクトリが存在しない
- AGアジルームの04.システムには以下の構成がある：
    - 01.情報：情報一覧.md、情報ER図.md、02.属性（情報属性一覧ファイル）
    - 02.ステート：ステート一覧.md、ステートマシン図.md
    - 03.イベント：イベント一覧.md、イベントER図.md、01.イベント定義（イベント詳細ファイル）
    - 04.画面：画面一覧.md、画面ER図.md、画面定義ファイル
    - 08.DDDモデル候補：DDDモデル候補.md

### Key Decisions

- AGアジルームの04.システムの構成パターンをEF電子帳票に適用
- 各業務領域の04.システムにテンプレートファイルを作成し、詳細ファイルは今後のステップで追加

### Proposed Changes

1. EF-01〜EF-05の各業務領域に04.システムディレクトリを创建
2. 各04.システムに以下のサブディレクトリとファイルを作成：
    - 01.情報：情報一覧.md、情報ER図.md、02.属性（空ディレクトリ）
    - 02.ステート：ステート一覧.md、ステートマシン図.md
    - 03.イベント：イベント一覧.md、イベントER図.md、01.イベント定義（空ディレクトリ）
    - 04.画面：画面一覧.md、画面ER図.md
    - 08.DDDモデル候補：DDDモデル候補.md
3. 各業務領域に07 用語集ディレクトリと用語集.mdを作成

### Risks

- 各業務領域の情報、イベント、画面の数が異なるため、テンプレートファイルの内容は業務領域ごとに調整必要

# Testing

### Validation Approach

- 创建されたディレクトリとファイルが正しく存在するか確認
- AGアジルームの04.システムの構成パターンとEF電子帳票の04.システムの構成が一致するか確認

### Key Scenarios

- EF-01〜EF-05の各業務領域に04.システムディレクトリが存在する
- 各04.システムに01.情報、02.ステート、03.イベント、04.画面、08.DDDモデル候補のサブディレクトリが存在
- 各サブディレクトリにテンプレートファイルが存在
- 各業務領域に07 用語集ディレクトリと用語集.mdが存在

### Edge Cases

- 各業務領域の情報、イベント、画面の数が異なる場合の対応
- テンプレートファイルの内容が業務領域ごとに適切か確認

# Delivery Steps

### Step 1: Create 04.システム directories for EF-01 to EF-05

EF電子帳票の5つの業務領域に04.システムディレクトリとサブディレクトリを创建。

- EF-01〜EF-05の各業務領域に04.システムディレクトリを作成
- 各04.システムに01.情報、02.ステート、03.イベント、04.画面、08.DDDモデル候補のサブディレクトリを作成
- 01.情報に02.属性サブディレクトリ、03.イベントに01.イベント定義サブディレクトリを作成

### Step 2: Create template files for 04.システム

各04.システムにテンプレートファイル（情報一覧、情報ER図、ステート一覧、ステートマシン図、イベント一覧、イベントER図、画面一覧、画面ER図、DDDモデル候補）を作成。

- 01.情報に情報一覧.mdと情報ER図.mdを作成
- 02.ステートにステート一覧.mdとステートマシン図.mdを作成
- 03.イベントにイベント一覧.mdとイベントER図.mdを作成
- 04.画面に画面一覧.mdと画面ER図.mdを作成
- 08.DDDモデル候補にDDDモデル候補.mdを作成

### Step 3: Create 07 用語集 for EF-01 to EF-05

EF電子帳票の5つの業務領域に07 用語集ディレクトリと用語集.mdを作成。

- EF-01〜EF-05の各業務領域に07 用語集ディレクトリを作成
- 各07 用語集に用語集.mdファイルを作成
