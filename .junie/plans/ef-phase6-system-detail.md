# Requirements

### Overview & Goals

フェーズ7として、EF電子帳票の5つの業務領域（EF-01〜EF-05）に04.システム配下の詳細ファイル（情報属性一覧、イベント詳細、画面定義）を作成します。

### Scope

**In Scope**:

- EF-01〜EF-05の5つの業務領域に04.システム配下の詳細ファイルを作成
- 01.情報/02.属性に情報属性一覧ファイル（29情報）を作成
- 03.イベント/01.イベント定義にイベント詳細ファイル（46イベント）を作成
- 04.画面に画面定義ファイル（30画面）を作成

**Out of Scope**:

- 04.システム配下の骨格ファイル（情報一覧、情報ER図、ステート一覧、ステートマシン図、イベント一覧、イベントER図、画面一覧、画面ER図、DDDモデル候補）はフェーズ6で完了済み

### User Stories

As a 要件定義者, I want EF電子帳票の各業務領域に04.システム配下の詳細ファイルを作成する so that
システムレイヤーの要件を詳細に整理できる.

### Functional Requirements

- AGアジルームの04.システムの詳細ファイルパターンに従って、EF電子帳票の5つの業務領域に詳細ファイルを作成
- 情報属性一覧には属性名、型、PK、必須、説明を定義
- イベント詳細にはイベント定義、ペイロード、不変条件、関連イベント、実装上の注意を定義
- 画面定義には画面レイアウト、項目、操作、制約を定義

# Technical Design

### Current Implementation

- EF電子帳票の5つの業務領域（EF-01〜EF-05）には04.システムの骨格ファイルが存在（フェーズ6で完了）
- AGアジルームの04.システムには以下の詳細ファイルがある：
    - 01.情報/02.属性：情報属性一覧ファイル（各情報ごとに属性定義）
    - 03.イベント/01.イベント定義：イベント詳細ファイル（各イベントごとにペイロード、不変条件、関連イベント）
    - 04.画面：画面定義ファイル（画面レイアウト、項目、操作、制約）

### Key Decisions

- AGアジルームの04.システムの詳細ファイルパターンをEF電子帳票に適用
- 情報属性一覧は属性名、型、PK、必須、説明を定義
- イベント詳細はイベント定義、ペイロード、不変条件、関連イベント、実装上の注意を定義
- 画面定義は画面レイアウト、項目、操作、制約を定義

### Proposed Changes

1. EF-01〜EF-05の各業務領域に04.システム配下の詳細ファイルを作成
2. 01.情報/02.属性に情報属性一覧ファイルを作成（29情報）
3. 03.イベント/01.イベント定義にイベント詳細ファイルを作成（46イベント）
4. 04.画面に画面定義ファイルを作成（30画面）

### Risks

- 各業務領域の情報、イベント、画面の数が異なるため、ファイル数は業務領域ごとに調整必要

# Testing

### Validation Approach

- 作成された詳細ファイルが正しく存在するか確認
- AGアジルームの04.システムの詳細ファイルパターンとEF電子帳票の詳細ファイルが一致するか確認

### Key Scenarios

- EF-01〜EF-05の各業務領域に04.システム配下の詳細ファイルが存在する
- 01.情報/02.属性に情報属性一覧ファイルが存在
- 03.イベント/01.イベント定義にイベント詳細ファイルが存在
- 04.画面に画面定義ファイルが存在

### Edge Cases

- 各業務領域の情報、イベント、画面の数が異なる場合の対応
- 詳細ファイルの内容が業務領域ごとに適切か確認

# Delivery Steps

### ✓ Step 1: Create 04.システム directories for EF-01 to EF-05

EF電子帳票の5つの業務領域に04.システムディレクトリとサブディレクトリを作成。

- EF-01〜EF-05の各業務領域に04.システムディレクトリを作成
- 各04.システムに01.情報、02.ステート、03.イベント、04.画面、08.DDDモデル候補のサブディレクトリを作成

### ✓ Step 2: Create 01.情報 files for EF-01 to EF-05

各04.システムの01.情報サブディレクトリに情報一覧.mdと情報ER図.mdを作成。

- 情報一覧.mdには情報ID、情報名、情報種類、履歴管理要、証跡要、実現方法、説明を定義
- 情報ER図.mdにはPlantUML ER図（英語版・日本語版）と情報エンティティ一覧を定義
- EF-01：システム利用環境、業務システム、ストレージ接続、アクセス制御ポリシー、組織、利用者、ロール、外部APIキー、システム設定
- EF-02：帳票定義、帳票テンプレート、帳票生成設定、帳票情報、帳票バージョン
- EF-03：帳票配信、帳票プレビュー、帳票検索、承認・確認
- EF-04：保存期間、廃棄、アーカイブポリシー、アーカイブ対象、アーカイブ処理、帳票自動復元
- EF-05：通知設定、監査ログ、運用管理、帳票分析、アーカイブ運用

### ✓ Step 3: Create 02.ステート files for EF-01 to EF-05

各04.システムの02.ステートサブディレクトリにステート一覧.mdとステートマシン図.mdを作成。

- ステート一覧.mdには状態ID、状態名、対象情報、説明を定義
- ステートマシン図.mdにはPlantUML状態遷移図（英語版・日本語版）と状態一覧、遷移一覧を定義
- EF-01：システム利用環境、業務システム、ストレージ接続、アクセス制御ポリシー、組織、利用者、ロール、外部APIキー、システム設定の状態
- EF-02：帳票定義、帳票テンプレート、帳票生成設定、帳票情報、帳票バージョンの状態
- EF-03：帳票配信、帳票プレビュー、帳票検索、承認・確認の状態
- EF-04：保存期間、廃棄、アーカイブポリシー、アーカイブ対象、アーカイブ処理、帳票自動復元の状態
- EF-05：通知設定、監査ログ、運用管理、帳票分析、アーカイブ運用の状態

### ✓ Step 4: Create 03.イベント files for EF-01 to EF-05

各04.システムの03.イベントサブディレクトリにイベント一覧.mdとイベントER図.mdを作成。
